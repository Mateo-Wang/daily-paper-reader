## 摘要
视觉-语言-动作（VLA）模型通常采用以LLM为中心的(V → L → A)路径，即先将视觉观测投影到大型语言模型的表示空间中，再解码为机器人动作。尽管这种方法有效，但每次策略调用都会产生巨大的计算和内存开销。在本工作中，我们引入了TurboVLA，一种新的VLA范式，将传统的(V → L → A)路径重构为直接的(V + L → A)映射。TurboVLA不使用大型语言模型作为感知与动作之间的中央接口，而是独立编码视觉观测和语言指令，通过轻量级的双向视觉-语言交互直接在它们之间交换信息，并使用紧凑的解码器预测连续动作块。这种简单设计直接从视觉和语言特征构建任务条件表示，显著降低了VLA推理的计算和内存成本。在LIBERO上，TurboVLA仅用0.2B参数、31.2 ms推理延迟和0.9 GB推理显存（在消费级RTX 4090上）就实现了97.7%的平均成功率，匹配或超越了规模大得多的VLA策略。这些结果使TurboVLA成为当前以LLM为中心的VLA范式的简单而有效的替代方案，为如何连接视觉、语言和动作以实现高效机器人操作提供了新视角。代码可在https://github.com/H-EmbodVis/TurboVLA获取。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型是语言条件化机器人操作的主流框架，将视觉观测、自然语言指令和机器人动作统一到一个策略中。现有 VLA 模型普遍采用**以 LLM 为中心**的 `V → L → A` 路径：视觉观测先被投影到 LLM 的嵌入空间，与指令标记拼接后由大型语言模型统一处理，再从 LLM 表示中解码出动作。
- **核心问题**：这种以 LLM 为中心的设计虽然带来了丰富的语义理解能力，但在**每次策略调用时都会产生高昂的计算和内存开销**，导致推理延迟高、控制频率低，难以满足实时交互、高吞吐操作及资源受限平台上部署的需求。无论是自回归式（token-by-token 生成动作）还是动作专家式（并行连续解码），都保留了对大型语言骨干的依赖。
- **关键观察**：对于执行级操作任务，指令已经明确指定了要执行的操作技能，策略**不需要开放式的语言生成或自主任务分解**，而只需利用指令来确定当前视觉证据如何引导动作。轻量级文本编码器（如 BERT）即可提供执行相关的指令语义。
- **整体含义**：作者据此提出一个根本性反思——**执行级控制是否必须围绕大型语言模型展开？** TurboVLA 以直接 `V + L → A` 映射替代 LLM 中心路径，为 VLA 架构设计提供了一种更高效的新范式参考。

## 2. 方法论：核心思想、关键技术细节与流程

**核心思想**：将传统 `V → L → A` 重构为直接的 `V + L → A` 映射——分别编码视觉和语言，通过轻量级**双向视觉-语言交互**直接融合两种模态，再由紧凑的解码器一次前向预测完整动作块，**完全不经过大型语言模型**。

**整体流程**：视觉编码器（DINOv3）+ 轻量文本编码器（BERT）→ 投影到共享维度 d=256 → N=6 层双向交叉注意力交互 → ACT 风格 Transformer 解码器结合机器人状态预测连续动作块。

**关键技术细节**：
- **多模态特征编码**：
  - 语言指令经 BERT 编码，保留**完整的 token 序列**（而非池化向量），使对象、属性、空间关系等细粒度语义得以保留用于视觉调制
  - 每路图像经 DINOv3 提取空间特征，加上**位置编码和相机视角编码**，多视角特征沿序列维度拼接
  - 机器人本体状态经轻量投影网络单独编码，直接送入动作解码器，使跨模态交互专注于任务条件化的场景理解
- **视觉-语言交互模块**：堆叠 N 个双向交叉注意力层，每层包含层归一化、双向交叉注意力（视觉→指令注入场景上下文，指令→视觉调制视觉特征）及模态特定的 FFN，并带有残差连接。初始化自 Grounding DINO 的预训练特征增强权重
- **连续动作块预测**：采用 ACT 风格轻量 Transformer 解码器，使用 H 个可学习的动作查询（action queries）**并行**解码出完整的 H 步连续动作块，无需动作分词或自回归生成;训练使用简单的 L1 行为克隆损失，无需辅助语言建模目标
