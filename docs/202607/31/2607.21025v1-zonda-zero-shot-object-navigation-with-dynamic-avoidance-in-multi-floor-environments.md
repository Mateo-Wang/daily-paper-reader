## 摘要
在目标导向导航任务中，现有方法通常局限于静态和单层环境，忽略了跨楼层拓扑和动态行人，这限制了它们的实际部署。为解决这些限制，我们提出了ZONDA，一种具有动态避让框架的零样本目标导航。具体而言，ZONDA集成了三个核心组件：(i) 启发式多楼层规划：基于高度差可通行地图，无需特定平台的学习控制器即可实现楼梯穿越和跨楼层探索；(ii) 多视图目标验证：使用视觉-语言模型交叉检查多尺度观测，显著减少误报；(iii) 动态行人避让：显式跟踪和预测移动行人以生成预期行为。在真实的Direct Drive Tech TITA双足机器人以及HM3D和MP3D上的广泛模拟中评估，ZONDA取得了显著改进的结果。此外，与现有基线相比，ZONDA在动态基准HM3D-DYNA上能够保持稳健的导航性能。

## Abstract
In Object Goal Navigation task, existing methods are typically restricted to static and single-floor environments, ignoring cross-floor topologies and dynamic pedestrian, which limits their real-world deployment. To address these limitations, we propose ZONDA, a zero-shot object navigation with dynamic avoidance framework. In particular, ZONDA integrates three core components: (i) Heuristic multi-floor planning: from height-difference traversable maps, enables stair traversal and cross-floor exploration without a platform-specific learned controller; (ii) Multi-view target verification: cross-checks multi-scale observations with a vision-language model, significantly reducing false positives; and (iii) Dynamic pedestrian avoidance: explicitly tracks and predicts moving pedestrians to generate anticipatory behaviors. Evaluated on a real Direct Drive Tech TITA biped robot and extensive simulations on HM3D and MP3D, ZONDA achieves significantly improved results. Moreover, ZONDA can maintain robust navigation on the dynamic benchmark HM3D-DYNA compared to the existing baseline.

### 2. 方法论：核心思想、关键技术细节

ZONDA建立在**物体-语义-可遍历地图**之上，集成三个核心模块：

#### (a) 物体-语义-可遍历地图（Object-Semantic-Traversable Map）
- **物体地图**：利用RGB-D图像检测并分割物体，将掩码反投影至3D体素网格，按置信度分数δ累积（公式1：δ = clip(S_det · f_FOV · f_dist, 0, 1)），再投影至鸟瞰图得到2D物体地图（公式2按类别聚合垂直方向最大语义置信度）。
- **语义地图**：LLM推理目标最可能的房间类型，将物体名与房间类型编码为文本向量，与图像全局嵌入计算最大余弦相似度（公式3），投影至地图FOV区域并做指数移动平均时间平滑（公式4，α = 0.9）。
- **可遍历地图**：根据各栅格地面高度计算与8邻域的最大高度差（公式5），高度差小于机器人最大可跨越高度的区域视为可通行（含楼梯、坡道），否则视为垂直障碍。

#### (b) 启发式多楼层规划器（Heuristic Multi-Floor Planner）
- **单层探索**：
  - 安全前沿点经DBSCAN聚类为块B = {b₁, ..., b_M}；
  - 每块按公式6评分（宽度优先于语义得分、距离惩罚和语义奖励加权）；
  - 选择最高分块后，前沿访问顺序通过TSP的贪心最近邻启发式求解；
  - 全部探索完毕后切换至跨楼层模式。
- **跨楼层导航**：
  - 查询地图中语义为“楼梯”且满足高度差条件的栅格作为楼梯候选；
  - 机器人旋转360°采集全景图像进行VLM场景推理，确认梯段或新楼层；
  - 新旧楼层连接存入无向拓扑图G_topo = (N, E)，实现双向免重复探索。

#### (c) 多视图目标验证（Multi-View Target Verification）
- 为每个目标实例维护观测缓冲区，按质量分数Q = S_raw · f_area · f_edge（公式7）筛选视图，其中f_area偏好大而清晰的观测，f_edge惩罚接触图像边界的物体。
- 到达候选目标位置时，从缓冲区取出不同尺度（近景/远景）的高质量视图，**联合送入VLM进行交叉验证**，结合上下文与细节排除误报（如小收音机与电视的区分）。

#### (d) 动态行人避让管道（Dynamic Pedestrian Avoidance）
- 从RGB-D帧中检测并分割行人，将实例掩码内的深度点反投影获取3D质心；
- 采用恒定速度卡尔曼滤波器（状态x = [x, y, vx, vy]ᵀ）跟踪，匈牙利算法做数据关联；
- 未来T_pred = 3.0 s（每0.5 s采样）的外推轨迹**作为障碍物**投影到占据栅格，附加0.5 m安全膨胀；
- 全局路径由A*搜索规划，连续场景下用MPPI局部规划器输出平滑速度指令。

### 6. 主要结论与发现

- **HM3D**：ZONDA达成SR 66.5%、SPL 33.0%，SR超过最强零样本基线ASCENT（65.4% SR）与学习方法PIRLNav（64.1% SR）；ASCENT在SPL上仅高出0.5个百分点。
