## 摘要
端到端的视觉运动策略很少为人类提供理解或修正策略视觉注意力的机会。我们提出GuidedAttention，一种视觉运动模仿学习框架，将可解释且可修正的视觉注意力作为显式的中间表示。从相机图像预测任务相关的注意力关键点，并调节基于扩散的动作策略。用户可以在rollout初始化时检查并可选地修正选定的关键点，之后修正的注意力通过跟踪模块在执行过程中自动传播。在仿真和现实世界中的实验表明，GuidedAttention持续提高机器人操作性能，特别是在位置和外观分布外（OOD）条件下。

## Abstract
End-to-end visuomotor policies provide little opportunity for humans to understand or correct the policy's visual attention. We propose GuidedAttention, a visuomotor imitation learning framework that introduces interpretable and correctable visual attention as an explicit intermediate representation. Task-relevant attention keypoints are predicted from camera images and condition a diffusion-based action policy. Users can inspect and optionally correct selected keypoints once at rollout initialization, after which the corrected attention is automatically propagated throughout execution by a tracking module. Experiments in simulation and the real world demonstrate that GuidedAttention consistently improves robot manipulation performance, particularly under positional and appearance out-of-distribution (OOD) conditions.

## 1. 论文的核心问题与整体含义（研究动机和背景）

### 核心问题
- **端到端视觉运动策略缺乏可解释性**：传统端到端模仿学习策略直接从高维图像输入映射到动作输出，人类用户无法理解策略当前"在看什么"、"关注哪里"，也无法在策略失败时进行干预。
- **OOD 场景下性能显著下降**：当测试环境与训练分布存在偏差（如目标位置移动、背景纹理变化）时，策略容易丢失对任务相关物体的注意力焦点，导致操作失败。
- **现有方法不足**：尽管已有大量提升 OOD 鲁棒性的工作（如数据增强、分布约束等），但都缺少一个**人类可介入的显式接口**——人类明明能轻易看出问题所在，却无法将这一提示传达给策略。

### 整体含义
GuidedAttention 通过引入**可解释且可修正的视觉注意力**作为显式中间表征，架起了人类与端到端策略之间的桥梁：
- 策略不仅输出动作，还显式输出"注意力关键点"；
- 人类可以检查这些关键点的含义；
- 当预测不准时，可一次性修正，之后自动跟踪传播。

> 该工作的核心定位在于，**将人类从"旁观者"变成"可介入的监督者"**，在不牺牲自主执行的前提下提供纠正机制，这对于提升 OOD 泛化能力具有重要价值。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体架构（DP-GA）

DP-GA（Diffusion Policy with GuidedAttention）在感知与动作生成之间插入一个**显式的视觉注意力表示层**：

```
多视角 RGB 图像 + 本体感受关节状态
        ↓
视觉注意力编码器（AttnEnc）→ 预测注意力关键点 + 注意力特征
        ↓
注意力特征 + 本体感受特征 → 条件化 CNN 扩散策略（U-Net）
        ↓
动作生成
```

### 2.2 视觉注意力编码器（AttnEnc）

- **结构**：采用 DETR 风格架构（Transformer encoder-decoder），但不同于 DETR 预测边界框，**预测 2D 注意力关键点坐标**。
- **流程**：RGB 图像 → ResNet-18 骨干提取 patch 特征 → Transformer encoder（含位置编码）→ decoder 接收可学习 query → 输出注意力特征 → 线性坐标头映射为 2D 坐标：

\[
p_i = h_\theta(f_i) = A f_i + b
\]

- 每个图像输出 \(N_k\) 个关键点及其对应的注意力特征 \(\{f^i\}_{i=1}^{N_k}\)。
- 关键点损失为 MSE：

\[
\mathcal{L}_{kp} = \frac{1}{N_k} \sum_{i=1}^{N_k} \|p_i - p^{gt}_i\|_2^2
\]

### 2.3 关键点覆盖（Override）机制

**用户交互流程**：
1. 策略在 rollout 时预测关键点；
2. 用户检查关键点位置，判断是否偏移；
3. 按需修正**部分**关键点（可以只选 1 个关键点、只选 1 个相机视角）；
4. 修正后的坐标通过逆映射转为注意力特征并替换原特征：

\[
z_i = \begin{cases} f^i & (\text{prediction path}) \\ h^{-1}_\theta(p^{gt}_i) & (\text{override path}) \end{cases}
\]

**三重关键技巧**：

1. **前向-逆映射权重共享**：利用线性映射的解析伪逆 \(h^{-1}_\theta(p_i) = A^+(p_i - b)\)，无需额外参数；
2. **特征空间对齐损失**：鼓励前向预测特征与逆映射恢复特征一致：

\[
\mathcal{L}_{feat} = \frac{1}{N_k} \sum_{i=1}^{N_k} \left\| f^i - h^{-1}_\theta(p^{gt}_i) \right\|_2^2
\]

3. **随机特征路由**：训练时随机选择每个关键点的特征来自预测路径还是覆盖路径，防止扩散模型依赖单一通路。

### 2.4 关键点标注与跟踪

- **训练阶段**：人工仅在第一帧标注关键点（轻量级），后续帧由 Co-Tracker 自动传播；静态关键点全程固定。
- **Rollout 阶段**：策略自主预测关键点 → 用户可选一次性修正 → 跟踪模块自动传播修正后的关键点。

## 6. 主要结论与发现

### 6.1 核心结论

GuidedAttention（DP-GA）在各种条件下**一致优于**无显式注意力表征的基线：

| 条件 | 关键结果 |
|------|----------|
| **ID** | DP-GA 比 DP 提升约 15 pp；比 ACT 提升约 30 pp |
| **Pos-OOD（自主）** | DP-GA 比 DP 提升约 10 pp |
| **App-OOD（自主）** | DP-GA(default) 略逊于 DP，但 coord-as-feat 明显优于 DP |
| **OOD（+修正）** | 比自主执行提升 15-30 pp，比 DP 提升 20-30 pp |
| **真实世界** | 位置 OOD 下修正带来额外 +20-40 pp，外观 OOD 下约 +80 pp 提升 |

### 6.2 关键发现

1. **人类修正是一种高效的 OOD 恢复机制**：一次性纠正注意力可在无需持续监督的情况下大幅提升 OOD 性能；
2. **正确的训练策略（随机路由 + 注意力监督）至关重要**：去掉任一组件，修正功能几乎失效（成功率下降到 <26%）；
3. **显式注意力比 overlay prompting 更有效**：相比对输入图像叠加标记，通过注意力特征条件化策略性能更优（高出 20 pp+）；
4. **两个关键点已足够**：只要关键点选取得当，少量关键点即可取得高成功率，无需大量标注；
5. **相机视角的质量比数量更重要**：增加相机并不总是提升性能，选择能清晰观察任务相关结构的视角更为关键。

## 7. 优点

### 方法设计亮点

1. **新颖的"可修正注意力"范式**：不同于以往仅把注意力当作提高性能的潜在表示，GuidedAttention 将注意力作为人机交互的显式接口，概念上具有创新性；
2. **轻量标注设计**：仅需在第一帧标注，剩余帧利用现成跟踪器自动传播，极大降低数据标注成本；
3. **部分覆盖机制**：用户可只修正一个关键点、一个相机视图，交互成本低、灵活性高；
4. **前向-逆映射共享权重 + 特征对齐损失 + 随机路由**：这些技巧在工程层面解决了"如何让覆盖特征与预测特征协同工作"的问题，设计巧妙；
5. **对噪声鲁棒性好**：在一定范围（<8 像素）内性能几乎不受影响，表明方法在现实应用中具有一定的实用性。

### 实验设计亮点

6. **仿真 + 真实世界双验证**：且在真实世界中验证了外观 OOD（彩色积木强干扰），具有较高的说服力；
7. **多种消融和附加分析**：追踪/标注噪声、关键点数量、相机数量、与 MOP 对比等，覆盖面较广；

## 8. 不足与局限

### 方法自身的限制（论文已声明）

1. **假设少量关键点足以表征任务**：复杂任务可能需要更丰富或自适应的注意力表征；
2. **仅使用 2D 图像坐标**：未显式处理深度和遮挡，关键点不在视野内时性能可能下降；
3. **依赖现成跟踪模块**：跟踪质量（Co-Tracker）直接影响整体性能，严重变形或长期遮挡时可能出现跟踪失败；
4. **修正只在 rollout 初始化时进行**：如果执行中途注意力再次漂移，无法中途修正（设计如此，但也是限制）。

### 实验层面的局限

5. **任务数量有限（仿真 3 + 真实 3）**：集中在桌面抓取/放置类任务，未涉及更复杂的多阶段操作或移动操作；
6. **真实世界实验的充分性**：真实实验缺乏逐任务的表格化详细结果，仅以图的形式展示汇总数据；外观 OOD 只在 Towel Fold 单一任务上验证；
7. **未披露算力信息**：无法评估训练成本与可复现性；
8. **消融实验只在单一任务（Ring）上进行**：扩展到其他任务是否同样成立，证据稍显不足；
9. **与最先进基线比较有限**：仅对比了 DP 和 ACT，未与近年基于基础模型的策略（如 RT-2、π0 等）或其他 OOD 鲁棒性方法（如 ROSIE、RoCoDA）进行对比。

### 潜在偏差风险

10. **人工修正的"人"可能存在偏差**：关键点标注和修正由作者团队完成，未进行多用户研究，交互成本与 UX 欠缺量化；
