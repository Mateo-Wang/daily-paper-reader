## 摘要
连续环境下的视觉与语言导航（VLN-CE）要求智能体在低延迟执行动作的同时，维护长时间跨度的视觉历史以确保轨迹一致性。现有的基于视频的VLN方法通常难以同时满足这两个需求。为应对这些挑战，我们提出了MemVLN，一种新颖的VLN框架，以实时推理效率（14 FPS）实现了最先进的性能。MemVLN利用视觉编码器处理连续观测，并使用大语言模型（LLM）解释指令和生成动作。我们方法的核心是一种应用金字塔分辨率的情景记忆管理机制。该机制将计算集中在即时感知上，同时保留压缩的长期历史。作为该设计的补充，我们引入了程序性记忆，通过紧凑的原子级中层动作词汇表实现快速动作，从而绕过自回归解码延迟。在VLN-CE上的实验表明，MemVLN-4B在R2R中的SR比基线Qwen3-VL-4B架构高出5.8%，在RxR中高出9.7%，同时推理延迟实现了7倍的加速。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires agents to maintain long-horizon visual history for trajectory consistency while executing actions with low latency. Existing video-based VLN approaches typically struggle to satisfy both demands simultaneously. To address these challenges, we propose MemVLN, a novel VLN framework that achieves state-of-the-art performance with real-time inference efficiency (14 FPS). MemVLN utilizes a visual encoder to process continuous observations and a Large Language Model (LLM) to interpret instructions and generate actions. Central to our approach is an Episodic Memory management that applies pyramidal resolutions. This mechanism concentrates computation on immediate percepts while retaining compressed long-term history. Complementing to this design, we introduce Procedural Memory for fast action with a compact vocabulary of atomic mid-level actions to bypass auto-regressive decoding latency. Experiments on VLN-CE show that MemVLN-4B surpasses the baseline Qwen3-VL-4B architecture by 5.8\% SR in R2R and 9.7\% SR in RxR, while achieving a 7$\times$ speedup in inference latency.

## MemVLN 论文总结

### 1. 核心问题与研究动机

- **背景**：VLN-CE（连续环境下的视觉与语言导航）要求智能体在未知的三维空间内，依据自然语言指令从起点导航至终点，且无预设地图辅助。相比离散图结构，连续环境要求智能体将语言线索直接映射到原始视觉观测，并执行低层级动作规划。
- **核心矛盾**：导航任务必须同时满足两个需求：
  - **长时视觉历史维护**：需要保留足够长的历史观测序列，以保证轨迹一致性和防止路径漂移；
  - **低延迟执行**：需要实时响应环境变化，确保动作控制流畅。
- **现有方法的不足**：
  - 固定帧数采样（如 NaVILA 均匀采样 8 帧）牺牲了时间密度，无法充分捕捉连续动态；
  - Token 合并/池化压缩方法（如 Uni-NaVid、StreamVLN）破坏视觉 token 的 2D 空间拓扑结构，与现代架构（如 M-RoPE 位置编码）存在兼容性冲突。
- **本文目标**：提出一种既充分利用长时视觉上下文、又能达到实时推理速度的统一 VLN 框架。

### 2. 方法论

#### 2.1 总体架构（MemVLN）

- 采用 **Qwen3-VL** 作为 LVLM 骨干（4B 和 8B 两个版本），由视觉编码器处理连续单目 RGB 观测，LLM 负责指令理解与动作生成。
- 核心创新：“**双记忆机制**”——情景记忆 + 程序性记忆，分别解决观测管理效率和推理速度问题。

#### 2.2 情景记忆（Episodic Memory）——金字塔分辨率机制

- **动机来源**：注意力分析实验发现——在动作生成时，最新 4 帧观测贡献了超过 50% 的视觉注意力，近期观测的注意力权重显著高于远期观测。
- **核心思想**：模仿人类记忆的时间粒度偏差——近期事件保留高感知保真度，远期经历则渐进压缩。将历史帧划分为三个时间层级，并按层级设置不同的空间分辨率：

| 层级 | 时间范围 | 分辨率 | 采样尺寸 |
|---|---|---|---|
| 即时（immediate） | `T - B_short < t ≤ T - 1` | 高（`r_imm`） | 512 × 512 |
| 短期（short-term） | `T - B_long < t ≤ T - B_short` | 中（`r_short`） | 256 × 256 |
| 长期（long-term） | `0 ≤ t ≤ T - B_long` | 低（`r_long`） | 128 × 128 |

- **关键设计**：参数满足 `r_imm > r_short > r_long`，且长时序列累计 token 数不超过单帧即时帧的 token 数。这样在固定上下文窗口内大幅扩展了智能体的有效“回看”范围。
- **与 Token Merging 的对比**：已在方法部分明确论证了优势。Token merging 在潜在空间基于语义相似性聚类，破坏均匀 2D 空间网格，导致与 M-RoPE、DeepStack 不兼容；金字塔分辨率在原始像素空间（输入 LLM 之前）下采样，保持严格均匀的空间拓扑结构，从而与主流架构完全兼容。
- **变体探索**：比较了 U 型、递减型、递增型三种配置。注意力分析实验为递增型（Ascending）提供了依据——近期帧应保留最高分辨率。

#### 2.3 程序性记忆（Procedural Memory）——快速动作机制

- **瓶颈分析**：自回归解码是延迟的主要来源。生成首 token 因预填充耗时较长，后续 token 的生成时间随输出长度近似线性增长（如表 1 所示：输出 170 token 时延迟 5199ms，输出 10 token 时为 360ms），远超过实时控制所需的延迟阈值。
- **核心思想**：模仿人类程序性记忆（执行技能时自动无意识运作），将导航决策重构为**单次前向预测**——用单 token 表示一个中层动作或短时动作组合。通过从 LLM 原始词汇表中借用单 token 来映射扩增动作，完全绕过自回归循环。
- **扩增动作词汇表（Aaug）** 包含 10 个原子动作（见附录 E 表 8）：
  - 停止/结束导航；
  - 前进短距（25cm）、中距（50cm）、长距（75cm）；
  - 左转 15°/30°/45°；
  - 右转 15°/30°/45°。

#### 2.4 训练目标与数据

- **目标函数**：标准的交叉熵损失（CE Loss），监督扩增动作空间的单 token 预测：

$$L = -\frac{1}{T} \sum_{t=1}^{T} \log P(a_t^* \mid F_t, I; \theta)$$

- **训练数据**：R2R、RxR 及 EnvDrop 增强变体，随机采样的 416K 对 ScaleVLN 数据（来自 HM3D 和 Gibson 环境），557K 条人类导航轨迹，278K 条 DAgger 算法合成的数据。

### 6. 主要结论与发现

- **SoTA 性能**：MemVLN-8B 在 R2R 上取得 58.4% SR、65.3% OS，在 RxR 上取得 66.0% SR、57.3% SPL，均优于现有方法（含依赖深度/里程计/全景图的方法）。
- **实时性突破**：MemVLN-4B 达到 14 FPS 的推理速度，较自回归基线提升 7 倍，且无性能损失。
- **快速动作的双重收益**：不仅加速推理，还**提升了导航精度**（R2R 上 SR 绝对提升 1.8%，RxR 上提升 2.1%），说明原子动作的紧凑表征本身有助于动作决策。
- **金字塔分辨率有效性**：最佳配置（4 个即时帧 + 8 个短期帧 + 32 个长期帧）较无金字塔基线在 R2R 上 SR 提升 1.2%、SPL 提升 1.9%；OS 指标变化小，说明金字塔设计的主要贡献在于帮助智能体正确执行**停止**动作而非仅到达目标附近。
- **上升型（Ascending）金字塔最佳**：进一步验证了近期观测对决策最关键。
- **数据规模化收益明显**：DAgger 在线策略数据贡献最大（R2R 上 OS/SPL 分别提升 2.4% 和 0.6%，RxR 上 OS/SR 分别提升 4.6% 和 3.5%）；人类活动数据和 ScaleVLN 数据虽导致指标小幅回落，但保留它们可增强环境多样性。
- **跨数据集泛化竞争力强**：仅在 R2R 上训练，即可在 RxR 上实现 47.9% OS、38.4% SR、33.8% SPL，显著超越 NaVILA 等基线（SR 提升 12%，SPL 提升 20%）。
- **RxR 上性能优于 R2R**：定性分析表明 RxR 的指令更详细、语义锚定更强，有助于智能体保持正确路径。

### 7. 优点

- **认知启发的双记忆架构富有新意**：将情景记忆与程序性记忆的概念引入 VLN 框架，分别对应观测历史管理和动作执行效率，两个模块各司其职、相互协同。
- **金字塔分辨率设计精巧且工程友好**：在原始像素空间降采样，不改变 backbone 内部机制，兼容 M-RoPE 和 DeepStack；注意力分析为设计提供了数据支撑，而非凭空假设。
- **单 token 快速动作机制直击痛点**：精准识别了 VLM 用于导航的延迟瓶颈（自回归解码），并通过扩增单 token 词汇表从根上消除这一问题，同时带来精度收益，实现“以快促准”。
- **实验全面且有说服力**：覆盖主对比、模块消融、超参探索、数据贡献归因、跨域泛化、推理延迟量化等多个维度；消融实验中控制总 token 数恒定，保证了对比的公平性。
- **应用价值突出**：仅依赖单目 RGB 输入，不依赖深度传感器或里程计，降低了对传感器质量的依赖，实用性更强；14 FPS 推理速度使其具备部署潜力。

### 8. 不足与局限

- **计算资源门槛高**：依赖 8 块 H200 GPU（140GB 显存）进行训练，1 epoch 仍需 27 小时，扩展至更大规模模型在算力上困难。
- **硬件部署限制**：推理仍需 GPU 加速，不适用于无 GPU 的轻量边缘设备或功率受限的移动机器人平台，实际落地范围受限。
- **视觉模态单一隐含脆弱性**：仅依赖单目 RGB，在光照变化、遮挡严重或纹理稀缺环境下，性能可能显著退化。
- **受限于室内场景与数据分布**：R2R 和 RxR 都是室内轨迹，实验中加入的 ScaleVLN、人类导航数据也来自室内环境，训练数据不覆盖室外或非结构化环境，通用性存疑。
- **动作词汇表简化可能限制灵活性**：10 个原子动作的粒度较粗（如前进仅 25/50/75cm），在需要精细操作或复杂交互的场景中，可能无法表达必要的运动控制。
- **消融解释存在过强风险**：表 3 显示 fast action 同时提升精度与速度，但其精度增益可能部分来源于 token 语义差异（单 token 与文本描述序列的表示差异），而非快速机制本身，文章未严格区分这两种解释维度。
- **风险识别不充分**。
