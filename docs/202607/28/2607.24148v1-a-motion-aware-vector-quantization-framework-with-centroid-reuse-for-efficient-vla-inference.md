## 摘要
视觉-语言-动作（VLA）模型在具身智能中展现出强大潜力，但它们在GPU上的高推理延迟限制了实时部署。现有加速器（如Dadu-Corki）提升了效率，但将VLA模型视为全精度工作负载，未充分挖掘内存和计算中的冗余。本文提出VQVLA，一种通过利用权重相似性和执行动态来加速VLA推理的算法-硬件协同设计框架。我们首先引入MotionVQ，一种运动感知向量量化方案，根据机器人的执行状态动态调整量化精度，在减少内存访问的同时保持任务成功率。然后提出一种基于码本索引表示的合并质心向量化GEMM范式，通过质心的空间聚合和时间复用来消除冗余乘法。为实现这些优化，我们设计了一种高效支持动态精度选择和质心复用计算的加速器。实验结果表明，VQVLA相比A100 GPU、Dadu-Corki、LUT-DLA、CodeGEMM和ShiftAddLLM分别实现了6.5倍、2.8倍、1.9倍、3.3倍和4.3倍的加速，且精度下降可忽略不计。

## Abstract
Vision-Language-Action (VLA) models have demonstrated strong potential for embodied AI, yet their high inference latency on GPUs limits real-time deployment. Existing accelerators, such as Dadu-Corki, improve efficiency but treat VLA models as full-precision workloads, leaving substantial redundancy in both memory and computation underexploited.   In this paper, we propose VQVLA, an algorithm-hardware co-design framework that accelerates VLA inference by exploiting weight similarity and execution dynamics. We first introduce MotionVQ, a motion-aware vector quantization scheme that dynamically adjusts quantization precision based on the robot's execution state, reducing memory access while preserving task success rate. We then propose a merged-centroid vectorized GEMM paradigm that operates on the codebook-index representation, eliminating redundant multiplications through spatial aggregation and temporal reuse of centroids. To realize these optimizations, we design an accelerator that efficiently supports dynamic precision selection and centroid-reuse computation. Experimental results show that VQVLA achieves 6.5x, 2.8x, 1.9x, 3.3x, and 4.3x speedup over the A100 GPU, Dadu-Corki, LUT-DLA, CodeGEMM, and ShiftAddLLM, respectively, with negligible accuracy degradation.

## 1. 核心问题与整体含义（研究动机和背景）
视觉-语言-动作（VLA）模型在具身智能任务（如物体操作、空间导航）中展现出强大能力，但其在GPU上的推理延迟过高，难以满足实时控制需求（尤其在资源受限的边缘设备上）。现有加速器（如Dadu-Corki）虽能提升效率，但将VLA模型视为全精度黑盒，未挖掘模型内部的冗余（如权重相似性、执行动态中的量化敏感性差异）。  
**目标**：通过算法-硬件协同设计，在保持任务成功率的前提下，大幅降低VLA推理的内存开销和计算量，实现实时高效推理。

## 2. 提出的方法论

### 核心思想
利用VLA驱动机器人执行过程的两个关键洞察：
- **状态依赖的量化敏感性**：机器人动作幅度较小时（接近目标物体，执行状态）对量化更敏感；动作幅度较大时（过渡状态）对扰动更鲁棒。
- **质心访问频率不均衡**：向量量化（VQ）后，部分质心被频繁访问（热点质心），存在大量冗余乘法。

### 关键技术
#### (1) MotionVQ（运动感知向量量化）
- **状态预测**：根据上一轮VLA输出的3D动作幅度 \( D = \sqrt{A_x^2 + A_y^2 + A_z^2} \) 与阈值 \( T_d \)（设为0.8）比较，判断当前为执行状态（\( D \leq T_d \)）或过渡状态（\( D > T_d \)）。
- **精度适应**：离线准备两种精度配置：
  - 高精度：VQ[256, 2, 256]（平均4.125 bits）
  - 低精度：VQ[128, 2, 64]（平均3.125 bits）
- 运行时根据状态动态选取对应码本和索引矩阵。

#### (2) Merged-Centroid Vectorized GEMM（合并质心向量化GEMM）
直接在码本-索引表示上运算，无需反量化，通过两种技术消除冗余乘法：
- **空间合并**：利用同一列中相同质心对应的多个权重向量，先累加对应输入，再与质心相乘（分配律）。构造空间质心位置表，仅对计数>1的质心执行累加。
- **时间重用**：跨列缓存热点质心的乘法结果。离线Top-k选取最常用质心，运行时初始化结果缓存（1.5MB），通过标签匹配跳过重复计算。

#### (3) 专用加速器架构
由状态预测器（简单比较器）、矩阵乘法引擎（分为空间合并PE阵列和时间重用PE阵列）、索引处理引擎（多IPU并行构建质心位置表）组成。采用三级流水加法树支持可变输入数量的累加，缓存初始化单元预计算热点质心结果。
