## 摘要
世界动作模型（WAMs）通过联合建模视觉状态转换和机器人动作，为机器人操作提供了一种有前景的范式。然而，现有的WAMs受限于有限的时间上下文、粗糙的片段级语言监督以及主要以文本为条件的设定，这阻碍了任务进度跟踪和细粒度语言-视频-动作对齐，同时限制了视觉上下文推理和跨本体迁移。在本文中，我们介绍了WorldScape Policy 2.0，一种具有推理增强的长短期记忆的可控WAM。其因果短期视觉记忆提供最近观察作为DiT预填充，以保留局部交互动态，而其长短期事件记忆将历史VLM输出组织为全局历史、局部活跃和事件边界表示，用于进度感知检索。检索到的历史增强了感知和自回归生成的规划标记，为自主规划提供了隐式子目标条件；语义强制进一步将事件级指令语义注入这一潜在规划路径。为了建立细粒度多模态可控性，我们构建了ManipEvent-5M，一个事件导向的具身预训练数据集，包含近500万个事件片段，配有对齐的动作轨迹、片段级任务指令、片段级子任务描述、目标图像和视频演示。这些设计为从高层指令进行自主规划和从细粒度文本、目标图像或视频上下文提示进行可控执行提供了统一接口。在仿真和真实世界平台上的实验展示了在长时域自主规划、细粒度指令跟随和上下文适应方面的优越能力。

## Abstract
World Action Models (WAMs) offer a promising paradigm for robotic manipulation by jointly modeling visual state transitions and robot actions. However, existing WAMs are constrained by limited temporal context, coarse episode-level language supervision, and predominantly text-only conditioning, which hinder task-progress tracking and fine-grained language-video-action grounding while limiting visual-context reasoning and cross-embodiment transfer. In this paper, we introduce WorldScape Policy 2.0, a controllable WAM with reasoning-augmented long short-term memory. Its causal short-term visual memory supplies recent observations as DiT prefill to preserve local interaction dynamics, while its long short-term event memory organizes historical VLM outputs into global-history, local-active, and event-boundary representations for progress-aware retrieval. The retrieved history augments perception and autoregressively generated planning tokens, yielding an implicit subgoal condition for autonomous planning; semantic forcing further transfers event-level instruction semantics into this latent planning pathway. To establish fine-grained multimodal controllability, we construct ManipEvent-5M, an event-grounded embodied pretraining dataset containing nearly 5 million event segments with aligned action trajectories, episode-level task instructions, segment-level subtask captions, goal images, and video demonstrations. These designs provide a unified interface for autonomous planning from high-level instructions and controllable execution from fine-grained text, goal-image, or video-context prompts. Experiments in both simulation and real-world platforms demonstrate superior capabilities in long-horizon autonomous planning, fine-grained instruction following and in-context adaptation.

*   **研究背景**：机器人学习正从特定任务的策略向通用具身模型转变。世界动作模型（World Action Models, WAMs）通过联合建模视觉状态转换和机器人动作，为动作规划和环境适应提供了有前景的范式。
*   **核心问题**：当前的主流WAMs面临三个关键局限，阻碍其发展成为可控的长时域策略：
    1.  **上下文记忆有限**：多数模型仅依赖当前或极短的历史观察，无法感知任务进度（例如，在视觉上相似的中间子任务阶段，模型无法知道“已经做了什么”，从而做出错误的下一步决策）。
    2.  **粗粒度语言-动作对齐**：现有数据集通常提供整个片段的单一任务指令，缺乏对每个原子动作的细粒度语义监督，导致模型对细粒度指令变化不敏感。
    3.  **交互接口单一**：大部分WAMs仅支持文本作为控制指令，无法有效利用目标图像、演示视频等更直观的视觉提示，限制了视觉推理和跨本体迁移能力。
*   **整体含义**：本文旨在将WAM从一个仅能进行短时预测的模型，升级为一个具备长期记忆、细粒度可控且支持多模态交互的通用长时域策略。

### 2. 论文提出的方法论：核心思想、关键技术细节

本文提出了 **WorldScape Policy 2.0**，其核心是**推理增强的长短期记忆**和**事件级预训练**，以实现多功能可控的WAM。

*   **核心思想**：将长时域可控性分解为两种互补的上下文：**语义事件记忆**（用于推理任务进度）和**帧级视觉记忆**（用于保存局部交互动态）。

*   **关键技术细节**：
    1.  **推理增强的长短期记忆**:
        *   **短期视觉记忆**：一个因果 DiT 分支，缓存最近的几帧观察作为预填充（prefill），以保留局部交互的动态一致性。
        *   **长期事件记忆**：一个VLM推理分支，历史和当前片段信息被组织成三种视图：
            *   **全局历史**：整个轨迹的压缩摘要。
            *   **局部活跃**：最近完成的子任务片段。
            *   **事件边界**：关键子任务切换点。
        *   通过可学习的门控机制，当前VLM推理标记可以从历史记忆中检索并融合相关信息，增强感知和规划能力。
    2.  **隐式子目标潜在规划**:
        *   **语义强制（Semantic Forcing）**：在训练自主规划模式时，VLM生成的潜在规划标记会受到对应细粒度子任务描述的语义对齐损失（L_sem）的监督。这使得模型学会将高层任务指令隐式地分解为子目标，而无需在推理时显式提供。
    3.  **多模态控制接口**:
        *   **文本模式**：T5编码器编码细粒度指令，直接通过交叉注意力控制WAM。
        *   **自主规划模式**：VLM根据高层指令和记忆推理出子目标，输出潜在规划标记作为条件。
        *   **视觉提示模式**：目标图像或演示视频被编码为VAE潜在表示，作为持续的视觉预填充，用于目标条件策略或跨本体模仿学习。
    4.  **ManipEvent-5M数据集**:
        *   构建了一个事件级的多模态预训练数据集，包含约500万个事件片段。
        *   每个片段都包含细粒度子任务描述、目标图像、视频演示、动作轨迹和全局任务指令。
        *   来源包括真实机器人数据、人类手部演示视频、仿真数据等，并通过VLM进行层次化标注。
    5.  **三阶段训练课程**:
        *   **阶段1**: 在ManipEvent-5M上进行事件级基础WAM预训练，建立细粒度可控性和短期视觉记忆。
        *   **阶段2**: 引入VLM推理分支和长期事件记忆，通过语义强制进行自主规划能力的训练。
        *   **阶段3**: 在下游任务上进行微调，适应不同交互模式（自主规划、细粒度控制、视觉提示适应）。
