## 摘要
视觉-语言-动作策略是通用机器人控制的有前景基础，但长时程的类人移动操作要求机器人将任务对象视为跨越运动、接触、遮挡和恢复的持久物理实体。我们将此问题视为对象状态发散：用于调节全身动作的对象状态可能与用于判断动作是否实现预期物理关系的状态不同。我们提出持久对象令牌化（POT），该方法从RGB-D观测中维护角色索引的3D对象记录，并将其转换为面向全身动作专家的对象令牌。实例化为POT-VLA后，相同的对象记录既调节动作生成又支持几何谓词检查，从而形成一个对象状态既可操作又可验证的闭环执行系统。在宇树G1机器人上，POT-VLA在八个真实世界任务族中将匹配的直接GR00T-N1.7基线从39/80成功率提升至71/80。在外部Being-0对齐参考中，POT-VLA在对齐的服务任务上达到44/50成功率，而Being-0论文报告的成功率为37/50。最大的提升出现在需要维持3D关系的任务上，这表明持久化以对象为中心的状态是可验证的类人VLA执行的有用抽象。

## Abstract
Vision-language-action policies are a promising foundation for general robot control, but long-horizon humanoid loco-manipulation requires the robot to treat task objects as persistent physical entities across movement, contact, occlusion, and recovery. We study this problem as object-state divergence: the object state used to condition a whole-body action can differ from the state used to decide whether the action achieved the intended physical relation. We propose \emph{Persistent Object Tokenization} (POT), which maintains role-indexed 3D object records from RGB-D observations and converts them into object tokens for a whole-body action expert. Instantiated as \emph{POT-VLA}, the same object records condition action generation and support geometric predicate checks, yielding a closed-loop execution system in which object state is both actionable and verifiable. On a Unitree G1, POT-VLA improves a matched direct GR00T-N1.7 baseline from 39/80 to 71/80 successes over eight real-world task families. In an external Being-0-aligned reference, POT-VLA achieves 44/50 successes on aligned service tasks, compared with the 37/50 success reported by the Being-0 paper. The largest gains occur on tasks requiring maintained 3D relations, suggesting that persistent object-centered state is a useful abstraction for verifiable humanoid VLA execution.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在人形机器人长时程移动操作任务中，存在**对象状态发散**问题——用于调节全身动作的对象状态与用于验证动作是否实现预期物理关系的对象状态可能不一致。
- **具体表现**：机器人需要处理同一杯子、篮子、支撑面或交接伙伴等对象，在行走、抓取、放置、观察失败和恢复过程中必须保持这些对象的可寻址性。现代VLA策略通常基于当前观测的视觉-语言特征来调节动作，而任务进展可能由单独的监控器、谓词层或语言级状态来检查，导致细微的接地错误、抓取错误或放置错误引发过早的子任务转换、错误对象操作或无效恢复。
- **研究意义**：提出一种共享的、持久的、以对象为中心的物理记忆，使得对象状态既能用于动作生成，又能用于执行验证，从而闭环人形VLA执行。该方法显著提高了真实世界任务成功率，尤其是需要维持3D关系的任务（如堆叠、运输、容器放置、手递手交接）。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想：持久对象令牌化（Persistent Object Tokenization, POT）
- 从RGB-D观测中提取任务相关的3D对象记录，并按角色建立索引（如TARGET、DESTINATION、SUPPORT、HANDOVER_PARTNER）。
- 将这些记录序列化为持久3D对象令牌（Persistent 3D Object Tokens），供全身动作专家（whole-body action expert）使用。
- 同样的对象记录在动作执行后通过RGB-D刷新，并由几何谓词验证是否达到预期物理关系，形成“维护-动作-观察-验证-恢复”闭环。

### 关键技术细节

1. **任务角色对象记忆（Role-indexed object memory）**
   - 根据指令和当前观测，由VLM规划器或人工任务文件生成带类型子任务计划Π = ⟨task_id, I, {τ_i}⟩。
   - 每个子任务指定实体集E_i，POT构建角色索引对象记忆M_τi_t = {m_e_t | e ∈ E_i}。
   - 每条记录m_e_t包括：角色短语、图像框、3D质心和范围、置信度、可见性、关系特征（如对象-容器距离、支持高度、末端执行器-对象偏移、目标-目的地位移、对齐、包含、手递手线索）。

2. **对象令牌模式（Persistent token schema）**
   - 将M_τi_t映射到固定槽特征张量x_obj_t ∈ R^{K×F}（默认K=8个槽，每槽F=33个特征）。
   - 有效槽包含角色ID（TARGET等），未使用槽为PADDING并掩码。
   - 槽特征包括：可见性、置信度、归一化2D框、3D质心、3D范围、可选方向、关系特征。
   - 持久性体现在：任务实体绑定到角色槽，每个动作块后刷新度量证据；被遮挡或低置信度时角色槽仍存在，但可见性、置信度标记为不确定。

3. **对象令牌条件化的VLA执行**
   - 采用GR00T-N1.7作为学习型动作专家，保持Unitree G1全身动作表示和运行时。
   - 基线直接基于语言、视觉观测和本体感觉。POT-VLA在动作头序列前注入持久3D对象令牌。
   - 对象令牌投影器（f_obj_θ）将每个槽特征嵌入DiT隐藏维度，与角色嵌入、上下文嵌入组合，输入到动作头的自注意力序列（布局为[Z_state_t, Z_obj_t, Z_action_t]）。
   - 动作专家预测全身动作块â_{t:t+H}，执行后刷新对象记忆。

4. **谓词级验证与恢复（Geometric predicate supervisor）**
   - 读取同一角色索引对象记忆，检查子任务准备度（前提谓词）和执行后完成度（目标谓词）。
   - 每个谓词p = ⟨κ, α, op, ν, n⟩，通过标量证据ϕ(κ, α, M_τi_ξ)判断是否满足。
   - 状态返回：in_progress, done, blocked, failed, uncertain。
   - 提供诊断d_ξ定位失败模式（如缺失可见性、抓取失败、不稳定支撑、错误放置、手递手距离过大）。
   - 根据状态和诊断选择继续、重试、重新观察、重新接地或重新规划。

## 7. 优点

- **问题识别精准**：首次系统提出“对象状态发散”这一关键失败模式，并设计针对性解决方案。

- **实际部署友好**：使用在线SAM3掩码、深度反投影等现成模块，无需额外标注或仿真训练。
