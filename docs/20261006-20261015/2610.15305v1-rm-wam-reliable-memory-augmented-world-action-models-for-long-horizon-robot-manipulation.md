## 摘要
世界动作模型（WAMs）通过联合预测未来视觉状态和动作来提升机器人操作能力，但现有大多数方法主要基于当前观测进行决策。这限制了其在长时程任务中的可靠性，因为视觉上相似的状态可能对应不同的交互历史和任务阶段。此外，直接引入历史观测可能引入过时、阶段不匹配或受错误污染的信息，导致世界预测不准确和闭环误差累积。我们提出 RM-WAM，一种可靠的记忆增强世界动作模型，它将记忆视为依赖上下文的预测资源，而非普遍有用的历史上下文。RM-WAM 使用互补的短期视觉状态记忆和潜在事件记忆来表示历史，二者分别捕捉近期交互动态和较长期的状态转换。一种反事实记忆学习方案在保持当前输入和预测目标固定的同时改变可访问的历史，使模型能够学习历史记忆的上下文相关效用估计。基于该估计，一种效用感知门控机制自适应地控制记忆注入世界-动作主干网络。实验表明，RM-WAM 凸显了在长时程任务中可靠且选择性利用记忆的重要性。

## Abstract
World Action Models (WAMs) improve robotic manipulation by jointly predicting future visual states and actions, yet most existing methods make decisions primarily from the current observation. This limits their reliability in long-horizon tasks, where visually similar states may correspond to different interaction histories and task stages. Moreover, directly incorporating historical observations can introduce stale, stage-mismatched, or error-contaminated information, leading to inaccurate world prediction and accumulated closed-loop errors. We propose RM-WAM, a reliable memory-augmented World Action Model that treats memory as a context-dependent predictive resource rather than universally useful historical context. RM-WAM represents history using complementary short-term visual state memory and latent event memory, which respectively capture recent interaction dynamics and longer-term state transitions. A counterfactual memory learning scheme varies the accessible history while keeping the current inputs and prediction targets fixed, enabling the model to learn a context-dependent utility estimate for historical memory. Based on this estimate, a utility-aware gating mechanism adaptively controls memory injection into the world-action backbone. Experiments demonstrate that RM-WAM highlights the importance of reliable and selective memory utilization in long-horizon tasks.

# RM-WAM 论文总结

## 1. 核心问题与整体含义

- **背景**：视觉-语言-动作模型（VLA）通过在当前观测上直接预测下一动作，已具备较强的任务理解与泛化能力；但世界动作模型（WAM）进一步联合预测"动作条件下的未来视觉状态"与动作，从而同时回答"该做什么"和"世界会如何变化"。
- **核心痛点一**：现有 WAM 大多仍以**当前观测**为主要决策依据，在长时程任务中，视觉上相似的状态可能对应**不同的交互历史与任务阶段**，仅凭单帧无法区分。
- **核心痛点二**：直接把历史观测塞进模型会引入**陈旧（stale）、阶段错配（stage-mismatched）、误差污染（error-contaminated）**的信息，反而扭曲未来预测并导致闭环误差累积。
- **关键洞察**：把记忆机制从 VLA 迁移到 WAM 存在两个根本限制——(a) WAM 中记忆不仅要支撑动作生成，还要支撑**世界状态建模**，不当历史会直接污染预测未来；(b) **检索相关性 ≠ 可用性**，即使高度相关的记忆也可能过期或与当前阶段不符。
- **认知科学类比**：记忆不是被动回放缓冲，而是主动、依赖上下文的控制来源；人类会有选择地提取有助于当前目标的经验，并抑制干扰性记忆。
- **整体含义**：论文主张记忆增强 WAM 的核心挑战不只是"检索什么记忆"，而是"检索到的记忆**是否应该被使用**"，从而把记忆重新定义为**依赖上下文的预测资源**，而非默认有用的历史上下文。

## 2. 方法论

### 2.1 问题形式化
- 原始 WAM：`pθ(h_{t+1:t+Hv}, a_{t:t+Ha-1} | o_t, c, p_t)`，其中 `o_t`、`c`、`p_t` 分别为当前观测、语言指令、本体感知状态。
- 引入记忆集合 `M_t = (m_{t-δ1}, …, m_{t-δK})`（`0 < δ1 < … < δK`）后，改为记忆条件预测：`pθ(h_{t+1:t+Hv}, a_{t:t+Ha-1} | o_t, c, p_t, M_t)`。

### 2.2 整体框架（双分支 + 选择性记忆注入）
- **视频分支**：以 Wan2.2-TI2V-5B 为骨干（含 VAE 编解码器与 Video DiT），负责世界预测。
- **动作分支**：30 层 Diffusion Transformer（Expert DiT），输出连续动作块。
- **交互方式**：两支通过 Mixture-of-Transformers（MoT）耦合；语言与本体信息经 state/text encoder 注入。
- **记忆构造**：一层时序 Transformer 编码近期视觉隐 token → 短期视觉记忆；另一层 Transformer 编码历史隐状态转移 → 潜在事件记忆。
- **注入控制**：两类记忆各配一个轻量两层 MLP 门控，门控强度由反事实记忆监督学习。

### 2.3 反事实记忆（核心创新）
- 固定当前观测、指令、本体状态与预测目标，**只改变可访问的历史**，从而把记忆的影响从其他变量中隔离出来。
- 四种反事实条件：
  - `M_ref`：同回合内因果对齐的历史（参考条件）；
  - `M_stale`：时间上遥远的历史（同回合但相关性低）；
  - `M_stage`：在回合内**时间平移采样位置**，得到因果有效但与当前决策点阶段错配的历史（无需显式阶段标注）；
  - `M_cross`：来自同任务的**另一条轨迹**，保留任务语义但破坏与当前轨迹的对应关系。
- 每个条件配一个软效用目标 `q_v ∈ [0,1]`，作为记忆在当前预测上下文下相对可靠性的**监督代理**（非因果性能增益的直接测量）。实现中参考/陈旧/阶段/跨回合分别设为 1.0 / 0.01 / 0.01 / 0.01，反事实样本占训练数据 50%。

### 2.4 短期视觉记忆（Short Visual Memory）
- 取最近 K 帧与当前观测，用共享 VAE 编码为空间 patch token `P ∈ R^{B×(K+1)×N×dv}`。
- **不展平成 (K+1)N 的长序列**，而是重排为 `S ∈ R^{(BN)×(K+1)×dv}`，使每个空间位置形成短时序序列，由共享时序编码器聚合，得到历史条件表示 `R^s_t`，避免序列膨胀与背景重复。
- 门控注入：`X̃_cur = X_cur + g^s_t R^s_t`，其中 `g^s_t = σ(G_s(X_cur, R^s_t, c)) ∈ [0,1]`。

### 2.5 潜在事件记忆（Latent Event Memory）
- 在**共享隐空间**中构造，不使用图像级标签或离散事件检测器；以 16 步为间隔采样历史视觉隐状态，构成 `K_e` 个转移级候选。
- 每个候选 `U_i` 拼接：转移前隐状态 `Z^before_i`、转移后 `Z^after_i`、带符号变化量 `Z^after_i − Z^before_i` 及其绝对值，再加时间位置编码 → 编码为事件表示 `[e_1,…,e_{Ke}] ∈ R^{B×Ke×de}`。
- 以当前视觉映射为 query `q_t`、每个事件映射为 key-value，做软注意力聚合：`r_i = Softmax_i(q_t^T k_i / √d_r)`，`M^e_t = Proj_o(Σ_i r_i v_i)`。
- **注入方式**：AdaLN-Zero 风格调制到未来视觉隐 token：`[η_l, β_l] = W_l M^e_t`，`D_l = Adapter_l(LN(X^fut_l) ⊙ (1+η_l) + β_l)`，再经事件门控 `g^e_t = σ(G_e(X_cur, M^e_t, c))`，`X̃^fut_l = X^fut_l + g^e_t D_l`。
- 注意：注意力权重 `r_i` 只反映相关性，**是否影响预测由门控决定**。

### 2.6 训练与推理
- 总损失：`L = L_act + λ_v L_vid + λ_e L_evt + λ_u L_utility`。
- 动作与未来视觉隐变量均用 **flow matching** 联合建模：插值路径 `y_τ = (1−τ)y + τϵ`，`L_FM(y) = E‖f_θ(y_τ, τ, s_t) − (ϵ − y)‖²`；`L_act = L_FM(a_{t:t+Ha-1})`，`L_vid = L_FM(z_{t+1:t+Hv})`。
- 事件未来转移目标：`L_evt = SmoothL1(ŷ_evt, sg(y_evt))`，其中 `y_evt` 由当前与未来视觉隐序列构造，`sg(·)` 为 stop-gradient；未来隐变量**仅用于定义训练目标**，不参与构建事件记忆本身。
- 效用监督：`L_utility = BCE(g^s_t, q_v) + BCE(g^e_t, q_v)`（两分支共享样本级软目标，但各自门控网络独立决定注入强度）。
- 训练细节：动作分支到视频分支的梯度被截断；施加与预测目标一致的因果掩码，未来视觉隐变量**不作为动作分支可见输入**。
- 推理：维护因果视觉历史缓冲，执行动作块后追加新观测并按训练时相同时间偏移采样记忆；回合起始历史不足时**用掩码而非复制当前帧**；由于因果掩码已阻断动作分支访问未来视觉，推理时可省略未来视频生成；CFG 引导尺度为 1.0。

## 3. 实验设计

### 3.1 数据集 / 场景与 Benchmark
- **LIBERO**：语言条件操作，四个套件（Spatial / Object / Goal / Long），共 40 个任务，每任务 50 条专家演示训练，每任务 50 次评测 rollout。
- **RMBench**：面向**部分可观测下的记忆依赖型**双手操作，9 个任务，每任务 100 次 rollout。
- **真实世界**：双 AGILEX PIPER 机械臂 + Intel RealSense D435i RGB-D；自建长时程 "Organize Table" 任务（3 个时序依赖子阶段），500 条专家演示，每设置 30 次 rollout；测试分 Standard / Disturbance（人为移除已放置物体等外部干预）/ Unseen（训练未见物体）三种设置；控制频率 30 Hz，动作块 32，每 8 控制步重规划。

### 3.2 对比方法
- **DP（Diffusion Policy）**：无世界建模的动作生成基线。
- **π0.5**：强 VLA 连续控制策略。
- **FastWAM**：联合学习视觉与动作的世界-动作建模基线。
- **HiMem-WAM**：最相关的记忆增强 WAM（分层记忆门控）。
- 所有方法使用相同数据与评测协议。

### 3.3 主要结果
- **LIBERO**：RM-WAM 平均 98.5%（Spatial 98.8 / Object 100.0 / Goal 98.2 / Long 97.0），优于 HiMem-WAM 97.7%、FastWAM 97.6%、π0.5 96.9%、DP 72.4%；提升最明显在 LIBERO-Long。
- **RMBench**：RM-WAM 平均 55.8%，大幅领先 HiMem-WAM 26.3%、π0.5 10.4%、FastWAM 5.9%、DP 3.8%；单任务如 Blocks Ranking 75%、Put Back Block 70%、Rearrange Blocks 65%。
- **真实世界**：Standard 90.0 vs FastWAM 80.0；Disturbance 83.3 vs 70.0；Unseen 86.7 vs 76.7。
- **消融（LIBERO）**：去掉短期记忆 → 平均 97.7%（Spatial 98.8→97.8）；去掉事件记忆 → 97.5%（Goal 96.8、Long 95.0 下降更大）；完整模型 98.5%。
- **
