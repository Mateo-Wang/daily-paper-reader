## 摘要
通过预测未来状态，潜在世界模型为端到端驾驶提供了丰富的自监督，但往往继承预训练视觉编码器的稠密特征作为其世界状态接口。这造成了一种错配：视觉预训练产生信息丰富、空间稠密的特征，而它们针对运动条件世界建模与规划的适配却被推迟到下游训练。随着视觉分辨率提高，稠密网格还使未来预测的计算开销更大。因此我们认为，视频预训练应直接学习适合下游世界建模与规划的状态表示，而不是依赖下游训练来适配继承的视觉特征。我们提出 MORE，一个 V-JEPA 框架，它在视频预训练期间学习运动导向寄存器，作为驾驶世界模型与规划的共享状态接口。MORE 将时间对齐的自车运动注入一小组寄存器，并将它们用作掩码图像块预测的唯一上下文，通过紧凑的状态瓶颈传递稠密的图像块级监督。一个互补的分块寄存器掩码目标进一步在寄存器空间中塑造预测结构。在下游训练期间，同一寄存器空间定义了世界模型预测的未来状态，并为轨迹生成与评分提供共享场景记忆。在 NAVSIM-v2 上，MORE 在 EPDMS 上以 1.6 的优势超越当前最优方法，同时实现更高效率，推理延迟仅为 DriveLaW 的 1/10。这些结果支持在视频预训练期间直接学习用于世界建模与规划的状态接口。

## Abstract
By predicting future states, latent world models provide rich self-supervision for end-to-end driving, but often inherit dense features from pretrained visual encoders as their world-state interface. This creates a mismatch: visual pretraining produces information-rich, spatially dense features, but their adaptation for motion-conditioned world modeling and planning is deferred to downstream training. The dense grid also makes future prediction more computationally expensive as visual resolution increases. We therefore argue that video pretraining should directly learn state representations suited to downstream world modeling and planning, rather than relying on downstream training to adapt inherited visual features. We propose ***MORE***, a V-JEPA framework that learns **M**otion-**O**riented **RE**gisters during video pretraining as a shared state interface for driving world models and planning. MORE injects temporally aligned ego motion into a small set of registers and uses them as the sole context for masked patch prediction, channeling dense patch-level supervision through a compact state bottleneck. A complementary blockwise register-masking objective further shapes predictive structure in the register space. During downstream training, the same register space defines the future states predicted by the world model and provides shared scene memory for trajectory generation and scoring. On NAVSIM-v2, MORE outperforms the state of the art by 1.6 in EPDMS, while achieving superior efficiency with only 1/10 the inference latency of DriveLaW. These results support learning the state interface for world modeling and planning directly during video pretraining.

- **背景**：端到端自动驾驶直接从传感器观测预测未来轨迹，但低维专家轨迹监督信号有限；驾驶世界模型通过预测未来观测、占据/BEV 状态或潜在特征提供更丰富的自监督信号。JEPA（Joint-Embedding Predictive Architecture）路线（I-JEPA、V-JEPA、V-JEPA 2、Drive-JEPA 等）以表征空间预测替代像素重建，展现出在动作条件预测与轨迹规划上的潜力。
- **核心问题——"状态接口错配"（state-interface mismatch）**：
  - 视觉预训练学到的是**信息丰富、空间稠密**的通用视觉表征；
  - 而世界模型需要的是**以自车运动为条件、能刻画场景演化**的状态，规划器还需要**决策相关**的上下文；
  - 现有做法（V-JEPA 2-AC、LAW、WorldRFT 等）先学视觉表征，再把"运动条件化 + 预测结构"的适配**推迟到下游训练**，导致大量结构与控制信息必须在下游从零学习。
- **效率问题**：稠密未来状态（时空 patch 特征、latent BEV 网格、视觉 latent）使状态规模与视觉分辨率绑定，分辨率越高每步预测的 token 越多；DrivoR、NTR 等把稠密特征压成少量规划 token，但**紧凑本身并不保证运动敏感性与预测结构**。
- **核心主张**：不应在下游继续压缩视觉特征，而应让**视频预训练直接学习适合下游世界建模与规划的状态表示**，关键挑战是在保留稠密视觉监督的同时，赋予该状态空间足够的信息量、自车运动敏感性与预测结构。

## 2. 方法论

### 2.1 总体思想
- 提出 **MORE**（**M**otion-**O**riented **RE**gisters），一个 V-JEPA 框架：在视频预训练中学习一小组**运动导向寄存器**，作为世界模型与规划器**共享的紧凑状态接口**。
- 两阶段流程：**预训练**（塑造寄存器状态空间）→ **联合训练**（复用同一寄存器空间做世界建模、轨迹生成与评分）。

### 2.2 预训练阶段的关键技术
- **运动导向寄存器状态**：
  - 视频按 τ×p×p tubelet 切分，每个时间块有 Np 个 patch token，引入 Nr ≪ Np 个可学习寄存器，通过自注意力与 patch 交互；
  - 相邻帧相对自车运动 a_t = (Δx_t, Δy_t, Δψ_t)（在 t 帧自车坐标系下），对齐到时间块得到 ã_k；默认 τ=2 时 ã_k = a_{2k−1}，更大 τ 时按 SE(2) 复合；
  - 寄存器输入 = 可学习嵌入 + 运动投影（R⁰_{k,r} = E^{reg}_{k,r} + ã_k^⊤ W_a），同块内寄存器共享运动条件。
- **双分支预训练（共享 online 编码器 E_θ、预测器 P_ϕ、EMA target 编码器 Ē_θ）**：
  - **寄存器中介的掩码 patch 预测**：掩掉连续时空块 M_p，online 编码器处理可见 patch + 全部运动条件寄存器；随后**丢弃上下文 patch 特征 P^p_c**，仅用寄存器输出 R^p_c 与位置感知查询 Q^p_{M_p} 预测被掩 patch 的 latent；监督目标来自 EMA 编码器对完整序列的输出。即：**稠密 patch 级监督被强制通过紧凑寄存器瓶颈传递**，迫使寄存器保留恢复 patch latent 所需信息。
  - **分块寄存器掩码**：把寄存器组织为 N_t×N_r 的"时间块–槽位"网格，掩掉连续块 M_r；online 编码器处理全部 patch + 可见寄存器，丢弃上下文 patch 后由共享预测器从可见寄存器恢复被掩寄存器状态，目标取自 EMA 全寄存器 latent。该分支把**寄存器空间本身确立为预测目标**，直接对齐下游世界模型的未来状态预测。
  - 两分支互补：一个保信息量，一个塑预测结构，共同约束同一寄存器空间。
- **预训练损失**：L_pretrain = L_patch + L_reg（均为 ℓ1），target 编码器仅由 EMA 更新（θ̄ ← μθ̄ + (1−μ)θ）。

### 2.3 联合世界建模与规划阶段
- 仅保留寄存器作为共享状态接口：To 个观测帧 → N_o 个观测寄存器 Z_o；未来帧对应 N_f 个未来查询 Q_f。
- **未来寄存器世界建模**：online 编码器只用观测视频与自车运动产生 Z_o；EMA 编码器处理完整视频生成目标 H，未来部分 H_f = sg(H[T_f])；运动条件 ã_o 在观测窗内保留、未来位置零填充（保证训练/推理一致）；世界模型 F_ψ 联合处理 (Z_o, Q_f, ã_o, S_o)，**非自回归一次性预测全部未来寄存器**。
- **轨迹生成与评分**：观测+预测寄存器拼接为共享场景记忆 Z；生成器 D_γ 由 K 个可学习轨迹查询（K=64）产生候选轨迹；独立评分器 S_ω 用同一场景记忆打分（对候选轨迹施加 stop-gradient，保留经 Z 的梯度），评分目标由 NAVSIM/PDM 驾驶准则构造。
- **联合损失**：L_joint = λ_pred L_pred + λ_traj L_traj + λ_score L_score（权重均为 1）；L_traj 为 min-over-K 的位置+朝向 ℓ1 损失，L_score 为对每个候选各准则的 BCE。
- **推理**：online 编码器出观测寄存器 → 世界模型预测全部未来寄存器 → 规划器生成并打分 K 条候选 → 取最高分执行。
