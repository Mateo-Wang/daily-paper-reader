## 摘要
在复杂场景中的端到端规划必须建模多样的驾驶意图，并利用场景上下文和未来风险选择最合适的轨迹。然而，多查询回归可能坍缩到单一模式，而基于锚点和生成式的规划器共享一个扩展瓶颈：小候选集限制了机动覆盖或高质量轨迹的发现，而大候选集增加了生成与评分成本。我们提出 ManeuverFlow，一步生成针对不同意图的轨迹，并利用当前和未来证据对其进行评估与细化。该模型选择相关机动模式，从高斯混合先验中抽取相应噪声，并通过机动路由的专家混合 MeanFlow 场将其映射为意图特定的轨迹。由世界模型预测的当前特征和未来特征沿每个候选路径聚合为轨迹特定的证据，用于 PDM 因子预测。利用相同证据，细化器为选中的候选预测局部 Frenet 残差；随后对细化和保留的候选共同重新评分以进行选择。在轻量级 TransFuser 风格 ResNet-34 骨干网络上，ManeuverFlow 在 NAVSIM v1/v2 navtest 上分别达到 90.6 PDMS 和 90.1 EPDMS。在 WorldEngine 最近的 3DGS 闭环基准上，其在记录交通和 IDM 控制交通下分别取得了所列最高 PDMS$^\ast$ 分数 75.19 和 74.58。代码：https://github.com/wyh-autonomy/maneuverflow。

## Abstract
End-to-end planning in complex scenes must model diverse driving intentions and select the most appropriate trajectory using scene context and future risks. However, multi-query regression may collapse to one mode, while anchor-based and generative planners share a scaling bottleneck: small candidate sets limit maneuver coverage or discovery of high-quality trajectories, whereas large sets increase generation and scoring costs. We propose ManeuverFlow to generate trajectories for distinct intentions in one step and evaluate and refine them using current and future evidence. The model selects relevant maneuver modes, draws corresponding noise from the Gaussian mixture prior, and maps it to intention-specific trajectories through a maneuver-routed mixture-of-experts MeanFlow field. Current features and future features predicted by the world model are aggregated along each candidate path into trajectory-specific evidence for PDM-factor prediction. Using the same evidence, the refiner predicts local Frenet residuals for selected candidates; refined and retained candidates are then jointly re-scored for selection. With a lightweight TransFuser-style ResNet-34 backbone, ManeuverFlow achieves 90.6 PDMS and 90.1 EPDMS on NAVSIM v1/v2 navtest, respectively. On WorldEngine's recent 3DGS closed-loop benchmark, it attains the highest listed PDMS$^\ast$ scores of 75.19 and 74.58 under logged and IDM-controlled traffic, respectively. Code: https://github.com/wyh-autonomy/maneuverflow.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：端到端自动驾驶将传感器观测、自车状态与导航指令直接映射为未来自车轨迹，统一感知与规划。但复杂交通场景往往存在多种合理驾驶意图，单一轨迹无法覆盖潜在决策空间。
- **现有范式的问题**：
  - **多查询回归（learned queries）**：缺乏显式模式结构，候选易聚集在轨迹空间相似区域，产生冗余并面临模式坍缩（mode collapse）风险。
  - **固定锚点规划器**：锚点定义预置模式，但可能将候选预算浪费在与当前场景弱相关的模式上。
  - **生成式规划器（扩散 / ODE 流）**：采样通常迭代多步；即便如 MeanFuser 一步生成多个提案，其 ARM 模块会把提案融合为单一输出，初始假设不再作为显式候选进入下游评估、精炼与选择。
  - **候选评估**：当前特征打分器不查询候选路径上的未来场景状态；WoTE 为每个候选单独做一次未来推演，导致未来 BEV 预测在候选与时间步上重复计算。
- **核心问题定义**：这是一个**固定预算下的假设生命周期问题**——如何在固定候选预算下生成场景相关、模式互异的假设，并利用当前/未来证据对其进行评估、精炼与选择？
- **关键观察（Fig. 2）**：对冻结的 M3F 生成器在 12,146 个 NAVSIM v1 navtest 场景上做后验分析，发现更大的候选池能暴露更强的候选，这激励在紧凑预算下提升候选质量。
- **整体含义**：提出 ManeuverFlow，一个统一的 **Hypothesize–Verify–Improve** 框架，保持机动索引的显式假设贯穿生成、评估与精炼全过程。

## 2. 方法论

### 2.1 核心思想
- 用**机动结构化先验**分配候选预算，用**一步 MeanFlow 传输**生成意图特定轨迹，用**共享未来 BEV 场**提取路径特定证据，再以同一证据驱动 PDM 因子打分与局部 Frenet 精炼，最终联合重评分。

### 2.2 关键技术细节与流程

- **M-GMP（Maneuver Gaussian Mixture Prior）**
  - 基于位移、平均航向、速度趋势三个规则指标，将专家轨迹划分为 **8 个运动族**（Stop/Crawl、Cruise、Accelerating、Decelerating、Left lane change、Left turn、Right lane change、Right turn，见 Table S1）。
  - 在归一化 diff 空间中为每个族拟合因子化高斯（位移对角高斯 + 环形航向分布）。
  - 场景条件下预测机动权重：$\pi^{man}_n = \text{Softmax}(D_{man}(q^{man}_n, c^{SN}_n))$。
  - 辅助损失：$L_{aux} = L_{map} + L_{agent} + L_{man}$，其中 $L_{man} = CE(y^{man}_n, \pi^{man}_n)$，软标签由归一化负距离给出。

- **M3F（Maneuver-Mixture MeanFlow Field）**
  - 采用 Improved Mean Flows (iMF) 的边界场与 JVP 构造，驱动性贡献在于：运动结构化 M-GMP 源、场景条件分量分配、机动路由专家（MoE）。
  - 定义插值状态 $z^t_{n,i} = (1-t)x^{gt}_n + t e_{n,i}$，速度目标 $v^c_{n,i} = e_{n,i} - x^{gt}_n$。
  - M-GMP tokenizer 将 $z^t$ 映射为查询 $Q^0$，经时间区间编码 $\phi_F(t, t-r)$ 调制，依次交叉注意 BEV–ego 记忆与 agent 记忆，由机动码选择对应 FFN 专家。
  - 边界速度提供 JVP 切向量，得到 $\tilde{v}_\theta = u_\theta + (t-r)\,\text{sg}[J_\theta]$（sg 为 stop-gradient）。
  - 生成损失：$L_{M3F} = \mathbb{E}[\|\tilde{v}_{\theta,n,i} - v^c_{n,i}\|_1]$。
  - 推理时一步传输：$\tau_{n,i} = \Gamma^{-1}(e_{n,i} - u_\theta(e_{n,i}, 0, 1 \mid C_n, w^{man}_{n,i}))$。

- **共享未来 BEV 场与世界模型**
  - 每个规划步仅预测**一次**与候选无关的未来 BEV 特征场：$\hat{F}_n = W_\vartheta W(B_n, c^{SN}_n) = \{\hat{B}_{n,j}\}_{j=1}^{H_B}$，$H_B=4$，1 秒间隔。
  - 训练时通过 stop-gradient 目标分支复用感知骨干编码未来观测（TF 用 LiDAR，LTF 用学习到的潜在张量 $Z_{lat}$ 替代），损失含绝对特征 Smooth-L1 + 余弦对齐、时序残差 Smooth-L1。

- **轨迹引导证据探针与 Metric Prism**
  - 学习到的探针将候选航点投影到当前 BEV 图与时间对齐的预测状态，沿路径采样并聚合为**轨迹特定证据记忆** $E_{n,i}$。
  - Metric Prism 将候选编码为 score token，经集合自注意力与对证据记忆的交叉注意力，由 5 个因子头输出 PDM 因子（NC、DAC、EP、TTC、Comf）。
  - 固定 log-PDM 组合打分：$S_{n,i} = \log(s_{NC}) + \log(s_{DAC}) + \log(5s_{EP} + 5s_{TTC} + 2s_{Comf} + \epsilon)$，同时适用于 NAVSIM v1/v2；v2 专属因子仅作评估指标不进入选择。
  - 验证损失：$L_{verify} = L_{FBEV} + L_{score}$。

- **ECFR（Evidence-Coupled Frenet Refiner）**
  - 利用同一证据记忆预测路径对齐 Frenet 残差：$\Delta^F_{n,i} = R_\eta(\tau_{n,i}, E_{n,i})$，更新轨迹 $\tilde{\tau}_{n,i} = U_F(\tau_{n,i}, \Delta^F_{n,i})$。
  - 参考轨迹由同一机动索引下评估器得分最高的候选给出（式 15），损失 $L_{ref} = \alpha_{ref} \sum_i \omega_{n,i} \ell_F / \max(1, \sum_i \omega_{n,i})$，$\alpha_{ref}=5$。

- **训练与推理流程**
  - **两阶段训练**：Stage 1 优化 $L_{aux} + L_{M3F}$；Stage 2 联合优化全部推理模块，$L_{joint} = \lambda_{aux}L_{aux} + \lambda_{M3F}L_{M3F} + \lambda_{verify}L_{verify} + \lambda_{ref}L_{ref}$。
  - **推理**：保留 $\pi^{man}_n$ 的 Top-3 分量并重归一化，按最大余数法分配 $N=64$ 个候选；Metric Prism 预评分；ECFR 精炼 $R=N/4=16$ 个选中基准候选并替换槽位，其余 48 个保留；全部 64 个候选重新查询共享未来场并联合重评分，最高分轨迹作为最终规划 $\tau^\star_n$。
