## 摘要
流匹配是机器人基础模型常用的一种生成方法。视觉-语言-动作模型（VLA）生成动作块，而世界-动作模型（WAM）还额外生成未来视觉状态。二者都从固定的高斯先验开始生成，尽管过去与未来的状态和动作之间存在时间连续性。这需要昂贵的训练和迭代采样，尤其是对于带有额外视觉分支的 WAM。我们提出 $Δ$-flow，它从近期历史中以轻微噪声构建源，而不是从固定的高斯先验构建源。这使源更接近目标，将传输缩减为一个可高效学习的小残差 $Δ$，并支持单步推理。我们将 $Δ$-flow 集成到 VLA 策略 $π_{0.5}$ 以及 WAM 策略 ImageWAM 和 Fast-WAM 中。在 LIBERO 上，ImageWAM 在一个 epoch 内达到 90% 的成功率，而非六个 epoch；Fast-WAM 在两个 epoch 内达到 95%，而非八个 epoch。通过 LoRA 微调，$π_{0.5}$ 在一个 epoch 后便超过了其基线五个 epoch 的性能。单步推理在 $π_{0.5}$、ImageWAM 和 Fast-WAM 上分别带来 1.54 倍、2.49 倍和 4.45 倍的加速。它保持了动作平滑性，与一步高斯采样相比，动作加加速度（jerk）降低了 4.5 倍。$Δ$-flow 在 LIBERO-Plus 上达到了最先进的泛化性能。动作历史源可应用于预训练的 WAM 策略，而无需重新训练。在推理时替换高斯动作源，使用单步采样即可基本保持任务成功率，并能略微提升。我们进一步研究了动作学习中的动作表示与视觉信息如何影响 $Δ$-flow 中从历史到未来的预测。这些结果表明，$Δ$-flow 简单而有效，能够提升机器人基础模型的效率与泛化能力。

## Abstract
Flow matching is a common generative recipe for robot foundation models. Vision-language-action models (VLAs) generate action chunks, while world-action models (WAMs) additionally generate future visual states. Both start generation from a fixed Gaussian prior, despite temporal continuity between past and future states and actions. This requires costly training and iterative sampling, especially for WAMs with an additional visual branch. We introduce $Δ$-flow, which constructs the source from recent history with mild noise rather than from a fixed Gaussian prior. This moves the source closer to the target, reducing transport to a small residual $Δ$ that can be learned efficiently and enables single-step inference. We integrate $Δ$-flow into the VLA policy $π_{0.5}$ and the WAM policies ImageWAM and Fast-WAM. On LIBERO, ImageWAM reaches 90% success in one epoch rather than six, and Fast-WAM reaches 95% in two epochs rather than eight. With LoRA fine-tuning, $π_{0.5}$ exceeds its baseline's five-epoch performance after one epoch. Single-step inference gives $1.54\times$, $2.49\times$, and $4.45\times$ speedups on $π_{0.5}$, ImageWAM, and Fast-WAM, respectively. It preserves action smoothness, achieving a $4.5\times$ reduction in action jerk compared with one-step Gaussian sampling. $Δ$-flow reaches state-of-the-art generalization performance on LIBERO-Plus. Action-history sources can be applied to pretrained WAM policies without retraining. Replacing the Gaussian action source at inference largely preserves task success with a single sampling step and can slightly improve it. We further study how action representation and visual information in action learning affect history-to-future prediction in $Δ$-flow. These results show that $Δ$-flow is simple yet effective, improving the efficiency and generalization of robot foundation models.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：流匹配（Flow Matching）已成为机器人基础模型（Robot Foundation Models）中连续动作生成的标准方法。当前主要存在两类模型：
  - **VLA（视觉-语言-动作模型）**：如 π₀、π₀.₅，从高斯先验生成动作块（action chunk）。
  - **WAM（世界-动作模型）**：如 ImageWAM、Fast-WAM，除动作外还联合生成未来视觉状态（图像或视频 latent）。

- **核心痛点**：两类模型均从**固定的高斯先验**开始生成，完全忽略了"过去与未来状态/动作之间存在的强时序连续性"。
  - **训练代价高**：高斯源与目标无关，速度场必须"陡峭"（Lipschitz 常数大），收敛慢（VLA 收敛慢，WAM 更慢，因为要同时拟合高维视觉与动作两条传输）。
  - **推理代价高**：需要多次函数评估（NFE ≥ 10 步 Euler 更新），直接增加控制延迟；WAM 在每个采样步还要同时计算视觉与动作两个模态。

- **现有缓解手段的局限**：
  - 高效采样器 / 蒸馏（DPM-Solver、Consistency Models）：主要为动作生成设计，对 WAM 视觉分支是否有效仍存疑。
  - 暖启动（warm-start）：依赖单独训练的预测器提供初始化。
  - Fast-WAM / ImageWAM 在推理时跳过未来预测：牺牲显式未来条件，在分布漂移下性能下降。
  - **本质问题**：这些方法都在"缩短、近似或绕过"生成传输，而没有**降低学习传输本身的成本**。

- **核心洞察**：动作与视觉信号天然连续，且其已执行历史可直接从反馈测量中获得。既然历史与未来如此接近，**为何不直接以历史作为流的源？** 这样既能简化训练映射，又能缩短推理路径。

- **整体含义**：论文提出 **Δ-flow**，将源分布从固定高斯先验改为"近期历史 + 轻噪声"，让网络只学习"过去到未来"的小残差 Δ，从而同时改善训练效率、推理速度、动作平滑性和泛化能力。

## 2. 方法论

### 2.1 核心思想

- 用符号 Δ 表示"历史与未来（视觉状态或动作）之间的差异"。
- 不再从高斯噪声生成未来，而是学习"近期视觉与动作历史如何演化为其未来"，网络只负责残差。
- **关键区别**：与作者前作 A2A Flow Matching（直接传输干净历史）不同，Δ-flow 对历史施加**一定程度的噪声扰动**——若源完全确定，则每个历史只映射到单一目标，会牺牲目标分布的多模态性与鲁棒性。

### 2.2 关键技术细节

**（1）历史扰动源构造**（式 3）
对模态 m ∈ {a（动作）, v（视觉）}：
```
s_m = α_m · h_m + σ_m · b_m ⊙ ε_m,   ε_m ~ N(0, I)
```
- `h_m`：历史表示。动作历史 `h_a = [a_{t-H}, …, a_{t-1}]`（最近 H 个已执行动作）；视觉历史 `h_v = P_v(E_v(o_≤t))`（编码后的观测按未来目标的 latent 布局排列）。
- `α_m, σ_m`：历史尺度与噪声尺度；`b_m`：维度级噪声掩码；⊙ 为逐元素乘。

**（2）流匹配损失**（式 4）
插值 `y_τ = (1-τ)y_m + τ·s_m`，训练速度场预测 `(s_m - y_m)`：
```
L_FM = E[ || f_θm(y_τ, τ, c_t) - (s_m - y_m) ||²₂ ]
```

**（3）端点一致性损失**（式 5，为单步生成直接监督）
从 τ=1 做一次 Euler 更新到 τ=0，惩罚与目标的偏差：
```
ŷ_m = s_m - f_θm(s_m, 1, c_t)
L_EC = E[ || ŷ_m - y_m ||₁ ]
```
> 注意：此期望不含流时间 τ（始终在 τ=1 评估），使用 L1 距离。

**（4）VLA 实例**（式 6）：仅对动作模态应用 Δ-flow，保留原视觉-语言条件与动作专家架构。
```
L_VLA = L^a_FM + λ^a_EC · L^a_EC
```
推理时单次 Euler 更新：`Â_t = s_a - f_θa(s_a, 1, c_t)`，无需辅助历史预测器。

**（5）WAM 实例**（式 8–10）：视觉与动作分支联合训练，动作分支通过 **stop-gradient（sg）** 读取视觉中间特征：
```
R^τv_t = R_θv(y^τv_v, τv, c_t),   c^a_t = (c_t, sg(R^τv_t))
L_WAM = λ_v(L^v_FM + λ^v_EC L^v_EC) + λ_a(L^a_FM + λ^a_EC L^a_EC)
```
推理时视觉网络在其源处求值（`R¹_t = R_θv(s_v, 1, c_t)`），视觉端点与动作块各做一次 Euler 更新，**未来视觉端点无需解码**。

### 2.3 三个架构实例化

|---|---|---|

**（1）训练效率大幅提升**
- ImageWAM 完整 Δ-flow：**1 个 epoch 达 91.30%**（原始仅 24.60%，+66.7pp），比原始提前 5 个 epoch 达到 90%，即 **6× 训练加速**；仅动作 Δ-flow 在 epoch 4 达 90%。
- Fast-WAM：**2 个 epoch 达 95.65%**，基线需 8 个 epoch，**4× 加速**；1 个 epoch 即达 72.60% vs 基线 42.55%。
- π₀.₅ + LoRA：**1 个 epoch 92.20%**，已超过 10 步基线 5 个 epoch 的 91.30%，**5× 加速**；5 个 epoch 达 98.00%。

**（2）泛化性能 SOTA**
- ImageWAM 在 LIBERO-Plus 从 82.49% → **88.55%**（+6.06pp），在**无额外具身数据预训练**下达到 SOTA。
- π₀.₅ 从 80.70% → 84.53%；Fast-WAM 从 77.51% → 80.58%。
- 增益最大的扰动类别：机器人初始状态（52.90% → 73.94%）和物体布局（81.31% → 88.39%）。

**（3）推理加速与动作平滑**
- 单步推理加速：π₀.₅ **1.54×**（82.91→53.99ms）、ImageWAM **2.49×**（296.31→118.87ms）、Fast-WAM **4.45×**（857.54→192.62ms）。
- 相比 1 步高斯采样，完整 Δ-flow 将 chunk 边界的动作变化峰值降低 **48%**、jerk 峰值降低 **67%**；平均 jerk 从 0.19399 降至 0.04335，**降低 4.5×**，接近 10 步高斯采样水平（0.04221）。

**（4）免训练迁移**
- 冻结预训练模型、仅替换推理源：ImageWAM LIBERO 从 97.50% → 98.10%，LIBERO-Plus 从 81.65% → 82.82%；Fast-WAM LIBERO 从 95.55% → 96.15%（Plus 略降至 67.58%）。**无需后训练即可获得单步推理收益**。

**（5）反直觉的设计发现**
- **动作表示影响被低估**：在 LIBERO 上三种表示差异很小，但在 LIBERO-Plus 上差距超过 **14 个百分点**（局部 delta 85.82% vs 7D 绝对 61.07%）；10D rotation-6D 优于 7D axis-angle。
- **更稀疏的未来帧预测反而更好**：Sparse8（4 帧，r=8）比稠密（8 帧，r=4）在 LIBERO-Plus 高 **5.19pp**。
- **stop-gradient 有益**：阻断动作损失梯度回传视觉分支，同时提升未来图像 PSNR 与 LIBERO-Plus 成功率——说明"特征共享"与"梯度耦合"应作为两个独立设计决策。
- **仅端点一致性几乎够用**：源为历史信息且保留视觉监督时，只监督单步端点（EC only）在最终性能上接近完整 FM+EC（97.40% vs 97.70%），但早期收敛更慢（1 epoch 78.10% vs 89.90%）。

**（6）理论解释**：高斯源为每个目标配对无关噪声，邻近源可能映射到完全不同未来，迫使速度场陡峭（Lipschitz 常数大）；历史源为每个目标配对自身历史，只剩小而平滑的偏移需拟合。

## 7. 优点

- **极简且通用**：只改变流的源构造，**不修改网络架构、不增加模块、不需要额外数据**，可即插即用地集成到 VLA 与 WAM。
- **一举多得**：同时改善训练效率（3–6×）、推理速度（1.54–4.45×）、动作平滑性（jerk ↓4.5×）和分布漂移下的泛化（LIBERO-Plus +6pp），而非单点优化。
- **诚实的基线设计**：为 Fast-WAM 专门构造了同架构、同布局、同采样预算的 Gaussian sparse-joint 基线，隔离了源设计这一变量，对比具有说服力。
- **免训练迁移的实用价值**：为已部署的高斯源策略提供零成本升级路径，对实际工程落地意义显著。
- **设计洞察具外推性**：关于动作表示、稀疏未来预测、stop-gradient、端点一致性的四条实证结论，对任何耦合世界建模与动作生成的策略都有参考价值。
- **统计与可视化严谨**：误差棒、配对 bootstrap 置信区间、边界对齐曲线、逐扰动分解，报告完整。
- **清晰的理论动机**：用 Lipschitz 常数/速度场陡峭度解释历史源的优势，而非纯经验堆砌。

## 8. 不足与局限

- **仿真为主，缺乏真机验证**：全部实验在 LIBERO / LIBERO-Plus 仿真 benchmark 上完成

- **仿真为主，缺乏真机验证**：全部实验在 LIBERO / LIBERO-Plus 仿真 benchmark 上完成，未提供真实机器人平台上的部署结果。历史源构造依赖已执行动作与观测的时序对齐，真机上的延迟抖动、传感器噪声分布、动作执行误差累积是否会削弱 Δ-flow 的"历史近未来"假设，仍缺乏实证。尤其免训练源替换在真实闭环中的长期稳定性（误差是否随轨迹漂移放大）无法从仿真推断。

- **训练时间成本未报告**：论文给出 epoch 数与硬件规模，但未报告墙钟时长或总 GPU 小时。因此"6× / 5× / 4× 训练加速"是**以 epoch 为单位**的相对指标，而非绝对时间加速。由于 Δ-flow 改变了源的构造（需维护历史缓存、视觉源 latent 布局对齐），单步计算开销可能略有变化，仅凭 epoch 数无法完全排除"每 epoch 变慢"的干扰。建议补充 wall-clock 对比与每步 FLOPs/显存占用。

- **超参敏感性未系统探索**：α_m、σ_m、历史长度 H、噪声掩码 b_m 在各骨干上被设为接近的固定值（如 α_a=1、σ_a=0.5），但论文**未给出这些超参的敏感性分析或调参曲线**。噪声尺度 σ 是 Δ-flow 区别于"A2A 干净历史源"的核心变量——σ 过小退化为确定性映射、牺牲多模态，σ 过大则逼近高斯源、失去优势，其最优区间及是否随任务/模态变化，是该方法能否稳健迁移的关键，文中缺少定量刻画。

- **消融覆盖范围受限**：作者明确说明"所有消融在 ImageWAM 上进行"，动作表示、稀疏未来帧、stop-gradient、EC-only 等结论**主要在单一骨干上验证**。这些结论是否在 Fast-WAM（视频骨干）与 π₀.₅（纯动作）上同样成立，缺乏跨骨干重复。尤其是"动作表示在 LIBERO-Plus 上差距 >14pp"这一强结论，仅在 ImageWAM 上测量，外推需谨慎。

- **理论解释偏定性**：以"Lipschitz 常数更小/速度场更平滑"解释历史源优势，属于直观论证，**未给出严格定理、误差界或与收敛速度的定量联系**。未证明历史源下速度场 Lipschitz 常数确实更小，也未将该常数与实测训练收敛曲线做数值关联，理论部分更像"合理性叙事"而非"可证伪命题"。

- **WAM 的视觉分支仍保留部分高斯成分**：ImageWAM 视觉源设为 `(h_v+ε_v)/√2`，即 50% 图像 latent 先验与 50% 历史混合，而非纯历史。这一折中削弱了"源即历史"的纯度，也意味着视觉分支的收益可能部分来自混合比例而非历史本身；论文未系统扫描该混合系数。同时视觉端点"无需解码"意味着**无法验证生成未来 latent 的语义质量**（仅用 PSNR 间接评估），可能掩盖视觉分支的退化。

- **评估指标局限**：动作连续性用 jerk 与边界变化量衡量，未报告任务级的安全性/接触力指标；未来预测仅用 PSNR，未用 LPIPS/FID 等感知指标，也未验证生成未来对下游规划是否真正有用（即"显式未来条件"的实际贡献未被消融隔离）。

- **对比公平性的边界**：文献基线（OpenVLA、UniVLA、LingBot-VA、Motus、ABot-M0.5、Cosmos Policy）保留其原始报告协议，训练数据规模、预训练语料、评测细节可能与本文自测不一致；"无额外具身数据预训练下 SOTA"的表述依赖这一前提，跨来源数字直接比较存在残余混淆。

- **泛化增益的归因未完全拆解**：LIBERO-Plus 提升最大的两类是机器人初始状态与物体布局，作者将其归因于历史源提供的时序连续性。但初始状态扰动下的提升也可能来自**历史动作中隐含的当前构型信息**（相当于隐式状态估计），这一机制与"缩短传输路径"是两种不同的解释，文中未设计实验区分。

- **单步生成的精度上界未讨论**：所有 Δ-flow 推理均为单次 Euler 更新。单步离散化误差在强多模态或大 Δ 场景（如长程任务末期、突发目标切换）下是否会显著上升，论文未给出"Δ 幅度 vs 单步误差"的分析，也未讨论在必要时退回多步采样的自适应策略。

## 9. 启示与展望

- **"源的设计"是被低估的建模自由度**：主流工作聚焦于架构、规模与采样器，而本文表明——在保持网络、数据、预算不变的前提下，仅把源从高斯改为历史，即可获得跨训练/推理/平滑/泛化的系统级收益。这提示生成式策略研究应把"先验/源分布"作为一等设计变量。

- **历史即先验，可推广到更多模态与任务**：Δ-flow 的范式不限于动作与视觉，凡是存在**可测量的近期历史且未来连续**的信号（力/触觉序列、多视角 latent、语言子目标、灵巧手关节轨迹）都可能适用。其核心条件是"历史与未来足够接近"，这为长时序任务的分段传输提供了思路。

- **特征共享与梯度耦合应解耦**：stop-gradient 的双赢结果说明，多模态联合训练中"共享表示"与"共享梯度"是两个独立决策，前者有益、后者可能有害。这一洞察对任何世界模型+策略耦合的架构都有方法论价值。

- **免训练升级路径的工程意义**：对已部署的高斯源策略，仅替换推理源即可获得单步加速与精度小幅提升，是一种低风险、低成本的落地手段，可能推动"推理期源适配"成为部署后的常规优化项。

- **待推进方向**：真机闭环验证与误差累积分析；α/σ/H 的系统敏感性研究与自适应噪声调度；跨骨干消融复现；将历史源与蒸馏/一致性方法叠加，探索单步之外的自适应 NFE 策略；用感知指标与下游规划收益评估未来预测质量；给出历史源下速度场 Lipschitz 常数的严格界或数值验证。

## 10. 总体评价

本文是一篇**动机清晰、方法极简、实验扎实**的工作。其最大价值不在于提出复杂的新架构，而在于指出了一个被普遍忽视的建模缺陷——生成式机器人策略"从高斯噪声凭空生成连续信号"违背了信号本身的时序连续性——并给出一个几乎零成本、即插即用的修正：**用可测量的近期历史（加轻噪声）替代高斯先验作为流的源**。

方法上，Δ-flow 通过"历史扰动源 + 流匹配损失 + 端点一致性损失"三件套，把学习目标从"陡峭的大位移传输"简化为"平滑的小残差拟合"，并在 VLA（π₀.₅）与 WAM（ImageWAM、Fast-WAM）两类主流骨干上一致验证了训练加速（3–6×）、推理加速（1.54–4.45×）、动作平滑（jerk ↓4.5×）与泛化提升（LIBERO-Plus +6pp）。基线的严格匹配设计（尤其 Fast-WAM 的 Gaussian sparse-joint 对照）与免训练源替换实验，显著增强了结论可信度与实用价值。

局限同样明确：**纯仿真、缺真机闭环；训练时间未以墙钟报告；关键超参（σ、H）缺敏感性分析；消融集中于单一骨干；理论解释偏定性**。这些并不动摇核心结论的方向性，但限制了其外推强度与工程可预测性。

**一句话总结**：Δ-flow 用一个近乎免费的改动——"别从噪声生成未来，从历史生成未来"——同时买下了更快训练、更快推理、更平滑动作与更强泛化，是把"时序连续性"这一先验显式写进流匹配源分布的漂亮范例；其后续价值取决于真机验证与超参稳健性。
