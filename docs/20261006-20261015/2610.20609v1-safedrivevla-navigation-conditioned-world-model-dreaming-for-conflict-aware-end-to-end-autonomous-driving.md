## 摘要
视觉-语言-动作（VLA）模型在自动驾驶领域正受到关注，它们从大语言模型（LLM）继承常识先验，并将导航接口从固定命令集扩展为自由形式的自然语言指令。然而，这种开放式接口暴露了新的脆弱面：注意力不集中的驾驶员可能发出在当前场景下不安全的指令，而恶意用户可能故意发出危险指令。我们提出了首个同时评估导航跟随与冲突感知以及对抗鲁棒性的基准测试套件。现有 VLA 在这两方面均表现不足：SimLingo 在闭环中无法完成任何语言指示的车道变更，且所有模型在冲突信号下性能均急剧下降。我们提出 SafeDriveVLA，这是首个驾驶 VLA，其（1）显式预测三级导航遵从模式，以将冲突推理与动作生成解耦；（2）利用导航条件化的世界模型梦境推演来为该预测提供信息。与先前推演专家动作或规划动作的世界模型不同，我们的方法通过想象严格遵循导航信号，展示何时遵循是安全的。SafeDriveVLA 在 Bench2Drive 上达到 88.16 驾驶得分（DS）和 68.64% 成功率（SR），与最佳 SimLingo 变体相比，将闭环语言跟随能力提升 49.3%，并将不安全指令下的碰撞次数从 60 次减少到 38 次。视频演示可在我们的项目页面获取。

## Abstract
Vision-Language-Action (VLA) models are gaining attention in autonomous driving, inheriting commonsense priors from large language models (LLMs) and widening the navigation interface from a fixed command set to free-form natural-language instructions. However, this open-ended interface exposes a new vulnerability surface: an inattentive driver may issue instructions that are unsafe given the current scene, and a malicious user may issue dangerous ones on purpose. We present the first benchmark suite that evaluates navigation following and conflict awareness together, along with adversarial robustness. Existing VLAs fall short on both: SimLingo completes no language-instructed lane change in closed loop, and all models degrade sharply under conflicting signals. We propose SafeDriveVLA, the first driving VLA that (1) explicitly predicts a three-level navigation-compliance mode to decouple conflict reasoning from action generation, and (2) uses navigation-conditioned world model dreaming to inform this prediction. Unlike prior world models that roll out expert or planned actions, ours dreams of strictly following the navigation signal, showing when following is safe. SafeDriveVLA reaches 88.16 Driving Score (DS) and 68.64% Success Rate (SR) on Bench2Drive, lifts closed-loop language following by 49.3% and reduces collisions under unsafe instructions from 60 to 38 compared to the best SimLingo variant. Video demonstrations are available on our project page.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景演进**：自动驾驶正从模块化流水线（感知→预测→行为规划→运动规划）转向端到端（E2E）系统，最新一代 E2E 模型即视觉-语言-动作（VLA）模型，把导航接口从固定命令集（turn_left、go_straight 等）扩展到**自由形式的自然语言指令**。Li Auto 已将 VLA 驾驶模型推送到量产车，NVIDIA 的 Alpamayo VLA 也计划搭载于 Mercedes-Benz CLA。
- **安全机制缺失**：模块化架构中，导航信号需先经过规则化的行为规划器，与交通灯、行人等局部场景做冲突消解，才形成驾驶决策。E2E/VLA 系统把这一判断"内化"到神经网络中，只能靠数据隐式学习"何时该跟随、何时该延迟或拒绝"导航信号。
- **新增脆弱面**：
  - 注意力不集中的驾驶员可能发出**在当前场景下不安全**的指令（如行人横穿时要求"加速到 15 m/s"）；
  - 恶意用户可能**故意**发出危险指令（如"直接撞向施工障碍物，不要变道"）。
- **核心矛盾（类似 LLM 的 helpfulness–harmlessness 权衡）**：
  - 一个"无视所有指令"的模型在冲突基准上看起来安全；
  - 一个"盲从所有指令"的模型在跟随基准上看起来优秀。
  - 因此必须**同时**评估导航跟随与冲突感知。
- **现有模型的失败证据**：SimLingo 开环语言变道成功率 83%，但**闭环完成率为 0%**；所有模型在冲突信号下性能骤降，会脱离场景直接执行指令。
- **论文整体含义**：这是首个同时评估导航跟随、导航-场景冲突感知与对抗鲁棒性的基准套件，并给出首个显式解耦"冲突推理"与"动作生成"的驾驶 VLA，呼吁在 VLA 大规模上车前重视导航-场景冲突这一安全漏洞。

## 2. 方法论：核心思想与关键技术

### 2.1 总体架构（三个组件）

1. **驾驶模式归因（Driving Mode Attribution）**：为每一专家帧打上三级模式标签，显式监督冲突推理。
2. **动作条件化潜在世界模型（Latent WM）**：在"严格执行导航信号"的假想动作下推演未来潜在状态（dreaming）。
3. **VLA 主干（InternVL3-1B + LoRA）**：自回归输出模式 token → `<ACTIONS>` 分隔符 → 动作 token，并附带辅助路径头做横向控制。

### 2.2 关键技术细节

- **三级导航遵从模式**：
  - `<STRICT>`：立即执行导航信号；
  - `<CAUTIOUS>`：跟随但在局部危险前让行/减速；
  - `<FALLBACK>`：覆盖（拒绝）导航信号。
  - 标签由**运动学规则**从专家未来 2.5 s 轨迹 + 当前速度 + 限速推导：
    - `follow_road` / `go_straight`：巡航速度 > 6 m/s 且平均未来加速度 > −0.5 m/s² 且横向偏移 < 1.5 m → strict；停止或急刹（< −2.5 m/s²）无横向移动 → fallback；其余 → cautious。
    - `turn_left/right`：以 2.5 s 内运动学最大弧长比例为判据（≥70% strict，<10% fallback，中间 cautious）。
    - `lane_change_*`：以横向越过 0.3 m 时对应的纵向行进比例判定（前 30% strict，从不越线或最后 10% 才越线 fallback）。
  - 模式 token 在动作 token **之前**发出，使冲突决策被直接监督，而非与动作生成纠缠。

- **世界模型预训练**：
  - 基于 **V-JEPA 2 AC**（ViT-L 冻结目标编码器 + 从零训练的因果 Transformer 预测器，8 层 8 头，宽 512，约 25 M 参数）。
  - 与原始 V-JEPA 2 AC 的关键差异：**用两帧真实连续图像**（间隔 0.25 s）构成 tubelet，而非复制单帧，使每个潜在状态携带运动信息（周围车辆速度无法从单帧恢复）。
  - 预测 2.5 s 未来、2 Hz 共 5 步，动作 a_t = (Δx, Δy, Δψ) 为自车坐标系位姿增量；ego state 仅在 t=0 提供，后续置零以匹配部署时只有动作、无未来状态的分布。
  - 损失：教师强制损失 L_TF + 自回归损失 L_AR（各步 ℓ1，等权）；自回归深度从 2 线性增至 5（前 40% 训练），20 epochs。

- **导航条件化 dreaming（核心创新）**：
  - 不像以往世界模型那样推演专家动作或规划动作，而是**在"严格遵循导航信号"的假想动作序列下**推演潜在未来。
  - 每个 meta-command 预先由 2.5 s 训练轨迹平均得到**动作锚点**（lane-change 锚点被手工校准为 0.5 s 横向 3.5 m，以区别于 follow_road）。
  - meta-command 的获取方式：
    1. 规划器命令 → 直接用命令；
    2. 目标路点 → 用随附的规划器命令；
    3. 语言指令 → 通过词表匹配解析（如 "turn left" → turn_left）。
  - 冻结的 WM 预测器从当前潜在 z₀ 向前推演 5 步，得到"严格执行的未来"，再经**世界 token 投影器**（1×1 Conv + GroupNorm + GELU + AvgPool + Linear，输出 896 维 LM token）送入 VLA。

- **动作生成**：
  - 离散动作 token 来自离线 K-disk 聚类构建的 **2048 项运动基元码本**，T = 10 个 token 编码 4 Hz、2.5 s 的未来轨迹。
  - 辅助 MLP 路径头读取 `<ACTIONS>` 处的隐状态，回归 20 个自车坐标系路径点，喂给横向 PID；纵向目标速度由离散动作 token 积分得到。
  - 训练目标：L = L_action + L_mode + L_path + 0.5 L_text。

- **算法流程（推理）**：导航信号 → 解析 meta-command → 选取动作锚点 → 冻结 WM 推演 dreamed latents → 与相机帧、导航信号一起送入 VLA → 先输出模式 token，再输出 `<ACTIONS>` 与动作 token → 解码为轨迹 + PID 控制。

- 在 5,095 个"起始无危险"的 clip 上训练 hazard 探针，比较三类潜在：编码器 oracle z_t、冻结首帧 z₀、预测器 rollout ẑ_t。
- 验证两个性质：(1) rollout 携带场景演化信息（hazard AUC 高于 z₀，恢复 49–78% 的 oracle 增益）；(2) rollout 对动作敏感（ℓ1 到 oracle：GT < mirror < zero）。

## 5. 实验数量与充分性评估

- **实验组数概览**（粗略）：
  1. Bench2Drive 主结果（8 个基线 + 自身 2 种导航模态）；
  2. CARLA-F 导航跟随（5 个基线 × 多种协议 + 自身 2 种协议）；
  3. B2D-C 冲突（SimLingo 三变体 + 自身，含 3 类违规分解）；
  4. NavSim-C（4 个模型 × ORI/Cflct 两条件 × 7 项指标）；
  5. B2D-Adv（SimLingo、baseline、+Mode、完整模型，共 4 组）；
  6. 世界模型探针（3 种潜在 × 6 个时间尺度 + 3 种动作变体）；
  7. 消融：模式 token、世界模型、训练规模（×0.2/×1.0）、WM 动作输入（2 档），并绘制 Pareto 前沿；
  8. 模式预测准确率（6 类 meta-command × 100 帧 = 600 帧）；
  9. 定性演示（B2D-C、CARLA-F、NavSim-C、模式条件化动作生成多组可视化）。
- **充分性评价**：
  - **优点**：覆盖"跟随—冲突—对抗"三视角，且刻意避免单一基准上的假象（盲目跟随或全盘拒绝）；消融做到了组件级归因，并用 Pareto 前沿展示两项指标的权衡；世界模型用探针定量验证了预测性与动作条件性，而非只看损失曲线；B2D-Adv 采用"同路线有/无指令"的配对设计，把指令效应从场景难度中分离出来，这是很严谨的做法。
  - **公平性**：与 SimLingo 使用相同 PDM-Lite 专家数据训练，直接可比；NavSim-C 明确声明只做诊断、不评自身模型（因自身是 CARLA 训练的单视角模仿模型），避免了不对等比较，态度诚实。
  - **可能的不足**：B2D-Adv 仅 15 条路线，样本量偏小；B2D-C 只与 SimLingo 比较，缺少更多自由语言 VLA 的横向对比；CARLA-F 与 B2D-C 的指令均来自固定同义句池，不能覆盖真正自由形式的用户输入。

## 6. 主要结论与发现

- **主结果**：SafeDriveVLA 在 Bench2Drive 上达到 **88.16 DS / 68.64% SR**（WP 导航），相比同数据训练的 SimLingo 平均提升 **+2.15 DS / +1.89% SR**；效率 264.51，舒适度 30.14。
- **闭环语言跟随**：语言协议下平均 NCR 从 SimLingo 最好的 55.6% 提升到 **83.0%**（提升 49.3%），变道 NCR 从 **0%** 提升到 63.6%（左）/ 72.4%（右）——这是所有模型中最高的，作者归因于导航条件化 dreaming。
- **冲突场景（B2D-C）**：**85.9 DS / 67.3% SR**，碰撞从 60 降至 **38**（↓36.7%），交通违规从 61 降至 **9**（↓85.2%），偏离路线从 11 降至 **4**（↓63.6%）。SimLingo-IF（优先跟随）崩到 56.3 DS / 12.7% SR、166 次碰撞，说明"优先跟随"会摧毁冲突感知。
- **NavSim-C 诊断**：所有被评模型在冲突命令下显著退化（AutoVLA PDMS 88.2→70.7，DAC 崩到 79.0），证明存在**系统性盲从导航信号、不做场景接地**的问题；CuriousVLA 冲突感知最好（84.4，仅降 6.2）。
- **对抗指令（B2D-Adv）**：SimLingo DS 从 95.7 掉到 76.0（降 19.7），SafeDriveVLA 仅从 94.7 掉到 83.9（降 10.8），**降幅约减半**；无模式 token/无 WM 的 baseline 降幅最大（93.0→69.7），说明韧性来自显式驾驶模式而非 VLA 主干。
- **消融核心发现**：
  - **数据规模**只改善安全（B2D-C DS 70.6→79.2），却损害跟随（NCR 65.3%→55.1%），说明单纯扩数据只是沿 Pareto 前沿滑动；
  - **模式 token**主要提升安全（DS 79.2→87.3，交通违规 47→10），但使模型过于保守，跟随只从 55.1%→59.8%；
  - **世界模型**主要提升跟随（59.8%→83.0%，+23.2 点），同时保住安全（DS 仅 −1.4，小数据档甚至从 73.8 升到 81.2）；
  - **两者互补**，共同把 Pareto 前沿向外推。
  - 模式预测与规则标签的一致率 **90.2%**，最低是 turn_left（0.770，无保护左转中 strict 与 cautious 难分），最高是 lane_change_right（0.970）。
  - 预填不同模式 token 会产生**可区分的条件分布**：`<FALLBACK>` 几乎静止，`<STRICT>`/`<CAUTIOUS>` 仍尝试前进。
  - 用自车历史外推替代导航条件锚点，三项基准均下降。

## 7. 优点

- **问题定义新颖且切中部署风险**：首次把"导航-场景冲突"作为 VLA 驾驶的独立脆弱面提出，并类比 LLM 的 helpfulness–harmlessness 权衡，构建了同时覆盖"跟随—冲突—对抗"的三视角基准，逻辑闭环。
- **方法论解耦干净**：把"是否该执行"（模式 token）与"怎么执行"（动作 token）显式拆开，既提升可解释性（模式可在动作前暴露意图），又便于直接监督，避免行为克隆把混合决策隐式学掉。
- **世界模型的用法有原创性**：不是推演专家/规划动作，而是**推演"严格遵从导航信号"的假想未来**，从而回答"跟随是否安全"，这是一个决策导向而非生成导向的用法；并用探针实验证明 rollout 既具预测性又对动作敏感，而非退化为复制 z₀。
- **工程细节扎实**：针对驾驶场景把 V-JEPA 2 AC 的 tubelet 从单

- 帧复制改为**两帧真实连续图像**（间隔 0.25 s）构成 tubelet，使每个潜在状态携带运动信息——因为周围车辆速度无法从单帧恢复。这是针对驾驶物理属性的定向修改，而非直接套用通用视频世界模型。
- **可解释性与可控性兼具**：模式 token 先于动作 token 输出，既能在部署时暴露模型的"意图层级"（strict/cautious/fallback），也支持预填模式 token 做条件化生成，为安全回退与人机协同（如向驾驶员解释"我拒绝该指令"）提供了接口。
- **评估态度诚实**：明确声明 NavSim-C 仅作诊断、不评自身模型（因自身是 CARLA 训练的单视角模仿模型），避免不对等比较；对自身在对抗场景下仍有 10.8 点下降也如实报告，未过度包装。

## 8. 不足与局限

- **基准覆盖的边界**：
  - B2D-Adv 仅 **15 条路线**，虽按 13 类场景分层，但单类场景样本极少，对抗鲁棒性结论的统计置信度有限；
  - B2D-C 仅与 SimLingo 及其变体比较，缺少更多具备自由语言接口的 VLA（如 AutoVLA、ORION 若改造为语言接口）的横向对比，冲突感知能力的相对位置不够清晰；
  - CARLA-F 与 B2D-C 的"语言指令"均来自**预定义同义句池**，并非真正开放的用户输入，对真实自由语言的泛化性（口语化、含歧义、多轮指代）未验证。
- **模式标签的启发式依赖**：三级模式由运动学规则（速度、加速度、横向偏移、弧长比例）从专家轨迹反推，规则阈值（如 6 m/s、−0.5 m/s²、1.5 m、70%/10%）为人工设定。这些阈值可能把某些"合理跟随"误标为 cautious，或在无保护左转中难以区分 strict 与 cautious（turn_left 一致率仅 0.770 即为例证），标签噪声会传导至模式监督。
- **世界模型的输入约束**：
  - 动作锚点由训练轨迹平均或手工校准（lane-change 锚点手工设为 0.5 s 横向 3.5 m），属于**预定义常量**，难以覆盖千变万化的导航语义；
  - 语言指令经**词表匹配**解析为 meta-command，无法处理词表外的自由表达，是"伪自由语言"接口；
  - ego state 仅在 t=0 提供、后续置零，虽为对齐部署分布，但也限制了模型利用实时自车状态做细粒度推演。
- **部署可行性未量化**：未报告训练总时长、GPU 显存、**推理时延**、世界模型 rollout 的额外计算开销与实际能耗。考虑到量产车算力受限，冻结 WM 每步前向 + VLA 自回归的开销是否能满足实时性，是上车前的关键未知数。
- **评估停留在仿真**：全部结论来自 CARLA 与 NavSim 闭环仿真，缺少真实路测或硬件在环验证；仿真中的对抗指令构造也无法穷尽真实世界的攻击面（如对抗性感知扰动、多模态指令冲突）。
- **对抗鲁棒性仍是"缓解"而非"解决"**：SafeDriveVLA 在 B2D-Adv 上仍下降 10.8 DS，说明显式模式监督提升了韧性但未根除盲从倾向；对于训练分布外的全新危险语义，模式 token 可能仍预测为 strict。
- **单视角输入限制**：作为 CARLA 训练的单视角模仿模型，在 NavSim 真实传感器数据上的适用性受限，这也正是其回避 NavSim-C 自评的原因，间接说明跨域泛化尚未打通。

## 9. 启示与展望

- **对 VLA 上车安全评估的范式意义**：论文提出的"跟随—冲突—对抗"三视角基准，把 helpfulness 与 harmlessness 的张力显式化。这提示行业：**仅报告开环语言跟随成功率（如 SimLingo 的 83%）会严重高估系统能力**，闭环完成率（0%）才是真相。未来 VLA 的评测应把"是否该执行"与"能否执行"分开度量。
- **决策导向的世界模型用法值得推广**：将 WM 从"预测接下来会发生什么"转向"若严格执行指令会发生什么"，把世界模型变成**反事实安全推理器**。这一思路可迁移至机器人操作（"若严格抓取该物体是否会碰撞"）、具身导航等同样存在"指令-环境冲突"的领域。
- **显式决策解耦的通用架构价值**：模式 token + 动作 token 的两段式输出，为"高层该不该做 / 低层怎么做"的解耦提供了轻量实现，且模式 token 可作为安全审计与人工接管触发点，具备工程落地价值。
- **数据规模不是万能药**：消融显示扩数据只改善安全、损害跟随，说明**沿 Pareto 前沿滑动 ≠ 外推前沿**，必须引入结构性组件（模式监督、导航条件化 WM）才能同时改善两项指标。这对"堆数据即可解决"的行业惯性是有力反证。
- **后续可探索方向**：更细粒度的模式分级（或多维风险标签）、在线/闭环的冲突检测与语言解析、跨域（仿真→真实）泛化、对抗指令的形式化威胁建模，以及在真实车辆上验证模式 token 的可解释性与回退机制。

## 10. 总体评价

SafeDriveVLA 是一篇**问题意识鲜明、方法解耦干净、评估态度诚实**的驾驶 VLA 安全研究。其核心贡献不在于刷新某个单一指标，而在于：(1) 首次把"导航-场景冲突"确立为 VLA 驾驶的独立安全漏洞，并给出三视角基准套件；(2) 提出用"驾驶模式归因 + 导航条件化 dreaming"显式解耦冲突推理与动作生成，实现跟随与安全的 Pareto 外推（语言 NCR 55.6%→83.0%，冲突交通违规 ↓85.2%，对抗降幅减半）。主要局限在于基准样本量与语言接口的"半自由"性质、模式标签的启发式依赖，以及部署可行性与真实世界验证的缺位。尽管如此，它清晰指出了一条重要判断：**在 VLA 大规模上车前，导航-场景冲突必须被当作与感知安全同等重要的独立议题来对待**，这一呼吁具有超出单篇论文的行业价值。
