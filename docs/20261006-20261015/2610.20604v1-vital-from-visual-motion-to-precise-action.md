## 摘要
世界-动作模型旨在将视觉预期转化为驾驶决策，但通常在与视觉动态无关的轨迹表示上训练动作专家。这促使我们直接从视觉运动推导动作目标。我们首先研究一个更简单的设定：从记录的未来图像中重建轨迹。即使不需要未来预测，重建也能捕捉主导机动动作，但会留下厘米级误差。因此，我们提出 VITAL（Vision-Induced Tokens for Action Learning，用于动作学习的视觉诱导词元），这是一种动作分词器，它将视觉推导出的运动骨架与一个紧凑残差耦合起来，该残差编码该骨架留下的轨迹误差。这种表示使视觉运动成为主要预测目标，并为小幅度量修正提供单独、归一化的学习尺度。使用流匹配，动作专家从当前图像、自车状态和导航命令联合预测这两个分量，而在推理时无需生成未来图像。相同的残差坐标支持有界强化学习后训练，在保持预测视觉骨架固定的同时细化执行。仅需一个动作去噪步骤，VITAL 在 NAVSIM v1 navtest 上达到 90.8 PDMS，与其十步得分相差 0.13 分以内，端到端推理速度为其 3.29 倍。无需重新训练，它在 NAVSIM v2 navtest 上达到 91.1 EPDMS，在 navhard 上达到 38.6。项目主页：https://worldbench.github.io/vital

## Abstract
World-action models aim to turn visual anticipation into driving decisions, yet typically train action experts on trajectory representations defined independently of visual dynamics. This motivates deriving action targets directly from visual motion. We first examine a simpler setting in which trajectories are reconstructed from recorded future images. Even without the need for future prediction, reconstruction captures the dominant maneuver but leaves centimeter-scale errors. We therefore introduce VITAL (Vision-Induced Tokens for Action Learning), an action tokenizer that couples a visually derived motion scaffold with a compact residual encoding the trajectory error left by that scaffold. This representation makes visual motion the principal prediction target and gives small metric corrections a separate, normalized learning scale. Using flow matching, the action expert jointly predicts both components from the current image, ego state, and navigation command, without generating future images at inference. The same residual coordinates support bounded reinforcement post-training that refines execution while keeping the predicted visual scaffold fixed. With only one action denoising step, VITAL achieves 90.8 PDMS on NAVSIM v1 navtest, within 0.13 points of its ten-step score at 3.29x the end-to-end inference speed. Without retraining, it achieves 91.1 EPDMS on NAVSIM v2 navtest and 38.6 on navhard. Project page: https://worldbench.github.io/vital

## 1. 核心问题与研究动机

- **背景**：世界-动作模型（World-Action Models）试图把"对世界如何演变的视觉预测"转化为"车该怎么开"的驾驶决策，常见做法是在 Mixture-of-Transformers 中让动作 token 通过注意力读取视觉特征，再解码自车轨迹。
- **核心矛盾**：注意力只连接了特征，却没有让两个专家共享**预测目标**。视频专家学习场景演化，动作专家通常学习一个仅由轨迹坐标定义的编码——两者用各自独立构造的表示描述同一物理运动。
- **关键实证发现（问题的定量化）**：作者先做一个更简单的设定——把"未来预测"从问题中彻底移除，直接给模型**已录制的当前与未来图像**去重建自车轨迹。即便未来已在眼前，重建仍留下 **123.6 mm ADE / 221.6 mm FDE**，且速度能量高频占比（HF fraction）仅 **0.1%**，说明视觉重建得到的只是一个**平滑的"机动骨架"（motion scaffold）**，在道路边界附近缺失厘米级细节，可能让"看起来合理"的轨迹变得不合规。
- **整体含义**：视觉运动是良好的动作目标来源，但不足以承载执行所需的度量精度。因此需要一种同时保留"视觉接地"与"度量精度"的动作表示，并且该表示必须能在部署时（看不到未来）被预测出来。

## 2. 方法论

### 2.1 核心思想
把动作目标拆成两个互补分量：**视觉运动骨架（visual scaffold）** 定义主导机动，**配对度量残差（paired metric residual）** 编码骨架未能还原的轨迹误差；残差经过标准化，使小尺度修正拥有独立的学习尺度。二者由流匹配联合预测，并复用同一残差坐标系做有界强化后训练。

### 2.2 阶段一：目标构建（视觉-残差编解码器）
- **视觉骨架**：编码器 `Ev` 从录制图像序列提取运动，解码器 `Dv` 映射为轨迹坐标：`z*_v = Ev(V+), τ*_v = Dv(z*_v)`。
  - 驾驶实例：在 VGGT-Ω 上用 LoRA 适配 5 帧前视图像（0/1/2/3/4 s），单目平移被视为非度量，**度量尺度由轨迹监督提供**；时序编码器 + 区间混合层输出 **4 个 64 维运动 token**；宽度 256 的解码器预测车身系前向/侧向速度与偏航率，在 40 点、10 Hz 网格上积分。
  - 训练目标含轨迹/增量/关键帧重建、运动平滑、隐变量条件化、噪声码重建与辅助流任务等加权项；拟合后**整体冻结**。
- **度量残差**：`e* = vec(τ − τ*_v)`，在训练残差上拟合均值 `µ`、正交 PCA 基 `U` 与正对角系数尺度 `S`：
  - `z*_r = S⁻¹Uᵀ(e* − µ)`，`M = US`
  - 解码：`D(z_v, z_r) = D_v(z_v) + unvec(µ + M z_r)`
  - 驾驶实例：每个 1 秒区间 12 个残差系数 + 1 个视觉 token，构成 **4×76 的动作接口**，残差总维度 `dr = 48`；航向残差拟合前做 wrap。rank 在 {2,…,30} 中扫描后选 12（权衡紧凑性与精度）。
  - `S` 的标准化作用：让小幅度物理修正获得与主导运动相当的学习尺度；残差保留的是"重建误差"而非预设频段，因此同时含快变与慢变分量。

### 2.3 阶段二：联合动作学习与单步推理
- **联合流匹配**：`z* = N(concat(vec(z*_v), z*_r))`，在 `z_t = (1−t)ϵ + t z*`、目标速度 `u = z* − ϵ` 下最小化加权目标 `L_FM^a = E[w(t)‖v_θ(z_t, t, h(c)) − u‖²_W]`，视觉与残差坐标相对权重 **1:2**（归一化后视觉前缀占 72.7% 维度权重）。
- **附加监督**：`L_IL = L_FM^a + λ_v L_FM^v + λ_d ℓ_τ(D(ẑ_v, sg[ẑ_r]), D(z*_v, z*_r))`，`λ_v = 0.25`，stop-gradient 只阻断解码损失经 `ẑ_r` 的回传。
- **因果条件化**：仅对首帧 token 前缀施加 rank-16 KV 适配器（最后 8 个视频块），隔离注意力使动作查询可用观测帧特征、但**不能访问未来视频 token**；部署时未来图像不参与。
- **单步执行**：一次 Euler 更新 `ẑ(1) = ϵ + v_θ(ϵ, 0, h(c))`，`τ_IL = eD(ẑ(1))`；解码与残差算术用 FP32 保精度。改变 NFE 只是对同一条件场的数值积分不同。

### 2.4 理论分析（误差分解）
- **表示容量**：`vec(τ − D(z*_v, z*_r)) = (I − UUᵀ)(e* − µ)`，即残差直接瞄准骨架误差，其保留子空间决定码长-保真度权衡。
- **解码预测误差上界**：`‖τ − τ̂‖_Q ≤ ε_codec + L_v‖ẑ_v − z*_v‖_F + ‖M‖_{2→Q}‖ẑ_r − z*_r‖₂`，把"表示容量 / 视觉预测 / 残差预测"三项分离；`MᵀQM` 给出残差 token 误差到物理轨迹误差的度量。
- **一步积分误差界**：`‖eD(z₁) − eD(z_E)‖_Q ≤ (L_D/2)·sup‖a(t)‖₂`，`a(t)` 为沿解的物质加速度，说明预测更好不必然积分更好。

### 2.5 阶段三：结构保持的残差策略精炼（残差 RL）
- **冻结**动作生成器、视觉条件化与完整 codec；残差 actor 读取冻结策略隐状态、上下文与基础预测，输出 `q_φ ∈ R⁶`。
- **有界修正空间**：6 个解析扰动模板（纵向/侧向，`ρ^p, p∈{2,3,4}`）经正则化加权最小二乘投影到残差解码器张成空间，再用解码 Gram 矩阵白化，得到固定 `B ∈ R^{48×6}`；径向限幅器 `Π_C` 强制位置 ≤ 1 m、航向 ≤ 0.2 rad、残差 token 幅度受限：`Δz_r = Π_C(Bq_φ)`，`τ_φ = τ_IL + unvec(MΔz_r)`。零修正严格还原基础轨迹。
- **奖励优化**：把每个训练场景视为上下文 bandit；硬场景池（训练集中 base PDMS < 90 的 17,013 个）做奖励探索，6,598 个高分 anchor 做零修正正则；对偶高斯扰动估计平滑奖励梯度 `ĝ(q) = (1/2Kσ)Σ[F(q+σξ_k) − F(q−σξ_k)]ξ_k`（对 6 个动作坐标做高斯平滑，奖励无需可微）；actor 输出层零初始化，初始行为等同基策略；1,600 次更新，16 硬场景 × 8 对偶对 + 64 anchor。
- **部署**：`ξ = 0`，只施加一次确定性均值修正，**不需要**额外去噪、候选搜索、集成或奖励评估。
