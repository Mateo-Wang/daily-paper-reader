## 摘要
视觉-语言-动作（VLA）模型通过利用世界知识与理解，在长尾场景中表现出色，展现出用于端到端自动驾驶的强大潜力。然而，当前VLA模型存在两个局限：1）退化为视觉-动作（VA）模型。为降低时延，基于回归/流的方法直接生成动作，却未充分利用VLM理解，导致动作不安全且难以解释。2）自回归高时延。自回归方法依次生成思维链（CoT）和动作token，充分利用了VLM理解，但高时延阻碍部署。为在利用CoT辅助动作生成的同时实现低时延部署，我们提出AUGUstus，一种统一生成与理解的自动驾驶VLA模型。我们将基于扩散的动作生成与自回归CoT理解统一到一个模型中，其中理解仅服务于生成。联合CoT监督在共享表示中保留VLM的空间理解，从而生成更安全、更准确的轨迹。AUGUstus模式将动作生成排在CoT之前，因此训练时CoT监督可靠动作，而推理仅需动作输出，从而实现低时延。AUGUstus-GRPO是一种统一的GRPO算法，联合优化动作与CoT，提升动作性能。实验表明，AUGUstus在NAVSIMv1上达到94.6 PDMS，在NAVSIMv2上达到90.7 EPDMS，在无需评分器模块的情况下实现SOTA规划性能。在nuScenes上，其平均L2误差为0.27 m，平均碰撞率为0.05%，在对比方法中最佳。为验证AUGUstus的实用性，我们使用512块NVIDIA H800 GPU在内部数据上训练约2天，在内部1000 km数据集上评估，并初步部署到真实车辆，实现12 Hz运行。项目页面：https://augustus-ad.github.io

## Abstract
Vision-language-action (VLA) models show strong potential for end-to-end autonomous driving by leveraging world knowledge and understanding to excel in long-tail scenarios. However, current VLAs have two limitations: 1) Degeneration into vision-action (VA) models. For low latency, regression/flow-based methods directly generate actions but underuse VLM understanding, causing unsafe, unexplainable actions. 2) Autoregressive high latency. Autoregressive methods sequentially generate chain-of-thought (CoT) and action tokens, fully leveraging VLM understanding, but high latency hinders deployment. To enable low-latency deployment while using CoT to assist action generation, we propose AUGUstus, an Autonomous-driving VLA model with Unified Generation and Understanding. We unify diffusion-based action generation and autoregressive CoT understanding in one model, where understanding only serves generation. Joint CoT supervision preserves VLM spatial understanding in shared representation for safer, more accurate trajectories. AUGUstus-mode orders action generation before CoT, so CoT supervises reliable actions during training while inference needs only action output, enabling low latency. AUGUstus-GRPO, a unified GRPO algorithm, jointly optimizes action and CoT, improving action performance. Experiments show AUGUstus achieves 94.6 PDMS on NAVSIMv1 and 90.7 EPDMS on NAVSIMv2, SOTA planning without scorer module. On nuScenes, it achieves average L2 error 0.27 m and average collision rate 0.05%, best among compared methods. To validate AUGUstus practicality, we train on in-house data with 512 NVIDIA H800 GPUs for ~2 days, evaluate on an internal 1,000 km dataset, and preliminarily deploy on a real vehicle, achieving 12 Hz operation. Project page: https://augustus-ad.github.io

# AUGUstus 论文总结

## 1. 核心问题与整体含义

- **背景**：自动驾驶正从模块化（感知-预测-规划）走向端到端模型（ST-P3、UniAD、VAD），但其模型容量与训练数据有限，长尾场景处理能力不足。VLA 模型借助大规模预训练的视觉概念、语言先验与推理能力，被视为解决长尾问题的有前景方案。
- **核心矛盾**：现有自动驾驶 VLA 架构难以兼顾 VLM 理解能力与低延迟控制，具体表现为三类局限：
  - **回归头**：低延迟，但无动作分布，难以做 RL 后训练，且未充分利用 VLM 知识，动作质量低（退化）。
  - **扩散/流匹配专家**：具备动作分布、对 RL 友好，但生成器独立于 VLM，仍不充分利用空间理解，动作不安全且难解释。
  - **自回归解码**：串行生成 CoT 与动作，充分利用理解，但高延迟导致难以实时部署。
- **关键论点**：问题根源在于"理解"与"动作生成"被人为分离，而非当作统一过程处理。作者主张 CoT 不应是独立推理阶段或动作的串行前缀，而应与动作生成在同一架构内联合优化，其中动作生成为核心、CoT 服务于动作。
- **核心问题**：能否设计一种架构，既保留对动作有用的理解，又保持低延迟、易部署？

## 2. 方法论

### 2.1 统一框架（Unified Framework）

- **输入上下文**：`c = (S, E, C, H)`，即摄像头视频 S、自车状态 E、路径指令 C、历史轨迹 H。
- **核心统一**：在同一 Transformer 内融合**基于扩散（流匹配）的连续动作生成**与**自回归 token 式 CoT 理解**。
- **训练映射**：`(c, x_t, y_<k) → (x̂_0, p_θ(y_k | c, x_t, y_<k))`，即同时预测干净轨迹与下一个 CoT token。
- **x_0 参数化**：采用 `x_t = (1-t)x_0 + tε`，`x̂_0 = f_θ(x_t, t, c)`，直接预测干净轨迹而非速度场。这样 t=1 时单步 Euler 即可返回 x̂_0，支持少步/单步采样，构成真正的单步策略。
- **注意力设计（AUGUstus-mode）**：
  - 上下文 token：因果注意力；
  - 动作 token：双向块，可关注完整上下文与彼此；
  - CoT token：因果，可关注完整动作块；
  - **动作 token 不能关注 CoT token**，保证推理时无需依赖 CoT。
- **推理**：仅给定上下文 c，从噪声 x_1 经 1 步或少数步去噪得到 x̂_0，CoT 解码可选（仅 RL rollout 或事后请求时使用）。

### 2.2 AUGUstus-mode（先动作、后 CoT）

- 训练时将动作生成排在 CoT 之前，使 CoT 监督信号反向作用于动作表示；推理只需动作输出，从而保持低延迟。
- CoT 内容设计探索：**预测型 CoT（关键物体的 2D 边界框 + 未来相对位置，如 near-front、far-left）** 对动作最有益，优于感知型、规划型与自由推理型 CoT。

### 2.3 监督微调（SFT）

- 联合优化流匹配损失与教师强制语言建模损失：
  - `L_SFT = λ_FM · E_{t,ε}[‖x̂_0 − x_0‖_1] − λ_CoT · E[Σ_k log p_θ(y_k | y_<k, c, x_t)]`
  - 默认 λ_diff = 10，λ_lm = 1。
- 动作段使用双向注意力，CoT 段使用因果注意力；时间条件通过分段 AdaRMSNorm 注入（上下文/CoT 用 t=0，动作 token 用采样 t），避免扩散状态污染语言流。
- 动作投影器（Action Projector）：3 层 SiLU MLP 拼接正弦时间嵌入；动作解码器：LN→Linear→SiLU→LN→Linear(3)，末端近零初始化。

### 2.4 AUGUstus-GRPO（统一强化学习）

- **共享组相对优势**：每个上下文采样 G 条配对的（动作，CoT）rollout，两分支共享归一化优势：
  - `R_i = R_pred,i + w_plan · R_plan,i`
  - `A_i = (R_i − mean_j R_j) / (std_j R_j + ε_0)`
- **JaT-GRPO（动作分支）**：在 x_0 参数化下推导闭式高斯重要性采样比率与 KL。基于线性条件流路径与 Flow-GRPO 的反向转移核 `x_{t−Δt} = x_t − [v_θ + g(t)²/(2t)(x_t + (1−t)v_θ)]Δt + g(t)√Δt·z`，由于协方差固定，比率与 KL 化简为：
  - `log r = (c_0/σ_s)⟨δ_old, z⟩ − (c_0²/2σ_s²)‖δ_old‖²`
  - `KL_act = (c_0²/2σ_s²)‖x̂_0^θ − x̂_0^ref‖²`
  - 该闭式解支持少步与单步去噪下的 RL 优化；论文还论证了单步 GRPO 中探索噪声 λ>0 的必要性（否则组内样本相同、优势为零）。
- **CoT-GRPO（语言分支）**：token 级 GRPO，使用与动作相同的共享优势。
- **总体目标**：`L = −J_action + β_action·KL_act + α_CoT(−J_CoT + β_CoT·KL_CoT)`。
- **两阶段训练（Run-then-Walk）**：
  - Stage I：`R_plan = PDMS`，侧重进步性，对齐基准目标；
  - Stage II：`R_plan = R_end + R_safe`，保留进步性的同时强化终点精度与安全性（有意去掉 PDMS，因后期组内方差近饱和且会牺牲 NC/TTC 换 EP）。
