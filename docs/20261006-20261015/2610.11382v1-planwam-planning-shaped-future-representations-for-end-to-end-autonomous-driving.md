## 摘要
端到端自动驾驶中的世界模型通过预测未来场景演化，为轨迹规划提供前瞻性。现有方法主要研究如何预测未来以及如何使用未来，但较少追问哪种未来表征实际上对规划最有用。为此，我们提出 PlanWAM，一种规划塑形的世界动作模型。其核心思想是让规划任务塑造未来状态表征，使其保留对规划最有用的信息。随后，一个潜在世界模型根据历史观测预测这种规划塑形的未来潜在表征，并将其用于规划，从而实现具有前瞻性的规划。具体而言，我们首先使用时间寄存器金字塔（Temporal Register Pyramid）以近期感知的方式压缩多帧历史信息，学习一种面向未来推理与规划的紧凑历史表征。然后，我们引入一个特权未来后验分支，该分支观测真值未来帧，并用轨迹规划目标塑造其未来潜在表征，以获得规划塑形的未来潜在表征。后见至前瞻蒸馏（Hindsight-to-Foresight Distillation）训练一个仅依赖历史的先验分支来预测该未来潜在表征。预测得到的未来潜在表征作为规划上下文，引导轨迹生成与选择。PlanWAM 在 NAVSIM-v1/v2 navtest 上达到 93.8 PDMS / 90.9 EPDMS，并在零样本设置下于闭环 HUGSIM 上达到 38.7 HD-Score，在开环和闭环评估中均展现出领先的规划性能。大量实验进一步表明，规划塑形的未来表征为世界动作模型提供了一种有效且可部署的前瞻形式。

## Abstract
World models in end-to-end autonomous driving predict future scene evolution to provide foresight for trajectory planning. Existing methods mainly study how to predict the future and how to use it, but less often ask which future representation is actually most useful for planning. To this end, we propose PlanWAM, a Planning-Shaped World Action Model. The key idea is to let the planning task shape the future-state representation, so that it retains the information most useful for planning. A latent world model then predicts this planning-shaped future latent representation from historical observations and uses it for planning, enabling foresighted planning. Specifically, we first use a Temporal Register Pyramid to compress multi-frame historical information in a recency-aware manner, learning a compact history representation oriented toward future reasoning and planning. We then introduce a privileged future posterior branch that observes ground-truth future frames, and shape its future latent representation with trajectory-planning objectives to obtain a planning-shaped future latent representation. Hindsight-to-Foresight Distillation trains a prior branch that depends only on history to predict this future latent representation. The predicted future latent representation serves as planning context and guides trajectory generation and selection. PlanWAM achieves 93.8 PDMS / 90.9 EPDMS on NAVSIM-v1/v2 navtest and reaches 38.7 HD-Score on closed-loop HUGSIM in a zero-shot setting, demonstrating leading planning performance across both open-loop and closed-loop evaluations. Extensive experiments further demonstrate that planning-shaped future representations provide an effective and deployable form of foresight for world-action models.

## 1. 核心问题与研究动机

- **背景**：端到端自动驾驶直接从原始传感器观测规划轨迹，而可靠驾驶不仅依赖当前观测，还需要历史动态线索与未来场景演化的推断，因此世界模型成为重要方向。
- **现有方法的演进路径**：
  - 早期（Epona、PWM）：通过生成未来图像/视频/BEV 等像素级或稠密状态重建学习环境动态，但建模了大量与规划弱相关的视觉细节，生成成本高。
  - 中期（LAW、Latent-WAM）：转向潜在世界建模，在紧凑特征空间预测未来状态，但未来表征主要作为预测目标或辅助监督，对规划的影响是间接的。
  - 近期（DriveFuture、WorldDrive）：将预测的未来隐变量显式引入轨迹规划器，使未来信息直接参与规划。
- **被忽视的关键问题**：现有工作多关注"如何预测未来"和"如何使用未来"，却很少追问 **哪种未来表征对规划最有用**。基于像素重建或通用图像隐变量（DINO、JEPA、BEV）定义的未来表征，可能与下游规划目标不匹配——能重建场景的表征未必保留影响轨迹决策的关键信息。
- **核心重构**：论文将端到端驾驶中的未来建模重新表述为 **规划导向的预测表征学习问题**：世界模型不仅要预测未来，还要学会"哪些未来信息值得预测"。统一了历史建模、未来预测与轨迹规划，使规划定义何为重要的未来信息，未来预测反过来指导历史信息的保留，所得未来表征再改善规划。

## 2. 方法论

### 2.1 核心思想

- 让**轨迹规划目标直接塑造未来隐表征**，而非使用预定义的重建/通用预测目标；该表征再由仅依赖历史的先验分支预测，作为可部署的前瞻用于轨迹生成与选择。

### 2.2 问题形式化

- 传统端到端规划器建模 $p(\tau_{1:T} \mid v_{t-n:t}, c_{t-n:t})$。
- 未来条件 WAM 引入未来状态表征 $z_t^+$，分解为：
  $$p(\tau_{1:T}, z_t^+ \mid v_{t-n:t}, c_{t-n:t}) = p(z_t^+ \mid v_{t-n:t}, c_{t-n:t})\, p(\tau_{1:T} \mid v_{t-n:t}, c_{t-n:t}, z_t^+)$$
- 关键问题是 $z_t^+$ 应如何定义与构造才对规划最有利。

### 2.3 三大关键组件

**(1) 时序寄存器金字塔（Temporal Register Pyramid, TRP）——近期感知的历史表征**

- 共享视觉编码器将每帧每相机映射为视觉 token，并提取场景寄存器 $r_i^k$；自车状态与导航信息经 MLP 编码为 $e_i$。
- 将历史按时间距离划分为 $L$ 个层级，近期层级分配更多可学习查询，远期历史压缩更强。
- 查询融合自车特征、时间/相机/压缩层级嵌入及当前场景上下文，再经 Q-Former 对相应层级的场景寄存器做压缩，各级压缩 token 拼接为紧凑历史表征 $h_t$（128 token）。
- 不使用额外的历史重建目标，$h_t$ 由后续的未来隐表征蒸馏损失与轨迹规划损失联合优化。

**(2) 规划塑形的未来表征（特权后验分支，仅训练时使用）**

- 对真值未来观测提取场景寄存器，加上未来时间嵌入形成未来查询 $f_t^+$。
- 后验世界模型以 $f_t^+$ 为 Q、以历史表征 $h_t$ 为 K/V，输出后验未来隐变量 $z_t^+$。
- **关键点**：不对 $z_t^+$ 施加通用重建目标，而是将 $z_t^+$ 与 $h_t$ 拼接（加类型嵌入）构成后验规划上下文 $m_t^+$，同时送入轨迹生成器 $G_{plan}$ 与轨迹评分器 $G_{score}$，由 $L_{post} = L_{plan} + L_{score}$ 反向塑造 $z_t^+$，使其优先编码影响轨迹生成与选择的未来信息。

**(3) 后见至前瞻蒸馏（Hindsight-to-Foresight Distillation, H2F）与前瞻条件规划（FCP）**

- 部署时未来观测不可用，故构造仅依赖 $h_t$ 的先验分支 $P_\theta$，使用可学习未来查询，并**按未来时间、相机视角、寄存器槽位的相同顺序**排列，以保证与后验 token 一一对应。
- 通过 token 级对齐损失将先验预测 $\hat{z}_t^+$ 与后验目标 $z_t^+$ 对齐（stop-gradient + Frobenius 范数），把特权后见蒸馏为前瞻：
  $$L_{latent} = \frac{1}{N_z d}\|\hat{z}_t^+ - \text{sg}(z_t^+)\|_F^2$$
- 预测的 $\hat{z}_t^+$ 与 $h_t$ 拼接成先验规划上下文 $m_t^-$，同时指导轨迹生成与选择，即前瞻条件规划。

### 2.4 训练与推理

- **两阶段训练**：
  - 阶段 1：仅优化特权后验，损失为 $L_{task} = L_{plan} + L_{score} + \lambda_{reg} L_{reg}$（含防坍缩的正则项：范数正则 + 多样性正则）。
  - 阶段 2：冻结后验，用其 checkpoint 初始化先验中结构兼容的参数，以更低学习率微调：$L_{train} = L_{task} + \lambda_{latent} L_{latent}$（$\lambda_{latent}=0.05$）。
- **推理**：移除特权后验，仅保留先验；历史编码为 $h_t$ → 先验预测 $\hat{z}_t^+$ → 与 $h_t$ 拼接 → 轨迹生成与评分。全程仅依赖可观测历史。
- **其他细节**：轨迹生成器输出 K=64 条候选轨迹（8 个路点），评分器用 6 个 MLP 头预测 NC、DAC、TTC、EP、DDC、舒适度子分数用于排序；规划记忆为 384 token（128 历史 + 256 未来）。

## 6. 主要结论与发现

- **性能**：NAVSIM-v1 达 93.8 PDMS（比 DrivoR 高 0.7，比最强世界模型规划器 DriveFuture 高 3.1）；NAVSIM-v2 达 90.9 EPDMS（比此前最强学习结果高 1.0，超过 Human Agent 0.6）；HUGSIM 零样本闭环达 53.7 平均 RC 与 38.7 HD-Score（比最强基线高 7.8 / 9.8）。
- **表征质量比表征容量更重要**：在相同 128-token 预算下，近期感知分配 [4,4,8,16] 优于均匀与反向分配；增至 256 token 仅得 93.6，说明查询分配方式比扩大表征更关键。
- **通用预测目标不足**：通用未来特征监督仅 93.5 PDMS，而用规划目标直接塑形可达 93.8，说明规划导向的监督更有效。
- **未来隐变量用于选择比用于生成更有效**：仅辅助监督或仅条件化生成收益很小（93.5），用于轨迹选择达 93.7，两者兼用达 93.8。
- **蒸馏是必要的但并非越紧越好**：无蒸馏时 latent 相似度仅 0.46；$\lambda_{latent}=0.05$ 时相似度 0.93、PDMS 最高 93.8；增至 0.10 相似度升到 0.95 但 PDMS 降至 93.7——更紧对齐不必然带来更好规划。
- **失败模式改善集中在动态场景理解**：NC 失败下降 62.3%，TTC 下降 52.4%，DDC 下降 66.7%；而 DAC 略有恶化，表明收益集中于动态决策而非可行驶区域建模。

## 7. 优点

- **问题视角新颖**：把"未来表征该编码什么"作为一等公民问题，将未来建模重构为规划导向的预测表征学习，并用规划目标直接塑形隐空间，区别于通用的像素重建或图像隐变量目标。
- **方法论设计严谨**：
  - 特权后验（训练时）+ 历史先验（部署时）的师生式结构，配合 token 级对齐（时间/相机/槽位顺序一致）与 stop-gradient，保证蒸馏方向正确、避免目标被学生拉偏。
  - 近期感知的时序寄存器金字塔在固定 token 预算下合理分配历史信息，兼顾效率与信息价值。
  - 两阶段训练 + 防坍缩正则（范数 + 多样性）设计完整。
- **实验体系完整**：同时覆盖开环（NAVSIM-v1/v2）与闭环零样本（HUGSIM），横跨四个来源域；消融维度全面（表征监督、使用位置、token 分配、蒸馏权重、可训练模块），并给出 oracle 后验上界与 latent 相似度指标，可信度较高。
- **工程可部署性**：推理时完全移除未来观测与后验分支，仅保留先验；报告了推理延迟（~335–380 ms），并指出未来信息只被冻结教师消费、不做数据增强，保证了部署合规性。
- **失败分析具洞察力**：不仅报告指标，还统计失败类型与归因，明确指出收益来自动态决策与轨迹选择可靠性，同时诚实报告 DAC 的轻微退化。

## 8. 不足与局限

- **数据集与场景覆盖有限**：主实验依赖 NAVSIM-v1/v2（同源 OpenScene/nuPlan，非反应式 proposal 仿真），闭环验证仅 HUGSIM 的 436 个公开场景；缺少在 nuPlan 闭环、CARLA 或其他大规模真实闭环基准上的验证。
- **未报告训练成本**：仅给出 GPU 型号/数量、batch size 与 epoch 数，未提供训练墙钟时间、总 GPU 小时或显存占用，难以评估实际训练开销与可复现成本。
- **两阶段 + 特权后验的复杂度**：需要真值未来帧进行阶段 1 训练，对数据标注/时序对齐要求较高；两阶段训练与蒸馏权重（$\lambda_{latent}$）需要调参，且论文显示蒸馏过强反而损害规划性能，存在调参敏感性。
- **潜在偏差风险**：
  - 所有消融均在 NAVSIM-v1 navtest 上完成，未验证结论在 v2/闭环下的普适性。
  - HUGSIM 平均分按场景数加权（Medium 场景最多），不同难度分布不均衡，可能影响对困难场景能力的解读。
  - 论文为 arXiv preprint，部分引用文献为 2026 年，尚需同行评议验证。
- **方法细节的取舍**：DAC 失败略有恶化，说明规划塑形表征偏向动态场景理解而对静态可行驶区域约束帮助有限；附录表 17 显示复制自后验的 planner/scorer 权重需要重新学习，说明先验与后验隐空间之间仍存在分布差异。
- **应用限制**：依赖 4 路相机与历史多帧输入，闭环零样本虽表现领先但绝对 HD-Score（38.7）仍不高，距离真实道路部署仍有较大差距；未讨论极端天气、传感器失效等安全关键场景。
