## 摘要
动作条件世界模型能够减少视觉-语言-动作模型（VLA-RL）强化学习中对昂贵真实机器人交互的需求，但幻觉可能误导策略优化。将其扩展到更丰富的VLA接口和长时程任务，会带来时空与跨模态一致性、强化学习中的探索-可靠性平衡以及展开误差累积等挑战。我们提出WoVR+，通过重新设计学习环境和想象交互协议，扩展了WoVR的幻觉感知WM-RL框架：一个与VLA接口对齐的世界模型提供多视图预测和本体感觉更新，同时减轻幻觉。分块噪声在保持基于流的策略探索的同时，限制了会损害预测的动作抖动。对于长时程任务，阶段局部想象训练结合了阶段进入重置、阶段特定奖励、局部时域和可控采样，以缩短生成前缀并平衡各阶段训练。WoVR+在RoboTwin和6个真实机器人任务上，将成功率较SFT分别提升21.09%和16.7%。长时程手机包装任务的成功率从30%提升至75%。视频见：https://youmo445.github.io/WoVR_Plus.github.io/。

## Abstract
Action-conditioned world models can reduce costly real-robot interaction in reinforcement learning for Vision-Language-Action models (VLA-RL), but hallucinations can mislead policy optimization. Extending them to richer VLA interfaces and long-horizon tasks raises challenges in spatiotemporal and cross-modal consistency, exploration-reliability balance in RL, and compounding rollout errors. We present WoVR+, extending WoVR's hallucination-aware WM-RL framework by redesigning the learned environment and imagined interaction protocol: A VLA-interface-aligned world model provides multi-view prediction and proprioceptive updates while mitigating hallucinations. Chunk-wise noise preserves flow-based policy exploration while limiting prediction-degrading action jitter. For long-horizon tasks, stage-local imagined training combines stage-entry resets, stage-specific rewards, local horizons, and controllable sampling to shorten generated prefixes and balance training across stages. WoVR+ improves success over SFT by 21.09% and 16.7% on RoboTwin and 6 real-robot tasks. Long-horizon phone-packaging success rises from 30% to 75%. Videos are available at https://youmo445.github.io/WoVR_Plus.github.io/.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：VLA（视觉-语言-动作）模型通常通过监督微调（SFT）训练，其性能上限受限于示范数据的质量与覆盖范围。强化学习（RL）可进一步突破该上限，但在真实机器人上做在线 RL 交互代价极高。
- **世界模型作为替代方案**：基于视频生成的动作条件世界模型（ACWM）可作为"学习到的环境"，让 VLA 策略在想象中做闭环交互，从而减少真实机器人交互。
- **关键风险——幻觉**：ACWM 并非忠实模拟器，会产生视觉上合理但物理上错误的 rollout，制造"虚假成功信号"。若直接用于策略优化，RL 会利用模型系统性误差而非真实任务进展。
- **WoVR 的立场**：将世界模型用于 RL 本质上是**可靠性问题**而非建模问题，需在"可控模拟器设计、可靠想象交互、策略-模型对齐"三个层面控制幻觉。
- **本文要解决的三个新挑战**：
  1. 现代 VLA 依赖**多视角观测 + 本体感知**，要求世界模型保持时间、空间、跨模态一致性；
  2. 基于流的动作块策略在探索时易产生**动作抖动**，加剧世界模型幻觉；
  3. 长时程多阶段任务中，世界模型误差沿自回归 rollout **累积**。
- **整体含义**：WoVR+ 在保留 WoVR 幻觉感知 WM-RL 框架的前提下，重新设计学习环境与想象交互协议，将可靠性问题扩展到"接口完整性、探索导致的预测退化、长时程阶段式学习"。

## 2. 方法论

### 2.1 核心思想
以 WoVR 的 WM-RL 框架为基础（可控模拟器、可靠交互、策略-模型对齐三层），针对多视角 VLA 接口与长时程任务，重构三个耦合组件：

1. **VLA 对齐的多视角世界模型**（可靠局部动力学）
2. **时序一致的探索**（chunk-wise Flow-SDE）
3. **阶段局部想象优化**（长时程）

### 2.2 关键技术细节

#### （A）VLA 对齐的多视角世界模型
- **骨干**：Wan2.2-TI2V-5B 视频生成模型 + VACE 并行控制分支。
- **几何接地的动作与相机条件**：
  - 将绝对关节目标经正运动学转为 EEF 位姿，投影到各视角生成**动作图**（圆表示 EEF 位置，半径编码深度，颜色编码夹爪开合度，三轴编码朝向），双机械臂用半透明叠加合成。
  - **相机光线图（Raymap）**：直接构建在视频 latent 网格上（避免额外 VAE 编码路径），逐帧用正运动学与手眼标定更新相机位姿。
- **Latent 对齐控制注入**：动作图 latent 与按时间分组的射线原点/方向沿通道拼接，经 3D patch embedding 投影，加视角嵌入，注入并行 DiT 控制流：
  - `c_{j+1} = C_j(c_j, g)`，`h_{j+1} = B_j(h_j) + 1[j∈S] P_j(c_{j+1})`
  - 主 DiT 与控制分支可训练，VAE 与文本编码器冻结。
- **闭环上下文与本体感知更新**：
  - **锚定稀疏历史**：`ι_t = (0, [t-(C-2)s]+, ..., [t-s]+, t)`，C=5，s=4，兼顾首帧场景锚点与近期任务进度。
  - **基于指令的本体感知**：直接用上一步的绝对关节/夹爪指令近似下一步状态 `ŝ_{t+1:t+H} = a^joint_{t:t+H-1}`，无需额外学习转移模型（附录 A 验证其在跨任务场景下比学习式 MLP 更稳定）。
- **鲁棒训练与高效生成**：
  - 对非锚点上下文帧的操控相关区域做**几何感知局部模糊**；
  - 采样时序步长 {1,2,3,4}，同步观测/动作/动作图/相机条件；
  - 流匹配目标 `L_FM = E[||v_φ(z_τ, τ | O_ι, g) - (ε - z_0)||²]`；
  - 标准 5 步推理，并用 DMD2 蒸馏得到 1 步生成器。

#### （B）时序一致探索（Chunk-wise Flow-SDE）
- 将流 ODE 转为 SDE（沿用 πRL 的 ODE-to-SDE 转换）：
  - `x_{k+1,h} = μ_{θ,k,h} + σ_k ε_{k,h}`
- **问题**：在绝对关节动作块上，对相邻 token 施加独立噪声会产生高频抖动。
- **方案**：保持每 token 的边际噪声尺度不变，仅重塑时间协方差——**同一动作块内共享同一噪声向量**：
  - `ε^cw_{k,h} = z_k`，`Cov(ε^cw_{k,h}, ε^cw_{k,h'}) = I_D (h≠h')`
- 训练时每个动作块随机选一个 SDE 步，其余步保持 ODE。
- 注意：chunk-wise 噪声改变了跨 token 依赖，因此逐 token 代理比率并非精确联合似然比。

#### （C）阶段局部想象优化
- **Full-start 的三个局限**：后续阶段覆盖不足（到达概率 `q^π_m = Π p^π_j` 乘性衰减）、稀疏轨迹级二值奖励、自回归前缀误差累积。
- **KIR 的局限**：只在单一任务级关键帧附近初始化，是"缩短 rollout"机制，而非跨阶段组织学习。
- **WoVR+ 方案**：构建数据支撑的各阶段入口分布，配合阶段特定奖励、局部时域、可控阶段采样：
  - `q^π_{m,reset} = ω_m`，`T^{pre}_{m,reset} = 0`
  - 采用均衡权重 `ω_m = 1/M`，每阶段期望获得 N/M 次直接 rollout 起点。
  - 阶段平衡 GRPO 目标 `J_stage(θ)`：各阶段内对同一 reset 状态分组归一化局部回报 `R^{(i)}_m = y^{(i)}_m`。
  - 各阶段共享同一 VLA 策略，部署时端到端执行、无重置。

### 3.3 实验分组（对应五个研究问题）

4. **WM-RL 策略优化**：RoboTwin 单/多视角、真实机器人六任务。
5. **长时程策略学习**：奖励粒度、自回归前缀长度、阶段训练分配、优化效率、与 KIR 对比。

## 6. 主要结论与发现

- **世界模型保真度**：WoVR+ 在头部与腕部视角的 LPIPS/FID/FVD/SSIM/PSNR 上整体最优；自回归 200 帧范围内退化最慢；在策略诱导动作分布下泛化最强。光线图直接构建于 latent 网格优于图像+VAE 编码，视角嵌入进一步增益；锚定稀疏历史、几何感知模糊、时序步长采样三种训练策略均有提升（时序步长单项增益最大）。
- **策略级效用**：世界模型与真实环境成功率强相关（Pearson r=0.97，Spearman ρ=0.94）；过滤后的合成示范可将 WM-BC 成功率从 71% 提升至 91%（固定重置）。
- **探索机制**：chunk-wise Flow-SDE 比 I.I.D. 优化更稳定、最终成功率更高；DCT 频谱显示其将扰动集中在低频相干分量；噪声尺度增大时扫掠工作空间更广。
- **策略优化**：WoVR+ 在 ACWM 环境中表现最强，优于预算匹配的 Direct RL，逼近无预算约束的收敛 Direct RL；多视角策略始终优于单视角。
- **真实机器人**：6 任务平均成功率从 39.2%（SFT）提升至 55.8%；较 SFT 平均提升 16.7%。
- **长时程**：Phone Packaging 端到端成功率从 SFT 的 30% 提升至 75%（均匀阶段采样）；阶段奖励将全启动 WM-RL 从 50% 提升至 55%，并使 94% 的组保持信息量（对比轨迹奖励 51%）；长前缀会导致后期阶段高估与物体漂移，阶段入口初始化更贴近真实；均匀阶段采样显著优于 arrival-matched（Stage 4：93.8% vs 22.2%）；阶段局部训练每小时信息组吞吐为全启动的 1.58 倍。
- **RoboTwin 总体**：较 SFT 平均提升 21.09%。

## 7. 优点

- **问题定位精准**：将"世界模型用于 RL"明确定位为可靠性问题，并把幻觉控制贯穿模拟器、交互、对齐三层，思路系统。
- **接口对齐彻底**：动作图 + 光线图的几何接地条件、多视角 + 本体感知的完整 VLA 接口对齐，优于纯向量条件或单视角方案。
- **探索机制设计巧妙**：chunk-wise 噪声不降低探索幅度而只重塑时间协方差，兼顾探索有效性与动作平滑性，且有 DCT 频谱与扫掠空间的机制性证据。
- **长时程训练协议完备**：阶段入口重置 + 阶段奖励 + 局部时域 + 均匀采样的组合，同时解决阶段访问不平衡、奖励稀疏、前缀误差累积三个问题。
- **本体感知近似简洁**：利用绝对关节接口直接移位指令，避免额外转移模型，附录证明其跨任务稳定性。
- **实验链条完整**：从视频保真度到策略级一致性再到下游策略改进，含真实机器人验证，说服力较强。
- **效率优化**：DMD2 一步生成、阶段局部短 rollout 带来 1.58× 吞吐提升。

## 8. 不足与局限

- **依赖预定义阶段**：当前框架需要预定义任务阶段和数据支撑的阶段入口状态，无法自动发现阶段或自适应构建重置状态。
- **理论一致性问题**：chunk-wise Flow-SDE 引入跨 token 相关性，但 GRPO 仍使用逐 token 代理比率，并非精确联合似然比，存在理论上的不严谨。
- **阶段边界依赖人工标注**：Phone Packaging 的阶段边界由人工标注最终确定，可扩展性受限。
- **长时程验证范围窄**：仅一个长时程任务（Phone Packaging），结论的泛化性有待更多任务验证。
- **真实机器人评估样本量有限**：每任务 20 次匹配评估，统计置信度有限；六任务虽覆盖多种技能，但任务数量仍偏少。
- **世界模型训练开销未充分披露**：仅给出 8×A100 与 batch size 等配置，未报告总训练时长/算力消耗，可复现性与成本评估受限。
- **奖励模型依赖**：使用任务/阶段特定的 ResNet 二分类器，需人工标注成功帧，奖励模型的准确性可能影响 WM-RL 可靠性。
- **仿真与真实差距**：RoboTwin 上仅评估 2 个任务，仿真结论向真实场景的迁移仍需更多证据。
