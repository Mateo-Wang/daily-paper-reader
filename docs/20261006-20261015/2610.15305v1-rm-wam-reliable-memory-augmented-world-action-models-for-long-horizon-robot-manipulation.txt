RM-WAM: Reliable Memory-Augmented World Action Models
for Long-Horizon Robot Manipulation
Cui Miao1,2, Junhao Yu3, Ping Liu1, Ning Yang4, Xuhua Chen2,
He Zheng2, Xiaodong Wang1, Tao Zhang2∗
1National University of Defense Technology
2Magic-Lab Team, Magiclab Robotics Inc.
3Beijing Institute of Technology

Abstract— World Action Models (WAMs) improve robotic
manipulation by jointly predicting future visual states and ac-
tions, yet most existing methods make decisions primarily from
the current observation. This limits their reliability in long-
horizon tasks, where visually similar states may correspond to
different interaction histories and task stages. Moreover, di-
rectly incorporating historical observations can introduce stale,
stage-mismatched, or error-contaminated information, leading
to inaccurate world prediction and accumulated closed-loop
errors. We propose RM-WAM, a reliable memory-augmented
World Action Model that treats memory as a context-dependent
predictive resource rather than universally useful historical
context. RM-WAM represents history using complementary
short-term visual state memory and latent event memory,
which respectively capture recent interaction dynamics and
longer-term state transitions. A counterfactual memory learning
scheme varies the accessible history while keeping the current
inputs and prediction targets fixed, enabling the model to
learn a context-dependent utility estimate for historical memory.
Based on this estimate, a utility-aware gating mechanism
adaptively controls memory injection into the world–action
backbone. Experiments demonstrate that RM-WAM highlights
the importance of reliable and selective memory utilization in
long-horizon tasks.
I. INTRODUCTION
By further training pretrained vision-language models
on embodied data, Vision-Language-Action models (VLAs)
are becoming an important foundation model paradigm for
robotics and show strong abilities in task understanding and
generalization [1], [2], [3], [4]. However, existing VLAs
focus on predicting the next action from the current ob-
servation directly. This local decision-making paradigm has
clear limitations in long-horizon tasks, because each action
not only determines the immediate behavior but also affects
subsequent environment states and task progress. World Ac-
tion Models (WAMs) are designed to bridge this gap [5], [6],
[7], [8], [9]. By modeling action-conditioned state transitions
and future observations, WAMs predict both what action
the robot should take and how the world changes after the
action is executed. However, reliable prediction of world
evolution depends not only on the current observation, but
also on a continuous understanding of past interactions. This
makes historical context particularly important for WAMs in
complex long-horizon manipulation, where visually similar
observations may correspond to different interaction states
and require different future evolutions.

Recent studies use memory mechanisms to improve policy
performance in long-horizon manipulation tasks. For ex-
ample, MemoryVLA [10], MEM [11], and other memory-
augmented methods [12], [13], [14] build perceptual, se-
mantic, or multi-scale memories to provide additional his-
tory for long-horizon action generation. However, directly
extending these memory mechanisms to WAMs presents
two fundamental limitations, as illustrated in Fig. 1. First,
existing memory-augmented VLAs are primarily designed
to support action prediction, whereas WAMs additionally
model action-conditioned world evolution through future
visual-state prediction. Memory in a WAM therefore needs
to support not only action generation but also world-state
modeling, where inappropriate historical information can
directly distort the predicted future. Second, retrieving task-
relevant history does not necessarily mean that the retrieved
memory is useful for the current world-action prediction.
Existing memory mechanisms typically retrieve historical
information according to relevance or similarity and then
use the retrieved memory as additional context. However,
even highly relevant memory may be stale, inconsistent with
the current task stage, or contaminated by previous rollout
errors. Therefore, WAMs require an additional mechanism
to explicitly assess the utility of retrieved memory before
incorporating it into the prediction process.
This view is also consistent with cognitive science, where
memory is not treated as a passive replay buffer but as an
arXiv:2610.15305v1  [cs.RO]  11 Oct 2026


active and context-dependent source of control [15]. Humans
selectively retrieve and reorganize past experience when it
supports the current goal, while suppressing or weakening
memories that interfere with ongoing behavior. Similarly,
historical information in WAMs should not be assumed to
be beneficial simply because it is relevant to the task. Its
usefulness depends on the current observation, task stage,
and prediction objective. We therefore argue that the key
challenge in memory-augmented WAMs is not only which
memory to retrieve, but also whether the retrieved memory
should be used. This motivates explicitly modeling memory
utility for reliable world-action prediction.
To address this challenge, we propose Reliable Memory-
augmented World Action Model (RM-WAM), a utility-aware
memory framework for long-horizon robot manipulation. We
first model history as short-term visual memory and latent
event memory according to their different roles in world-
state prediction. Short-term visual memory describes local
visual changes, providing interaction states that are difficult
to infer from current observation. Latent event memory
encodes historical transitions in the shared latent space
and captures history that is relevant to future world evo-
lution. We then introduce a counterfactual memory learning
scheme for WAMs. By keeping the current observation and
task instruction fixed while changing the accessible history,
the model learns how different memory conditions affect
future prediction and action generation, thereby obtaining
a context-dependent utility estimate for historical memory
under the current state. Based on the learned utility, the
model adaptively controls memory injection before WAM
backbone, so that it preserves history that helps the cur-
rent prediction while suppressing stale, stage-misaligned,
or error-contaminated memory. In this way, memory is no
longer treated as extra context that is useful by default, but
as a selective historical intervention in world evolution.
Our contributions are summarized as follows:
• We extend memory augmentation to the World Action
Models, and show that the key challenge in memory-
augmented WAMs is not only storing or retrieving his-
tory, but also determining whether memory is consistent
with the current world-evolution prediction and whether
it has positive utility for future state estimation and
closed-loop decision making.
• We propose Reliable Memory-augmented WAM, a

II. RELATED WORKS
A. Vision-Language-Action Models
Vision-Language-Action models (VLAs) integrate visual
observations, language instructions, and robot actions into
end-to-end policies [18], [19], [20]. Many recent VLAs
build on pretrained vision-language models (VLMs) and
are further trained on large-scale robot demonstrations,
improving generalization across tasks, environments, and
robot embodiments [21], [22]. Early works such as RT-
1 [23] and RT-2 [24] show the scalability of Transformer-
based policies. Open X-Embodiment [25], Octo [2], and
OpenVLA [1] further push multi-embodiment training and
efficient downstream adaptation. The π family [26], [3] fur-
ther uses diffusion or flow matching to generate continuous
action chunks. However, existing VLA methods mainly learn
a direct mapping from current observations and language
instructions to action sequences, while overlooking how the
environment evolves under robot actions.
B. World Action Models
World models learn environment dynamics by predicting
future observations or latent states, providing predictive rep-
resentations for planning and policy learning [27], [28], [29].
The Dreamer series [30], [31] optimizes policies in a learned
latent world and shows the value of imagined trajectories.
UniPi [32] and Video Language Planning [33] use future
videos for planning and convert visual predictions into robot
actions through inverse dynamics or goal-conditioned poli-
cies. Recent world action models jointly model future visual
states and actions in a unified architecture [7], [8]. However,
existing WAMs mainly rely on the current observation and
lack effective modeling of historical state. This limits history-
dependent prediction in long-horizon tasks with partial ob-
servability and stage-dependent behavior.
C. Memory-Augmented Robotic Manipulation
Memory is important for handling long-horizon task de-
pendencies in robotic manipulation. Early approaches mainly
use recurrent states or temporal attention to aggregate his-
tory [34]. Recent studies use updatable memory bank to
extend the temporal context of robot policies [35], [11].
However, directly applying memory-augmented mechanisms
to WAMs does not ensure that the retrieved history remains
consistent with the current world prediction. Although recent
studies improve policy performance by introducing hierarchi-
cal, persistent, or higher-capacity memory mechanisms [36],
[37], they primarily focus on organizing and extending
historical context, while the context-dependent utility of
retrieved memory for current world-action prediction remains
less explicitly modeled. Historical information may be stale,
stage-mismatched, or corrupted by closed-loop errors. Our
RM-WAM therefore treats visual memory as a predictive
resource with context-dependent utility rather than uniformly
useful historical context.

A. Problem Formulation
A World Action Model (WAM) jointly predicts future
visual states and robot actions:

ht+1:t+Hv denotes future visual states, and Hv is the visual
prediction horizon. However, the current observation alone

Mt = (mt−δ1, . . . , mt−δK) ,

We focus on selecting memory according to its utility under
the current context, so as to improve future-state and action
prediction in long-horizon tasks.
B. Framework Overview
The overall framework of RM-WAM is illustrated in
Fig. 2. Given the current and historical observations, lan-
guage instruction, and proprioceptive state, RM-WAM first
constructs a dual-scale memory from visual latent tokens.
A temporal encoder aggregates recent latent states to form
short-term memory tokens, while an event encoder repre-
sents historical state transitions as event-memory tokens.
These memory representations are selectively injected into
the video branch through gated adapters, where the gating
functions are learned with counterfactual memory supervi-
sion to estimate the utility of memory. The video branch
adopts Wan2.2-TI2V-5B [38] as the backbone, including
its VAE encoder-decoder and Video DiT, while the action
branch employs an Expert DiT for action prediction. The
two branches interact through a Mixture-of-Transformers
(MoT) and are conditioned on language and proprioceptive
information through the state/text encoder, enabling memory-
enhanced joint prediction of future visual states and action
chunks.
C. Counterfactual Memory

current context, we construct counterfactual memory con-
ditions by varying only the accessible history while keeping
the current observation, task instruction, proprioceptive state
and prediction target unchanged. This design isolates the
influence of memory from changes in the current inputs and
supervision targets. Specifically, Mref

E. Training and Inference
RM-WAM is trained with joint world-action modeling,
future-transition supervision for latent event memory, and
memory-utility supervision. The overall objective is
L = Lact + λvLvid + λeLevt + λuLutility,
(9)
where Lact and Lvid are the flow-matching losses for action
generation and future visual dynamics, Levt encourages
latent event memory to retain historical transitions related
to future world evolution, and Lutility provides memory-
utility supervision from counterfactual memory conditions.
The coefficients λv, λe, and λu balance the video, event,
and utility losses.

During inference, RM-WAM maintains a causal visual
history buffer for each episode. After the robot executes an
action chunk and receives a new observation, the observation
is appended to the buffer in temporal order, and memory
is sampled with the same temporal offsets as in training at
the next decision step. When valid history is insufficient at
the beginning of an episode, missing positions are masked
instead of being filled by copying the current frame. Since
causal attention masks already prevent the action branch from
accessing future visual information during training, future
video generation can be omitted during inference without
affecting action prediction.
IV. EXPERIMENTS
A. Experimental Setup
1) Model architecture: RM-WAM adopts a dual-branch
architecture for joint modeling of future visual and robot
actions. The video branch uses Wan2.2-TI2V-5B [38] as
the backbone for world prediction, while the action branch
employs a 30-layer Diffusion Transformer (DiT) [39] to
generate continuous action chunks. The two branches interact
through a Mixture-of-Transformers (MoT). In addition, a
one-layer temporal Transformer encodes recent visual latent
tokens to construct short-term visual memory, while another
one-layer Transformer encodes historical latent transitions
to form latent event memory. For the two memory types,
lightweight two-layer MLP gating modules are employed
to control memory injection, with their strengths learned
through counterfactual memory supervision.
2) Benchmarks:
We
evaluate
RM-WAM
on
two
simulated benchmarks, LIBERO [16] and RMBench [17].
LIBERO
evaluates
language-conditioned
manipulation
across
four
suites:
LIBERO-Spatial,
LIBERO-Object,
LIBERO-Goal, and LIBERO-Long, covering spatial, object-
centric, goal-conditioned, and long-horizon tasks. RMBench
focuses on memory-dependent manipulation under partial
observability, where reliable execution requires the model
to retain and utilize historical visual states and interaction
events over extended temporal horizons. Together, the two
benchmarks assess both the general manipulation capability
of RM-WAM and its effectiveness in long-horizon tasks.
3) Baselines: We compare RM-WAM with four represen-
tative methods. Diffusion Policy (DP)[40] is included as an
action-generation baseline without world modeling. π0.5 [3]
represents a strong vision-language-action policy for contin-
uous robot control. FastWAM [9] serves as a world–action
modeling baseline that jointly learns visual and robot actions.
HiMem-WAM [36] is the most closely related memory-
augmented world-action model and introduces hierarchical
memory gating for long-horizon manipulation. All methods
are evaluated using the same data and evaluation protocol.
4) Implementation Details: Short-term memory encodes
the four most recent frames, while event memory samples
visual latents every 16 timesteps to construct four transition-
level candidates. Counterfactual supervision is implemented
by modifying the historical sampling pools of short and
event memory while keeping their memory lengths fixed.
The reference, stale, stage, and cross-episode conditions are
assigned soft utility targets of 1.0, 0.01, 0.01, and 0.01,
respectively. These values are used as soft supervision priors
to distinguish causally aligned history from deliberately
perturbed memory conditions, and counterfactual memory
samples account for 50% of the training data.
Multi-view observations are concatenated into a single
image before being fed into the model. Robot actions are
represented in 7-DoF, with an action horizon of 32. Models


are trained for 10 epochs with a batch size of 16 and gradient
accumulation of 1, using AdamW with an initial learning
rate of 1 × 10−4 and a weight decay of 1 × 10−2. During
training, gradients from the action branch to the video branch
are stopped. At inference, RM-WAM maintains a causal his-
tory buffer that is updated with incoming observations, and
unavailable historical states at the beginning of an episode
are masked out. For action generation, we use classifier-free
guidance (CFG) [41] with a guidance scale of 1.0.
B. Simulation
1) Task: For both LIBERO and RMBench, each task
uses 50 expert demonstrations for training, and all models
are trained for 10 epochs under the same configuration. On
LIBERO, we evaluate all 40 tasks across the four suites,
performing 50 evaluation rollouts per task with different
environment initialization seeds, and report the average suc-
cess rate. On RMBench, we evaluate the nine bimanual
manipulation tasks with 100 evaluation rollouts per task
under different environment initialization seeds and also
report the average success rate.

history according to the current task state.

E. Ablation Studies
We conduct an ablation study on LIBERO to analyze the
short-term memory and latent event memory across tasks.
As shown in Table IV, w/o short-mem. and w/o event-
mem. denote removing the short-term memory and latent
event memory, respectively. Removing short-term memory
decreases the success rate on LIBERO-Spatial from 98.8%
to 97.8%, indicating that recent visual history is impor-
tant for preserving local spatial information. On LIBERO-
Goal and LIBERO-Long, removing event memory leads to
larger performance drops, with success rates decreasing to
96.8% and 95.0%, respectively. This is consistent with the
stronger dependence of these tasks on task progress and
longer-range state transitions, for which latent event memory
provides more persistent historical context. Overall, RM-
WAM achieves the highest average success rate, validating
the complementary roles of the two memory components.

V. CONCLUSION
In this paper, we propose RM-WAM, a reliable memory-
augmented World Action Model for long-horizon robot
manipulation. Different from existing memory augmenta-
tion methods that treat historical information as universally
useful context, RM-WAM considers memory as a context-
dependent predictive resource and models history through
complementary short-term visual memory and latent event
memory to capture local interactions and long-term state
transitions. Furthermore, counterfactual memory learning is
introduced to learn a context-dependent utility estimate for
historical information under the current task state, enabling
adaptive memory utilization for world prediction and action
generation. Experiments demonstrate that RM-WAM effec-
tively exploits reliable historical information and improves
long-horizon task performance through more accurate world
evolution modeling and closed-loop decision making.
