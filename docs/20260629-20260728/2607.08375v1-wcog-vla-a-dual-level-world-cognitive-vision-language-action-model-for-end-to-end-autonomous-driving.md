## 摘要
视觉-语言-动作（VLA）模型推动了端到端自动驾驶的发展。然而，现有方法要么缺乏全面的世界认知，要么存在零散的世界预知能力，本质上将模型限制在反应式驾驶中。为解决这一局限，我们提出WCog-VLA，一种新颖的双层世界认知VLA框架，成功地将语义世界预测与生成世界演变相结合，以实现主动式自动驾驶。在语义层面，WCog-VLA通过整合3D空间感知和注入智能体标记来捕捉世界动态，同时实现博弈论思维链（Game-CoT）推理，统一了世界认知与推理。在生成层面，我们引入对齐解耦扩散变换器（ADDT）作为强大的生成世界模型，合成物理上合理的多智能体联合轨迹。通过场景表示对齐，ADDT减少了所需的去噪步数，从而显著加速推理。为促进策略推理，我们进一步构建了一个包含8.5万条Game-CoT注释的大规模数据集。在NAVSIM基准上的大量实验表明，WCog-VLA达到了92.9的PDMS得分，创下最新最优（SOTA）水平。

## Abstract
Vision-Language-Action (VLA) models have advanced end-to-end autonomous driving. However, existing methods either lack comprehensive world cognition or suffer from fragmented world foresight, inherently confining these models to reactive driving. To address this limitation, we propose WCog-VLA, a novel dual-level World-Cognitive VLA framework that successfully bridges semantic world forecasting with generative world evolution to achieve proactive autonomous driving. At the semantic level, WCog-VLA unifies world cognition and reasoning by incorporating 3D spatial perception and injecting agent tokens to capture the world dynamics, while concurrently enabling Game-theoretic Chain-of-Thought (Game-CoT) reasoning. At the generative level, we introduce the Aligned Decoupled Diffusion Transformer (ADDT) as a powerful generative world model that synthesizes physically-plausible joint multi-agent trajectories. Through scene representation alignment, ADDT reduces the number of denoising steps required and thus significantly accelerates inference. To facilitate strategic reasoning, we further construct a large-scale dataset featuring 85k Game-CoT annotations. Extensive experiments on the NAVSIM benchmark demonstrate that WCog-VLA achieves a State-Of-The-Art (SOTA) PDMS score of 92.9.

- **核心问题**：现有端到端自动驾驶的视觉-语言-动作（VLA）模型存在两大缺陷：
  - **缺乏全面世界认知**：大多数方法仅依赖2D图像特征，缺少3D空间感知，无法理解周围环境的动态变化。
  - **世界预见碎片化**：即使部分工作引入世界建模（如未来图像生成），但仅作为辅助语义任务，忽略了自车与周围智能体之间的交互博弈，导致模型只能进行**反应式驾驶**（reactive driving），而非主动/前瞻性驾驶（proactive driving）。
- **整体含义**：为了实现智能、安全的自动驾驶，模型必须同时具备**语义级世界预测**（理解当前状态、推理未来意图）和**生成级世界演化**（合成多智能体联合轨迹），从而实现从被动观察到主动博弈的转变。

## 2. 论文提出的方法论：核心思想、关键技术细节
### 核心思想
- **双层级世界认知框架（WCog-VLA）**：
  - **语义层**（Semantic Level）：通过3D空间感知、注入智能体标记（agent tokens）以及博弈论思维链推理（Game-CoT），实现对世界状态的理解和未来动态的预测。
  - **生成层**（Generative Level）：引入 **对齐解耦扩散变换器（ADDT）** 作为生成世界模型，合成物理合理的多智能体联合轨迹，将语义认知转化为具体动作。

### 关键技术细节
- **VLM骨干网络结构**：
  - 采用 **InternVL3-2B** 作为基础模型（InternViT 300M 视觉编码器 + Qwen2.5 LLM）。
  - 输入：多视图环视图像、导航指令、自车状态（速度、加速度、2秒历史轨迹）。
  - **3D空间感知**：使用 BEVFormer 提取 BEV 特征，再通过 TrackFormer（可学习的 agent queries）提取稀疏的 **agent tokens**（含空间位置和几何特征），注入 LLM 进行多模态交互。
  - **统一世界认知与推理**：LLM 输出三种 token（视觉、文本、agent），其中 agent tokens 通过一个 **world head** 解码为当前3D感知和未来轨迹预测；视觉与文本 token 用于生成文本响应（包含 Game-CoT 推理过程）。

- **博弈论思维链推理（Game-CoT）**：
  - 构建 85k 条 Game-CoT 数据集，通过 Qwen3-VL-Plus 自动生成四步推理：
    1. 场景描述
    2. 关键目标分析
    3. **博弈论推理**（“如果-那么”想象）：将交通交互建模为 Stackelberg 博弈（自车为领导者，其他车为跟随者），枚举候选自车动作并推断跟随者的反应。
    4. **收益评估**：根据安全性和效率选择最优策略。
  - 使用真实动作作为指导线索，减少幻觉输出。

- **ADDT（对齐解耦扩散变换器）**：
  - **解耦架构**：分为**条件编码器**（提取结构语义）和**生成解码器**（恢复高频几何细节），避免单网络编码语义与解码细节的冲突。
  - **条件编码器**：接收联合噪声、历史动作、平均池化的 VLM 输出，经过8个 DiT 块，通过 AdaLN 注入时间步和自车状态，并通过交叉注意力注入完整 VLM 输出，输出语义自条件特征 z_t。
  - **表示对齐**：将编码器中第6个 DiT 块的中间特征与预训练 VAE 的隐空间场景表示进行余弦相似度对齐（公式3），减少去噪步骤间的语义漂移，提高生成一致性和加速推理。
  - **生成解码器**：同样 8 个 DiT 块，通过 AdaLN 注入时间步和 z_t，估计去噪后的多智能体轨迹（公式4）。
  - **训练目标**：L2 去噪损失（公式8） + 表示对齐损失（公式3），对自车和周围车使用不同权重。

- **四阶段训练**：
  1. **Stage 1（3D感知预训练）**：训练 BEV 编码器和 TrackFormer（分类焦点损失 + 3D box L1 损失）。
  2. **Stage 2（VLM SFT）**：联合训练 VLM 与 world head，使用混合 VQA 数据（公开驱动 VQA + 轨迹特定 VQA + Game-CoT），损失为语言建模交叉熵 + 世界认知损失（当前感知和未来预测的 L1 损失）。
  3. **Stage 3（ADDT SFT）**：冻结 VLM，训练 ADDT，使用去噪损失 + 对齐损失。
  4. **Stage 4（强化微调，RFT）**：使用 DiffGRPO（扩散 GRPO）优化驾驶策略，奖励函数包括 NAVSIM 的 PDMS 和周围车辆轨迹 L1 惩罚。
