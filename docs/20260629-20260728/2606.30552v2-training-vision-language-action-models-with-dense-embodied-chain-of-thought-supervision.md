## 摘要
跨实体迁移在视觉-语言-动作（VLA）模型中仍然具有挑战性，因为不同机器人平台的底层状态和动作空间存在根本差异。我们观察到，操作背后的高层认知过程，包括场景感知、物体识别、任务规划和子任务分解，在实体间很大程度上是共享的。基于这一观察，我们提出了ZR-0，一个拥有26亿参数的端到端VLA模型，它使用密集的具身思维链（ECoT）监督来对齐视觉-语言模型（VLM）中的跨实体表征。ZR-0采用双流架构：一个预训练的VLM（系统2）在训练期间生成结构化的ECoT推理，而一个基于扩散Transformer的动作专家（系统1）通过流匹配生成连续的动作块。这两个组件通过交叉注意力耦合，并使用一个注意力掩码将动作专家限制为仅输入提示特征，从而在推理时可以完全跳过ECoT生成而不损失任何性能。ZR-0在ProcCorpus-60M上进行了预训练，这是一个包含超过40万条轨迹、约6000万帧（约1000小时）的大规模数据集，密集的ECoT注释覆盖了96.8%的帧。我们在三个模拟基准上评估了ZR-0，涵盖单臂（LIBERO）、双臂（RoboTwin 2.0）和人形（RoboCasa GR-1 Tabletop）实体，以及在xArm平台上的真实世界实验，展示了在所有设置中的强大性能。代码和模型检查点可在https://github.com/RUCKBReasoning/ZR-0获取。

## Abstract
Cross-embodiment transfer in vision-language-action (VLA) models remains challenging because low-level state and action spaces differ fundamentally across robot platforms. We observe that the high-level cognitive process underlying manipulation, including scene perception, object identification, task planning, and sub-task decomposition, is largely shared across embodiments. Based on this observation, we present ZR-0, a 2.6 billion parameter end-to-end VLA model that uses dense Embodied Chain-of-Thought (ECoT) supervision to align cross-embodiment representations within the vision-language model (VLM). ZR-0 adopts a dual-stream architecture: a pre-trained VLM (System 2) generates structured ECoT reasoning during training, while a Diffusion Transformer-based action expert (System 1) produces continuous action chunks via flow matching. The two components are coupled through cross-attention, with an attention mask that restricts the action expert to input prompt features only, enabling ECoT generation to be entirely skipped at inference without any performance loss. ZR-0 is pre-trained on ProcCorpus-60M, a large-scale dataset comprising approximately 60 million frames (approximately 1,000 hours) from over 400K trajectories, with dense ECoT annotations covering 96.8% of all frames. We evaluate ZR-0 on three simulation benchmarks spanning single-arm (LIBERO), bimanual (RoboTwin 2.0), and humanoid (RoboCasa GR-1 Tabletop) embodiments, as well as real-world experiments on the xArm platform, demonstrating strong performance across all settings. Code and model checkpoints are available at https://github.com/RUCKBReasoning/ZR-0.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：跨本体迁移（cross-embodiment transfer）在视觉-语言-动作（VLA）模型中仍是一个挑战。不同机器人平台的低层状态和动作空间（如自由度、控制接口、传感器配置）存在根本性差异，导致现有方法仅通过零填充、归一化等格式级技术难以实现真正的语义对齐。
- **关键观察**：尽管低层空间不同，但操作背后**高层认知过程**（场景感知、物体识别、任务规划、子任务分解）在机器人和人类之间是高度共享的。
- **整体含义**：利用这种共享的高层推理作为监督信号（即密集的具身思维链 ECoT），可以对齐跨本体的 VLM 表征，从而实现更有效的迁移。作者提出 ZR-0 模型验证这一思路。

### 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：
    - 采用 **System 1 / System 2** 双流架构。System 2（预训练 VLM）生成结构化的 ECoT 推理（场景描述、进度评估、未来规划、原子子任务、目标框、离散动作），System 1（扩散 Transformer 动作专家）通过流匹配生成连续动作块。
    - 关键设计：**交叉注意力掩码**限制动作专家仅关注 VLM 输入提示（指令和图像）的特征，**而非 ECoT 令牌**，从而确保推理时可完全跳过 ECoT 生成，不损失性能且无额外延迟。
- **关键技术细节**：
    - **VLM（System 2）**：基于 Qwen3-VL-2B-Instruct 初始化，训练时通过 next-token prediction 损失生成 ECoT 序列。
    - **扩散 Transformer 动作专家（System 1）**：包含状态编码器、动作编码器、堆叠的 DiT 块和动作解码器。DiT 块中 self-attention 与 cross-attention 比例为 1:3（相比 GR00T N1 的 1:1 更多跨模态交互）。
    - **训练目标**：联合优化 next-token prediction 损失（L_ntp）和流匹配损失（L_fm）。L_ntp 仅更新 VLM，L_fm 更新动作专家和 VLM（通过 ft）。
    - **推理流程**：从高斯噪声初始化动作块，通过 N 步前向欧拉积分去噪。ECoT 生成完全省略。
    - **预训练数据**：ProcCorpus-60M（约 6000 万帧，1000 小时，来自 Open X-Embodiment、DROID、RH20T 等，96.8% 帧带 ECoT 注释）。
    - **动作与状态对齐**：将不同本体的状态和动作都填充到 64 维，并对填充维度进行损失掩码；每个维度基于训练数据 1st/99th 百分位数进行 min-max 归一化。

### 7. 优点：方法或实验设计上的亮点

- **新颖的 ECoT 监督方案**：将高层认知推理（场景描述、进度、规划、子任务、目标框）密集应用于每一帧，显式对齐跨本体语义。
- **推理零开销设计**：通过交叉注意力掩码隔离 ECoT 令牌，推理时仅需一次 VLM 前向，不生成文本，延迟仅 90ms，适合实时部署。
- **双流架构灵活**：VLM 负责语义理解，扩散专家负责连续控制，可独立升级，且允许后训练中去除 ECoT 和 VL 数据，只使用机器人数据微调。
- **实验多样性**：覆盖单臂、双臂、人形和真实平台，且所有下游微调源自同一预训练权重，强验证跨本体迁移能力。
- **开源**：代码和模型检查点公开，可复现。

### 8. 不足与局限

- **实验覆盖完整性不足**：消融实验仅一项，未系统性分析 ECoT 各组件（如目标框、子任务分解）的贡献，也未探索数据规模缩放效应（如使用更少帧或不同本体组成）。
- **预训练数据量有限**：约 1000 小时，远低于 π0（>10k 小时）、LingBot-VLA（~20k 小时）。导致对低频技能（如关门、关微波炉）迁移效果较弱（RoboCasa 上 Close 类任务低于部分基线）。
- **精密操作局限性**：真实世界 Hang Cups 任务性能显著低于 π0.5，表明 ECoT 对纯动作精度帮助有限，可能仍需更大规模动作数据或更好动作表示。

- **未在真正“异质”本体上测试**：所有实验机器人都属于不同平台但均为仿真或 xArm（类似单臂），未测试如四足、轮式等非操纵本体。
