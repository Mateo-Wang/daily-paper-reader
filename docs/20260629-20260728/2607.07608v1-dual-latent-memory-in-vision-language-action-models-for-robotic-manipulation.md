## 摘要
主流的视觉-语言-动作（VLA）模型主要在马尔可夫假设下从当前观测预测动作，因此在长时程、时间依赖的任务中表现不佳。现有的记忆增强VLA要么扩展观测窗口，要么从记忆库中检索历史作为辅助策略上下文。然而，它们将记忆置于VLA推理的固有潜在嵌入空间之外，阻碍了历史经验与多模态推理和动作形成的流畅交织。为此，我们提出LaMem-VLA，一种潜在记忆内生框架，将历史经验重构为潜在记忆令牌，并直接与VLA推理交织。其核心是LaMem-VLA引入了四个协调组件：（i）一个整理器，将历史经验组织成两个互补的短期和长期记忆库；（ii）一个搜索器，利用多模态认知查询两个库以检索上下文相关证据；（iii）一个压缩器，将检索到的证据重构为紧凑的短期和长期潜在记忆令牌；（iv）一个编织器，将这些记忆令牌与当前观测和指令注入到连续的嵌入序列中。通过完全在相同连续潜在空间中表示、检索和消费历史经验，LaMem-VLA使记忆直接参与VLA推理并在有限上下文中指导动作生成。在SimplerEnv和LIBERO上的大量实验证明了我们的LaMem-VLA的优越性。

## Abstract
Mainstream Vision-Language-Action (VLA) models predict actions primarily from the current observation under a Markovian assumption, thus struggling with long-horizon, temporally dependent tasks. Existing memory-augmented VLAs either expand the observation window or retrieve history from the memory bank as auxiliary policy-side context. However, they leave memory outside the native latent embedding space of VLA reasoning, preventing historical experience from being fluidly interleaved with multimodal reasoning and action formation. To this end, we introduce LaMem-VLA, a latent-memory-native framework that reconstructs historical experience into latent memory tokens and directly interweaves them with VLA reasoning. At its core, LaMem-VLA introduces four coordinated components: (i) a curator that organizes historical experience into two complementary short-term and long-term memory vaults; (ii) a seeker that queries both vaults using the multimodal cognition to retrieve context-relevant evidence; (iii) a condenser that reconstructs the retrieved evidence into compact short-term and long-term latent memory tokens; and (iv) a weaver that injects these memory tokens with the current observation and instruction into one continuous embedding sequence. By representing, retrieving, and consuming historical experience entirely in the same continuous latent space, LaMem-VLA enables memory to directly participate in VLA reasoning and guide action generation under a bounded context. Extensive experiments on SimplerEnv and LIBERO demonstrate the superiority of our LaMem-VLA.

### 2. 论文提出的方法论：核心思想、关键技术细节

#### 核心思想
LaMem-VLA提出一种**潜在记忆原生框架**，将历史经验组织为互补的短期（视觉主导）和长期（语义主导）记忆库，通过四个协调组件将检索到的证据重构为紧凑的潜在记忆令牌，并与当前观测、指令和动作查询令牌拼接成统一嵌入序列，使记忆在VLA推理中直接参与动作生成。

#### 关键技术细节（组件与流程）
1. **Latent Memory Curator（潜在记忆整理器）**  
   - 维护两个互补记忆库：  
     - **短期记忆库** `M_short`：存储当前episode的视觉证据（由视觉令牌经SE-bottleneck压缩模块处理后得到），每个单元为键值对（键为均值池化摘要，值为压缩后的视觉令牌）。  
     - **长期记忆库** `M_long`：存储动作隐藏状态（'H_action'），用于跟踪任务进度和动作连续性。  
   - 当单元数超过容量`L`（默认16）时，计算相邻单元余弦相似度，合并最冗余的一对（平均键和值），从而压缩冗余。

2. **Latent Memory Seeker（潜在记忆搜索器）**  
   - 从当前多模态认知（视觉令牌`Xt`和指令令牌`I`）构建上下文感知查询`Qcon_t`。  
   - 通过轻量Transformer查询构建器`B`生成查询令牌`Qt`。  
   - 使用均值池化后的全局查询`qt`，分别从两个记忆库中检索Top-K个相关单元（基于余弦相似度），得到原始检索证据`Z_short`和`Z_long`。

3. **Latent Memory Condenser（潜在记忆压缩器）**  
   - 引入可学习的短期记忆槽`Ts`和长期记忆槽`Tl`。  
   - 通过轻量Transformer记忆形成器（`Fv`、`Fc`），以查询令牌`Qt`和检索证据为条件，将检索证据压缩为**固定长度**的潜在记忆令牌：  
     - `M_short = Fv([Qt; Z_short; Ts])[-Ls:]`，`Ls=8`  
     - `M_long = Fc([Qt; Z_long; Tl])[-Ll:]`，`Ll=4`  
   - 压缩后令牌维度与VLA嵌入空间一致，且长度固定，不影响上下文长度。

4. **Latent Memory Weaver（潜在记忆编织器）**  
   - 将压缩后的短期、长期记忆令牌与当前视觉令牌`Xt`、指令令牌`I`、动作查询令牌`Q_action`拼接为记忆增强输入序列：  
     `St = [M_short + bs; M_long + bl; Xt; I; Q_action]`  
   - 通过VLA骨干网络（Prismatic VLM + LLaMA-7B）处理，输出记忆锚定的动作令牌`Z_action`。

5. **动作生成**  
   - 利用扩散动作专家（Diffusion Policy）基于`Z_action`进行条件去噪，生成连续7-DoF动作块（chunk size=16）。  
   - 训练损失为噪声预测MSE，推理使用DDIM采样（10步）。

#### 关键公式（文字说明）
- 记忆库写入压缩策略：相邻单元余弦相似度最大者合并。  
- 检索：`I_s = Top-K(cos(qt, ki_s))`  
- 压缩：通过可学习槽和注意机制将检索证据映射为固定长度令牌。  
- 最终序列：`St = [M_short; M_long; Xt; I; Q_action]`，送入VLM得到`Z_action`。
