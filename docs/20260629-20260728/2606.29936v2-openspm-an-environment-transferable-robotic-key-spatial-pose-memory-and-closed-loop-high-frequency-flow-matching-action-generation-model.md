## 摘要
开放环境下的桌面机器人操作需要系统具备语义理解、精确几何位姿估计和高频动作生成能力。端到端视觉-语言-动作（VLA）模型在语义泛化方面表现出色，但往往缺乏细粒度任务所需的显式几何约束，并且需要高昂的训练成本。为了弥合高层语义与底层物理执行之间的鸿沟，我们提出OpenSPM，一种开放环境空间持久记忆框架，由空间位姿记忆和流匹配动作生成模型组成。OpenSPM首先利用语义条件3D感知和卡尔曼滤波来跟踪连续的6D位姿。然后从人类示范中提取关键空间位姿，将其保存为可迁移的、以物体为中心的空间持久记忆条目。在推理时，OpenSPM根据自然语言指令检索相关记忆条目，使用SE(3)变换将空间位姿迁移到新场景，并通过轻量级条件流匹配模型生成高频动作块。结合实时本体感受状态反馈和末端残差校正，系统有效抑制了轨迹误差累积。在十个LIBERO-GOAL任务上的评估显示，OpenSPM达到85.6%的成功率和1033.3 Hz的等效控制频率，同时仅需最小推理AI算力。大量消融实验表明，结构化的空间持久记忆和闭环残差校正在可靠的高频机器人操作中起着关键作用。

## Abstract
Open-environment tabletop robotic manipulation requires systems to possess semantic understanding, precise geometric pose estimation, and high-frequency action generation. While end-to-end vision-language-action (VLA) models excel at semantic generalization, they often lack explicit geometric constraints for fine-grained tasks and require costly training. To bridge the gap between high-level semantics and low-level physical execution, we propose OpenSPM, an open environment spatial persistent memory framework consisting of spatial pose memory and flow-matching action generation model. OpenSPM first leverages semantically conditioned 3D perception and Kalman filtering to track continuous 6D poses. It then extracts key spatial poses from human demonstrations, keeping them as transferable, object-centric spatial persistent memory entries. During inference, OpenSPM retrieves relevant memory entries in terms of natural language instructions, transfers the spatial poses to new scenes using SE(3) transformations, and generates high-frequency action chunks via a lightweight conditional flow-matching model. Combined with real-time proprioceptive state feedback and terminal residual correction, the system effectively suppresses trajectory error accumulation. Evaluated on ten LIBERO-GOAL tasks, OpenSPM achieves an 85.6% success rate and an equivalent control frequency of 1033.3 Hz, while requiring minimal inference AI computing power. Extensive ablations illustrate that structured spatial persistent memory and closed-loop residual correction play a crucial role in reliable, high-frequency robotic manipulation.

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架
- OpenSPM由两阶段构成：
  - **离线阶段**：从人类演示中提取阶段级关键空间位姿，存储为以物体坐标系为参照的SE(3)相对位姿。
  - **在线阶段**：根据语言指令检索记忆条目，利用当前场景估计的物体位姿通过SE(3)变换迁移关键位姿，再使用轻量条件流匹配模型生成相邻关键位姿之间的短程动作块，并结合实时状态反馈与终端残差校正抑制误差累积。

### 2.2 语义条件3D感知与卡尔曼状态估计
- 采用多视图图像+文本提示，经语义分割（如SAM等）得到目标掩码，结合已知相机内外参提升至3D点云约束。
- 对单目主观视角，使用SAM 3D等获取物体局部形状与主方向。
- 将位姿估计视为噪声状态空间问题，应用**卡尔曼滤波**连续预测与更新物体6D位姿（状态包括平移、线速度、局部方向误差、角速度），并引入轻量平滑（指数移动平均）。该模块仅在演示构建和在线初始化时调用高频3D重建，执行期间仅依赖低维滤波。

### 2.3 关键空间位姿记忆库
- **关键位姿选取**：综合三种证据——夹爪状态切换、末端速度/方向变化、以及多模态模型（如Qwen3-VL）的阶段性语义判断。
- **记忆条目格式**：包含检索键、语言描述、一系列关键位姿（末端相对于锚定物体的SE(3)相对位姿）、阶段标签、置信度、质量评分等。
- **可迁移性保证**：存储的相对位姿定义为 $\Delta T_{o\rightarrow e}^j = ({}^w T_o)^{-1} \cdot {}^w T_{e,j}$，在线迁移时将演示场景的目标物体位姿 $^w T_o$ 替换为新场景估计值 $^w T_o'$，按 $^w T_{e,j}' = {}^w T_o' \cdot \Delta T_{o\rightarrow e}^j$ 获得新末端位姿。**定理1**证明：若新物体位姿是演示位姿的任意SE(3)变换，则迁移后末端相对位姿保持不变。
- **在线检索**：结合语义匹配、几何一致性与历史成功率进行加权选择。

### 2.4 条件流匹配动作生成
- 使用条件流匹配模型生成相邻关键位姿间的动作块（块长H=5）。条件包括当前实际末端位姿、目标关键位姿、相对误差及段内进度。
- 训练采用线性插值路径和均方误差损失；推理时从高斯噪声通过ODE积分得到动作块。
- 模型仅约240K参数（轻量MLP），可高频调用。

### 2.5 闭环执行与终端残差校正
- **段间闭环**：每个动作块开始时用实时本体感受位姿构建条件，而非理想起点，防止开环累积误差。
- **终端残差校正**：在关键接触节点（抓取/放置点）附近，若当前位置与目标位姿残差超过阈值，则重新生成校正动作块，直至误差收敛或达最大迭代次数。

### 2.6 复杂度与误差传播分析
- 在线复杂度主要由感知初始化（一次性）、记忆检索（线性扫描或向量索引）、关键位姿迁移（O(K)矩阵乘法）、动作生成（O(N_ode H P_θ)，P_θ≈240K）构成，执行瓶颈不在模型而在环境步进。
- 误差传播模型显示：开环拼接时误差递归放大；闭环实时状态反馈与终端残差校正可将误差压缩为观测纠正形式，显著提升稳定性。
