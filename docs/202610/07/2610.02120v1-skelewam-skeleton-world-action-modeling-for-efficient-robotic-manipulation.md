## 摘要
世界动作模型（WAMs）将机器人动作生成与未来状态预测相结合。现有 WAM 通常预测视频或学习到的视觉隐变量，这些表示仅隐式地刻画交互几何，且可能保留与控制无关的外观信息。我们提出 SkeleWAM，一种紧凑的 WAM，将操作场景表示为由机器人关节、物体中心和交互点构成的稀疏三维骨架。该骨架由当前 RGB-D 观测和机器人本体感知在线构建，为动作生成与未来骨架预测提供统一的几何状态。未来骨架预测为动作学习提供额外的几何监督，而无需视觉重建。在推理阶段，SkeleWAM 直接根据当前骨架与语言指令生成动作，而 Medoid Action Consensus（MAC）作为面向随机动作采样的辅助共识策略。在 LIBERO-Plus 上，SkeleWAM 以 57.1M 参数取得 85.9% 的总体成功率，较 Cosmos-Policy 高出 3.7 个百分点。这些结果表明，稀疏的三维机器人—物体结构为稳健且参数高效的世界动作学习提供了有效的状态空间。项目主页：https://skelewam-project.github.io/。

## Abstract
World action models (WAMs) combine robot action generation with future state prediction. Existing WAMs typically predict videos or learned visual latents, which represent interaction geometry only implicitly and may retain appearance information unrelated to control. We introduce SkeleWAM, a compact WAM that represents a manipulation scene as a sparse 3D skeleton composed of robot joints, object centers, and interaction points. Constructed online from current RGB-D observations and robot proprioception, the skeleton provides a unified geometric state for action generation and future skeleton prediction. Future skeleton prediction provides additional geometric supervision for action learning without requiring visual reconstruction. At inference, SkeleWAM generates actions directly from the current skeleton and language instruction, while Medoid Action Consensus (MAC) serves as an auxiliary consensus strategy for stochastic action samples. On LIBERO-Plus, SkeleWAM achieves an overall success rate of 85.9% with 57.1M parameters, outperforming Cosmos-Policy by 3.7 percentage points. These results demonstrate that sparse 3D robot--object structure provides an effective state space for robust and parameter-efficient world action learning. The project is available at https://skelewam-project.github.io/.

## 1. 核心问题与整体含义

- **研究背景**：机器人操作学习已从任务专用视觉运动策略（ACT、Diffusion Policy、DP3）发展到通用机器人基础模型与 VLA 模型（RT-2、Octo、OpenVLA、π0、π0.5）。**世界动作模型（WAM）** 进一步将动作生成与未来状态预测联合建模，用未来状态预测为动作学习提供额外监督。
- **核心问题**：现有 WAM 通常以**视频**或**学习到的视觉隐变量**表示未来状态。这类表示存在两个缺陷：
  - 仅**隐式**刻画机器人—物体交互几何，压缩视觉观测本身并不能隔离支配交互的几何变量（空间构型、相对运动）；
  - 视觉隐变量保留的信息很大程度上由视觉编码器及其预训练目标决定，可能残留与控制无关的外观信息。
- **核心追问**：能否用机器人—物体结构的**稀疏表示**支撑有效的世界动作学习，同时大幅降低模型复杂度？
- **整体含义**：作者主张，操作场景中与控制最相关的部分可归结为机器人关节 + 物体中心 + 交互点构成的稀疏 3D 骨架。论文把这一观察落实为紧凑的世界动作模型，验证"稀疏显式几何状态空间"在稳健性与参数效率上的价值。

## 2. 方法论

### 2.1 核心思想
- 用**统一稀疏 3D 骨架**同时充当"当前状态表示"与"未来状态预测目标"，不重建视觉外观，也不需要推理时的未来预测。

### 2.2 问题形式化
- 输入：语言指令 ℓ、当前 RGB-D 观测 o_t、机器人本体状态 q_t；输出动作块 A_t ∈ R^{Ha×da}。
- 骨架提取：S_t = Φ_ψ(o_t, q_t, ℓ) ∈ R^{N×3}。
- 训练时额外定义未来骨架序列 S⁺_t = [S_{t+δ1}, …, S_{t+δHs}]，联合学习动作分布 p_aθ(A_t | S_t, ℓ) 与未来骨架分布 p_sθ(S⁺_t | S_t, ℓ)。

### 2.3 骨架世界表示
- 物体 m 的节点：P_{t,m} = [c_{t,m}; u_{t,m,1}; …; u_{t,m,Lm}]，即**物体中心 + L_m 个交互点**。
- 完整骨架：S_t = [J_t; P_{t,1}; …; P_{t,M}]，节点数 N = N_r + Σ_m(1 + L_m)。
- 机器人节点沿**运动学连通性**连接，物体中心连接其交互点；节点身份、顺序、连通性在时间上保持一致。
- 机器人关键点由**前向运动学**计算；物体关键点由**冻结的预训练感知网络**从 RGB-D 估计；所有坐标统一到以机器人为中心的坐标系并按训练集统计归一化。

### 2.4 模型结构
- 语言编码为 C_ℓ；三类输入适配器分别把当前骨架、加噪动作块、加噪未来骨架映射为 token：X^c_t = φ_c(S_t)，X^a_{t,τa} = φ_a(Ã_{t,τa})，X^s_{t,τs} = φ_s(S̃⁺_{t,τs})；**当前骨架不加噪**。
- 采用 Fast-WAM 式的**双专家 Mixture-of-Transformers**：世界专家（处理当前与未来骨架 token，参数共享）+ 动作专家（处理动作 token），均以 C_ℓ 为条件。
- **块注意力掩码**（行=query 组，列=key/value 组，顺序为当前骨架 / 动作 / 未来骨架）：
  - 当前骨架 token 仅在自身组内注意；
  - 每个预测组注意当前骨架与自身；
  - **动作与未来骨架 token 之间无注意力**。
- 输出头在一次前向中同时预测动作向量场 v̂^a_θ 与未来骨架向量场 v̂^s_θ。

### 2.5 训练目标（Flow Matching）
- 独立采样高斯噪声 ϵ_a、ϵ_s 与噪声时刻 (τ_a, τ_s) ~ ρ；
  - 插值路径：Ã_{t,τa} = (1−τ_a)A_t + τ_a ϵ_a，S̃⁺_{t,τs} = (1−τ_s)S⁺_t + τ_s ϵ_s（τ=0 为数据，τ=1 为噪声）；
  - 目标向量场：v_a = ϵ_a − A_t，v_s = ϵ_s − S⁺_t。
- 联合损失：L = L_action + λ_s · L_skeleton，其中 L_action = E[MSE(v̂^a_θ, v_a)]，L_skeleton = E[MSE(v̂^s_θ, v_s)]。
- 两个损失**都更新世界专家**：骨架损失监督未来几何预测，动作损失经当前骨架上下文反向传播。

### 2.6 推理与 Medoid Action Consensus（MAC）
- 推理时**保留当前骨架处理与动作专家，丢弃未来骨架 token**；从 Ã_{t,1} ~ N(0, I) 出发沿 dÃ/dτ = v̂^a_θ(Ã, τ; S_t, ℓ) 由 τ: 1→0 积分 10 步得到动作块。
- MAC：从 K ≥ 2 个独立噪声初始化采样候选，在归一化动作空间中比较前 h ≤ H_a 步、d_m 个连续运动维度上的成对距离 d_ij；计算每个候选到其他候选的平均不相似度 c_i，取 c_i 最小者作为最终输出（**medoid**）。
- 选中的动作块**完整保留**（包括未参与距离计算的维度）；MAC 无需奖励模型或价值模型，也不对轨迹做平均（避免平均不兼容轨迹）。
- 执行前 H_e ≤ H_a 个动作，用最新观测更新骨架后重复；H_e 控制重规划频率，h 仅用于候选选择。

## 6. 主要结论与发现

- **参数效率与性能**：SkeleWAM 以 ≈57.1M 参数在 LIBERO-Plus 上取得 **85.9% 总体成功率**，比最强的观测型基线 Cosmos-Policy（82.2%，≈2B）高 **3.7 个百分点**，参数少约两个数量级。
- **扰动鲁棒性**：Camera 扰动下 **93.4%**（超 Cosmos-Policy 17.6 点）；Language 89.1%、Background 96.0%、Noise 93.9% 均为观测型方法中最佳。
- **感知估计的影响有限**：sim-state 变体 87.7%，仅比 RGB-D 高 1.8 点，说明冻结感知网络提供的骨架估计已相当有效，同时留有小幅提升空间。
- **未来骨架监督有效**：去掉未来骨架损失后从 85.9% 降至 80.1%（−5.8 点），且两者推理流程相同，证明增益来自训练期几何监督。
- **骨架组成互补**：中心+交互点（85.9%）优于仅中心（82.3%）和仅交互点（77.7%）。
- **跨分支注意力并非必要**：无跨分支注意力即达最佳（85.9%），说明主要收益来自共享世界专家的**协同训练**，而非分支间直接信息交换；这也让推理时可移除未来分支。
- **MAC 有适度收益**：K=3（85.9%）优于 K=1（84.2%），但 K=5/10 反而下降，性能不随采样预算单调增长。
- **真实世界**：平均成功率 **89%**，超过 Cosmos-Policy（87%）、Fast-WAM（83%）、π0.5（76%），在 5 个任务中的 4 个取得最高或并列最高。
- **明确的短板**：Layout 扰动仅 66.6%（π0.5 为 84.1%），即便用 sim-state 也只有 69.0%，说明稀疏几何本身无法完全解决大幅空间布局变化的泛化问题，该困难超出视觉定位范畴。

## 7. 优点

- **表示设计清晰且有原则**：把"控制相关的几何"显式参数化为机器人关节 + 物体中心 + 交互点，避免了视频/视觉隐变量中与控制无关的外观冗余，从源头降低了对视觉重建的依赖。
- **训练/推理解耦**：未来骨架预测仅作训练期辅助监督，推理时移除该分支，不增加测试时成本；同时该设计天然支持"未来预测是否有用"的可控消融。
- **参数效率突出**：57.1M 参数即可对标甚至超越 2B–7.7B 的 VLA/世界模型方法，工程与部署意义明显。
- **MAC 设计轻量且无需奖励模型**：只做候选选择、不做轨迹平均，避免平均不兼容轨迹的常见问题；距离只在前 h 步运动维度上计算，成本可控。
- **实验诊断性强**：引入 sim-state 特权输入作为"上界参照"，把感知误差与策略泛化误差部分解耦；跨分支注意力消融的结论（协同训练优于直接信息交换）具有方法学启示。
- **仿真 + 真实双重验证**，并配定性可视化（骨架随时间演化）与推理效率/计算成本的定性对比。

## 8. 不足与局限

- **空间布局泛化弱**：Layout 仅 66.6%，显著落后 π0.5（84.1%），且 sim-state 也只到 69.0%，说明问题不在感知而在策略对新空间构型的泛化；这是论文自身承认的主要局限。
- **骨架构建依赖固定感知与手工设计**：物体中心与交互点由冻结的预训练感知网络估计，交互点数量/位置为预设，缺乏对不确定性的建模；感知网络误差会直接传导至状态表示，论文未量化其敏感度。
- **机器人形态与场景覆盖有限**：真实实验仅一台 ARX R5、桌面场景、5 个任务、每任务 20 次试验，缺乏双臂、移动操作、可变形物体等场景；统计样本量偏小。
- **基线比较口径不完全对等**：参数量相差 1–2 个数量级，虽然体现效率优势，但也意味着"同等规模下的对比"缺失；部分基线为不同训练数据/预训练规模，未完全控制变量。
- **算力与效率信息不完整**：未报告 GPU 数量、训练时长、显存、实际推理延迟/吞吐的绝对数值，"更快更高效"的证据主要是定性图。
- **消融覆盖局限**：所有消融仅在 LIBERO-Plus RGB-D 设定下完成，未验证结论在真实世界或其他 benchmark 上的可迁移性；λ_s（骨架损失权重）、未来状态数量 H_s、时间偏移 δ 等关键超参未做敏感性分析。
