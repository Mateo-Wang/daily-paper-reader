## 摘要
自回归视觉-语言-动作模型通常将连续的机器人动作表示为离散标记序列，从而能够以标准的下一标记预测目标进行动作预测。FAST 通过将包含多种时间频率的动作紧凑地编码为相对较少的标记，显著改进了这种表示。然而，尽管这种压缩减少了自回归预测所需的动作标记数量，它并不一定提高从有限演示中学习策略的效率。具体而言，FAST 通常为每个量化动作序列分配单一的确定性标记化，尽管多个标记序列可以表示并解码为相同的机器人运动。我们研究利用这种表示冗余是否能够改进策略学习。在本文中，我们提出基于随机采样的动作序列标记化（TOAST），一种随机动作标记化方法，在策略训练期间对同一量化动作序列采样不同的标记化。这在保留底层机器人动作的同时多样化了离散监督，并且无需额外演示。在 LIBERO 上的实验表明，TOAST 持续优于其确定性对应方法，且随着训练数据减少，提升幅度增大；当仅有 1/16 的训练数据可用时，成功率提升 6.8 个百分点。在四个真实机器人操作任务中，TOAST 相比确定性对应方法进一步将平均成功率提高 15.8 个百分点。这些结果证明了随机动作标记化对于自回归机器人策略学习的有效性，尤其是在训练数据有限时。

## Abstract
Autoregressive Vision-Language-Action models often represent continuous robot actions as discrete token sequences, enabling action prediction with standard next-token objectives. FAST has substantially improved this representation by compactly encoding action containing diverse temporal frequencies into relatively few tokens. However, while such compression reduces the number of action tokens required for autoregressive prediction, it does not necessarily improve the efficiency of policy learning from limited demonstrations. In particular, FAST typically assigns a single deterministic tokenization to each quantized action sequence, although multiple token sequences can represent and decode to the same robot motion. We investigate whether exploiting this representational redundancy can improve policy learning. In this paper, we propose TOkenization of Action sequences with STochastic sampling (TOAST), a stochastic action tokenization method that samples alternative tokenizations of the same quantized action sequence during policy training. This diversifies the discrete supervision while preserving the underlying robot action and requires no additional demonstrations. Experiments on LIBERO show that TOAST consistently improves over its deterministic counterpart, with the improvement increasing as training data decreases, achieving a 6.8 point gain in success rate when only 1/16 of training data is available. Across four real-robot manipulation tasks, TOAST further improves mean success rate by 15.8 points over the deterministic counterpart. These results demonstrate the effectiveness of stochastic action tokenization for autoregressive robot policy learning, particularly when training data are limited.

## 一、核心问题与整体含义

- **背景**：自回归视觉-语言-动作模型（VLA）将连续机器人动作表示为离散 token 序列，从而可用标准"下一 token 预测"目标进行动作预测。FAST 通过 DCT + BPE 将包含多时间频率的动作压缩为少量 token，显著减少了自回归预测所需的 token 数。
- **核心问题**：token 压缩并不等于提升从有限演示中学习策略的效率。频率类 tokenizer（如 BPE）产生的分词边界对机器人动作**并非物理上有意义**——同一量化动作序列可以被多个不同 token 序列表示并解码为完全相同的运动。但确定性 tokenizer 仅依据语料频率统计选定唯一一种分词，策略在交叉熵监督下只会复现该序列。
- **研究动机**：NLP 领域的随机分词（subword regularization）已被证明能缓解对单一分词的过度依赖，在低资源场景尤其有效。机器人演示数据收集成本高昂，类似问题可能更严重。
- **整体含义**：作者将确定性动作分词视为"对单一离散表示的过度依赖"的来源，把随机分词形式化为一种**表示层正则化**，并提出 TOAST（TOkenization of Action Sequences with STochastic Sampling）——首个面向自回归机器人策略学习的随机动作分词框架。

## 二、方法论

### 核心思想
在策略训练时，对**同一量化动作序列**采样多种等价的 tokenization 作为监督目标；所有采样序列都解码为相同的底层机器人动作，因此不会改变动作语义，却能在不增加演示数据的前提下多样化离散监督信号。推理阶段不采样。

### 关键技术细节
1. **量化与展平**：动作块先经 DCT + 离散化得到 `q ∈ Z^{D×H}`，采用**维度主序展平**（同一动作维度的时间相邻值连续排列）。
2. **构建一元语言模型 tokenizer**：
   - 在量化展平序列语料 `Q` 上，先构造包含候选子序列的**大种子词表**，并保留全部单个量化值以确保任意序列可表示。
   - 每个 token `v` 赋予概率 `p(v)`，按标准 unigram LM 流程迭代优化并剪枝低贡献 token，直到目标词表规模（默认 512）。
   - 序列 `t` 的概率为各 token 概率之积：`P(t) = Π p(ti)`。
3. **随机采样**：
   - 给定 `q`，通过 unigram 分数做 **n-best 搜索**（Forward-DP Backward-A* 算法，线性时间），得到 n 个候选序列。
   - 第 i 个候选的分词概率近似为：
     `P(ti | q) ≈ P(ti)^α / Σ_j P(tj)^α`
   - `α` 控制分布锐度：α 越大越接近确定性，α 越小越接近均匀采样。所有采样序列都解码到同一 `q`。
4. **策略训练**：每步采样一个目标序列 `t̃`，最小化标准下一 token 预测目标 `−Σ log π(t̃i | l, o, t̃<i)`。**不改变策略架构与学习目标**，只改变训练目标所用的离散表示。推理时贪心解码并反 DCT 还原动作块。

### 算法流程（文字版）
量化+展平 → 一元 LM 计算 n-best 候选 → 按式(1)采样一个分词 → 作为训练目标更新策略 → 推理时确定性分词与解码。

## 三、实验设计

### 数据集 / 场景
- **仿真**：LIBERO 基准（Franka Emika Panda，10 Hz，7 维动作），含四个任务套件：LIBERO-Spatial、Object、Goal、Long。
- **真机**：Franka Research 3（20 Hz，8 维关节角+夹爪），四个任务：Table Bussing、Grocery Bagging、Breakfast Setup、Drawer Stowing；演示数量分别为 200/200/100/60，通过 GELLO 遥操作采集。
- **数据规模消融**：LIBERO 使用完整数据的 1/1、1/2、1/4、1/8、1/16，各方法共享同一子集。

### 对比方法
- Binning（均匀分箱，256 bins）
- FAST+（官方发布版，DCT+BPE，2048 词表）
- FAST (rebuilt)（重建版，512 词表，与 TOAST 同语料）
- BEAST（B 样条控制点）
- VQ-VLA（残差向量量化学习式 tokenizer）
- **TOAST (deterministic)**：与 TOAST 共享量化、展平、词表与策略配置，仅确定性选择单一分词——用于隔离随机分词效应。

### 评估协议
- LIBERO：每套件 500 次 rollout（50×10 任务），每种子共 2000 次，3 个随机种子。
- 真机：每任务 30 次 rollout（6 种配置×5 次），3 个种子。
- 显著性检验：分层 bootstrap（10,000 次重采样，种子为簇），配对相同评估回合，双侧 95% 百分位 CI 不含零即显著。

### 消融维度
- 采样参数 α 敏感性（0.05–1.0）
- 词表语料（DROID / DROID+LIBERO / 仅 LIBERO）
- 展平方向（维度主序 vs 时间主序）
- 对等价 tokenization 的敏感度指标 `Δtok = Lalt − Lcan`
- 训练计算开销

## 六、主要结论与发现

1. **Q1（仿真）**：TOAST 在每个数据规模上均优于确定性版本，且**数据越少增益越大**：1/16 数据时成功率 42.8% vs 36.0%（+6.8 分），1/2 及以下数据时增益显著。
2. **Q2（真机）**：TOAST 平均成功率 50.8%，比 TOAST(det.) 高 **15.8 分**，比 FAST+ 高 **20.0 分**，均显著。增益主要来自需要高精度操作的动作段（如抓盘子边缘、够抽屉把手），除 Grocery Bagging 外所有任务均有较大提升。
3. **Q3（消融）**：
   - α 在 [0.05, 1.0] 内性能稳定，α 增大趋近确定性时性能下降；
   - 词表越贴近目标域（仅 LIBERO），采样增益越大（+6.8 → +11.9），且不依赖外部语料；
   - 维度主序展平绝对性能更高（1/16 时 42.8% vs 36.0%），但随机分词在两种展平下均有增益且随数据减少而增大；
   - `Δtok` 从确定性训练下的显著正差距降至接近零，说明随机训练**大幅降低了对单一分词的依赖**，同时留出数据上 Lcan 更低（1.146 vs 1.252），表明泛化更好；
   - 采样开销可忽略（+0.4%）。
4. **总体结论**：随机动作分词是提升自回归机器人策略学习、尤其在有限演示下的简单有效手段。

## 七、优点

- **问题视角新颖**：首次指出频率类动作 tokenizer 存在"同一动作多种等价分词"的冗余性，并将其转化为可利用的训练信号。
- **方法极简且即插即用**：不改变策略架构、学习目标和推理流程，只改训练目标的离散表示，可与现有自回归 VLA pipeline 直接集成。
- **无需额外数据**：从现有演示中"挖掘"更多监督，特别契合机器人数据昂贵的现实约束。
- **变量隔离干净**：TOAST(det.) 与 TOAST 共享量化、展平、词表、策略配置，精确归因于随机采样；并用 FAST(rebuilt) 控制词表语料差异。
- **理论借鉴扎实**：直接沿用 NLP 的 subword regularization 与 Forward-DP Backward-A* n-best 搜索，采样成本线性、可忽略。
- **诊断指标有说服力**：`Δtok` 从表示层面量化了策略对单一分词的依赖，配合 Lcan 降低共同说明这是"学到了更好的表示"而非损失膨胀。
- **仿真与真机双重验证**，并指出真机增益与高精度操作鲁棒性相关，具有一定机理洞察。

## 八、不足与局限

- **适用面受限**：TOAST 依赖"同一量化序列存在多种有效分词"，因此**无法直接应用于学习式向量量化 tokenizer**（如 VQ-VLA、FASTer、OAT），扩展到学习式离散表示留作未来工作。
- **具身单一**：实验仅用 Franka 一种具身（仿真为末端位姿动作，真机为关节角动作），未研究跨具身的共享词表。
- **随机分词方案单一**：仅实例化为 unigram + subword regularization，未与 BPE-dropout 等其他随机方案对比，无法判断增益来自 unigram 模型还是随机分割本身。
- **超参敏感性未考察**：词表大小（512）与候选数 n（64）固定，未做敏感性分析。
- **真机实验规模有限**：仅 4 个任务、每任务 30 次 rollout，任务类型集中在桌面操作，泛化到更复杂/长时程任务的证据不足。
- **算力信息不透明**：未报告 GPU 数量与总训练时长，影响可复现性与成本评估。
- **增益归因不完全清晰**：作者自己指出仿真与真机在任务分布、动作表示、执行条件上也存在差异，因此不能将真机更大的增益完全归因于数据规模；真机 α 与仿真不一致也引入一定不确定性。
- **潜在偏差风险**：所有结果均来自作者自建 pipeline，缺少第三方独立复现；真机 α 由初步试验选定，可能带来调参偏差。
