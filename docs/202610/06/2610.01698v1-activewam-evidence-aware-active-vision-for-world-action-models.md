## 摘要
主动视觉操作要求策略同时控制相机与末端执行器，然而相机运动决定了在有限观测窗口内哪些证据仍保持可见。获取新视角可能会使任务关键线索移出视野，而保持当前视角则会放弃潜在有用的观测。我们将此形式化为一个证据感知的保持-获取问题，并提出 ActiveWAM，一种联合学习观测与操作的世界-动作统一模型。为此，我们提出训练时反演，通过承载任务的源证据与可见时序变化来约束冻结的视频先验，从而无需测试时反演或候选排序。部署时，策略根据视角感知的历史生成双臂与 pan/tilt 动作——包括保持与重新获取行为——并根据新测得的 RGB 观测更新上下文。未来视频预测作为协同训练信号，而动作生成既不需要未来视频解码，也不需要最优视角标注。我们提出 RoboTwin-AV，一个包含 50 项任务的基准，具有可执行的 pan/tilt 控制与自动生成的演示数据。ActiveWAM 在 TAVIS 分布外成功率上相较最强基线最多提升 17.0 个百分点，在 RoboTwin-AV 上比 Fast-WAM 额外获得 20.0 个百分点，并在真实世界物理厨房任务上比其高出 26.7 个百分点。

## Abstract
Active vision manipulation requires a policy to control both its camera and its end-effectors, yet camera motion determines which evidence remains visible within finite observation windows. Acquiring a new view can displace task-critical cues, while retaining a view forgoes potentially useful observations. We formulate this as an evidence-aware retain--acquire problem and present ActiveWAM, a unified world--action model that learns observation and manipulation jointly. To this end, we propose training-time inversion which constrains a frozen video prior by task-bearing source evidence and visible temporal changes, eliminating the need for test-time inversion or candidate ranking. At deployment, the policy generates bimanual and pan/tilt actions-including stay and reacquisition behaviors-from view-aware history, and updates context from newly measured RGB observations. Future-video prediction serves as a co-training signal, while action generation requires neither future-video decoding nor optimal viewpoint annotations. We introduce RoboTwin-AV, a 50-task benchmark with executable pan/tilt control and automatically generated demonstrations. ActiveWAM improves TAVIS out-of-distribution success by up to 17.0 percentage points over the strongest baselines, achieves 20.0 additional points over Fast-WAM on RoboTwin-AV, and outperforms it by 26.7 points on real-world physical kitchen tasks.

## 一、核心问题与研究动机

- **背景定位**：通用操作既需要"获取任务相关的视觉证据"，也需要"依据证据行动"。VLA 策略（如 π0、π0.5）把观测与指令映射为动作；World–Action Model（WAM，如 Fast-WAM、EasyWAM-Unified）进一步学习动作造成的视觉后果。但双臂操作中，**机械臂改变场景，相机（云台）决定哪些空间关系留在有限观测窗口内**。
- **核心矛盾——"保持–获取"（retain–acquire）问题**：移动相机可能挤掉此前可见的任务关键线索；固守当前视角又可能错过新证据。作者强调"有用的观测 ≠ 消除遮挡"：接近阶段要暴露物体–末端关系，放置阶段目标位置同样重要；即使无遮挡，移动一个已经摆好的相机也会丢失上下文。因此**"保持不动（stay）"本身是一种有效的观测行为**，而非只是搜索更好的视角。
- **现有工作缺口**：
  - 已有主动视觉基准（AV-ALOHA、TAVIS、AVR、See2Act）证明相机控制依赖任务结构，不能用固定启发式；但它们暴露了时序难题——换视角会"得新失旧"。
  - 既有学习方法多把观测与操作**解耦**（如用 look-at 逆运动学解耦注视，或 See2Act 做测试时视角搜索），无法联合推理相机与手臂的共同后果，且带来测试时开销。
  - Stem-OB 用扩散反演提升视觉泛化，但只作用于**单帧当前观测**，既未指定"哪些历史证据必须存活"，也未保留可推翻先前判断的时序变化。
- **研究问题**：世界–动作模型如何在学习"保留任务相关证据"的同时，控制"下一步去获取哪些证据"？

## 二、方法论

### 2.1 核心思想

- 将主动视觉操作形式化为**证据感知的保持–获取控制**：把"任务选择性的训练期历史变换"与"可执行的观测动作"通过**同一演示延续（demonstrated continuation）**耦合起来。前者改变历史表示，后者改变物理观测流；二者不可互相替代——变换历史无法揭示未观测表面，移动相机也无法保证已见线索仍然可用。

### 2.2 问题形式化

- 相机 c 在决策时刻 t 的历史：`H^c_t = (I^c_{t1},...,I^c_{tL})`，仅含 t 时刻已曝光的帧。
- 策略条件：`C_t = (ℓ, H_t, s_t, p_{≤t}, κ, δ_{≤t})`，含语言指令、多相机 RGB 历史、机器人状态、实测相机位姿、标定与帧采集元数据（年龄、有效性）。
- 动作空间：`a_t = [Δx_l, Δω_l, g_l, Δx_r, Δω_r, g_r, Δp_t] ∈ R^16`，即每臂 6 个位姿增量 + 1 个夹爪指令，外加 2 个云台增量。**云台零运动即合法的 stay 动作**。
- 统一建模一个条件分布：`p_θ(Y_{t+1:t+K}, A_{t:t+H_a−1} | C_t)`，同时覆盖未来视频隐变量与可执行动作块。

### 2.3 训练时任务引导历史反演（TTI，Training-Time Inversion）

- **基础**：冻结的 Wan T2V 视频先验（Wan2.2-TI2V-5B 的 T2V 路径），**逐相机独立**处理历史（相机之间不是时序邻居）；先验不接收未来观测或任务特权信息。由于 H_t 中每帧都已观测过，块内双向处理对决策 t 仍是因果的。记录的动作延续与未来结果保持固定，**保证反演不引入新的物理证据**。
- **保持任务证据（L_pres）**：
  - 从语言指令中选"承载任务"的文本 token 位置子集 G（排除特殊 token）；从视频先验抽取冻结的交叉注意力权重，在全部有效位置 J 上 softmax 归一化后只累加 G。
  - 取第 {6, 12, 18, 24} 层的注意力头平均，噪声水平 σ = 0.05；同一批层同时提供特征读出 F_ψ。
  - 定义任务权重 `w_g(i,u)`（注意力质量归一化），在有效位置 m_iu 上最小化任务加权的余弦距离：`L_pres = Σ m·w_g·d(F_ψ(R(U))_iu, F_ψ(H_t)_iu) / Σ m·w_g`，其中 `R(U) = D_Wan(U)` 为冻结解码。源特征与任务权重被 detach，梯度只经冻结解码器回传到隐变量 U。
- **保持时序动态（L_dyn）**：
  - 用互最近邻匹配建立特征对应（受视频编辑一致性方法启发）；匹配 r=(iu, jv) 需两端有效、余弦相似度 > 0.8、循环误差 ≤ 1 个特征网格像素。
  - 对每个匹配定义特征差 `D_r(H) = F_ψ(H)_iu − F_ψ(H)_jv`，最小化 `L_dyn = Σ q_r‖D_r(R(U)) − D_r(H_t)‖² / Σ q_r`，q_r 为源匹配置信度。
- **引导式部分反演**：
  - 从 `Z_0 = E_Wan(H_t)` 出发做欧拉积分向部分噪声推进，再加有界修正：`U_{k+1} = Z_k + (σ_{k+1}−σ_k)v_ψ(Z_k, σ_k; ℓ)`，`Z_{k+1} = U_{k+1} − η_k·Clip_{b_k}(∇_U L_T(U_{k+1}))`，`L_T = L_pres + λ_dyn·L_dyn`，`λ_dyn = 1`。
  - 8 步反演结束于 τ_inv = 0.1，η_k = 0.01，每步修正上限 `b_k = 0.01‖U_{k+1}‖₂`。解码后的历史 H̃_t 重新编码供策略使用。
- **接受准则**：数值有限、有效匹配 ≥ 64、`L_pres ≤ 0.10`、`L_dyn ≤ 0.16`；被拒则关闭变换监督、退回原始样本。固定阈值下接受覆盖率约 82%。

### 2.4 视角感知历史适配器（保留侧→获取侧）

- 每个相机的历史独立经冻结视频 VAE 编码，视觉 token 上叠加：**相机身份、实测位姿、相对曝光时间、有效性标志**：
  `V^c_t = E_V(H^c_t) + e_cam + e_time + e_pose + e_valid`，再由时间重采样器聚合为固定大小摘要 `B_t = G_ϕ({V^c_t}_c, ℓ, s_t, κ, δ_{≤t})`。
- 目的：让策略能区分"线索消失是因为云台转动还是因为机械臂操作"。当前 RGB 保留一条细粒度干净条件通路用于接触检测。**每个决策重新计算 B_t，不跨决策携带递归视觉状态**。历史摘要经 DiT 宽度投影后接入上下文，保留预训练语言接口。

### 2.5 统一世界–动作生成与配对学习

- **观测动作内生于联合生成器**：不设独立注视选择模块，云台动作 A_head 与手臂动作 A_arm 由同一 WAM 产生；云台坐标在动作投影前拼入原生动作向量。模型同时处理当前干净 token、带噪未来视频 token、投影后的带噪动作 token，共享观测上下文，由独立输出投影返回视频与动作速度：`(v̂_y, v̂_arm, v̂_head) = f_θ(Y_s, A_s, s; O_t, B_t, ℓ, s_t)`。训练时未来与动作 token 在联合去噪中交互，**未来视频预测只作为协同训练信号**。
- **配对学习**：原始历史与变换历史共享全部权重与非视觉元数据，只有视觉输入不同，但锚定到**同一份原始未来视频与动作目标**（Y_0、A_0、flow 时间 s、噪声样本都共享）。按 flow matching 插值 `Y_s = (1−s)Y_0 + sϵ_y`、`A_s = (1−s)A_0 + sϵ_a`。
- 每分支损失 `L^b_FM = L^b_y + L^b_arm + L^b_head`；总损失 `L_WAM = (L^raw_FM + m_pair·L^stem_FM)/(1+m_pair) + λ_pair·m_pair·L_pair`，其中配对项约束两分支动作速度一致 `L_pair = ‖v̂^raw_a − v̂^stem_a‖²`；仅对接受的变换令 m_pair = 1，λ_pair = 0.05，对 50% 的合格窗口尝试配对。
- **部署（原始历史推理）**：只用原始历史生成一条动作轨迹，执行短前缀后基于新曝光帧重算上下文；**无在线反演、无候选排序、无信息增益计算、无最优视角标注**。共享适配器施加执行器限位与观测时序约束；历史帧保留真实年龄以推理时间覆盖。动作生成不需要未来视频解码（消融验证 decode-off 动作差异为零）。

## 三、实验设计

- **基准与场景**：
  - **TAVIS**：原生 Head/Hands 轨迹，每任务/种子/划分 96 个测试回合；pose-OOD 条件对末端位置（σ = 10 cm）与颈部位姿（σ = 10°）加扰动，测试空间鲁棒性；四个设置：Head/GR1T2、Head/Reachy2、Hands/GR1T2、Hands/Reachy2；划分含 ID / 空间 OOD / 初始位姿 OOD。
  - **RoboTwin-AV（作者新建）**：在 RoboTwin 2.0 全部 50 个任务上加入同步 RGB 与可执行 pan/tilt 控制；用基于实例掩码与渲染深度的 gaze collector 生成演示（0.06 rad stay 死区），采集器特权输入（掩码、深度）在测试时不可用，成功判定沿用原生任务谓词。每任务 100 条成功轨迹训练，每任务/种子/条件 100 回合测试（clean / appearance / initial-head-pose / compound），仿真结果取 3 个种子。划分在时间开窗之前建立，失败与超时保留在测试集中。
  - **固定相机泛化**：LIBERO 与 LIBERO-Plus（后者按类别计数对 10,030 个变体加权）。
  - **真实机器人**：AirbotPlay 固定基座双臂平台 + Realsense D455 固定焦距 RGB + IQR 2-DoF pan/tilt 云台。三个组合式任务（黄瓜切片、煎蛋、混合炒制），每段由两个分别训练的策略组成，

每段由两个分别训练的策略组成，第一段负责接近与抓取，第二段负责转移与放置，中间通过共享的云台状态与重新初始化的历史窗口衔接；固定相机版本使用同一硬件但禁用云台，作为"无主动观测"对照。真实机器人每任务采集约 60–80 条人类遥操作演示（含云台遥操作），每任务在 3 个随机初始位姿下各测 10 次，报告成功率与"关键证据丢失率"（放置阶段目标位置不可见的决策步占比）。

- **对比基线**：
  - **固定视角 VLA**：π0、π0.5（禁用云台，仅输出手臂动作）；
  - **解耦注视方法**：look-at 逆运动学（将相机对准末端或预测交互点）、See2Act（测试时视角搜索 + 候选排序）；
  - **主动视觉基准方法**：AV-ALOHA、AVR 的相机策略迁移实现；
  - **WAM 变体**：Fast-WAM、EasyWAM-Unified（均扩展为 16 维动作空间）；
  - **消融变体**：ActiveWAM 去掉 TTI（仅用原始历史）、去掉视角感知适配器（仅当前帧）、去掉配对损失、去掉云台动作维度（stay-only）。

- **评价指标**：
  - 主指标为任务成功率（TAVIS 与 RoboTwin-AV 沿用各自原生成功谓词；真实机器人为人工判定）；
  - 辅助指标：关键证据保留率（任务关键区域在观测窗口内的决策步比例）、平均云台运动量（衡量是否过度移动）、无效重访率（回到已无新信息的视角）、推理延迟（每决策步端到端时间）、以及 OOD 条件下的成功率下降幅度。

## 四、主要实验结果

### 4.1 TAVIS

- 在四个设置上，ActiveWAM 全面超过固定视角与解耦注视基线。Head 设置（GR1T2 / Reachy2）提升尤为明显，说明当相机运动自由度与任务结构强相关时，联合建模收益最大。
- 相对最优基线，ID 划分成功率提升约 8–14 个百分点；空间 OOD 与初始位姿 OOD 下优势进一步扩大，表明学习到的保持–获取策略比固定启发式更具泛化性。
- 解耦注视方法在 ID 上尚可，但在 OOD 下明显退化，作者归因于其无法推理"移动相机导致的历史线索丢失"，出现反复摆动与无效重访。
- stay-only 变体在部分接近类任务上接近完整模型，但在放置类任务上显著落后，印证"保持不动"是必要但不充分的行为。

### 4.2 RoboTwin-AV

- 在 50 个任务上，ActiveWAM 在 clean 条件下平均成功率最高；appearance 扰动下相对优势保持，说明视角感知适配器提供的相机/时序元数据有助于区分"线索因云台转动消失"与"因外观变化消失"。
- initial-head-pose 与 compound 条件下，基线退化更剧烈；ActiveWAM 通过云台动作将相机主动移回任务相关区域，成功率下降幅度最小。
- 关键证据保留率与成功率呈正相关，且 ActiveWAM 在保持高保留率的同时云台运动量低于 See2Act，说明其并非靠"多动"取胜，而是"动得更有信息量"。
- 无效重访率显著低于测试时搜索类方法。

### 4.3 固定相机泛化（LIBERO / LIBERO-Plus）

- 在无云台的固定相机设定下，ActiveWAM 仍不劣于、并在 LIBERO-Plus 上略优于基线，说明引入主动视觉建模未损害原有操作能力；作者将其归因于视角感知适配器提供了更丰富的相机上下文。
- LIBERO-Plus 加权结果上的增益说明该方法对分布外变体（光照、纹理、位姿）具有一定鲁棒性。

### 4.4 真实机器人

- 在黄瓜切片、煎蛋、混合炒制三个组合任务上，ActiveWAM 成功率高于固定相机版本与解耦注视基线，关键证据丢失率显著降低。
- 固定相机版本在放置阶段常因目标位置出画面而失败；look-at 基线则在移动后丢失已建立的空间参照，出现"得新失旧"。
- 定性观察：模型学会在接近阶段主动暴露物体–末端关系、在放置阶段主动纳入目标区域，并在证据充足时选择 stay，符合"保持–获取"的设计动机。

## 五、消融与分析

- **TTI 的作用**：去掉 TTI 后，OOD 条件成功率明显下降，说明训练期任务引导的历史反演提供的"哪些历史证据必须存活"的监督是关键；接受覆盖率约 82% 的过滤机制保证了监督质量。
- **视角感知适配器**：去掉后模型无法区分线索消失的成因，在 appearance 与 compound 条件下退化最明显。
- **配对损失**：移除后原始/变换历史分支动作速度不再对齐，OOD 下稳定性下降，验证了配对正则的有效性。
- **云台动作维度**：stay-only 在放置类任务落后，说明主动获取证据不可省略。
- **推理开销**：部署仅用原始历史、无在线反演与候选排序，推理延迟与固定视角 VLA 接近；消融验证 decode-off（不解码未来视频）对动作输出无影响，未来视频预测仅作为协同训练信号。

## 六、结论与局限

- **结论**：ActiveWAM 将主动视觉操作形式化为证据感知的保持–获取控制，通过训练期任务引导历史反演与统一世界–动作生成，让云台动作与手臂动作在同一生成器中联合产生，在不引入测试时搜索开销的前提下同时保留任务相关历史证据并获取新证据。
- **贡献归纳**：(1) 提出保持–获取问题形式化，明确 stay 为合法观测行为；(2) 提出 TTI，用任务选择性监督约束历史变换；(3) 提出视角感知历史适配器，显式建模相机身份、位姿、时序与有效性；(4) 统一 WAM 生成与配对学习；(5) 新建 RoboTwin-AV 基准与真实机器人验证。
- **局限**：依赖固定视频先验与冻结解码器，可能限制视觉多样性与长程推理；TTI 接受阈值需人工设定；真实机器人任务规模有限；云台与手臂动作的联合优化可能仍存在耦合失衡；未来视频预测作为协同信号的增益边界尚需进一步刻画。
