## 摘要
中间表示是弥合可泛化操作策略与大规模预训练视觉语言模型（VLM）之间模态差距的关键。其中，基于轨迹的表示紧凑地编码了与运动相关的线索，但大多数现有方法在2D图像空间中预测轨迹，导致固有的3D歧义。此外，使用带深度的2D轨迹仍会使自由空间路点不明确，限制了可靠的3D推理。为解决这一问题，我们提出从多视图图像预测3D一致路点（3DWay）。通过将3D路点预测重新表述为生成多视图一致的2D路点并随后进行几何三角测量，我们在保留预训练VLM强大先验的同时，实现了明确的3D运动规格。预测的路点可以引导现有的VLA模型以获得更好的泛化，或直接执行简单任务。大量实验表明，3DWay显著改善了3D空间定位和视觉语言推理，展示了在可泛化机器人操作方面的强大潜力。代码将在https://github.com/ziqin-h/3DWay发布。

## Abstract
Intermediate representations are key to bridging the modality gap between generalizable manipulation policies and large-scale pretrained vision-language models (VLMs). Among these, trajectory-based representations compactly represent motion-relevant cues, yet most existing approaches predict trajectories in 2D image space, resulting in intrinsic 3D ambiguity. Moreover, using 2D trajectories with depth still leaves the free-space waypoints ambiguous, limiting reliable 3D reasoning. To address this, we propose predicting 3D consistent waypoints (3DWay) from multi-view images. By reformulating 3D waypoints prediction as generating multi-view consistent 2D waypoints followed by geometric triangulation, we enable explicit 3D motion specification while preserving the strong priors of pretrained VLMs. The predicted waypoints can guide existing VLA models for better generalization or be directly executed on simple tasks. Extensive experiments show that 3DWay substantially improves 3D spatial grounding and vision-language reasoning, demonstrating strong potential for generalizable robot manipulation. Codes will be released at https://github.com/ziqin-h/3DWay.

### 2. 论文提出的方法论

- **核心思想（技术路线）**：
  - 不直接让模型回归 3D 坐标，而是**将 3D 路点预测问题重构为"多视图一致 2D 路点预测 + 几何三角化"**：使用 VLM 从多视角 RGB 图像中预测各视角的 2D 路点，利用相机内外参做三角化恢复出确定性的 3D 路点，从而绕开直接预测 3D 的模态鸿沟与深度歧义问题。
- **生成流程**：
  - **输入**：V 个多视角 RGB 图像 `{I_v}`、对应相机内参 `{K_v}`、外参 `{T_v}`、语言指令 ℓ。
  - **第一步**：微调后的 VLM 预测多视角一致 2D 路点 `Ŵ_2D = VLM(I, ℓ)`。
  - **第二步**：通过多视角三角化（Triangulation）恢复 3D 路点：`Ŵ_3D = Tri(Ŵ_2D, K, T)`。
- **训练数据构建**：
  - 基于末端执行器模型和机器人状态信息计算原始 TCP（Tool Center Point）轨迹；
  - 使用 **RDP（Ramer-Douglas-Peucker）算法**做轨迹简化；
  - 将简化后的 3D 点通过相机内外参**投影为 2D 路点标签**；
  - 利用开放词汇检测器和任务相关提示做**自动数据质量过滤**；
  - 直接以语言建模目标监督 2D-MCW 的像素坐标文本输出，避免复杂损失函数或专家头设计，与主流 VLM 训练范式兼容。
- **模型与训练策略**：
  - 基于 **NVILA 系列 VLM**（2B/8B/15B 参数）；
  - 先在 RoboPoint 数据集上微调 1 epoch，后在自建多数据集上微调 10 epoch；使用交叉熵损失 + AdamW，采用 cosine 学习率衰减；
  - 多视图一致性体现在训练时不同视角的 2D 标签来自同一组 3D 路点投影，从而保证跨视角监督一致。
- **策略使用方式**：
  - **直接执行（3DWay-TD）**：配合自上而下抓取和基于路点的运动规划，将 3DWay 转为低层控制命令；
  - **自适应路点引导的 VLA 集成**：将 3DWay 按执行阶段自适应地选取局部时间窗口（窗口大小 N=2），与机器人本体感知状态拼接后馈入 π0 等 VLA 骨干，通过微调提升其 3D 空间接地与泛化能力。

### 6. 论文的主要结论与发现

- **3D 一致性路点具有直接可执行性**：3DWay-TD 在 RLBench unseen 上达到 64.0% 成功率（而 π0.5 为 18.8%），表明仅凭简化 3D 路点就能在许多旋转无关任务上完成动作。
- **继承并保留了 VLM 的视觉-语言先验能力**：丰富的定性结果（如“把天空色球放入金属容器”“把梨放在最凶猛动物的照片上”等抽象指令与跨视角图片）显示模型能泛化到开放世界与语义技巧很强的指令。
- **3DWay 可作为 VLA 的强适配器**：以 π0 为例，3DWay-augmented few-shot 比起标准 π0 微调：仿真平均成功率从 17.6% 提升到 46.1%；真实世界（基本任务）从 21.7% 提升到 65.8%，在视觉泛化与语义任务上也大幅抛离基线（例如语义类成功率从 2.5% 提升至 51.7%）。
- **只需少量数据**：在 3DWay 引导下，10 demos/task 的结果即可约与 50 demos/task 标准 π0 微调成效相当，缓解了数据匮乏问题。
- **多视图一致性训练是关键的**：去掉一致性监督后（D0）成功率从 64.0% 腰斩至 22.0%，证明多视图几何约束不可替代。
- **鲁棒且灵活的框架**：骨干模型从 15B 缩至 2B 时成功率降幅有限；相机外参扰动只带来温和下降；不同机械臂与相机配置下表现基本稳定。

### 7. 优点

- **明确 3D 空间接地，无需深度传感器**：用多视图三角化替代深度回归，绕开了深度噪声和自由空间歧义。
- **将 3D 问题转译为 VLM 熟悉的 2D 文本输出**：用户可实现文本格式的 2D 路点监督，不改变模型预训练范式，且自然保留了 VLM 世界知识。
- **跨视图几何一致监督**：一种用“投影 + 三角化”闭环来构造监督信号的优雅方案，本质保证了 3D 一致。
- **可扩展性好**：3DWay 可被多种下游使用（直接执行或 VLA 条件）；对本体、相机配置并不挑剔；从 2B 到 15B 的骨干都可行。
- **验证充分且很有说服力**：模拟+真实环境的综合测试、跨本体和跨相机配置消融、以及大量开源并发/对比方法；对小样本与视觉-语言联合挑战设置了专门的评估设置。
