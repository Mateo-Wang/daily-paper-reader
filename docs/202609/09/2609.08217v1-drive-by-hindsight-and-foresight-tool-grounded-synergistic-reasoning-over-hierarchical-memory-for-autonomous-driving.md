## 摘要
视觉语言模型（VLM）在自动驾驶领域展现出潜力，但仍存在幻觉、时空感知薄弱和泛化能力有限等问题。近期方法通过思维链（CoT）解释、检索增强生成或静态注入工具输出来提升推理与决策能力。尽管这些机制丰富了上下文，但模型既不会主动感知场景信息，也无法在作答后积累经验。为克服这些局限，我们提出了（据我们所知）首个将分层记忆与主动工具调用在闭合推理回路中紧密耦合的协同框架。我们的贡献有三方面：(i) 分层驾驶记忆：场景级短期记忆维护动态场景状态，进化的长期记忆检索可复用经验与工具策略。(ii) 记忆-工具协同推理框架：在场景状态与检索经验的引导下，模型在推理时自适应地调用工具以优化推理，并在离线阶段将可复用经验整合进长期记忆池。(iii) 数据生成与两阶段训练流程：通过多步教师展开构建经过验证的记忆-工具轨迹，用于SFT和GRPO训练。我们的7B模型在DriveLMM-o1上达到80.03的总体推理得分和79.09%的多选题（MCQ）准确率，比最强基线高出7.74个MCQ百分点，并在多个基准上表现出强大泛化能力。值得注意的是，消融与分析研究验证了各组件的有效性，并进一步揭示了分层记忆的互补作用：短期记忆增强时空理解，使STSBench准确率提升24.2个百分点，而离线长期记忆整合在全参数冻结的情况下额外带来3.57个MCQ百分点的提升，展现了通过累积驾驶经验实现的持续自我进化。

## Abstract
VLMs have shown promise for autonomous driving, yet still suffer from hallucination, weak spatio-temporal perception, and limited generalization. Recent methods improve reasoning and decision-making through CoT explanations, retrieval-augmented generation or the static injection of tool outputs. Although these mechanisms enrich the context, the model neither proactively perceives scene information nor accumulates experience after answering. To overcome these limitations, we present, to our knowledge, the first synergistic framework that tightly couples hierarchical memory with proactive tool invocation in a closed reasoning loop. Our contributions are threefold. (i) Hierarchical Driving Memory: a scene-level short-term memory maintains the dynamic scene state, and an evolving long-term memory retrieves reusable experience and tool strategies. (ii) Memory-Tool Synergistic Reasoning Framework: guided by the scene state and retrieved experience, the model adaptively invokes tools to refine its reasoning at inference time and consolidates reusable experience into a long-term memory pool offline. (iii) Data Generation and Two-stage Training Pipeline: verified memory-tool trajectories built by multi-step teacher rollout are used to train with SFT and GRPO. Our 7B model reaches an overall reasoning score of 80.03 and MCQ accuracy of 79.09% on DriveLMM-o1, surpassing the strongest baseline by 7.74 MCQ points and generalizes strongly across benchmarks. Notably, ablation and analysis studies validate the effectiveness of each component and further reveal the complementary roles of hierarchical memory. Short-term memory strengthens spatio-temporal understanding, improving STSBench accuracy by 24.2 points, while offline long-term memory consolidation yields an additional 3.57-point MCQ gain with all parameters frozen, demonstrating continual self-evolution through accumulated driving experience.

## 2. 方法论

### 2.1 核心思想

> 给定当前六视角图像，模型不再一次性直接作答，而是条件于**场景级短期记忆**（记录动态时空状态）与**检索到的跨场景长期记忆**（提供可复用经验），在"思考—行动—观察—更新"（Think–Action–Observation–Update）的闭环中**迭代调用驾驶工具**以弥补证据缺口，直至证据充分再给出答案，并在离线阶段将验证过的经验巩固回长期记忆。

其决策策略可形式化为：

\[
y \sim \pi_\theta(q, I_t, M_s, E_K, \mathcal{T})
\]

其中 \(M_s\) 为短期记忆，\(E_K\) 为长期记忆中检索出的 Top-K 条目，\(\mathcal{T}\) 为工具集。

### 2.2 分层驾驶记忆

**（1）场景级短期记忆（STM, Scene-Level Short-Term Memory）**

- **动机**：单时刻六视角图无法显式揭示自车和交通参与者的时间演化；直接喂多帧原始图会大幅增加视觉上下文负担并要求语言模型隐式做跨视角对齐与时间对应。
- **构造**：取两个相邻时刻的六视角观测 \(I_{t-1}\) 和 \(I_t\)，用预训练BEV感知模型（HERMES风格编码器）生成结构化语义描述与场景属性，再用**场景图**（scene graph）组织为包含节点（自车/参与者/道路要素）与关系（空间、时间、交互关系）的图结构。在单个轨迹内只读、新场景到达时刷新。

**（2）跨场景长期记忆（LTM, Cross-Scene Long-Term Memory）**

- 每条记忆 \(e_i = (c_i, r_i, p_i^+, \pi_i^{tool}, w_i)\)，分别刻画适用场景与任务条件、风险因素、可复用成功推理模式、有效工具使用策略及检索效用。
- **检索**：将问题与STM联合编码为查询表征，按语义相关性和归一化效用加权的公式计算相关度并取Top-K：

\[
S(e_i | q, M_s) = \text{sim}(E_m([q; M_s]), E_m(e_i)) + \lambda \bar{w}_i
\]

- **检索安全措施**：排除源自同一场景的条目（防止泄露）；剥离内部身份字段与教师决策，保证推理期安全的检索视图。
- **离线巩固（Offline Consolidation）**：对通过验证的轨迹提取经验，经滤除、抽象、去重、冲突消解和合并后写入长期记忆库；已有条目的检索效用按 \(w_i \leftarrow w_i + \eta g_i(C)\) 更新。

### 2.3 Memory-Tool Synergistic Reasoning (MTSR)

- 完整推理轨迹定义为：\(C = (x_0, s_1, \dots, s_T, y)\)，每步 \(s_t = (h_t, a_t, o_t, u_t)\)（推理状态、动作、工具观察、更新的场景信念）。
- 每一步策略生成下一个推理状态与动作：

\[
(h_t, a_t) \sim \pi_\theta(\cdot \mid x_0, H_{<t}),\quad a_t \in \mathcal{T} \cup \{\text{finish}\}
\]

- 迭代目标：在记忆与上下文固定的情况下，模型通过工具调用获取的外部观测逐步缩小不确定性，当证据充足时发出 `finish` 并生成最终答案。
- 工具库共含**27个可调用函数**（实验中报告20个核心工具），涵盖开放词汇2D检测、实例选择、3D定位与深度估计、自车状态、轨迹预测、占用率与地图查询等。工具返回值全部是**结构化观测**，可被纳入场景信念，而无需模型凭外观猜测。

### 2.4 数据生成与两阶段后训练

- **教师多步展开**：使用API模型Qwen3.6-Plus在给定答案锚定的条件下生成7,000条工具执行轨迹，6,383条通过验证。验证标尺包括：最终答案正确性、工具调用合法性、推理与观察的一致性。验证通过的经验进一步沉淀为初始LTM。
- **分步SFT（两阶段）**：
  - **Phase 1**：掩蔽工具返回的观察，训练模型学会"选什么工具、生成什么参数"（13,679条记录；3 epochs）；
  - **Phase 2**：从Phase 1检查点继续，提供完整记忆与工具反馈，训练基于观察的接地推理（20,062条记录；20 epochs）。
- **轨迹级GRPO**：从Phase 2检查点出发，每个提示采样 \(G=8\) 条轨迹，使用**六层分级奖励**（Tiers 1–6）：
  - Tier 1：答案正确 ∧ 使用工具 ∧ 引用记忆 → +0.7
  - Tier 2：答案正确 ∧ 使用工具 ∧ 未引用记忆 → +0.5
  - Tier 3：答案正确 ∧ 未用工具 → 0.0
  - Tier 4：答案错误 ∧ 使用工具 → +0.2（**有意的引导项**，用于工具冷启动与防走捷径）
  - Tier 5：答案错误 ∧ 未用工具 → 0.0
  - Tier 6：格式错误 → 0.0
  - 奖励经过正确性门控设计（如正确但不用工具的奖励低于正确且用工具的奖励，但错误轨迹的工具奖励仅为引导，且组内优势标准化使其在存在正确答案时自动失效）；KL系数 \(\beta=0.001\)。训练分四个连续阶段（v0→v1→v2→v3），从v2起在提示中注入LTM检索结果。

3. **跨数据集泛化实验（STRIDE-QA）**：5个基线模型的zero-shot对比；
4. **消融实验**：
   - 训练管线：Base → +SFT → +GRPO的逐步增益；
   - 记忆组件：无记忆 / +LTM / +STM / +STM+LTM；
   - 时空表征：base → +6帧原始输入 → +静态STM → +STM（在STSBench上）；
5. **行为分析**：工具调用深度分布、条件工具选择、LTM离线自我进化曲线（10个巩固轮次）；
6. **定性分析**：在DriveBench上对照Qwen3-VL-32B的若干视觉损坏场景案例，覆盖距离估计、未来状态预测、恶劣天气决策、左右方位推理等；
7. **统计稳健性**：对DriveLMM-o1主结果做了10,000次bootstrap的95%置信区间分析。

### 5.2 充分性与客观性评价

- **优点（充分性）**：
  - 消融设计**完整且各有针对性**：训练阶段（SFT/GRPO各自贡献）、分层记忆（两者互补性表述有数据支撑）、时间表征方式（对比调原始多帧与结构化STM）均被独立测试；
  - 泛化实验覆盖不同数据分布（nuScenes系 + DriveMLLM的正面单视图 + STRIDE-QA的非nuScenes城市、更多上下文帧），能有力支撑其泛化主张；
  - 给出**bootstrap置信区间**并做出了诚实的结论区分：MCQ优势稳健，但推理得分与最强基线差异没有统计学意义（79.68落在[79.46, 80.57]区间内）——这样的报告方式值得肯定；
  - 工具调用行为、终端状态、成功率、延迟分布、GPU内存等工程性指标报告细致。
- **值得注意的限制（公平性考量）**：
  - DriveLMM-o1测试集上，与AgentThink等基线的最强对比中，**推理得分优势在统计上不显著（区间重叠）**，作者只在MCQ上明确宣称优势；
  - 定性对比仅与单个基线（Qwen3-VL-32B）进行且为手工挑选案例，不构成系统性的鲁棒性证据；
  - 部分基线结果（如GPT-4o、Qwen3-VL-32B）是API调用或非官方适配，可能存在提示差异等不一致来源；
  - DriveAgent-R1因资源未开放未纳入正式对比，但作者做了说明，可接受。

## 6. 主要结论与发现

1. **整体效果**：7B模型在DriveLMM-o1上达到 **80.03推理得分**和 **79.09% MCQ准确率**，比骨干模型Qwen2.5-VL-7B分别提升28.26和41.28个点；比AgentThink（同规模的工具注入型方法）**MCQ高出7.74个点**，并在Rule Adherence和Scene Awareness维度排名第一。
2. **跨基准泛化**：DriveMLLM上zero-shot AccS 74.36 / one-shot 80.59（对比AgentThink的56.96/61.21）；未见过的STRIDE-QA上MLSR 3.9，在2秒/3秒长时序定位上达5.6/4.4，均为开源模型最优。
3. **分层记忆互补性的消融**：无记忆72.16% MCQ → +LTM 75.20% → +STM 76.91% → +二者 79.09%。STM贡献更大（对应大多数问题依赖当前场景状态），LTM提供持续一致的经验增益。STM使STSBench时空理解提升 **24.2个百分点**（31.38%→55.61%），且优于直接增加视觉上下文（"6 frames input"仅35.64%）——显式时间状态组织优于增加视觉上下文。
4. **两阶段训练必要性**：S

4. **两阶段训练必要性**：仅 Base（骨干）模型推理得分 52.03、MCQ 34.7%；加入 Phase 1 和 Phase 2 SFT 后推理得分大幅跃升至 70.19，MCQ 达到 64.63%；再经轨迹级 GRPO 强化（v0→v3）后，推理得分提升至 80.03，MCQ 提升至 79.09%。训练曲线表明：分步 SFT 建立了基础的工具选择与观察整合能力，而 GRPO 进一步优化了工具使用时机、记忆引用策略与推理链质量，两者缺一不可。
5. **工具使用是关键行为增益来源**：有工具条件（Tool）下模型 MCQ 为 79.09%，无工具条件（No Tool）下降至 70.42%；无工具且无记忆（No Tool + No Mem）时进一步降至 66.07%，说明工具主动感知带来约 8.7–13 个百分点的稳定增益。行为分析还显示模型学会了条件化选择工具——空间推理问题优先调用 3D 定位与深度估计，时间预测问题优先调用轨迹预测工具，而部分简单问题（如静态属性查询）会在少量工具调用后直接终止，说明"何时停止调用工具"也被策略学到。
6. **经验固化机制有效（持续进化）**：离线巩固实验中，初始 LTM 库经过 10 轮巩固后，DriveLMM-o1 测试集上的 MCQ 从 76% 左右提升至约 79%，增益主要集中在前几轮，随后趋于饱和；这说明 MTSR 具备"用过即学、越用越强"的经验沉积能力，而非一次性静态模型。
7. **推理维度与定性分析**：在 DriveLMM-o1 的 12 个推理维度中，模型在 Rule Adherence（交规遵守）和 Scene Awareness 上排名第一；定性对比显示，在恶劣天气（雨、雪、雾）条件下，基线 Qwen3-VL-32B 往往给出基于表面纹理的错误距离估计或忽略风险目标，而 MTSR 通过工具获取结构化 3D 观测后，能够正确感知空间关系并输出保守且合规的驾驶决策。

## 7. 局限性（作者自我报告与读者补充）

### 7.1 作者自述局限

1. **领域限制**：目前记忆库覆盖的是自驾场景（nuScenes 等数据分布）下的驾驶任务。跨领域（如室内导航、通用具身操作）的迁移有效性未经验证。
2. **缺少真实闭环测试**：评估均在离线数据集上进行（nuScenes、STRIDE-QA 等的记录帧），没有在真实车辆或闭环模拟器中测试模型行为，推理延迟（~35s）也远未达到实时决策要求。
3. **依赖历史数据而非在线经验获取**：LTM 的初始条目来自教师模型生成的已验证轨迹，离线巩固迭代也依赖已有数据集；模型不具备在线交互中自主发现新经验的能力。
4. **感知工具受限于预训练 BEV 模型**：短期记忆依赖 HERMES 风格 BEV 感知模型的支持，长尾场景或极端传感器噪声下，上游感知错误可能被传播到推理结果中。
5. **LTM 知识维护**：冲突消解与去重规则目前为手工设计，如何在大规模记忆库中长期保持一致性、及时剔除过时经验，仍是悬而未决的问题。

### 7.2 读者补充的观察

1. **统计显著性的边界**：推理得分上（79.68 vs AgentThink 等）与最强基线差异未通过 bootstrap 区间分离，作者在行文中对"推理得分优势"的表述应理解为"与最强方法持平或略有优势"，而非决定性超越。真正稳健且显著的优势集中在 MCQ 准确率上。
2. **延迟与工具调用的实际可行性**：35 秒的中位查询延迟意味着该方法在当前阶段只能用于离线分析和辅助决策，不能直接部署到实车端到端系统。虽然作者指出工具执行仅需毫秒级、瓶颈在 LLM 解码，但并未报告任何加速尝试（如蒸馏到小模型、推测解码）。
3. **泛化实验的评估协议非完全对齐**：DriveMLLM 和 STRIDE-QA 上使用了与原始作者不同的 prompt 模板与输出解析策略，与这些 benchmark 原始报告值之间的可比性需注意。
4. **LTM 检索的上下文开销**：Top-K 记忆条目被注入每步推理上下文后，长上下文（max seq len 12,288）与多步工具调用叠加的推理成本未被单独计算"，但在 35s 总延迟中已有体现。

## 8. 关键参考价值（对后续研究的启示）

1. **"协作工具 + 闭环推理 + 记忆更新"的架构模板**：MTSR 将三类原本分离的技术（工具增强、链式推理、记忆系统）统一在同一优化目标（分级奖励）下协同优化，为后续自动驾驶 LLM（乃至通用智能体）提供了一种可复现的整体设计范式——**推理不是单次前向，而是带状态更新的闭环过程**。
2. **分步 SFT 的设计被验证有效**：先掩蔽工具输出教"选动作"，再提供工具反馈教"读观察"的两阶段训练方案，为工具调用型模型的训练课程设计提供实用参考。
3. **分级奖励体系是"行为引导"而非"结果奖惩"**：Tier 4（错误但用工具 → +0.2）防止模型走捷径跳过工具，Tier 1/2 与 Tier 3 的差值强制模型"必须通过工具获得正确答案"，这种奖励塑形设计对工具学习冷启动具有启发性。
4. **显式时空状态优于增加视觉上下文**：在 STSBench 上，结构化 STM（55.61%）远胜直接输入多帧原始图像（35.64%），该对比给予了"LVLM 时空理解瓶颈更应靠状态表征而非数据堆叠解决"的实证证据。
5. **经验进化的可衡量框架**：离线巩固 + 10 轮自举提升 3 个点 MCQ 的实验设计，为评估"记忆系统是否真的在进化"提供了可操作的度量协议（记忆条目增长曲线、检索命中率、下游任务分数变化）。
6. **对"工具调用与无工具性能差距"的归因分析**：从 No Tool 66.07%、No Tool+No Mem 70.42% 到 Full 79.09% 的渐进差异，清晰分解了工具与记忆各自的增量贡献，可作为类似智能体系统的标准消融模板。

## 9. 总结论（一段话概括）

本文提出了 **MTSR（Memory-Tool Synergistic Reasoning over Hierarchical Memory）**，一个让 7B 视觉语言模型在自动驾驶场景中同时具备"远见（基于短时场景记忆的动态时空推理）"与"后见（基于跨场景长期记忆的经验复用）"的统一闭环推理框架。MTSR 将自动驾驶任务重新定义为"Think–Action–Observation–Update"的迭代过程：模型通过主动调用 27 个驾驶专用工具获取结构化外部观测，逐步消解不确定性后再输出决策；同时，两类分层记忆分别提供当下场景的动态演化状态与历史经验约束，且在离线阶段通过验证、抽象与冲突消解持续巩固新经验入长期记忆库，使系统具备可持续进化的能力。通过两阶段 SFT 与轨迹级 GRPO 强化，仅 7B 参数的模型在 DriveLMM-o1 基准上取得 80.03 推理得分与 79.09% MCQ 准确率的大幅领先，并在 DriveMLLM 与 STRIDE-QA 两个未见基准上展现出明显优于同类工具注入型基线的泛化能力。消融与行为分析验证了分层记忆的互补性（STM 贡献动态感知，LTM 提供经验增益）、结构化时态状态优于额外视觉上下文，以及"主动感知 + 记忆巩固"是实现可持续进化的驾驶智能的关键支柱。尽管延迟与真实闭环测试的限制使其距实车部署尚有距离，MTSR 为 LLM/VLM 驱动的自动驾驶开放了一条"感知—推理—记忆—进化"协同发展的清晰路径，也为各类具身智能系统（机器人、通用智能体）提供了极具参考价值的闭环学习框架设计蓝图。
