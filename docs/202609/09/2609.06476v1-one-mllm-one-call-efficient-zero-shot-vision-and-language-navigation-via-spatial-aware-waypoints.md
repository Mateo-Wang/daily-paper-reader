## 摘要
连续环境中的视觉与语言导航（VLN-CE）要求具身智能体通过遵循自然语言指令在未见环境中导航。当前的零样本VLN-CE方法要么依赖预训练的路点预测器，要么每一步需要多次查询大型模型。为了解决高昂的推理延迟和计算开销，我们提出了O2C-Nav，一种高效的零样本导航框架，每个决策步骤仅调用一次单一大型模型。我们的方法引入了一种无需训练的结构化路点生成器，以及一种新颖的抽象表示，将稀疏的、历史感知的候选路点直接作为视觉标记投影到RGB图像上。MLLM在每一步选择一个路点或生成一个回退的目标边界框，而低层快速行进法（FMM）规划器将所选目标转换为可执行的免碰撞路径。该范式为模型提供了具体的空间感知和显式记忆，同时显著降低了视觉处理负担。在R2R-CE和RxR-CE基准上的广泛评估表明，O2C-Nav优于当前最先进的零样本方法，凸显了其在实时机器人部署中的巨大潜力。代码可在https://github.com/kkpsq/O2C-Nav-Code获取。

## Abstract
Vision-and-Language Navigation in Continuous Environments (VLN-CE) requires an embodied agent to navigate unseen environments by following natural language instructions. Current zero-shot VLN-CE methods either rely on pre-trained waypoint predictors or require multiple queries to large models per step. To address prohibitive inference latency and computational overhead, we propose O2C-Nav, an efficient zero-shot navigation framework that calls only a single large model once per decision step. Our approach introduces a training-free structured waypoint generator and a novel abstract representation that projects sparse, history-aware candidate waypoints directly onto RGB images as visual markers. The MLLM selects a waypoint or generates a fallback target bounding box at each step, while a low-level Fast Marching Method (FMM) planner converts the selected target into an executable collision-free path. This paradigm provides the model with concrete spatial perception and explicit memory while significantly reducing the visual processing load. Extensive evaluations on the R2R-CE and RxR-CE benchmarks demonstrate that O2C-Nav outperforms current state-of-the-art zero-shot methods, highlighting its great potential for real-time robotic deployment. Code is available at https://github.com/kkpsq/O2C-Nav-Code.

  - 每个决策步骤需要多次查询大型多模态模型（如 STRIDER 每步 3 次、LaViRA 每步 2 次），导致推理延迟和计算开销过高，不适合实时机器人部署。

## 2. 论文提出的方法论：O2C-Nav

总体原则是 **One MLLM, One Call**：每步仅调用一次单一 MLLM 完成高层的空间选择与意图判断，低层运动交给规则式/几何规划器执行。整体流程如下：

1. **结构化路点生成器（无训练）**
   - 利用四视角 RGB-D 观测和位姿构建二维俯视语义栅格地图，提取“可步行区域”；
   - 对可步行区域做形态学闭合和骨架化（中轴变换 / Zhang–Suen 细化），得到单像素宽的拓扑骨架；
   - 识别骨架上的端点与岔路口，再结合 NMS 和空间采样间隔（如 `dsample = 0.5 m`）获得稀疏但全覆盖的候选路点集合；
   - 维护已访问的历史路点集合 `W_reached`，并按距离阈值合并，形成紧凑的结构化轨迹记忆。

2. **抽象路点表示（Spatial-Aware Waypoint Overlay）**
   - 通过相机内参、位姿和地图分辨率，将 2D 栅格路点投影到四视角 RGB 图像上；
   - 路点以带 ID 的颜色圆点渲染：青色表示未访问候选，红色表示已访问历史点，蓝色表示当前位置；
   - 这样将底层几何拓扑转化为 MLLM 可以直接理解的视觉地标，提供“显式空间感知”和“历史感知”。

3. **单次 MLLM 决策**
   - 输入包括：自然语言指令、标注路点的可视化四视角图像、滑动窗口（w=5）的执行历史、由 Grounding DINO 抽取的对象列表（如 door、chair 等标签），以及循环警告等；
   - 输出包含：进度分析、推理理由、高层面动作（forward/right/left/back/stop）、目标路点 ID（`target_id`），若无可用路点则生成目标边界框（`navigable_bbox`）作为兜底；
   - 循环检测与历史访问计数机制能帮助 MLLM 避免重复进入同一个区域。

4. **低层控制**
   - 若选定路点 ID，则取其像素坐标；若选择 bbox，则取其底部中心像素；
   - 通过反投影得到 2D 世界目标点，然后用快速行进法（FMM）在实时可通行代价图上规划无碰撞路径，并转化为离散运动指令执行。

算法整体以循环形式描述：每步获取状态 → 提取可导航区域 → 更新已访问路点 → 结构化生成候选 → 投影可视化 → 单次 MLLM 决策 → 若 stop 则结束，否则执行底层控制并更新历史。

## 8. 潜在问题与批评

- **MLLM 依赖性与不可控风险**：模型整体性能依赖于 GPT-4o/Gemini-2.5/Qwen3-VL 等专有或超大模型的即时推理质量，而这些模型的决策存在随机性和不可解释性。尽管论文报告了较高成功率，但单次错误推理可能直接导致导航失败，且无训练纠错机制。
- **感知级联误差**：地面真值深度与真实机器人深度差异大。真实环境中基于深度图的可通行区域提取、骨架化质量易受噪声或传感器误差影响；论文在物理实验中未报告失败案例的误差来源，因此对真实世界噪声的鲁棒性未知。
- **未真正端到端可微**：MLLM 本身以“黑盒”方式被直接调用，既没有针对 VLN 任务微调，也没有通过环境反馈进行强化学习；其“空间意图”输出是否稳定依赖提示词措辞与模型版本亦有待检验。
- **路程效率指标（SPL/NDTW）偏低**：尽管 SR 高，SPL 和 NDTW 明显弱于一些监督基线，说明智能体经常绕远路或未能沿最优路径行进。高成功率可能来自更长的探索轨迹，而非语义理解驱动的高效决策。
- **仿真评估规模仍有限**：R2R-CE 仅 100 个随机 episodes，且零样本设定下的重采样可能会得到不同数值；RxR-CE 也没有完全覆盖多语言与更长指令的全部谱系。这在一定程度上削弱了统计显著性。
- **步行/动作空间离散化限制**：底层控制依赖路点之间导航，而路点采样间隔 `dsample = 0.5 m` 可能导致穿过狭窄通道或临近目标时动作粒度不够精确；真实机器人实验的成功率只有 50%，尚且没有接近仿真水准。

## 9. 未来研究方向

- **自适应采样间隔与动态路点选择**：可根据局部障碍密度或目标距离动态调整 `dsample`，既保证全局拓扑覆盖，又提高目标附近的导航精度。
- **轻量化 MLLM 替代**：为了摆脱对闭源或超大模型的依赖，未来可探索将现有决策知识蒸馏到 7B/13B 级别的开源视觉语言模型中，同时通过目标检测与地图感知增强其空间推理能力。
- **引入记忆型闭环反馈**：将导航历史与目标完成度作为 prompt 的一部分，甚至用短时记忆网络让 MLLM 对“已探索区域”形成隐式表征，减少重复决策和死循环。
- **统一多种传感器模态**：在真实机器人上增加 LiDAR 或深度点云融合，使路点生成在噪声环境下依然稳健；或直接训练一个轻量路点预测头，兼顾零样本泛化与实时性。
- **扩展到多目标与动态场景**：当前只考虑静态环境中的单指令导航，若环境中有动态障碍或任务要求 ObjectNav，还需引入动态占用地图更新与重新规划机制。未来可评估该方法在 Spot/其他双足或轮式平台上的迁移能力。

## 10. 总体结论

O2C-Nav 通过“结构化路点提取 + 视觉化路点覆盖 + 单次 MLLM 高层决策 + 几何控制器”的分层架构，成功将零样本 VLN-CE 的每步查询成本压缩到一次 MLLM 调用，并在 R2R-CE、RxR-CE 中取得大幅度领先。其核心贡献在于证明了一个设计良好的“空间感知路点可视化”能作为 MLLM 与几何世界之间的桥梁，使通用的视觉语言模型在连续物理环境中执行导航任务时具备竞争潜力，也为低成本真实机器人指令跟随提供了一条可行路径。

然而，该方法仍存在对 MLLM 的强依赖、路径效率偏低、仿真规模有限等明显短板，距离“可可靠部署”的大规模应用仍有距离。未来若能将像素级路点覆盖思想移植到轻量化端侧模型，并引入更具鲁棒性的感知与记忆机制，则有望进一步推动零样本具身导航走向实用。
