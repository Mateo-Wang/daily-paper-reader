## 摘要
自动驾驶中，预测周围车辆的未来轨迹对于碰撞风险评估和自车安全路径规划至关重要。传统的基于神经网络的轨迹预测器通常通过利用智能体历史、动态场景图和语义地图来取得较强的预测性能。然而，在加速、减速和转弯等特定运动状态下，这些预测器可能无法反映物理上可行的轨迹。为解决该问题，本研究提出了一种在后期融合阶段将基于神经网络的轨迹预测器Trajectron++的输出与基于扩展卡尔曼滤波（EKF）的多个轨迹候选相融合的框架。在nuScenes数据集上，所提方法在不修改基线架构的情况下，将Trajectron++ robot基线的平均位移误差和最终位移误差分别降低了13.7%和14.6%。这些结果表明，基于EKF的轨迹候选可以通过学习到的融合有效补充神经轨迹预测。

## Abstract
Predicting the future trajectories of surrounding vehicles in autonomous driving is important for collision risk assessment and safe ego-vehicle path planning. Conventional neural network-based trajectory predictors typically achieve strong prediction performance by exploiting agent history, dynamic scene graphs, and semantic maps. However, in specific motion regimes such as acceleration, deceleration, and turning, these predictors may fail to reflect physically feasible trajectories. To address this issue, this study proposes a framework that fuses the output of Trajectron++, a neural network-based trajectory predictor, with extended Kalman filter (EKF)-based multiple trajectory candidates at a late stage. On the nuScenes dataset, the proposed method reduces the average displacement error and final displacement error of the Trajectron++ robot baseline by 13.7% and 14.6%, respectively, without modifying the baseline architecture. These results indicate that EKF-based trajectory candidates can effectively complement neural trajectory prediction through learned fusion.

- **核心问题**：神经预测器依赖训练分布，在**加速、急刹、转弯、入弯**等特定运动状态下可能输出物理上不可行的轨迹，无法体现运动学约束。
- **整体含义/思路**：物理模型与深度网络在自动驾驶中具有互补性。论文提出**后期融合（late fusion）**框架，在**不修改、不重训**神经基线的前提下，把冻结的 Trajectron++ 输出与基于 EKF 的多运动模式轨迹候选融合，从而在保留丰富上下文表征的同时，在特定运动状态下选择性利用物理可行的替代轨迹。

## 二、方法论

### 1. 总体架构（两条并行分支 + 后期融合）

- **神经分支**：输入完整场景信息（目标与邻居历史、动态场景图、语义地图、自车未来规划），采用 **Trajectron++ 的 robot-conditioned 配置**，取其最高概率轨迹作为基线候选 **C₀**。权重全程冻结。
- **物理分支**：仅使用目标车辆自身历史轨迹，由 **EKF 多模式生成器**产生 5 条候选 **C₁…C₅**，分别对应匀速（CV）、加速（Accel）、减速（Decel）、左转（Left）、右转（Right）。
- **融合模块**：将候选集合 C = [C₀, C₁, …, C₅] 经特征构造器（feature builder）送入 MLP，输出样本相关的融合权重 **w**，最终预测为凸组合 **ŷ = Σₖ wₖ Cₖ**。
- 由于基线冻结、只训练融合阶段，方法保留基线原始输出能力，同时在不重训昂贵预测器的条件下修正特定运动模式的失效。

### 2. EKF 多模式候选生成

- **运动模型**：非线性**独轮车（unicycle）模型**。
  - 状态：xₜ = [pₓ, p_y, θ, v]ᵀ；控制：uₜ = [a, ω]ᵀ（纵向加速度、横摆率）。
  - 加速度与横摆率由相邻时刻有限差分估计：aₜ = (vₜ − vₜ₋₁)/Δt，ωₜ = wrap(θₜ − θₜ₋₁)/Δt；并对速度、加速度、横摆率做物理范围裁剪以抑制观测噪声与离散化误差。
  - 离散转移模型采用**中点航向 θ_mid 与中点速度 v_mid**，允许一个时间步内航向与速度变化；速度用 clip(·, 0, v_max) 约束。
- **观测与滤波设置**：观测 zₜ 与状态同维，观测矩阵 H = I₄；协方差固定为
  - P₀ = diag(10, 10, π, 5)
  - Q = diag(0.25, 0.25, 0.0225, 1.0)
  - R = diag(1.0, 1.0, 0.0625, 2.25)
  - 未向输入历史注入合成噪声，噪声仅通过协方差传播与量测更新体现。
- **五种模式的控制输入**（a、ω 取自近期历史代表值）：
  - CV：a = 0, ω = 0
  - Accel：a = max(a, 1.5), ω = 0
  - Decel：a = min(a, −2.0), ω = 0
  - Left：a = 0, ω = max(ω, 0.18)
  - Right：a = 0, ω = min(ω, −0.18)
- 所有候选从**同一 EKF 估计状态 x̂ₜ** 出发，按各模式控制输入在预测时域 T 内 rollout（T = 6），形成 C_k = rollout(f, x̂ₜ, uₖ, T)。
- **模式概率**：基于 a、ω 的量值与符号构造证据分数（score_CV、score_Accel、score_Decel、score_Left、score_Right，含阈值 a_thr、ω_thr 与归一化尺度），再经 softmax 得 πₖ。这些概率**不直接决定最终预测**，仅作为融合模块的辅助特征。生成器最终输出 5 条候选轨迹、模式分布 π 与运动摘要特征（速度、加速度、横摆率）。

### 3. 学习式融合

- 先计算概率加权 EKF 均值 **C̄ = Σ_{k=1..5} πₖ Cₖ**。
- 融合特征 φ 拼接内容：基线相对轨迹（12 维）、5 条 EKF 候选相对基线的轨迹（5×12 = 60 维）、加权均值与基线的差（12 维）、模式概率（5 维）、最可能模式的 one-hot（5 维）、标量运动摘要（速度/加速度/横摆率，5 维），**总计 99 维**。
- MLP 输出 6 个候选的 logits，经 softmax 得权重：w = softmax(MLP(φ))；最终 ŷₜ = Σ_{k=0..5} wₖ Cₖ,ₜ。
- 凸组合使预测落在各时刻候选位置的**凸包内**，限制极端外推；动态可行性由候选本身可行性与学习权重间接保证。

### 4. 训练目标（四项损失加权和）

- **L_pred**：融合输出与真值的 SmoothL1 距离。
- **L_CE**：以"每样本 ADE 最小的候选"为 oracle 标签 k* 的交叉熵，监督融合网络学习该强调哪个候选。
- **L_base**：基线保留项 (1/B)Σ(1 − w_{i,0})，防止基线权重坍缩。
- **L_guard**：守护项 (1/B)Σ max(0, f_i − b_i − m)，惩罚融合显著劣于基线的样本（f_i、b_i 为融合与基线的 SmoothL1 误差，m 为允许裕度）。
- 总损失：L = L_pred + λ_CE·L_CE + λ_base·L_base + λ_guard·L_guard。
