## 摘要
视觉-语言-动作（VLA）策略通常在每个策略推理时运行具有数十亿参数的视觉-语言模型（VLM）骨干网络，这会带来延迟和能耗开销。我们重新审视一种用于多任务操作的解耦替代方案：分离视觉和语言编码器，并以其表示调节一个紧凑的动作头。我们进行了标准化比较，在固定演示数据、训练步数预算、任务、评估协议和测量平台的情况下，改变视觉编码器、语言编码器和动作头，并与七个 VLA 基线进行对比。得到的解耦具身模型（Decoupled Embodiment Model，DEM）结合了微调的 DINOv3 视觉编码器、冻结的 NeoBERT 语言编码器，以及一个在单次前向传播中生成动作块的 MeanFlow 头。在 18 个 RoboCasa 任务上，使用留出的指令复述和随机化场景进行评估，DEM 达到 55.6% 的平均成功率，而 GR00T N1.7 为 56.9%，$\pi_{0.5}$ 为 54.6%；在三个真实机器人任务上，DEM 达到 66.0%，而 GR00T N1.7 为 68.0%。在同一工作站上，DEM 每次策略前向传播需要 6.1 ms，最大吞吐量为每秒 162.7 次策略调用，估计每次调用消耗 2.07 J 的 GPU 能量，相比这些 VLM 骨干策略，吞吐量高出八到十七倍，能耗低六到十五倍。在这一训练任务范围内，DEM 位于所观察到的成功率-延迟-能耗前沿，并为语言条件化的机器人技能提供了一个强大而高效的基线。

## Abstract
Vision-Language-Action (VLA) policies commonly run Vision-Language Model (VLM) backbones with billions of parameters at every policy inference, which costs latency and energy. We revisit a decoupled alternative for multi-task manipulation: separate vision and language encoders whose representations condition a compact action head. We run a standardized comparison that varies the vision encoder, the language encoder, and the action head while holding the demonstrations, the training-step budget, the tasks, the evaluation protocol, and the measurement platform fixed, against seven VLA baselines. The resulting Decoupled Embodiment Model (DEM) combines a fine-tuned DINOv3 vision encoder, a frozen NeoBERT language encoder, and a MeanFlow head that generates an action chunk in one forward pass. On 18 RoboCasa tasks evaluated with held-out instruction paraphrases and randomized scenes, DEM reaches 55.6\% mean success against 56.9\% for GR00T N1.7 and 54.6\% for $π_{0.5}$, and on three real-robot tasks it reaches 66.0\% against 68.0\% for GR00T N1.7. On the same workstation, DEM needs 6.1\,ms per policy forward pass, a maximum throughput of 162.7 policy calls per second, and draws an estimated 2.07\,J of GPU energy per call, eight to seventeen times the throughput and six to fifteen times less energy than these VLM-backbone policies. Within this trained-task regime, DEM sits on the observed success--latency--energy frontier and provides a strong, efficient baseline for language-conditioned robot skills.

## 1. 核心问题与研究动机

- **背景**：当前主流 Vision-Language-Action（VLA）策略普遍以数十亿参数的 VLM 作为骨干网络，并在**每一次策略推理**时完整运行该骨干（如 π0.5 单次推理约需 100 ms）。
- **痛点**：这种设计在低层操作任务中代价高昂——策略需要在 25–50 Hz 的高频控制下保持反应性，且受能耗约束；动作分块（action chunking）和异步执行只能"掩盖"慢推理，无法真正缩短感知到动作的计算本身。
- **关键观察**：对于这类策略，VLM 的主要作用是**为动作预测提供图像与指令的表征**，而非生成语言。用为自回归生成而设计、并因此被放大参数量的 decoder-only 模型来提供表征，存在结构性错配。
- **历史脉络**：早期通用策略（RT-1、Octo、BAKU）本就采用解耦设计，但受限于 2019 年前后的组件水平；随着预训练投入转向 decoder-only 模型，机器人领域转而复用 VLM 检查点。与此同时，DINOv3、NeoBERT、ModernBERT、mmBERT 等独立编码器已取得显著进步，甚至有配对实验显示 150M 编码器在 MNLI 上超过 400M 解码器。
- **本文问题（有意限定范围）**：当策略被训练执行一组**固定的、语言条件化的操作技能**时，用现代独立编码器替换联合融合的 VLM 骨干，能保留多少观测成功率？又能节省多少推理开销？
- **整体含义**：论文并不主张解耦编码在一般意义上优于联合预训练，而是论证在"已训练技能"这一制度下，解耦策略可以占据**成功率–延迟–能耗前沿**上的有利位置，为语言条件化机器人技能提供一个强而高效的基线。

## 2. 方法论：DEM（Decoupled Embodiment Model）

### 2.1 核心思想
- 视觉编码器、语言编码器、动作头是**三个独立网络**，其输出仅在动作头内部的**交叉注意力**中相遇，不共享骨干。
- 三条通路的独立性带来关键工程收益：语言通路的计算与图像无关，因此**指令不变时可复用缓存 token**，只在指令变化时重新编码；而联合融合的 VLM 无法做这种复用。

### 2.2 关键模块
- **视觉编码器**：DINOv3 ConvNeXt-B。取 stage-3 特征图（256 像素输入下为 16×16×512），展平为每相机 256 个 token；场景相机 + 腕部相机共 $N_v = 512$ 个 token。从公开检查点初始化并**与动作头联合微调**。
- **语言编码器**：NeoBERT（加载时 222M 参数），指令填充/截断至 $N_l = 32$ token，保留最后一层每个 token 的隐状态及注意力掩码（**不做句向量池化**）。**保持冻结**（微调无增益）。
- **动作头**：MeanFlow，一次前向生成整段动作块 $a \in \mathbb{R}^{H \times A}$（$H=16$）。配置为宽度 $d=768$、$D=8$ 个 block、107M 参数。

### 2.3 公式与算法流程（文字说明）
- **Flow Matching 基线**：学习插值 $z_t = (1-t)a + t\epsilon$ 的瞬时速度 $v$，推理时需多步积分。
- **MeanFlow 核心**：改为学习区间 $[r,t]$ 上的**平均速度** $u(z_t,r,t)=\frac{1}{t-r}\int_r^t v(z_\tau,\tau)d\tau$，因此区间位移可由单次乘积给出：$z_r = z_t - (t-r)u(z_t,r,t)$。
- **MeanFlow 恒等式**：对 $t$ 求导得 $u = v - (t-r)\frac{d}{dt}u$，网络 $u_\theta$ 被训练满足该恒等式；沿插值路径 $v=\epsilon-a$ 有闭式解，总导数 $\frac{d}{dt}u_\theta = v\partial_z u_\theta + \partial_t u_\theta$ 仅需一次 Jacobian-向量积。
- **训练损失**：以停止梯度的恒等式右端为目标，采用自适应权重 $w=(\|\cdot\|_2^2+c)^{-p}$，取 $c=10^{-3}$、$p=0.5$；$(r,t)$ 从 logit-normal 采样，并以 0.5 的概率令 $r=t$（此时退化为 flow-matching 损失，起锚定作用；MeanFlow 默认为 0.75）。
- **推理**：仅一次前向，$\hat{a} = \epsilon - u_\theta(\epsilon, 0, 1 \mid C)$。

### 2.4 模块组装
- 视觉 token $V$、语言 token $L$（带掩码 $m$）与本体状态 $q$ 各自线性投影到头部宽度 $d$，并加上可学习模态嵌入，拼接成上下文 $C \in \mathbb{R}^{(N_v+N_l+1)\times d}$（本文配置为 **545 个上下文 token/步**）。
- 噪声动作块作为 $H$ 个动作 token 输入，加位置嵌入；时间区间 $(r,t)$ 经时间嵌入 $c$ 注入。
- 每个 block：先做动作 token 间自注意力 + FFN，均由 $c$ 通过 **adaLN（DiT 式）** 调制；再做交叉注意力，动作 token 为 query，上下文为 key/value，掩码仅屏蔽填充的语言 token；输出经**零初始化的逐通道门控** $g_i$ 加权，使每个 block 初始为无条件去噪器，再学习"读多少"场景与指令。
- 最后经 LayerNorm + 零初始化线性层输出 $u_\theta$。由于只有动作头消费 $C$，替换任一编码器只需改动 $W_v$ 或 $W_l$，因此所有消融变体都插入同一动作头。

## 6. 主要结论与发现

- **成功率可比**：18 任务 RoboCasa 上 DEM 平均 55.6%，GR00T N1.7 为 56.9%，π0.5 为 54.6%，三者处于相近的观测成功率区间；DEM 在抽屉、拉杆、按钮类别上点估计最高，在拾放、门、插入上落后，最大差距在旋钮任务（37.0% vs 49.0%）。
- **效率优势显著**：DEM 单次前向 6.1 ms、最大吞吐 162.7 次调用/秒、估计每次调用 2.07 J；GR00T N1.7 与 π0.5 分别仅 19.3 与 9.7 次/秒、13.7 与 31.7 J。即吞吐高 8–17 倍、能耗低 6–15 倍。
- **语言缓存的价值**：若每步都跑 NeoBERT，DEM 延迟升至 10.4 ms（96 次/秒）、能耗 3.09 J，仍是表中最快的策略。
- **视觉编码器微调是主要增益来源**：冻结 DINOv3 ConvNeXt-B 仅 32.6%，微调后 55.6%，相差 23 点；而所有微调编码器都落在 51.8%–55.6% 区间。用 VLM 自己的视觉塔（PaliGemma 2、Qwen3-VL）在同一协议下并未取得更高的点估计（53.9%、51.8%），却需约 5 倍参数、3 倍延迟、4 倍能耗。
- **语言编码器的贡献被明确界定**：无语言 token 仅 11.3%；用 one-hot 任务码替代指令为 37.4%；T5-base 44.5%、BERT-base 47.8%、mmBERT-base 50.6%、NeoBERT 55.6%。Gemma 2（55.0%）与 Qwen3-VL LM（54.3%）用 8–12 倍参数、2–3 倍编码延迟并未取得更高成功率。**微调 NeoBERT 无增益**（55.1% vs 55.6%），故保持冻结。
- **不依赖 MeanFlow 特定性**：在相同解耦表征与交叉注意力下，flow matching 54.7%、Diffusion Policy 53.8%、ACT 52.4%、MeanFlow 55.6%，四者互相在 3.2 点内；稳健结论是**计算性的**——MeanFlow 用 1 次头部评估（而非 10 或 16 次）达到最高点估计，约 163 次/秒、约 2.1 J。
- **动作分块非必需**：块长 16 与 8 时成功率为 55.6%/55.9%，降至每步重规划时为 50.6%，但仍高于 Table I 中除前三名外的所有策略。

- **技能制度的前提**：论文的结论严格限定在"已训练技能"这一制度下——即策略被训练执行一组固定的、语言条件化的操作技能。作者明确不主张解耦编码在一般意义上优于联合预训练，也不声称 DEM 具备开放世界泛化能力。对未见物体、未见任务或组合指令的泛化**未被测试**。
- **因果隔离不足**：主基准是系统级比较，基线保留各自的融合方式、动作模块与训练配方，因此"成功率可比"只能说明解耦方案在整体上不落后，**无法证明**"联合 vs 解耦编码"这一单一变量本身的因果效应。作者对此措辞克制，仅在消融内部做同动作头的受控对比。
- **统计强度有限**：每个配置只训练一次，报告误差只覆盖评估采样而非训练种子变异，故作者拒绝将小的成功率差异解读为排序。真实机器人每方法仅 50 次 rollout/任务，统计分辨率更低。
- **效率测量的边界**：延迟与能耗为**设备级估计**，不含相机采集、预处理、机器人通信与执行器功耗，也未扣除空闲功耗；因此 2.07 J 等数字应理解为前向计算的相对指标，而非端到端系统能耗。
- **训练成本未报告**：论文未给出训练时长、GPU 小时数或训练能耗，无法评估解耦方案在训练侧的成本优势或劣势。
- **语言缓存的适用条件**：token 缓存只在指令不变时有效；对频繁改写指令或需要在线语言推理的场景，缓存收益会退化（论文给出的每步运行 NeoBERT 的 10.4 ms 上界仍是表中最快，但优势收窄）。

## 8. 结论与更广的含义

- **核心主张**：当策略只需执行一组已训练的语言条件化技能时，用现代独立编码器（DINOv3 ConvNeXt-B + NeoBERT）替换联合融合的 VLM 骨干，可以在**保持观测成功率可比**的同时，把单次策略推理的吞吐提升 8–17 倍、能耗降低 6–15 倍，从而占据成功率–延迟–能耗前沿上的有利位置。
- **设计层面的启示**：
  - VLM 在低层操作策略中的主要作用是**提供图像与指令表征**，而 decoder-only 架构为自回归生成而放大的参数量对这一用途是结构性浪费。
  - 视觉编码器的**微调**是主要增益来源（+23 点），而语言编码器的贡献在 32 个 token、冻结状态下已接近饱和——语言侧"更大模型"的边际收益很低。
  - 计算效率的关键不在于动作头选择，而在于**动作头评估次数**：MeanFlow 以单次前向达到与 flow matching（10 步）、Diffusion Policy（16 步）相当的成功率。
  - 动作分块并非必需：块长降至 1 时仍保持 50.6%，说明解耦 + 快速头部已能在高频重规划下工作。
- **方法学层面的启示**：在组件水平已大幅进步的当下，早期通用策略的解耦设计值得重新审视；独立编码器的进步使"用编码器而非解码器提供表征"成为一个现实且高效的工程选择。
- **对社区的意义**：论文为语言条件化机器人技能提供了一个强而高效的基线，并给出了一套可复用的受控消融协议（固定数据、步数、任务集、评估与测量平台）。

## 9. 客观评价与遗留问题

- **优点**：
  - 问题设定清晰且有意限定范围，避免了"解耦优于联合"这类过强主张。
  - 消融维度覆盖视觉、语言、动作头、块长四个正交轴，且动作头参数匹配，受控程度高。
  - 同时报告仿真与真机结果，并给出延迟、吞吐、能耗三类效率指标，兼顾性能与部署现实。
  - 统计措辞克制，明确标注单种子训练的局限，并给出置信区间而非仅报点估计。
- **待澄清的问题**：
  - 训练侧成本（GPU 小时、能耗）缺失，无法完整评估解耦方案的全生命周期效率。
  - 端到端延迟（含感知、通信、执行）未测，6.1 ms 与 25–50 Hz 控制频率之间的实际匹配关系只能间接推断。
  - 语言缓存与指令变化的交互在真实交互场景中的表现未被系统研究。
  - 未测试技能组合、长时程任务或需要在线语言推理的场景，因此"固定技能"边界的鲁棒性未知。
  - 单训练种子意味着训练方差未知，小差异（如 DEM 与 GR00T 的 −1.3 点）的稳定性有待多 seed 验证。
- **总体判断**：这是一篇定位精准、实验设计克制、结论与证据匹配良好的工作。它的贡献不在于提出全新的学习范式，而在于用现代组件重新检验一个被忽视的设计选择，并以严格的受控实验量化其效率收益。其结论应被读作"在已训练技能制度下，解耦编码是成功率–效率前沿上的有利选择"，而非对联合预训练的普遍否定。
