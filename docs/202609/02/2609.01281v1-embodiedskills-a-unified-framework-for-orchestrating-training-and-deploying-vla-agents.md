## 摘要
视觉-语言-动作（VLA）模型将视觉观察和语言指令直接映射为机器人动作，但长时域任务需要的不仅仅是动作预测。智能体必须随着物理状态的演化协调感知、规划、执行、进度验证和恢复。动作预测或模型生成的技能决策本身并不能保证所提议的操作在当前状态下有效，也不能保证其执行结果会被验证。我们提出了EmbodiedSkills，一个统一框架，将每个技能决策视为一个执行提案：运行时在执行前检查其前置条件，并在执行后验证其结果。一个共享的可执行技能接口在单一智能体循环中连接了高层技能选择、受限的低层VLA执行和动作后验证。由于该接口保持固定，低层VLA策略可以在不改变智能体循环的情况下进行替换或适配。该接口还将规划、执行、验证和恢复事件记录为结构化轨迹，为各个组件提供监督，并在交互式反馈可用时支持可选的在线适配。我们在RoboTwin 2.0和LIBERO上使用Qwen3-VL和OpenPI/pi0.5实例化了EmbodiedSkills。任务适配的低层VLA策略在50个RoboTwin 2.0任务中平均成功率达到86.20%，在四个LIBERO套件中平均成功率达到97.40%。这些结果确立了EmbodiedSkills中使用的任务适配低层VLA策略的执行性能。在四个依赖记忆的RMBench任务中，相同的任务适配执行方法实现了12.5%的平均成功率。该框架提供了一个可训练且可检查的智能体层，用于将这些策略转化为闭环具身系统。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions directly to robot actions, but long-horizon tasks require more than action prediction. An agent must coordinate perception, planning, execution, progress verification, and recovery as the physical state evolves. An action prediction or a model-generated skill decision does not, by itself, guarantee that the proposed operation is valid in the current state or that its outcome will be verified. We propose EmbodiedSkills, a unified framework that treats each skill decision as an execution proposal: the runtime checks its prerequisites before execution and verifies the outcome afterward. A shared executable-skill interface connects high-level skill selection, bounded low-level VLA execution, and post-action verification within a single agent loop. Because this interface remains fixed, low-level VLA policies can be replaced or adapted without changing the agent loop. The interface also records planning, execution, verification, and recovery events as structured trajectories, which provide supervision for individual components and can support optional online adaptation when interactive feedback is available. We instantiate EmbodiedSkills with Qwen3-VL and OpenPI/pi0.5 on RoboTwin 2.0 and LIBERO. Task-adapted low-level VLA policies achieve an average success rate of 86.20% across 50 RoboTwin 2.0 tasks and 97.40% across the four LIBERO suites. These results establish the execution performance of the task-adapted low-level VLA policies used in EmbodiedSkills. On four memory-dependent RMBench tasks, the same task-adapted execution approach achieves 12.5% average success. The framework provides a trainable and inspectable agent layer for turning these policies into closed-loop embodied systems.

## 1. 论文的核心问题与整体含义

- **研究动机**：现有视觉-语言-动作（VLA）模型能够将视觉观察与语言指令直接映射为机器人动作，但其本质上只是"动作预测器"。在长时程（long-horizon）操作任务中，机器人需要的不只是下一步动作，而是要在物理状态不断变化的过程中，持续协调感知、规划、执行、进度验证和失败恢复等能力。
- **核心问题**：一个语义上合理的动作预测或技能决策，并不能保证该操作在当前物理状态下是合法的，也无法保证其执行后能产生预期的效果。即使在高层次引入了大语言模型（LLM）进行中间决策的机器人智能体方案中，显式的推理与工具调用仍然无法替代对物理状态的小心检查——模型可能提出了与当前阶段不兼容的技能、依赖了过时观测、遗漏了必要参数，或执行后并未产生预期结果。
- **总体含义**：论文主张在"模型级决策"与"物理级执行"之间建立一座坚实的桥梁——使得每个被提出的操作在执行前都经过前置条件检查，在执行后都有结果验证，并将这些记录为结构化证据，用于后续决策与学习。这构成了从"VLA 动作模型"到"闭环具身 VLA 智能体"的必要过渡框架。

## 2. 论文提出的方法论

### 2.1 核心思想

EmbodiedSkills 提出了一个统一框架，用于编排、训练和部署 VLA 智能体。其核心思路是：**将每一项技能决策视为一个"执行提案"（execution proposal）**——由高层策略提出，经运行时（runtime）校验通过后才实际执行。

### 2.2 三层结构

框架包含三个层次：
- **高层策略层**：由 VLM（如 Qwen3-VL）驱动，负责读取任务指令、当前视觉证据和循环状态，输出结构化的技能决策。
- **低层 VLA 策略层**：如 OpenPI/π0.5，将活动子目标（active subgoal）映射为有界动作块（bounded action chunk）。
- **守卫式运行时（Guarded Runtime）**：执行前置条件检查、产物新鲜度（artifact freshness）验证、状态合法性检验，保证非法操作不能被执行。

### 2.3 六阶段闭环智能体循环

框架由六个语义阶段构成，但**并非固定的线性流程**，而是根据状态动态路由：

| 阶段 | 作用 |
|---|---|
| Observe | 获取当前视觉证据，更新场景状态 |
| Plan | 将任务转化为可验证的子目标序列 |
| Preflight | 检查子目标是否具备执行条件 |
| Execute | 调用低层 VLA，生成并执行一个受限动作块 |
| Verify | 基于新鲜的事后观测评估子目标是否推进 |
| Recover | 根据失败证据修订执行上下文 |

### 2.4 关键技术细节

- **可执行技能契约**：每个技能定义为 `k=(Xk, Yk, pre_k, exec_k, post_k, fail_k)`，包含类型的输入输出、前置条件、执行操作、状态更新与失败映射。这一契约同时作为组合接口、运行时合法性边界和训练轨迹来源。
- **策略-运行时分离**：策略提出决策 `d_t ∈ {RunSkill(k,q), AdvanceStage, FinishRun}`，而运行时通过守卫函数 `G_skill`、`G_advance` 和 `G_finish` 分别判定操作是否合法。无效决策被阻断并记录，而不是被静默地翻译为物理动作。
- **受限动作执行**：每个动作块为有界指令序列 `a_t=(τ_t, U_t, H_t, η_t)`，需满足策略特定的动作模式、数值有效性、执行步数限制以及与当前子目标和观测的一致性检查。
- **验证路由机制**：Verify 阶段输出语义路由 `V={Advance, Continue, Reobserve, Replan, Recover, Finish}` 来决定下一步选择。
- **模块化训练**：每个组件可独立用监督学习适配——规划器、调度器、验证器、低层 VLA 策略分别训练，而不需要修改 AgentLoop 本身。训练样例采用"部署一致"（deployment-consistent）的输入边界构造，避免训练时看到测试时不存在的证据。
- **可选的在线强化学习**：支持以组相对策略优化（GRPO）方式进行闭环在线优化，但论文明确将其定位为**可选细化手段而非主要训练范式**。

## 6. 论文的主要结论与发现

1. **任务适配的 π0.5 策略在 RoboTwin 2.0 上平均成功率 86.20%**，比 LingBot-VA 报告的 π0.5 参考值（82.74%）高出 3.46 个百分点。在 50 个任务中有 39 个任务实现提升，最大增益出现在接触敏感与多阶段任务（如 Hanging Mug 提升 +20，Blocks Ranking Size +15 等）。
2. **LIBERO 四套件平均成功率 97.40%**，比 OpenPI 官方参考（96.85%）高 0.55 个百分点，在难度最高的 LIBERO-Long 套件上提升最大（92.4% → 93.6%）。
3. **RMBench 记忆依赖任务上平均成功率 12.5%**，显著高于对比列中最好结果（X-VLA 的 7.3%）。这证明了任务适配的 π0.5 策略在该类具有挑战性的任务上远超其他方法。
4. **消融实验量化了各机制的重要性**：移除语义子任务使成功率从 86.2% 降至 34.4%，移除验证使成功率降至 48.2%，单块执行更是降至 19.5%。这说明语义子目标分解、中间验证与自适应继续执行都是闭环系统中不可或缺的组成部分。
5. **框架的通用性**：同一执行接口可跨 RoboTwin 2.0 和 LIBERO 两个风格不同的操作基准工作，说明该统一接口与低层 VLA 策略解耦成功。

## 7. 优点

- **研究定位精准**：论文清晰地看到 VLA 策略作为动作预测器在真实闭环系统中面临的空白，提出的框架定义了任务分解中长时间未解决的一环，即"策略决策与物理执行之间的验证界限"。
- **"策略-运行时"分离是一个重要的架构贡献**：让高层策略输出与底层物理执行之间的语义鸿沟有了一个结构化的弥合方案——将文本提议与实体状态变更明确区分。
- **共享技能接口带来模块可替换性**：低层策略可替换、可适配而不改变 AgentLoop，规划器、调度器、验证器也可独立训练——这使框架在不同基座上具有良好的"即插即用"潜力。
- **消融设计非常出色**：干净地分离了三个关键机制（语义子目标、中间验证、自适应多块执行）的贡献，因果推理清晰可靠。
- **充分的诊断性**：结构化轨迹使失败可以在规划、感知、执行、验证等层面被准确定位，而非笼统地归因于"策略失败"。

## 8. 不足与局限

- **任务专属策略的工程成本高**：50 个任务需要训练 50 个策略，其训练、存储与部署开销远高于单一通用策略。作者将其归为限制，期望未来有更强的子目标条件通用 VLA 策略。
- **框架整体性能受限于底层 VLM 的标定质量**：即使运行时能阻断非法状态转换，也无法保证语义上合理但实际错误的决策（如错误的对象定位、不正确的子目标）不被执行——验证阶段在遮挡或视觉模糊场景下也可能产生不确定结论。
- **额外延迟**：多模态模型调用与事后观测验证增加了相对于单次前馈动作策略的推理延迟。
- **RMBench 结果依然很低**：12.5% 的成功率虽然优于所有对比方法，但它本身是一个不容回避的低数值，表明在视觉记忆依赖的任务上，当前方法仍远远不足。
- **对比公平性问题**：RoboTwin 2.0 上的成功建立在任务特化微调策略上，与通用策略相比较时需谨慎解读；其更高的成功率某种程度上是"以 50 倍的部署成本换 3.46 个百分点的提升"，读者需要权衡这一成本-收益关系。
- **在线强化学习仅作定性介绍**：论文中对可选的在线优化部分仅提供了公式化描述而缺乏实证（事实上连公式的详细介绍都只是示意性的），因此难以验证其在"闭环优化智能体层"这一目标上的实际效力。
- **未提供真实机器人验证**：所有实验均在仿真环境中评价，真实世界的可迁移性尚缺乏直接证据。

## 总结

EmbodiedSkills 的核心贡献不在于提升底层 VLA 策略的性能，而在于为 VLA 策略提供了**可编排、可训练、可检查的闭环具身智能体层**。它通过可执行技能契约实现了高层决策与低层物理执行之间安全、可诊断的桥接。虽然任务专属策略的部署方式具有较高的资源开销，RMBench 上的低绝对成功率也显示了该方法的不足，但其框架的消融结果扎实、设计思路清晰，为在仿真中构建可靠、可调试的长期任务机器人系统提供了一个统一、通用且具有实际意义的架构基座。
