## 摘要
移动操作需要为底盘运动和机械臂控制提供不同空间尺度上的感知证据，而这两种动作模态在运动学上仍然相互耦合。现有策略通常针对不同子系统采用专门的动作生成，却让异构的动作分支以共享的感知表示为条件，从而使子系统特定的感知-动作对应关系保持隐式。我们提出 MoPA，一个将感知条件与移动和操作分别对齐，同时在动作层面保持协调的框架。双感知流采用两个相互掩码的查询库，从共享的视觉-语言上下文中提取各自独立的感知表示。感知到动作的适配在结构化 Mixture-of-Transformers 解码器的每一层中联合更新每个查询库及其对应的动作流，同时允许两个动作流之间进行信息交换。耦合条件流匹配学习一个联合向量场，以协调生成两个动作块。在 ManiSkill-HAB 基准上，MoPA 在所有三个任务套件上均达到最先进性能。在四个真实世界任务中，MoPA 取得 76.3% 的平均全任务成功率，比最佳基线高出 12.5 个百分点。消融研究和进一步分析验证了所提出设计的有效性。网站见：https://mopa-policy.github.io/。

## Abstract
Mobile manipulation requires perceptual evidence at different spatial scales for base motion and arm control, while the two action modalities remain kinematically coupled. Existing policies often employ specialized action generation for different subsystems but condition heterogeneous action branches on a shared perceptual representation, leaving subsystem-specific perception-action correspondence implicit. We present MoPA, a framework that aligns perceptual conditioning with mobility and manipulation while preserving coordination at the action level. Dual Perceptual Streams employ two mutually masked query banks to extract separate perceptual representations from a shared vision-language context. Perception2Action Adaptation jointly updates each query bank and its corresponding action stream at every layer of a structured Mixture-of-Transformers decoder, while enabling information exchange between the two action streams. Coupled conditional flow matching learns a joint vector field for coordinated generation of both action chunks. On the ManiSkill-HAB benchmark, MoPA achieves state-of-the-art performance across all three task suites. Across four real-world tasks, MoPA achieves a mean full-task success rate of 76.3%, outperforming the best baseline by 12.5 percentage points. Ablation studies and further analyses validate the effectiveness of the proposed design. Website is available at: https://mopa-policy.github.io/.

## 1. 核心问题与整体含义（研究动机和背景）

- **研究背景**：移动操作（Mobile Manipulation）要求机器人在非结构化家庭环境中，一边在多个工作空间之间移动，一边与物体交互。与固定基座桌面操作不同，移动操作需要同时控制移动底盘和机械臂，二者通过单一运动学链耦合：底盘位姿误差会传播到末端执行器，而机械臂的可达性又约束底盘的可行运动。
- **核心痛点**：底盘依赖场景级几何信息进行重定位，机械臂依赖局部几何和交互状态进行精确控制，二者强调的感知空间尺度不同。然而现有策略通常为不同子系统设计专门的动作生成分支（如分层/并行解码器、token 路由、专用 Transformer 流），却让这些异构动作分支共享同一个或全局融合的感知表示，导致“子系统特定的感知–动作对应关系”始终是隐式的。
- **深层问题**：
  - 共享表示必须同时编码场景布局和局部交互几何，但二者空间尺度不同；
  - 即使分开动作头，两个分支的损失仍会更新共享投影/融合层，可能引发多任务优化中的梯度冲突；
  - 直接给多个动作分支提供融合特征，等于给所有专家相同的、未区分的条件；让动作 token 独立从完整感知序列检索信息，又需要反复访问大 token 集合，且缺乏与特定动作空间对齐的持久中间表示。
- **整体含义**：论文主张移动操作需要一个机制，从共享视觉–语言上下文中派生**子系统特定**的感知表示，在动作生成过程中持续更新这些表示，同时在动作层面保留底盘与机械臂之间的协调。MoPA 正是围绕这一思路提出的框架。

## 2. 论文提出的方法论

### 2.1 核心思想

MoPA 包含两个互补模块：
- **Dual Perceptual Streams（双感知流）**：从共享的 Qwen3-VL 视觉–语言上下文中，用两个相互掩码的查询库（Manip Query / Mobile Query）分别提取操作与移动的感知表示。
- **Perception2Action Adaptation（感知到动作适配）**：在结构化 Mixture-of-Transformers（MoT）解码器的每一层，联合更新每个查询库及其匹配的动作流，同时允许两个动作流交换信息。

整体分三阶段：Qwen3-VL 编码共享视觉–语言 token → 双查询库提取分支特定感知流 → 结构化 MoT 解码器配对感知流与动作流 → 耦合条件流匹配同步生成两个动作块。本体感知（proprioception）绕过 VLM，在每个动作分支中单独编码。

### 2.2 关键技术细节

**问题形式化**：在时刻 t，策略接收头部与腕部 RGB 图像、本体状态 s_t 和语言指令 ℓ，预测全身动作块 A_t = (A_t^man, A_t^mob)，建模条件分布 p_Θ(A_t^man, A_t^mob | I_t^head, I_t^wrist, s_t, ℓ)。操作分支控制臂/夹爪，移动分支控制躯干/底盘；联合建模使策略能从全身演示中直接学习协调。

**Dual Perceptual Streams**：
- 设共享视觉–语言 token 序列为 P_t，学习到的 Manip Query 库 Q_Manip 和 Mobile Query 库 Q_Mob 被追加到 P_t 之后：Z_t = [P_t, Q_Manip, Q_Mob]。
- 两个查询库都关注 P_t，但彼此之间的直接注意力被掩码（Mutual Masking）。它们通过不同路径聚合同一上下文，最终隐藏状态 H_t^Manip 和 H_t^Mob 只路由到各自匹配的动作流。
- 不同学习嵌入、独立聚合路径、以及来自对应动作分支的监督，共同促使每个查询库保留与其控制目标相关的信息。

**Perception2Action Adaptation**：
- 独立投影器将感知状态映射到动作模型特征空间：Q_{t,0}^q = Φ^q(H_t^q)，q ∈ {Manip, Mob}。
- 每个分支 k ∈ {man, mob} 在流时间 τ 下拼接本体感知 token 与动作 token：X_{τ,0}^k = [E_s^k(s_t) + e_s^k, E_a^k(A_τ^k, τ) + E_pos^k]；投影器 Φ^q 与编码器 E_s^k、E_a^k 均为分支特定，e_s^k 是状态 token 类型嵌入，E_pos^k 是动作 token 位置嵌入。
- 结构化 MoT 解码器有 L 个块，第 l 块 B_l 执行联合更新：(Q_{t,l+1}^Manip, Q_{t,l+1}^Mob, X_{τ,l+1}^man, X_{τ,l+1}^mob) = B_l(Q_{t,l}^Manip, Q_{t,l}^Mob, X_{τ,l}^man, X_{τ,l}^mob; τ)。
- 每个流拥有自己的投影、归一化和前馈参数；每次速度场评估时查询状态由上式初始化，并在每一层与动作 token 联合更新，从而从感知摘要演变为动作条件控制状态。

**Coupled Conditional Flow Matching（耦合条件流匹配）**：
- 对每个分支 k，A_1^k ≡ A_t^k 为干净演示块，A_0^k 为独立同分布标准高斯噪声块；两个分支的干净块来自同一演示区间，保持时间对应关系。
- 共享流时间 τ ~ U(0,1)，线性插值与常数目标速度：A_τ^k = (1-τ)A_0^k + τA_1^k，U^k = A_1^k - A_0^k。
- 联合动作头 G_ψ 预测两分支速度：(Û^man, Û^mob) = G_ψ(Q_{t,0}^Manip, Q_{t,0}^Mob, X_{τ,0}^man, X_{τ,0}^mob; τ)。
- 损失函数为分支归一化的流匹配目标：L_FM = E[Σ_{k∈{man,mob}} λ_k/(H d_k) · ||Û^k − U^k||_F²]，其中 λ_k 平衡分支贡献，除以 H d_k 防止高维分支仅因通道数多而主导目标。
- **推理**：两个动作块从独立高斯噪声出发，用 N 步欧拉积分同步更新：A_{τ_{n+1}}^k = A_{τ_n}^k + (1/N)Û_n^k；两个速度均基于更新前的同一对动作块评估。τ_N = 1 时拼接为全身动作块，执行初始动作后从更新观测重新规划。

## 4. 主要实验结果

### 4.1 仿真基准表现

- **总体趋势**：MoPA 在三个任务套件上均取得最优或接近最优的平均成功率，尤其在需要“先移动、再精细操作”的长程任务（TidyHouse、PrepareGroceries）上优势更明显。相比 π0、π0.5 等大规模 VLA 基线，MoPA 以更小的模型规模和更少的训练数据取得了有竞争力的结果。
- **与视觉运动策略对比**：DP3*、DP、ACT 等仅使用几何/深度输入的方法在需要语义泛化的任务上明显落后；AC-DiT*、GeoHAT*、InCoM* 等引入深度或结构化动作建模后有所提升，但仍未显式区分移动与操作子系统的感知表示。
- **与世界–动作模型对比**：MobileWAM 在部分短程技能上接近 MoPA，但在跨工作空间的长程任务中，由于缺乏分支特定的感知–动作对齐，误差累积更快。
- **技能级分析**：在 Open Fridge、Open Drawer、Close Drawer 等需要底盘精确定位到交互点的技能上，MoPA 的移动分支感知流起到关键作用；在 Pick/Place 等操作技能上，操作分支感知流对局部几何与夹爪状态更敏感。

### 4.2 真实世界实验表现

- **总体趋势**：MoPA 在四个真实任务上均取得较高成功率，且在跨桌转移（Cross-Table Fruit Transfer）与微波炉取物（Microwave Object Retrieval）等需要大范围移动 + 精细操作的任务上，相较基线方法的优势更为突出。
- **鲁棒性**：在物体位置、光照和初始底盘位姿存在扰动的情况下，MoPA 的成功率下降幅度小于基线，说明分支特定感知表示有助于抑制底盘位姿误差向末端执行器的传播。
- **失败模式**：主要失败集中于夹爪遮挡导致的视觉歧义、以及长程任务中段的重规划延迟，而非全身协调本身。

## 5. 消融与分析

### 5.1 模块消融

- **去掉 Dual Perceptual Streams**（所有动作分支共享同一感知表示）：成功率显著下降，说明“子系统特定感知表示”是核心增益来源。
- **去掉 Mutual Masking**（两个查询库可互相注意）：性能下降，验证了相互掩码在保持分支独立聚合路径中的作用。
- **去掉 Perception2Action Adaptation**（感知流仅在解码前提供一次，不在每层与动作流联合更新）：性能下降，表明感知表示需要在动作生成过程中持续演化。
- **去掉 Coupled Conditional Flow Matching**（两分支独立训练/独立采样）：协调性下降，尤其在需要底盘与机械臂同步的任务中误差累积明显。

### 5.2 损失权重与归一化

- 分支归一化项（除以 H·d_k）对平衡高维移动动作与低维操作动作的梯度贡献至关重要；去掉后高维分支主导损失，操作精度下降。
- 权重 λ_k 的取值对结果有一定敏感性，但整体趋势稳健。

### 5.3 表示分析

- 可视化显示，Manip Query 的注意力更集中于腕部视角、目标物体与夹爪附近区域；Mobile Query 的注意力更集中于头部视角中的场景布局、可行走区域与目标交互点。
- 这种分工是在训练中自发涌现的，而非人工指定，进一步支持了“从共享上下文中派生子系统特定表示”的设计动机。

## 6. 贡献与创新点

- **问题层面**：明确指出移动操作中“异构动作分支共享同质感知表示”是长期被忽视的瓶颈，并给出可诊断的分析（尺度冲突、梯度冲突、条件未区分）。
- **方法层面**：提出 Dual Perceptual Streams，用相互掩码的查询库从共享 VLM 上下文中派生分支特定感知表示；提出 Perception2Action Adaptation，在结构化 MoT 解码器每层联合更新感知流与动作流；提出 Coupled Conditional Flow Matching，同步生成耦合的移动与操作动作块。
- **实验层面**：在 ManiSkill-HAB 三个套件与真实双臂移动平台上系统验证，并与主流视觉运动策略、VLA 策略和世界–动作模型对比，辅以充分消融。

## 7. 局限性与未来方向

- **局限性**：
  - 感知流数量与动作分支数量绑定，扩展到更多子系统（如多臂、灵巧手）时查询库设计需要重新考虑；
  - 依赖大规模 VLM 编码共享上下文，推理成本较高；
  - 真实世界实验任务规模有限，尚未覆盖高度动态或人机协作场景。
- **未来方向**：将双感知流推广到任意数量的子系统；探索更轻量的共享上下文编码；在动态环境和长期自主任务中验证。

## 8. 总结

MoPA 的核心洞见是：移动操作的协调问题不仅在于“动作如何协调”，更在于“感知如何为不同子系统分别服务”。通过在共享视觉–语言上下文之上引入分支特定、可随动作生成持续演化的感知表示，并在动作层面以耦合流匹配保持协调，MoPA 在仿真与真实平台上均展现出优于现有方法的性能与鲁棒性。该工作为移动操作策略设计提供了一个清晰且可扩展的“感知–动作对应关系显式化”范式。
