## 摘要
基础视觉-语言模型（VLM）展现出关于世界的广泛智能，但将这种智能转化为机器人控制仍然具有挑战性。我们提出 Show-Harness，一种具身 Harness（Embodied Harness），使 VLM 能够通过一个连接意图与动作的紧凑语义接口来“玩”机器人。Show-Harness 暴露离散的语义动作单元，VLM 可以自然地对其进行推理，而具身特定的解释器确定性地将它们落地为本地机器人动作，从而使 VLM 直接负责细粒度的物理决策。通过同一接口，Show-Harness 证明了以下可行性：(1) 直接解锁闭源前沿 VLM 用于零样本机器人控制；(2) 仅需几个 GPU 小时的微调即可适配小规模开源 VLM 以实现低成本部署。我们进一步开发了 GUMI（GUI 操作接口，GUI Manipulation Interface），它将相同的语义动作空间扩展到基于 GUI 的演示收集，使人类和智能体无需专门的遥操作硬件即可跨具身“玩”机器人。大量实验表明，配备 Show-Harness 的 VLM 智能体在任务、具身和环境之间具有稳健的泛化能力，优于代表性的智能体范式和 VLA 范式。这些结果表明，正确的接口可以从基础 VLM 中释放可观的具身能力，而无需额外的模型容量或昂贵的具身特定预训练。

## Abstract
Foundation vision-language models (VLMs) exhibit broad intelligence about the world, yet translating this intelligence into robot control remains challenging. We present Show-Harness, an Embodied Harness that enables VLMs to "play" robots through a compact semantic interface linking intent to action. Show-Harness exposes discrete semantic action units that VLMs can naturally reason over, while embodiment-specific interpreters deterministically ground them into local robot actions, keeping the VLM directly responsible for fine-grained physical decisions. Through the same interface, Show-Harness demonstrates the feasibility of (1) directly unlocking closed-source frontier VLMs for zero-shot robot control, and (2) adapting small-scale open-source VLMs for low-cost deployment with just a few GPU-hours of fine-tuning. We further develop GUMI (GUI Manipulation Interface), which extends the same semantic action space to GUI-based demonstration collection, allowing humans and agents to "play" robots across embodiments without specialized teleoperation hardware. Extensive experiments show that Show-Harness-equipped VLM agents generalize robustly across tasks, embodiments, and environments, outperforming representative agentic and VLA paradigms. These results suggest that the right interface can unlock substantial embodied capability from foundation VLMs, without requiring additional model capacity or costly embodiment-specific pretraining.

## 1. 核心问题与研究动机

- **背景**：基础视觉–语言模型（VLM）已编码大量机器人操作所需知识（物体识别、空间关系、长程目标分解），但这类知识难以直接转化为机器人行为。
- **现有两条路线的困境**：
  - **VLA 路线**：把 VLM 微调为回归本体特定连续动作，将广泛语义知识坍缩为不透明的"像素→驱动"映射，跨任务/环境/本体需反复适配。
  - **分层/程序化路线**：VLM 输出子任务调用或手写控制 API 程序，物理控制由下游控制器中介，削弱了语义意图与物理执行之间的直接联系。
- **核心论点**：把基础模型智能带入物理世界需要一个**合适的接口**——动作空间既要对 VLM 语义上有意义，又要足够细粒度以支持直接物理控制。
- **整体含义**：Show-Harness 是一个模型无关的具身 Harness，让 VLM 通过紧凑语义接口直接"玩"机器人；同一接口同时支持零样本前沿模型与轻量微调小模型，并自然统一了人类 GUI 控制与智能体控制。

## 2. 方法论

### 2.1 核心思想：语义动作接口

- 将机器人控制重构为**离散语义动作单元集合 A**，每个单元对应一个可直接解释的末端执行器运动或夹爪意图，不向模型暴露本体特定控制变量。
- **动作词汇表**：
  - 平移：`MV_FWD/MV_BACK`、`MV_LEFT/MV_RIGHT`、`MV_UP/MV_DOWN`（相对参考视图定义方向）。
  - 旋转：`ROTATE_CW/ROTATE_CCW`，配合指定轴（x/y/z），每次增量旋转。
  - 夹爪：`GRASP` / `RELEASE`；完成：`DONE`。
- **词汇设计三性质**：(i) **增量式**——每单元引起小的局部物理变化，使 VLM 处于控制回路中，可通过连续修正实现精确行为；(ii) **可解释且本体无关**——用语义符号而非数值目标，低层控制下放给解释器；(iii) **视觉接地**——运动方向相对可观测视图定义，使空间推理可映射为动作。

### 2.2 具身接地（Embodiment Grounding）

- 每个语义决策 $a_t \in A$ 交给**本体特定解释器** $g_E$，确定性地落地为机器人控制。
- 位姿设定点更新公式：

$$s_{t+1} = \Pi_E\big(x_t + \sigma_t R_E d_a,\ \exp(\theta_t [R_E r_a]_\times) Q_t\big)$$

  - $x_t \in \mathbb{R}^3$、$Q_t \in SO(3)$ 为位置与姿态；$d_a$、$r_a$ 编码平移/旋转方向（旋转时 $d_a=0$，平移时 $r_a=0$）。
  - $\sigma_t$、$\theta_t$ 为校准后的平移/旋转增量；$R_E$ 将语义方向映射到本体运动帧。
  - $\Pi_E$ 强制工作空间与单步平移/旋转限制；违反安全边界的动作在执行前被阻止。
- 夹爪单元绕过位姿更新，直接映射为开/合命令。
- 不同本体用不同低层控制器实现同一语义单元：Franka 用阻抗控制跟踪笛卡尔设定点，AgileX 用逆运动学+关节目标流，仿真器执行操作空间命令。**适配新本体只需新解释器**。

### 2.3 感知–推理–动作闭环

- 每步：观察 $o_t=(I_t, p_t)$ → 推理插件 $P$ 生成精炼上下文 $c_t=\Phi_P(\ell,o_t,h_t)$ → VLM 选择 $a_t=\pi(c_t)$ → 解释器 $u_t=g_E(a_t;s_t)$ → 执行后反馈新观察与状态。
- **插件体系**（Table 1）：
  - **感知**：Multi-View Guidance（多视角角色与优先级）、Proprioception（将机器人状态/接触/夹爪状态转文本反馈）。
  - **推理**：Subtask Planning（有序子任务+可视化完成判据）、Situated Planning（延迟不确定决策、按需重规划）、Action Chunking（自适应动作分块）、Adaptive Step（自适应步长）、Visual Prompt（将模糊语言目标转为视觉标记）。
  - **动作**：Action History（最近动作摘要，抑制振荡）、Failure Recovery（检测抓取失败并回滚恢复）。

### 2.4 两种控制模式

- **ZS 模式**：前沿闭源 VLM 无需微调直接通过 Harness 控制机器人，继承前沿模型进步。
- **FT 模式**：微调小开源 VLM 直接预测语义动作单元，损失为 token 级交叉熵：

$$L(\theta) = -\sum_{(\ell,o,h,a)\in D} \log \pi_\theta\big(a \mid \Phi_{P_{\min}}(\ell,o,h)\big)$$

  - $P_{\min}$ 只保留最小决策上下文（任务指令、多视角观察、短动作历史）。
  - 语义动作通过 VLM **原生词表**预测，无专用动作头或特殊 token，支持低秩适配（rank-64 LoRA，仅更新约 3% 参数）。

### 2.5 GUMI：GUI 操作接口

- 因语义动作空间离散且可直接操作，可暴露为轻量 GUI：每个单元映射为带标签控件与键击。
- 人类用键盘"玩"机器人，computer-use 智能体操作同一 GUI，VLM 智能体直接预测单元。
- 每步记录执行前观察与所选语义动作，得到策略可用对 $(o_t, a_t)$；也可保留低层命令与轨迹，使同一演示可同时训练语义动作策略与连续控制策略。
- 支持步进控制、队列动作块、单/双臂操作、人机混合采集；无需专用遥操作硬件，跨本体复用，支持远程采集。
