## 摘要
人形机器人移动操作要求机器人在执行协调的全身运动的同时理解任务指令和场景语义。我们提出了一种分层框架，将运动关键帧用作视觉语言模型（VLM）规划与强化学习（RL）控制之间的中间表示。每个关键帧指定一个目标全身机器人位姿，并在适用时指定一个物体位姿。给定语言指令、场景观测和执行反馈，VLM 从预定义库中选择连续的、与任务相关的关键帧。所选关键帧会被重定向到当前场景，以考虑物体位姿和尺寸。然后，一个以关键帧为条件的全身策略生成关节级动作以达成这些目标。我们引入了一种基于显著性的关键帧采样策略用于底层策略训练，该策略在使用稀疏 VLM 关键帧时将端到端任务成功率从 44% 提升到 92%。我们在仿真中以及 Unitree G1 人形机器人上，在物体拾取、运输和放置任务上评估了我们的框架。该系统成功执行单手和双手操作，并能泛化到训练参考数据之外的放置位置。

## Abstract
Humanoid loco-manipulation requires robots to interpret task instructions and scene semantics while executing coordinated whole-body motions. We propose a hierarchical framework that uses motion keyframes as an intermediate representation between Vision-Language Model (VLM) planning and Reinforcement Learning (RL) control. Each keyframe specifies a target whole-body robot pose and, when applicable, an object pose. Given a language instruction, scene observations, and execution feedback, the VLM selects successive task-relevant keyframes from a predefined library. The selected keyframes are retargeted to the current scene to account for object poses and dimensions. A keyframe-conditioned whole-body policy then generates joint-level actions to reach these goals. We introduce a saliency-based keyframe sampling strategy for low-level policy training that improves end-to-end task success rate from 44% to 92% when using sparse VLM keyframes. We evaluate our framework on object pickup, transport, and placement tasks in simulation and on a Unitree G1 humanoid. The system successfully performs both one- and two-handed manipulation and generalises to placement locations beyond the training reference data.

# KINO 论文总结

## 1. 核心问题与整体含义

- **研究动机**：人形机器人移动操作（loco-manipulation）要求同时理解语言指令与场景语义，并执行协调、动态可行的全身动作。高层任务规划与低层运动控制之间存在明显鸿沟。
- **背景问题**：
  - VLM 擅长语言理解、视觉推理和任务分解，但输出是语义级目标，难以直接对应关节级控制。
  - VLA 模型可直接从图像和指令预测动作，但需要大量机器人特定交互数据，采集成本高，且扩展到高频、高维人形全身控制困难。
  - RL 可学习鲁棒的低层全身控制，但端到端扩展到长时程、多技能任务仍困难。
  - 现有运动跟踪/模仿方法通常需要完整参考运动轨迹，难以直接用于真实场景中的在线规划。
- **核心含义**：KINO 提出以“运动关键帧”作为 VLM 高层规划与 RL 低层全身控制之间的紧凑中间接口，从而避免端到端 VLA 对大规模机器人数据的需求，同时保留 VLM 的语义推理能力。

## 2. 方法论

### 2.1 核心思想

- 采用分层框架：
  1. **VLM 规划器**：根据语言指令、场景观测和机器人执行反馈，从预定义关键帧库中选择下一个任务相关关键帧。
  2. **关键帧重定向**：将库中的通用关键帧适配到当前场景中物体的位姿与尺寸。
  3. **关键帧条件全身策略**：接收重定向后的关键帧目标，输出关节级动作，驱动机器人完成该全身位姿。
- 关键帧表示机器人全身目标位姿；若涉及操作，还包含物体目标位姿。它比完整轨迹稀疏，比语言指令更结构化，可直接作为 RL 目标。

### 2.2 关键帧条件策略

- 将低层执行建模为**目标条件强化学习**问题。
- 策略观测包括：
  - 机器人状态：基座局部线速度、角速度、投影重力、关节位置与速度；
  - 物体状态：物体局部位置与四元数；
  - 上一动作；
  - 当前关键帧目标。
- 关键帧目标包含：目标根位置、目标根朝向、目标关节角、目标物体位置与朝向。若不涉及物体，则物体目标置零。
- 策略输入使用过去 10 帧观测历史。
- 采用**非对称 actor-critic**：
  - Critic 额外获得特权信息，如参考运动状态、当前状态与目标误差、剩余时间等；
  - Critic 使用 3 帧时间历史；
  - 部署时策略仅使用真实可获取的观测。
- 使用 **PPO** 训练。
- 奖励分为三组：
  - 参考跟踪奖励：按 DeepMimic 形式跟踪参考根位姿、速度、关节配置、身体位姿及物体位姿；
  - 关键帧到达奖励：仅在目标时间激活，鼓励到达关键帧；
  - 正则化奖励：惩罚力矩、动作变化率、关节加速度、脚部滑动等。
- 使用**多 critic 形式**，为跟踪、目标到达、正则化分别设置价值函数，缓解不同奖励组之间的负干扰。
- 动作输出为 29 维目标关节位置，由 PD 控制器跟踪。
- 为缩小 sim2real 差距，训练中使用域随机化：摩擦、物体与机器人质量、质心偏移、执行器增益、关节参数、执行器延迟、观测噪声、外部推力等。

### 2.3 显著性关键帧采样

- 训练时以参考运动中的代表性帧作为关键帧目标。
- 均匀采样的问题：移动操作包含接近、抬起、运输、放置等不同阶段，均匀采样会被大量行走/接近的中间帧主导，稀疏关键帧目标训练不足。
- 提出基于显著性的采样：
  - 计算选定机器人身体的聚合加速度信号，经低通滤波后取局部极大值，得到候选关键帧；
  - 过滤由周期性腿部运动引起的候选，避免把普通行走中间状态当作关键阶段；
  - 利用物体垂直加速度峰值识别物体事件候选；
  - 保留与物体事件在时间容差内重合的候选，并补充未与机器人候选重合的物体事件候选；
  - 最终显著关键帧集合包含起始帧、终止帧、筛选后的机器人事件候选和新增物体事件候选。
- 该策略使训练关键帧分布更接近 VLM 推理时选择的稀疏关键帧。

### 2.4 关键帧库、场景对齐与路径规划

- **关键帧库**：
  - 每个关键帧对应一个语义运动阶段，如接近物体、下蹲拾取、抬起、搬运等；
  - 包含机器人全身位姿及适用时的物体位姿，定义机器人-物体标称空间关系；
  - 每个关键帧配有自然语言描述，供 VLM 选择。
- **关键帧重定向**：
  - 源关键帧定义在源物体坐标系下；
  - 根据目标物体中心、朝向和包围盒半尺寸，将末端执行器与机器人根位置变换到目标物体坐标系；
  - 变换保持点相对于源物体的归一化位置，同时适应目标物体位姿与尺寸；
  - 机器人根仅更新水平坐标；
  - 使用迭代阻尼最小二乘逆运动学恢复其余关节配置，并加入脚部高度约束。
- **路径规划**：
  - 在初始与目标移动关键帧之间构造中间关键帧序列；
  - 使用切线对齐圆弧，必要时使用最短有效 Dubins 路径；
  - 曲率限制为 3 m⁻¹，对应最小转弯半径约 0.33 m；
  - 密集采样路径后贪婪选择中间目标，限制航向变化不超过 45°、欧氏位移不超过 2 m。

### 2.5 VLM 规划器

- 输入：
  - 用户语言指令；
  - 第三人称视角场景图像；
  - 结构化规划上下文，包括上一关键帧、上一目标是否完成及成功、当前机器人根位姿、当前物体位姿、目标物体位姿、控制器诊断误差等。
- 输出为结构化 JSON，例如：
  - `keyframe`：选择的关键帧名称；
  - `object_to_manipulate`：是否涉及物体操作；
  - `task_complete`：任务是否完成。
- 闭环执行：
  - 事件驱动循环；
  - 仅当机器人与物体达到静止状态、上一目标有足够执行时间后，才向 VLM 发起新查询；
  - 若上一关键帧成功到达，则进入下一语义阶段；否则可重试或选择恢复关键帧；
  - VLM 可基于视觉与误差判断失败并重新发送上一关键帧，实现失败恢复。

## 6. 主要结论与发现

- 关键帧可作为 VLM 语义规划与全身 RL 控制之间的有效、紧凑、可解释接口。
- 显著性关键帧采样显著提升稀疏 VLM 关键帧下的端到端任务成功率：从均匀采样的 **44%** 提升到 **92%**。
- 在仿真与 Unitree G1 真机上，系统可完成单手和双手的拾取

-运输-放置任务；VLM 在闭环中能够根据执行反馈选择下一关键帧，并在检测到目标未达成时重发上一关键帧，从而实现一定程度的失败恢复。

- **关键帧接口的有效性**：实验表明，将 VLM 的语义输出压缩为“关键帧”这一中间表示，既保留了任务分解所需的语义信息，又为 RL 策略提供了可直接优化的结构化目标。相比让 VLM 直接输出关节动作或完整轨迹，该接口更稳定、更易学习，也更便于模块化替换与调试。
- **稀疏关键帧下的训练—推理分布匹配**：显著性采样使训练时的关键帧分布与 VLM 推理时实际选择的关键帧分布更接近。论文认为，这是端到端成功率从均匀采样的 44% 提升到 92% 的主要原因，而非单纯增加训练数据或调整奖励。
- **目标到达精度**：表 II 显示，显著性采样在 Approach、Pick、Place 各阶段均降低了根位置误差、关节 RMSE 与物体位置误差；尤其在 Place 阶段，样本数从 63 增至 93，说明更多试验能够走到最终阶段，间接反映中间阶段失败的减少。
- **放置位置泛化**：网格化放置实验表明，策略在训练参考数据覆盖范围之外的一定区域内仍能保持较高成功率，但成功率随目标位置远离训练分布而下降，说明泛化能力存在边界。
- **真机可行性**：在 Unitree G1 上，系统能够以本体感知获取机器人状态、以外部动捕估计物体位姿，完成单手与双手的拾取—运输—放置。这验证了“关键帧 + RL 全身控制”路线在真实硬件上的可部署性，尽管真机实验仍以演示为主。

## 7. 局限与不足

- **关键帧库依赖人工设计**：每个关键帧对应一个语义运动阶段，需要人工定义机器人全身位姿、物体标称关系及自然语言描述。新增技能或新物体类别时，可能需要重新设计关键帧库，限制了系统的开放世界扩展能力。
- **物体位姿依赖外部感知**：真机实验中物体相对位姿由动捕系统提供，未验证仅凭机载视觉即可完成闭环。若替换为真实视觉估计，误差与延迟可能影响重定向精度和 VLM 决策。
- **重定向假设较简化**：重定向主要依据目标物体的中心、朝向与包围盒半尺寸进行归一化变换，并假设机器人—物体标称空间关系可迁移。对于铰接物体、可变形物体或形状差异较大的物体，该方法可能失效。
- **缺少强基线对比**：论文未与端到端 VLA、完整运动跟踪/模仿方法或其他分层规划方法进行定量对比，因此难以判断 KINO 相对现有路线的绝对优势。
- **消融覆盖有限**：核心消融仅围绕关键帧采样策略，未系统分析关键帧库规模、VLM 模型选择、重定向方式、多 critic 结构、奖励权重等设计选择的影响。
- **训练细节披露不足**：低层 RL 策略的训练 GPU 型号、数量、时长、并行环境数、PPO 步数等均未给出，影响复现与算力评估。
- **真机统计不足**：真机实验未报告试验次数、成功率与失败模式统计，更多是可行性演示而非严格评估。
- **任务范围较窄**：实验集中在单手/双手的拾取—运输—放置，尚未覆盖需要精细接触、工具使用、多物体交互或长时程多阶段任务。
- **VLM 推理频率受限**：闭环采用事件驱动、等待机器人/物体静止后再查询 VLM，虽然降低了调用频率，但也可能限制动态环境下的响应速度与连续操作能力。

## 8. 启示与未来方向

- **中间表示的价值**：KINO 的核心贡献不在于某个单一模型，而在于提出“运动关键帧”这一介于语义与关节控制之间的中间表示。它提示：在具身智能中，选择合适的中间抽象可能比单纯扩大端到端模型更有效。
- **VLM 与 RL 的分工**：VLM 负责“做什么、按什么顺序做”，RL 负责“如何动态可行地做到”，两者通过结构化关键帧解耦。这种分工降低了对机器人特定交互数据的需求，也便于分别升级各模块。
- **训练分布对齐的重要性**：显著性采样说明，即使策略与接口设计不变，训练目标分布与推理时目标分布的匹配程度也会显著影响端到端表现。这一经验可推广到其他“稀疏目标条件”的机器人学习问题。
- **可扩展方向**：
  - 自动发现或生成关键帧，减少人工库设计；
  - 用 VLA 或视频模型生成候选关键帧，再由 RL 验证可行性；
  - 引入在线视觉物体位姿估计，替代动捕依赖；
  - 扩展到铰接/可变形物体、多物体与工具使用场景；
  - 与端到端 VLA 进行更严格的定量对比与互补结合。
- **总体评价**：KINO 在方法层面清晰、模块化，核心思想具有较强可迁移性；实验在仿真中提供了有说服力的消融与泛化结果，并完成了真机验证。但其外部对比、训练细节披露与真机统计仍显不足，距离全面证明该路线优于现有方案还有差距。作为一项面向人形机器人 loco-manipulation 的系统性工作，它更重要的贡献是提供了一种可解释、可复用的分层接口范式。
