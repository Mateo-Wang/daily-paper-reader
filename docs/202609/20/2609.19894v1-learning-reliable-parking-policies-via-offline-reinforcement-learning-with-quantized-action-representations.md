## 摘要
泊车对在城市环境中运行的自动驾驶车辆而言是一项常规但安全攸关的任务。然而，杂乱且弱结构化的泊车空间，加之来自周围车辆的交互不确定性，阻碍了可靠机动动作的生成。为应对这些挑战，我们开发了一个面向交互感知自动泊车的路点级离线强化学习框架。具体而言，利用带有旋转路点增强的分层专家推演构建了专用泊车数据集，覆盖非交互场景与交互场景。随后，策略以紧凑的状态表示为条件，其中基于 LiDAR 的障碍物特征通过特征级线性调制适配到目标位姿。一个以状态为条件的 tokenizer 进一步将连续路点序列量化为离散动作 token，并在其上执行保守 Q 学习，以抑制对支持不足动作的价值高估。在高保真 CARLA 模拟器中进行了大量闭环实验。所提框架在所有基线中取得了最高泊车成功率，并能可靠迁移到未见过的停车位。

## Abstract
Parking is a routine yet safety-critical task for autonomous vehicles operating in urban environments. However, cluttered and weakly structured parking spaces, compounded by the interactive uncertainty from surrounding vehicles, hinder reliable maneuver generation. To address these challenges, we develop a waypoint-level offline reinforcement learning framework for interaction-aware autonomous parking. Specifically, a dedicated parking dataset is constructed from hierarchical expert rollouts with rotational waypoint augmentation, covering both non-interactive scenarios and interactive ones. The policy is then conditioned on a compact state representation, in which LiDAR-based obstacle features are adapted to the target pose via feature-wise linear modulation. A state-conditioned tokenizer further quantizes continuous waypoint sequences into discrete action tokens, over which conservative Q-learning is performed to suppress value overestimation on poorly supported actions. Extensive closed-loop experiments are conducted in the high-fidelity CARLA simulator. The proposed framework attains the highest parking success rate among all baselines and transfers reliably to unseen parking slots.

- **已有方法的困境**：
  - **基于模型的轨迹优化**：可解释、能显式编码安全与可行性约束，但依赖精确场景建模和大量专家设计（手工目标、约束、启发式），在复杂约束、不良初始化、频繁重规划时效率与鲁棒性下降。

  - **在线强化学习（RL）**：可进行长时域奖励驱动决策，但试错交互代价高，在受限空间中探索不安全，且面临延迟奖励与高维连续动作空间的难题。

- **主要贡献**：
  - 提出路点级离线 RL 泊车框架，将连续路点序列离散化为状态条件动作 token，并执行保守价值学习，无需任何在线交互即可获得奖励引导策略。
  - 构建专用泊车数据集：基于分层专家推演 + 旋转路点增强，覆盖非交互与交互（需与周围交通协调）两类场景。

## 2. 方法论

### 2.1 问题建模（MDP）

- 将泊车建模为折扣 MDP：`M = (S, A, P, r, γ)`。
- **状态** `s_t = (D_t, M_t, p_t)`：
  - `D_t`：最近 `N_h` 步的 LiDAR 障碍物距离向量序列（`N_ψ` 条采样射线的最近障碍距离）；
  - `M_t`：最近 `N_h` 步的自车运动历史（速度、纵向加速度）；
  - `p_t`：相对目标泊车位的位姿误差 `[Δx, Δy, Δθ]`。
- **动作** `a_t`：自车坐标系（后轴中心为原点）下 `H` 个有序未来路点序列，每点为相对位姿 `[x, y, θ]`，作为短时域参考轨迹交由下游控制器跟踪。
- **奖励**：`r_t = r_goal + r_coll + r_len + r_ctrl`，分别刻画泊车精度、碰撞惩罚、轨迹效率与运动平滑性。

### 2.2 分层离线数据集生成

1. **全局参考生成**：Hybrid A* 生成粗略几何路径，再按离散化车辆动力学（运动学自行车模型）分配速度剖面，得到动力学可行全局参考。
2. **局部轨迹优化**：每步从全局参考抽取定长局部参考序列，求解非线性规划（NLP）最小化参考跟踪误差与控制变化量，同时施加执行器限制与障碍物间隙约束；优化解的姿态分量转换到自车坐标系后作为专家动作。
3. **路点动作扰动**：对专家动作施加旋转扰动角 `α_t`（每个路点绕原点旋转、朝向角加 `α_t`），提升动作多样性并保持路点序列几何结构。
4. **转移采集**：扰动动作由 LQR 跟踪执行一个决策间隔，记录 `(s_t, a_t, r_t, s_{t+1}, η_t)`，其中 `η_t` 为终止指示。

### 2.3 网络架构（模块化：状态编码 / 动作离散化 / token 级价值估计）

- **状态编码器**：
  - 障碍物分支：分别处理当前距离观测与由历史导出的时间差分流（逐角度时间卷积），两路经角度残差卷积（循环填充）细化后融合得障碍物特征图 `F_obs`。
  - 目标位姿经 MLP 编码为目标嵌入 `g_t`，再通过 **FiLM** 生成通道级系数 `γ_t, β_t`，对障碍物特征图做仿射调制：`F̃ = (1+γ)⊙F + β`。
  - 学习到的角度门控模块将 `F̃` 池化为障碍物上下文向量；运动历史经 MLP 编码为运动嵌入；二者拼接成条件嵌入 `c_t`。
- **动作 Tokenizer（受状态条件动作量化 SAQ 启发）**：
  - 动作编码器 `E_ψ(a_t, c_t)` 产生连续隐动作 `z_t`；
  - 通过最近邻查找可学习码本 `E = {e_q}` 得到离散动作 token `q_t`；
  - 动作解码器 `G_ω(e_{q_t}, c_t)` 重建路点动作 `â_t`。
  - 关键点：量化以状态条件嵌入为上下文，使同一紧凑码本能区分不同泊车情境下的机动选择。
- **Q 网络**：在动作 token 词表上输出 `Q_θ(c_t, ·) ∈ R^{|Q|}`；执行时贪心选 token，解码为连续路点动作后由 LQR 跟踪。

### 2.4 学习目标

- **Tokenizer 训练**：重建损失 + 承诺损失（`λ_com` 控制），码本嵌入用 EMA 更新。
- **离散 CQL**：将数据集中动作替换为 token 得 token 化数据集，优化目标 = Bellman 均方误差 + 保守正则项（对候选 token 的对数求和项抑制 Q 值高估），Bellman 目标为 `r_t + γ(1-η_t) max_{q'} Q̄(c_{t+1}, q')`。

### 2.5 奖励设计细节

- `r_goal`：仅在终端位姿进入位置/朝向阈值时激活，按指数形式对位置与朝向误差加权衰减。
- `r_coll`：碰撞惩罚项。
- `r_len`、`r_ctrl`：由于有限时域路点动作不反映完整 cost-to-go，从局部轨迹端点初始化 NLP 轨迹延续，拼接成完整候选轨迹后计算平均路径长度与平均控制变化量，经稳健 z-score 归一化后作为效率与平滑性奖励。

## 6. 主要结论与发现

- **分布内性能最优**：本方法 TSR = 96.53%、CR = 2.78%、SCT = 95.44%，均为所有方法中最佳；终末位姿误差与 BC、TD3-BC 相当（APE 0.71 m，AOE 5.26°）。
- **基线表现**：
  - SAC 完全失败（TSR 0%），训练中平均 Q 值急剧上升并持续震荡不收敛，是典型的由 OOD 动作 token 自举导致的价值发散；
  - SAC-N 仅部分缓解（TSR 32.64%），集成分歧未能提供可靠的不确定性信号；
  - BC（88.19%）与 TD3-BC（90.97%）能取得不低成功率，但 BC 碰撞率更高（11.81%），说明纯监督拟合难以区分长期安全后果不同的局部相似机动；TD3-BC 的 BC 正则使其偏向混合质量的数据动作，限制进一步提升。
- **本方法的价值曲线平滑上升后保持稳定**

，而非像 SAC 那样发散或震荡，说明"状态条件动作量化 + 离散 CQL"有效抑制了由 OOD 动作自举引发的价值高估；这是其能稳定超越基线的重要机制性证据。

- **泛化到未见车位**：在 S11–S14 四个训练集中未出现的目标车位上，本方法仍保持最高成功率与最低碰撞率，优于 BC、TD3-BC 与 SAC-N，表明学到的策略并非对特定车位坐标的记忆式拟合，而是具备一定的场景几何泛化能力。其优势主要来源于奖励引导的保守价值学习，使策略在偏离演示分布时仍能选择相对安全的机动。

- **消融结论（动作 tokenizer）**：
  - 去掉状态条件（仅用无条件码本、|Q| = 24）后性能明显下降，验证了"以状态嵌入为上下文进行量化"对区分不同泊车情境下同类机动选择的关键作用；
  - 在保留状态条件的前提下，码本规模从 |Q| = 24 增大到 36、48 时，性能有进一步提升但呈边际递减趋势，说明 24 的码本已能覆盖主要机动模式，过大词表反而增加价值学习难度与过拟合风险。

- **交互场景的意义**：在存在对向车、且优先通行权归属随机的场景中，本方法能够通过路点级动作表示隐含地编码"让行/抢行"这类交互决策，避免因局部几何相似但长期后果不同的机动而误判，这也是其碰撞率显著低于纯模仿类方法的原因之一。

## 8. 方法亮点与批判性评价

- **核心创新点**：将"动作量化"从底层控制指令提升到"路点序列"这一交互友好、几何可解释的层级，并以状态条件嵌入作为量化上下文，使离散码本在语义上对应"不同泊车情境下的机动选择"，从而把连续动作空间的离线 RL 转化为在有限 token 词表上的离散 CQL 问题，兼顾了表达的灵活性与价值学习的稳定性。
- **工程合理性**：模块化设计（状态编码器 / tokenizer / Q 网络）与统一共享组件（所有基线共享编码器、tokenizer、LQR 跟踪器）使对比聚焦于学习目标本身，实验设计较为干净。
- **可解释性收益**：路点动作天然可视化，Q 值可直接对应"选择哪一类机动"，为安全攸关系统的调试与验证提供了便利。
- **主要疑虑**：其一，性能优势在多大程度上来自"离线 RL 的奖励引导"而非"路点表示 + 高质量专家数据"，缺少对专家数据质量退化的敏感性分析；其二，冻结的预训练状态编码器是否限制了在新场景下的适应性；其三，保守系数 α_cql 等超参的敏感性未被系统研究。
- **总体判断**：这是一篇问题定位清晰、方法自洽、实验方向明确的工作，在自动泊车这一安全攸关任务上展示了离线 RL + 动作量化的可行性与可靠性优势；但其结论的普适性受限于场景与任务的窄覆盖，后续工作需要在更广泛的地图、车位类型与交互复杂度上加以验证。
