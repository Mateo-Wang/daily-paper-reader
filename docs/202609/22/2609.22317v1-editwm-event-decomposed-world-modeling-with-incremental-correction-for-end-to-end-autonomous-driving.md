## 摘要
世界模型通过预测与候选轨迹相关的场景演化来支持自动驾驶。驾驶动态在可预测性上存在差异，这促使我们区分常规演化与事件引发的偏差，后者需要选择性校正。我们提出 EditWM，一种在紧凑视觉特征空间中将未来预测分解为常规演化和事件驱动增量校正的世界模型。一个以轨迹为条件的常规预测器提供基础预测，随后被冻结以用于校正学习。一个校正解码器将该预测与观测历史和规划动作进行比较，生成有界特征更新，其贡献由学习得到的门控进行调节。校正后的未来特征通过候选特定的交叉注意力为轨迹评分提供条件，从而将世界建模与规划选择联系起来。在推理时，EditWM 仅使用过去和当前的观测、自车状态以及候选轨迹。在所有 12,146 个 NAVSIM navtest 场景中，以专家轨迹为条件的评估显示，未来特征 MSE 相比 Normal 降低 5.35%，并在 83.54% 的场景中有所改善。该系统使用官方 EPDMS 评估器，在 100 分制下达到 91.05 EPDMS。这些结果表明，当校正后的未来表征被集成到规划中时，未来特征预测得到改善，轨迹选择也具有竞争力。

## Abstract
World models support autonomous driving by predicting the scene evolution associated with candidate trajectories. Driving dynamics differ in predictability, motivating a distinction between regular evolution and event-induced deviations that call for selective correction. We propose EditWM, a world model that decomposes future prediction into normal evolution and event-driven incremental correction in compact visual feature space. A trajectory-conditioned normal predictor provides the base forecast and is then frozen for correction learning. A correction decoder compares this forecast with observation history and planned actions, producing a bounded feature update whose contribution is regulated by a learned gate. The corrected future features condition trajectory scoring through candidate-specific cross-attention, linking world modeling to plan selection. At inference, EditWM uses only past and current observations, ego state, and candidate trajectories. Across all 12,146 NAVSIM navtest scenes, expert-trajectory-conditioned evaluation shows a 5.35\% reduction in future-feature MSE over Normal, with improvements in 83.54\% of scenes. The system achieves 91.05 EPDMS on a 100-point scale using the official EPDMS evaluator. These results demonstrate improved future-feature prediction and competitive trajectory selection when corrected future representations are integrated into planning.

## 1. 核心问题与整体含义
- **研究动机**：端到端自动驾驶中，世界模型被用于预测候选轨迹对应的未来场景演化，从而支持轨迹评分与规划选择。
- **核心问题**：驾驶场景中不同动态的可预测性并不一致。大部分场景遵循由自车运动、持续几何结构和平滑智能体动态驱动的“常规演化”，但少部分决策关键变化来自突发或交互驱动事件，难以由普通预测器统一建模。
- **整体含义**：现有世界模型通常把完整未来作为统一预测目标，忽略了常规演化与事件扰动之间的可预测性不对称，也缺少“保留可靠预测、选择性修正未解释变化”的机制。EditWM 因此提出将未来预测分解为常规演化和事件驱动增量校正，并把校正后的未来表征接入候选轨迹评分。

## 2. 方法论
- **核心思想**：在紧凑视觉特征空间中，未来预测 = 轨迹条件常规预测 + 事件驱动增量修正。先训练并冻结常规预测器，再训练门控校正解码器，最后冻结世界模型训练轨迹评分器。
- **常规预测器 Normal**：
  - 使用 DINOv2 编码多视图历史，得到历史特征 \(H_t\)。
  - 历史编码器初始化共享场景状态 \(S_0\)，轨迹与自车嵌入初始化候选动作 \(a_{i,0}\)。
  - 通过共享 Transformer \(D_\theta\) 进行 \(M\) 步 rollout，并由投影 \(P_\theta\) 输出常规未来特征：
    \[
    \hat{Z}^N_i = Z_t + P_\theta(S_{i,M})
    \]
  - 常规预测器拟合专家轨迹后冻结，作为后续校正的参考。
- **事件驱动增量校正**：
  - 将常规预测相对真实未来特征的残差定义为“surprise”：
    \[
    R = Z^+ - \hat{Z}^N(H_t,e_t,\tau_{gt})
    \]
  - 校正解码器以常规未来为 query，以历史 token、候选轨迹 token、自车 token 为 memory，输出校正表示。
  - 两个头分别预测门控 \(g_i\) 和有界跳跃 \(\Delta Z_i\)：
    \[
    \hat{Z}^{EditWM}_i = \hat{Z}^N_i + \alpha g_i \odot \Delta Z_i
    \]
  - 门控控制每个 token 的局部修正强度，跳跃由 \(\tanh\) 和拟合集尺度 \(B_\Delta\) 限制，\(\alpha\) 为验证集选择的全局增益。
- **门控监督**：
  - 对每个 token，用残差能量 \(\rho_n=\|R_n\|_2^2/d\) 构造软门控目标：
    \[
    y_n = \rho_n/(\rho_n+\kappa_n)
    \]
  - \(\kappa_n\) 为拟合集残差能量的第 80 百分位。
  - 训练损失为特征损失、门控 BCE 和门控激活正则之和：
    \[
    L_{EditWM}=L_{feat}(\tilde Z,Z^+)+\lambda_g BCE(g,y)+\lambda_m mean(g)
    \]
  - 特征损失梯度通过 stop-gradient 阻断门控值，防止重建误差直接推高门控激活。
- **轨迹评分与规划连接**：
  - 每个候选轨迹拥有自己的校正未来特征。
  - 未来记忆由归一化校正未来特征和相对当前特征的变化组成。
  - 候选特征通过候选特定交叉注意力查询自己的未来记忆，再经残差更新和九头评分器输出九个 EPDMS 组件 logits。
  - 最终按固定指标组合规则打分并选择轨迹。
- **推理输入**：仅使用过去和当前观测、自车状态以及候选轨迹，不依赖未来图像或专家轨迹。
