## 摘要
世界动作模型（World Action Models, WAMs）已成为一种有望实现可泛化机器人控制的范式。尽管 WAM 系统数量不断增长，现有工作往往提出将架构、训练策略等多种设计选择捆绑在一起的统一系统，从而难以分离各项贡献并系统比较不同替代设计。在本工作中，我们开展了一项受控研究，解耦这些设计选择，不仅分析它们的实证效果，还分析它们如何以及为何塑造 WAM。更具体地说，我们关注构建 WAM 的三个基本问题：(1) 何种因果结构应支配世界建模与动作生成之间的交互？(2) 世界建模应在哪个潜在空间中进行？(3) 不同的世界-动作建模目标如何影响模型行为与性能？通过在三个代表性基准 RoboCasa-GR1、LIBERO 和 LIBERO-Plus 上进行结构受控实验，我们系统比较了六种因果结构、八种潜在表示和四种训练目标，涵盖了现有 WAM 中的流行设计选择。我们进一步在来自 DROID 数据集的真实机器人数据上验证了关键发现。我们希望系统地理解核心设计选择如何影响世界-动作建模，以及哪些原则可以指导未来 WAM 系统的开发。

## Abstract
World Action Models (WAMs) have emerged as a promising paradigm for generalizable robot control. Despite the growing number of WAM systems, existing works often introduce unified systems that bundle together multiple design choices, such as architecture and training strategy, making it difficult to isolate individual contributions and systematically compare alternative designs. In this work, we present a controlled study that disentangles these design choices and analyzes not only their empirical effects, but also how and why they shape WAMs. More specifically, we focus on three fundamental questions in building WAMs: (1) what causal structure should govern the interaction between world modeling and action generation? (2) in which latent space should world modeling be performed? and (3) how do different world-action modeling objectives affect model behavior and performance? Through structurally controlled experiments on three representative benchmarks, RoboCasa-GR1, LIBERO, and LIBERO-Plus, we systematically compare six causal structures, eight latent representations, and four training objectives, covering popular design choices in existing WAMs. We further validate our key findings on real-robot data from the DROID dataset. We hope to provide a systematic understanding of how core design choices affect world-action modeling and what principles can guide the development of future WAM systems.

  - 无法判断性能提升究竟来自更好的世界表示、更有效的世界-动作条件化、更有信息量的辅助目标，还是仅仅来自更大、更精细工程的系统；

  2. 世界建模应在哪个**潜空间**中进行？
  3. 不同的**世界-动作建模目标**如何影响模型行为与性能？

## 2. 方法论：核心思想与关键技术细节

### 2.1 总体思路
- **控制变量法**：在每个设计维度内部固定基座模型（base framework）、架构与训练流程，仅改变被研究的单一因素，从而隔离各设计选择的独立贡献。
- 覆盖三大设计轴：**因果结构（6 种）× 潜表示（8 种）× 训练目标（4 种）**。
- 除成功率的经验比较外，还引入**机制层面的分析工具**：推理时干预（intervention）、线性探针（linear probe）、梯度对齐分析、目标歧义度量。

### 2.2 维度一：视频-动作因果结构（6 种）
- 解耦/无条件（Disentangled/Unconditional）：视频与动作独立预测；
- 视频→动作（Video-to-Action）；
- 动作→视频（Action-to-Video）；
- 双向交互（Bidirectional）；
- 联合预测（Joint）；
- 因果交错生成（Causally Interleaved）。
- 所有结构在**同一框架内**实例化，保持架构与训练流程一致；对因果交错模式采用"单流、分组因果"抽象，以保留原始工作（[9],[18]）的时间依赖顺序，同时保证跨变体可比。
- 分类依据是"标准策略路径上定义性的视频-动作依赖关系"，而非单纯的 chunk 自回归调度（如 DreamZero 因在每 chunk 内对两模态共同去噪而归为 Joint）。

### 2.3 维度二：潜世界表示（4 族 / 8 种）
- **语义潜表示**：DINOv3、Qwen3-VL、SAM3；
- **几何潜表示**：VGGT-Ω、DA3（Depth Anything 3）；
- **重建潜表示**：VAE（SDXL、Wan 等视频生成模型继承的 VAE 潜空间）；
- **预测潜表示**：V-JEPA 2.1。
- **关键区分维度**：潜表示本身是否编码跨帧时间关系
  - **帧间潜（inter-frame）**：DA3、VGGT-Ω、V-JEPA、Qwen3-VL(video)、Video-VAE —— 联合编码多帧；
  - **逐帧潜（framewise）**：DINOv3、SAM3、Image-VAE —— 独立编码每帧，时间整合推迟到策略主干。

### 2.4 维度三：世界-动作建模目标（4 种）
设 $o_t$ 为当前观测，$\ell$ 为任务指令，$a_{t+1:t+k}$ 为未来动作块，$z_{t+1:t+k}$ 为对应未来视觉潜表示：
- **行为克隆（BC）**：$p(a_{t+1:t+k} \mid o_t, \ell)$，即标准 VLA 目标；
- **逆动力学建模（IDM）**：$p(a_{t+1:t+k} \mid o_t, z_{t+1:t+k}, \ell)$；
- **前向动力学建模（FDM）**：$p(z_{t+1:t+k} \mid o_t, a_{t+1:t+k}, \ell)$；
- **视频生成（VG）**：$p(z_{t+1:t+k} \mid o_t, \ell)$。
- 在同一框架（[10]）内实例化，比较：仅 BC、BC+单辅助目标、留一目标（leave-one-out）、全目标联合训练，以及分阶段训练。

### 2.5 关键分析手段（机制解释）
- **推理时干预**（针对 Joint 与 Bidirectional 路由启用变体）：
  - *内容损坏（content corruption）*：将每个未来槽位与固定噪声按 0.10/0.25/0.50 强度混合，同时保持逐通道空间均值与方差；
  - *时间反转（temporal reversal）*：在去噪最后 25%/50%/100% 阶段交换两个未来槽位；
  - 两种干预均不改变当前帧槽位；测量动作预测变化与 rollout 成功率变化。
- **线性探针**：在第 0、7、15 层隐藏状态上拟合线性探针预测专家动作，以 held-out $R^2$ 衡量"动作可解码性"。
- **时间错配扰动**：将 ID 输入 $[H, C]$（历史帧、当前帧）替换为同轨迹更早观测，得到 $[H', C]$、$[H, C']$、$[H', C']$，测试时间依赖的脆弱性。
- **梯度对齐分析**：目标两两之间的梯度余弦相似度（上三角为 LIBERO，下三角为 RoboCasa-GR1）。
- **目标歧义度量**：逐维目标散布（target spread），衡量 BC/IDM 的动作目标或 FDM/VG 的未来潜目标的局部变化。

## 6. 主要结论与发现

### 6.1 视频-动作因果性
- **Takeaway 1.1：生成未来主要通过时间结构影响动作，而非精确内容。**
  - 路由启用变体（可读取生成未来视频）在 LIBERO-Plus OOD 上比匹配对照高 16.14% 与 14.93%，但在 ID RoboCasa-GR1 上反而低 2.33% 与 4.00%；
  - 最强内容损坏下，动作预测变化 <1%，成功率基本不变；而时间反转使动作变化 2.30–2.41%、成功率下降 6.08–11.08%（RoboCasa-GR1），OOD 下动作变化 12.79–14.36%、成功率下降 24.24–32.37%。
- **Takeaway 1.2：因果视频生成（而非视频与动作 token 之间的时间因果）才是主要的时间性优势来源。**
  - Causally Interleaved 取得最高 LIBERO-Plus 成功率 77.33%；
  - 放宽为 Video-Causal Global 后进一步提升到 79.84%（+2.51%），说明优势更多来自帧因果的视频生成，而非严格的视频-动作 token 时间因果。

### 6.2 潜世界表示
- **Takeaway 2.1：潜表示中的时间结构跨分布地塑造性能——帧间潜利于 ID 控制，逐帧潜利于 OOD 鲁棒性。**
  - 帧间潜在 RoboCasa-GR1 上更优，但排序在 LIBERO-Plus 上反转，且在传感器噪声与相机视角偏移下差距最大；
  - 线性探针显示动作可解码性与该分布依赖的性能分裂完全一致（ID 上帧间潜各层均更高，OOD 上逐帧潜各层领先，深层差距收窄）。
- **Takeaway 2.2：预编码的帧间关系引入脆弱的时间依赖。**
  - 在 $[H',C]$、$[H,C']$、$[H',C']$ 三种时间错配扰动下，帧间潜策略退化显著大于逐帧潜策略；
  - 结论：**时间结构最好通过世界-动作建模来"学习并情境化整合"，而非由输入表示固定施加**；固定预编码的时间关系在测试时关系变化后会变脆。

### 6.3 世界-动作建模目标
- **Takeaway 3.1：辅助目标的效果依赖分布——损害 ID 性能，但未来预测类目标（尤其视频生成）提升 OOD 鲁棒性。**
  - RoboCasa-GR1（ID）上 BC-only 最优，所有辅助配置均更差；IDM 退化最小，因其梯度与 BC 更对齐；
  - LIBERO-Plus（OOD）上 VG 把 BC-only 从 77.96% 提升到 81.22%，FDM 仅边际增益，IDM 略降；
  - VG 对相机视角偏移提升 13.32%，但对机器人或布局偏移无提升；VG 优于 FDM，因其未来目标更宽泛、保留更丰富的视觉-时间信息；
  - 动力学目标对数据覆盖与训练阶段敏感，数据有限或表示不成熟时可能依赖数据集特异的"捷径"（如动作转移相关性）。
- **Takeaway 3.2：目标互补性关键取决于训练调度。**
  - BC+IDM+FDM 略优于单独 IDM/FDM，但全目标从头联合训练反而比 BC+VG 低 4.04%，说明朴素多目标会互相干扰；
  - 分阶段训练（前 80% 用 BC+VG 建立稳定策略与视觉-时间表示，最后 20% 引入动力学目标作弱正则）取得最高 83.15%；
  - 同一分阶段策略**未**带来对应的 ID 提升，与 Takeaway 3.1 一致。

### 6.4 真实机器人数据（DROID）验证
- **因果结构**：Causally Interleaved 在 10K–200K 所有 checkpoint 上均优于 Uncond，四项指标全面更好（MSE 0.0666 vs 0.0730；L1 0.1544 vs 0.1630；Acc@0.1 53.78% vs 51.83%；Acc@0.5 94.52% vs 93.87%）；
- **潜表示**：逐帧 DINOv3 在四项指标上均优于帧间 DA3（MSE 0.0684 vs 0.0702；Acc@0.1 53.08% vs 52.40%）；
- **训练目标**：BC+

VG 在离线动作预测上优于 BC-only，与仿真中"VG 主要提升 OOD 泛化"的结论方向一致；由于 DROID 的测试划分是按**任务语义**而非随机划分，本身即构成分布外设定，因此该结果可视为对 Takeaway 3.1 的跨域佐证。分阶段训练在 DROID 上同样未出现退化，支持"先建立稳定视觉-时间表示、后引入动力学目标"的调度合理性。

### 6.5 跨维度综合结论

- **时间结构是贯穿三个设计轴的核心变量**：因果结构中的帧级因果视频生成、潜表示中的帧间/逐帧区分、目标中的未来预测类辅助任务，本质上都在操纵"模型在何处、以何种方式获得时间信息"。三者的最优选择一致指向：**时间结构应由模型在建模过程中动态整合，而非由输入表示预先固化或由 token 级因果强制约束**。
- **ID 与 OOD 的目标并不一致，且这种张力是可预测的**：帧间潜、BC-only、严格 token 级因果在 ID 上更优；逐帧潜、VG 辅助目标、放宽的因果视频生成在 OOD 上更优。这意味着 WAM 的设计本质上是在 ID 精度与 OOD 鲁棒性之间做显式取舍，而非存在单一最优配置。
- **梯度对齐可以部分解释目标组合的成败**：IDM 与 BC 梯度更对齐，因而在 ID 上退化最小；VG 的未来目标更宽泛、保留更多视觉-时间信息，因而在 OOD 上增益最大；全目标朴素联合因目标间梯度冲突而互相干扰，分阶段训练通过时间上错开目标来缓解冲突。

## 7. 局限性与未来方向

- **规模限制**：作者明确将结论限定为中等规模受控实验，未验证结论在更大模型、更长训练、更大数据下的可扩展性；规模效应是否改变 ID/OOD 的取舍方向仍是开放问题。
- **表示覆盖有限**：潜表示每族仅取 1–2 个代表，几何族（VGGT-Ω、DA3）与语义族（DINOv3、Qwen3-VL、SAM3）内部的其他选择、以及更强的视频基础模型潜空间未被覆盖。
- **真实机器人评测为离线动作预测**：虽避免了二值成功率的粗粒度问题，但无法捕捉闭环执行中的误差累积、恢复行为与长程任务失败模式，与仿真成功率不可直接比较。
- **因果结构的抽象化**：将原始工作抽象为"单流、分组因果"形式以换取可比性，可能损失原系统中与实现细节耦合的性能来源。
- **未报告算力**：缺少 GPU 规模与训练成本信息，不利于复现与成本-收益分析。
- **潜在方向**：自适应地按分布/任务切换时间整合方式；将分阶段目标调度推广为可学习的目标权重或课程；在闭环真实机器人上验证干预实验揭示的时间依赖机制。

## 8. 对研究的启发与总体评价

- **方法论价值大于单点结论**：本文的主要贡献是把 WAM 设计从"整体系统比拼"转向"单维度受控对照 + 机制解释"，其"匹配对照 + 推理时干预 + 线性探针 + 梯度对齐"的组合，为后续世界模型/VLA 研究提供了一套可复用的分析范式。
- **反直觉结论具有指导意义**：生成未来的**内容**几乎不影响动作（内容损坏 <1% 动作变化），而生成的**时间结构**影响显著（时间反转导致成功率下降 6–32%），提示社区不应把精力过度投入视频生成保真度，而应关注时间一致性与因果组织方式。
- **实践建议清晰**：若追求 ID 性能，选帧间潜 + BC-only；若追求 OOD 鲁棒性，选逐帧潜 + 分阶段引入 VG；若要兼顾，分阶段训练是目前证据支持的最佳折中。
- **总体评价**：这是一篇定位清晰、实验设计严谨、结论有机制支撑的实证研究，其价值在于"澄清设计空间"而非"刷新榜单"。主要短板是规模中等、真实机器人侧为离线评测、算力信息缺失，因此结论应被理解为"在该实验条件下的稳健规律"，而非普适定律。
