## 摘要
近年来，机器人模仿学习的进展催生了可直接从视觉观测预测动作的视觉运动策略。然而，当目标位置、物体高度或接触几何发生变化时，视觉上相似的场景可能需要不同的动作。预训练的 RGB 特征可能将这些几何上不同的状态映射为相似的策略输入，而简单地加入深度信息则要求策略从用于学习控制的同样有限的演示中学习 RGB-深度对应关系。我们提出 StereoPatch，一种图块对齐的 RGB-深度表示，它将配准的度量几何直接绑定到用于动作预测的 RGB 图块上。在共享的二维图块网格上，非对称交叉注意力在动作解码之前将深度信息融入对应的 RGB 特征中。由此得到的 StereoPatch Tokens 提供了一种几何感知的视觉表示，可在不改变底层学习目标的前提下对通用视觉运动策略进行条件化。在六项真实机器人任务中，StereoPatch 的闭环成功率高于仅外观、仅几何、原始 RGB-D 和晚期融合基线。另外，在三个仿真套件上的实验评估了其与不同视觉运动策略架构的兼容性、空间泛化能力和运行限制。结果表明，解决与控制相关的几何歧义，更受益于将深度直接与用于动作预测的视觉特征对齐，而不是将其作为独立模态提供。项目页面：https://aus.bot/research/stereopatch/。

## Abstract
Recent advances in robot imitation learning have produced visuomotor policies that predict actions directly from visual observations. Yet visually similar scenes can require different actions as target position, object height, or contact geometry changes. Pretrained RGB features may map these geometrically distinct states to similar policy inputs, while simply adding depth requires the policy to learn RGB-depth correspondence from the same limited demonstrations used to learn control. We introduce StereoPatch, a patch-aligned RGB-depth representation that binds registered metric geometry directly to the RGB patches used for action prediction. On a shared 2-D patch grid, asymmetric cross-attention incorporates depth information into the corresponding RGB features before action decoding. The resulting StereoPatch Tokens provide a geometry-aware visual representation that can condition general visuomotor policies without changing their underlying learning objectives. Across six real-robot tasks, StereoPatch achieves higher closed-loop success than appearance-only, geometry-only, raw RGB-D, and late-fusion baselines. Additional experiments across three simulation suites evaluate compatibility across visuomotor policy architectures, spatial generalization, and operating limits. Results suggest that resolving control-relevant geometric ambiguity benefits from aligning depth directly with the visual features used for action prediction, rather than supplying it as an independent modality. # StereoPatch 论文中文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：机器人模仿学习中的视觉运动策略直接从视觉观测预测动作，但视觉上相似的场景可能因目标位置、物体高度或接触几何不同而需要不同动作。预训练 RGB 特征（如 DINOv3）可能将几何上不同的状态映射为相似的策略输入，形成“表示—控制失配”（representation–control mismatch）。
- **现有方案局限**：
  - 仅用 RGB：保留物体身份，却可能欠表示控制相关的度量差异。
  - 简单加入深度：策略仍需从与学习控制相同的有限演示中自行学习 RGB–深度对应关系，两种模态的互补信息未必能联合用于动作预测。
  - 已有几何表示（体素、点云、虚拟视图等）通常替换 RGB patch 网格，而非在动作解码前将度量几何绑定到 RGB 特征上。
- **整体含义**：论文主张在动作解码之前，将配准的度量几何直接对齐到用于动作预测的 RGB patch 表示中，而非把深度作为独立模态供给策略。目标是提升模仿策略的空间感知与闭环操作成功率，同时不改变原有学习目标与动作生成器结构。

## 2. 方法论

- **核心思想**：构建“图块对齐”的 RGB–深度表示（StereoPatch Tokens），让每个 RGB patch 在保留自身图像位置的同时，通过软检索纳入相关的度量深度证据，再由该统一表示条件化通用视觉运动策略。
- **编码器与对齐**：
  - 冻结的 DINOv3 编码 RGB 外观，冻结的 DeFM 编码配准度量深度。
  - 通过各自输入变换与可训练投影到共享特征宽度 C，并使两个编码器输出相同的 Hp×Wp patch 晶格，得到共索引（co-indexed）的 R⁰ 与 D⁰。
  - 仅保留空间 patch token，移除编码器特有的全局前缀 token。
- **非对称交叉注意力融合**：
  - 两个融合块（ℓ∈{0,1}）。每块先在各模态内做自注意力（含归一化与残差），得到上下文化的 R̄、D̄。
  - RGB patch 作为 query，深度 patch 作为 key/value，做多头交叉注意力，将深度证据检索进 RGB 索引的 token。
  - 注意力权重为 `α_pj = softmax(q_p k_j^T / √d + B_pj)`，其中 `B_pj` 为学习的二维相对位置偏置（行偏移与列偏移查找表之和），使模型能区分同格、邻格与远处深度特征。
  - 融合是非对称的：深度只更新 RGB 字段，自身通过自注意力更新；输出经残差与 FFN，保留原始 RGB 信息。
- **关键设计**：
  - “图块对齐”指共享地址系统与偏移感知检索，而非硬性一对一对应或固定 patch 分辨率。
  - 深度是内部证据场，不作为第二 token 序列直接传给控制器；每个输出 token 仍保留其 RGB patch 地址。
- **策略集成**：
  - 将 StereoPatch token、腕部视图 token 与机器人状态嵌入拼接为统一观测序列 `O_t = [T_sp; T_w; e_s(s)]`，再输入动作生成器。
  - 兼容 ACT（并行解码动作块）与 Diffusion Policy（迭代去噪动作块），两者保持原有动作生成结构与行为克隆目标。
  - 预训练 RGB/深度编码器冻结；输入投影、融合块、腕部与状态编码器、动作策略端到端联合优化；不使用 RGB–深度对应标签或辅助融合/位置损失，仅由动作监督决定几何证据如何进入各 RGB patch。
- **深度来源**：校准立体经 Fast Foundation Stereo 估计，或直接来自 RGB-D 相机。

## 6. 主要结论与发现

- **融合方式比是否提供深度更重要**：将深度直接对齐到动作预测所用的视觉特征，比作为独立模态或晚期拼接更能缓解控制相关的几何歧义。
- **真实机器人性能**：
  - 放置任务：StereoPatch-ACT 在未见位置达 80.0%，相比 Patch MLP 提升 25.0 个百分点。
  - 抓取任务：StereoPatch-DP 在未见位置达 79.7%，相比 Patch MLP 提升 36.5 个百分点。
  - 碗提取：StereoPatch-ACT 86.3%（69/80），空抓与多碗抓取均减少；StereoPatch-DP 达 97.5%（78/80）。
  - 杯子转移：StereoPatch-ACT 90.0%（18/20）。
  - 插销插入：中间网格 20×40 最佳（任务成功 36.1%），优于单模态控制。
  - 多阶段打包：StereoPatch-ACT 完成 7/24，高于各匹配控制。
- **泛化规律**：融合收益在未见位置比已见位置更大，说明其与空间泛化相关；更广的演示覆盖比单纯增加重复次数更有效。
- **分辨率非单调**：更细网格（30×60）并不保证更好控制，中间网格表现最佳，提示需任务相关地选择空间采样。
- **传感配置影响显著**：AR0234 立体（FastFS）89.2% > D435 73.0% > D405 51.4%，说明传感配置是学习控制器的实际设计变量。
- **输入交换**：深度交换比 RGB 交换对前十个预测动作的影响更大（RMS 幅值 2.9–5.5 倍），表明策略对深度变化敏感。
- **推理预算**：ACT 与 4 步 DP 可在 30 Hz 预算内容纳感知；更长去噪调度会消耗余量，解码器配置成为运行选择的一部分。

## 7. 优点

- **问题识别清晰**：明确指出视觉模仿学习中的“表示—控制失配”，并用空间混叠/几何歧义解释 RGB-only 的失败模式。
- **方法简洁且兼容性强**：不替换 RGB patch 网格，不改变模仿目标与动作生成器结构，可即插即用地条件化 ACT
