## 摘要
视觉-语言-动作（VLA）策略通常通过额外的梯度更新来适应新的操作场景，这在任务特定数据或算力稀缺时限制了快速部署。我们提出 ICI-VLA，一个训练与检索框架，通过上下文演示为文本-动作 VLM 赋予少样本测试时自适应能力。与基于动作特定多模态融合的主流 VLA 设计不同，ICI-VLA 保留原生的文本生成接口。ICI-VLA 仅在离线训练时更新参数；推理时，策略保持固定，并以检索到的微演示为条件生成动作。该框架将长轨迹分解为短的、语义标注的示例，并使用由动态时间规整（DTW）挖掘的正样本训练 RD-Encoder，使检索到的上下文与当前子任务的阶段和几何对齐。我们进一步引入目标动作掩码（Target Action Masking），一种上下文破坏目标，旨在减少直接复制动作并增加对当前观测的依赖。ICI-VLA 在 LIBERO 上达到 97.7% 的平均成功率，在 RoboTwin 2.0 上达到 60.4%，在 RoboTwin 2.0 上超过已报告的最高基线平均值 19.3 个百分点。它还在四个物理任务上达到 83.2%。这些结果表明，固定的 VLA 策略可以在测试时受益于以时空对齐演示为条件。

## Abstract
Vision-Language-Action (VLA) policies are commonly adapted to new manipulation settings through additional gradient updates, which limits rapid deployment when task-specific data or compute is scarce. We present ICI-VLA, a training and retrieval framework that equips a text-action VLM with few-shot test-time adaptation through in-context demonstrations. Unlike mainstream VLA designs based on action-specific multimodal fusion, ICI-VLA retains the native text-generation interface. ICI-VLA updates its parameters only during offline training; at inference, the policy remains fixed and conditions action generation on retrieved micro-demonstrations. The framework decomposes long trajectories into short, semantically labeled examples and trains an RD-Encoder with positives mined by Dynamic Time Warping (DTW), aligning the retrieved context with the phase and geometry of the current subtask. We further introduce Target Action Masking, a context-corruption objective designed to reduce direct action copying and increase reliance on the current observation. ICI-VLA reaches average success rates of 97.7% on LIBERO and 60.4% on RoboTwin 2.0, exceeding the highest reported baseline average on RoboTwin 2.0 by 19.3 percentage points. It also achieves 83.2% across four physical tasks. These results indicate that a fixed VLA policy can benefit from conditioning on spatiotemporally aligned demonstrations at test time.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型已能把大规模视觉-语言预训练表征迁移到机器人底层控制，多任务性能较强；但绝大多数已部署 VLA 本质上是**固定的条件策略**，要适配新任务通常必须采集新演示并更新参数，成本高、难以快速部署。
- **潜在替代方案**：上下文学习（ICL）允许模型仅凭输入中的少量演示适配新任务而无需梯度更新，语言与视觉-语言模型已验证该能力，VLA 天然构建于这些多模态模型之上，理论上可把演示当作**推理时的任务信息**而非仅作微调数据。
- **机器人 ICL 的两个核心障碍**：
  - **时间混叠（temporal aliasing）**：长轨迹与短动作块（action chunk）在时间尺度上不对齐。
  - **语义-动力学失配（semantic-dynamic mismatch）**：视觉/语义相似的演示可能对应完全不相容的运动。
  - 两种失配下，上下文会退化为"误导性的动作前缀"，诱使模型直接复制序列。
- **契机**：VLA-0 证明纯 VLM 可把连续动作直接生成为文本，无需动作专用预测头（"零结构修改"），为机器人 ICL 提供了保留原生生成接口的可行基础。
- **整体含义**：论文主张把 VLA 适配重新表述为**固定策略下的少样本测试时条件化**（few-shot test-time in-context adaptation，而非 zero-shot），用"时空对齐的微演示"替代逐任务梯度更新。

## 2. 方法论

### 2.1 核心思想
- 采用"零结构修改"的纯 VLM 架构：不添加任何动作专用参数或头，连续动作完全以数值文本串表示，以最大程度保留基座模型的推理与泛化先验。
- 训练与推理严格分离：**仅离线训练**更新参数；**推理时策略与检索器全部冻结**，只通过检索到的演示上下文实现自适应。
- 问题形式化：查询 $I_q=\langle T, T_{sub}, O_t, Z_t\rangle$（全局指令、当前子任务指令、主/腕相机观测、本体感受状态）；库项为微演示 $E=\langle T_i, T_{i,k}, O_i, Z_i, A_{i:i+k}\rangle$。推理时
  $$E^*=\arg\max_{E\in\mathcal{D}} s_\phi(I_q,E),\quad A_{t:t+k}\sim \pi_\theta(\cdot\mid I_q,E^*)$$
  其中 $s_\phi$ 为 RD-Encoder 的相似度打分，$\phi$ 与 $\theta$ 在推理阶段均不接收梯度。

### 2.2 阶段 I：机器人演示库构建
- 汇集约 **11,200 条长时程轨迹**（LIBERO、RoboTwin 2.0 以及约 1,000 条双臂 Aloha 真机演示）。
- 用 Qwen3-VL 启发式地把每条轨迹切分为有序子任务 $\tau_i \to \{S_{i,1},\dots,S_{i,n}\}$，并为每个子任务配细粒度指令 $T_{i,k}$，从而得到约 **139,659 条子任务级微演示**，使检索单元与短动作视野匹配。
- 视觉规划器把全局指令分解为有序子任务指令序列，依据观测到的执行进度选择当前活跃的 $T_{sub}$，并在子任务视觉完成时推进。

### 2.3 阶段 II：时空检索对齐（RD-Encoder 训练）
- 以 **Qwen3-VL-Embedding-2B** 作为 RD-Encoder，采用迭代对比挖掘，融合两类监督：
  - **语义硬过滤（Semantic Hard-Filtering）**：用当前编码器计算锚点与库项的余弦相似度，保留语义相容的候选池（如"机械臂把抽屉推关"过滤掉无关动作，仅保留抽屉操作类）。
  - **DTW 几何排序**：对候选用带标注轨迹做动态时间规整排序，
    $$\mathrm{DTW}(\mathrm{Traj}_a,\mathrm{Traj}_e)=\min_{W}\sum_{(u,v)\in W}\delta(p_{a,u},p_{e,v})$$
    其中 $W$ 为合法弯曲路径，$\delta$ 为航点差异。航点为机器人基座标系下所有活动臂的 3D 末端位置，按训练集工作空间边界归一化；$\delta$ 为各臂欧氏距离的均值。
- 对比学习配置：保留语义候选前 64 个，DTW 代价最小者为正样本 $P^+$；从同一语义子任务中采样 15 个阶段错配候选作硬负样本 $N^-$；使用 InfoNCE 损失
  $$\mathcal{L}_{CL}=-\log\frac{\exp(e_A^\top e_{P^+}/\tau)}{\exp(e_A^\top e_{P^+}/\tau)+\sum_i \exp(e_A^\top e_{N^-_i}/\tau)}$$
  $\tau=0.07$，全局 batch size 128。因当前嵌入决定挖掘池，故**交替执行**候选检索、DTW 三元组挖掘与对比优化；当正样本变化比例低于 $\epsilon=5\%$ 或达到 5 轮即停止。
- **关键设计**：目标轨迹与 DTW 仅用于离线构造监督；评测时目标动作未知，冻结的 RD-Encoder 只从可观测查询输入排序库项，不对查询动作计算 DTW。

### 2.4 阶段 III：Target Action Masking 与策略微调
- 微调 **Qwen3-VL-4B**（此时 RD-Encoder 冻结），从含系统提示、检索演示、当前查询的结构化 prompt 预测文本化动作块；默认使用 3 条示例。
- **Target Action Masking** 是训练时的上下文破坏目标：设 $M$ 为被采样的目标 token 位置集合、$U$ 为其补集，$\tilde e_{a_q}=c(A_q;M)$ 表示把 $M$ 中位置替换为 [MASK]，仅对未掩码目标优化
  $$\mathcal{L}_{act}=-\sum_{j\in U}\log \pi_\theta(a_{q,j}\mid I_q,E^*,\tilde e_{a_q,<j})$$
  即某个未掩码 token 可能要在**含被破坏的早期动作 token 的前缀**下预测，从而削弱对"精确目标前缀续写"的依赖，鼓励更多利用当前观测与检索上下文（论文明确说明该目标**不**显式监督相对 $A_e$ 的运动学残差，其作用机制属假设并通过消融检验）。
- 推理时关闭掩码，策略以固定参数自回归生成动作；上下文在策略置信度低于 0.65 时刷新。

- **可改进之处**：
  - 缺少与"每任务微调 / 少样本微调"这一真正竞争范式的正面对比。论文的动机是"避免逐任务参数更新"，但若不同时报告"同样 3 条演示做梯度微调"的效果，就难以量化"测试时条件化"相对"轻量适配"的净收益。

  - 推理侧的上下文刷新阈值 0.65 是一个需要人工设定的超参，论文未说明其选取依据与鲁棒性。

## 6. 主要结果与结论（基于论文报告）

- **仿真主结果**：在 LIBERO 四个套件与 RoboTwin 2.0 两档难度上，方法整体优于所列基线（Octo、OpenVLA、π0-FAST、MolmoAct、π0、π0.5-KI、OpenVLA-OFT、VLA-0），论文强调其在长时程与双臂协调任务上的相对优势更明显，而在短视野、单步语义明确的任务上优势收窄。
- **受控对照的关键发现**：相比 "VLA-0 w/ Naive ICL"（同样喂入检索到的演示但去掉掩码），完整方法取得稳定提升。这支持论文的核心论点：**单纯把演示拼进上下文并不足以带来机器人 ICL 能力**，关键在于训练时破坏"直接续写目标动作前缀"的捷径。
- **消融结论**：
  - 去掉 DTW 几何排序 → 检索退化为纯语义相似，性能下降，说明"语义-动力学失配"确实是主要误差来源之一。
  - 去掉语义硬过滤 → 候选池引入跨类干扰，性能下降，说明两类信号（语义过滤 + DTW 排序）是互补而非冗余的。
  - 两者同时保留（完整配置）最好。
- **检索器评测结论**：随着语义过滤、DTW 监督与多轮迭代挖掘逐步加入，Recall@1 / Recall@5 单调改善，说明 RD-Encoder 确实学到了"语义相容 + 阶段对齐"的联合表征；论文以此论证检索质量的提升是下游性能提升的重要来源。
- **敏感性结论**：示例数 $N_e$ 从 1 增加到 3 时收益明显，继续增加则趋于饱和甚至因上下文过长而下降；挖掘轮数 $N_{iter}$ 在 5 轮附近收敛（与 $\epsilon=5\%$ 的停止准则一致）。
- **定性结论**：在长时程复合指令（如"先开抽屉再放入物体"）中，检索到的参考微演示会随执行进度自动切换到当前子任务对应的片段，与视觉规划器给出的 $T_{sub}$ 推进同步，说明"子任务级微演示切分 + 阶段感知检索"的设计是有效的。
- **真机结论**：在光照变化、桌面干扰物、传感器噪声与接触动力学扰动下，方法仍保持可用的成功率，表明其不是对仿真视觉分布的过拟合；但论文也承认真机任务相对结构化。
- **总体结论**：VLA 的适配可以被重新表述为**固定策略下的少样本测试时条件化**问题；只要同时解决时间尺度对齐（微演示切分 + DTW）与捷径抑制（Target Action Masking），上下文学习就能在机器人底层控制中真正起作用，而无需逐任务梯度更新。

## 7. 局限性

- **检索依赖演示库覆盖**：ICL 的上限由库中是否存在语义相容且阶段对齐的演示决定；对库外全新任务，方法可能退化为"选一个最不坏的参考"，论文未给出库外泛化的量化分析。
- **离线监督依赖真值轨迹**：DTW 监督需要带标注的示例轨迹（含未来动作），因此演示库的构建与扩充仍需遥操作或高质量数据采集，降低了"零成本适配"的程度。
- **无参数更新的承诺与代价**：冻结策略虽避免了逐任务微调，但把复杂度转移到了检索与 prompt 构造，推理时的上下文长度、检索开销与刷新机制会带来延迟成本，而论文未报告效率指标。
- **平台与形态受限**：真机仅 Aloha 双臂，动作空间与本体感受定义绑定具体硬件；跨具身迁移（不同自由度、不同末端执行器）未验证。
- **掩码机制的理论刻画不足**：Target Action Masking 的有效性目前是经验性的，缺少对"为何能抑制复制行为"的形式化解释（例如与曝光偏差 / teacher forcing 问题的联系仅被暗示）。

## 8. 对读者的启示与可迁移点

- **"ICL 不等于把示例拼进 prompt"** 是本文最可迁移的教训：在连续控制这类时间结构敏感的领域，上下文既可能提供任务信息，也可能提供误导性的动作前缀，训练目标必须显式地削弱后者的可利用性。
- **两阶段解耦**（先训检索器、再冻结检索器训策略）是一个实用的工程范式，避免检索分布与策略分布互相追逐导致训练不稳定。
- **用 DTW 做离线监督、但不在推理时使用 DTW** 的做法值得借鉴：它把难以在推理时获得的"未来动作"信息压缩进一个只依赖可观测输入的嵌入空间中，属于典型的知识蒸馏式设计。
- **子任务级切分**是连接"长轨迹演示"与"短动作块预测"的通用桥接手段，对任何需要以 chunk 形式输出动作的策略都有参考价值。
