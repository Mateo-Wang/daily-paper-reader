## 摘要
稀疏表示将端到端驾驶系统的环境感知形式化为一组离散元素，如目标和车道线。这种表示在拥挤、遮挡场景中会遇到安全风险，需要应对非结构化障碍物、不确定区域以及错综复杂的交互。本文提出一种密集表示——风险感知占据，以显式且统一的方式刻画与规划相关的风险。它将全局场景占据、地图导出的交通约束以及未来动态智能体占据联合编码到统一的BEV地图中。统一的BEV地图在空间和时间维度上捕获用于轨迹规划的风险证据。我们设计了一个端到端网络ROIDrive来实现风险感知占据。它通过独立分支预测风险感知占据，并将其注入规划查询，以生成安全导向的轨迹。此外，为量化安全问题，我们引入了基于nuScenes和Occ3D-nuScenes构建的RiskOcc4D-nuScenes。在nuScenes上，我们的风险感知占据在UniAD指标下实现了52.9%的相对开环碰撞减少，在ST-P3指标下实现了35.0%的相对开环碰撞减少。

## Abstract
Sparse representation formulates the environment perception for the end-to-end driving system as a set of discrete elements like objects and lane lines. This formulation meets safety risks in crowded, occluded scenes dealing with unstructured obstacles, uncertain regions, and intricate interactions. In this paper, we propose a dense representation, risk-aware occupancy, to characterize planning-relevant risks in an explicit and uniform manner. It jointly encodes global scene occupancy, map-derived traffic constraints, and future dynamic agent occupancy into a unified BEV map. The unified BEV map captures the risk evidence for trajectory planning in both spatial and temporal dimensions. We design an E2E network, ROIDrive, to realize risk-aware occupancy. It predicts risk-aware occupancy with an independent branch and injects it into planning queries for safety-oriented trajectory generation. In addition, to quantify the safety problem, we introduce RiskOcc4D-nuScenes built upon nuscenes and occ3d-nuscenes. Our risk-aware occupancy yields relative open-loop collision reductions of 52.9% under the UniAD metric and 35.0% under the ST-P3 metric on nuScenes.

## 1. 核心问题与整体含义

- **研究背景**：端到端（E2E）自动驾驶当前主流采用**稀疏表示**，即将环境感知形式化为离散的目标（agents）与车道线（map elements）集合。这种表示在常规场景下表现良好，但在**拥挤、遮挡、非结构化障碍物、不确定区域和复杂交互**场景下存在显著安全风险。
- **核心问题**：
  - 稀疏表示只能建模被检测到的离散目标，无法显式表达**遮挡盲区、非结构化障碍、未定义空间**等规划相关风险。
  - 传统 3D 语义占据虽然稠密，但存在**高冗余、任务无关信息多、语义与规划目标错位**等问题，难以直接量化碰撞威胁与法规约束。
  - 感知目标与下游规划决策**解耦**，缺乏面向安全的统一接口。
- **整体含义**：作者主张用**稠密的、面向规划的风险场**替代稀疏表示，让规划器能够直接查询候选轨迹周围的风险，从而将感知目标与安全决策对齐，为 L2/L4 自动驾驶提供可解释、可检查的安全表示。

## 2. 方法论

### 2.1 核心思想

- 提出**风险感知占据（Risk-Aware Occupancy）**：一种稠密 BEV 表示，将**全局场景占据、地图导出的交通约束、未来动态智能体占据**统一编码为单一风险场。
- 每个 BEV 单元携带可比较的**风险分数**，由物体几何、安全语义先验、地图约束和未来运动线索共同决定。
- 将规划相关的 3D 结构投影到 BEV，降低垂直冗余，并与现代 E2E 网络的特征布局对齐，使其**既可作为感知监督目标，又可作为规划的中间特征**。

### 2.2 关键公式

- **面向规划的最小充分统计量提取**：
  `R* = arg max_R I(R; T_plan)`，约束为 `dim(R) ≪ dim(V)`
  即最大化风险表示 R 与最优轨迹 T_plan 之间的互信息，同时大幅压缩维度。

- **双轴降维**：
  - **空间轴**：仅保留关键高度区间 `H_crit ∈ [0 m, 2.2 m]`（车辆相关碰撞区域），丢弃无威胁空域。
  - **语义轴**：用**物体高度**作为主要风险量化指标替代细粒度类别；弱势道路使用者（VRU）保留语义先验并获得更高风险权重。

- **分层风险量化**：
  - 静态全局障碍风险：`V_global_risk ∈ [0.2, 0.7]`
  - 动态物体风险：`V_dyn_risk ∈ [0.5, 1.0]`
  - 二者**故意重叠**以强制优先级：动态碰撞 > 静态障碍 > 法规风险。
  - 通过**最大聚合**（max operator）解决碰撞与法规项冲突，避免梯度冲突。

- **监督信号（风险决策理论）**：
  `L(T_plan | Z) = E[max(ℓ_col(T_plan, O), ℓ_reg(T_plan, M)) | Z]`
  其中 ℓ_col 为碰撞风险，ℓ_reg 为法规风险。

### 2.3 ROIDrive 框架

- 基于 query-based 生成式 E2E 范式（BEVFormer backbone + agent/map queries + 条件 VAE 规划器）。
- 针对两个结构弱点——**表示稀疏**与**token 稀疏不可靠**——设计两个模块：

  - **风险感知占据分支（RiskOcc Branch）**：
    - BEV 特征经通道压缩后，由 **Bi-Mamba2 状态空间块**建模（O(N) 复杂度捕获长程依赖），再上采样。
    - 通过**查找表**将类别预测转换为归一化风险场 `R ∈ [0, 0.7]`，可选与 **SDMap+ 先验**融合。
    - 通过**滑动窗口采样**将风险场 token 化，经**交叉注意力**注入规划查询。
    - 与稀疏 token 正交：查询编码物体身份与位置，风险场编码每个位置的当前与近未来风险。
    - 提供**无检测依赖的回退机制**，可覆盖漏检危险。

  - **时序查询一致性模块（TQC）**：
    - 无学习参数，缓存前帧 agent 状态，经 CAN 总线自车运动对齐，匹配最近前驱。
    - 一致性权重融合特征余弦相似度与距离衰减空间分数。
    - 通过**几何平均门控**映射为 log-odds 偏置 β，以 stop-gradient 调制注意力：
      `Attn(Q, K, V) = softmax(QKᵀ/√d + sg(β)) V`
    - 一致 token 被放大，虚假/闪烁 token 注意力趋零；首帧回退到基础模型。

- **生成式规划**：经 RiskOcc 稠密化、TQC 重加权、ego slot 初始化的 instance token，由 VAE 编码为潜高斯分布 `p(z|T) ~ N(μ_i, σ_i)`，采样后经 GRU+MLP 解码为多模态自车与 agent 轨迹。

### 2.4 RiskOcc4D-nuScenes 数据集构建

- 基于 nuScenes 与 Occ3D-nuScenes，构建**首个 4D 风险感知占据基准**。
- 四条自动化标注流水线：
  1. **静态标注**：从 Occ3D-nuScenes 经 3D→BEV 归约，在 H_crit 内垂直边缘化，形态学膨胀-腐蚀 + 自定义卷积核修补。
  2. **车道线标注**：从 nuScenes 提取 80m×80m 语义图，对路面标线（斑马线、停止线、车道分隔线）赋 `V_risk = 0.1`。
  3. **可行驶道路标注**：融合 HD 地图可行驶掩码，填补未定义区域；对遮挡盲区赋予**非信息先验 0.05**（严格为正，编码认知不确定性）。
  4. **动态标注**：对 `v > 0.5 m/s` 的移动物体跨帧跟踪，记录未来 2.5s 内实际占据位置（0.5s 间隔），风险注意力与时间步成反比（近高远低），再经空间高斯扩散生成 Lipschitz 连续场。
- 输出两个地图：**全局风险感知占据图 R_Mt** 与 **动态风险感知占据图 R_Md**，提供三类目标：离散全局风险分类、连续全局风险回归、动态时序风险预测。

## 6. 主要结论与发现

- **安全性显著提升**：将预测的风险感知占据图融合进 GenAD，相比原始 GenAD 碰撞率降低 **52.9%（UniAD 指标）** 和 **35.0%（ST-P3 指标）**，且在所有时间跨度上一致改善，2s 时刻增益最大（UniAD ↓73.3%，ST-P3 ↓51.7%）。
- **最低平均碰撞率**：在 UniAD 协议下取得所有对比方法中最低的平均碰撞率（0.08%）。
- **风险分层是关键**：Binary Map 和 Gaussian Map 均劣于无地图基线，证明单纯的占据信号或额外交叉注意力参数不能带来增益，**有序的风险分层**才是核心机制。
- **动态与静态先验互补**：Bi-Mamba2 提供动态避障能力，SDMap+ 先验填补静态盲区，二者结合取得最低平均碰撞率。
- **ROIDrive 模块协同**：RiskOcc 提供稠密风险先验，ego-token 初始化显著降低 L2（UniAD 0.52→0.34），TQC 进一步降低碰撞（UniAD 0.15%→0.08%）且几乎不损失 L2。
- **占据预测基准结论**：DHDOcc-M 在 mIoU（34.15）和动态 Mask-MAE（0.559）上领先；FB-Occ 在回归（MAE 0.075）和 SSIM（0.480）上最优，且速度-精度权衡最佳（34.1 FPS）。

## 7. 优点

- **表示设计有原则**：从互信息最大化出发形式化风险表示，通过空间/语义双轴降维实现"面向规划的最小充分统计量"，理论动机清晰。
- **统一性与兼容性**：将碰撞风险、法规约束、动态未来风险统一到单一 BEV 风险场，且与现有 3D 占据算法完全兼容，可直接迁移。
- **即插即用**：风险图通过滑动窗口采样 + 交叉注意力注入，保持原 E2E 协议不变，可无缝集成到任意 query-based E2E 框架。
- **分层风险设计巧妙**：动态与静态风险区间故意重叠，强制优先级顺序，避免多任务梯度冲突。
- **数据集贡献**：RiskOcc4D-nuScenes 是首个 4D 风险感知占据基准，四条自动化流水线覆盖静态、法规、可行驶区域和动态未来线索，对遮挡和点云稀疏区域有专门处理（非信息先验 0.05）。
- **消融严谨**：通过 Gaussian Map 控制组排除了参数容量解释，通过 Binary Map 排除了单纯占据解释，证据链完整。
- **效率考虑**：Bi-Mamba2 实现 O(N) 长程依赖建模；TQC 无学习参数、仅推理时生效，轻量。
