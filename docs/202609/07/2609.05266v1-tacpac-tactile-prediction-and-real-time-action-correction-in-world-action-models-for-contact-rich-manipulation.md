## 摘要
世界动作模型通过预测的未来观测来引导动作生成，但以视觉为中心的预测会错过决定高接触操作的局部接触线索。然而，在我们的实验中，简单地将未来的触觉观测作为附加视图进行预测，仅能恢复可达成收益的三分之一。这一差距反映了时间错配：预测先于执行，而触觉反馈在执行过程中才到达。我们提出了TacPAC，它将触觉预测转化为实时动作修正。一旦基础模型规划出一个动作块，TacPAC会将该规划所依赖的预测接触信息与规划自身的表示一起缓存，并由触觉专家将每个新观察到的触觉图像与该缓存进行比对，以修正尚未执行的动作。因此，反馈是依据规划的预期来解释的，而不是孤立地解释；一次修正只需对该缓存进行单次扫描，比重新生成该动作块便宜$20.7\times$。在五个涵盖精密插入、易碎物体处理、物体重新定向和长时程操作的真实机器人任务中，TacPAC在每项任务中均表现最佳，并将平均成功率从仅视觉基础模型的22%提高到64%。代码可在 https://github.com/LogosRoboticsGroup/TacPAC 获取。

## Abstract
World-action models guide action generation with predicted future observations, but vision-centric predictions miss the local contact cues that decide contact-rich manipulation. However, naively predicting future tactile observations as additional views recovers only a third of the achievable gain in our experiments. This gap reflects a timing mismatch: predictions precede execution, while tactile feedback arrives during it. We introduce TacPAC, which turns tactile prediction into real-time action correction. Once the base model has planned an action chunk, TacPAC caches the predicted contact that plan was conditioned on together with the plan's own representation, and a tactile expert reads each newly observed tactile image against that cache to correct the actions not yet executed. Feedback is thus interpreted against what the plan anticipated rather than in isolation, and one correction is a single pass over that cache, $20.7\times$ cheaper than regenerating the chunk. On five real-robot tasks spanning precision insertion, fragile-object handling, object reorientation, and long-horizon manipulation, TacPAC leads every task and raises the average from 22% for its vision-only base model to 64%. Code is available at https://github.com/LogosRoboticsGroup/TacPAC.

### 1. 论文的核心问题与整体含义

**研究动机：**
接触丰富型操作（contact-rich manipulation）的性能高度依赖机器人通过物理接触获得的局部信息，而不仅仅是可见的场景几何。例如，插入充电器插头需要精确对齐，抓取薯片需要在提起时不过度施力造成破碎，这类任务中细微的错位、滑移或变形往往在普通RGB图像中不明显或被遮挡，但触觉传感器可以捕捉。

**现有方法的问题：**
- 世界动作模型（World-Action Models, WAMs）通过预测未来的观测来引导动作生成，但预测通常以视觉为主，缺少局部接触线索。
- 直接将触觉观测作为额外的“视频流”加入预测目标（即触觉预测式WAM），实验表明只恢复了可实现增益的约三分之一。

**关键缺陷（时间错配）：**
预测发生在执行之前，而触觉反馈发生在执行过程中。即使能准确预测未来触觉，一旦动作块被提交，预测结果便固定不变——它无法根据执行中实际出现的触觉偏差来修正尚未执行的计划动作。

**核心挑战：**
如何将触觉预测与执行过程中实时到达的触觉证据连接起来，使预测能够作用于动作修正而非仅用于一次性的规划。

**论文核心含义：**
这项研究提出TacPAC，通过“缓存预期接触 + 实时触觉比对”的方式，将世界模型中单调的“前瞻–执行–固定动作块”流程改造为闭环任务：预测的接触不再是结束，而是执行中动作修正的参照基准。

### 2. 论文提出的方法论

**核心思想：**
TacPAC把一个触觉预测型世界动作模型（基础模型）与一个轻量级实时触觉修正器结合起来。基础模型规划动作块时，对接触的未来变化进行预测；规划完成后，不是将计划和预测丢一边，而是把它们作为“缓存”（cache）保留下来。执行过程中，每个新到达的触觉图像都被触觉专家与缓存比对——只有当现场触觉和计划预期不一致时才修正剩余动作。反馈被解读为“与计划的预期之差”，而不是孤立的触觉状态。

**架构：**
- 三专家混合Transformer（Mixture-of-Transformers, MoT）：视频专家、动作专家、触觉专家。
  - 视频专家负责生成未来的视觉和触觉观测（被建模为同一视频流的不同view）。
  - 动作专家在生成动作时让动作token attend到视频（包括触觉）预测结果，从而让动作计划受到预期接触影响。
  - 触觉专家是新增的轻量组件，执行期间接收当前触觉图像，attend到“触觉–动作KV缓存”并直接输出每个未执行步骤的delta_action。
- 触觉预测任务通过将两个触觉传感器图像与相机画面一起tile进单一视频latent来实现，以条件流匹配（conditional flow matching）进行训练。

**缓存策略的细节：**
- 基础模型完成去噪之后，在干净的预测 latent（τ=0）上再做一次前向，存下每一层的key和value。
- 缓存里只保留两组token：预测的触觉token和动作token。视觉token不缓存——执行中场景变化较小，且缓存中的视觉信息是通过注意力隐式携带的。
- 每个新触觉图像与缓存比对：它被编码到相同tokenizer/patch embedding空间；同时把“已执行部分”替换为实际发给机器人的命令，并用学习的状态embedding区分已执行/未执行。
- 一个修正只需一次单pass over固定缓存，不需要重新去噪或重算视频。

**训练流程（两阶段）：**

阶段1（基础模型训练）：训练视频专家与动作专家。输入是第一个视觉–触觉帧，未来视频latent和动作块都加噪，输出是视频velocity与动作velocity。损失函数是视觉（含触觉）流匹配损失+动作流匹配损失。

阶段2（触觉专家训练）：
- 冻结阶段1的所有参数。
- 初始化时直接用训练好的动作专家权重（因为结构匹配，更容易消费缓存）。
- 每次训练迭代冻结基础模型，从头生成一个plan并预填充缓存；然后为同一plan采样K=4个执行偏移量m。
- 对偏移量m，把动作块前m步替换为真实执行动作（ground truth），触觉输入取该偏移下记录的真实触觉图像，监督损失只覆盖未执行的后缀，要求delta_action把计划动作修正为真实动作：

  \( L_{tac} = \frac{1}{H-m} \sum_{i \ge m} \| \hat{a}_i + \Delta a_i - a_i \|^2 \)。

该设计的关键点：在同一次episode中，一个冻结plan与prefill可以被多个偏移共享，因此只增加少量前向开销。

**异步推理机制：**
- 每当触觉帧到达，触觉专家生成一次修正，可能来不及在执行触发的chunk offset立即写入机器人；
- 方案是训练时条件化于实际触觉出现的offset m，但写入时只从 m+d 开始（d为最近滞后窗口的最大延迟，实测中通常d=0）。
- 这种设计避免了累积误差：新修正不依赖上一次修正，每次都是对原始计划块的剩余部分直接重算delta，之前错误的修正不会传播。

### 6. 论文的主要结论与发现

1. 综合表现：TacPAC在5个接触丰富真实任务上全部领先；平均成功率为64%，而最强的触觉世界模型基线T-Rex是48%，差距达16个点。
2. 逐步拆解视角：
   - 学习触觉预测（不分修正）只让成功率从22%改善到37%，而完整系统达到64%，说明预测提升很小，主要受益来自于把预测和实时修正结合起来。
   - 仅做反应式修正（没有预测）也不够，平均33%，仅与仅预测的37%相当，且在许多任务上性能较低。
   - 缓存的存在极有价值：在同一系统下，将触觉专家与缓存的触觉key连接（即让待修正确认“预期接触”），从47%提升到64%（提升17个点）。
3. 实时性：单次修正平均30.4 ms，等效约33 Hz的修正率，比重新生成完整动作块便宜20.7倍。运行期间触觉专家几乎没有造成执行延迟（只有1.6%的调用产生额外一个步的延迟），说明可以实时响应当前触觉反馈。
4. 理论含义：TacPAC确认了接触反馈只有“相对于计划预期”解读才有实际价值。这为闭环触觉控制提供了一种通用范式——将预测未来与在线执行打通。

### 7. 优点

**方法设计亮点：**
1. 发现问题背后的关键时序矛盾，并直接创建一个缓存机制来补上它，而不是简单增加更多触觉模态或更大模型。
2. 三专家MoT架构清晰解耦了基础模型（视觉+动作）与修正器（触觉），修正器很小且只做单pass，保持了高效性。
3. 消除了预测递归误差：修正不建立在前一次修正基础上，不会使误修正传播。
4. 采用“已执行开prefix + 未执行delta”结构，天然与执行状态对齐，可处理异步延迟（d窗口），工程实现考虑细致。
5. 触觉图像和视觉图像统一tokenize，不需要特制触觉编码器，简化了实现，同时仍能获得很好效果。
6. 训练阶段2在冻结基础模型的计划上进行监督学习，实现了learned corrector和角色一致的“以自己人为假设对比的真实触觉与ground truth命令”，这很符合教学信号的本质。

**实验分析亮点：**
1. 触觉活动分析量化了接触变化的时间稀疏性：接触过渡帧仅占4.9%但承载总量18.6%的触觉“变化”，有说服力地解释了为什么仅预测触觉不够。
2. 表格Q3的消融设计干净地分离了预测 vs 修正 vs 缓存三者的因果作用，而不是笼统地“模型大/小”。
3. 每项结果都有细致解读（比如Dream-Tac在损坏类任务上胜过T-Rex，T-Rex在插入类任务更优，解释接触预期与反馈响应差别）。

---

### 8. 不足与局限

**覆盖范围局限：**
1. 只评估在单个机器人、两个触觉传感器和固定任务集合上，尚不清楚在更广的工作平台或更长时间操作中是否有效。
2. 没有涵盖复杂的双手操纵或全身移动，只涵盖了单个6/7自由度臂。
3. 数据来自遥操作+相对固定的起始配置与场景，泛化到不同物体位置/光照/物体相同但姿态多变的情况仍需要更强验证。

**方法局限：**
1. 触觉专家仅修正动作块内部的未执行步骤，未来需要修改时只能在固定H=48的块长内修改，无法在块中途扩展或额外插入新步骤。对于更长的操作序列可能需要大量触觉与缓存周期性刷新。
2. 缓存固定且不更新：如果接触状态发生重大而持久的改变（比如物体滑走、抓取点偏移很大），缓存将失去意义，可能会导制错误修正。作者并未处理长期漂移或历史缓存重刷。
3. 动作块的生成仍为主时序，修正回路依赖“d步延迟”的近似，如果系统时间抖动较大，仍可能导致小的修正不精确。

**实验统计局限：**
1. 每种方法仅20次物理试验，部分任务（bottle–40%）未报告成功置信区间，统计可靠性相对有限。
2. 消融表数字可能来自20次试验但并未明确标注每次消融是否为固定20次，需要查看附录确认。
3. 没有进行多轮种子重复以评估随机方差。

**算力资源披露不足：**
4. 报告了8×H100、10 epoch与batch 64，但没有报告具体训练时间，也不清楚总共收集了多少demonstration episodes（每个任务多少demonstration——除了诊断样本）。

---

### 结论

TacPAC为高接触操作中利用世界模型的预测能力提供了一个务实的闭环范式：用缓存将“预测”保留为执行期间的参照，让每个触觉帧都可以通过注意机制与预期比对，在避免重新规划的高算力开销的同时提升成功率和鲁棒性。该思想在精度插入、易碎物体抓取和姿态稳定等任务上效果显著。该方法距离真正的通用操纵还有距离，但为触觉预测模型提供了新的工作基线。
