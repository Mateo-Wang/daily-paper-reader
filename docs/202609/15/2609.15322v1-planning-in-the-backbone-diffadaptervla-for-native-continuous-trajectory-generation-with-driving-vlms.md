## 摘要
预训练的驾驶视觉语言模型（VLM）将视觉、路线、语言和驾驶上下文整合为丰富的驾驶先验，然而其表示目标仍与连续驾驶规划相分离。现有方法通常仅在 VLM 形成最终条件之后才开始轨迹生成，使各深度的条件计算处于轨迹状态的逐步形成过程之外。我们提出 DiffAdapterVLA，它实现了“骨干网络中的规划”：将显式轨迹 token 注入选定的 VLM 后层，把轨迹状态引入骨干网络前向计算，使其在不同深度上与驾驶条件协同演化。轻量级的逐层 DiffAdapter 将这一计算组织为递归轨迹细化，而非对称联合注意力则保留从条件流到轨迹规划的有向引导。通过将规划置于现有骨干网络计算之中，而不是依赖独立的轨迹规划器，DiffAdapterVLA 仅适配轻量级轨迹模块，便将现有驾驶先验转化为高效的连续规划能力。NAVSIM 结果表明，它以少量可训练参数实现了高质量的闭环规划与较低的端到端延迟，并证明在 VLM 后层计算中联合演化轨迹状态和各深度驾驶条件能够有效实现连续轨迹规划。

## Abstract
Pretrained driving vision-language models (VLMs) integrate visual, route, language, and driving context into rich driving priors, yet their representation objectives remain separated from continuous driving planning. Existing methods typically begin trajectory generation only after the VLM has formed a final condition, leaving depth-wise condition computation outside the stepwise formation of trajectory state. We introduce DiffAdapterVLA, which realizes Planning in the Backbone: it injects explicit trajectory tokens into selected VLM late layers, bringing trajectory state into backbone forward computation, where it co-evolves with driving conditions at different depths. Lightweight layer-wise DiffAdapters organize this computation into recursive trajectory refinement, while asymmetric joint attention preserves directed guidance from the condition stream to trajectory planning. By placing planning within existing backbone computation rather than relying on an independent trajectory planner, DiffAdapterVLA adapts only lightweight trajectory modules to turn existing driving priors into efficient continuous planning capability. NAVSIM results show that it achieves high-quality closed-loop planning with low end-to-end latency using few trainable parameters, and demonstrate that jointly evolving trajectory state and depth-wise driving conditions in VLM late-layer computation effectively realizes continuous trajectory planning.

## 2. 方法论

### 核心思想
- 将显式**轨迹 token** 注入冻结驾驶 VLM 的选定后层，使轨迹状态在骨干前向计算中与不同深度的驾驶条件**协同演化**；用轻量逐层 **DiffAdapter** 组织为递归轨迹细化，不依赖独立外部规划器。

### 基础设定
- 条件：\(c_t = (I_{1:M}^t, r_t, h_t)\)，即多相机观测、路线信息、车辆历史与驾驶上下文。
- 目标：生成 \(H\) 个未来路点的连续轨迹 \(x_0 = [p_{t+1}, \dots, p_{t+H}] \in \mathbb{R}^{H \times d}\)。
- 骨干：\(L\) 层预训练驾驶 VLM \(F_\theta\)，条件 token 逐层传播 \(H_{\ell+1} = F^\ell_\theta(H_\ell)\)；实例化为 Cosmos-Reason2-8B（来自 Alpamayo-1.5-10B），参数 \(\theta\) 全程冻结。

### 条件扩散与去噪
- 前向加噪：\(x_s = \sqrt{\bar\alpha_s} x_0 + \sqrt{1-\bar\alpha_s}\epsilon\)。
- 条件去噪器预测噪声 \(\hat\epsilon = \epsilon_\phi(x_s, s; c_t)\)，用标准噪声预测损失 \(L_{denoise} = \mathbb{E}\|\epsilon - \epsilon_\phi\|_2^2\) 训练。
- 推理采用 DDPM 噪声参数化 + DDIM 式确定性采样，从高斯噪声出发经 5 步等间隔 \(x_0\) 投影恢复轨迹。

### 历史轨迹编码器
- 输入 ego 位置历史 \(h_t^{ego} \in \mathbb{R}^{T_h \times 3}\) 与有效性掩码 \(m_i\)。
- 构造 7 维描述子 \(r_i = [q_i, \Delta q_i^{xy}, m_i, \rho_t]\)，保留绝对位置、局部平面运动与观测有效性。
- 线性投影归一化后做核大小 3 的**深度可分离时序卷积**（不混合隐藏通道），再经掩码均值池化，最后通过两个残差 MLP 得到共享运动上下文 \(g_t \in \mathbb{R}^D\)，被所有选中后层 DiffAdapter 共享。

### DiffAdapter（逐层轨迹细化）
- 轨迹 token 嵌入：\(z^0_{s,i} = W_{traj}x_{s,i} + e_i^{pos} + e^{type} + e_s^{time}\)，即投影状态 + 未来位置嵌入 + 轨迹 token 类型嵌入 + 扩散步嵌入（正弦嵌入经 SiLU MLP）。
- 前 \(L-K\) 层冻结 VLM 层处理多模态条件得到 \(C^{L-K}\)；随后轨迹 token 追加进联合序列，穿越最后 \(K\) 层。
- 每层后接独立 DiffAdapter，仅更新轨迹切片：\(C^{\ell+1} = \tilde C^{\ell+1}\)，\(Z_s^{\ell+1} = A^\ell(\tilde Z_s^{\ell+1}, \tilde C^{\ell+1}, g_t, s)\)。
- Adapter 内部（384 维瓶颈、8 注意力头）：
  - 时间步 \(s\) 经 SiLU MLP 产生 AdaLN 仿射调制与各残差门控（时序混合、自注意力、历史融合、FFN）。
  - 时序混合：深度卷积 3 混合相邻未来路点；自注意力：捕获路点长程依赖。
  - 交叉注意力：轨迹状态为 query，投影后的条件 token 为 key/value，无效条件位置被排除。
  - 历史摘要 \(g_t\) 广播到每个轨迹 token，经门控 GELU MLP 融合；随后门控 FFN，瓶颈上投影并加外层残差。
- 输出：最终轨迹 token 经 VLM 最终归一化层与轻量线性读出，预测噪声 \(\hat\epsilon_s = W_{out}Z_s^L + b_{out}\)。

### 条件保持的非对称联合注意力
- 对条件与轨迹两路 token 设定**非对称读取权限**：
  - 条件 query 不能关注轨迹后缀（保留 VLM 原始因果掩码 \(M^{cond}\)）。
  - 轨迹 token 可关注所有有效条件 token，且轨迹之间双向交互。
  - 条件 token 到无效条件的注意力被置为 \(-\infty\)。
- 效果：驾驶条件引导轨迹去噪，但含噪轨迹信息不会污染条件流，保持条件流原始传播。

### 推理与条件复用
- 去噪过程中条件 \(C^{L-K}\)、有效性掩码与位置信息可缓存复用；历史编码 \(g_t\) 每样本仅计算一次，跨去噪步与后层共享。
