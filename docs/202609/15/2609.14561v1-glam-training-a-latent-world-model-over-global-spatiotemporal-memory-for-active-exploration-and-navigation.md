## 摘要
主动探索与语义导航要求具身智能体从部分观测中构建记忆，预测已观测空间记忆的演化如何支持未来运动，并将该预测转化为可执行的规划。我们提出 GLAM，一种在全局时空记忆上训练的目标条件潜在世界模型，以及围绕其构建的完整导航系统 GLAM NAV。给定历史地图 token、导航目标和当前机器人位姿，GLAM 联合预测未来地图表示和以机器人为中心的路点潜在表示，从而能够在共享表示空间中推断未来空间上下文与导航意图。该模型遵循类似 JEPA 的潜在预测范式，直接作用于地图级潜在 token，而非进行 RGB 重建，并使用预训练的路点编码器-解码器在 GLAM NAV 中监督和解码导航规划。训练数据通过在 Habitat 中回放基于 HM3D v0.2 场景资源的 ObjectNav 专家轨迹，并将其切分为多时间尺度预测样本而收集。在受控的 HM3D-ObjectNav 子集复现设置中，GLAM NAV 在成功率和按路径长度加权的成功率两方面均优于复现的 BSC-Nav 基线。

## Abstract
Active exploration and semantic navigation require an embodied agent to build memory from partial observations, predict how the evolution of observed spatial memory may support future motion, and convert that prediction into actionable plans. We present GLAM, a goal-conditioned latent world model trained over global spatiotemporal memory, and GLAM NAV, the complete navigation system built around it. Given historical map tokens, a navigation goal, and the current robot pose, GLAM jointly predicts future map representations and robot-centric waypoint latents, allowing future spatial context and navigation intent to be inferred in a shared representation space. The model follows a JEPA-like latent prediction paradigm, operates directly on map-level latent tokens rather than RGB reconstruction, and uses a pretrained waypoint encoder-decoder to supervise and decode navigation plans within GLAM NAV. Training data are collected by replaying ObjectNav expert trajectories in Habitat over HM3D v0.2 scene assets and slicing them into multi-timescale prediction samples. On a controlled HM3D-ObjectNav subset reproduction setting, GLAM NAV improves over a reproduced BSC-Nav baseline in both success rate and success weighted by path length.

# GLAM 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：目标物体导航（Object-Goal Navigation）要求具身智能体在陌生环境中，仅凭局部第一人称观测找到指定类别的物体。目标可能初始不可见或随移动脱离视野，因此导航同时依赖**累积的空间知识**与**"下一步去哪探索"的决策**。
- **现有方法的局限**：
  - 语义探索类方法（SemExp、PONI、VLFM）证明显式地图、物体先验、地图接地的子目标选择有效，但**只做"记忆检索"，不预测记忆的未来演化**。
  - 结构化空间记忆系统（ConceptGraphs、BSC-Nav）强调持久地图与检索，但**未把"未来地图演化"与"路点规划"统一为联合潜预测问题**。
  - 潜在世界模型（I-JEPA、DINO-WM、PlaNet、MuZero）证明可不做像素重建而预测未来状态，但尚未被引入语义导航中，与全局记忆上下文结合。
- **核心问题**：如何从一个持久、空间索引的地图中，**联合学习"未来空间记忆预测"与"目标导向路点规划"**？
- **整体含义**：论文提出 **GLAM**（目标条件潜在世界模型）与 **GLAM NAV**（完整导航系统），把"记忆—预测—规划"放在同一表示空间内，功能上类比海马-内嗅系统的空间索引、位置-事件绑定、预测性回放，以及前额叶的目标条件记忆检索与规划控制（明确声明是功能类比，非生物电路实现）。

## 2. 方法论

### 2.1 核心思想
- 遵循 **JEPA 式潜空间预测范式**：直接回归连续的未来表示，**不重建未来 RGB**，而是预测**地图级潜 token** 与**机器人中心路点潜变量**。
- 视觉查询与路点查询在**单次前向**中一并输入，共享同一记忆、目标、位姿上下文，实现两路输出的联合预测。

### 2.2 模型形式化
- 输入：历史地图 token 序列 $Z_{t-H+1:t}$、目标描述 $g$、当前位姿 $p_t$，以及可学习查询 $Q_v$（未来地图）、$Q_w$（路点）。
- 输出：
$$\left(\hat{Z}_{t+1:t+F},\ \hat{E}^w_{t+1:t+F}\right) = \mathcal{F}_\Theta(Z_{t-H+1:t}, g, p_t, Q_v, Q_w)$$
- $H$ 为历史长度，$F$ 为预测时域；两路输出分别表示未来地图 token 与路点潜变量。
- 主干网络为 **Qwen3.5-0.8B**。

### 2.3 地图 token 编码
- 由 **4 个 RGB-D 视角**构造；视觉特征投影到体素网格并在体素内融合。
- 体素坐标表达在**当前机器人坐标系**，使用**三维空间 RoPE** 编码位置。
- token 序列截断或零填充到固定长度，并用有效性掩码标记非填充位。
- 线性输入投影映射到 **2560 维**表示。

### 2.4 路点潜变量编码
- 路点表示为机器人中心平面位姿增量 $(\Delta x, \Delta y, \Delta\theta)$。
- 归一化与正余弦朝向编码：
$$u = \left[\text{clip}(\tfrac{\Delta x}{s_x},-1,1),\ \text{clip}(\tfrac{\Delta y}{s_y},-1,1),\ \sin\Delta\theta,\ \cos\Delta\theta\right]^\top,\quad e_w = \phi(u)\in\mathbb{R}^{2560}$$
- 平移尺度 $s_x,s_y$ **仅由训练集估计**。
- 编码器 $\phi$ 为两层 MLP（$4 \to d_a \to 2560$）+ LayerNorm；解码器 $\rho$ 与 $\phi$ **联合预训练**（最小化归一化路点重构 MSE），预训练独立于世界模型，之后**两者冻结**：$\phi$ 提供监督目标，$\rho$ 在推理时把预测潜变量解码为归一化路点：$\hat{u}_j = \rho(\hat{e}^w_j)$。

### 2.5 训练损失
- 联合目标为两路掩码 MSE：
$$\mathcal{L} = \lambda_v \text{MSE}_{m_v}(\hat{Z}, Z^*) + \lambda_w \text{MSE}_{m_w}(\hat{E}^w, \phi(U^*))$$
- 掩码 MSE 定义为：
$$\text{MSE}_m(\hat{X},X^*) = \frac{\sum_\ell m_\ell \|\hat{x}_\ell - x^*_\ell\|_2^2}{d\sum_\ell m_\ell},\quad \sum_\ell m_\ell > 0$$
- 即同时按**有效目标位置数**与**目标表示维度**归一化。路点损失 $d=2560$，地图损失用未来地图目标特征维度。
- **不使用语言模型交叉熵项**；训练时优化主干、输入投影、可学习查询与两个回归头。

### 2.6 GLAM NAV 系统组成
- **感知、检索与目标验证模块**：接收 RGB-D、位姿、运动状态，生成语义潜特征，投影到全局地图；检索目标相关地图上下文并判断目标是否已在观测/记忆中验证；已验证则直接导航，否则触发预测性探索与规划。
- **时空记忆模块**：由**地标记忆 + 图-体素记忆**构成稀疏空间记忆；更新时比较新观测与已有记忆，决定单元是新增、融合还是刷新；检索时用语义信息及关联潜特征定位候选导航点。
- **GLAM 主干**：预测核心，输出未来地图表示与路点潜计划。
- **规划专家**：接收检索到的地图上下文与 GLAM 预测，提出/接地可行子目标，向底层控制器发送可执行指令。**明确划分边界**：GLAM 只负责潜预测，几何执行、可达性检查、避障运动由系统其余部分负责。
- **闭环流程**：环视建图 → 目标相关检索 → 已验证则直达，否则 GLAM 预测未来地图与路点 → 解码路点 → 执行 → **仅用真实观测更新记忆** → 再次验证 → 循环。

## 3. 实验设计

- GLAM 在**单一潜世界模型**中统一了"未来地图预测"与"目标条件路点潜预测"，把记忆、预测、规划连接在同一表示空间，无需 RGB 重建。
