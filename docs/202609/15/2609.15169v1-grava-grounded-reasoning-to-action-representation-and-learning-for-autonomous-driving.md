## 摘要
驾驶视觉-语言-动作（VLA）模型日益先推理后行动，但其中间推理往往缺乏物理场景证据的支撑，且与可执行行为联系松散。我们提出 GRAVA，一个围绕基于场景证据的推理到动作（Grounded Reasoning-to-Action, GRA）构建的框架，该框架在单一自回归流中统一了场景落地、推理与动作生成。GRA 将动作相关的语言指代链接到二维视觉区域和以自车为中心的物理状态，在轨迹锚定的类型化图中组织物体交互与决策，并将该结构序列化为基于场景证据的推理。单个 VLM 生成该推理，随后生成紧凑的可执行规划器（Executable Planner）动作，该动作被确定性地解码为连续轨迹。我们进一步提出一个智能体式 GRA 数据构建流水线，将前向场景落地与后向轨迹锚定相结合，并用其构建 GR-NavSim，包含 220 万个基于场景证据的问答对和 7 万条 GRA 推理轨迹。渐进式训练策略通过预训练发展基于场景证据的认知，通过模仿建立推理到动作接口，并通过强化学习与探索改进驾驶行为。在仅使用约 60% 的可用人类驾驶示范进行动作监督的情况下，GRAVA-8B 在完整 NAVSIM 基准上取得了纯自回归驾驶模型中的最先进性能。在内部长尾基准上，完整 GRA 相比仅动作预测，分别将关键对象合规性和闭环驾驶得分提高了 19.3% 和 20.5%。这些结果表明，从基于场景证据的推理到可执行动作生成的过程中，保留动作相关物理证据具有优势。

## Abstract
Driving vision-language-action (VLA) models increasingly reason before acting, but their intermediate reasoning is often weakly grounded in physical scene evidence and loosely connected to executable behavior. We present GRAVA, a framework built around Grounded Reasoning-to-Action (GRA), which unifies grounding, reasoning, and action generation in a single autoregressive stream. GRA links action-relevant language references to 2D visual regions and ego-centric physical states, organizes object interactions and decisions in a trajectory-anchored typed graph, and serializes this structure into grounded reasoning. A single VLM generates this reasoning followed by a compact Executable Planner action that is deterministically decoded into a continuous trajectory. We further introduce an agentic GRA data construction pipeline that combines forward scene grounding with backward trajectory anchoring, and use it to build GR-NavSim with 2.2M grounded question-answer pairs and 70K GRA reasoning traces. A progressive training strategy develops grounded cognition through pre-training, establishes the reasoning-to-action interface through imitation, and improves driving behavior through reinforcement learning and exploration. Using about 60% of the available human driving demonstrations for action supervision, GRAVA-8B achieves state-of-the-art performance among purely autoregressive driving models on the full NAVSIM benchmark. On an internal long-tail benchmark, full GRA improves key-object compliance and Closed-loop Driving Score by 19.3% and 20.5% over action-only prediction, respectively. These results show the benefit of preserving action-relevant physical evidence from grounded reasoning through executable action generation.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型正成为自动驾驶的一种新兴范式，将多模态场景理解、推理与动作生成统一在通用生成模型中。近期工作开始在动作预测前引入显式中间推理，以应对复杂与长尾场景。
- **核心矛盾**：对驾驶任务而言，推理不仅要指出相关交通参与者，还必须说明这些对象通过哪些**物理状态与交互**约束自车行为（例如前车的车道占用、距离、运动状态）。这些与场景绑定的关系必须与最终生成的动作保持显式连接。
- **论文识别的两个根本性缺陷**：
  - **G1 接地鸿沟（Grounding Gap）**：语言推理与物理场景证据脱节。动作相关实体常以自由文本或高层语义描述，未显式对应到视觉区域与度量状态，导致"语义上合理"的推理可能与该场景中真实约束自车的物体、距离、运动无关。
  - **G2 推理—动作割裂鸿沟（Reasoning-to-Action Fragmentation Gap）**：即使存在接地，通常也通过独立的感知任务或问答任务引入，推理与规划分别由不同监督或不同功能模块实现，导致某一任务中建立的接地对象与状态未必被保留为后续交互推理、决策与动作生成的证据。
- **解决思路的动机**：场景相关性是**动作依赖**的——视觉显著的对象不一定是约束示范自车行为的对象，不同对象施加不同的交互要求。因此需要一个按"在驾驶决策中的角色"来组织场景证据的**动作接地表示**，把物理证据从推理一路保留到可执行行为。

## 2. 方法论

### 2.1 核心思想：Grounded Reasoning-to-Action（GRA）

- 在**单一自回归流**中统一接地、推理与动作生成，形成链式过程：`Ga → r → a → τ̂`（动作相关子图 → 接地推理序列 → 可执行规划器动作 → 连续轨迹）。
- 概率分解为：`πθ(y|x) = πθ(r|x) · πθ(a|x,r)`，即推理序列引入接地对象并解释其行为相关性，动作在该推理上下文中生成。
- 训练监督来自离线构建的目标图 `G* = A(x, τ*, z)`（x 为输入，τ* 为专家轨迹，z 为特权标注证据）；推理时仅需 x，不需要专家轨迹或特权信息。

### 2.2 轨迹锚定的类型化图（Typed Grounded Reasoning Graph）

- 定义为有向无环图 `G = (V, E, ν, η)`，节点集分解为：
  - `V^S` 场景/路线上下文节点
  - `V^O` 接地对象节点
  - `V^Ψ` 交互节点
  - `V^D` 物体级决策节点
  - 自车级决策节点 `vδ` 与终端动作锚点 `va`
- **对象接地三元组**：`o_i = (m_i, b_i, σ_i)`，其中 `m_i` 为语言指代，`b_i ∈ [0,1000)^4` 为归一化 2D 边界框，`σ_i` 为以自车为中心的物理状态（类别、相对位置、距离、速度、朝向等）。
- **分支—汇聚拓扑**：对每个关键对象 i，`(V^S, o_i) → {ψ_i} → d_i`（物体级决策），再 `(V^S, {d_i}) → vδ → va`（自车级决策）。这样每个物体的响应来源可追溯，再被合并。
- **结构接地约束**（防止推理脱离可观测证据）：
  - 每个交互/物体级决策节点必须至少有一个接地对象祖先：`Anc_G(v) ∩ V^O ≠ ∅`
  - 每个物体级决策必须贡献到自车决策：`d_i → vδ`
  - 自车决策必须到达动作锚点：`vδ → va`

### 2.3 图构建与序列化

- **双向构建**：
  - **前向场景接地**：识别候选交通参与者与场景要素，赋予视觉区域与物理状态（产生 V^S 与 V^O）。
  - **后向轨迹锚定**：从专家轨迹 τ* 出发，回溯到支撑该示范行为的关键对象、交互与决策，从而确定**行为相关性**；不贡献于示范决策的对象被排除。
- **序列化**：取动作锚点的严格祖先集诱导子图 `Ga = G[Anc_G(va)]`，得到接地推理序列 `r = Ser(Ga)`。按拓扑顺序：先以语言指代 + 归一化边界框 token + 物理状态引入接地对象，再描述交互与物体级决策（保留对象引用），最后汇聚到自车决策。动作锚点本身不进入 r，动作紧随 r 生成。

### 2.4 共享认知与规划监督

- **认知预训练目标**：`L_QA = -E[log πθ(u | x, q)]`（图查询采样问题 q 与答案 u）。
- **规划目标**：`L_plan = -E[log πθ([r*; a*] | x)]`，其中 `r* = Ser(G*_a)`。
- 两种监督共享同一 G* 中的对象身份、物理状态、交互与决策，使"通过单题学到的接地概念"在支持动作的完整推理中再次出现。

### 2.5 可执行规划器（Executable Planner）

- 动作 `a = (p, g, ϕ)`：运动基元 p、挡位 g ∈ {D, R}、基元特定参数 ϕ。
- 基元集合与参数空间：
  - **STOP**：端点 R²（近静止/停车）
  - **CRAWL**：8 个路点 R^{8×2}（低速走走停停，保留不规则纵向变化）
  - **CURVE**：3 个控制点 R^{3×2}（转向与高曲率，三次贝塞尔）
  - **CRUISE**：progress_end、v_end、lat_end（R³，车道保持与跟车，三次 Hermite 纵向 + 线性横向）
- **固定几何解码器** `τ̂ = D_p(g, ϕ; s_ego)`：**无可学习参数**，输出 4 秒时域内 8 个路点的自车坐标系轨迹。动作选择仍属于 `πθ(a|x,r)`，几何实现不引入额外的学习型轨迹策略。
- **监督动作目标构建**：由专家轨迹确定性地推导 p*（按运动剖面与导航指令）、g*（运动方向），仅拟合对应 Φ_{p*} 的参数并量化序列化，形成 `y* = [r*; a*]`。

### 2.6 渐进式训练（四阶段）

1. **Grounded Pretrain**：用 Eq.(15) 认知目标学习参考解析、物理状态理解、交互推理与决策语义。
2. **Light SFT（planner warm-up）**：用 Eq.(17) 序列目标学习"推理→可执行动作"的延续，仅轻量模仿。
3. **Verified Self-Distillation**：采样完整 `y_i = [r_i; a_i]`，按解码轨迹的闭环奖励筛选，蒸馏目标 `y+_i = [r+_i; a+_i]`（推理与动作来自同一被选中的 rollout），该检查点初始化 RL 并作为冻结参考策略 π_ref。
4. **Active RL Loop**：
   - **可恢复场景筛选**：先找贪心输出仍不达标者 `D_g(θ) = {x : s_greedy(x) < τ_g}`；再要求采样 rollout 中存在足够好的解、明显更差的解与显著奖励方差（`max s_i ≥ τ_hi`、`min s_i < τ_lo`、`std_i(s_i) ≥ τ_σ`）。全部候选由 GRAVA 自身生成，无需额外动作教师。
   - **优化**：奖励为解码轨迹的 PDMS（不可解析或违反 schema 得 0 奖励）。组内归一化优势 `Â_i = (s_i - s̄)/(σ_s + ε)`；DAPO 风格非对称裁剪的 token 级目标；序列级目标 `J_RL` 含 KL 正则 `β·D_KL(πθ || π_ref)`。**同一 rollout 级优势同时更新 r 与 a 的 token 概率**，保留完整 `[r; a]` 作为学习单元。
   - **迭代**：`πθ(k) → D(k)_act → πθ(k+1)`，每轮外层循环后重新评估贪心性能并重建活动集。
   - 补充细节：K=8 采样（temperature 0.8、top-p 0.95）、β=0.01、非对称裁剪 (0.20, 0.28)；筛选阈值 `min s_i < 0.8`、`max s_i ≥ 0.9`、`std(s_i) ≥ 0.10`。

### 2.7 数据构建管线（Agentic GRA Pipeline）

- 多智能体 + 工具增强标注（相机、2D 检测、3D 状态、BEV、自车状态、轨迹绘图、标志/OCR、案例召回），结合前向接地与后向锚定。
- **标注期用短别名（如 G、L）**在标注 LLM 与感知工具间传递对象身份；**训练期将别名解析为归一化边界框 token**，只改变指代形式、不改变交互与决策内容。
- 可见性过滤：标注期保留在任一环视相机中可见的对象（`π_c(P_j) ∩ Ω_c ≠ ∅` 且 `z_c(P_j) > 0`）；训练期重新投影到训练相机集合，丢弃训练视角外引用。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **GR-NavSim（本文构建）**：基于 nuPlan 训练场景，含 107K 带接地状态标注的驾驶场景、**2.2M 接地问答对**、415K 前相机可执行规划器样本、70K 接地轨迹迹；其中 102,861 个场景具有有效官方评测缓存，构成规划与 Active RL 池，接地一致性过滤后 62,111 个用于 planner warm-up。作者称其为迄今最大的开放词汇、非模板化自动驾驶问答数据集。
- **NAVSIM**：使用真实驾驶场景与留出规划基准，在 **navtest** 上按官方 full protocol 评测，指标为 **PDMS** 及其分量（NC、DAC、EP、TTC、Comf），每场景一次贪心自回归补全。
- **内部长尾基准**：50K 片段、700K 帧，覆盖路线受阻、借道、道路危险等场景；关键对象表示为 `o_j = (t_j, Ω_j, p_j)`（语义类型、人工标注 BEV 区域、可通行性）。
  - **闭环驾驶得分**：`CDS = Safety × (0.45·KOC + 0.35·Progress + 0.20·Comfort)`，Safety 为碰撞门与非可行驶空间门之积（硬门控）。
  - **关键对象合规（KOC）**：把每个关键对象的 pass/hold 标签转成对仿真轨迹的几何约束（通过触发边界、跟停边界），允许多条几何不同但满足同一交互约束的轨迹；Progress 在越过 hold 边界时置零。
- **GR-NavSim 留出问答评测集**：类别均衡，13 个子类型，开放式答案由独立 LLM 评审（MiniMax-M3）打分，决策类用标签准确率。
