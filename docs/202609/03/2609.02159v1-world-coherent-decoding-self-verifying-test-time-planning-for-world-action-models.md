## 摘要
世界行动模型（WAMs）旨在通过随机生成视觉未来并随后解码动作来控制机器人，但经验观察表明，其结果可能强烈依赖于选择哪个未来。我们提出了世界一致性解码（WCD），这是一种自我验证的测试时规划框架，将WAM的展开视为可证伪的未来-行动假设。在每个决策步骤，WCD从冻结的WAM中采样多个候选，并使用内部生成信号对其进行排名：基于流的视频惊异度用于视觉合理性，行动路径努力用于行动生成的稳定性。执行后，实际观测对所选想象进行审计，产生想象-现实不匹配，该不匹配用于训练一个轻量级在线预测器，以用于未来的候选选择。因此，WCD将延迟的自我验证转化为执行前的可靠性估计，而无需更新骨干模型。在RoboTwin 2.0上，WCD在有限的随机场景监督下，将Hard成功率从55.80%提高到60.90%，在Horizon-3任务上获得+16.43的提升，并在真实Franka视觉偏移测试中显示出定性鲁棒性。这些结果突显了一个简单原则：WAM的测试时扩展较少依赖于采样更多未来，而更多依赖于选择可靠的未来。

## Abstract
World Action Models (WAMs) aim to control robots by stochastically generating visual futures and then decoding actions, but empirical observations indicate that the results can strongly depend on which future is selected. We propose World-Coherent-Decoding (WCD), a self-verifying test-time planning framework that treats WAM rollouts as falsifiable future--action hypotheses. At each decision step, WCD samples multiple candidates from a frozen WAM and ranks them using internal generative signals: flow-based video surprisal for visual plausibility and action path effort for action-generation stability. After execution, the realized observation audits the selected imagination, yielding an imagination--reality mismatch that trains a lightweight online predictor for future candidate selection. Thus, WCD converts delayed self-verification into pre-execution reliability estimation without updating the backbone model. On RoboTwin 2.0, WCD improves Hard success under limited randomized-scene supervision from $55.80\%$ to $60.90\%$, with a $+16.43$ gains on Horizon-3 tasks, and shows qualitative robustness on real Franka visual-shift tests. These results highlight a simple principle: test-time scaling for WAMs depends less on sampling more futures than on selecting reliable ones.

## 1. 核心问题与研究动机

- **背景**：世界行动模型（World Action Models, WAMs）是近年来兴起的一类机器人控制框架，与直接映射观测到动作的视觉-语言-动作模型（VLA）不同，WAM 先随机生成视频形式的视觉未来，再从该未来中解码动作。该类模型在因果架构下逐层生成“未来视觉 + 动作块”，隐式地将未来视觉状态作为动作解码的目标。
- **核心问题**：视频生成具有内在随机性——在相同历史条件下，WAM 采样出的不同“未来”质量差异极大。有的未来在物理上自洽且与任务相关，有的则包含不存在的物体、不合理的姿态或机械臂漂移，这些不可靠的未来会直接导致动作解码失败。这使得 WAM 的控制效果高度依赖“选中的是哪个未来”。
- **关键洞察（Pilot 验证）**：作者通过实验发现：
  - 同一观测前缀下，不同采样未来之间存在**可选择的可靠性差距**（hindsight error 有显著变化幅度）；
  - 想象-现实不匹配（imagination–reality mismatch）与任务失败存在正相关——失败片段的前期想象误差显著大于成功片段，最低误差四分位数组的失败率仅 4.9%，而最高组的失败率升至 21.2%；
  - 这构成了“可证伪性”的结构性机会：WAM 在执行前预测了一个显式未来，物理世界随后可对其进行审计，无需任何外部监督信号。

## 2. 方法论：WCD 框架

### 2.1 核心思想

WCD 将测试时规划视为**可靠性感知的候选选择问题**：将 WAM 产生的随机未来-动作对视为“可证伪假设”，在冻结 WAM 骨干的前提下，通过生成痕迹的内部信号进行最优-of-N（best-of-N）筛选，并借助执行后的延迟不匹配信号训练在线预测器，将“事后验证”转化为“事前选择依据”。

### 2.2 候选采样与三级评分机制

在每个决策步骤 m 中，WCD 从 WAM 的缓存状态

\[
C_m = (z^{\text{obs}}_{<m}, a_{<m})
\]

采样 N 个未来-动作候选，并使用两个内部信号以及一个在线学习信号进行排名：

**（一）视频侧：流惊异度（Flow-based Video Surprisal）**
- 理论基础：在流匹配（Flow Matching）采样器中，对数密度沿轨迹的变化为

\[
\frac{d}{d\tau} \log p_\tau(x_\tau|C_m) = -\nabla \cdot u^\theta_v(\tau, x_\tau|C_m)
\]

即速度场的散度累积决定了最终密度。
- 实现方式：沿保存的视频求解轨迹，用 Hutchinson 迹估计器离散计算散度累积，得到路径惊异度分数 \(s^{v,\text{surp}}_{m,n}\)。
- 含义：正散度代表概率外流、密度降低、惊异度上升，分数越高表示该未来在模型的视觉动态下越不可信、越不“主流”。

**（二）动作侧：动作路径努力（Action Path Effort）**
- 对从选定未来解码动作的去噪过程，按每一步更新幅度与调度步长之比归一化求和：

\[
s^{a}_{m,n} = \sum_{q=0}^{R_a-1} \frac{\text{mean}((\Delta a_{m,n,q})^2)}{|\Delta\sigma^a_q| + \epsilon}
\]

- 含义：分数越低代表动作去噪路径越平滑、越直接，是控制端稳定性的一个计算代价代理（无需外部奖励）指标。

**（三）融合与选择**
- 视频和动作分数在 N 个候选中以 z-score 方式归一化；
- 最终评分是两者的凸组合，再取 argmin 得到最优候选：

\[
c_{m,n} = \lambda_m \tilde{s}^v_{m,n} + (1-\lambda_m) \tilde{s}^a_{m,n}
\]

### 2.3 延迟自我验证与在线校准

- **事后签名**：执行所选动作后，用实际观测隐向量与被选想象未来之间的逐帧 MSE 计算**后向误差** \(b_m\)，该信号不需要任何外部奖励或成功检测器。
- **在线融合权重调整**：当前向后误差较大时（超过历史均值），自动降低视频信号在当前步的相对信任度（公式 8）。
- **在线预测器（Post-warm）**：将执行时的生成时特征（去噪速度范数序列、潜空间特征等）与事后误差组成数据对，存入重放缓冲区并训练一个轻量级回归器 \(f_\psi\)，用以预测未来候选可能产生的想象-现实误差。
- **两阶段课程**：
  - **Pre-warm 阶段**：使用流惊异度作为冷启动信号（无需任何部署经验）；
  - **Post-warm 阶段**：缓冲区数据达到阈值后，视频侧分数切换为预测器的输出，昂贵的惊异度计算即被停用，只保留在线预测器与动作路径努力信号。
- 全程骨干 WAM 权重完全冻结。

## 6. 主要结论与发现

1. **WAM 的采样未来中蕴含着可利用的可靠性变化**——在相同历史前缀下，不同随机未来之间的想象-现实误差差异显著，且该差距跨任务普遍存在。
2. **想象-现实不匹配是行为上有意义的自我监督信号**——早期误差较大的滚动段失败率明显上升（4.9% → 21.2%），可以不依赖成功检测器、奖励或外部验证器而获得。
3. **WCD 在有限随机化 Hard 配置上带来显著提升**——Hard Avg. 从 55.80% 提高到 60.90%（+5.10），其中 Horizon-3 提升最明显（+16.43 点），说明选择可靠未来能有效抑制早期误差的连锁放大。
4. **测试时扩展的核心在于“选择”而非“采样”**——候选数增加本身不能持续改善性能（Random-N 随 N 波动），只有配合可靠的选择信号时，增加 N 才有意义。
5. **组合优于任单一信号**——视频惊异度侧重过滤分布外视觉未来，动作路径努力侧重短期动作质量，在线预测器侧重远视野误差预判，三者互补，单一分支各有短板。
6. **真实场景定性验证**——WCD 在面对颜色变化、模糊、杂乱干扰等未见视觉偏移时，能从同一个冻结 WAM 中恢复可执行轨迹，而基线和 π0.5 在彩色光照下失败。

## 7. 优点

- **问题定义清晰且具有重要实践价值**——不修改模型权重、不依赖外部奖励或验证器，仅通过更聪明的“选择”来提升测试时性能，切中真实部署中 WAM 随机性导致的痛点。
- **“可证伪未来”的视角新颖**——将 WAM 的未来生成从“中间产物”重新定位为“自然界可审计的假设”，这种建模视角为测试时规划提供了一个统一框架。
- **延迟自我验证逻辑严谨**——“事后才知道，事前又要决定”这一困难被两类机制缓解：事先以内部生成信号冷启动；事后将延迟信号经轻量在线预测器前移。且全程骨干冻结，不引入灾难性遗忘风险。
- **计算控制设计完整**——pre-warm/post-warm 课程策略使昂贵的流惊异度计算只存在于冷启动阶段，平衡了质量与推理效率，这是面向工程落地的必要考虑。
- **消融链条完整**——从现象（可选择差距）→ 行为意义（误差-失败相关）→ 方法（模块分解）→ 资源分析（候选数效应）形成自洽闭环。

- **跨任务通用性未验证**：实验集中在 RoboTwin 的模拟锤/摆/分配等任务和单一桌面 Franka硬件，对重操作力控场景、多机器人协同、复杂材料交互等的泛化能力未作论述。
- **训练协议选择偏主观**：70% 干净 / 30% 随机化的“有限随机化”是人为设定的新协议，且缺少对混合比例的敏感性测试，其“实用性”论证有一定隐含假设性。
- **理论上的局限**：视频惊异度 + 动作路径努力作为选择信号为期望捕获物理合理性，但对“奖励远程状态”等目标不可察觉的精细操作（比如任务在延迟阶段才体现成败）无法成立。
