## 摘要
视觉语言模型越来越多地被用作机器人学习的奖励函数，但这一角色要求具备释义不变性：在语义等价的目标描述下，相同轨迹应获得相同奖励。我们表明，当前的VLM奖励模型常常违反这一属性。仅对指令进行释义就可能显著改变预测的进度分数，甚至可能将相同的机器人行为从失败翻转为成功。为了衡量这种失败模式，我们引入了ROBORMBENCH，一个包含2,390条真实机器人轨迹、地面真值进度标签以及涵盖词汇、句法和动作目标重写的21,673个已验证释义的基准。在专有和开源VLM中，释义引发的不稳定性普遍且严重，在更具差异性的重写下加剧，并且不能通过规模或显式推理可靠地减轻。经过轨迹监督训练的专用奖励模型则明显更加稳定。这些结果表明，释义鲁棒性是基于VLM的可靠机器人奖励建模的核心要求。

## Abstract
Vision-language models are increasingly used as reward functions for robotic learning, but this role requires paraphrase invariance: the same trajectory should receive the same reward under semantically equivalent goal descriptions. We show that current VLM reward models often violate this property. Paraphrasing the instruction alone can substantially change predicted progress scores, and can even flip identical robot behavior between failure and success. To measure this failure mode, we introduce ROBORMBENCH, a benchmark with 2,390 real-robot trajectories, ground-truth progress labels, and 21,673 verified paraphrases spanning lexical, syntactic, and action-goal rewrites. Across proprietary and open-source VLMs, paraphrase-induced instability is widespread and severe, grows under more divergent rewrites, and is not reliably reduced by scale or explicit reasoning. Dedicated reward models trained with trajectory-grounded supervision are substantially more stable. These results show that paraphrase robustness is a core requirement for reliable VLM-based reward modeling in robotics.

## 论文总结：Same Trajectory, Contradictory Rewards (ROBORMBENCH)

### 1. 核心问题与研究动机

- **背景**：视觉语言模型（VLM）正越来越多地被用作机器人强化学习中的奖励函数。其核心优势在于，用户可以用自然语言指定任务目标（如“把红色萝卜放进粉色碗里”），模型则根据视觉轨迹和文本目标输出一个进度分数（如1-5分），作为密集奖励信号指导策略优化。
- **核心问题**：论文指出，VLM奖励模型在角色上必须具备“**释义不变性（Paraphrase Invariance）**”：对于同一条机器人轨迹，在语义等价但措辞不同的任务指令下，应给出相同或相近的奖励分数。
- **发现的缺陷**：作者通过初步实验揭示了一个严重的失败模式（即论文标题中的 “Contradictory Rewards”）：仅对指令进行同义改写（如将“Pick radish, then place in pink bowl”改为“After picking radish, place in pink bowl”），就足以让同一个模型在高分段和低分段之间剧烈波动，甚至将同一行为从“成功”判为“失败”，反之亦然。
- **研究含义**：这种释义脆弱性会给强化学习提供冲突的优化信号，导致策略被引向措辞伪影（Wording Artifacts）而非真正的任务意图，严重威胁基于VLM奖励的机器人学习的可靠性。

### 2. 方法论：ROBORMBENCH基准框架

论文的核心贡献是提出了一个系统性的评估基准和方法框架，用于量化和分析奖励模型的释义脆弱性。

- **核心思想**：在**保持机器人轨迹和任务意图完全不变**的前提下，系统地变化任务指令的文本形式（即生成语义等价的释义），通过检测奖励模型输出分数的波动幅度判断其鲁棒性。
- **数据构建流程**：
    1.  **基础数据源**：从RoboRewardBench (Lee et al., 2026) 中抽取真实机器人轨迹，该数据集覆盖14种机器人形态、多种视角和操作任务，并带有真值进度标签。
    2.  **类别平衡**：针对原数据集真值标签偏向高分的问题，对进度分数为1（成功）的多数类进行降采样，使各分数段（1-5）分布更均衡。
    3.  **释义生成**：使用GPT-5作为生成器，通过三种**语言偏离度递增**的策略生成候选释义：
        - **词汇替换 (LS)**：用同义词替换句子中的实词。
        - **句法重构 (SR)**：改变句子结构（如主动/被动、从句位置等），保持语义不变。
        - **动作-目标视角转换 (AGPS)**：将动作描述改写为目标状态描述，或反之。
    4.  **语义过滤**：为确保释义严格保持原意，使用**三模型集成验证器**（gemini-3-flash, claude-sonnet-4.6, deepseek-v3.2）对候选释义进行筛选。只要任一模型判定候选释义在物体属性、动作动词、空间关系、时序或约束语义等方面有变化即被丢弃。人工抽验显示该过滤器能达到96%的召回率，且偏向保守。
- **评估指标**：
    - **Score Crossing Rate (SCR)**：评分穿越率，核心无参考指标。衡量一条轨迹是否在多个释义下同时获得失败级（1-2分）和成功级（4-5分）的预测，即发生类别矛盾。
    - **Flip Rate (FR)**：翻转率，衡量相对“原始标准指令”，有多少释义会翻转模型的成败判断。
    - **Mean Error (ME)**：平均误差，衡量模型在多个释义上的平均预测分数与人类真值标签之间的绝对差距，用于解耦“鲁棒性”和“预测精度”。
- **降噪措施**：作者通过实验证明（表8），同一条输入下API调用的随机性所产生的标准差（平均0.09）远小于由释义不同引入的标准差（平均0.52），确认了SCR/FR指标反映的是文本诱导的不稳定性而非采样噪声。

### 3. 实验设计与对比

实验设计严谨，旨在全面评估不同模型的释义鲁棒性及其对下游任务的影响。

- **数据集**：构建的 **ROBORMBENCH** 基准，包含 2,390 条平衡后的真实机器人轨迹（LS: 613条，SR: 943条，AGPS: 834条），以及经过严格验证的 21,673 条释义指令。
- **评估场景**：- **上下文一致性**：将文本与真实轨迹结合，涵盖多种具身智能和操作任务。
    - 覆盖三种改写策略（LS, SR, AGPS）的完整独立测试集。
- **对比模型**：
    - **专有闭源VLM**：GPT-4o, GPT-5.1, Gemini2.5-flash-lite, Gemini2.5-flash, Gemini3-flash, Claude-haiku-4.5, Claude-sonnet-4.6。
    - **开源通用VLM**：Qwen3-VL系列(2B/4B/8B/32B/235B-A22B)，Gemma3系列(4B/12B/27B)，Llama4系列(scout/maverick)。
    - **专用奖励模型 (Baseline)**：RoboReward-4B (RR-4B) 和 RoboReward-8B (RR-8B)，它们是在轨迹-奖励数据上做了专门训练的模型。
- **实验设置**：所有模型在评估时均使用相同的视觉帧输入和提示词模板，仅替换指令文本变量。为了对比有无思考模式的影响，还测试了Qwen3-VL-235B和Gemini3-flash的Instruct与reasoning版本。
- **下游任务验证实验**：
    1.  **离线最佳-N（Best-of-N）轨迹选择**：在候选池（N=20）中，各模型选择得分最高的轨迹，对比其真值分数与遗憾值（Regret）。
    2.  **成对轨迹偏好判断**：判断模型给一对轨迹中真值进度更高者赋予更高分数的准确率（Pair Accuracy）。

### 6. 主要结论与发现

1.  **释义脆弱性普遍且严重**：几乎所有被测试的通用VLM奖励模型均表现出显著的SCR与FR，在动作-目标视角转换（AGPS）下尤为严重。例如Gemini2.5-flash-lite和Llama4-scout的SCR超过了0.5，意味着仅靠改写措辞就能让一半以上的轨迹在成败间互换。
2.  **脆弱性随改写差异加深**：SCR和FR的数值普遍呈现出 LS < SR < AGPS 的趋势，说明模型对深层的句法重构和视角变化比表层的词汇替换更敏感。
3.  **规模与推理不是“银弹”**：

4.  **专用模型具备显著优势**：经过轨迹监督训练的专用模型（RR-4B, RR-8B）在各策略上的SCR、FR和ME均显著优于通用VLM，说明领域内受控的奖励监督信号比单纯的模型通用能力更能提升奖励建模的稳定性。
5.  **释义不稳定影响下游策略优化**：在Best-of-N和成对偏好的实验中，SCR较低（更稳定）的模型始终选择出真值进度更高、遗憾值更低的轨迹，并与Pair Accuracy高度负相关（r = -0.893）。这证明短语释义鲁棒性是实际强化学习决策质量的关键指标。

### 8. 不足与局限

- **语言单一性**：基准中的全部指令均为英文，未覆盖多语言或代码混合场景，削弱了结论的全球通用性。
- **轨迹与任务类型覆盖有限**：数据来自有限的机器人操作任务集合；所有实验都聚焦于完整片段的终局奖励（End-of-episode），对分步级（Step-level）奖励、轨迹对比较或分层奖励的鲁棒性未做探讨，这些场景可能展现完全不同的稳健属性。
- **“语义等价”过滤器的潜在依赖**：判断释义是否保义高度依赖三个LLM验证器的一致性，尽管人工抽验，但不同的验证器组合可能过滤出略有差异的数据分布。
- **对API模型的评估依赖外部环境**：对许多模型的评估是通过托管API完成的，不同provider间的解码默认值或微小差异无法完全控制，虽然论文做了重复性分析证明释义方差远大于采样方差，但在严格的控制变量精度上还有提升空间。
- **缓解策略效用的局限**：虽然“聚合”和“方差惩罚”启发式有效，但前者在高阶计算成本方面存在开销，后者在后文的消融实验部分（表7）仅用了单一的Qwen3-VL-4B基础配比，没有关联讨论与RR系列训练模式的优劣。
