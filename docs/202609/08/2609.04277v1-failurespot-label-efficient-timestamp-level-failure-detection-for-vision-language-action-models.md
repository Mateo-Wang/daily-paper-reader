## 摘要
视觉-语言-动作（VLA）策略在通用机器人操作中展现出强大潜力，但在长时间执行过程中仍可能不可预测地失败，因此可靠的故障检测对于安全部署至关重要。现有方法要么依赖视觉模型，通常仅在错误动作发生后才能检测到故障，要么使用在VLA内部表示上训练的轻量级主动检测器。然而，这些主动方法通常使用轨迹级标签进行监督，导致不成功轨迹中正常的故障前行为被错误地标记为故障。这种监督不匹配引入了标签噪声，并限制了轨迹级检测精度和精确的时间戳级故障定位。在本工作中，我们研究细粒度的时间戳级VLA故障检测，同时解决密集标注的成本问题。我们提出一个数据高效的框架，首先利用无标签的VLA动作块构建源自动作的弱监督信号，捕获诸如不一致的连续块、冻结或空闲动作以及激进的随机运动等异常模式。然后，我们使用主动学习仅选择最不确定的轨迹进行时间戳级标注，并利用这些信息丰富的标签对检测器进行微调。跨多个VLA策略的实验表明，我们的方法提高了时间戳级和轨迹级的故障检测性能。

## Abstract
Vision-language-action (VLA) policies have shown strong potential for general-purpose robotic manipulation, but they can still fail unpredictably during long-horizon execution, making reliable failure detection essential for safe deployment. Existing methods either rely on visual models that typically detect failures only after erroneous actions have occurred, or use lightweight proactive detectors trained on VLA internal representations. However, these proactive methods are often supervised with trajectory-level labels, causing normal pre-failure behavior in unsuccessful trajectories to be incorrectly labeled as failure. This supervision mismatch introduces label noise and limits both trajectory-level detection accuracy and precise timestamp-level failure localization. In this work, we study fine-grained timestamp-level VLA failure detection while addressing the cost of dense annotation. We propose a data-efficient framework that first leverages unlabeled VLA action chunks to construct action-derived weak supervision signals, capturing abnormal patterns such as inconsistent consecutive chunks, frozen or idle actions, and aggressive random motions. We then use active learning to select only the most uncertain trajectories for timestamp-level annotation and fine-tune the detector with these informative labels. Experiments across multiple VLA policies show that our method improves both timestamp-level and trajectory-level failure detection performance.

## 1. 核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）策略在通用机器人操作中表现出很强的能力，但在长时间（long-horizon）执行中仍会以多种不可预测的方式失败，例如漏抓目标、卡住、静止不动或输出不稳定的动作。
- **现有方法的不足**：
  - **被动式检测**（基于视觉观察）只能在错误动作已经执行并体现在画面中之后才能发现故障，不利于提前干预。
  - **主动式检测**（如 SAFE）虽然利用 VLA 内部表示在动作执行前输出每个时间戳的故障分数，但通常只用**轨迹级标签**进行监督。
  - 轨迹级标签会把整条失败轨迹中的所有时间戳都标为故障，包括机器人仍在正常工作的“故障前阶段”。这种**监督不匹配**带来了严重的标签噪声，导致模型难以学到精确的故障边界，既损害轨迹级检测效果，也削弱时间戳级故障起点的定位能力。
- **研究目标**：在不依赖大量密集人工时间戳标注的情况下，实现**时间戳级（timestamp-level）** 的 VLA 故障检测，即不仅要判断轨迹是否失败，还要尽量准确地定位失败开始的时间点。

## 2. 提出的方法论：FailureSpot

### 2.1 总体框架

FailureSpot 是一个两阶段、标签高效的学习框架：

1. **弱监督预训练阶段**：利用大量无需人工标注的 VLA 动作块（action chunks），构造“动作派生弱监督信号”，训练时间戳级故障检测器。
2. **主动学习微调阶段**：让预训练检测器估计轨迹的不确定性，只挑选信息量最大的轨迹进行人工时间戳级标注，再用这些标注微调检测器。

### 2.2 问题形式化

- 每条轨迹 i 有 Ti 个时间戳，每个时间戳对应 VLA 的内部表示 hi,t 和动作块 Ai,t。
- 检测器 fθ 以 hi,t 为输入，输出故障概率 pi,t = fθ(hi,t) ∈ [0,1]，轻量级检测器可采用 MLP 或 LSTM。

### 2.3 时间戳级标注定义

- 当机器人不再朝任务目标做出有意义进展时，该时间戳记为失败（如错过目标、卡住、空闲或出现不稳定动作）。
- 失败轨迹的“失败起点”定义为第一个被判为失败的时间戳。
- 还允许“先偏离后恢复并最终成功”的轨迹存在：只将 tdev ≤ t < trec 的时间戳标注为失败。

### 2.4 源自动作的弱监督信号

核心思路：很多 VLA 失败会体现在动作块中。论文定义了三种互补的弱监督信号：

- **短期动作一致性（short-term action consistency）ci,t**：
  - 对于重叠式动作块（chunked policy），计算上一动作块中未执行动作与当前动作块已执行动作之间的平均 ℓ2 距离；距离越大，说明相邻 chunk 不一致，越可能是失控或故障前兆。
  - 对自回归型策略（如 OpenVLA），相邻动作无重叠，则直接计算前后单步动作的 ℓ2 距离。
- **全动作块平均幅度（full-chunk action magnitude）ri,t**：
  - 计算当前动作块内所有动作的 ℓ2 范数平均值。幅度过小通常表示冻结或空闲。
- **已执行动作平均幅度（executed action magnitude）rexec i,t**：
  - 只计算实际会被执行的 K 个动作的平均幅度，用于捕获不稳定的剧烈或异常小的动作。对自回归模型，该信号与 ri,t 相同。

### 2.5 信号平滑、融合与归一化

- 对每个原始信号计算**指数移动平均（EMA）**：E(u)i,t = βE(u)i,t−1 + (1−β)ui,t，其中 β=0.8，用于缓解短期抖动。
- 将每个信号的“瞬时值 + 平滑值”加权求和得到单一标量 si,t：
  si,t = [ci,t + E(c)i,t] + η1[ri,t + E(r)i,t] + η2[rexec i,t + E(rexec)i,t]。
- 在训练集上统计 si,t 的 1% 和 99% 分位数作为 slow 与 shigh，再进行线性缩放并裁剪到 [0,1]，作为“软伪标签”：
  s̃i,t = clip((si,t − slow)/(shigh − slow + ε), 0, 1)。

### 2.6 主动学习

- 由于弱监督伪标签有噪声，FailureSpot 使用不确定性采样主动学习。
- 对每个时间戳计算预测熵：H(pi,t) = −pi,t log pi,t − (1−pi,t)log(1−pi,t)。
- 因为时间戳级标注通常以一个完整轨迹为单元进行，论文按轨迹取平均熵作为轨迹不确定度：Ui = (1/Ti) Σt H(pi,t)。
- 只对不确定度最高的若干轨迹请求人工标注，然后使用标准二分类损失微调检测器。
- 实验中标注预算固定为训练轨迹的 15%。

### 2.7 共形预测决策阈值

- 借鉴 SAFE，采用函数型共形预测（functional conformal prediction）利用留出的成功轨迹构造单边、时变共形频带 bα(t)，让阈值适应正常执行下的分数自然波动。
- 给定显著性水平 α，若 pi,t ≥ bα(t)，则判定该时间戳为故障；故障起点定义为 τα = min{t : pi,t ≥ bα(t)}。

## 3. 实验设计

### 3.1 数据集与场景

- 使用 **LIBERO-10（LIBERO-Long）** 模拟操作套件，包含 10 个长时序操作任务。
- 采用三种代表性 VLA 策略：
  - **π0**：每步预测长度为 H=50 的动作块，执行前 K=5 步后重新规划。
  - **π0-FAST**：每步预测 H=10 的动作块，同样执行前 K=5 步。
  - **OpenVLA**：自回归策略，每步只输出并执行一个动作（H=K=1）。
- 三种策略的动作空间相同，维度为 7（末端位置、方向、夹爪开合）。

### 3.2 数据划分

- 每个策略在每个任务上 rollout 50 条轨迹，共计 500 条轨迹；三种策略最终成功率分别为 81.4%、61.4% 和 53.8%。
- 选取 3 个任务作为 seen tasks，余下 7 个作为 unseen tasks。
- seen tasks 中 60% 轨迹用于训练、40% 用于 seen 评估；7 个 unseen tasks 共 350 条轨迹仅用于评估。
- 时间戳级人工标注预算固定为 seen 训练轨迹的 15%，并通过主动学习选择轨迹。

### 3.3 对比基线

- **无训练检测器**：
  - STAC-Single（仅适用于有重叠动作块的 π0 和 π0-FAST；不适用 OpenVLA）。
- **轨迹级标签检测器**：
  - LogpZO（FAIL-Detect 的一部分）。
  - SAFE-MLP、SAFE-LSTM。
  - ActProbe（由于代码可用性只在 π0 与 OpenVLA 上评估）。
- **时间戳级标签检测器**（直接训练并以相同 15% 时间戳标注预算作为公平比较）：
  - MLP、LSTM。

### 3.4 评估指标

- 轨迹级与时间戳级 AUROC。
- 时间戳级平衡精度 BalACC_ts(α) = ½(TPR_ts(α) + TNR_ts(α))，并扫描 15 个共形显著性水平 α ∈ [0.02, 0.9]。
- 检测到的失败起点时间与真实失败起点之间的接近程度。

## 6. 主要结论与发现

- 以轨迹级标签直接监督时间戳级检测会造成标签噪声，弱化检测边界；时间戳级标注对精确故障定位更重要。
- FailureSpot 仅用 15% 时间戳级标注预算，就在 π0、π0-FAST、OpenVLA 上普遍取得最优或次优的**时间戳级 AUROC**。
- 在 π0 与 π0-FAST 上，FailureSpot 同时取得了最优的**轨迹级 AUROC**；在 OpenVLA 上轨迹级表现略弱于部分基线。
- 在共形预测阈值设定下，FailureSpot 在取得高平衡精度的同时，能在真实失败起点之前（或略微提前）触发警报，有利于及时干预。
- 消融结果表明：仅靠动作弱监督或仅靠主动学习都不充分，**弱监督预训练与主动学习微调互补**，前者提供可扩展的初始化，后者提供精确的失败边界。
- 不同 VLA 策略的失败模式不同：π0 常见重复失败抓取，π0-FAST 常见大幅甩动，OpenVLA 则常出现停滞。

## 7. 优点与亮点

- **问题定义清晰**：将 VLA 故障检测从粗糙的轨迹级拓展到时间戳级，并同时区分“最终失败”“最终成功但中间偏离”“全程正常”三种情况，比既有工作更贴合长程任务实际。
- **标签高效设计巧妙**：先利用动作块本身的物理语义（一致性、幅度）构造零成本弱监督，再用主动学习将有限的人工标注放在最难分类的轨迹上，兼顾成本与精度。
- **普适性较强**：检测器直接基于 VLA 内部表示，可搭配轻量 MLP/LSTM；所提弱监督信号同时适配 chunked 与 autoregressive 策略。
- **评估体系较严谨**：同时报告 AUROC 和基于共形预测阈值的平衡精度；特别关注检测到的故障起点与真实起点的时间差，且将轨迹级失败与时间戳级定位统筹考察。
- **可解释性较好**：通过可视化故障分数曲线与实际操作帧，直观解释了“过早报警/过晚报警”问题的改进效果；还归纳了 VLA 策略的具体失败模式，对后续干预设计有参考价值。

## 8. 不足与局限

- **任务覆盖有限**：只使用 LIBERO-Long 这一模拟环境，缺少真实机器人多任务验证。
