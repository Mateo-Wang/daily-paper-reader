## 摘要
局部行人-车辆预测跨越异构物理尺度：行人将根节点运动与关节式运动相结合，而车辆是由运动学状态和有向范围描述的刚体。现有的道路智能体预测器通常忽略行人关节结构，而姿态预测器则将车辆未来置于学习到的推演之外。我们提出PV-WM，一种基于结构化感知后轨迹、仅依赖历史的世界模型。它在同步的异构状态中递归推进行人根节点运动、15关节的关节式运动和学习到的车辆状态。生成的行人和车辆片段为下一个递归边界提供输入；车辆框由预测的中心和航向与观测到的范围重建，并在每次状态转移后重新计算P-V几何关系。相对于匹配的单次完整状态预测器，递归执行将Root ADE降低12.7%，MPJPE降低14.8%。反馈干预表明，后续预测依赖于所生成关节式运动的内容、时间顺序和行人身份。在824个对齐的Waymo场景中，有797个提供有效的未来车辆支撑，PV-WM相对于验证集选择的模块化专家模型，将Root ADE降低5.2%，MPJPE降低7.6%，P-V距离误差降低11.9%，有向框最近接近误差降低5.8%。该单网络模型参数量减少57.1%，每个局部场景的平均FLOPs降低96.5%，实测p95延迟降低25.5%。PV-WM统一了这种异构未来状态，同时保留了行人/车辆各自类型特有的动力学。

## Abstract
Local pedestrian-vehicle forecasting spans heterogeneous physical scales: pedestrians combine root locomotion with articulated motion, whereas vehicles are rigid bodies described by kinematic state and oriented extent. Existing road-agent forecasters typically omit pedestrian articulation, while pose forecasters leave vehicle futures outside the learned rollout. We introduce PV-WM, a history-only world model over structured post-perception tracks. It recurrently advances pedestrian root motion, 15-joint articulation, and learned vehicle states within a synchronized heterogeneous state. The generated pedestrian and vehicle chunks supply the next recurrent boundary; vehicle boxes are reconstructed from predicted center and heading with observed extent, and P-V geometry is recomputed after every transition. Relative to a matched one-shot complete-state predictor, recurrent execution reduces Root ADE by 12.7% and MPJPE by 14.8%. Feedback interventions show that later predictions depend on the content, temporal order, and pedestrian identity of generated articulation. Across 824 aligned Waymo contexts, with 797 providing valid future vehicle support, PV-WM reduces Root ADE by 5.2%, MPJPE by 7.6%, P-V distance error by 11.9%, and oriented-box closest-approach error by 5.8% relative to a validation-selected Modular Specialist. The single-network model uses 57.1% fewer parameters, 96.5% lower average FLOPs per local scene, and 25.5% lower measured p95 latency. PV-WM unifies this heterogeneous future state while preserving type-specific pedestrian and vehicle dynamics.

- **研究动机**：局部行人-车辆场景在物理类型与分辨率上高度异构。行人由根节点（root）运动与关节式身体运动组合而成；车辆则是用运动学状态与有向范围（oriented extent）描述的刚体；而行人-车辆（P-V）几何关系随双方运动不断演化。三者共享同一时钟，因此一个完整的局部世界模型必须在同一个同步的未来中推进这些变量。
- **现有方法的缺口**：
  - 多智能体预测器（如 Trajectron++、QCNet、MTR、MotionLM 等）预测轨迹、中心、框或运动 token，但通常将行人保留在智能体级分辨率，忽略关节结构。
  - 关节式人体运动预测器（如 TBIFormer、T2P、Waymo-3DSkelMo）保留全局运动与局部姿态，但周围车辆仍作为观测条件，而非生成未来状态。
  - 车辆条件姿态模型（VehCondPose3D）使用交通历史，但不生成车辆未来。
  - 驾驶世界模型（TrafficBots、OccWorld、DriveWorld、GAIA-1 等）覆盖不同状态空间，但未在一个循环局部状态中同时暴露关节式行人状态、学习到的车辆运动、有向范围与同步 P-V 几何。
- **核心问题**：如何将行人关节运动、行人根运动、学习到的车辆状态、有向框以及同步 P-V 几何统一到一个循环推演的世界模型中，同时保留各类型特有的动力学？
- **整体含义**：论文提出 PV-WM，将行人-车辆预测形式化为异构状态的循环预测问题，用单个端到端网络实现"完整状态"的未来推演，兼顾精度与效率。

## 2. 论文提出的方法论

### 2.1 核心思想

- **仅依赖历史**（history-only）的世界模型，基于结构化感知后轨迹（post-perception tracks）运行。
- **异构状态**：宏观尺度预测行人根运动与刚性车辆运动学；微观尺度预测根相对的行人关节运动（15 关节）。所有变量在同一时钟上演化。
- **生成状态共同推演**（generated-state co-rollout）：每个 transition 生成的行人/车辆 chunk 共同构成下一个两帧边界；车辆 OBB 由生成的中心与航向加观测到的范围重建；P-V 几何在每个 transition 后重新计算。
- **类型化端点动力学 + 持续对状态**：端点分支保持因子化（factorized），但保留一个持续更新的 pair 状态用于关系表示与辅助读出。
- **路由控制**：可将 pair 上下文注入行人分支、车辆分支或两者。

### 2.2 关键技术细节

- **时序设置**：观测 20 帧（2 s），预测 10 帧（1 s），10 Hz；通过 M=5 个 transition，每个 chunk 为 c=2 帧。
- **状态定义**：
  - 行人状态：`p_{i,t,a} = p_{i,t,0} + ℓ_{i,t,a}`，其中 `p_{i,t,0}` 为根传输，`ℓ` 为根相对关节位置，`a=0` 为骨盆根。
  - 车辆状态：`s^V_{k,t} = (x^V, u^V, sinψ, cosψ, ν, o)`，分别表示平面中心、平面速度、航向正弦/余弦、速率、存在标志。
  - 关系：`δ_{ik,t} = x^V_{k,t} - x^P_{i,t}`，`d = ||δ||₂`，`κ` 为接近运动指示（正表示接近），`r = (δx, δy, d, κ)`。
  - 物理状态：`S^phys_t = (P_t, V_t, R_t, B_t)`，其中 `R_t = Φ(P_{t-1:t}, V_t)`，`B_t = Ψ_box(V_t; ξ^V,obs)`。
- **编码器**：行人编码器聚合根、解剖组、根相对运动；车辆 GRU 池化中心增量、速度、加速度、航向、速率、存在。pair 编码器 `F_R` 融合双方编码与关系观测。
- **循环状态**：`Z_m = (H_m, E_m)`，`H_m` 携带类型化上下文（含持续 pair 状态），`E_m` 提供相邻 P/V 状态用于恒速参考与有限差分几何。
- **Transition 公式**：
  - `(Ŝ^phys,(m), Q̂(m), Z_{m+1}) = T_{θ,ρ}(Z_m; M, ξ^V,obs)`，`ρ=(ρP,ρV)∈{0,1}²` 控制 pair 上下文路由。
  - 根与车辆运动用恒速残差；关节用当前根相对姿态的门控残差：`ℓ̂ = ℓ_cur + σ(γ)Δℓ`。
  - 两个端点从同一个 pre-chunk `Z_m` 解码，chunk 内不消费对方的新未来。
- **物理闭包与递归**：
  - `R̂(m) = Φ(E_m, P̂(m), V̂(m))`；`B̂(m) = Ψ_box(V̂(m); ξ^V,obs)`。
  - `E_{m+1} = Tail2(P̂(m), V̂(m))`；`Z_{m+1} = (H_{m+1}, E_{m+1})`。
  - 最终 `Ŝ^phys_{1:Tf} = Concat_{m=0}^{M-1} Ŝ^phys,(m)`。
- **学习目标**：`L = L_P + L_V + L_R + L_Q + 0.05 L_scene`。
  - `L_P` 使用关节、根、根相对、体局部、骨骼、速度、加速度加权（1.0, 0.50, 0.25, 0.10, 0.05, 0.05, 0.02）。
  - `L_V` 使用状态与中心加权（1.0, 0.50）。
  - `L_R` 使用 R4、距离、horizon 最小距离加权（0.35, 0.30, 0.15）。
  - `L_Q` 使用成对与 chunk 风险加权（0.10, 0.10），目标为平滑接近度与接近运动分数的乘积。
  - 关系由生成端点闭合，因此 `L_R` 直接监督 P/V 预测器；框重建无单独回归损失。

### 2.3 算法流程（文字说明）

1. 用类型化编码器压缩完整历史，初始化 `Z_0 = (H_0, E_0)`。
2. 对每个 transition `m=0..M-1`：
   - 从 `Z_m` 解码行人与车辆 chunk（根运动、15 关节、车辆状态）。
   - 用生成状态重算 P-V 关系 `R̂(m)`。
   - 用生成中心与航向加观测范围重建车辆 OBB `B̂(m)`。
   - 更新类型化记忆，刷新 `E_{m+1}` 与 `Z_{m+1}`。
3. 拼接 5 个 transition 的输出得到完整结构化未来。
4. 参数 `θ` 在所有 M 个 transition 间共享。

## 3. 实验设计

### 3.1 数据集 / 场景

- **Waymo 数据集**：将 Waymo-3DSkelMo 的 15 关节行人轨迹与 Waymo Open Dataset 的车辆轨迹及有向框对齐，得到 **824 个驾驶场景（contexts）**。
- 每个 context 提取最多 8 个 3 s 窗口（1 s 步长），形成局部场景。
- 车辆筛选：与任意行人最小观测距离 ≤ 25 m 的车辆保留为候选。
- P-V 边激活条件：最小观测距离 ≤ 12 m，或最小碰撞时间 ≤ 4 s，或最大接近速度 ≥ 0.25 m/s。
- 每个连通分量最多 8 行人 + 8 车辆，共得到 **8,364 个局部场景实例**。
- 其中 **797 个 context 具有有效未来车辆支撑**，用于车辆与成对指标。

### 3.2 Benchmark 与评估协议

- **时序协议**：观测 20 帧（2 s），预测 10 帧（1 s），10 Hz；PV-WM 执行 5 次两帧 transition。
- **评估方式**：segment-grouped、context-disjoint 五折折外（out-of-fold）评估——同一 Waymo segment 的 context、重叠窗口、轨迹保持在同一折，每个 context 被留出一次。
- **训练模型**使用种子 42、123、456；确定性 CV 参考只评估一次。
- **检查点与 Modular Specialist 组合**仅用对应验证集选择。
- **统计**：每种子跨五折池化充分统计量后计算跨种子均值与样本标准差；配对比较用 10,000 次 context-clustered bootstrap 重采样，家族内 Holm 校正。

### 3.3 评价指标

- 行人：Root ADE / FDE、MPJPE、APE（去除根平移的局部关节误差）、fMPJPE（末帧 MPJPE）、wAPE（按未来目标身体运动幅度加权的根相对误差）。
- 车辆：Vehicle ADE / FDE（平面中心误差）。
- P-V 几何：P-V Distance MAE（逐帧行人根到车辆中心距离误差）、DCAE OBB（有向框最近接近误差，基于 0.30 m 半径行人根圆盘与重建 OBB 的有符号 BEV 间隙）、Cyclic BoxCorner（消除起始角依赖的循环角点匹配）。

### 3.4 对比方法

- **关节式行人预测 + 规定 CV 车辆运动**：CV all-joints + CV-V、TBIFormer、VehCondPose3D、T2P。
- **轨迹原生学习行人-车辆预测**：Trajectron++、QCNet、MTR。
- **完整状态系统**：Modular Specialist（从 3 种姿态模型 × 4 种车辆模型中按验证分数选择）、PV-WM。
- 多模态方法取最高概率模态，而非测试 oracle 最小。

### 3.5 消融与扩展实验

- 核心组件消融：one-shot 完整状态预测、共享端点更新、去除持续 pair 状态、去除显式几何损失、去除 Q 监督、去除全部关系监督。

- **精度提升**：相对于验证集选择的 Modular Specialist，PV-WM 在 824 个 Waymo context 上：

  - P-V Distance MAE 降低 **11.9%**（15.31 mm）

  - APE 统计上无显著差异；Vehicle ADE 增加 0.85 mm。
- **循环执行的价值**：相对于匹配的 one-shot 完整状态预测器，循环执行降低 Root ADE **12.7%**、MPJPE **14.8%**；在消融中降低 Root ADE 24.1 mm、MPJPE 32.8 mm、DCAE OBB 28.3 mm、Cyclic BoxCorner 101.3 mm。
- **类型化端点动力学与持续 pair 状态**：替换为共享 transition 会使 Root ADE 增加 21.7 mm、MPJPE 增加 17.3 mm；移除持续 pair 状态会使 Root ADE 增加 22.9 mm、MPJPE 增加 19.9 mm。
