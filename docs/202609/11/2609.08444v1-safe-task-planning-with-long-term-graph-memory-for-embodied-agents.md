## 摘要
大语言模型（LLM）与视觉-语言模型（VLM）显著推进了具身智能体的零样本任务规划。然而，大多数由 LLM 和 VLM 驱动的方法由于缺乏物理风险意识，难以生成安全的高层动作，尤其是在部分可观测条件下，危险位于当前视野之外。为应对这一挑战，我们提出了一种新颖的安全任务规划框架 SafeMem，它构建并维护开放动态环境的长期语义图记忆。基于自我中心观测，所提框架以图的形式增量式积累关于周围物体及其关系的知识。然后，一个基于 LLM 的风险预测器利用图记忆评估候选动作，触发带有对检测到危险解释的保守度调制重规划循环。在 IS-Bench 基准和真实机器人平台上的大量实验表明，与最先进的 VLM 驱动任务规划器相比，SafeMem 框架显著提高了安全成功率。视频结果可在我们的网页查看：https://sites.google.com/view/safemem。

## Abstract
Large language models (LLMs) and vision-language models (VLMs) have significantly advanced zero-shot task planning for embodied agents. However, most LLM- and VLM-driven methods struggle to generate safe high-level actions due to a lack of physical risk awareness, particularly under partial observability, where hazards lie outside the immediate field of view. To address this challenge, we propose a novel safe task-planning framework, SafeMem, which constructs and maintains a long-term semantic graph memory of the open and dynamic environment. Based on egocentric observations, the proposed framework incrementally accumulates knowledge about surrounding objects and their relationships with a graph. Then, an LLM-based risk predictor evaluates candidate actions using the graph memory, triggering a conservatism-modulated replanning loop with explanations for detected hazards. Extensive experiments on the IS-Bench benchmark and a real-world robot platform demonstrate that the SafeMem framework substantially improves safe success rates compared to state-of-the-art VLM-driven task planners. Video results are available on our webpage: https://sites.google.com/view/safemem.

## 2. 方法论：核心思想与关键技术细节

### 2.1 问题形式化
- 将任务规划建模为 **POMDP**：$\mathcal{M} = \langle \mathcal{O}, \mathcal{S}, \mathcal{A}, \mathcal{T}, \mathcal{L} \rangle$，其中 $o_t$ 为自我中心单视角 RGB-D 观测，$\mathcal{L}$ 为自然语言任务指令，$\mathcal{A}$ 对应预定义技能集 $\Pi$。
- 评价指标：**成功率（SR）** 与 **安全成功率（SSR）**，安全目标 $G_{safe}$ 用 BDDL 谓词定义。

### 2.2 长期图记忆（Long-Term Graph Memory）
- **表示**：图 $\mathcal{G} = (\mathcal{V}, \mathcal{E})$，节点 $v_k$ 含实例 ID、边界框、掩码、类别标签；边 $e_q = \langle v_s, r_q, v_t \rangle$ 为语义关系三元组。
- **图初始化**：
  1. 用 **Gemini 2.5 flash** 从 RGB 生成初始图 $\tilde{\mathcal{G}}_t$（输入含任务指令、技能集、关系集、标签集）；
  2. 用 **SAM 2.0** 网格采样生成精确掩码，通过 IoU 匹配节点与掩码（式 3），并对低 IoU 节点和重复掩码节点进行裁剪；
  3. **深度感知的边校正**：对可计算关系子集 $\mathcal{R}_{cal}$（ON、IN、ABOVE、NEAR、ATTACHED TO），利用相机内参 $K$ 和深度图反投影（式 4）得到 3D 点云，计算轴对齐 3D 边界框并据此修正边。
- **图更新**：
  - 基于掩码 IoU 的**二分匹配**关联跨时间步节点（式 5），匹配节点继承持久 ID 并更新几何与类别；
  - **未匹配的旧节点被保留**（不删除），增强对遮挡和出视野事件的鲁棒性；
  - 新观测边覆盖旧边，涉及当前不可见物体的边保留；
  - 与上一动作 $a_{t-1}$ 交互物体相关的不可见物体边被剪枝；
  - 根据动作语义更新边（如放置后添加 IN 边），最终合并（式 6）。

### 2.3 安全感知任务规划
- **LLM 风险预测器**：输入简化后的图记忆 $\mathcal{G}_t$（省略边界框与掩码，保留语义与关系）与候选动作 $\hat{a}_t$，输出 **REPLAN 信号**及危险解释；
- **VLM 规划器**：接收 REPLAN 与原因后重新生成动作，循环直至无 REPLAN；
- **保守因子 $\eta \in [0,1]$**：以概率 $\eta$ 遵循 REPLAN，避免规划器与预测器死锁；$\eta=1$ 完全保守但延迟更高，$\eta=0$ 忽略所有风险；
- **算法流程**（Alg. 1）：每步构建新图 → 合并图 → VLM 生成候选动作 → 风险预测器评估 → 若 REPLAN 且随机数 < η 则重规划 → 执行动作 → 获取新观测。

## 6. 主要结论与发现

- **部分可观测下**（表 1）：SafeMem 平均 SSR 达 **0.59**，远高于 SaP（0.13）、CoT（0.17）、Base（0.00）和 SafeMem w/o GM（0.21），说明长期图记忆对安全规划至关重要。

- **消融发现**：
  - 图记忆优于 full history、RAG 和 object-list，说明**结构化表示与关系边**是风险预测的关键；
  - 无效的记忆表示（full history、object-list）SSR 甚至低于 SafeMem w/o GM，说明**不良记忆反而有害**；

## 8. 不足与局限

- **假设限制**：论文明确承认，SafeMem 依赖“危险已出现在历史或当前观测中”的假设，**无法仅凭更广泛的物理上下文推断未见过的潜在危险**（如完全隐藏的物体或隐式环境动态）。
- **保守因子机制**：η 为概率性机制，η = 0.8 时仍有约 0.35 的安全违规率；作者指出在更安全关键的场景中应设计**停止式回退（halting fallback）**替代概率机制，而 η = 1 又会显著增加延迟。
- **实验覆盖**：
  - IS-Bench 各危害类别任务数量不均衡，保留原始分布可能带来偏差；
  - 真实机器人实验每任务仅 10 次，样本量有限；
  - 未报告多次随机种子的方差或置信区间。
- **依赖外部模型**：图构建依赖 Gemini 2.5 flash、SAM 2.0，风险预测与规划依赖 GPT-4o，存在 API 成本、延迟与模型版本变动带来的可复现性风险。
- **计算开销**：SafeMem 平均 token 消耗（9425）约为 Base 的 2.4 倍，延迟（17.62s）约为 Base 的 1.7 倍，实时性受限。
- **关系集封闭**：使用闭集关系 $\mathcal{R}$ 与标签集 $\mathcal{C}$，对开放环境的泛化能力可能受限。
