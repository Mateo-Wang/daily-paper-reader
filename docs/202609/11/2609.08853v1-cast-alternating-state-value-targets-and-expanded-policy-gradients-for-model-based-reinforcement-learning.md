## 摘要
基于模型的强化学习（MBRL）是一类学习环境模型并将其用于动作选择的强化学习方法，因其样本效率高而非常适合机器人领域。将学习到的模型与在线规划相结合可以进一步改进动作选择，因为规划器能够利用该模型找到比仅靠学习到的策略更好的动作。近期将学习到的策略与在线规划相结合的方法通常学习策略的价值，而不是更强的规划器引导行为。我们提出 CAST（Critic with Alternating State-value Target，带交替状态值目标的评论家），它利用规划器引导的行为来改进价值学习，同时用当前策略对价值估计进行正则化。CAST 将动作价值评论家替换为状态价值评论家，并使用一个目标进行训练，该目标结合了真实的规划器引导转移和当前策略下的想象转移。由此得到的价值函数对应于规划器引导行为与当前策略之间的交替过程，使其能够受益于更强的规划器行为，同时被正在学习的策略正则化。我们在 DeepMind Control 和 HumanoidBench 套件上针对若干最先进方法评估 CAST，并展示了成功迁移到执行动态倒立的实体 Unitree Go2 四足机器人。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

- **背景**：基于模型的强化学习（MBRL）通过学环境模型做规划与策略优化，样本效率高，适合机器人。将学习模型与在线规划结合（如 MPPI 规划器）可进一步改善动作选择。
- **核心矛盾**：近期"策略 + 在线规划"方法（MOPAC、LOOP、TD-MPC/TD-MPC2、BOOM、BMPC、MODIP）中，回放数据由**规划器增强的行为策略 β** 产生，但评论家学习的却是**神经策略 πθ 的价值**，二者存在分布不匹配。
- **作者的观察**：行为策略 β（规划器）通常显著优于 πθ，尤其在训练早期。因此评论家应当学习 **β 的价值**，以便策略改进能依托更强的评论家。
- **两大障碍**：
  - 直接从 β 自举会因 β 与 πθ 差距过大而产生剧烈策略更新，导致训练不稳定；
  - 学习 **Qβ(z,a)** 不现实——β 在状态上的动作分布只能通过反复调用规划器获得，每个 TD 目标都需一次规划器查询，而无法复用回放缓冲区中的转移。
- **整体含义**：论文试图用最小的结构改动，把"规划器引导的强行为"注入价值学习，同时用当前策略加以正则化，从而在样本效率与训练稳定性之间取得平衡。

## 2. 方法论

### 2.1 核心思想
将 TD-MPC2 的**动作价值评论家 Q(z,a) 替换为状态价值评论家 V(z)**，并用一个**混合（交替）贝尔曼目标**训练：目标由"一条 β 产生的真实转移"+"一条 πθ 在学得模型下产生的想象转移"组成，使价值函数对应 **β → πθ → β → πθ → …** 的交替过程。

### 2.2 关键技术细节

- **状态价值替代动作价值**：保留 TD-MPC2 的隐世界模型（编码器 hξ、动力学 dξ、奖励 Rξ、SimNorm 隐状态、symlog 分箱 + 交叉熵目标），但评论家变为 N=5 的状态价值集成 {Vᵢψ(z)}，并用同样的 Polyak 平均维护目标网络 {V̄ᵢψ}。
- **动作价值的重构估计**：需要 Q 时用模型一步展开重建

- **混合价值目标**（式 9）：
  - **yₜ = rₜ + γ[ Rξ(zₜ₊₁, ãₜ₊₁) + γ·V̄ψ(z̃ₜ₊₂) ]**

## 6. 主要结论与发现

- **样本效率提升**：CAST 在多数环境上匹配或超越基线，且更早达到高回报；在 H1hand-run、H1hand-pole、Dog-run 等 HumanoidBench 任务上优势明显。
- **AUC 剖面最优**：在归一化 AUC 性能剖面上，CAST 平均表现优于所有基线；DMControl 上 CAST 与 BMPC 在 τ ≈ 0.9 前均保持 1.0，HumanoidBench 上 CAST 在 τ ≈ 0.85 前保持 1.0，而 BMPC 掉得最早。
- **最终性能**：1M 步时 CAST 平均回报最高（**764 ± 63** vs. BOOM 721 ± 41、BMPC 644 ± 43、TD-MPC2 340 ± 77）；2M 步时各规划类方法趋近收敛，CAST 平均 **839 ± 29**，与 BOOM（849 ± 29）相当、优于 BMPC（691 ± 60），并在多个 HumanoidBench 任务（如 H1hand-run 867 vs. BOOM 682、Dog-stand 988、Dog-trot 953、H1hand-sit 919）上取得最好成绩。
- **消融结论**：
  - 纯 off-policy（直接自举 Vβ）**始终最差**，印证了从 β 直接自举会破坏稳定性；
  - 纯 on-policy 有竞争力但仍落后于混合目标；
  - H_V = 1（一条真实 β 转移后即重新引入 πθ）在 Humanoid-run 上明显最优，在 Dog-run 上与 H_V = 2/3 相当，是较均衡的选择；
  - Hπ = 1 略优于 Hπ = 2/3，后两者几乎重合，说明更长的想象展开未带来收益（且方差更小）。
- **真机迁移**：仿真训练的策略可直接零样本迁移到 Unitree Go2，完成实时稳定的动态倒立。
