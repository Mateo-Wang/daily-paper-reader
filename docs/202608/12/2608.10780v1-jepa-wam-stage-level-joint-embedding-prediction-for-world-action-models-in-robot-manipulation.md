## 摘要
通用机器人策略旨在将多模态观察和语言任务指令映射为跨多样任务的动作。然而，现有方法通常将未来表示为固定的短时视频-动作块。这种短期未来捕获局部场景演变以用于动作执行，但它并未明确描述指定任务应如何从当前阶段推进到下一阶段的分阶段未来。因此，我们区分了机器人操作的两种互补未来：用于捕获局部场景演变的短期物理未来和用于表示任务进度的分阶段语义未来。我们引入了JEPA-WAM，它通过Stage-JEPA（一种目标条件下的联合嵌入预测架构（JEPA）预测器）增强了基于Motus的世界动作模型（WAM）。给定当前观察和任务指令，Stage-JEPA使用冻结的V-JEPA2编码器提取当前状态表示，并预测下一推断阶段的潜在目标。在干净和随机化环境中的50个RoboTwin 2.0任务中，JEPA-WAM实现了90.25%的总体成功率，并将成功 rollout 中的平均执行步数相对于最强基线减少了5.97%。

## Abstract
Generalist robot policies aim to map multimodal observations and linguistic task instructions to actions across diverse tasks. However, existing methods typically represent the future as a fixed, short video-action chunk. This short-term future captures local scene evolution for action execution, but it does not explicitly describe the stage-level future that specifies how a task should progress from its current stage to the next. We therefore distinguish two complementary futures for robot manipulation: a short-term physical future to capture local scene evolution and a stage-level semantic future to represent task progress. We introduce JEPA-WAM, which augments a Motus-based World Action Model (WAM) with Stage-JEPA, a goal-conditioned Joint-Embedding Predictive Architecture (JEPA) predictor. Given the current observation and task instruction, Stage-JEPA uses a frozen V-JEPA2 encoder to extract the current-state representation and predicts the latent target of the next inferred stage. Across 50 RoboTwin 2.0 tasks in clean and randomized environments, JEPA-WAM achieves 90.25% overall success and reduces the mean number of execution steps in successful rollouts by 5.97% relative to the strongest baseline.

  - **Vision-Language-Action Models（VLAs）**：如 RT-2、OpenVLA、π0.5 等，直接建立“观察到动作”的映射，完全未显式建模环境的未来演变过程，任务进度隐含在策略内部。
  - **World Action Models（WAMs）**：如 UWM、UVA、Motus 等，联合预测未来视频帧与动作块，提供了密集的局部场景演变监督（物体运动、接触、场景变化），但将“任务进展”隐式地表示为稠密的时间 rollout，未明确表达当前任务应达到的**下一个有意义的状态**。
- 论文的核心洞察是：机器人操作中存在两种互补的“未来”——
  - **短期物理未来（short-term physical future）**：局部视频-动作的即时演变，回答“接下来画面怎么变、手怎么动”；
  - **阶段级语义未来（stage-level semantic future）**：任务从当前阶段推进到下一阶段所需达到的目标状态，回答“这个任务下一步应该完成什么”。
- 直接预测远端目标图像存在缺陷：像素级预测容易过度关注外观细节而非任务完成度。因此论文引入 **JEPA（Joint-Embedding Predictive Architecture）** 这一在表征空间进行预测的机制，来建模阶段级语义未来。

**整体含义：** 论文提出 JEPA-WAM，将“预测下一任务阶段”的语义引导与“局部视频-动作生成”的世界模型有机结合，使策略既理解任务应如何推进，又能生成实现该推进所需的精细动作。

## 2. 论文提出的方法论

**核心思想：** 用目标条件化的 JEPA 预测器（Stage-JEPA）从当前观察和任务指令中预测下一任务阶段的潜在表征，再将该表征通过门控接口注入 WAM（Motus）中，作为视频预测和动作生成的去噪条件，从而让阶段级语义目标引导短时世界模型的生成过程。

**总体架构（两阶段训练 + 闭环推理）：**

**Stage I：训练 JEPA 预测器（Stage-JEPA）**
- **阶段边界自动构建（无需人工标注）**：
  - 从机器人轨迹中每 8 帧采样候选中心帧，用冻结的 V-JEPA2 编码 64 帧片段，得到 token 级和片段级表征。
  - 通过局部窗口内的表征变化分数（clip-level 与 token-level 的最大归一化距离）识别显著过渡帧，再经时序 NMS（半径 r=3，最多 K=5 个关键帧）得到阶段边界序列 B = (b₀, ..., b_L)。
  - 对每个阶段区间 [bᵢ, bᵢ₊₁)，将每个当前帧 t 与下一边界 bᵢ₊₁ 配对，形成稠密监督对集合 P。
- **目标条件化预测**：
  - 使用冻结的 V-JEPA2 编码器分别编码当前切片 Sₜ（以 t 为中心的 64 帧）和目标切片 S_target（以 bᵢ₊₁ 为中心），得到当前潜变量 zₜ 与目标潜变量 z_target。
  - 可训练的预测器（从 V-JEPA2 predictor 初始化）预测 token 级下一阶段表征，经池化与归一化后与目标表征计算余弦相似度损失：

  $$L_{stage} = \frac{1}{B}\sum_{i=1}^{B}\left(1 - (\hat{z}^{target}_i)^\top z^{target}_i\right)$$

  - 仅优化预测器和指令适配器，编码器保持冻结。

**Stage II：训练阶段条件化的 WAM**
- 以 **Motus**（Mixture-of-Transformers 架构）为 WAM 骨干，包含三个专家流：视频生成专家（初始化自 Wan2.2）、动作专家、视觉语言理解专家（冻结的 Qwen3-VL），通过 Tri-modal Joint Attention 实现跨流信息交换。
- **门控注入机制**：将 Stage-JEPA 输出的 token 级预测进行 mean-pooling，经 MLP 映射到 Wan 视频 token 维度后，通过全局标量门控 α = 0.2σ(β) 缩放，加到视频分支的 noisy tokens 上：

  $$h_t = P_\psi(\text{Pool}(\hat{Z}^{target}_t)) \in \mathbb{R}^{d_v}$$
  $$\alpha = 0.2\sigma(\beta)$$
  $$\tilde{X}^v_t = X^v_t + \alpha h_t$$

- **条件正则化**：训练损失为 L = L_video + L_action + L_reg，其中 L_reg 包含两项正则：λ_g α² 使门控偏向小的残差更新，λ_ρ(ρ − ρ₀)² 约束注入特征幅度相对于原始视频 token 的比值 ρ 接近目标 ρ₀。
- 阶段 I 的 JEPA 分支完全冻结，仅训练 WAM 和条件接口，防止细节导向的损失破坏语义目标。

**闭环推理：**
- 维护因果 64 帧观察缓冲区（不足时重复最早帧填充），每个决策时刻执行两步：
  1. 冻结的 f_θ 从缓冲区与指令预测阶段潜变量 ẑ_target；
  2. WAM 以该潜变量为条件，预测短时视觉未来和动作块。
- 环境执行动作块后更新缓冲区，循环往复。阶段边界和目标切片仅为训练时监督，推理时不依赖未来信息。

## 6. 论文的主要结论与发现

1. **有效性**：JEPA-WAM 在 50 个 RoboTwin 任务上实现 clean 环境 91.42%、随机化环境 89.08% 的平均成功率，总体 90.25%，超过所有基线（Motus 为 88.66%/87.02%）。
2. **类别差异**：在 handover、targeted placement、container packing 等依赖显式任务进展变化的类别上提升最显著（如 Handover 在 Motus 82.00%/68.00% 基础上提升至 96.50%/93.50%）；在 acquisition & lifting 等主要依赖抓取几何与接触稳定性的类别上提升有限。
3. **消融验证**：各组件均有贡献——移除 JEPA 降幅最大；不注入未来潜变量（仅改当前观察表征）也会显著降低成功率；Stage-I 训练和门控正则化提供额外增益。
4. **执行效率**：JEPA-WAM 将全部 rollout 的平均 episode 长度从 156.28 降至 132.80（降 15.02%）；仅统计成功 rollout 时，从 79.57 降至 74.82（降 5.97%），表明阶段引导能减少冗余纠正运动。
5. **定性验证**：执行轨迹和视觉 rollout 显示，JEPA-WAM 能更快推进到任务完成阶段，而 Motus 会出现反复的上下移动和局部修正。
6. **真实世界验证**：在 LIFT2 平台上，JEPA-WAM（48.00 平均任务进度分）优于 π0.5（41.50），尤其 Cube_Grasp 提升明显（45.00 vs 33.50）。

## 7. 优点

1. **问题视角新颖**：明确提出“短期物理未来”与“阶段级语义未来”的区分，为机器人未来建模提供了双尺度互补的理论框架。
2. **免人工标注的阶段挖掘**：利用冻结 V-JEPA2 表征自动检测阶段边界，无需人工标注或额外的阶段标注模型，可扩展性强。
3. **JEPA 的合理运用**：在表征空间预测而非像素空间预测，天然避免了对低级外观细节的过度关注，更匹配任务完成语义。
4. **模块化设计**：两阶段训练解耦了“语义目标学习”与“局部执行学习”，Stage-I 冻结防止细节损失破坏语义目标，设计逻辑清晰。
5. **注入方式精巧**：门控注入（全局标量 α + 正则化约束）在引入阶段信号的同时限制了其对视频 token 原始表示的干扰幅度，工程实现上简单而有效。
6. **实验设计较全面**：50 任务大规模评估、7 类语义划分、4 组消融、执行效率分析、真实机器人验证，多维度支撑核心主张。
7. **诊断详细**：对自动构建的阶段监督进行了充分的统计分析（阶段长度、跨边界比例、重叠比例），增强了方法透明度。

## 8. 不足与局限

1. **架构依赖较强**：Stage-JEPA 强依赖 V-JEPA2（需 64 帧输入），推理时需要维护 64 帧因果缓冲区，引入额外内存与计算开销；未讨论该分支的推理延迟对闭环控制频率的影响（论文在结论中也承认这一点）。
2. **实验对比的公平性存疑**：基线数据来自 Motus 论文的公开结果，而非在本论文统一的代码框架下复现，可能在数据预处理、训练配置、评估细节上存在不一致。
