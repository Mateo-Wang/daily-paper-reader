## 摘要
视觉-语言-动作（VLA）模型近来已成为端到端自动驾驶的一种有前景的范式，能够在感知、语言和规划之间实现统一推理。然而，现有方法缺乏利用过往故障或适应分布偏移的机制，导致模型在之前失败的类似场景中持续表现不佳。本文提出DriveVLA-M0，一种带有故障感知潜在记忆的检索增强VLA模型。我们构建了一个存储故障案例及其结构场景表示和专家轨迹标签的潜在记忆池，并设计了一个专用的检索模型，该模型解耦静态道路结构与动态智能体交互，以实现基于结构的检索。在推理时，检索到的案例通过一种轻量级的解耦LoRA测试时训练（TTT）机制注入模型，从而在不修改主干网络的情况下实现针对性和场景特定的修正。在NAVSIMv1和NAVSIMv2基准上的大量实验表明，我们的方法持续优于先前方法，在Navtest上达到94.1 PDMS，在Navhard上达到47.0 EPDMS，且仅产生26.44毫秒的TTT反向传播延迟开销。此外，我们展示了DriveVLA-M0随着记忆的增加而有效扩展，通过记忆扩展实现无需训练的性能提升。代码可在https://github.com/ZebinX/DriveVLA-M0获取。

## Abstract
Vision-Language-Action (VLA) models have recently emerged as a promising paradigm for end-to-end autonomous driving by enabling unified reasoning across perception, language, and planning. However, existing approaches lack mechanisms to exploit past failures or adapt to distribution shifts, causing the model to persistently underperform on similar scenarios where it has previously failed. In this paper, we propose DriveVLA-M0, a retrieval-augmented VLA with failure-aware latent memory. We construct a latent memory pool that stores failure cases along with their structure scene representations and expert trajectory labels, and design a dedicated Retrieve Model that decouples static road structure and dynamic agent interactions to enable structurally grounded retrieval. At inference time, retrieved cases are injected into the model via a lightweight decoupled LoRA-based test-time training (TTT) mechanism, allowing targeted and scenario-specific correction without modifying the backbone. Extensive experiments on NAVSIMv1 and NAVSIMv2 benchmark demonstrate that our approach consistently outperforms prior methods, achieving 94.1 PDMS on Navtest and 47.0 EPDMS on Navhard with only 26.44 ms TTT backward latency overhead. Furthermore, we show that DriveVLA-M0 scales effectively with additional memory, enabling training-free performance gains through memory expansion. The code is available at https://github.com/ZebinX/DriveVLA-M0.

- **研究背景**：视觉-语言-动作（VLA）模型通过统一推理感知、语言与规划，成为端到端自动驾驶的新兴范式（如 LMDrive、DriveVLM、AutoVLA 等），展现出良好的泛化与扩展潜力。
- **核心痛点**：现有 VLA 驾驶模型缺乏两大关键能力：
  1. **利用过往失败经验**：模型在相似场景中会重复犯错，无法将当前情境与历史失败建立关联；
  2. **适应分布偏移**：面对训练分布之外的场景（长尾、安全关键场景）时表现持续欠佳。
- **认知科学依据**：人类行为学研究表明，人类会将当前情境与历史错误关联，预测当前情境的失败概率并相应调整行为（Botvinick 等，2001；Brown & Braver，2005）。作者由此获得启发。
- **现有方法不足**：已有的记忆增强方法（如 MemoryVLA、EchoVLA、MANTRA、MemoNet 等）主要在视觉-语言特征空间进行检索，难以有效捕捉自动驾驶决策依赖的两类关键信息：
  - **动态信息**：周围智能体的运动状态；
  - **结构信息**：道路拓扑、车道线等场景几何结构。

## 2. 方法论

### 2.1 整体核心思想

提出 **DriveVLA-M0**，一种"故障感知潜在记忆 + 结构化检索 + 测试时训练（TTT）"的检索增强 VLA 框架。核心洞察是有效的驾驶记忆增强需要同时满足两个性质：
1. **结构化检索**：基于场景的动态（智能体交互）与物理（道路结构）相似度检索，而非视觉-语言相似度；
2. **故障感知**：专注基础模型表现不佳的场景，而非均匀覆盖所有场景。

框架分为两个阶段：**离线记忆生成（[M]）** 与 **在线 TTT 推理（[I]）**，由算法 1 给出完整流程。

### 2.2 基础模型（Base Model）

- **VLM 骨干**：采用 InternVL3，在大规模自动驾驶问答数据上微调（基于 ReCogDrive 收集的约 775K 高质量 QA 对）。
- **特征压缩模块**：由于 LLM 最后一层特征（2800×1536 token）内存开销过大，采用 Q-Former 风格压缩模块（16 个可学习查询，维度 256），通过交叉注意力将特征压缩为紧凑表示 **F_lang**（压缩比约 1050×）。
- **动作解码器（Action Decoder）**：两阶段设计：
  - **Trajectory Head**：将 Ego 状态编码为 F_ego，与 F_lang 联合解码，通过可学习查询 Q_ego 生成 M 条多样化的轨迹簇 T̂ ∈ R^{M×8×3}；
  - **Score Head**：对轨迹候选重新编码并与 F_lang 融合，输出 K 个子评分（碰撞率、可行驶区域合规等安全指标）；
  - 最终选择聚合评分最高的轨迹作为输出。

### 2.3 检索模型（Retrieve Model）

- **架构**：采用轻量级预训练 **DINOv2** 作为特征提取器，使用 LoRA 微调。
- **解耦 LoRA 设计**：将特征提取分为 Map（静态）与 Agent（动态）两个分支，并行路由输入图像，同时输出：
  - **F_map**：捕捉静态道路结构（车道线、边界、路缘）；
  - **F_agent**：捕捉动态智能体上下文。
- **监督训练**：遵循 Transfuser 的占用网格监督范式，预测地图与智能体的占用网格，使用二元交叉熵损失联合训练：`L_Retrieve = BCE(M̂_map, M_map) + α·BCE(M̂_agent, M_agent)`（实验中 α=10）。
- **可视化验证**：注意力图显示 map 嵌入聚焦道路拓扑，agent 嵌入主要关注前方车辆，验证了解耦设计的有效性。

### 2.4 记忆生成（Memory Generation，离线阶段）

- **记忆结构**：采用基于案例（case-based）的潜在记忆设计。每个记忆条目包含三类信息：
  - **检索键 k**：静态地图特征 F_map 与动态智能体特征 F_agent；
  - **适配输入 x**：语言嵌入 F_lang、Ego 状态嵌入 F_ego、中间轨迹簇 T̂；
  - **监督标签 y**：专家轨迹 τ 与 PDM 评分的轨迹簇评分 S。
- **失败场景识别**：将基础模型在训练/外部数据上推理，用 PDM 模拟评分器评估轨迹质量，当聚合评分 `Q(τ̂) < β`（β=0.5）时判定为失败场景并写入记忆。
- **去重机制**：写入前通过余弦相似度去重，防止冗余，控制记忆池规模（Base 配置约 4K 条，Scale 配置约 10K 条）。

### 2.5 在线 TTT 推理（Inference with TTT）

- **结构化检索**：当前场景图像经检索模型提取 F_map 与 F_agent，分别在地图层与智能体层检索 top-k 最相似案例。
- **触发机制（Trigger）**：基于余弦相似度判定是否激活 TTT：
  - 当相似度 > λ（实验中 λ=0.9）时触发 TTT；
  - 否则直接返回基础模型输出，避免无关检索引入噪声、控制计算开销。
- **解耦 LoRA TTT**：针对每个测试场景重新初始化 LoRA 权重，保证场景特定适配：
  - **地图检索案例** → 微调 Map（静态）LoRA 分支；
  - **智能体检索案例** → 微调 Agent（动态）LoRA 分支。
- **路径感知评分融合**：道路理解类子评分（如可行驶区域合规）采用静态 LoRA 预测；动态能力类子评分（如碰撞避免）采用动态 LoRA 预测，跨轨迹簇融合选择最优输出 τ̂*。
- **部署优化**：采用分层检索策略——先用地图嵌入过滤 top-k₁ 场景，再用智能体嵌入精排 top-k₂ 匹配（k₁=3k₂, k₂=3），以应对无周围交通参与者的空场景。

## 6. 主要结论与发现

1. **故障感知记忆有效**：将失败案例以结构化潜在记忆形式存储并在推理时注入，能显著提升 VLA 驾驶模型在易错场景中的表现（NAVSIMv1 上 +1.3 PDMS over base，NAVSIMv2 上达到 47.0 EPDMS）。
2. **结构化检索优于语言空间检索**：语言嵌入检索（90.7 PDMS）甚至低于基础模型（91.0 PDMS），而 Map+Agent 解耦检索可达 92.3 PDMS，证明驾驶场景检索需要显式考虑道路拓扑与智能体交互。
3. **TTT 优于离线微调**：离线用失败数据训练 10 轮仅获得 91.2 PDMS，而 TTT（92.3-92.4 PDMS）能实现场景特定适配，更充分利用记忆的纠正潜力。
4. **选择性触发是关键**：λ=0.9 为最优（91.7 PDMS），过宽松（0.7）引入噪声、过严格（0.99）失去覆盖，验证了"基于高置信结构相似性的选择性适配"优于无条件 TTT。
5. **解耦 LoRA 兼顾效率与性能**：Decoupled LoRA TTT（92.3 PDMS）几乎匹配全参 TTT（92.4 PDMS），但反向传播延迟降低约 52%。
6. **记忆池可无训练扩展**：通过合成数据扩展记忆至 10K，无需修改基础模型即可获得一致性能提升（92.3 → 94.1 PDMS）。

**训练/推理范式高效**：TTT 只需 3 步优化即可实现显著的场景特定适配，且解耦 LoRA 进一步将反向传播开销降低至全参数适配的一半以下，兼顾了性能与实时性。  
- **扩展性设计巧妙**：记忆池与基础模型解耦，支持通过合成数据或外部数据持续扩充而无需重训练，为自动驾驶模型的持续学习提供了一条低成本路径。
- **工程细节扎实**：从特征压缩（Q-Former）、动作解码器两阶段设计、检索触发阈值到分层检索策略，均有清晰的工程考量与实验支撑，可复现性强。

## 8. 缺点与局限性

- **对 NAVSIMv2 的 VLA 对比不足**：Navhard 基准上仅与少数非 VLA 方法（如 LTF、DiffusionDrive、GTRS-Dense）对比，缺少与其他 VLA 模型的横向比较，削弱了“VLA 方法中最优”这一结论的说服力。
- **记忆依赖 PDM 评分器**：失败场景的判定依赖 PDM 模拟评分器，该评分器的指标设计（如 NC、DAC 等）是否与真实道路安全完全对齐存在疑问；在真实世界中，“失败”的定义远不止轨迹评分所能涵盖。
- **检索质量的天花板效应**：结构化检索虽优于语言空间检索，但其效果高度依赖 DINOv2 提取的静态/动态特征质量；若场景中存在极端光照、遮挡或罕见道路结构，检索嵌入的可靠性可能下降，但论文未对此类鲁棒性做压力测试。
- **触发机制的保守性**：λ=0.9 的高相似度阈值意味着仅对与记忆高度匹配的场景激活 TTT，面对中等相似度的长尾场景可能仍无法受益，“选择性适配”在覆盖范围上存在上限。
- **记忆规模仍需人工/合成数据支撑**：10K 记忆池依赖 Sim-Scale 合成数据，合成数据的分布与真实场景的偏差可能限制扩展增益；论文对此偏差的分析较浅。
- **缺乏闭环实验验证**：NAVSIMv1 为开环、NAVSIMv2 为伪闭环，均未在真实闭环仿真（如 CARLA）或实车中验证，TTT 引入的逐场景参数更新在真实系统长期运行中的累积稳定性仍未知。
- **消融实验规模偏小**：触发阈值与 TTT 超参消融各在一个基础模型上完成，缺少在不同骨干网络（如不同规模 VLM）上的泛化验证。

## 9. 个人评价与思考

DriveVLA-M0 的核心贡献在于将“记忆增强”从视觉-语言语义空间推进到“结构化驾驶语义空间”，并以测试时训练的方式实现真正的场景特定适配。这一思路在当下 VLA 驾驶模型“重预训练、轻在线适配”的潮流中显得尤为可贵，也为“如何让自动驾驶模型从错误中学习”提供了一个工程上可落地的范式。  
当然，论文的实验主要依托仿真基准，记忆检索与 TTT 的实际安全收益仍需在更真实的闭环环境中检验。此外，逐场景的 TTT 更新虽然延迟可控，但如何在长期运行中防止灾难性遗忘与参数漂移，仍是值得后续探索的重要方向。总体而言，这是一篇问题聚焦、方法新颖、实验扎实的论文，对 VLA 自动驾驶领域具有较高的参考价值。
