## 摘要
请求到交接的差距有三个耦合来源：请求时预期行为的不确定性、动作生成期间累积的物理状态漂移，以及新动作最终接管时的残留不兼容性。BICPO-VLA 依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序 Haar 子空间生成将每个动作块分解为互补的成对支架和残差系数，从而实现两个专门的生成阶段，随后进行精确重构。通过减少原始动作空间中的迭代细化，它缩短了在新块可用之前机器人继续移动的间隔。最后，BICPO 将已知的传出动作推进到实际的交接状态，并在行为匹配的候选中应用参考相对的 Flow-DPO，使生成的块适应剩余的请求到交接的不匹配，而不改变其预期的行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

### 1. 论文的核心问题与整体含义

**研究动机。** 异步视觉-语言-动作（VLA）控制中，机器人执行上一个动作块时，系统正在推断下一个动作块。新动作块在一个运动上下文中生成，却在另一个状态下接管控制，因此即使语义预测完全正确，仍可能出现边界跳跃或运动趋势中断。作者将“请求到交接（request-to-handoff）”间隙归纳为三个耦合来源：

- **行为意图歧义**：请求时刻对预期行为的理解不唯一；
- **物理状态漂移**：动作生成期间机器人持续运动，实际状态已偏离请求时状态；
- **残留不兼容**：新动作最终接管时，与当前物理状态存在不匹配。

**核心洞察。** 一个“行为（behavior）”定义的是一个动作实现族（作者称之为 *behavior-conditioned action fiber*），而非唯一轨迹；同一族内成员共享任务语义，但局部运动与交接兼容性不同。因此，延迟执行问题应被重构为“在语义有效的动作族内，依据交接状态选择恰当实现”的问题，而非泛泛追求平滑。

**总体思路。** 论文提出 BICPO-VLA，通过三步分解逐一攻克三个耦合来源：先识别行为、再结构化生成实现、最后基于交接状态做偏好优化适配。该分解的意义在于：三个决策受不同约束支配，混淆它们会掩盖延迟变化时究竟哪一部分需要调整。

### 2. 论文提出的方法论

**整体框架。** BICPO-VLA 将行为识别（behavior identity）、实现结构（realization structure）、交接选择（handoff selection）三者显式分离，整个流程为：

1. 指令感知编码 → 识别行为纤维
2. Haar 子空间生成 → 结构化动作实现
3. 交接状态滚动 + Flow-DPO → 偏好适配

**2.1 指令感知的行为识别**

- 视觉 token 在进入历史编码器之前，先通过交叉注意力被指令特征“路由”（instruction-aware routing），过滤与当前指令无关的视觉证据，避免无关信息混入历史状态。
- 因果历史编码器（采用因果 Mamba 块）聚合路由后的观测序列与已执行动作，得到行为状态 z_r（指令相对进度的连续表征，而非离散阶段）。
- 解码器将 z_r 与检索到的长期记忆 m_r 融合，输出动作先验 μ_r。条件 b_r ≡ (ℓ, z_r, m_r, μ_r) 共同固定行为身份，后续阶段只调整其实现。

**2.2 交接条件化的 Haar 实现**

- **滚动交接上下文**：利用冻结的动作历史模型，将已知的传出命令 U_k^r 确定性滚动到实际交接状态 h̄_{r+k}，并计算其与请求时状态的位移 Δh，两者拼接后通过投影网络得到交接条件 g_k。
- **Haar 变换**：对动作块 A 做正交 Haar 变换，分解为支架系数 C（成对动作的粗略趋势）与残差系数 D（对内的精细变化），可由正交逆变换精确重构（无损）。
- **两阶段生成**：第一阶段基于先验 μ_C^r、交接条件 g_k 生成支架 C；第二阶段以冻结的支架为条件，生成残差 D。两阶段共享同一专家网络，但使用不同的阶段嵌入与掩码。有监督训练最小化两阶段速度场预测误差。

**2.3 行为识别的延续偏好优化（BICPO）**

- **同纤维候选对**：在相同条件 χ_{r,k} 下，用不同流噪声采样两个候选动作块，从“同一行为的不同实现”中做偏好学习。
- **延续代价**：定义零阶跳跃（J_jump）和一阶趋势不匹配（J_trend），组合成延续代价 J_cont；代价更小的候选被偏好。
- **参考相对 Flow-DPO**：将 DPO 推广到流匹配能量（flow energy）上，通过比较当前策略与冻结参考模型的能量差（reference-relative）来构造偏好梯度，避免局部平滑优化破坏语义正确性。冻结语义通路，只更新延续投影、交接投影及部分专家参数。
- **可迁移性**：该 DPO 目标可直接应用于 π0.5 flow matching、Legato、RTC 等其他策略，无需附加 BICPO-VLA 的指令编码器、Haar 生成器或交接投影器。

### 6. 论文的主要结论与发现

- **三源耦合问题可被顺序分解解决**：行为识别、结构生成、交接适配三个步骤增益互补，各自消除一个不匹配来源。
- **Haar 子空间生成有效缩短交接前间隔**：两阶段生成比在原始动作空间迭代细化更快，且正交变换保证无损重构，不引入表示瓶颈。
- **参考相对 Flow-DPO 优于直接平滑回归**：直接 SFT 会通过“少动”来降低平滑代价，严重损害成功率（π0.5 从 96.9% 跌至 49.1%）；DPO 在保持成功率的同时降低跳跃和趋势代价。
- **延续偏好目标可迁移**：应用于 π0.5、Legato、RTC 时均能降低 jump 15.8–40.3%、trend 11.5–21.2%，而成功率仅变化 0.1–0.2 点。
- **指令在感知层介入最有效**：在历史融合之前进行指令路由优于后期查询融合或记忆融合。
- **延迟鲁棒性良好**：k=3/4/5/随机时成功率和延续代价均稳定。

### 7. 优点

- **问题分解清晰**：将“行为是什么—如何实现—如何交接”三者解耦，分别受指令、结构与交接状态约束，逻辑严密。
- **纤维化视角新颖**：将行为视为动作实现的等价类，而非单一路径，为交接问题提供了优雅的形式化框架。
- **Haar 变换设计巧妙**：无损、线性、可逆，将动作分解为语义明确的粗趋势+细残差，同时加速生成过程；与简单压缩/蒸馏有本质区别。
- **参考相对 DPO 机制稳健**：冻结参考模型做相对比较，有效防止平滑优化退化为“少动”或“改变行为阶段”；候选过滤机制排除低活性动作。
- **可迁移性实验设计出色**：将 DPO 目标单独剥离到三种外部策略上验证，证明“偏好原则”本身有效，而非仅依赖 BICPO-VLA 整体架构。
- **消融实验系统性强**：从组件级到指令注入位置再到延迟鲁棒性，多层次验证设计决策。
