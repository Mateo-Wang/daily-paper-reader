## 摘要
视觉-语言-动作（VLA）模型近期在机器人操作领域展现出良好的性能。然而，现有基准主要评估静态操作任务的泛化能力，而在很大程度上忽略了动态交互场景。为解决这一差距，我们提出了ReflexBench，一个面向关键反应操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。在ReflexBench的基础上，我们提出了ReflexVLA，一种高效VLA模型，专为关键反应操作设计，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA图重放降低了部署延迟。实验表明，ReflexVLA在保持标准静态操作基准上具有竞争力的准确性的同时，持续提升了动态操作性能，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. Project website: https://reflexvla.github.io

## 2. 方法论

### 2.1 ReflexBench：延迟感知的动态操作基准

- **任务设计**：包含6个动态操作任务，均要求策略在动态环境中快速反应并预判未来：
  - 传送带抓取放置、接球、打地鼠、滚动球拦截、抛球入桶、旋转插销插入
- **评估框架**（核心创新）：
  - 将**模拟器步进**与**机器人控制**解耦，环境动态独立于策略计算持续推进
  - 显式建模两种推理范式：**同步推理**（阻塞执行直至推理完成）与**异步推理**（推理与动作执行重叠，存在动作延迟）
  - 支持**可配置延迟注入**：可手动指定延迟时长，或通过实时因子（RTF = t_sim / t_wall）将实测推理延迟换算为模拟器内等效延迟

### 2.2 ReflexVLA：面向动态操作的预测性高效模型

- **基础架构**：基于VLA-Adapter（1B参数），视觉编码器为融合DINOv2与SigLIP的ViT（224×224），语言骨干为Qwen2.5-0.5B，通过可学习动作查询和连续回归头生成动作块。
- **三大核心设计**：

**(a) 潜在未来预测（Latent Future Prediction）**
- 使用**冻结的DINOv3模型**提取未来观测的语义特征作为预测目标：
  - y_{t+i} = φ_DINOv3(o_{t+i})，特征维度1024
- 在输入序列中追加H个可学习的未来token（H等于动作块大小），使每个token对应动作块中的一个未来控制步
- 通过掩码余弦相似度损失训练：
  - L_future = Σ m_i [1 − cos(ŷ_{t+i}, y_{t+i})] / Σ m_i
- 总损失：L = L_act + λ_future · L_future
- 关键发现：使用**冻结**的DINOv3特征（而非可训练的目标编码器）提供稳定监督信号，效果显著更优

**(b) 多帧时间融合（Multi-Frame Temporal Fusion）**
- 在视觉编码器的**中间层特征**（而非最终层）上执行时序融合，保留更丰富的运动线索
- 对每个视角及patch位置，将T个历史帧的特征形成时序轨迹，依次进行LayerNorm、降维投影、加时间位置编码，然后执行**因果时序注意力**（防止未来信息泄漏），最后上采样并残差加到当前帧的最终层特征上
- 优势：语言模型侧可见的视觉token数量与单帧设置完全相同，避免了多帧拼接带来的二次复杂度开销

**(c) 推理延迟优化（Inference Latency Optimization）**
- **批量视觉编码**：将V×T张图像合并为一次视觉编码器前向，减少框架重复执行开销
- **CUDA Graph重放**：将完整推理管线（含视觉编码、时间融合、多模态投影、语言模型推理、动作预测）捕获为CUDA Graph；部署时将新观测拷贝至预分配缓冲区并直接重放，消除逐次kernel启动的开销
- 这两项优化不修改模型架构或学习目标，仅降低系统开销

## 6. 主要结论与发现

1. **推理范式与超参选择**：高频异步推理搭配较大的动作块尺寸与较短的动作视野能取得最佳动态操作性能；低频时异步推理因观测-动作失配而劣于同步推理。

## 7. 优点

- **基准设计具有开创性和实用性**：ReflexBench首次将推理延迟显式纳入评估协议，解耦模拟器步进与机器人控制，且支持可配置延迟注入，比现有基准更贴近真实部署条件。
- **方法设计轻量高效**：ReflexVLA无需大规模预训练即可获得优异动态性能；潜在未来预测仅增加H个token，时间融合不增加语言模型侧序列长度，计算开销极小。
- **未来预测目标选择合理**：使用冻结的DINOv3特征作为监督目标，避免联合优化不平衡问题，设计决策有实验支撑。

## 8. 不足与局限

- **预训练缺失**：未来预测和多帧融合仅在微调阶段引入，未参与大规模预训练，模型潜力可能未完全发挥。
