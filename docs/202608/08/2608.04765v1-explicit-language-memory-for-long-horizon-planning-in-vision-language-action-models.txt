# Explicit Language Memory for Long-Horizon Planning in Vision-Language-Action Models 

Houze Xu Fudan University Jizhong Li Fudan University Ziyi Ye Fudan University 

Abstract 

Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process. 

# 1 Introduction 

Embodied agents must close a loop between perception, understanding, decision making, and physical action. Vision-language-action models seek to learn this loop in a unified policy by conditioning robot actions on visual observations and language instructions [5, 8, 22]. The formulation is attractive because semantic knowledge from large vision-language models can be transferred to control, and because one interface can support many tasks and robot embodiments. However, strong short-horizon action generation does not by itself provide reliable long-horizon planning. Many multi-stage tasks are non-Markovian from the perspective of a single observation. The same view of a radio, package, or gripper can correspond to different decisions depending on whether an earlier grasp succeeded, whether a button has already been pressed, or whether a package has passed through a required scanning stage. When history is weakly represented, a VLA policy can skip stages, repeat completed actions, or commit to a downstream action after an unobserved failure. Errors then accumulate across the action sequence. Appending all past frames to the input is a direct response, but its context and compute costs grow with task duration and make real-time deployment increasingly difficult. 1arXiv:2608.04765v1 [cs.RO] 5 Aug 2026 We study a compact alternative: maintain task history as an explicit natural-language memory. At each decision step, a high-level VLM reads the global instruction, current observation, and previous memory. It produces an updated memory and a concise subtask. The updated memory summarizes completed milestones in the past tense, preserves decision-relevant object and state information, and states the next intent. A low-level VLA receives the current observation and subtask and predicts a fixed-horizon action chunk. The resulting design gives semantic planning and continuous control separate optimization targets while exposing the internal progress state for analysis. The central hypothesis is that language memory improves phase consistency : the agent should advance only after the observation supports completion of the current milestone. This mechanism is complementary to improved low-level control. It can explain that pressing a button is still required, but it cannot by itself guarantee geometric alignment or successful contact. We test this distinction in household simulation, humanoid manipulation simulation, and a real low-cost dual-arm mobile robot. Our contributions are: 

• a hierarchical VLM-VLA architecture that decomposes a long-horizon policy into recursive semantic state tracking and continuous action generation; 

• an explicit rolling language memory that compresses completed stages while retaining detailed information for the current and next subtasks; 

• an automated supervision pipeline that converts expert videos, skill labels, and timestamps into aligned subtask and memory targets, followed by independent training of the high-level and low-level branches; and 

• simulation and real-robot evidence that language memory improves stage tracking, reduces skipped steps, and supports simple in-context failure recovery. 

# 2 Related Work 

2.1 Language Models for Hierarchical Robot Planning 

Language models have been used as high-level planners over pretrained robot skills. SayCan grounds proposed language actions with skill affordances, connecting broad semantic knowledge to an embodied action set [1]. Inner Monologue closes the planning loop by feeding success detection, scene descriptions, and human feedback back into the language context [7]. These systems make high-level decisions interpretable, but typically rely on externally defined skills and interfaces between planning and control. Our method retains a hierarchical interface while learning both semantic progress tracking and low-level action generation from demonstrations. 

2.2 Vision-Language-Action Policies 

RT-1 models robot control as token prediction at scale, while RT-2 transfers web-scale visual-language knowledge into robotic action tokens [5, 22]. OpenVLA provides an open VLA model and efficient adaptation mechanisms [8]. Flow-based policies such as π0generate continuous action trajectories without forcing high-frequency control into a small discrete vocabulary [3]. π0.5extends this family with heterogeneous co-training and high-level semantic prediction for open-world generalization [14]. 2Figure 1: Original illustration of the two-stage inference pattern in π0.5: a pretrained VLA predicts a semantic subtask and conditions a flow-matching action expert that produces continuous actions. The asset is extracted from Fig. 2-1 of the source thesis, where it illustrates the model described in [14]. 

The two-stage pattern shown in Fig. 1 motivates the separation between semantic subtask prediction and continuous action generation used in this work. Several approaches expose reasoning before action generation. Embodied Chain-of-Thought trains VLAs to reason about plans, subtasks, motions, and grounded visual features [20]. dVLA and DualCoT-VLA further integrate multimodal or parallel visual-linguistic reasoning with action generation [18, 21]. These methods focus on reasoning traces produced for the current decision. In contrast, our memory is a recursively updated state variable designed to persist across decisions. 

2.3 Memory for Long-Horizon Control 

History-aware robot policies represent temporal context in several ways. RDT and Octo learn generalist action priors from diverse robot data [12, 13]. HAMLET compresses perceptual history into moment tokens and a lightweight memory module [9]. MemoryVLA maintains perceptual and cognitive memories, while MAP-VLA retrieves demonstration-derived memory prompts for long-horizon manipulation [11, 16]. Our approach instead treats natural language as the primary memory carrier. This choice gives the history a compact supervised representation, allows direct inspection of progress and failure state, and provides a stable semantic interface to the low-level VLA.

3.2 Recursive Language Memory 

The memory mt is a structured natural-language summary of historical events, current task state, and near-future intent. It is not intended to narrate every frame. Instead, it retains information that disambiguates the current decision: completed stages, completion evidence, relevant object attributes, observed failures, and the next pending milestone. The update follows a rolling-compression rule. Before a subtask is completed, memory preserves details that help identify its target, such as category, color, and location. After completion, those details are compressed into a short past-tense statement and attention shifts to the next action. For the radio task, an update can take the form 

mt : I am moving to the red radio on the coffee table. 

mt+1 : I moved to the radio, and I am going to pick up the red radio. (2) This detail-to-summary transition keeps the memory bounded in practice while preserving a semantic anchor for phase progression. The high-level model updates memory only when the current observation provides evidence that the active milestone has changed. 

3.3 Automated Memory Supervision 

Training the high-level branch requires a target memory and subtask for each sampled observation. Each expert episode contains a video and manually provided skill-level annotations with skill names, descriptions, and start and end timestamps. The video is divided into frames, and the timestamp identifies the active skill index. A general-purpose VLM receives the current frame together with the complete skill annotation for the episode and produces two fields: 1. a concise subtask in the form action + target object + context , with no agent subject; and 42. a first-person language memory that describes completed skills in the past tense and transitions to the next skill using a future-oriented statement. The prompt explicitly asks the annotator to use natural object names and visible attributes and to avoid implementation terms such as frame, sequence, index, or skill index. Two annotation routes are reported in the source thesis: a hosted Gemini 3.5 Flash API and a locally deployed Qwen3.5-9B model [15]. The resulting frame-aligned pairs ( mt, s t) form supervised targets for the high-level policy.

BEHAVIOR-1K turning on a radio. BEHAVIOR-1K defines 1,000 everyday activities in 50 realistic scene categories [10]. We use the turning-on-radio task. Evaluation is divided into four stages: MoveTo, PickUp, PressOn, and PlaceOn. 

Genie Sim 3.0 package sorting. Genie Sim 3.0 is an Isaac Sim-based humanoid manipulation platform with more than 200 tasks and a large synthetic dataset [19]. In the single-package task, the robot follows and picks up a package, turns to a barcode-scanning area, places the package with the barcode upright, picks it up again, places it in a blue bin, and returns to its initial orientation. The six scored stages are Follow, PickUp, Inside-1, Upright, PickUp, and Inside-2. The continuous variant asks the robot to sort four differently colored packages in any order. Each package counts as a completed stage when it is placed in the scanning area with its barcode facing upward. 

Real XLeRobot pick and place. The real platform uses two SO-ARM 101 manipulators, a LeKiwi mobile base, one RGB head camera, and hand cameras [17]. A Windows host controls the robot. The experimental pipeline extends the XLeRobot, Joycon-Robotics, and LeRobot software stacks to support Switch Joycon teleoperation, trajectory recording, model training, cloud inference, and local action execution [4, 6]. The task is to pick up a block from a table and place it on a plate. It is scored at Follow, PickUp, MoveTo, and Place stages. The dataset contains 25 manually collected trajectories, and evaluation uses 20 trials. 

4.2 Models and Training Configuration 

The baseline is the native π0.5policy, and the proposed model adds the explicit language-memory hierarchy. PaliGemma is used for the high-level VLM. 6Training and fine-tuning use four NVIDIA A100 GPUs, while inference is run on one NVIDIA RTX 5880 Ada Generation GPU. The action chunk length is H = 30. The high-level PaliGemma model and the corresponding VLM backbone in the low-level VLA are adapted with LoRA, while the 300M-parameter Gemma action expert is fully fine-tuned. Optimization uses AdamW with warmup followed by cosine learning-rate decay, a peak learning rate of 2 .5 × 10 −5, batch size 64, and 50,000 training steps.

5.2 Phase Consistency and Skipped Steps 

Figure 4 aligns observations with the semantic outputs of the two policies. After picking up the radio, the no-memory baseline predicts place the radio on the table , advancing before the required button press. The resulting action sequence matches this semantic error. With memory, the state is updated to record that the radio has been approached and picked up and that pressing the button is next. The model advances only after observing evidence for that milestone. The same failure pattern appears in package sorting. During placement at the scanning area, the baseline may predict placing the package in the basket and skip barcode scanning. The memory policy does not advance to the basket stage until its context explicitly records that the package was placed in the scanning area and picked up again. The gains at Inside-1 and in the continuous task support the interpretation that memory constrains stage order. 

5.3 Semantic Planning Versus Motor Control 

The PressOn result also exposes the boundary of the method. Even when memory identifies button pressing as the correct subtask, repeated contact attempts can fail because of button localization, geometric alignment, force, or action timing. Language memory primarily resolves what to do 

and which stage is active ; it does not directly improve how to execute contact-rich motions. This distinction allows failures to be diagnosed as high-level semantic errors or low-level control errors rather than treating all failures as one end-to-end outcome. 

5.4 In-Context Failure Recovery 

The real-robot logs provide a second use for explicit state. When a grasp fails, the baseline can remain in an inconsistent state until timeout. The memory model can record that the object was not secured, issue a subtask to reopen the gripper, and attempt the grasp again. This behavior was not implemented as a separate recovery controller. Instead, the textual failure state conditions the next prediction. We describe this as in-context adaptation: history makes a failed attempt available to subsequent decisions and helps prevent immediate repetition of the same strategy. More broadly, the observed benefits fall into four categories. First, explicit completed and pending events reduce ambiguity at subtask boundaries. Second, evidence-conditioned updates discourage premature stage transitions. Third, readable memory and subtask outputs make decision failures easier to localize. Fourth, failed actions can be represented as context for recovery. 5.5 Limitations 

The real-robot evaluation is limited to a short pick-and-place task with 25 training trajectories and 20 evaluation trials. It does not establish performance on minute-scale real-world tasks with multiple objects, repeated interactions, or environmental changes. The simulation results report stage success rates but not variation across random seeds or confidence intervals, so the statistical stability of the improvements remains to be measured. The hierarchical design adds a high-level VLM call before low-level action generation. This increases compute, end-to-end latency, and deployment complexity relative to native π0.5. A future unified backbone could generate memory, subtasks, and actions together, but it would need to balance language and control objectives without degrading either capability. Finally, language memory cannot compensate for insufficient low-level data or control precision. The low PressOn success rate illustrates this limitation. Robust recovery also depends on collecting and labeling failures such as grasp offsets, collisions, and target loss together with successful corrective actions. 96 Conclusion 

We presented an explicit language-memory component for long-horizon VLA planning. The approach decomposes robot control into a high-level VLM that recursively tracks task state and a low-level VLA that produces continuous action chunks. Rolling natural-language summaries preserve completed milestones, current state, and next intent without concatenating the full visual history. An automated annotation pipeline makes this representation trainable from expert videos and skill timestamps. Across household simulation, humanoid manipulation simulation, and a real low-cost robot, the memory model improves average stage success and reduces failures caused by phase confusion. Qualitative logs show why: the memory makes stage progression conditional on observed completion evidence and can expose failure state to later decisions. The remaining gap on contact-rich actions confirms that semantic memory and motor competence solve different parts of long-horizon execution. Explicit language memory therefore provides a compact, interpretable route from short-horizon action generation toward more consistent multi-stage robot behavior. Future work can extend the current language-only state into a multimodal memory that jointly records visual evidence, language history, and physical interaction signals. In particular, tactile and force feedback could help the model distinguish successful contact, unstable grasps, button presses, collisions, and other states that may remain ambiguous in images alone. Combining these modalities with broader failure-and-recovery demonstrations may preserve the interpretability of explicit memory while giving the high-level planner more reliable evidence for progress tracking and corrective action.
