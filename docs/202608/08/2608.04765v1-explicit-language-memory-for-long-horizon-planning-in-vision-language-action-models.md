## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有的VLA模型在长时程任务中仍面临重大挑战：稀疏的专家演示限制了跨任务的组合泛化；长时程任务的非马尔可夫性使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA则根据子任务指令和视觉观测执行精确的连续控制。高层VLM利用先前记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行中实现持久的时间追踪和动态修正。我们在多个模拟环境中评估了所提方法，并在真实机器人平台上进行了仿真到现实（sim-to-real）实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务上的成功率和鲁棒性，同时为决策过程提供了可解释的语义描述。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型通过将机器人动作与视觉观测和语言指令条件化，提供了一个统一的感知-决策-控制范式，但现有VLA模型在**长时程任务**中表现不佳。
- **四个核心挑战**：
  - **稀疏专家演示**：专家数据量有限，难以支撑跨任务的组合泛化；
  - **非马尔可夫决策**：同一视觉观测在不同任务阶段可能对应不同正确动作（如"是否已按压按钮"），仅依赖当前观测无法区分，导致阶段跳变、重复或遗漏；
  - **误差累积**：闭环纠错能力有限，单步执行错误沿动作序列不断累积；
  - **语义表示弱化**：端到端动作微调可能破坏VLM骨干网络的高层语义表征。
- **核心含义**：提出一种紧凑替代方案——以**显式自然语言记忆**维护任务历史，将"做正确的事"（语义规划）与"正确地做事"（连续控制）解耦，在多阶段任务中实现阶段一致性和可解释决策。

## 2. 方法论

### 2.1 核心思想
将长时程策略分解为两层：
- **高层VLM（π_HL）**：负责语义推理，递归更新语言记忆和子任务指令；
- **低层VLA（π_LL）**：基于当前观测与子任务指令生成固定时域（H=30）的连续动作块。

策略分解公式：

```
π(a_{t:t+H}, s_t, m_t | o_t, m_{t-1}, l) = π_LL(a_{t:t+H} | o_t, s_t) · π_HL(s_t, m_t | o_t, m_{t-1}, l)
```

### 2.2 关键技术细节
- **递归语言记忆（Rolling Language Memory）**：
  - 记忆以结构化自然语言表示，包含：已完成阶段、完成证据、对象属性、观测失败、下一步待办里程碑；
  - 遵循**滚动压缩规则**：子任务未完成时保留详细目标信息（类别、颜色、位置），完成后压缩为简短过去式陈述，注意力转向下一步；
  - 记忆仅在观测提供当前里程碑已变更的证据时更新，保持记忆有界。
- **自动化监督管线**：
  - 输入：专家视频、技能级标注（技能名称、描述、起止时间戳）；
  - 通用VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B）对当前帧生成两类目标：①简洁子任务（动作+目标对象+上下文，无主语）；②第一人称语言记忆（已完成技能用过去式、下一步用将来式）；
  - 输出帧对齐的 (m_t, s_t) 对作为高层策略监督目标。
- **独立分支训练**：
  - 高层：PaliGemma（3B VLM），自回归训练，联合预测记忆和子任务；
  - 低层：遵循π0.5动作专家架构，采用流匹配动作目标，300M参数Gemma动作专家全量微调；
  - 两分支独立训练，避免单一大目标中语义损失与控制损失的人工权重调节。
- **闭环推理流程**：
  - 初始化 m₀ = ∅；
  - 循环：获取观测 → 高层更新 (m_t, s_t) → 低层生成动作块 → 执行 → 高层判断是否终止。

## 6. 主要结论与发现

1. **显式语言记忆提升阶段成功率**：
   - BEHAVIOR-1K 收音机任务：平均成功率 30.0% → **40.0%**（PickUp由10%→30%，PressOn由0%→10%，PlaceOn由10%→20%）；
   - Genie Sim 3.0 单包分拣：41.7% → **63.9%**（Follow和PickUp-1翻倍，Inside-1由50%→83.3%）；
   - Genie Sim 3.0 连续分拣：31.3% → **46.9%**（baseline从未到达第3/4次放置，记忆模型达12.5%完成全部4次）；
   - 真实拾取放置：62.5% → **66.3%**（提升较小，与任务阶段少一致）。
2. **阶段一致性改善**：记忆使阶段推进取决于观测到的完成证据，减少跳步和提前推进；
3. **可解释性**：记忆和子任务均为可见文本，可对齐动作失败进行诊断；
4. **上下文内失败恢复**：记忆能记录"物体未抓牢"，引导重新尝试抓取，无需专门恢复控制器；
5. **边界明确**：语言记忆解决"做什么/处于哪个阶段"，不直接改善接触密集动作的"怎么做"（如PressOn成功率仍低）。

## 7. 优点

- **层次化解耦设计**：高层语义规划与低层动作生成独立优化，避免统一目标中的损失权衡问题；
- **显式语言记忆**：具有可解释、紧凑、有监督的表示，记忆输出可直接用于人机交互与故障分析；
- **自动化标注管线**：将专家视频+技能时间戳自动转化为记忆/子任务监督目标，降低人工标注成本；
- **滚动压缩机制**：平衡记忆信息量与上下文长度，无需拼接全部历史帧，避免上下文和算力随任务时长线性增长；
- **多场景验证**：覆盖家庭仿真、人类机器人仿真和真实低成本机器人，验证了方法的泛化性；
- **诊断能力**：可区分高层语义错误与低层控制错误，便于定位失败原因。

## 8. 不足与局限

- **真实实验覆盖有限**：仅短时程拾取放置任务，25条训练轨迹、20次评估，无法验证分钟级真实多对象场景；
- **统计充分性不足**：未报告不同随机种子下结果的方差或置信区间，改进的可靠性有待验证；
- **计算开销增加**：每次决策需要额外的高层VLM调用，增加端到端延迟和部署复杂度；
- **无法补偿低层控制缺陷**：语言记忆对接触丰富型动作（如按钮按压）的几何对齐、力度控制无能为力，PressOn低成功率即为此局限；
- **失败恢复依赖数据**：可靠的错误恢复需要覆盖抓取偏移、碰撞、目标丢失等多样化失败-纠正轨迹，当前演示数据不足；
- **单骨干方案未验证**：未来统一骨干同时生成记忆、子任务和动作尚需平衡语言与控制目标；
- **模态局限**：当前仅语言+视觉，触觉与力反馈的缺失使某些接触状态在图像中难以区分。
