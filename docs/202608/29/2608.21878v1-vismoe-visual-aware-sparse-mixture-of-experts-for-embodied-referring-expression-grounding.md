## 摘要
具身指代表达定位是一项任务，旨在使智能体能够在真实环境中导航，并根据自然语言指令定位远处的目标物体。在此场景中，智能体需要在每一步选择一个视角进行导航，并在目的地从所有候选物体中识别出特定物体。然而，以往的大多数方法未能区分视角和物体，而是使用普通的视觉编码器对它们进行处理，导致视角和物体的表示模糊不清。为了解决上述问题，我们提出了ViSMoE，它为具身智能体配备了具有视觉感知路由策略的稀疏混合专家模型。该框架专门处理不同类型的视觉信息，从而为视角和物体生成具有区分性的视觉表示。在REVERIE和SOON数据集上的实验结果表明，ViSMoE优于以往的最先进方法，显示出我们提出方法的优越性。

## Abstract
Embodied Referring Expression Grounding is the task of enabling an agent to navigate in real environments and to localize a remote object based on natural language instructions. In this scenario, the agent needs to select one view for navigation at each step and identify a specific object among all candidate objects at the destination. However, most of the previous approaches fail to distinguish between views and objects, instead processing them using the vanilla vision encoder, which results in ambiguous representations of both views and objects. To address the above issues, we propose ViSMoE, which equips sparse Mixture-of-Experts with a visual-aware routing policy for the embodied agent. This framework processes different types of visual information specifically, resulting in discriminative visual representations for both views and objects. Experimental results on REVERIE and SOON datasets demonstrate that ViSMoE outperforms the previous state-of-the-art methods, showing the superiority of our proposed method.

## 2. 论文提出的方法论

- **核心思想**：利用稀疏混合专家（SMoE）的“分而治之”能力，对不同视觉类型（视图 vs. 物体）进行专门化处理；并引入视觉感知路由策略，使路由器能够根据输入类型选择相应专家，从而生成分布更具判别性的视觉表示。
- **整体流程**：
  - 语言编码：使用多层 Transformer 编码指令得到上下文语言表示。
  - 视觉编码：视图和物体分别附加角度特征、边界框特征和导航类型嵌入（ `nV` 和 `nO` ），再通过全景编码器得到上下文视觉表示。
  - 跨模态编码：采用双尺度（局部/全局）跨模态 Transformer，分别对视觉特征与语言表示进行交叉注意力建模，用于导航和物体定位。
- **关键设计——视觉感知稀疏混合专家（ViSMoE）**：
  - 将原本的稠密 FFN 替换为 SMoE 层。
  - SMoE 层包含 N 个专家（FFN）和一个门控网络。路由计算为：
    - 原始路由： `G(x) = top-k(softmax(Wg · x))`
    - 视觉感知路由： `G(x) = top-k(softmax(Wg · (x + bt)))`，其中 `bt` 是类型嵌入（视图类型 `bv` 或物体类型 `bo`）。
  - 输出为被选中的 k 个专家结果的加权和。
- **辅助损失**：引入负载均衡损失（Load-Balancing Loss），防止路由不平衡，公式为 `LAux = α * N * Σ(p_i * f_i)`，α 设为 0.001。
- **训练与推理**：
  - 预训练任务：掩码语言建模（MLM）、掩码区域分类（MRC）、单步动作预测（SAP）和物体定位（OG）。
  - 微调阶段：除 SAP 外，使用 DAgger 算法训练导航策略，并结合物体定位损失。
  - 总损失 = 各任务损失 + 辅助负载均衡损失。

- **专家数量与 top-k 的影响**：专家数设置为 4、top-k=2 时性能最优；过多专家（16）或过大 top-k 提升有限或出现性能下降，且计算开销增加。

- **任务复杂性相关性**：SOON 数据集上 RGSPL 的提升更大，说明在视觉和语言复杂度更高、候选物体更多的场景中，ViSMoE 的收益更明显。
