## 摘要
视觉-语言-动作（VLA）模型作为一种可扩展的机器人操作方法，已引起越来越多的关注。尽管这些模型是有效的动作预测器，但将它们部署为机器人智能体时暴露出关键差距：缺乏故障恢复机制、在长时间跨度上执行不一致，以及对观测、任务或本体变化的鲁棒性有限。现有解决方案通过模型重训练或特定环境模块分别解决这些局限性，但我们需要的是一个通用框架，能够系统性地将预训练的VLA转化为机器人智能体。我们提出了RoboBRIDGE，一个模块化框架，它在五个协调模块（即监视器、感知器、规划器、控制器和机器人接口）之上提供一个编排层，通过现成组件（包括预训练的VLA）来组合稳健的机器人智能体。监视器将快速故障检测与分层恢复相结合，在错误级联之前进行纠正。当环境偏离当前计划时，规划器触发重新规划，而感知器异步更新场景理解，避免执行停滞。在控制器内部，基元技能微调通过专门的LoRA适配器将操作分解为域不变基元，从而在使用VLA时降低对域偏移的敏感性。在跨越多个机器人平台和VLA骨干的LIBERO、RoboCasa以及真实世界案例研究中，RoboBRIDGE始终优于独立策略和先前增强的VLA部署。这些结果表明，可靠的机器人智能体不仅来自扩展动作预测器，还源于围绕它们的结构化编排。

## Abstract
Vision-Language-Action (VLA) models have attracted growing interest as a scalable approach to robotic manipulation. While these models are effective action predictors, deploying them as robotic agents exposes critical gaps: no mechanism for failure recovery, inconsistent execution over long horizons, and limited robustness to shifts in observations, tasks, or embodiments. Existing solutions address these limitations individually through model retraining or environment-specific modules, yet what is needed is a general framework that systematically transforms a pretrained VLA into a robotic agent. We present RoboBRIDGE, a modular framework that provides an orchestration layer over five coordinated modules, namely Monitor, Perceptor, Planner, Controller, and Robot Interface, to compose robust robotic agents from off-the-shelf components, including pretrained VLAs. The Monitor pairs rapid failure detection with hierarchical recovery to correct errors before they cascade. When the environment diverges from the current plan, the Planner triggers replanning while the Perceptor updates scene understanding asynchronously, avoiding execution stalls. Within the Controller, primitive skill fine-tuning factors manipulation into domain-invariant primitives with dedicated LoRA adapters, reducing sensitivity to domain shifts when a VLA is used. Across LIBERO, RoboCasa, and real-world case studies spanning multiple robot platforms and VLA backbones, RoboBRIDGE consistently outperforms both standalone policies and prior augmented VLA deployments. These results suggest that reliable robotic agency does not arise from scaling action predictors alone, but from structured orchestration around them.

### 2. 方法论：核心思想、关键技术细节

**核心思想：**
RoboBRIDGE是一个模块化、可泛化的编排框架，通过五个协调模块（Monitor、Perceptor、Planner、Controller、Robot Interface）将任意动作生成策略（包括但不限于VLA）转化为稳健的机器人智能体。框架保留基础模型学到的操作能力，同时在推理时补充故障恢复、长程一致性和域鲁棒性，无需重训练基础模型。

**五大模块：**

- **Perceptor（感知器）**：将原始感官观测转换为对象中心状态（目标身份、3D位姿、语义属性如可操作性等）。
- **Planner（规划器）**：接收精炼状态和语言指令，将任务分解为有序的基元技能序列（如MOVE、GRIP、ROTATE），并由附加上下文参数化。
- **Controller（控制器）**：作为动作生成策略的插槽，将每个基元翻译为低级动作。
- **Robot Interface（机器人接口）**：抽象特定本体的API、时序、安全限制和坐标变换，使同一上游逻辑可跨机器人和仿真器运行。
- **Monitor（监视器）**：通过验证执行结果并触发分层恢复来闭环系统。

**核心机制一：两阶段监控与分层恢复（Two-phase Monitoring）**
- **阶段1——轻量级成功检查**：使用视觉-语言模型 `D_check` 周期性评估当前观测与预期计划上下文，输出二元成功标志和置信度。采用约束输出格式抑制冗长推理，保证约5Hz的低延迟，不阻塞控制回路。
- **阶段2——失败诊断与恢复**：当检测到高置信度失败时（`suc=false` 且 `conf ≥ γ_thresh`），立即停止机器人，调用诊断模型 `D_diag` 推断根因并选择恢复目标。恢复策略分为四个层级，按重新计算范围递增：
  1. **重试（retry）**：重新执行当前基元；
  2. **重新生成（regenerate）**：保留当前计划和感知状态，重新生成轨迹；
  3. **重规划（replan）**：利用最新异步感知结果重新规划；
  4. **重新感知（re-perceive）**：先强制完整重新感知，再重新规划（对象状态不可靠时）。

**核心机制二：异步感知的反应式规划（Reactive Planning with Asynchronous Perception）**
- 采用**生产者-消费者异步架构**：感知线程连续更新线程安全的缓冲区B（仅存最新检测结果），执行线程按序运行基元；感知延迟被隐藏在正常执行期间。
- 每个基元完成后，执行线程比较用于当前计划的感知结果与缓冲区中的最新感知结果，计算**发散度量**：
  - `Δ(o_a, o_b) = max_i∈O_a∩O_b ||p_a(i) - p_b(i)||₂ + λ · |O_a △ O_b|`（目标3D位置最大位移 + 出现/消失对象数量加权）。
- 当 `Δ ≥ τ` 时触发重规划：**保留高层动作序列**（如PICK → PLACE），仅重新生成当前及后续基元技能以反映最新状态，避免冗余的高层推理。

**核心机制三：基元技能微调（Primitive Skill Fine-tuning）**
- 将操作分解为领域不变基元集合 `P = {MOVE, GRIP, ROTATE, ...}`，每个基元配备专门的LoRA适配器，而非用单一权重集处理所有操作阶段。
- 冻结VLA骨干 `f_θ`，为每个基元训练轻量级LoRA模块 `Δθ_k`，条件输入包含指令、当前观测/机器人状态和基元标签。
- **控制器切换**：采用两层级解析器（Eq. 6）——可用时选择对应基元的适配器，否则使用所有注册LoRA适配器的均值回退。LoRA切换在位完成，不重新加载骨干。
- 动作生成预测7自由度增量动作 `a_t = (δx, δφ, g)`；执行时若IK可用则转为绝对目标求解关节位置，否则回退到笛卡尔速度控制，实现跨不同运动学接口的通用部署。

**算法流程（Algorithm 1）**：重置环境 → 初始感知 → 规划 → 启动异步感知线程 → 对每个基元循环：解析适配器 → 执行控制器推断 → 环境步进 → 轻量级失败检查 → 失败则停止、诊断、分层恢复 → 基元完成后检查感知发散 → 发散则重规划。

### 6. 主要结论与发现

1. **框架有效性**：RoboBRIDGE在LIBERO和RoboCasa上对所有VLA骨干均带来一致的性能提升——RoboCasa平均成功率从3.4-4.2%提升至5.9-9.8%（排除PnP任务后从5.1-7.4%提升至8.8-14.7%），LIBERO从35.5%提升至39.7%。
2. **监控与规划缺一不可**：LLM骨干消融实验显示，仅靠规划（无监控）所有骨干性能在1.8-8.0%的窄范围内；启用监控后，具有较强推理能力的骨干（Claude Opus 4.6、GPT-5 mini）获得显著增益，小型模型增益微弱。**规划和监控都是必要条件，且其联合收益随骨干诊断能力扩展**。
3. **框架策略无关**：全量微调（31.9% → 40.0%）和经典IK控制器（22.1%）同样受益，验证了框架级别的监控和重规划对强控制器也有增益，且框架设计不局限于学习策略。
4. **LoRA基元微调高效**：LoRA微调 + RoboBRIDGE（27.1%）接近独立全量微调（31.9%）但参数更新量远少；而模型内部自我纠正（CycleVLA，7.5%）不如外部编排有效。
5. **可靠机器人智能体来自结构化编排**：核心结论是可靠智能化不是仅靠扩展动作预测器规模，而是来自围绕动作预测器的结构化编排。

### 7. 优点

- **模块化编排设计**：五大模块分工明确、接口清晰、策略无关，允许现成组件自由组合，与LLM智能体框架的发展路径对齐。
- **分层恢复效率高**：两阶段监控降低了全量诊断的延迟开销，四级恢复策略（重试→重新生成→重规划→重新感知）在最经济的代价下解决失败。
- **异步感知避免执行停滞**：将感知延迟隐藏在正常执行期间，只在实质发散时触发重规划；发散度量计算仅涉及欧氏距离和集合操作，开销可忽略。
- **LoRA基元微调兼顾效率与性能**：将操作分解为领域不变基元并配以专用适配器，减少跨操作阶段的干扰，参数效率远超全量微调，还支持多策略混用。
- **系统性的消融设计**：分别验证LLM骨干选择、监控模块、控制器类型和微调策略的影响，逻辑清晰。
- **双路径执行策略**：IK可用时转换绝对目标求解关节位置，否则回退笛卡尔速度，提升跨平台兼容性。
- **真实世界+仿真双验证**：包含实际机器人部署案例，演示了训练环境和未见环境下的迁移能力。

### 8. 不足与局限

- **实验覆盖限制**：
  - 真实世界部分仅以定性案例呈现，缺少系统化的严格定量实验（成功率统计、多次重复、统计显著性检验）。
  - 实验中成功率数值波动较大（如RoboCasa中很多任务为0%），提升集中在少数任务类型上；许多任务即使有框架支持仍然完全失败（如PnP类任务几乎无改进）。
  - 未在LIBERO上使用SmolVLA和π0.5骨干，交叉验证不完整。
- **基元词表覆盖有限**：当前基元技能覆盖单臂桌面行为，但接触丰富的交互（contact-rich）、可变形物体、双臂任务需要更丰富的基元和状态表示。
- **超参手动设置**：监控阈值（γ、τ）、恢复规则均为手动设定，缺乏从交互数据中学习的机制。
- **感知瓶颈**：论文识别的两类主要失败模式之一是感知错误（遮挡和相似物体导致的误识别/错误定位），框架无法解决底层感知模型的能力上限。
- **不可恢复失败**：接触丰富交互中的不可逆环境改变使重试失效，现有框架缺少前瞻性可行性验证（prospective feasibility check）、替代策略选择和可校准的停止准则。
- **本体泛化有限**：论文声称RoboBRIDGE支持跨本体迁移，但真实实验仅涉及Franka和UR7e两种机械臂，跨本体泛化结论的证据基础较为薄弱。
- **基准难度不对称**：Robo-Casa基线的成功率极低（3-4%），提升空间大，框架增益是否能在更强基线上保持需进一步验证；LIBERO上增益较小也说明框架对于基础能力较强的策略增值有限。
- **规模和普适性**：由同一研究团队开发，缺少来自独立第三方在不同任务、不同骨干上的复现验证。
