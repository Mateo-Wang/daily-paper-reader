## 摘要
视觉-语言-动作（VLA）模型将视觉观察编码为扁平的二维补丁令牌，这些令牌不携带内在的几何结构，而通过密集单目深度信息注入的逐像素标量值既不能编码表面方向，也不能编码几何置信度。这使得策略在动作预测中缺乏结构化的空间推理能力。我们提出了GaussVLA，一个基于Mamba的VLA模型，它包含两个自定义模块：高斯空间分词器（GST），用于将冻结的语义特征和深度特征提升为紧凑的三维高斯令牌，并通过学习的查询池化几何显著区域；以及深度感知思维链（DA-CoT），在语言和流时间条件下执行结构化的非自回归几何推理。在仿真和真实世界评估中，GaussVLA展现了强大的空间操作性能，同时保持了参数效率。在LIBERO上，它仅用200M参数就实现了93.5%的平均成功率和100%的空间套件成功率，相对于SpatialVLA，平均相对成功率提高了19.7%，同时参数效率显著更高。

## Abstract
Vision-Language-Action (VLA) models encode visual observations as flat 2D patch tokens that carry no intrinsic geometric structure, and augmenting them with dense monocular depth injects per-pixel scalar values that encode neither surface orientation nor geometric confidence. This leaves the policy with limited structured spatial reasoning for action prediction. We propose GaussVLA, a Mamba-based VLA that incorporates two custom modules: Gaussian Spatial Tokenizer (GST) to lift frozen semantic and depth features into compact 3D Gaussian tokens, pools geometrically salient regions with learned queries, and \emph{Depth-Aware Chain-of-Thought (DA-CoT)} that performs structured, non-autoregressive geometric reasoning under language and flow-time conditioning. Across both simulation and real-world evaluations, GaussVLA demonstrates strong spatial-manipulation performance while remaining parameter-efficient. On LIBERO, it achieves 93.5% average success and 100.0% success on the Spatial suite with only 200M parameters, improving over SpatialVLA by 19.7% relative average success while remaining significantly more parameter-efficient.

## 1. 核心问题与整体含义

- **研究动机**：现有视觉-语言-动作（VLA）模型通常将 RGB 视觉观察编码为扁平的 2D patch token，这些 token 缺乏显式度量 3D 几何结构，导致策略难以进行精确的空间推理。
- **现有方案的不足**：虽然一些工作通过注入单目深度来增强空间信息，但深度通常被建模为逐像素标量，既不能表示表面朝向，也不能表达深度估计的置信度；同时，基于 2D 图像的链式思维（CoT）推理存在自回归延迟，并与动作解码脱节。
- **整体含义**：本文提出 GaussVLA，通过将视觉信息提升为紧凑的 3D 高斯 token 并引入深度感知的结构化推理，使策略在保持参数高效的同时显著增强空间操作能力。在 LIBERO 基准上，仅用 200M 参数即达到 93.5% 的平均成功率，空间套件达 100%。

## 2. 方法论

**核心思想**：  
GaussVLA 由四个部分组成：双流冻结视觉编码器、高斯空间分词器（GST）、深度感知链式思维（DA-CoT）以及基于 Mamba 的流匹配动作解码器。

**双流视觉编码**：
- 语义流：冻结 SigLIP-SO400M/14 提取 patch 特征 \(F \in R^{P \times d_s}\)。
- 深度流：冻结 Depth-Anything-V2 估计深度，并在 patch 中心采样，得到对齐的深度值 \(d\)。

**高斯空间分词器（GST）**：
- 对深度进行可学习仿射校正：\(\tilde{d} = \lambda_d d + \beta_d\)。
- 通过相机内参反投影得到 3D 坐标：\(c = \tilde{d} K^{-1} u\)。
- 用参数头预测残差均值偏移、log 尺度向量和置信度 \(\alpha\)。
- 构造 Gaussian 均值 \(\mu = c + \rho \tanh(\Delta \mu)\) 和协方差尺度 \(\sigma = \exp(\eta)\)。
- 对 \(\mu\) 施加 3D Fourier 位置编码，并与语义特征、\(\eta\) 拼接形成几何感知 token。
- 通过空间注意力池化（带 opacity 置信度偏置）输出紧凑的 3D Gaussian token 集合 \(Z_{GST}\)。

**深度感知链式思维（DA-CoT）**：
- 将 GST token 展平并与语言嵌入、flow-time 嵌入拼接为上下文 \(C_\tau\)。
- 使用少量可学习查询（\(N_r=4\)）进行自注意力、交叉注意力和前馈更新，得到结构化推理 token \(R_\tau\)。
- 该过程是非自回归的，且与动作预测目标联合训练，避免了传统文本 CoT 的推理延迟。

**动作生成**：
- 将时间、语言、GST、DA-CoT 和动作状态 token 拼接后送入 Mamba 骨干网络。
- 动作解码器对 action token 进行 refine，最终由速度头预测条件速度场 \(v_\theta\)，通过流匹配生成动作序列。

**训练目标**：
- 总损失：\(L = L_{FM} + L_{GST} + L_{CoT}\)。
- \(L_{FM}\)：流匹配损失，监督速度场。
- \(L_{GST}\)：opacity 加权的深度重建损失，保证 3D 几何一致性。
- \(L_{CoT}\)：用 DA-CoT token 的均值辅助预测目标速度，提供推理监督。
