## 摘要
图像目标视觉导航是具身智能体的基本能力。现有导航策略能高效预测航点轨迹，但缺乏视觉预见能力；而导航世界模型可以预测未来观测，但往往需要昂贵的规划 rollout。我们提出 UniNav，一个统一的世界-动作模型，通过单一的扩散过程生成未来视觉观测和连续航点轨迹。给定历史帧和目标图像，UniNav 在单个 transformer 内联合去噪视觉和航点 token，在共享框架中统一未来预测和动作生成。为了改进空间 grounding，我们融入了几何感知的相机 token。我们还在带轨迹标注的导航数据和纯视频数据上训练模型，使模型能够从无航点标注的多样视频中获益。基于这一统一框架，我们引入了两个变体：UniNav-Full 联合预测可解释的未来观测及其对应轨迹，而 UniNav-Fast 在推理时移除未来图像 token 以实现高效轨迹预测。在导航基准上的实验表明，UniNav 在所有数据集上的 ATE 均优于最强基线。通过一步推理，UniNav-Fast 实现 0.1 秒的延迟，且精度没有显著下降。代码将公开。

## Abstract
Image-goal visual navigation is a fundamental capability for embodied agents. Existing navigation policies efficiently predict waypoint trajectories but lack visual foresight, while navigation world models can anticipate future observations but often require costly planning rollouts. We present UniNav, a unified world-action model that generates future visual observations and continuous waypoint trajectories through a single diffusion process. Given history frames and a goal image, UniNav jointly denoises visual and waypoint tokens within a single transformer, unifying future prediction and action generation in a shared framework. To improve spatial grounding, we incorporate geometry-aware camera tokens. We also train on both trajectory-labeled navigation data and video-only data, enabling the model to benefit from diverse videos without waypoint annotations. Based on this unified framework, we introduce two variants: UniNav-Full jointly predicts interpretable future observations and their corresponding trajectories, while UniNav-Fast removes future-image tokens at inference for efficient trajectory prediction. Experiments on navigation benchmarks show that UniNav outperforms the strongest baseline in ATE across all datasets. With one-step inference, UniNav-Fast achieves a latency of 0.1s without a substantial accuracy drop. Code will be released.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：图像目标视觉导航要求智能体根据第一视角观测到达指定目标，是具身智能的基础能力。
- **现有方法的矛盾**：
  - **策略模型**（如 GNM、ViNT、NoMaD）能高效预测局部航点轨迹，但缺乏对未来视觉状态的显式建模，可解释性差，也无法对未见场景进行推理。
  - **导航世界模型**（如 NWM）能生成未来观测的 rollout，但采用“先生成后评估”的规划范式，每个候选轨迹都需要独立 rollout，计算开销极高，难以实时闭环控制。
- **核心问题**：如何在一个统一框架中同时获得**可解释的视觉预见**与**高效的航点预测**，避免两者的割裂和高额规划成本。
- **总体含义**：UniNav 提出将未来视觉观测、连续航点轨迹以及相机几何信息统一在一个扩散生成过程中，从而实现“既是世界模型又是策略模型”的导航范式，兼顾可解释性与实时性。

## 2. 方法论：核心思想、关键技术细节与公式

### 核心思想
- 将导航建模为**联合扩散过程**：给定历史帧与目标图像，同时去噪未来视频潜变量、航点轨迹 token 和相机几何 token。
- 基于预训练视频扩散模型 **Wan2.1-1.3B** 进行微调，利用其强大的视觉先验。
- 采用 **flow matching**（流匹配）目标统一优化多个模态。

### 关键技术细节

#### 异构 Token 序列
- **视觉 token**：历史帧、未来帧、目标图像由冻结的 VAE 编码并 patch 化为时空潜变量 token。
- **航点 token**：每个未来时间步的局部航点 \(a_k = (\Delta x, \Delta y, \Delta \psi)\) 经噪声扰动后通过 MLP 投影到 transformer 隐空间。
- **相机 token**：使用冻结的几何基础模型（如 Depth Anything 3）从历史和未来帧中提取归一化的相机感知 token，作为几何监督信号。
- **历史/目标 token**：提供条件信息。
- **寄存器 token**：用于全局信息交换，所有非视觉 token 使用恒等位置编码，避免人为空间坐标干扰。

#### 统一目标函数
对每个模态 \(m \in \{\text{vid}, \text{traj}, \text{cam}\}\)：
\[
z_m = (1-\sigma_m)x_m + \sigma_m\epsilon_m, \quad u_m = \epsilon_m - x_m
\]
模型预测速度场 \(v_\theta\)，损失为：
\[
\mathcal{L} = \lambda_{\text{vid}} m_{\text{vid}} \mathcal{L}_{\text{vid}} + \lambda_{\text{traj}} m_{\text{traj}} \mathcal{L}_{\text{traj}} + \lambda_{\text{cam}} m_{\text{cam}} \mathcal{L}_{\text{cam}}
\]
- \(\mathcal{L}_{\text{vid}}\)：视频潜变量速度的 L2 损失
- \(\mathcal{L}_{\text{traj}}\)：航点轨迹速度的 SmoothL1 损失
- \(\mathcal{L}_{\text{cam}}\)：相机 token 速度的 L2 损失
- \(m_{\cdot}\) 表示该模态监督是否可用，从而支持**混合数据训练**（轨迹标注数据 + 纯视频数据）。

#### 双变体设计
- **UniNav-Full**：训练和推理时同时去噪未来视频 token、航点 token 和相机 token，输出可解释的未来帧和轨迹。
- **UniNav-Fast**：训练时使用完整序列但采用**不对称注意力掩码**，使其他 token 不依赖未来视频 token；推理时移除未来图像 token，直接采样航点，避免视频解码，显著降低延迟。

## 7. 优点

- **统一框架**：首次将未来视觉预测、连续航点预测和相机几何信息整合在单一扩散 transformer 中，避免了两阶段规划的昂贵 rollout。
- **几何感知**：引入冻结几何模型提取相机 token，以辅助目标的方式注入 3D 结构先验，不增加推理负担。
- **数据利用高效**：支持混合数据训练，可挖掘大规模无标注视频的价值。
- **推理灵活**：Full 变体提供可解释的视觉未来；Fast 变体用不对称注意力解耦未来图像 token，实现低延迟在线部署。
- **基于强预训练**：利用 Wan2.1-1.3B 视频扩散模型，降低训练成本并提升视觉泛化能力。
