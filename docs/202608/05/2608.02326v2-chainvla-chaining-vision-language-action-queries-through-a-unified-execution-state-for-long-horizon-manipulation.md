## 摘要
人类通过保留先前动作所建立的知识，同时不断调整进行中的动作，来执行长时程操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入反复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作复用和集成保留短期运动，导致跨查询交接不完整。我们提出了ChainVLA，一个1.2B参数的VLA策略，通过一个联合且可修订的执行状态链接连续的查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带由观察得出的任务进度；而运动尾则将先前预测中未执行的延续部分输入到状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作视界，使得携带的状态能够指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些非对称消融实验与运动连续性有助于保留推断任务进度所依赖的观察流这一结论一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 一、核心问题与整体含义（研究动机与背景）

长时程操作（long-horizon manipulation）要求机器人既能够记住先前动作已完成的任务进展，又能持续调整当前运动。然而，当前主流的动作分块（action-chunked）VLA 策略存在 **跨查询状态交接不完整** 的关键问题，具体表现为两个层面：

- **任务层面（Task-level）**：在每个查询边界，先前查询中已确定的某些任务证据可能已不可逆地离开当前视野（如 RMBench 的 Put Back Block 任务，同一观察与指令可能对应不同历史），导致后续决策产生歧义。
- **运动层面（Motion-level）**：重新规划时，上一条预测中未执行完的后缀（unexecuted suffix）被直接丢弃，新预测前缀与所替代的运动之间可能不连续，尤其在当前位姿看似相似时。

现有方法分别处理这两个问题：记忆增强策略（MemoryVLA、MemER、EventVLA 等）保留观测衍生的长期任务证据，时序集成、实时执行等策略保留短期运动；但二者分属两条互不相交的解决路线，无法在**同一状态更新机制**内同时覆盖。此外，两个层面存在耦合关系：跨查询的运动连续性会影响机器人访问的观测流，进而影响任务进度的估计。论文的核心问题可凝练为：

> **如何让 VLA 策略在保留跨查询任务进度与运动连续性的同时，让每次新预测仍响应最新观测？**

## 二、方法论

### 2.1 核心思想

ChainVLA 提出了 **联合可修订执行状态（joint, revisable execution state）** 的概念，将每次查询的输入从 `xk = (ok, rk, ℓ)` 扩展为条件化历史依赖的生成：

$$\Pi_\theta (\cdot | x_k, s_k) \approx \Pi^*(\cdot | H_k), \quad s_{k+1} = F_\theta(s_k, x_k)$$

其中 $s_k = (g_k, u_k)$ 由两部分组成：
- **Progress Context $g_k$**：观测衍生的任务进度（回顾性信号），由循环工作状态与稀疏事件记忆融合得到；
- **Motion Tail $u_k$**：上一条预测中未执行的后缀（前瞻性信号），直接跨边界传递。

总的查询转移为：$(A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k), \quad u_{k+1} = \text{Tail}(A_k)$

### 2.2 Progress Context：携带任务进度

- **循环工作状态（Working State）**：以 8 个可学习的工作查询对当前多模态 token 进行交叉注意力，并结合上一时刻的实时 token 进行循环更新，形成“实时 token + 有界缓存”的递归结构。工作状态每查询更新一次，提供当前执行阶段的高频表征。
- **稀疏事件记忆（Sparse Event Memory）**：容量 16 条记录，存储视觉特征、阶段信息与时间特征三元组。写入策略在阶段标注数据上由预测阶段转换触发（置信度阈值 0.55），在无标注数据上按固定间隔（每 3 查询）写入。检索时使用年龄感知的余弦相似度评分，同时保留首个事件作为锚点（anchor），实现对早期关键证据的可检索访问。

### 2.3 Motion Tail：携带未完成运动

- **模型侧路径一**：将未执行后缀编码为尾 token（4 tokens），输入工作状态构建过程，影响下一查询的状态构造。
- **模型侧路径二**：将未执行后缀与全视界动作表征对齐，作为解码器的条件初始化：

$$\tilde{A}^{(0)}_{k+1} \mid u_{k+1} \sim \mathcal{N}(\mu_{k+1}, \sigma_u^2 I)$$

即新视界的初始状态以上一预测的尾部为均值，叠加有限噪声，而非重新随机采样。解码器仍会在最新观测下**重新生成每一个视界位置**，确保承载状态是“可修订的先验”而非“固定计划”。

### 2.4 训练策略

训练按 episode 查询顺序展开。每次查询更新工作状态、检索进度上下文、预测动作视界、条件写入事件，并将**脱离梯度**的尾后缀传给下一查询。总损失包括：
- 条件流动作目标（conditional-flow action objective）；
- 阶段监督（stage supervision，仅在存在阶段标注时）；
- 重叠一致性正则化（overlap-consistency regularizer，权重 0.2），用于鼓励前后查询在手势交接处的一致。

## 六、主要结论与发现

1. **完整 ChainVLA 在 RMBench 达 62.8%**（1.2B 参数），高于最强完整覆盖对比方法 Mem-0（52.8%，8B+2B 参数），且在每个任务上均进入前两名；Put Back Block 达到 96%，远超 MemoryVLA 的 50%。
2. **LIBERO 四套件平均 98.8%**，每套件均高于 98%，但论文指出 LIBERO 已接近天花板，用于验证广度而非区分度。
3. **非对称消融**：移除 Motion Tail 后 RMBench 降至 11.2%，移除 Progress Context 后降至 3.0%，移除两者仅剩 1.6%，说明“两部分之和远大于各自贡献”，且两者不是互为独立的改进。
4. **部分消融的插值行为**：减少 Progress Context 中的单一输入（如 w/o Event Readout 使 Put Back Block 从 96 降至 25）代价远小于整体移除；轨迹初始化是 Motion Tail 中更关键的通道（38.0 vs 52.0）。
5. **运动连续性支持任务进度推断**：w/o Motion Tail 的边界位置不连续可达 17.32 mm（匹配场景示例），全量池化降低 56.6%（CDp）/40.4%（CDR）/57.4%（B2）/43.1%（RMSE3），同时成功率从 62.8% 骤降至 11.2%，排除了简单“运动平滑是独立目标”的替代解释。
6. **后解码平滑不构成替代方案**：Linear Continuation 在边界指标上比 Full 更光滑，但成功率仅 0–2%，证明“在解码后平滑”无法替代“在解码前把未完成延续注入状态生成”。

## 七、优点

- **问题定位精准**：以严格的数学形式（决策不足判据）刻画了跨查询交接不完整的本质，区分了“观测不足”（任务进度缺失）与“预测不足”（运动延续缺失）两类互补问题。
- **统一状态设计优雅**：将记忆（任务进度）与平滑（运动延续）二者融合在一个可修订的执行状态内，既保留记忆的时间跨度，又能让新观测随时改写携带状态。
- **消融实验设计细致**：不仅做整体移除，还分别移除各子路径（Live Tokens、Event Readout、Tail Tokens、Traj. Init.），并设置 “FIFO+TE” 替代控制，排除了“观测历史+时序集成”即可逼近性能的替代假设。
- **诊断指标丰富且谨慎**：提出四个边界度量，明确其为“诊断指标”而非“优化目标”，并指出它们不测量物理平滑度或累积偏差，避免了指标被过度解读。
- **非对称消融的因果链条推理**：巧妙利用配对场景 rollout + 边界统计与成功率下降的对齐，论证了运动连续性对任务进度推断起保护作用，形成完整的故事线。

## 八、不足与局限

- **实验场景限制**：仅在固定频率仿真（RMBench、LIBERO）中验证，未进行硬件部署或异步环境测试；边界度量描述的是“命令流”而非物理轨迹，在真实执行中的泛化需谨慎判断。
- **统计效力不足**：单随机种子、无多次重复与显著性检验；论文明确提醒不应将结果视为异步/实时部署的预测。
- **外部可比性弱**：对比方法的数值来自各自原始论文，未使用本文统一协议重跑，演示数量、骨干网络、成功率判定标准可能差异明显。
- **干预结论为关联性而非因果性**：配对场景暴露的是 Full 与 w/o Motion Tail 之间的关联关系，论文承认无法从这些度量中断言严格的因果链条。
- **固定超参数无敏感性分析**：记忆容量 16、写入置信度阈值 0.55、写入间隔 3 查询、重叠一致性权重 0.2 等均一次性固定，未测试其敏感范围；训练时尾条件以 0.5 概率随机掩蔽，这些设计选择对结果稳健性的影响未知。
- **阶段标注依赖**：RMBench 上的训练使用了阶段级 ground-truth 写入目标（尽管未进入动作解码器），在无阶段标注的真实环境中，事件记忆的质量可能下降；论文以固定 3 查询写入的方式（53.4%）部分缓解了这一顾虑，但仍不能完全复现标注条件下的优势。
