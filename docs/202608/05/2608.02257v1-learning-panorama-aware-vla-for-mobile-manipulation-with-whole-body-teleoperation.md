## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身演示的高效采集需要对移动底座和机械臂进行协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR界面实现对轮式双臂机器人的协调控制，并支持采集包含5.5小时多模态演示的真实世界移动操作数据集。基于该数据集，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。PanoVLA基于混合Transformer架构，通过专用的全景编码和融合模块引入全局空间上下文，使全景观测能够与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA的平均阶段完成率达91.3\%，端到端成功率达73.4\%，显著优于局部视角基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

### 2. 论文提出的方法论

#### 核心思想
构建**数据侧**与**模型侧**双轮驱动的统一框架：以全身遥操作系统解决高质量数据稀缺问题，以全景感知VLA模型解决局部视野受限问题。

#### 关键技术一：GMR全身遥操作系统
- **硬件配置**：操作者佩戴VR头显（6-DoF头部追踪）+ 双手柄（手部姿态+夹爪指令）+ 三个身体追踪器（腰部+双脚踝），构成稀疏人体运动捕捉方案。
- **SMPL重建**：实时将稀疏追踪流重建为SMPL人体状态，提取骨盆运动、脚部运动及双手姿态作为重定向输入。
- **GMR重定向公式**：
  - 机器人配置参数化为 q = (x_b, y_b, θ_b, q_L, q_R)，即平面底座位姿 + 左右臂关节配置；

  - 通过加权目标函数优化：
    ```
    q* = argmin_q  λ_pos·L_pos + λ_rot·L_rot + λ_base·L_base + λ_reg·L_reg
    ```
  - L_pos对齐手与夹爪位置，L_rot对齐手与末端执行器方向，L_base将平面底座运动与操作者骨盆位移和朝向耦合，L_reg约束关节极限与剧烈变化。
- **创新点**：将移动底座建模为3-DoF平面虚拟浮动基座，与双臂关节联合优化，当目标末端位姿超出臂工作空间时自动调整底座平移与偏航，实现"身体带动移动"的自然交互。
- **模式切换**：设计了成本驱动的运动模式切换策略，在自旋、阿克曼转向、斜向平移三种模式中动态选择最优执行模式。

#### 关键技术二：PanoVLA模型架构
- **基础框架**：基于π0.5 Mixture-of-Transformers（MoT）双专家架构，插入全景专家模块形成三专家结构（VLM专家、全景专家、动作专家）。
- **全景编码器（Panorama Encoder）**：
  1. **球面重投影**：将双目鱼眼图像映射到公共观测球面，栅格化为等距柱状投影（ERP）图像；
  2. **全景特征提取**：使用MTPano全景基础模型，提取分割分支（语义特征）与深度分支（几何特征），沿通道拼接为统一稠密表征；
  3. **令牌适配**：通过自适应平均池化压缩到固定分辨率，再经轻量MLP映射到全景专家隐藏维度，得到全景令牌序列。
- **全景专家（Panorama Expert）**：
  - 以KV缓存为融合接口，全景令牌与VLM缓存执行联合自注意力，生成包含任务相关全局空间信息的全景缓存；
  - 动作专家基于拼接缓存 Ct = [C_vlm; C_pano] 预测动作，同时利用局部精细操作线索与机器人中心全局空间上下文。
- **训练目标**：采用条件流匹配（Conditional Flow Matching），学习条件速度场，预测32步连续动作块。

### 3. 实验设计

#### 数据集
- **规模**：800条成功遥操作轨迹、约5.5小时、50万同步帧（25Hz采样，每条轨迹20-30秒）；
- **模态**：局部RGB视图（1前视+2腕部）、顶部360°全景相机、本体感知状态（双臂关节位置+夹爪状态+底座位姿）、17维全身动作；
- **任务分类**（4个真实世界任务）：

| 任务 | 目标 | 空间设置 |
|------|------|----------|
| Move Pen | 将笔放入笔筒 | 前方/左侧/右侧 |
| Move Block | 将积木转运至前方区域 | 左侧/右侧/双侧 |
| Open Curtain | 打开双侧窗帘 | 左侧/右侧 |
| Wipe Table | 擦拭污渍并归还毛巾 | 长桌 |

#### 对比方法（基线）
1. **π0.5**：仅使用局部相机视图（SigLIP编码），无全景信息；
2. **π0.5 w/ Pano**：将ERP全景作为额外图像输入，用相同SigLIP编码，无专门全景分支；
3. **π0.5 w/ Stacked Pano**：将全景重投影为3个间隔120°的透视视图，拼接为合成图像输入；
4. **PanoVLA**：MTPano全景编码器 + 全景专家。

#### 评估指标
- **成功率（SR）**：整条轨迹端到端是否完成任务（二值指标）；
- **阶段完成率（SCR）**：各任务分解为多个阶段，所有试验中完成阶段的平均比例；
- 每个任务15次闭环真实机器人试验，单次不间断运行，无人工重置。

### 6. 论文的主要结论与发现

1. **全景感知显著提升移动操作性能**：PanoVLA平均SCR 91.3%、SR 73.4%，较π0.5基线（SCR 58.6%、SR 30.0%）分别提升32.7和43.4个百分点，验证了全景空间上下文对移动操作的关键作用。
2. **全景建模方式决定性能上限**：仅添加原始全景图像（π0.5 w/ Pano）虽能提升性能（SCR 80.8%、SR 56.7%），但低于专门设计的PanoVLA；透视重投影方案（Stacked Pano）在部分任务上反而因破坏跨视角连续性而性能下降。
3. **全景专家有助于多阶段状态追踪**：在Wipe Table任务中，原始全景基线在最后阶段仅26.7%完成率，而PanoVLA达73.3%，表明全景专家能更有效地维持全局空间一致性和任务状态转换的追踪。
4. **几何感知的全景编码器至关重要**：SigLIP仅取得75.6% SCR和40.0% SR，而MTPano达到95.6% SCR和86.7% SR，说明专为全景设计的视觉编码器能更好地保留全景空间结构。
5. **专家规模存在最优区间**：100M参数全景专家在性能与数据效率之间取得最佳平衡，50M不足而200M/300M无一致增益。
