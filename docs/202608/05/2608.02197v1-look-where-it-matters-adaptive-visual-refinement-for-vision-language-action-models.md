## 摘要
VLA模型的视觉表示在空间精确的机器人操作中仍不可靠。我们发现，VLA中的视觉编码器也表现出先前在通用Vision Transformer中记录到的注意力伪影，并进一步表明，在具身策略中，这些伪影与后训练期间获得的空间感知能力密切相关。随着编码器学习任务相关信息，如物体位置、深度排序和局部几何，有限的全局token容量导致部分信息溢出到低信息量的patch token中。我们引入AtVLA，一种将可学习的寄存器token插入视觉编码器的框架。仅使用具身数据和原始动作目标进行端到端训练，这些寄存器成为具身空间信息的专用载体，而剩余的patch token恢复干净且空间上忠实的注意力分布，这对于精确的目标定位和细粒度接触至关重要。干净的注意力恢复了可靠的定位，但无法恢复在低分辨率观测中丢失的几何细节。因此，AtVLA将注意力校正与不确定性门控的局部精化相结合。动作专家采样多个动作块，并根据其不一致性估计不确定性；仅对于不确定的预测，动作条件注意力展开识别任务相关区域，该区域被裁剪、以高分辨率重新编码，并附加到缓存前缀中以生成精化动作。在LIBERO、SimplerEnv和具有挑战性的单视图真实世界基准上，AtVLA将平均LIBERO成功率从94.2%提高到98.4%，真实世界成功率从46.5%提高到69.0%。在代表性部署设置下，裁剪仅在约30%的重新规划步骤中触发，导致总计算量仅为基础模型的1.4-1.6倍。

## Abstract
Visual representations of VLA models remain unreliable for spatially precise robotic manipulation. We uncover that vision encoders in VLAs also exhibit attention artifacts previously documented in generic Vision Transformers, and further show that, in embodied policies, these artifacts are closely associated with spatial perception capabilities acquired during post-training. As the encoder learns task-relevant information such as object location, depth ordering, and local geometry, limited global-token capacity causes part of this information to spill into low-information patch tokens. We introduce AtVLA, a framework that inserts learnable register tokens into the visual encoder. Trained end-to-end using only embodied data and the original action objective, these registers emerge as dedicated carriers of embodied spatial information, while the remaining patch tokens recover clean and spatially faithful attention distributions crucial for precise target localization and fine-grained contact. Clean attention restores reliable localization, but cannot recover geometric details lost in low-resolution observations. AtVLA therefore couples attention rectification with uncertainty-gated local refinement. The action expert samples multiple action chunks and estimates uncertainty from their disagreement; only for uncertain predictions, action-conditioned attention rollout identifies the task-relevant region, which is cropped, re-encoded at high resolution, and appended to the cached prefix for refined action generation. Across LIBERO, SimplerEnv, and a challenging single-view real-world benchmark, AtVLA improves the average LIBERO success rate from 94.2% to 98.4% and real-world success from 46.5% to 69.0%. The cropping is triggered on approximately 30% of replanning steps, resulting in only 1.4-1.6x the total computation of the base model under the representative deployment setting.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究对象**：视觉-语言-行动（VLA）模型，这类模型将大规模视觉-语言预训练中的语义知识与指令跟随能力迁移至连续机器人控制策略。
- **核心问题**：尽管 VLA 模型在通用操作任务中表现优异，其视觉编码器在**空间精确操作**（目标定位、几何推理、精细接触）中仍存在不可靠之处——模型常常无法正确识别目标、区分任务类型，且细粒度操作需要局部几何细节，而低分辨率观测无法提供这些信息。
- **关键发现（两层瓶颈）**：
  1. **注意力伪影**：VLA 视觉编码器存在与通用 Vision Transformer 类似的高范数伪影，即背景 patch 被作为全局信息存储库，挤占局部空间内容、污染注意力图；且具身后训练过程中，物体位置、深度排序、实例结构、局部几何等操作相关空间信息超出原始全局 token 容量，**溢出到 patch token**，损害了定位与接触推理。
  2. **分辨率不足**：即使定位正确，低分辨率观测仍无法提供精细操作所需的接触区域局部几何细节；腕部相机虽能提供近景，但对视角和姿态变化高度敏感。
- **核心含义**：论文提出应先在视觉编码层面校正注意力伪影，再对不确定的预测进行**选择性的局部高分辨率精化**，而非对所有输入一律进行重处理——这为提升 VLA 的空间精确操作能力提供了一条高效路径。

## 2. 论文提出的方法论：AtVLA

### 2.1 核心思想概览

AtVLA 由两个互补机制构成：

1. **寄存器增强的视觉编码（Register-Enhanced Visual Prefix）**——解决注意力伪影问题；
2. **不确定性门控的局部精化（Uncertainty-Gated Local Refinement）**——解决低分辨率下几何细节丢失问题。

### 2.2 寄存器增强视觉前缀

- 在视觉编码器中插入 **Nr = 4 个可学习寄存器 token**，位于 CLS token 之后：

  `Xt = [x_cls; r_1, ..., r_Nr; p_1, ..., p_Nb]`

- 输出为 `[h_cls, R_t, P_t]`，其中 `R_t` 为寄存器特征，`P_t` 为 patch 空间特征。
- 与原始仅将寄存器作为内部工作空间的做法不同，**寄存器输出被保留并与 PaliGemma 视觉投影器对接**，形成多槽位全局上下文。
- 基础多模态前缀为：

  `Cb_t = [Π(R_t); Π(P_t); E_lang(ℓ); E_state(s_t)]`

- **关键点**：后训练中寄存器自然成为具身空间信息的专用载体；去除这些已学习的寄存器会导致所有 LIBERO 套件上的性能大幅下降，表明其不仅抑制伪影，还保留了与任务相关的具身知识。
- **线性探针实验**证实，寄存器特征在物体位置、深度和表面法线预测方面均优于 CLS token 或池化 patch 特征（得分均超 0.70）。

### 2.3 不确定性门控的动作预测

- LLM 骨干仅对基础前缀处理一次，构建可复用的**前缀键-值缓存**。
- 动作专家从独立的 Gaussian 初始化中采样 **K = 4 个动作块**，所有样本共享视觉和语言预填充，仅动作专家去噪过程不同。
- 在平移动作维度 `D_tr` 和前 h 个将实际执行的动作上计算不确定性：

  `U_t = (1/(h|D_tr|)) Σ_j Σ_d sqrt((1/(K-1)) Σ_k (A^(k)_{j,d} - Ā_{j,d})²)`

- 若 `U_t ≤ τ`，直接执行平均动作块（**置信路径**）；若 `U_t > τ`，触发局部精化（**不确定路径**）。
- 阈值 `τ` 在每个实体上单独校准，目标是在约 30% 触发率预算内最大化裁剪的期望收益。

### 2.4 注意力引导的局部精化

- 利用基础动作采样过程中已产生的注意力矩阵，在全部 18 层联合注意力层上执行**注意力展开（attention rollout）**，平均欧拉去噪步骤 `{3, 6, 9}`，传播 token 间影响力，生成 16×16 显著性图。
- 通过**对比式窗口搜索**（窗口边长 {84, 112, 140} 像素、步长 14 像素）选择任务相关区域，判据为窗口内部注意力与周围环形区域的差异最大化。
- 所选区域从原图中裁剪，缩放至 224×224，由**同一寄存器增强编码器**重新编码；裁剪侧寄存器输出被丢弃（基础寄存器已提供全局上下文），仅保留 256 个裁剪 patch 特征。
- 通过 **MLP 位置编码**将裁剪位置 `(x1/W, y1/H, x2/W, y2/H)` 编码并加到每个裁剪 token 上，保持其在原图中的位置感知。
- 将裁剪 token 前缀追加到缓存前缀后（**无需重新计算基础图像/语言 KV 缓存**），重新生成精化动作。

### 2.5 训练目标与三阶段范式

- 保留 π0 原始动作目标 `L_π0`，最终目标：

  `L = L_π0 + λ_cp L_cp + λ_ag L_ag`（其中 `λ_cp = 0.1`, `λ_ag = 1.0`）

  - `L_cp` 监督预测的裁剪坐标；
  - `L_ag` 鼓励动作到图像的注意力集中在任务相关区域内部。

- **三阶段课程**（共 70K 步）：
  1. **Stage 0（寄存器适应，20K 步）**：先仅微调寄存器嵌入（4K 步），再解冻 SigLIP 最后 4 个 transformer 块（16K 步）；仅使用基础视图，裁剪分支禁用。
  2. **Stage 1（真实裁剪对齐，10K 步）**：冻结视觉编码器，仅训练裁剪位置编码器和 LoRA 适配器，使用带标注的任务相关区域作为真实裁剪。
  3. **Stage 2（联合精化与推理对齐，40K 步）**：联合微调完整策略，使用裁剪课程——从真实裁剪逐步过渡到模型自身注意力展开生成的裁剪，并引入裁剪丢弃率（最高 0.3）以保持基础路径能力。

## 6. 论文的主要结论与发现

1. **注意力伪影可修复**：通过具身后训练插入寄存器 token，能有效消除高范数伪影，使注意力分布集中于任务相关物体和交互区域；无需额外的纯视觉预训练或通用视觉监督。
2. **寄存器捕获具身空间信息**：线性探针证实寄存器特征包含丰富的任务相关空间信息（位置、深度、表面法线），且移除寄存器会导致显著性能退化，证明其不仅是伪影抑制器。
3. **裁剪对大范围任务有益**：裁剪不仅提升细粒度感知，还改善了长时域任务（LIBERO-Long-10 和真实世界长时域类别），说明附加的视觉上下文支持时序扩展规划。
4. **裁剪质量至关重要**：外部 VLM 生成的裁剪因缺乏具身监督经常无法隔离任务关键区域，导致性能低于完整 AtVLA；不准确的裁剪可能扭曲策略输入。
5. **性能增益显著**：
   - LIBERO：平均成功率从 94.2% 提升至 98.4%（π0 基线）；
   - 真实世界：成功率从 46.5% 提升至 69.0%；
   - 在 LIBERO-Object、Kitchen Grab/Pick、LIBERO-Spatial、Building Blocks Spatial/Grab 等物体中心与空间要求高的任务上增益最明显。
6. **计算开销可控**：裁剪仅在约 30% 的步骤触发，总计算为 π0 的 1.4–1.6 倍。

## 7. 优点

- **问题诊断深入**：不仅发现注意力伪影，还揭示了其与具身后训练获取空间信息之间的因果关联（信息溢出假说），分析具有原创性。
- **方法简洁高效**：寄存器 token 为训练增加极少参数（4,608 个），却带来显著性能提升；三阶段课程设计合理，逐层对齐新组件，避免干扰预训练表示。
- **推理设计巧妙**：不确定性门控 + 前缀 KV 缓存复用，使裁剪仅在必要时触发且增量计算成本低；注意力展开复用已有注意力计算，几乎无额外开销。
- **训练与推理对齐**：裁剪课程从真实标注过渡到模型自生成的注意力裁剪，并模拟部署时的失败处理行为（无效 rollout 不依赖真实标注回退），有效避免训练-测试不一致。
- **实验体系完整**：模拟 + 真实世界 + 多组对照与消融，加上线性探针和注意力可视化，从多个角度验证了方法的有效性。

## 8. 不足与局限

- **实验范围限制**：SimplerEnv 未评估 WidowX 套件；真实世界仅在单一机器人平台（Franka Research 3）和单目第三视角下验证，缺少多平台、多相机设置的泛化验证。
- **基准对比的完整性**：部分基线结果来自文献报告值而非本地复现，可能引入环境配置差异；真实世界评测中各模型的微调步数/配置虽声明可比，但未提供详细对照表。
- **裁剪依赖注意力质量**：方法依赖动作条件注意力展开的可靠性；对于背景高度占据视野的场景（如 Open/Close Drawer），裁剪可能近似保留整图，无法有效提升细粒度感知。
- **不确定性阈值需逐实体校准**：不同机器人实体需要单独标定阈值，增加了部署复杂度；触发率预算（30%）是经验选择，未必在所有任务上最优。
- **几何细节恢复有限**：高分辨率裁剪恢复的是 2D 细节，对于单视图深度歧义问题（如 Building Blocks 中的空间堆叠），方法仍受限于观测本身的几何信息不足。
- **计算开销描述偏理想化**：论文给出 1.4–1.6 倍总计算的估算基于特定假设（K = 4、r ≈ 0.3、专家单次采样与裁剪精化的占比），实际场景中动作块长度、相机数量变化可能影响最终开销。
