## 摘要
多模态终身导航要求智能体自主探索未见环境，同时按顺序完成由物体类别、语言描述或参考图像指定的导航任务。现有方法主要通过构建以状态为中心的语义场景图来完成这些任务。通过将场景图视为语义观察的持久存储库，这些方法难以区分相似实例，难以联合表示语义目标与探索前沿，并且难以有效利用导航记忆和轨迹经验。为了解决这些限制，我们提出了时空事件图导航（STEGNav），这是一种无需训练的框架，通过互补的空间轴与时间轴将传统场景图扩展为时空事件图。空间轴执行查询条件下的实例定位，并联合表示语义目标以及以可达性、路径成本和探索效用为特征的占用感知探索前沿。时间轴利用轨迹感知的双窗口记忆，以保留最近的决策-轨迹事件和已验证的跨子任务导航结果。基于VLM的导航智能体对生成的时空事件图进行推理，并选择目标实例或探索前沿作为其下一个导航目标。STEGNav在GOAT-Bench上达到了66.3%的SR和39.7的SPL，并在HM3Dv1和HM3Dv2上分别取得了64.0%和69.4%的SR分数。消融研究和误差分析验证了两个轴的互补效应，表明事件驱动的时空表示提高了导航可靠性和跨子任务经验复用。

## Abstract
Multimodal lifelong navigation requires an agent to autonomously explore unseen environments while sequentially completing navigation tasks specified by object categories, language descriptions, or reference images. Existing methods primarily accomplish these tasks by constructing state-centric semantic scene graphs. By treating scene graphs as persistent repositories of semantic observations, these methods struggle to distinguish similar instances, jointly represent semantic targets and exploration frontiers, and effectively exploit navigation memory and trajectory experience. To address these limitations, we propose Spatio-Temporal Event Graph Navigation (STEGNav), a training-free framework that extends conventional scene graphs into spatio-temporal event graphs along complementary spatial and temporal axes. The spatial axis performs query-conditioned instance grounding and jointly represents semantic targets and occupancy-aware exploration frontiers characterized by reachability, path cost, and exploration utility. The temporal axis employs trajectory-aware dual-window memory to retain recent decision--trajectory events and verified cross-subtask navigation outcomes. A VLM-based navigation agent reasons over the resulting spatio-temporal event graph and selects either a target instance or an exploration frontier as its next navigation goal. STEGNav achieves 66.3% SR and 39.7 SPL on GOAT-Bench, as well as SR scores of 64.0% and 69.4% on HM3Dv1 and HM3Dv2, respectively. Ablation studies and error analyses validate the complementary effects of the two axes, demonstrating that event-driven spatio-temporal representations improve navigation reliability and cross-subtask experience reuse.

# STEGNav 论文总结

## 1. 核心问题与整体含义

- **任务背景**：多模态终身导航要求智能体在未知环境中自主探索，并连续完成多个子任务，每个子任务的目标可由物体类别（object）、语言描述（language）或参考图像（image）指定。
- **现有方法的问题**：已有方法主要构建“以状态为中心”的语义场景图，将其作为语义观测的持久存储库。这带来三个关键局限：
  - 无法区分同一类别中的不同物理实例；
  - 语义目标与探索前沿被分开表示，难以联合推理目标身份、可通行性和探索收益；
  - 缺少对历史导航轨迹和跨子任务经验的显式利用，容易导致重复探索和经验丢失。
- **核心意义**：STEGNav 将传统场景图扩展为“时空事件图”，通过空间轴和时间轴互补地组织环境状态与导航事件，从而提升多模态终身导航的可靠性和跨子任务经验复用能力。

## 2. 方法论

- **核心思想**：以事件驱动的方式重新组织场景图。空间轴负责“当前环境是什么”，时间轴负责“智能体如何到达、曾经验证过什么”，二者结合构成一个可供 VLM 直接推理的统一图结构。
- **空间轴：多层级语义-导航图**
  - **查询条件实例接地**：先用类别预过滤器保留语义相关节点；再由 VLM 接地模块评估每个候选节点与当前查询的相关性，生成相关分数和查询条件描述；对图像/语言查询保留 top-N 实例，构造查询-实例边。
  - **占用感知前沿接地**：将前沿单元聚类为前沿节点，每个节点记录可达性、路径成本、探索增益和访问状态；并建立前沿-语义边和导航边，使目标实例与探索前沿处于同一图结构中。
- **时间轴：轨迹感知双窗口记忆**
  - **短期窗口**：保留最近 Wst=20 条决策-轨迹事件，记录所选节点、轨迹段、穿越区域、路径长度和执行结果，用于识别重复导航模式。
  - **长期窗口**：保留最多 Wlt=8 个经 VLM 验证的跨子任务成功事件，仅作为“召回线索”，通过持久化标识或外观特征重新关联到当前场景图。
- **导航决策流程**：
  1. 构造查询事件；
  2. 构建空间图；
  3. 关联短期与长期记忆事件；
  4. 序列化为事件图；
  5. 由一个 VLM 策略选择“目标实例节点”或“探索前沿节点”作为下一步目标；
  6. 执行导航并更新场景图、占用图和记忆窗口。
- **关键验证公式**：成功事件需满足 `wk = 1`，其中要求终止实例与选中实例一致、VLM 判断为正且终止距离小于 δ（δ=0.8m）。

- **主要基准：GOAT-Bench**
  - 多模态终身导航 benchmark，Val-Unseen 包含 36 个场景，每个场景 10 个 episode，每个 episode 有 5–10 个连续子任务。
  - 评估指标：SR（成功率）和 SPL（路径长度加权成功率）。

- **泛化基准：HM3D 类别级 ObjectNav**

- **误差分析**：将失败子任务按五类原因（低效探索、记忆召回失败、目标接地失败、执行/停止失败、同类实例混淆）统计。

## 6. 主要结论与发现

- 在 **GOAT-Bench Val-Unseen** 上，STEGNav 取得 SR 66.3%、SPL 39.7，SR 比最强对比方法 MSGNav 高 3.9 个百分点，比 EvoMemNav 的 SR/SPL 分别提升 6.7%/0.8。
- 在 **HM3Dv1/v2** 上，STEGNav 取得 SR 64.0%/69.4%，均为最高 SR；但 SPL 不是最优，说明成功率提升尚未充分转化为最短路径。
- **消融实验**表明：完整模型比仅用 3D 场景图的基线在 SR 上提升 15.1%，SPL 提升 9.3；其中 OFG 对图像查询的提升最大，DWM 进一步改善图像查询成功率。
- **错误分析**显示：总失败数减少 34.1%，其中实例混淆减少 53.8%，低效探索减少 40.0%；说明时空事件图主要改善高层目标接地、探索决策和记忆复用，而对低层执行/停止问题改善有限。

## 7. 优点

- **无需训练**：完全基于预训练 VLM 和开放词汇感知工具，易于迁移到新环境和开放目标。
- **统一表示**：将语义实例、可通行性、路径成本、探索收益以及历史轨迹事件整合到同一图结构中，便于 VLM 联合推理。
- **互补的空间/时间轴设计**：空间轴解决实例区分和探索联合建模，时间轴解决轨迹记忆和跨子任务经验复用，二者互补且可拆解验证。
- **实验分析深入**：不仅报告 SR/SPL，还进行了逐步消融和细粒度错误分类，能清楚指出性能提升来源。

## 8. 不足与局限

- **路径效率未达最优**：HM3D 上虽然 SR 最高，但 SPL 明显低于 EvoMemNav（如 HM3Dv2 SPL 28.2 vs 39.4），说明导航路径可能更长，存在过度探索或决策不够近优的问题。
- **低层控制仍是短板**：错误分析中执行/停止失败只从 18 降到 14，改进幅度较小，事件图并未解决低层控制问题。
- **记忆容量有限**：长期窗口仅存 8 个事件、短期窗口保留 20 个

的决策-轨迹事件。对于更长的任务序列或开放式探索，这种固定容量可能导致早期重要经验被过早遗忘，系统无法充分利用全部历史信息，限制了真正意义上的“终身”学习能力。

- **对 VLM 能力高度依赖**：实例接地、目标选择、成功验证等关键环节均依赖单一预训练 VLM 的语义判断，但文中未分析 VLM 不同强度或不同主模型带来的性能波动，也没有对 VLM 错误如何传导到最终导航结果做系统性归因，因此方法的性能上界受限于所选 VLM 的推理能力。

- **缺乏对不同查询模态的细粒度对比**：虽然 GOAT-Bench 包含 object、language、image 三种查询，但实验只报告了混合 SR/SPL，未分别统计三种模态下的成功率差异，难以判断时空事件图在不同模态上的增益是否均衡。

- **未报告推理时间与计算开销**：作为 training-free 方法，虽然免去了训练成本，但每一步决策都需要序列化大量图信息并调用 VLM 推理，实际部署时的延迟和 token 消耗未被讨论；同时未给出与端到端方法在推理效率上的对比。

- **评估场景规模有限**：GOAT-Bench 的 Val-Unseen 仅 36 个场景，消融实验又进一步限制为每场景第一个 episode，样本量较小；HM3DM 实验虽场景数较多，但仅评价类别级 ObjectNav，未覆盖多模态查询和跨子任务设置，因此结论的统计稳健性和泛化范围仍有待验证。

- **细节未完全公开**：长期事件如何从“召回线索”重新关联到当前场景图、短期窗口中的“重复模式”具体如何识别，以及失败事件是否参与更新，文中细节有限，不利于复现。

## 9. 总体评价

STEGNav 通过引入时空事件图，同时承担了“环境状态表示”和“导航经验记忆”两类功能，统一了语义实例、可通行前沿与历史轨迹的表达。结合 GOAT-Bench 和 HM3D 上的结果，其在高层次目标接地与跨子任务探索方面确实显著优于现有方法，且错误分析也佐证了事件图在减少实例混淆和低效探索上的有效性。然而，该方法仍属于 VLM 驱动的决策框架，其路径效率、低层控制能力和长期记忆容量都尚未达到完全“终身导航”的期望；未来工作或可在缩短路径、扩展记忆容量、采用更细粒度子任务评估以及增强对低层执行误差的鲁棒性等方面继续改进。
