## 摘要
视觉-语言-动作(VLA)驾驶模型将推理阶段与基于扩散的轨迹解码器相结合，但并未提供无需重新训练即可在推理时将注意力引向安全关键参与者的直接方法。我们研究了在Alpamayo-R1的Qwen3-VL骨干网络上，对检测器定位的交通参与者的视觉标记施加的有界加性预Softmax注意力偏置。它以故障开放的前向预钩子形式应用，不改变权重。在来自Physical AI World Model Synthetic数据集的50个变道场景上，轨迹解码器在偏置幅度上显示出单调的剂量反应，与每个测试幅度下配对的零偏置对照相区分。在钳制值处，平均位移达到约17厘米，横向偏移可达约140厘米。层消融将动作相关信号定位在后期层，且效果随挂钩层数增加而增强（前8层为2.0厘米；全部36层为67.6厘米）。逐调用注入审计解释了为什么因果链文本从未改变。在此服务栈中，基于掩码的偏置从未到达推理路径，因此这种不变性是经过验证的暴露，而非鲁棒性。被引导的轨迹倾向于移向被关注的参与者，这表明偏置控制的是模型的注视位置，而非编码目标行为。

## Abstract
Vision-language-action (VLA) driving models couple a reasoning stage with a diffusion-based trajectory decoder, but do not give a direct way to redirect attention toward safety-critical actors at inference time without retraining. We studied a bounded additive pre-softmax attention bias on the visual tokens of detector localized traffic actors on Alpamayo-R1's Qwen3-VL backbone. It is applied as a fail open forward pre-hook with no weight changes. On 50 lane-change scenarios from the Physical AI World Model Synthetic dataset. The trajectory decoder shows a monotonic dose response in the bias magnitude, separate from a paired zero bias control at every tested magnitude. It reaches $\approx 17$\,cm mean displacement with lateral shifts up to $\sim 140$\ cm at the clamp. A layer ablation places the action-relevant signal in late layers, where the effect increases with the number of hooked layers (2.0cm for the first 8 layers; 67.6cm for all 36). A per call injection audit explains why the Chain-of-Causation text never changes. The mask based bias never reaches the reasoning pathway in this serving stack, so the invariance is verified exposure, not robustness. Steered trajectories tend to shift toward the attended actor, suggesting the bias governs where the model looks rather than encoding a target behavior.

# 论文详细总结

## 1. 核心问题与整体含义

本论文针对 VLA（视觉-语言-动作，Vision-Language-Action）自动驾驶模型的一个结构性局限展开研究：**模型一旦部署，其对视觉 token 的注意力分配便被训练固定**。若模型对安全关键参与者（如盲区中的汇入车辆、人行横道上的行人）关注不足，现有方法无法在不重训练的前提下将注意力重定向至这些对象。对于 10B+ 参数的大模型，重训练成本极高，且会破坏部署模块化。

论文的核心问题是：**能否在不修改任何权重、不进行任何训练的情况下，在推理时通过有界注意力偏置将 VLA 驾驶模型的轨迹预测"推向"某个方向，并系统性地研究该干预在混合架构中的传播特性？** 研究关注的是干预的可传播性及其量化特征，而非主张位移幅度本身代表更好的驾驶行为。

## 2. 方法论

### 2.1 核心思想

论文提出一种**有界的、加性的 pre-softmax 注意力偏置**，注入到由检测器定位的交通参与者对应的视觉 token 上，通过 Qwen3-VL 自注意力模块的轻量级前向 pre-hook 实现，完全不改动模型权重。该机制具备四个特性：推理时生效（无训练/梯度计算）、有界（钳制防抑制）、模块化（偏置源外部可替换）、故障开放（失败即回退原生注意力）。

### 2.2 关键技术细节

- **偏置形式**：在注意力 logits 上添加偏置向量 b ∈ R^N，对目标 token 集 T_A 施加 b_j = min(λ, β)，其中 λ≥0 为幅度控制参数，β>0 为安全钳制值，其余位置为 0。因与 Qwen3-VL 的 per-head QK-Norm 点积之后施加，保持了学习到的尺度校准。
- **注入实现**：通过 `register_forward_pre_hook` 在每个目标 `Qwen3VLTextAttention` 模块上实现；在 eager attention 路径中，直接编辑 4D 的 `attention_mask` 张量（形状为 [B,1,L_q,L_k]，被掩码位置为 -∞，未掩码为 0），将 +λ 加到 T_A 对应列上，在数学上等价于式 (2)。
- **检测器到 token 映射**：YOLO11-nano 检测器在模型输入分辨率（576×320）上运行，检测前向最近的前车；通过 Qwen3-VL 的 patch 尺寸 p 和 2×2 空间合并因子得到 10×18 的 token 网格（由 `image_grid_thw` 直接读取，非假设），按式 (4) 将边界框映射到确切 token 索引，每次运行都会对照分词器的 video-token span 验证映射正确性。
- **注意力累积保证**：Proposition 1 说明对目标 token logits 添加 λ 会使其 softmax 分子放大 e^λ > 1，因此重归一化后目标 token 上的注意力质量单调不减——这是 InstABoost 的加性形式定理。
- **暴露审计**：逐调用记录 hook 触发情况（推理阶段、mask 存在性、目标列数）。审计揭示：在部署路径中，扩散动作解码器的前向过程带有显式 4D mask 因此收到偏置；CoC 文本的 prefill 与自回归解码走 fused causal kernel 路径，**不存在可注入的 mask**，因此从未被偏置触及。

### 2.3 算法流程（文字说明）

给定目标层子集 L、检测器输出的 actor 边界框，流程为：(1) 以模型输入分辨率运行 YOLO11-nano 获取前车框；(2) 通过公式 (4) 计算边界框在 10×18 合并 token 网格上的行列区间，再从 tokenizer 的 video-token spans 验证每个索引；(3) 跳过前 k_sink 个"注意力汇"位置；(4) 在目标层的 forward pre-hook 中为 attention_mask 的目标列加上 min(λ, β)；(5) 记录应用情况，任何异常即跳过（fail-open）；(6) 配对种子运行基线（head_scale=0）与干预版本，对比轨迹。

## 3. 实验设计

### 3.1 数据集与场景

- **数据集**：PhysicalAI WorldModel-Synthetic Autonomous Driving Scenarios 数据集，Omniverse 渲染、多相机视频。
- **场景类型**：50 个变道（lane-change）场景，作者刻意选择合成环境以消除检测器方差对轨迹差分的混淆。
- **输入配置**：前广角相机、4 帧上下文（0.5s 间隔），resize 至 576×320。
- **案例筛选**：需在前方 ±4m 横向带、5–40m 纵向范围内检测到明确的领航车（优选约 20m），使变道场景中只有一个无歧义的关注对象。
- **基准**：模型输出 64 个 waypoint 轨迹（10Hz，6.4s 视野），基线 CoC 文本需为连贯驾驶描述，且零偏置门需在配对种子下完全复现基线轨迹（ADE≡0）。
- **对比方法**：本文无标准 benchmark 对比方法——它不是性能优化工作，而是系统性的干预研究。与 PASTA、InstABoost、SpotLight 等方法对比属于概念层面的差异（文本生成 vs. 物理轨迹输出），未做定量比较。

### 3.2 评测指标

- ADE（平均位移误差，基线 vs. 干预的 64 waypoint 轨迹间的平均 L2 距离）
- 最大横向偏移
- CoC 文本精确字符串匹配变化率
- Cliff's δ（vs. 配对零偏置对照）
- Wilcoxon 符号秩检验 + Holm 校正
- 相对于被关注 actor 的偏移方向

## 4. 资源与算力

- **模型**：Alpamayo-R1-10B，NF4 量化（QLoRA），约 12GB VRAM。
- **硬件**：单块 24GB GPU（具体型号未在文中给出），整个实验在单 GPU 上完成。
- **训练时长**：不适用——该方法**无需任何训练**，全部为推理时干预（inference-time）。但文中未说明总推理时长或每个场景的耗时。

## 6. 主要结论与发现

1. **单调剂量-反应**：ADE 随偏置幅度单调增长，λ=4 时平均 ADE ≈ 17cm，最大侧移均值 ≈ 38cm（存在单例上尾达 ~140cm）；所有非零条件经 Holm 校正后 p ≪ 10⁻¹⁰，Cliff's δ=1.0（每个干预案例都超过每个零偏置对照案例）。小 λ 时效应以纵向为主，大 λ 时横向分量占主导。
2. **层定位明确**：早期 8 层几乎惰性（ADE 2.0cm），**后 8 层（16.7cm）远超同层数中段（9.7cm）**，且效应随挂勾层数单调累积（last_4 < last_8 < last_16 < all_layers），全 36 层挂勾达 67.6cm 平均 ADE 与 ~205cm 平均最大侧移。这与多模态注意力文献中"动作相关信号在后期层"的预测一致。
3. **效应随 rollout 累积**：横向偏移在最初 ~2s 内接近零，之后近似二次式增长并在 horizon 末端达到峰值。作者指出 ADE 会低估后期的重要偏移，最大横向偏移是更忠实的指标。
4. **轨迹趋向被关注 actor**：在 actor 保持在前方的时间子集上，轨迹倾向于偏向 actor 所在侧。作者谨慎地将此解读为偏置增加了 actor 在扩散解码器聚合视觉表征中的显著度（saliency），而非编码了任何显式的安全语义。
5. **CoC 不变性是"暴露缺失"而非"架构鲁棒"**：逐调用审计证明偏置从未触及 CoC 的 prefill/解码路径（fused causal kernel 无显式 mask 可注入）。CoC 不变是因为它从未被扰动——这是经核实的事实，而非模型推理头对注意力扰动有免疫力的证据。该发现正确排除了"确定性解码导致文本不变"的替代解释。

## 7. 优点

- **无需训练的推理时干预**：对 10B+ 模型可即插即用，保持部署模块化，任何检测器可替换使用，不触碰权重。
- **严格的实验协议**：配对种子 + 零偏置门（ADE≡0 位相同）将扩散采样的噪声底限（3.23m 跨种子距离）与厘米级干预效应（0.107m）干净分离，方法论上值得借鉴。
- **理论-实现一致性验证**：不仅给出式 (2) 的理论断言，还逐层逐列验证 logit 增量精确等于 4.0，证明了实现与规范吻合（而非仅凭效果推测）。
- **诚实的归因分析**：逐调用暴露审计澄清了"CoC 不变"的正确解读，避免将暴露缺失误报为架构鲁棒性——这是一个容易误导读者的陷阱，作者主动纠正了。
- **多层控制变量设计**：偏置幅度、偏置层数与层位置（early/mid/late/all）、解码温度、随机种子、横向/纵向分量分别可控，提供了比单一静态干预更完整的图景。
- **精确的干预对象**：通过 YOLO 检测 + 分辨率匹配 + 每次运行验证 tokenizer spans，杜绝了坐标缩放误差导致的映射错位。

## 8. 不足与局限

- **缺少匹配对照（重要缺失）**：干预条件仅与零偏置对照比较，无法证明效应是"作用于该 actor"的结果，而非"作用于任意 token 集"的通用效应。作者本人承认这是最重要的缺失实验，控制 token 数量、位置、内容差异的对照是必要的下一步。
- **合成环境限制**：数据为 Omniverse 渲染视频，无记录的自车状态（合成恒定速度直线历史），模拟到真实的迁移（sim-to-real）未经测试；真实日志中停泊车辆误检、转弯出框、遮挡截断会破坏 actor 定义的清晰性。
- **仅开环评估**：轨迹是单次前向预测，未在闭环基准（如 Bench2Drive）上测试。
- **单一模型与单一场景**：仅 Alpamayo-R1-10B 和变道场景；对行人、交叉口、多 actor 交互的推广未经实证。
- **语言路径暴露未建立**：CoC 实际从未被扰动，其对该扰动的敏感性不得而知——这是方法论的后续关键课题。
- **方向性解读为定性观察**："趋向 actor"倾向缺少量化的依据支撑；后续可采用更丰富的反事实设计来支撑因果推断。
- **对"关注"的机制性解释有限**：作者只声称偏置"调配了 visual saliency"，而非编码目标行为；如何将期望的安全行为（如避障留距 vs. 跟车保持）映射为偏置符号、幅值和放置位置，仍是未解的设计问题。
