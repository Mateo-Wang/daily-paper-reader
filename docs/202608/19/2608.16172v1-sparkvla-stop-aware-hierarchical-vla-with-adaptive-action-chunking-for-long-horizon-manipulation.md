## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务，以及执行所提议动作块到何种程度。这两个决策相互依赖——最优停止点取决于执行者计划做什么，而最优执行长度取决于子任务边界位于何处——然而现有架构将它们孤立地评估，这种不对称性任何模块都无法单独克服。我们提出SparkVLA，一种停止感知的分层VLA，通过将两个决策表述为单一排名来解决这种相互依赖：停止与每个动作前缀长度在统一的候选集中竞争，系统选择得分最高的选项，从而消除了阈值调整，仅需要离线序数偏好。一个锚点条件上下文编码模块缓存具有历史感知的子任务锚点编码、起始状态记忆和目标语义，引导视觉令牌剪枝朝向任务相关区域；一个停止感知动作前缀选择头在块边界处通过全自注意力对所有候选进行评分，以提高效率。在RoboCerebra上，SparkVLA取得了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些在物理硬件上的增益。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：Vision-Language-Action（VLA）模型在机器人操作上展现了很强的泛化能力，但主要在短轨迹段上训练，难以在长时程任务中组合多个技能。分层 VLA 架构（高层 VLM 规划器 + 低层 VLA 执行器）是应对长时程操作的主流方案。
- **核心问题**：在分层 VLA 的每个重新观察点（decision boundary），系统必须同时做出两个接口决策：
	1. **何时终止当前子任务**（termination condition）；
	2. **动作块执行多长**（action chunk execution horizon）。
- **关键洞察**：这两个决策**相互依赖**——最优停止点取决于执行者接下来计划做什么，最优执行长度取决于子任务边界在哪里。然而现有架构将二者**孤立评估**：终止侧（如二进制检测器、VLM 预测长度、进度信号）不访问后续计划内容；执行长度侧（如 DEHP、ACH、AQC、AAC）无法发出子任务完成信号。这种信息不对称导致次优决策。
- **本文方案**：将两个决策统一为**单一排序问题**——Stop 与所有动作前缀长度（action-prefix lengths）在统一候选集中竞争，选择得分最高者。该方法无需阈值调参，仅需离线序数偏好（ordinal preferences）监督。

---

### 2. 方法论：核心思想、关键技术细节

#### 2.1 统一候选集：将两个决策合并为一个排序

- 定义统一候选集 C = {0, 1, ..., H}，其中候选 0 代表 **Stop**，候选 n ≥ 1 代表执行动作块 At 的前 n 个动作（即动作前缀）。
- 选择器 f_sel 将动作块、锚点上下文 αk 和高层隐藏特征 mt 映射为 H+1 个分数，取 argmax 作为决策：
  - 选择 Stop → 完成当前子任务，触发规划器生成下一子任务命令；
  - 选择动作前缀 n → 执行前 n 个动作后重新观察。
- 由于所有候选在同一表示下由同一评分头打分，**终止决策可感知计划内容**，**执行长度决策可感知子任务边界**，弥补了孤立模块的信息缺失。

#### 2.2 Anchor-Conditioned Context Encoding（锚点条件上下文编码）

分三阶段构建选择器上下文：

- **历史感知子任务锚点（History-Aware Subtask Anchor）**：
	- 子任务开始时，从规划器 VLM 骨干的**倒数第二层**提取生成命令最后一个 token 的隐藏状态，经 MLP 得到原始锚点 α̂k；
	- 维护锚点历史池 Ak = {α̂1, ..., α̂k−1}，通过**自注意力**将当前原始锚点与历史锚点融合，得到历史感知锚点 αk——编码起始状态记忆、目标语义和跨子任务上下文（如哪些区域已被操作过）；
	- 每个子任务计算一次并全程缓存。

- **锚点引导的视觉剪枝（Anchor-Guided Visual Pruning）**：
	- 冻结的 SigLIP 编码器为每个相机产生密集视觉 token（N 个），使用 **Grid-Sampler**（可微分算子）预测 K 个归一化 2D 采样坐标，通过双线性插值提取任务相关 token；
	- 以子任务锚点 αk 为条件，通过 CrossAttn 生成视觉摘要，再由 MLP_coord 映射为采样坐标，将视觉序列从 N 压缩到 K（K=32）每相机。

- **高层隐藏特征编码**：
	- 剪枝后的视觉 token 投影到骨干宽度，与本体感知状态嵌入和子任务命令嵌入拼接，经高层 VLM 骨干的前 ℓm=8 层（带 LoRA 适配器）处理；
	- 通过前缀注意力掩码聚合多模态上下文，得到高层特征 mt。此过程在每个决策边界重新计算。

#### 2.3 Stop-Aware Action-Prefix Selection（停止感知动作前缀选择）

- **统一候选评分**：评分头为 2 层 8 头的全自注意力 Transformer：
	- 锚点 αk 和高层特征 mt 分别经线性投影作为上下文 token；
	- Stop 候选使用可学习嵌入 e0；
	- 每个长度 n 的候选 token 由该前缀的最后一个动作的 MLP 嵌入 + 可学习长度嵌入初始化；
	- 全自注意力使每个候选观测完整上下文，包括 Stop 表示也因自注意力而具有上下文相关性。
- **训练目标**：两种互补损失，均作用于同一组分数：
	- **配对排序损失 L_rank**：基于离线执行结果分配序数优先权。成功轨迹中，完成后 Stop 排名最高；完成前覆盖前缀优于非覆盖前缀，且越接近边界越好；失败轨迹中所有前缀并列高于 Stop（鼓励继续探索）。训练时对边界标注施加均匀随机扰动（±2）增强鲁棒性。
	- **停止感知辅助损失 L_stop**：用 log-sum-exp 对比 Stop 分数与延续分数，强化终止决策的梯度信号。
	- 总损失 L = L_rank + λ_stop·L_stop，λ_stop = 1。
- **推理**：使用统一 argmax 规则决策，无独立推理路径；短确认窗口过滤瞬时分数波动后提交停止决策。

#### 2.4 整体架构与闭环推理

- 从预训练 π0.5 VLA 派生两个分支：
	- **高层规划分支**：保留 VLM 骨干，负责自回归子任务生成和选择器实现；
	- **低层执行分支**：完整 π0.5 VLA（含动作专家），负责提出动作块。
- 闭环流程：生成子任务命令 → 提取并缓存锚点 → 每个决策边界执行器提议动作块 → 选择器对 Stop 和所有前缀统一打分 → 执行选中的前缀或停止进入下一子任务。选择器仅在块边界调用，语义和锚点历史仅在 Stop 后更新。

### 6. 主要结论与发现

- **统一决策优于孤立决策**：在 RoboCerebra 上，SparkVLA 达到 **47.12%** 平均成功率，超过官方分层基线 HPE（16.55%）30.57%，超过最强可复现方法 Mem-0（20.29%）26.83%，超过独立 π0.5（12.29%）34.83%。
- **双向收益验证**：将 Stop 统一进候选集后，Stop Acc. 从 80.37% 跃升至 96.65%（+16.28 个百分点，精确率 94.3%，召回率 98.1%），SR 从 42.53% 升至 47.12%——终止决策从动作前缀上下文获益，前缀选择也从精确终止信号获益。
- **最大增益场景**：Dynamic Obs.（+34.78%）和 Memory Exp.（+47.69%）——自适应短前缀在场景变化下支持更频繁重观测，历史增强锚点防止重访已完成目标。
- **执行器无关性**：叠加在 OpenVLA-OFT 和 SmolVLA 上分别带来 +22.47% 和 +22.52% 增益，证明收益来自统一接口设计而非特定模型配对。
- **LIBERO 表现**：98.5% 平均成功率，LIBERO-Long 上 98.0%（对比 OpenVLA-OFT 94.5%、π0.5 92.4%），多步序列最受益于子任务分解。
- **真实机器人**：69.3% 平均成功率，超过 π0.5 21.3 个百分点；Tea Preparation（12 子任务）上差距最大（+30.0%）。自适应前缀在接触事件附近缩短、在自由空间运输中延长，行为模式与仿真一致。
- **效率**：命令缓存 2.91× 加速 + 边界调用 2.10× 加速，总体运行 4.14 Hz（41.4 动作步/s），保持独立 π0.5 吞吐量的 88%。

### 7. 优点

- **概念创新**：清晰识别了两个接口决策的相互依赖关系，并用统一排序优雅化解，而非堆砌独立模块。
- **免阈值调参**：终止决策从阈值问题变为排序问题，消除手工调参负担。
- **统一推理路径**：辅助损失只强化同一个分数集，不引入额外的推理通路，训练与推理目标一致。
- **离线序数偏好**：仅需相对顺序而非精确标签/奖励，利用专家轨迹的时间结构提供自然监督信号，配合边界扰动增强鲁棒性；失败 rollout 也以加权方式提供有效监督。
- **上下文编码设计**：历史感知锚点有效传播跨子任务语义，锚点引导视觉剪枝在降低计算量的同时保持任务相关注意力。
- **计算效率**：锚点缓存 + 块边界调用 + 视觉 token 剪枝（N→32），以少量吞吐损失换取大幅性能提升。
- **系统化实验**：逐层剥离每个设计选择（剪枝、锚点、历史、放置位置、调度），证据链完整；跨执行器和仿真到真实的迁移验证加强了结论的普适性。

- **基准覆盖偏差**：LIBERO 上强基线已接近性能天花板，区分度有限；RoboCerebra 的 HPE 结果非本地复现，存在跨协议比较风险。
- **真实实验范围较窄**

真实实验范围较窄：仅在 3 个桌面任务上验证，未涵盖移动操作、动态环境或人机交互场景，且每任务仅 50 条演示，训练数据规模远小于仿真基准，可能低估复杂长时程任务的挑战。
- **训练数据依赖**：选择器监督依赖大规模混合数据（6600+ 演示 + 5600+ rollout），离线收集成本高；失败 rollout 的标注依赖人工定义边界，引入标注噪声。
- **可解释性有限**：统一排序虽免阈值，但分数语义未显式建模；L_stop 的 log-sum-exp 形式与概率校准关系未分析，长期行为保证（如死锁、震荡）缺乏理论分析。
- **消融覆盖仍有空隙**：未测试不同视觉骨干（如 DINOv2）、不同动作解码器（扩散头 vs 离散 token）、不同高层 VLM（如 Qwen-VL）对选择的敏感度；选择器与执行器的联合训练（端到端微调）未探索。
- **计算资源报告不完整**：未提供单段训练时间、推理延迟的具体测量（仅给出通过缓存加速后的总吞吐），不利于复现比较。

---

### 9. 未来研究方向

- **动态在线适应**：将选择器改为 online 学习，利用真实交互反馈自适应调整停止边界和前缀长度，摆脱离线数据依赖。
- **开放式语义终止**：将 Stop 从二元动作扩展到语义层，允许“请求重规划”“等待外力”“切换到无人观测”等更丰富的终止类型。
- **多层级统一**：将统一排序扩展到多个粒度（子任务级、原始动作级、技能参数级），形成递归接口，支持更深层次的长时程层次结构。
- **理论分析**：为统一排序提供 regret 或样本复杂度上界，分析 L_rank 与 L_stop 之间的权衡，建立与部分可观察 MDP 的数学联系。
- **跨本体迁移**：验证锚点条件和剪枝策略是否对双机械臂、四足机器人、灵巧手等不同形态保持收益。

---

### 10. 总体评价

SparkVLA 针对分层 VLA 中“何时停止”与“执行多长”的耦合问题，提出了一种优雅且工程上高度可实现的统一排序框架。该方法将两个独立接口简化为一个免阈值选择器，通过历史感知锚点和视觉剪枝显著提升了上下文建模与推理效率。实验设计系统、基线选择合理，尤其在 RoboCerebra 上大幅超越现有方法，并通过消融清晰证明了每个组件的作用。尽管存在基准覆盖、数据依赖和理论深度方面的不足，该工作仍为长时程操作中的接口设计提供了新的思路，具有较强的启发意义与实践价值。
