## 摘要
从现实世界数据中学习具身城市导航策略受到任务特定数据收集成本以及罕见但安全关键场景覆盖有限的制约。为了应对这些挑战，我们提出了一个可扩展框架，用于从网络规模的野外自我中心视频中学习点目标城市导航，同时系统地揭示其长尾分布。该框架自动为未整理的网络视频标注度量轨迹和结构化导航语义，然后用于训练视觉-语言-动作策略，以实现可解释的导航规划。我们基于模型性能以及感知-运动模式的分布来刻画长尾特征，并采用基于反思的分析来诊断反复出现的失败模式。在网页视频数据和真实世界城市导航任务上的实验表明，从不受约束的视频中进行的知识迁移是有效的，并揭示了超越总体导航性能的连贯长尾结构。

## Abstract
Learning embodied urban navigation policies from real-world data is constrained by the cost of task-specific data collection and the limited coverage of rare yet safety-critical scenarios. To address these challenges, we present a scalable framework for learning point-goal urban navigation from web-scale in-the-wild egocentric videos while systematically exposing its long tail. The framework automatically annotates uncurated web videos with metric trajectories and structured navigation semantics, which are then used to train a vision-language-action policy for interpretable navigation planning. We characterize the long tail based on model performance and the distribution of perception-motion patterns, and employ reflection-based analysis to diagnose recurring failure modes. Experiments on web-video data and real-world urban navigation tasks demonstrate effective knowledge transfer from unconstrained videos and reveal coherent long-tail structures beyond aggregate navigation performance.

- **核心问题**：如何获得可扩展的训练数据来源，并在此基础上**系统性地暴露和分析**那些平均性能指标无法反映的长尾失败模式？

## 二、论文提出的方法论

### 1. 核心思想
- 从互联网采集未整理的野外步行视频，自动标注为可训练的点目标（point-goal）城市导航样本，训练一个具有结构化推理能力的视觉-语言-动作（VLA）模型，并进一步通过"稀有度 + 难度 + 反思归因"三个维度揭示长尾结构。

### 2. 数据流水线（Step ①：自动化视频标注）
- **网络视频数据集**：收集约500小时、覆盖**30个城市、15个国家**的步行视频（包括纽约、东京、成都、迪拜、马德里、悉尼等），统一分辨率后切分为5分钟片段。通过 VLM 过滤移门、楼梯、电梯等超出通用地面平面导航范围的片段。
- **轨迹重建**：使用 LoGeR（长上下文几何重建框架）+ Pi3X（视觉几何骨干）估计每帧相机位姿与度量尺度深度，对齐后投影到地面平面形成连续轨迹。以1Hz采样，构建10帧导航片段（5帧历史 + 5帧未来），并将时间相邻片段分组后再划分数据集，防止重叠窗口跨分区泄漏。
- **元动作语义标注**：基于速度、侧向推进和运动方向的确定性几何规则，将有效未来轨迹映射到 **20种元动作（meta-action）**之一。
- **结构化导航推理标注**：先用 GroundingDINO 检测导航相关物体，获得归一化的物体类别、图像平面位置和深度标签；再用 Qwen3.6VL-27B 作为标注教师VLM生成结构化的**感知–分析–规划（perception-analysis-planning）**推理链。教师模型同时接收未来观测与规则推导的元动作作为特权验证证据，但被明确要求推理必须在历史和当前可观测线索上成立，避免在训练标注中引入未来信息泄漏。
- **数据规模**：最终生成超过 **50万条（500K+）**导航样本。

### 3. WILD-Nav 模型
- 骨干为 **Qwen3.5VL-4B** 视觉语言模型，视觉编码器在训练中冻结。
- 模型输入：5张历史观测图像 + 历史轨迹 + 局部点目标 + 任务提示；输出：结构化 CoT 推理、元动作、5个未来路点组成的可执行轨迹。
- 关键设计：引入特殊token `<PLAN_QUERY>`，其对应的语言模型隐状态作为**动作专家（action expert）**的输入接口，动作专家由两个轻量输出头组成——
  - **元动作头**：线性分类器，\( \hat{a}_t = \text{softmax}(W_a h_q + b_a) \)；
  - **轨迹头**：四层MLP（3个512维隐藏层 + GELU激活），\( \hat{\tau}^{\text{plan}}_t = f_{\text{mlp}}(h_q) \)。
- 推理变体：
  - **WILD-Nav-think**：先自回归生成完整结构化推理，再附加 `<PLAN_QUERY>` token 做一次额外前向计算动作，动作显式依赖完整推理链；
  - **WILD-Nav-inst**：`<PLAN_QUERY>` 放在推理文本之前，利用因果注意力不能看到后续文本的特性，可在一次前向中直接输出规划，同时把 CoT 作为辅助训练目标（效率优化变体）。

### 4. 多任务监督学习
- 三个互补损失：
  - **CoT语言建模损失** \( \mathcal{L}_{\text{cot}} \)：对生成的推理token做自回归交叉熵；
  - **元动作交叉熵损失** \( \mathcal{L}_{\text{act}} \)；
  - **轨迹MSE损失** \( \mathcal{L}_{\text{traj\_mlp}} = \frac{1}{5}\sum_{k=1}^{5}\|\hat{p}_{t+k} - p_{t+k}\|_2^2 \)；
  - 总损失 \( \mathcal{L} = \lambda_{\text{cot}}\mathcal{L}_{\text{cot}} + \lambda_{\text{act}}\mathcal{L}_{\text{act}} + \lambda_{\text{traj}}\mathcal{L}_{\text{traj}} \)，动作专家使用比语言模型适配器更高的学习率。

### 5. 长尾发现方法（Step ②）
- **导航条件稀有度**：将开放词汇目标描述映射到归一化词汇表，构建感知特征（物体类别+图像位置+深度位置）与运动特征（元动作）的联合表征，使用平滑逆文档频率计算稀有度得分（公式见Eq. 8），联合稀有度越高代表包含更多稀少感知–运动组合。
- **模型依赖难度**：使用轨迹规划的平均位移误差（ADE）和终点位移误差（FDE）度量，取各自top-3%的并集作为困难集。
- **特权反思归因**：仅对困难集使用教师VLM进行反思式分析，利用未来观测和参考轨迹做回顾性校验，检查场景分析是否由观测历史支持、规划思路是否与目标一致、轨迹是否与元动作一致。ADE/FDE/稀有度分数被排除在反思提示之外，确保归因独立于挖掘标准。
- 对困难集进行 SVD + UMAP + HDBSCAN 聚类，将反思失败与特定场景簇关联。

## 六、主要结论与发现

1. **野外视频可以作为有效的可扩展导航监督**：WILD-Nav 在视频测试集上显著优于 UrbanNav 和 SocialNav。即使对比更强的 SocialNav 微调版，WILD-Nav-inst 在所有轨迹指标上降低至少53.4%误差。
2. **结构化推理对连续轨迹规划有益**：WILD-Nav-think 比 WILD-Nav-inst 减少 ADE 8.5%、FDE 4.2%，说明显式的感知–分析–规划推理链为路点生成提供有用的上下文信息。
3. **存在明显的 sim-to-real / video-to-real 域差距**：直接从视频迁移到真实数据时误差大幅升高（如 FDE 从0.068升至0.834），真实数据微调后显著恢复但未完全弥合，说明域差距主要由视角和运动约束差异导致。
4. **长尾结构是连贯而非随机的**：稀有度与难度仅有部分重叠（24.18%的困难样本是稀有的，14.48%的稀有样本是困难的），表明数据覆盖缺口和模型能力瓶颈**并非同一件事**；聚类分析显示失败模式具有**场景依赖性**——密集行人停下场景（C18）以规划和轨迹形状错误为主，滑板车–标志上下文（C47）存在规则和动作错误，交通标志场景（C60）放大规则违反，滑板车/自行车交互（C105/C141）暴露预测与碰撞风险缺陷。
5. **困难样本提供定向微调价值**：在固定困难集（fixed tail）上，困难样本微调比随机样本微调更有效（Test-hard FDE 从0.247降至0.165），但会损害全量分布性能；配合随机样本回放可实现最佳平衡（Test-all 保持低误差，Test-hard FDE 0.160）。

## 七、优点

1. **数据规模化思路清晰**：提出无需人工标注的端到端流水线，将500小时未整理网络视频转换为50万+带结构化推理的导航样本，自动化程度高。
2. **长尾暴露方法论新颖**：不依赖预定义的 corner-case 分类法，而是从数据的经验分布出发，通过**分布稀有性 × 模型难度**的双轴分解，将数据覆盖问题和模型能力问题区分开——这一视角比单一地找低频率类别更有解释力。
3. **特权反思归因的设计严谨**：教师模型获得未来观测和参考轨迹作为特权信息但仅用于验证/修正，并明确禁止在感知/分析/规划字段中引入未来事实；反思提示与挖掘标准（ADE/FDE/稀有度分数）隔离，避免归因偏差。
4. **模型架构具备实用价值**：通过 `<PLAN_QUERY>` 实现推理与规划的显式解耦，支持"先思考后规划"（think）和"一步规划"（inst）两种推理模式，兼顾性能与效率。
5. **消融实验有深度**：对增量微调数据（随机 vs 困难 vs 混合）的对比揭示了"定向困难样本 + 分布回放"的策略价值，为后续数据选择提供借鉴。
