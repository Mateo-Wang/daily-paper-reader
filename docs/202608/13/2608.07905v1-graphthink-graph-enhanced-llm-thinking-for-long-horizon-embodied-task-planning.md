## 摘要
使用基于LLM的规划器的具身代理常常面临物理幻觉、对长时程任务泛化能力差以及缺乏环境意识等问题。我们提出了GraphThink，一种新颖的框架，它集成了任务图以提供结构化的知识来支持稳健的规划，以及场景图以维护环境记忆用于事件驱动的重规划。具体而言，任务图通过上下文提示和迭代精炼引导LLM思考，有效缓解规划幻觉。此外，在GRPO框架内，任务图为训练LLM规划器提供了精细的奖励设计，增强了长时程规划能力并提高了泛化性。最后，由场景图驱动的事件驱动重规划模块实现了闭环的环境感知和错误纠正。GraphThink在ALFRED基准上达到了最先进的性能。特别地，我们的高层规划器在验证集和保留的长时程任务上均超越了领先的基于API的LLM，突显了其强大的零样本和少样本能力。额外的评估进一步证明了其对新颖任务和环境的强分布外泛化能力。

## Abstract
Embodied agents using LLM-based planners often struggle with physical hallucinations, poor generalization to long-horizon tasks, and lack of environmental awareness. We propose GraphThink, a novel framework that integrates a task graph to provide structured knowledge for robust planning and a scene graph to maintain environmental memory for event-driven replanning. Specifically, the task graph guides LLM thinking through contextual prompting and iterative refinement, effectively mitigating planning hallucinations. Furthermore, within the GRPO framework, the task graph offers delicate reward design to train the LLM planner, enhancing long-horizon planning capabilities and improving generalization. Finally, an event-driven replanning module, powered by the scene graph, enables closed-loop environment awareness and error correction. GraphThink achieves state-of-the-art performance on the ALFRED benchmark. In particular, our high-level planner surpasses leading API-based LLMs on both the validation set and held-out long-horizon tasks, underscoring its robust zero-shot and few-shot capabilities. Additional evaluations further demonstrate strong out-of-distribution generalization to novel tasks and environments.

### 1. 论文的核心问题与整体含义

- **研究背景**：具身智能体（Embodied Agent）需要依据人类指令在复杂环境中执行长时程任务（如导航、交互、操作物体等）。主流的层级式方法将任务分解为高层规划（将指令分解为子任务）和低层执行（将子任务映射为可执行动作）。
- **核心问题**：基于 LLM 的高层规划器在长时程具身任务中面临三大关键挑战：
  - **物理幻觉**：通用 LLM 缺乏物理世界常识，导致指令误解、规划幻觉，且随任务复杂度增加失败率上升。
  - **泛化能力差**：在有限领域数据上的监督微调（SFT）难以泛化到未见过的长时程任务，且需要昂贵的专家标注。
  - **环境感知不足**：现有重规划策略主要针对低层执行错误进行纠正，缺乏环境感知能力，无法检测"低层可执行但与指令意图相悖"的计划。
- **整体含义**：论文提出 **GraphThink**，一个双图增强的闭环规划系统，旨在通过结构化知识（任务图）和环境记忆（场景图）系统性解决上述问题，提升长时程具身任务规划的可靠性、泛化性和环境适应性。

### 2. 论文提出的方法论

GraphThink 由三个核心模块组成，形成"高层规划 → 低层执行 → 动态重规划"的闭环系统：

#### （1）高层规划与任务图（High-Level Planning with Task Graph）

任务图 \( G = (V, E) \) 是有向图，其中节点 V 表示子任务（如 PickupObject(obj)、PutObject(obj, rec)），边 E 表示子任务间的可行转换关系。

- **任务图构建**：
  - **节点设计**：子任务基于底层技能库，采用元类（Meta-classes）抽象 \( C := \{obj, rec, mov, spec\} \) 来泛化具体对象实例，提升跨环境泛化能力。
  - **边构建**：通过 LLM 辅助的转换兼容性分析，将各子任务抽象为结构化转换接口 \( \langle P_i, E_i \rangle \)（前置条件和效果），当 \( v_p \) 的效果满足 \( v_q \) 的前置条件且语义兼容时添加边。这种方式不依赖轨迹演示，可覆盖未观测到的可行转换路径。
  - **可扩展性**：新任务可通过相同的转换兼容性分析扩展图的节点和边，无需新的轨迹标注。

- **任务图提示（Prompt with Task Graph）**：将任务图的拓扑结构显式编码到 Prompt 中，指导 LLM 生成遵循图拓扑的子任务序列（每个子任务必须是前一个子任务的邻居节点）。

- **GRPO 训练（Group Relative Policy Optimization）**：在 GRPO 框架内，基于任务图设计精细化奖励函数：
  - **格式奖励 \( R_{fmt} \)**：约束模型输出符合 XML/JSON 格式。
  - **节点级奖励 \( R_{node} \)**：验证计划中对象的合法性（对象是否属于环境对象集）。
  - **边级奖励 \( R_{edge} \)**：验证相邻子任务对是否满足任务图的边约束。
  - **指令跟随奖励 \( R_{inst} \)**：两阶段设计——先奖励覆盖关键子任务的计划（0.5分），再奖励与 GT 计划完全一致的计划（1.0分），以此平衡多解性与意图对齐。
  - **总奖励**：\( R_{total} = R_{fmt} + R_{node} + R_{edge} + R_{inst} \)。

- **任务图验证（Verification）**：将任务图作为外部验证器，对生成的计划进行节点级合法性验证和边级合法性验证，对于非法子任务或转换，将错误信息反馈给 LLM 进行迭代修正（最多迭代 3 次），作为推理时的轻量级安全护栏。

#### （2）记忆感知低层策略（Memory-Aware Low-Level Action Policy）

- 将高层子任务翻译为可执行的低层原始动作。
- **主动缓存**：在前往目标任务对象的途中，主动检测并缓存其他可能需要交互的任务相关对象的位置和分割掩码，避免重复探索。
- **实例级判别**：对同类型多个对象维护单独交互记录，确保精确识别和一致放置（例如将两个相同玻璃瓶放入同一容器）。

#### （3）场景图动态重规划（Dynamic Replanning with Scene Graph）

- **任务感知场景图记忆**：构建紧凑的动态场景图 \( G_{scene} \)，由语义三元组 \( (o_i, r_{ij}, o_j) \) 组成，只关注任务相关对象（通常少于20个节点），减少视觉噪声。构建流程包括：关键对象提取 → 视点捕获 → 候选三元组生成（通过VLM）→ 场景图更新（带冲突感知校正）。
- **事件驱动重规划触发机制**：
  - **低层动作错误**：处理具体执行失败（如找不到物体、交互错误）。
  - **高层子任务完成**：在子任务完成检查点，主动评估当前计划是否与最终目标对齐，检测"可执行但目标偏移"的问题（如场景图显示微波炉在侧桌上但计划目标在台面上）。
- 所有重规划提案均受任务图约束，确保可行性。

### 6. 论文的主要结论与发现

1. **ALFRED 上达到 SOTA**：测试集 SR 67.71%（可见）/ 68.52%（不可见），领先最接近基线 6.17 个百分点，且不依赖元数据（metadata）或逐步指令。
2. **任务图有效抑制规划幻觉**：将任务图融入 Prompt 和 GRPO 训练显著提升规划质量，减少物理幻觉和非法子任务转换。
3. **图奖励增强泛化和零样本能力**：仅使用任务图奖励（无指令奖励）即可在验证集上平均获得 84.47% 的成功率，表明结构化图知识能独立提供规划基础技能。
4. **边约束是核心**：边级奖励比节点级奖励的消融差异更大，说明约束子任务转换关系对可行分解至关重要。
5. **两阶段指令奖励最优**："关键子任务覆盖 → 精确匹配"的渐进式奖励设计优于只用关键步覆盖或只用精确匹配。
6. **事件驱动重规划互补有效**：高层子任务完成触发和低层执行错误触发两种重规划机制互补，显著提升任务成功率（分别提升 4-5%）。
7. **强泛化能力**：在 AI2-Thor 新任务上零样本达到 80.5%，在 VirtualHome 跨环境传移具有竞争力（76.67%），且领域自适应后可达 88.89%。
8. **长时程鲁棒性**：在 12 子任务时仍保持 80.71% 规划成功率，远超 RAG-增强 GPT-5.2（22.40%）和 SFT（接近 0）。

### 7. 优点

1. **双图互补设计创新**：任务图（静态知识）与场景图（动态记忆）协同工作，前者提供规划的结构化约束，后者提供环境感知和重规划依据，既有理论深度又有实际效果。
2. **任务图构建自动化且可扩展**：基于 LLM 的转换兼容性分析，不需要人工标注或轨迹演示，可灵活扩展新任务和新动作原语，实用性较强。
3. **多解性奖励设计精巧**：通过元类抽象和图奖励支持多可行路径，配合两阶段指令奖励避免过度约束到单一 GT 轨迹，防止"奖励破解"。
4. **高效且低开销**：7B 模型 + 任务图约束即可超越大规模 API 模型（GPT-5.2 + RAG），推理时间稳定且明显低于 API 模型，推理时验证循环最多 3 次，开销可控。
5. **泛化验证全面**：覆盖新任务、新动作、新环境三个维度的泛化，实验可信度高。
6. **场景图紧凑高效**：任务驱动提取关键对象，节点数控制在 20 以内，避免冗余场景表示带来的噪声和推理开销。

7. **在部分任务类型上缺乏细粒度报告**：虽然整体指标领先，但未按 7 种 ALFRED 任务类型分开报告成功率，存在某种任务类型表现较差的可能性。
8. **重规划依赖 LLM 判断质量**：高层子任务完成时的语义评估依赖 LLM 的常识推断，当场景信息不完整或 VLM 给出错误关系时，可能触发不必要或错误的修正，影响执行效率。
