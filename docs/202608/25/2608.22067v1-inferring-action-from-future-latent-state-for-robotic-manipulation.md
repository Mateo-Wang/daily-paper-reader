## 摘要
世界-动作模型（WAMs）将机器人控制建立在视频生成骨干网络上，该网络联合预测密集的未来视觉轨迹和机器人动作。我们认为，对于世界-动作建模而言，视频生成是一个不必要的中间目标。对于机器人操作，世界模型的目标不是重现世界在每个中间时刻的外观，而是预测执行动作后世界将达到的状态。中间帧仅描述了物理状态之间的视觉过渡，这消耗了大量的模型容量和计算量，但并不直接指定机器人动作旨在产生的物理结果。在本文中，我们提出了DELE-w0.5，它不依赖视频生成，直接从预测的未来状态推断机器人动作。具体来说，DELE-w0.5从其对应的紧凑的未来潜在状态推断动作序列。未来潜在状态捕获了机器人交互中与动作相关的物理结果，并作为世界建模和动作生成之间的显式桥梁。DELE-w0.5的核心设计原则是模拟物理世界在机器人动作下如何变化，而不是其视觉外观如何逐帧演变。这种表述消除了密集视频表示带来的高维视觉冗余，从而实现了更廉价的训练和低延迟推理。在四个长时域操作任务的480次真实机器人试验中，我们的DELE-w0.5在所有对比策略中取得了最佳性能，实现了62.5%的总体完整任务成功率和81.3%的宏观有序阶段进展，分别超过最强基线47.5和30.7个百分点。

## Abstract
World-Action Models (WAMs) build robot control on video-generation backbones, which jointly predict dense future visual trajectories and robot actions. We argue that video generation is an unnecessary intermediate objective for world-action modeling. For robotic manipulation, the goal of a world model is not to reproduce how the world looks at every intermediate moment, but to predict the state that the world will reach after an action is executed. The intermediate frames only describe the visual transition between physical states, which consumes substantial model capacity and computation, but do not directly specify the physical outcome that the robot action is intended to produce. In this paper, we propose DELE-w0.5, which infers robot actions from predicted future states without relying on video generation. Concretely, DELE-w0.5 infers the action sequence from its corresponding compact future latent state. The future latent state captures the action-relevant physical outcome of robot interaction and serves as an explicit bridge between world modeling and action generation. The core design principle of DELE-w0.5 is to model how the physical world changes under robot actions, rather than how its visual appearance evolves frame by frame. This formulation removes the high-dimensional visual redundancy introduced by dense video representations, and it therefore enables cheaper training and low-latency inference. Across 480 real-robot trials on four long-horizon manipulation tasks, our DELE-w0.5 achieves the best performance among all compared policies, attaining 62.5 overall full-task success and 81.3 macro ordered-stage progress, outperforming the strongest baseline by 47.5 and 30.7 percentage points, respectively.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：具身智能在机器人操作领域快速发展，形成了两条主流技术路线：
  - **Vision-Language-Action（VLA）模型**：基于视觉-语言模型（VLM）骨干，将语言指令和视觉观测映射为机器人动作，但信息密度低、泛化性差，对光照、颜色变化敏感。
  - **World-Action Models（WAMs）**：将世界状态预测与动作生成统一在一个端到端学习目标中，通过大规模视频数据上的自监督未来状态预测获得时空先验。
- **核心问题**：现有基于视频生成的 WAM 存在**结构性错配**：
  - 视频生成的目标（逐帧重建视觉外观）与控制的目标（产生正确的物理结果）不一致。
  - 中间帧只描述视觉过渡，不直接决定机器人后续动作对应的物理结果。
  - 多帧视频潜变量远大于动作序列本身，在序列长度、内存和计算预算上占据主导地位。
  - 推理时需要在高维未来视频-动作潜变量上迭代去噪，控制回路被视觉轨迹合成所阻塞。
- **论文的核心论点**：对于机器人操作，世界模型**不应当重建世界的完整视觉演化过程**，而只需要预测与动作因果相关的**紧凑未来潜在状态**。视频生成是"不必要的中间目标"。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 核心思想

- **重定义世界模型目标**：从"预测世界看起来如何"转变为"预测世界将变成什么状态"。
- **从未来状态推断动作**：DELE-w0.5 直接推断紧凑的、与动作相关的未来潜在状态，再从该状态生成动作，完全避免视频生成。
- 三种建模框架的概率推断对比：
  - VLA：$p_\theta(\mathbf{A}_t | \mathbf{O}_t, \mathbf{q}_t, \mathbf{L})$
  - WAM：$p_\theta(\mathbf{A}_t, \mathbf{O}_{t:t+\Delta t} | \mathbf{O}_t, \mathbf{q}_t, \mathbf{L})$
  - DELE-w0.5：$p_\theta(\mathbf{A}_t, \mathbf{O}_{t+\Delta t} | \mathbf{O}_t, \mathbf{q}_t, \mathbf{L})$（只预测单一未来状态，不预测中间视频）

### 2.2 关键输入与表征

- **语言指令**：使用 Qwen3 文本编码器进行 token 化。
- **视觉观测**：使用 DINO-v3 视觉编码器，将多视角 RGB 图像压缩为潜在空间向量（机器人具有三个视角：头戴视角 + 每个手臂的腕部视角）。
- **动作空间**：单臂为 7-DoF（3-DoF 相对位置 + 3-DoF 欧拉角 + 1-DoF 夹爪二值状态），双臂为 14-DoF；动作块长度 $H = 60$。
- **时间步嵌入**：采用多尺度位置编码（余弦/正弦频率）加两层 MLP 映射。

### 2.3 双流注意力架构

模型由两个核心模块组成：

- **条件流（Condition Stream）**：
  - 将语言 token 和当前视觉 token 拼接，通过单流自注意力块实现跨模态交互。
  - 输出通过 AdaLN（自适应层归一化）调制：$\boldsymbol{\gamma}_c = 1 + W_{\text{AdaLN}} \mathbf{t}_c + b_{\text{AdaLN}}$。
  - 生成查询、键、值（Q/K 采用 ℓ2 归一化，即 QKNorm）。

- **噪声流（Noise Stream）**：
  - 对动作块和未来状态分别添加噪声：
    - $A_t^{\tau} = \tau A_t + (1 - \tau)\epsilon$
    - $z_{t+\Delta t}^{\tau} = \tau \hat{z}_{t+\Delta t} + (1 - \tau)\epsilon$
  - 执行与条件流相同的注意力和投影操作。

- **注意掩码设计（关键创新）**：
  - **训练时**：语言和当前观测彼此双向注意力；动作 token 只关注条件组和自身；未来观测 token 关注所有组。
  - **推理时**：移除未来观测 token，只预测动作序列，不生成任何未来视觉 token——这显著缩短推理序列、降低延迟。

### 2.4 流匹配目标（Flow Matching Objective）

- 动作损失：$L_a = \mathbb{E}\left[\|u_a(A_t^{\tau}, z_{t+\Delta t}^{\tau}, q_t, l) - (A_t - \epsilon)\|_2^2\right]$
- 未来状态损失：$L_o = \mathbb{E}\left[\|o_a(A_t^{\tau}, z_{t+\Delta t}^{\tau}, q_t, l) - (\hat{z}_{t+\Delta t} - \epsilon)\|_2^2\right]$
- 总损失：$L = L_a + \lambda L_o$（$\lambda$ 用于平衡动作学习与未来状态预测）。
