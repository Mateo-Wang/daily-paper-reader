## 摘要
用于物理交互的世界模型通常被训练用于预测未来的观测或潜在特征；然而，面向规划的模型必须回答一个根本不同的问题：候选动作是否能在保持关键关系的同时产生与任务一致的未来。 monolithic 的状态表征掩盖了底层实体，而标准的实例级对象槽仅识别存在“什么”，却没有指明每个实体在任务情境中扮演“什么角色”。为弥合这一鸿沟，我们提出了语义丰富世界模型（SR-WM），一种以任务为条件的世界模型，围绕五个功能角色构建：夹爪、目标、目的、关系和阶段。在 SR-WM 内部，视觉实体编码器从预训练的 patch 特征中提取软实体假设，使得分割掩码能够作为可选的提议先验，而无需将其强制作为必需的状态表征或推理输入。随后，一个角色绑定器将这些假设映射到特定任务角色，同时一个以动作条件为条件的动力学模型预测角色转换以及细粒度语义，包括抓取/接触、谓词建立、关系保持、夹具状态和阶段变化。至关重要的是，这一统一的角色状态为下游的多候选动作生成、阶段感知重排序和违反感知后缀重采样提供了基础。我们的综合评估协议涵盖全部四个 LIBERO 模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这一表述将对象中心预测转变为连接视觉动力学与面向规划的决策的语义接口。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task-consistent future while preserving essential relations.Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify \emph{what} is present without specifying \emph{what role} each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase.Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs.A role binder subsequently maps these hypotheses to task-specific roles, while an action-conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change.Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling.Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action-sensitivity analysis.Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making.

## 1. 核心问题与研究动机

传统世界模型（World Models）通常被训练用于预测未来的观测、像素或潜在特征，其优化目标是降低预测误差。然而，**低预测误差并不能保证动作对任务决策有用**——一个看似合理的未来可能接近了错误物体、丢失了抓取、破坏了已完成的子目标，或过早松开物体。规划本质上需要回答的问题是：**某个候选动作是否产生与任务一致的未来，同时保持关键关系不被破坏**。

现有方法的不足：

- **Monolithic 状态表征**：将场景编码为一个整体向量或特征图，掩盖了底层实体及其交互关系，难以判断特定实体在任务中的角色。
- **实例级对象槽（Instance-level slots）**：只能识别“场景中存在什么实体”，但无法说明每个实体在任务上下文中扮演什么角色。例如，胡萝卜和容器不会自动表明哪个是目标（target）、哪个是目的（goal）、抓握是否成立、需要满足什么谓词、何时应该释放。
- 语言条件分类器仅将语言作为全局上下文或后验读头，**没有将任务角色纳入世界模型自身的预测状态空间**。

因此，论文提出了 **语义丰富世界模型（SR-WM）**，将任务感知的角色绑定（role binding）引入世界模型的预测与规划接口，弥合视觉动力学与规划决策之间的语义鸿沟。

## 2. 方法论

### 2.1 核心思想

SR-WM 将任务条件化的状态空间构建为**五个不可交换的功能角色（functional roles）**：

| 角色 | 语义含义 |
|------|----------|
| **Gripper（夹爪）** | 末端执行器的位姿、开度、运动、接触、抓取状态 |
| **Target（目标）** | 任务相关的物体或铰接部件及其几何信息 |
| **Goal（目的）** | 容器、表面、目的地或期望的夹具状态 |
| **Relation（关系）** | 夹爪-目标、目标-目的之间的几何与符号谓词 |
| **Phase（阶段）** | 接近、抓取、搬运、对齐、释放、完成等进度状态 |

核心流程：**视觉观测 → 可交换实体假设（Entity Hypotheses）→ 任务条件角色绑定（Role Binding）→ 角色状态 Zt → 动作生成/语义动力学预测/选择与修复**。

### 2.2 技术细节

**（1）轻量级 LeWM 基础**
- 使用 15M 参数的 LeWM（5M ViT-Tiny 编码器 + 10M Transformer 预测器）作为基础架构，保留其预训练目标，增加角色模块、语义头、选择器和 FM 动作头。
- 完整系统（SR-WM + FM head）共 **45.4M 参数**。

**（2）软实体编码器**
- 利用预训练 patch 特征，通过可学习的跨视图查询提取 N 个软实体，每个实体的表征包括：外观（appearance）、几何（geometry）、运动（motion）、置信度（confidence）。
- 实体保持“软”性质：不必与分割掩码一一对应；不确定或被遮挡的物体可将证据分布到多个 patch。

**（3）可选分割先验**
- Grounding-DINO + SAM/SAM2 产生的 proposal-to-patch 亲和度仅作为加性注意力偏置（additive attention bias），而非硬性状态输入。
- 训练时对 proposal 集合、掩码、偏置强度进行三重 dropout；推理时 λseg = 0 即为无掩码推断。
- 该设计旨在验证：分割只是可选结构先验，patch 本身编码了任务关键的语义几何。

**（4）任务条件角色绑定**
- 五个非交换的角色查询（role queries）以语言指令和本体感觉为条件，通过交叉注意力从软实体中读取任务相关状态：

```
br,n = softmax_n( qr(ℓ, qt)^T k(et,n) / √d + ur^T gt,n )
zr_t = Σ_n br,n v(et,n)
```

- 目标/目的查询依赖指令 token；夹爪查询包含本体感受；关系和阶段是抽象状态成分而非物理槽。
- 同一视觉实体在不同指令下可绑定为目标、目的或不相关干扰物，无需重学实体编码器。

**（5）动作条件角色动力学**
- 动作编码器将每个候选动作块划分为 J 个有序子段，角色 Transformer 交替执行角色间自注意力与动作交叉注意力，通过门控残差更新：

```
Δzr,k_j = Drθ(Zk_{t,j-1}, Ea(Ak_{t,j}), ℓ)
ẑr,k_{t,j} = zr,k_{t,j-1} + σ(gr,k_j) ⊙ Δzr,k_j
```

- 门控机制允许不受影响的角色保持静态，预测 J 个中间状态而非仅端点，用于定位违规发生的最早边界。

**（6）语义过渡监督**
- 在每个子段边界预测：接触/抓取状态、谓词建立、谓词保持、合取条件满足、阶段身份与合法阶段转换、夹具状态（抽屉位移、微波炉门角、炉子激活）。
- 建立（establishment）与保持（preservation）分开监督，因为一个动作可能同时满足新谓词并破坏旧条件。
- 通过**硬负样本**（打乱段序、反转接近-抓取顺序、替换轨迹、扰动释放时序）进行排序训练，确保模型对因果动作顺序敏感：

```
Lshuf = max(0, m − Sω(Zt, A+t) + Sω(Zt, A−t))
```

**（7）候选生成、选择与修复**
- **FM 动作头**：以角色状态为条件，从 K 个独立噪声样本生成 K 个候选动作块。
- **阶段感知选择器**：综合阶段、接触、建立、保持、夹具有效性和预测不确定性，对 K 个候选并行打分。
- **违规感知后缀修复**：若最高得分低于阈值或预测到违规，保留有效前缀，仅对最早违规边界 j* 之后的后缀进行掩码式 FM 重采样（masked inpainting），而非丢弃整个块。

**训练目标**：共 11 项损失，分为三组——表征/状态构建（LeWM + 角色绑定 + 状态动力学）、语义过渡（接触/谓词/保持/阶段/夹具）、动作与决策（FM 动作 + 硬负样本排序 + 后缀修复）。

## 6. 主要结论与发现

1. **角色状态提升生成质量**：替换 monolithic latent 为 SR-WM 角色状态后，Candidate 0 成功率从 45.5% 提升至 62.8%，Oracle@4 覆盖率从 68.0% 提升至 89.5%——说明角色结构不仅改善了后验排序，还改善了候选生成本身。
2. **语义选择器有效转化覆盖率**：语义选择器将覆盖率转化为 75.3% top-1 成功率；后缀修复进一步提升至 **83.0%**。
3. **分割掩码是可选而非必需**：无掩码的 patch-only SR-WM 仍达 72.6% 成功率，损坏掩码仅降至 70.8%，先验掩码上界 78.4%，验证了弱依赖声称。
4. **动作敏感性来自语义监督**：移除语义头使排序准确率跌至 60.8%；移除混洗负样本使决策边际坍塌至 0.018（近似随机 53.7%）。
5. **渐进式角色结构带来单调增益**：55.0%（实例槽）→ 62.0%（+语言）→ 68.0%（+目标/目的）→ 73.0%（+关系）→ 83.0%（完整 SR-WM）。
6. **角色表征促进跨任务迁移**：Object 套件预训练模型在 Goal 套件适应后达 74.6%（vs 从头训练 66.3%），在 LIBERO-10 达 58.7%（vs 50.6%）；联合预训练进一步在留出任务上达 78.4%。
7. **完整系统轻量高效**：45.4M 参数、30.2ms 生成延迟、单卡 A100 即可训练。

## 7. 优点

1. **概念创新**：将对象中心预测从“识别实体”升级为“绑定任务角色”，使世界模型的隐状态空间直接对齐规划决策所需的语义变量，填补了实例槽与任务规划之间的鸿沟。
2. **状态即接口**：角色状态同时用于 FM 动作生成、动力学预测、语义过渡监督、选择器和修复模块，而非后验语义分类器，形成了统一的语义界面。
3. **弱依赖分割先验**：通过 proposal dropout 和可选的注意力偏置机制，使模型在实际部署时不依赖分割掩码，表3 的实验设计严谨地证明了这一点。
4. **硬负样本与动作敏感性**：打乱段序、反转顺序等负样本显式训练了模型对动作因果顺序的敏感性，实验显示该组件对决策边际至关重要。
5. **因果透明**：J 个中间状态的预测 + 最早违规边界定位 + 前缀保留式修复，使系统具备可解释性和局部可修复性。
6. **实验协议严谨**：分离生成/选择/覆盖率、匹配初始状态与候选集、严格 checkpoint 门槛、明确信息访问边界、失败分类学（表S12）和部署门控协议（表S13），学术方法论值得借鉴。
7. **效率意识**：在 15M backbone 基座上加语义模块，完整系统控制在 45.4M 参数，配合单卡训练和 30ms 级别推理延迟，更具实用性。

## 8. 不足与局限

1. **五角色本体假设的适用性有限**：适用于单臂、单目标、目标导向的操作任务；无法天然覆盖双臂操作、多目标并行、可变形物体、工具使用等更复杂场景。作者也承认可能需要可变基数状态图。
2. **标签依赖问题**：谓词、阶段、夹具状态的监督标签在仿真中廉价，但在物理系统上需要仔细标注或估计，限制了直接部署的可行性。
3. **感知失败的容忍度有限**：可选掩码降低了特定分割器的依赖，但不能消除遮挡或绑定失败；在精细插入类任务中仍可能出现目标中心丢失和谓词过早判断。
4. **离散阶段与高频控制不匹配**：阶段监督的离散性质可导致上下文错位——模型可能在运输轨迹中提前一个阶段触发释放，且 receding-horizon 控制器缺乏细粒度触觉反馈来中止和重新抓取。
5. **没有物理实验（real-world）验证**：仅在仿真中验证；附录中的物理部署协议（G节）只是描述性规定，论文未报告物理实验结果。
6. **修复增加推理开销**：前缀保留修复需要额外推理调用，在安全关键执行中若无碰撞检查和底层保护不适合直接使用。
7. **Oracle@K 不可过度解读**：高 oracle 覆盖率不代表部署性能；若 top-1 选择弱，高 oracle 只表明选择器问题未解决。
8. **未报告训练时长与详细超参数**：声称超参数等实现元数据不在此文范围内，降低了复现便利性。跨套件适应也缺少数据量与计算预算的精细数值。
