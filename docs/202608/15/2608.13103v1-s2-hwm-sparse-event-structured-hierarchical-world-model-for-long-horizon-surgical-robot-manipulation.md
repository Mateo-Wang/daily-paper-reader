## 摘要
长时程手术机器人操作具有挑战性，因为任务奖励稀疏，而有意义的交互变化以不规则的间隔发生。现有的世界模型智能体通常以原始步长分辨率进行想象，使得可变持续时间的任务进展隐含其中。手动指定的阶段可以提供中间结构，但其任务特定边界难以与状态相关的交互转换对齐。我们提出了S2-HWM，一种稀疏事件结构化的层次世界模型，它从原始潜在轨迹中学习稀疏事件证据，以协调事件级管理器和原始步长工作器。事件证据调度管理器目标更新，每个选定的潜在目标条件化工作器的原始动作，直到下一次更新。学习到的事件证据还为事件转换模型（ETM）形成可变持续时间片段，该模型预测下一个边界随机状态、片段持续时间和累积片段奖励。将这些事件级预测链接起来，提供了超出原始想象视野的可变持续时间延续，用于管理器学习，而工作器保留原始步长的演员-评论家学习。在基于SurRoL的PegTransfer任务中，S2-HWM实现了98.7%的成功率，比平坦的GAS DreamerV3基线高出22.7个百分点。

## Abstract
Long-horizon surgical robot manipulation is challenging because task rewards are sparse, while meaningful interaction changes occur at irregular intervals. Existing world-model agents typically imagine at primitive-step resolution, leaving variable-duration task progress implicit. Manually specified stages can provide intermediate structure, but their task specific boundaries are difficult to align with state-dependent interaction transitions. We propose S2-HWM, a Sparse Event-Structured Hierarchical World Model that learns sparse event evidence from primitive latent trajectories to coordinate an event-level manager and a primitive-step worker. The event evidence schedules manager goal updates, and each selected latent goal conditions the worker's primitive actions until the next update. The learned event evidence also forms variable-duration segments for an Event Transition Model (ETM), which predicts the next?boundary stochastic state, segment duration, and accumulated segment reward. Chaining these event-level predictions provides a variable-duration continuation beyond the primitive imagination horizon for manager learning, while the worker retains primitive-step actor-critic learning. On a SurRoL-based PegTransfer task, S2-HWM achieves a success rate of 98.7%, outperforming the flat GAS DreamerV3 baseline by 22.7 percentage points.

## 1. 核心问题与整体含义

- **研究问题**：长时程手术机器人操作（如从抓取、运输到放置的长时间序列）面临奖励稀疏、成功信号延迟、且有意义的交互状态变化以不规则时间间隔发生的问题。
- **现有方法的不足**：
  - 现有世界模型智能体（如 DreamerV3）以**原始步长（primitive-step）分辨率**进行想象，只能捕捉局部动态，无法显式表达“事件何时结束、持续多久、段内累积多少奖励”等高层时间结构。
  - 手动指定任务阶段虽然能提供中间结构，但阶段边界是事先固定、面向特定任务的，难以与状态依赖的交互转换对齐。
- **研究意义**：提出自动从潜在轨迹中学习“稀疏事件证据”，在不需语义阶段标注的前提下，将事件级时间抽象与原始步控制结合，解决长时程稀疏奖励下的信用分配问题。

## 2. 方法论

- **核心思想**：S2-HWM 学习一个稀疏上下文更新机制产生事件证据，该证据同时用于：
  1. **调度管理器目标更新**（何时切换高层意图）；
  2. **构造事件转移模型（ETM）** 的可变时长训练片段，实现事件级预测。
- **基础世界模型**：使用 DreamerV3 风格的循环状态空间模型（RSSM），在每个原始步更新潜在状态。特征表示为：
  - `ft = [zt, ht, mt]`，其中 `zt` 为随机状态，`ht` 为确定性记忆，`mt` 为持久交互上下文。
- **稀疏上下文动态**：
  - 通过上下文模型预测候选更新 `˜mt` 和软门控 `ρt`（逐维），并用 straight-through 二值化得到稀疏证据 `gt`。
  - `mt = ρt ⊙ ˜mt + (1−ρt) ⊙ mt−1`，正则化限制过度更新。
  - `gt` 经不同接受规则聚合后形成各自的事件边界（管理器更新点与 ETM 分段边界可以不重合）。
- **层次策略**：
  - 在每个接受的更新点 `τi`，管理器观察边界特征 `Fi`，从离散码书 `E` 中采样一个码 `ci`，得到潜在目标 `ηi = E(ci)`；
  - 工作器条件于当前特征和该目标输出原始动作：`at ~ πW(· | ft, ηi)`，直到下一更新点。
- **事件转移模型（ETM）**：
  - 每个事件段 `ei = [τi, τi+1)`，ETM 以起始边界事件状态 `xe_i = [zτi, mτi]` 为输入；
  - 预测下一边界随机状态 `ze_{i+1}`、段时长 `∆i` 和段累计奖励 `Ri`；
  - 引入内部类别变量 `ui`（transition mode）建模多模态转移，训练时用后验 `q(ui|xe_i, ze_{i+1})`，想象时用先验最可能模式。
- **事件扩展管理器 Bootstrap**：
  - 原始步想象得到短视终端估计 `Bshort = VM(˜fH)`；
  - 从同一端点继续 K 个 ETM 转移，得到事件级延续 `Bevent`；
  - 最终管理器目标：`BM = (1−ω)Bshort + ωBevent`；
  - 工作器仍保持原始步 actor–critic 学习，不受事件级 bootstrap 影响。

## 6. 主要结论

- S2-HWM 在单次 PegTransfer 上达到 **98.7±2.3%** 成功率，比 GASDreamerV3（76.0±12.0%）高出 **22.7 个百分点**；PPO 和 DreamerV2 在相同预算下无法解决任务。
- 在重复转移和扰动压力测试中，S2-HWM 仍保持最高成功率（91.3±6.1% 和 88.0±5.3%），显著优于基线和各消融变体。
- 消融结果表明：
  - **层次策略**最关键（去掉后退化为 flat actor，成功率降到 68.0±20.3%）；
  - **事件门控更新**次之（固定周期更新降到 80.7±28.3%，且跨种子方差大幅增加）；
  - **ETM 延续**提供进一步增益（单次转移下降 7.4 个百分点，在重复转移+扰动中扩大到 20.7 个百分点）。
- 诊断实验显示 ETM 的多事件预测误差增长慢于 RSSM，支持事件级延续能减少递归误差积累并扩展管理器 bootstrap 的设计动机。
- 管理器码在无语义监督下仍产生与语义阶段相关的工作器行为差异（如抓取阶段垂直调整和夹爪动作增多，抬升阶段上升动作占优，放置阶段横向修正为主）。

## 7. 优点

- **方法创新性强**：将学习到的稀疏事件证据作为共享接口，统一了高层的管理器调度和事件级动态建模，避免了手工阶段划分。
- **双时间尺度设计合理**：管理器获得超出原始想象视野的事件级价值 bootstrap，工作器仍保持原始步 actor–critic 精度，兼顾长期规划与短期控制。
- **减少误差累积**：ETM 直接做边界到边界的预测，不需要递归预测每个中间原始状态，从而限制了多步预测误差的复合。
- **实验对照严谨**：与最相关的 GASDreamerV3 在相同视觉前端、动作接口和 DreamerV3 骨干下对比，并通过消融逐项验证各组件贡献。
- **有机理分析**：不只报成功率，还提供了预测误差随事件数的增长趋势分析和行为-代码关联分析，使结果更具解释力。
