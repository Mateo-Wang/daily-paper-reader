## 摘要
多模态大语言模型（MLLM）能够整合长视觉历史，在部分可观测性下进行推理，并从少量示例中推断行为。然而，视觉-语言-动作（VLA）模型通常继承预训练表示，而不将其这种上下文能力用作情景记忆。依赖记忆的策略通过专门构建的历史机制来解决这一差距。相反，PonderPounce复用MLLM原生的因果上下文作为机器人记忆。Ponder，一个System2 MLLM，在其原生因果上下文中累积情景观察、演示和先前的认知，并可以生成用于内部使用的子目标文本和演示推理。Pounce，一个System1 VLA，直接接收当前观察、指令和本体感觉；通过Ponder-Pounce接口，它异步地仅接收最新的连续认知标记及其年龄。两者在没有专门构建的记忆模块或单独的桥接预训练的情况下联合端到端训练。优化的服务实现了认知刷新78ms和动作模型调用25ms的p50延迟，支持20Hz动作播放。在具有基础规模训练数据的RoboMME上，PonderPounce在相同的Pounce架构和接口下，以9B达到60.83%，以0.8B达到50.04%，而FrameSamp+Modul为44.51%，当前观察π_{0.5}为17.93%。在9倍数据下，它达到75.54%，而FrameSamp+Modul为57.88%。在RoboCasa-DC上，同一接口仅从动作监督中学习，达到12.5%，而最强的已发表演示条件基线为11.6%；当认知被学习到的空状态替代时，降至8.6%。

## Abstract
Multimodal large language models (MLLMs) can integrate long visual histories, reason under partial observability, and infer behavior from a few examples. Yet vision-language-action (VLA) models generally inherit pretrained representations without using this contextual capacity as episode memory. Memory-dependent policies address this gap through purpose-built history mechanisms. PonderPounce instead reuses an MLLM's native causal context as robot memory. Ponder, a System2 MLLM, accumulates episode observations, demonstrations, and prior cognition in its native causal context and can generate subgoal text and demonstration reasoning for internal use. Pounce, a System1 VLA, receives the current observation, instruction, and proprioception directly; through the Ponder--Pounce interface, it asynchronously receives only the newest continuous cognition token and its age. Both are jointly trained end to end without a purpose-built memory module or separate bridge pretraining. Optimized serving achieves p50 latencies of 78ms for cognition refresh and 25ms for action-model invocation, supporting 20Hz action playback. On RoboMME with base-scale training data, PonderPounce reaches 60.83% with 9B and 50.04% with 0.8B under the same Pounce architecture and interface, versus 44.51% for FrameSamp+Modul and 17.93% for the current-observation π_{0.5}. With 9x data, it reaches 75.54% versus 57.88% for FrameSamp+Modul. On RoboCasa-DC, the same interface learns from action supervision alone and reaches 12.5% versus 11.6% for the strongest published demonstration-conditioned baseline, falling to 8.6% when cognition is replaced by a learned null state.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：机器人操控任务常依赖当前观察中不存在的信息（如被遮挡的物体、先前发生的事件、指代对象的身份、演示过的操作流程）。这类"记忆依赖型控制"要求策略具备跨时间整合信息的能力。
- **现有研究缺口**：
  - 多模态大语言模型（MLLM）天然具备长视觉历史整合、部分可观测条件下推理、少样本行为推断等能力；
  - 但视觉-语言-动作（VLA）模型通常只继承 MLLM 的预训练表示，并未将其上下文能力用作"情景记忆"（episode memory）；
  - 已有记忆增强策略依赖专门设计的历史机制，如帧采样（FrameSamp+Modul）、分割记忆库（SAM2Act+）、键帧检索（MemER）、递归语言记忆（MEM）、感知-认知外部记忆库（MemoryVLA）、部署时快速权重更新（RoboTTT）等，这些方法均引入额外的采样器、存储器、检索路径或压缩器。
- **作者的核心主张**：可否直接复用预训练 MLLM 的原生因果上下文（native causal context）作为机器人记忆，而不需要任何专用记忆模块？这一设计点被称为"将预训练 MLLM 作为情景上下文引擎"。
- **整体含义**：论文展示了"记忆作为预训练上下文能力"这一新设计空间——System 2 的认知容量可作为独立设计轴，在不改动快速控制器架构的前提下扩展，为记忆依赖型机器人控制提供了一种更简洁、可扩展的范式。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 核心思想：双系统异步协作

- 沿用 Kahneman 双过程理论术语：
  - **PONDER（System 2）**：9B 预训练 MLLM（Qwen3.5-9B），负责累积情景上下文、演示和内部推理，慢节奏运行；
  - **POUNCE（System 1）**：预训练 VLA 动作模型（π0.5 3.6B 或 GR00T N1.5 3B），运行于快速动作路径上。
- 两者通过"连续认知令牌（continuous cognition token）+ 其年龄（age）"这一最小化接口异步连接，且**无需专用记忆模块、无需单独桥接预训练**，端到端联合训练。

### 2.2 PONDER（System 2）的工作流程

- 在查询时刻 t，PONDER 将当前观察 O_t **追加**到只增（append-only）的因果上下文中，其中包含指令、可选演示 D_{1:n}、内部生成的子目标文本与演示推理、以及先前的认知载体；
- PONDER 首先预测转移令牌 T_t ∈ {T_Yes, T_No}：
  - 若 T_t = T_Yes，则在插入载体位置前生成子目标文本 S_t（在演示情景的首次执行转移处，演示推理 DR 位于 S_t 之前）；
  - 若 T_t = T_No，载体直接跟在观察之后；
- 载体位置的最终隐藏状态构成认知 C_t ∈ R^{K×H}，无需解码或池化；
- DR 和 S_t 仅用于监督 PONDER 的 LM 头，**保持 System 2 内部私有**，不输入 POUNCE。

### 2.3 POUNCE（System 1）的动作生成

- 每次调用 j 时，POUNCE 接收：指令、当前观察 O_j、本体感觉，以及由最新就绪认知及其正弦编码年龄构成的前缀；
- 若无就绪认知，使用学习到的空认知 C_∅ 且年龄 Δ(j)=0；
- 输入前缀形式：P_j = [e_Δ(j), W_c * eC_{j,1}, ..., W_c * eC_{j,K}]；
- 动作头预测动作块 A_{1:h}，以 20Hz 播放。

### 2.4 训练与监督

- 总损失：**L = w₁L_fm + w₂L_ground**
  - L_fm：动作流匹配 MSE；
  - L_ground：令牌交叉熵，覆盖转移目标 T*_t、标注转移处的子目标文本 S_t，以及演示情景首次执行处的演示推理 DR。
- 训练时教师强制（teacher-forcing）转移目标和文本载荷；推断时 PONDER 自回归预测；
- 动作梯度通过 C_t 反向传播到 PONDER，进入 PONDER 的动作梯度缩放为 0.5，以防止多个 POUNCE 调用累积的梯度压过 LM 头监督；
- 无标注时（如 RoboCasa-DC）w₂=0，仅靠动作监督学习。

### 2.5 异步调度机制

- 两个模型时钟独立推进：调度器选取满足"源观察时间 + 计算延迟 ≤ POUNCE 调用时间"的最新 PONDER 查询作为认知来源；
- 训练时 RoboMME 采用对数正态采样：POUNCE 约 100ms、PONDER 约 1s 间隔、300ms 计算延迟，使每个状态暴露于多种年龄；
- 评估时两个模型均固定 1Hz 时钟、300ms 延迟、20Hz 动作播放。

### 2.6 推理优化

- 使用 Append-only StaticCache 会话，仅编码新令牌，避免因果上下文重编码（认知仅刷新 p50 78ms，45 令牌子目标触发 p50 820ms）；
- 融合 Triton 内核将 POUNCE 延迟从 142ms 降至 25ms（5.7×），支持 1Hz 模型时钟 + 20Hz 动作播放。

## 6. 主要结论与发现

- **原生 MLLM 上下文是强记忆基底**：RoboMME 上 PONDER-POUNCE 达 60.83%（1×）与 75.54%（9×），分别超出 FrameSamp+Modul 16.32 和 17.66 个百分点；当前观察 π0.5 仅 17.93%，加入过去动作后也仅 19.73%，凸显记忆依赖任务的难度与本文方法的有效性；
- **不是普遍最优**：FrameSamp+Modul 在 Imitation 家族与 9× Counting 上仍更强，说明直接帧复用对模仿型任务仍有价值；
- **更大的预训练上下文引擎可提升控制**：相同 POUNCE 架构和接口下，9B PONDER 比 0.8B 高出 10.79 个百分点（60.83% vs 50.04%），且保持离线动作路径不变；
- **认知刷新对控制至关重要**：仅保留转移时状态会使成功率从 60.83% 暴跌至 1.83%；离线诊断显示认知越陈旧损失越高，但慢刷新训练可换取陈旧鲁棒性（4s 训练检查点在 4.3s 年龄下损失仅 1.14×）；
- **监督信号显著影响性能**：去演示推理监督降至 48.21%，去全部 LM 头监督降至 27.96%；
- **连续认知与子目标文本接口精度相当**：60.83% vs 59.96%（0.87pp 差距小于运行间 2.63pp 波动）；
- **接口可迁移**：RoboCasa-DC 上无 LM 头监督仍达 12.5%（认知禁用降至 8.6%），支持跨具身演示条件化场景；
- **推理优化有效**：静态缓存 + 融合内核支持实时 20Hz 动作播放。

## 7. 优点（方法与实验设计亮点）

- **设计简洁优雅**：直接复用 MLLM 原生因果上下文，消除专用记忆模块、检索策略、历史压缩器，将"记忆机制设计"问题转化为"接口设计"问题；
- **双系统解耦**：System 2 容量可作为独立扩展轴，9B 上下文模型增大不改动快速控制器架构，兼顾能力与实时性；
- **最小化接口**：仅传输"认知令牌 + 年龄"两个信息，对控制器架构侵入性极小，且证明该接口可跨两种不同 VLA（π0.5 和 GR00T N1.5）迁移；
- **异步调度设计**：训练时通过对数正态间隔采样暴露多种认知年龄，使模型学会在非同步时钟下工作；
- **内部文本监督策略**：子目标文本与演示推理仅监督 LM 头、保持 System 2 内部私有，避免离散文本进入动作路径的延迟与信息损失；
- **丰富的诊断性分析**：通过刷新干预、陈旧认知离线诊断、规模对照等多角度实验，不仅报性能数字，还试图解析"什么使认知通道有效"；
- **工程实现扎实**：报告了完整的延迟剖析（H100/A100、多种编译路径对比、p50/p95），且优化幅度显著（5.7× 加速）。

## 8. 不足与局限

- **监督公平性问题（最重要）**：RoboMME 中 PONDER 获得模拟器生成的转移门、子目标和演示推理标注，而基线（如 FrameSamp+Modul）未获得同等推理监督，结论反映"架构 + 监督"的混合效应，无法分离二者贡献；
- **标注成本未测量**：模拟器模板标注的生产成本未被量化，向真实环境迁移时（如使用 VLM 生成标签）效果未知；
- **实验覆盖有限**：
  - 仅两个仿真基准，无真实机器人验证；
  - RoboCasa-DC 仅 5 个未见任务、绝对成功率偏低（12.5%），属于"接口可迁移的初步证据"而非广泛跨具身泛化；
  - 认知载体仅测试 K=1，未做宽度扫描；
- **推断-训练接口不匹配**：评估时固定 1Hz 时钟且从不使用空认知路径或陈旧状态复用，与训练分布存在差异；
- **干预实验的解释力受限**："仅转移时刷新"干预未训练稀疏传输策略，无法排除匹配训练下稀疏交付的有效性；陈旧诊断将认知与报告年龄同步改变，无法分离二者各自贡献；
- **预训练收益未在匹配收敛条件下验证**：随机初始化 9B 训练不稳定（0.00%），只能说明当前端到端配方依赖预训练初始化，无法量化预训练本身的增益；
- **额外计算成本**：9B 上下文模型 + 3–3.6B 控制器带来额外的训练与推理开销；append-only 上下文限制为 16K tokens；延迟剖析仅针对 batch-1 调用，未评估并发吞吐与能耗；
- **基线缺陷**：RoboCasa-DC 已发表基线未提供不确定性信息，无法进行统计显著性检验。
