## 摘要
本文介绍了具身场景重排规划（ESRP），这是一项新颖的任务，要求具身智能体仅使用以自我为中心的观察和自顶向下的目标布局，在3D场景中重新排列家具以匹配目标配置。与之前的重排任务不同，ESRP排除全局状态访问，并引入相互物体遮挡，反映了现实世界机器人部署的实际约束。这些因素使得将局部以自我为中心的观察与全局目标布局对齐，对于长视野规划尤其具有挑战性。为了促进研究，我们提出了ESRP-Bench，一个基于OmniGibson构建的综合基准，包含5,400多个场景对和8,200个物体。我们定义了三个多级指标来评估重排质量，并提供了四种基线方法：一种分层任务与运动规划方法、一种基于视觉语言模型的方法，以及两种基于学习的方法（IL和RL）。实验结果表明，现有方法难以高效完成任务，凸显ESRP作为具身智能体在场景理解与长视野任务规划中面临的挑战性前沿。这项工作为在现实场景中部署智能代理迈出了垫脚石。项目页面：https://pie-lab.cn/ESRP/。

## Abstract
This paper introduces Embodied Scene Rearrangement Planning (ESRP), a novel task requiring embodied agents to rearrange furniture in 3D scenes to match a target configuration using only egocentric observations and a top-down target layout. Unlike prior rearrangement tasks, ESRP precludes global state access and introduces mutual object occlusions, reflecting the practical constraints of real-world robotic deployment. These factors make aligning partial egocentric observations with the global target layout particularly challenging for long-horizon planning. To facilitate research, we present ESRP-Bench, a comprehensive benchmark built on OmniGibson featuring over 5,400 scene pairs and 8,200 objects. We define three multi-level metrics to evaluate rearrangement quality and provide four baselines: a hierarchical task-and-motion planning method, a vision-language-model-based method, and two learning-based approaches (IL and RL). Experimental results demonstrate that current methods struggle to complete the task efficiently, highlighting ESRP as a challenging frontier for embodied agents in scene understanding and long-horizon task planning. This work serves as a stepping stone toward deploying intelligent agents in real-world scenarios. Project page: https://pie-lab.cn/ESRP/.

## 2. 论文提出的方法论

- **任务定义**：
  - **观测**：每时间步由三部分组成——(i) 自我中心RGB图像（128×128）；(ii) 目标布局的俯视RGB图像（128×128）；(iii) 二进制夹爪状态指示（是否正在抓取物体）。
  - **动作空间**：`A = {move_forward, move_backward, turn_left, turn_right, fetch, release}`，其中前四个为导航原语，后两个为操作原语；旋转固定为22.5°，平移固定为0.25米。
  - **成功条件**：所有可重排物体均正确归位；物体2D包围盒与目标包围盒的IoU > 0.3。
  - **终止条件**：达到最大时间步L（超时失败）或所有物体成功归位（任务成功）。
- **数据集构建（ESRP-Bench）**：
  - 基于**3D-FRONT**数据集，在**OmniGibson**仿真器中构建；
  - 共**5,495个场景**、覆盖**24种房间类型**、**8,213个可移动物体**（柜/架/桌3,718、椅1,721、沙发453、凳/墩298、其他772）；
  - 按难度分层：**Easy（1个物体）、Medium（2-3个）、Hard（4-6个）**；
  - **目标布局获取**：采用3D-FRONT中专业设计的布局，渲染128×128俯视正交RGB图像；
  - **初始布局生成**：从目标布局出发，通过规则化模拟随机移动物体，得到无碰撞的初始位置，保证存在可行解——**反向构造**策略确保任务可行性。
- **四种基线方法**：
  1. **ESRP-BC（模仿学习）**：基于**扩散策略（Diffusion Policy）**，使用两个ResNet-50编码器分别处理自我中心观测历史和目标图像，通过条件1D U-Net去噪预测长度为8的动作序列；损失函数结合扩散去噪损失和交叉熵损失；
  2. **ESRP-PPO（强化学习）**：使用PPO算法，CNN视觉编码器 + 单层LSTM（上下文长度64）+ MLP输出动作；配置了包含成功奖励（+10）、接近/离开信号（±1）、势函数奖励、抓取奖励（+0.01）等在内的密集奖励；
  3. **ESRP-VLM（基础模型）**：基于**Qwen3-VL-2B-Instruct**的多模态**ReAct**智能体，交替进行推理和动作输出，无需任务特定微调；
  4. **ESRP-PLAN（规划方法）**：利用特权全局信息的**分层任务与运动规划（TAMP）**框架——任务规划器决定重排顺序，运动规划器使用BFS（导航至物体）和A*（导航至目标）规划无碰撞路径。

## 6. 论文的主要结论与发现

- **当前方法在ESRP上表现不佳**：即使最强的ESRP-PLAN（享有全局特权信息）SR仅达30.20%，而在Hard场景下骤降至0%，说明多物体长视界重排极具挑战性。
- **感知瓶颈与规划瓶颈并存**：
  - 学习类方法（PPO、BC、VLM）与特权规划的差距反映了**从自我中心视角推断全局场景状态**的困难；
  - 即使ESRP-PLAN在Hard场景仍失败（0% SR），说明**多物体重排的组合复杂度**本身就是独立于感知的挑战。
- **放置是最核心的瓶颈**：三种非特权基线中60%以上的失败发生在**放置阶段**（Stage 3），而非导航或抓取阶段，表明精准放置是ESRP的核心难点。
- **更强的VLM先验有帮助但不够**：替换为Gemini 2.5 Flash-Lite后性能显著提升，但距实际部署仍有很大差距。
- **简化操作抽象合理**：尽管使用了“魔术吸附”式的高层操作原语，现有方法在复杂场景仍大量失败，说明瓶颈在于长视界规划和部分可观测下的空间推理，而非抓取力学本身。

## 8. 不足与局限
