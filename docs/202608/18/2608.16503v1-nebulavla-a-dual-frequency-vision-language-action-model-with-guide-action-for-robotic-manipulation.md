## 摘要
视觉-语言-动作（VLA）模型在现实世界中的部署常常受到效率-性能权衡、跨实体泛化和执行平滑性的制约。我们提出了NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，从而优化计算资源和模块化。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来确保运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成速度提升了约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

  2. **跨本体泛化困难**：不同机器人（灵巧手、夹爪、机械臂）形态差异大，现有连续运动学到离散token的映射需要庞大词汇表和海量演示数据，缺乏统一动作语义。
  3. **执行平滑性不足**：异步实时推理与动作块生成之间的时间错位常引发显着抖动和动作不连续，影响真实部署可靠性。
- **整体意义**：论文提出NebulaVLA，通过双频架构、统一动作表示和引导动作机制，试图系统性地解决上述三大问题，为VLA模型从实验室走向真实高效部署提供了一条结构化路径。

## 2. 论文提出的方法论

### 2.1 核心思想：快慢双系统认知范式
借鉴卡尼曼“系统1/系统2”认知理论，将**深思熟虑的高层推理（10 Hz VLM）**与**反应式的低层控制（20 Hz DiT生成器）**解耦，打破单一频率的刚性约束。

### 2.2 关键技术细节

#### （1）NebulaVLA架构
- **System 2（S2）**：以Qwen3-VL为骨干，处理自然语言指令和稀疏视觉输入（约10 Hz），通过可学习token提取隐藏层特征，输出抽象动作引导（GESTURE-7轨迹）。
- **System 1（S1）**：以Q-Former压缩S2引导信息，结合高频视觉输入（20 Hz，DINOv2编码器）与动作历史，通过扩散Transformer（DiT）去噪过程生成执行动作。S1还引入了对比微调和Guide Action机制。
- **异步解耦**：S1与S2通过显式数据流规范解耦，天然支持分布式部署，最小化交互延迟。

#### （2）GESTURE-7：统一语言化动作表示
- 将末端执行器状态编码为7维向量：**[x, y, z, r, p, w, gesture]**
  - x,y,z：笛卡尔位置（整数厘米）；
  - r,p,w：方向角roll/pitch/yaw（整数度）；
  - gesture：自然语言关键词（如“grasp”“push”），不同本体执行相同动作共享同一关键词。
- 优点：量化至整数减少学习负担；自然语言关键词统一跨本体语义；支持强化学习（RL）奖励设计。

#### （3）Guide Action：引导动作机制
- **灵感来源**：图像外扩（Image Outpainting/RePaint），将动作块拼接嵌入生成过程，取代传统RTC或后处理平滑方法。
- **实现方式**：用前一动作块中**未执行的轨迹点**（如a4–a7）作为先验条件，引导下一动作块生成，并通过**二值掩码M**在扩散去噪过程中强制保留锚点区域（M=1），仅对生成区域（M=0）进行预测。
- **条件概率模型**：`pθ(A(t-1)_full | A(t)_full, A_prior, τ)`，其中`A_prior`为已执行历史动作+引导动作，τ为时间位置编码。
- **训练细节**：引导点数量随机采样0~3，适应推理延迟变化。

#### （4）三阶段训练流程
- **Stage 1：S2监督微调（SFT）**——五类任务：姿态回归、关键点回归、2D路点预测、3D轨迹预测（2 Hz）、思维链（CoT）生成（子任务分解+GESTURE-7轨迹），直接以Qwen3-VL原始权重初始化，避免大规模预训练导致灾难性遗忘。
- **Stage 2：S2强化学习（GRPO）**——保留相同任务套件，设GESTURE-7距离奖励（位置+方向+手势一致性）、关键点定位奖励、路点奖励（含DTW距离）、3D轨迹奖励、格式奖励。
- **Stage 3：S1监督微调**——联合优化S1/S2权重（视觉编码器冻结），采用L2损失监督连续动作输出，加权流匹配损失蒸馏S2先验，损失仅计算掩码M=0的新生成区域。

## 5. 主要结论与发现

- **性能领先**：NebulaVLA在LIBERO-Plus上平均成功率85.5%，超过InternVLA-M1（81.3%）4.2%、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和π0.5（58.0%），在多数扰动维度上保持最优或接近最优。
- **效率提升显着**：异构双频架构将推理延迟从同频的115ms降至42ms，动作生成加速约2.7倍，同时提升真实任务成功率（Task 1：87.14%→92.08%；Task 2：90%→92.5%）。
- **平滑性改善**：Guide Action使所有关节加加速度下降，平均降低25.6%，关节12和13分别降41.2%和45.1%，有效消除异步执行中的边界抖动。
- **三阶段训练有效**：Stage 1 SFT显著提升Layout维度（+6.2%），Stage 2 RL进一步强化Language和Layout性能，全流程比省略SFT/RL分别高1.7%和2.5%。

## 6. 优点（方法与实验亮点）

- **架构创新性强**：异步双频设计（10Hz+20Hz）打破了同步VLA的刚性效率-性能权衡，兼具学术启发价值与工程部署可行性（原生支持分布式）。
- **统一表示优雅**：GESTURE-7以7维连续向量+自然语言关键词实现跨本体动作语义统一，天然兼容RL，且有量化+语言标签的双重降维设计，降低学习难度。
- **平滑性内化处理**：Guide Action将轨迹连续性约束直接嵌入扩散生成过程（掩码强制保留锚点），避免后处理插值带来的语义不一致，创新性地将图像外扩思想迁移至动作块生成。
- **训练策略细致**：三阶段渐进式训练（SFT→RL→S1蒸馏），并针对RL设计了包含格式奖励、DTW距离等多种奖励函数，保证结构一致性。
- **实验报告较全面**：同时报告成功率、推理延迟和关节加加速度三类指标，仿真与真实场景互补。
