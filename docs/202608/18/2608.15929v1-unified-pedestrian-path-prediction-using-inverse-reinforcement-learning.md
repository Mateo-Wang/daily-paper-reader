## 摘要
行人路径预测对于提升自动驾驶车辆和高级驾驶辅助系统的安全性至关重要。以往的研究探索了行人路径预测的不同学习任务表述，并使用浅层神经网络比较了这些表述，但未将这一分析扩展到更复杂的深度学习模型。本文将时空图注意力网络（STGAT）适配到统一的行人路径预测框架中，并引入了特定于STGAT的状态和动作定义。所得到的表述支持确定性策略和随机策略、一次性决策和序列决策，以及包括REINFORCE和近端策略优化在内的强化学习算法。与标准的监督学习表述相比，所提出的学习任务表述在选定的基准数据集上提升了预测性能。这些结果表明，重新表述决策过程和训练目标可以改进先进的行人轨迹预测架构，并可能为改进其他基于图的预测模型提供一条途径。

## Abstract
Pedestrian path prediction is crucial for enhancing the safety of autonomous vehicles and advanced driver-assistance systems. Previous studies explored different learning-task formulations for pedestrian path prediction and compared these formulations using shallow neural networks, but did not extend this analysis to more complex deep-learning models. This paper adapts the Spatial-Temporal Graph Attention Network (STGAT) to a unified pedestrian path prediction framework and introduces state and action definitions specific to STGAT. The resulting formulations support deterministic and stochastic policies, one-time and sequential decision-making, and reinforcement-learning algorithms including REINFORCE and proximal policy optimization. The proposed learning-task formulations improve prediction performance across the selected benchmark datasets compared with the standard supervised-learning formulation. These results demonstrate that reformulating the decision process and training objective can improve an advanced pedestrian trajectory prediction architecture and may provide a path toward improving other graph-based prediction models.

## 2. 方法论

### 2.1 核心思想
将行人路径预测建模为强化学习（RL）任务，纳入统一 MDP 框架，并在 STGAT 架构上设计新的状态（state）与动作（action）定义，以支持不同学习任务表述：
- **一次决策（ODM）**：一步输出完整未来 12 步轨迹（单 episode、单步）；动作 `a₀ = (p̂₉, …, p̂₂₀)`。
- **序列决策（SDM, BEP 扩展）**：逐步预测未来 12 步，每步一个动作（单 episode、12 步）；状态由历史观测与已预测位置共同构成。

### 2.2 关键技术细节
- **架构**：STGAT = 编码器（G-LSTM + M-LSTM + GAT）+ 解码器（D-LSTM）。仅改变学习任务表述，不改变模型内部结构。
- **状态与动作设计**：
  - 初始状态 `s⁰` 为场景中所有行人的 8 步观测位置；
  - 模型输出分解为每个行人的独立 episode，共享同一 MDP 模板；
  - ODM 中动作维度为 24（12 步 × 2 坐标），SDM 中动作维度为 2（当前步坐标）。
- **专家目标（IRL）**：奖励函数定义为预测与真实轨迹间的平方 L2 距离：
  `rₜ = ‖(ŝₜ, âₜ) − (sₜ*, aₜ*)‖²₂`，回报为累积折扣奖励。
- **训练算法**：
  - 确定性策略：SL-MSE（监督学习）、SL-MSE-SDM；
  - 随机策略：SL-MSE-SPG（随机策略梯度）、REINFORCE（有无基线）、PPO（有无基线）；
  - 值网络：两种架构——“完整状态基线”（复用 STGAT 编码器 + 3 层 DNN）与 “简化基线”（仅单行人观测输入）。

## 6. 主要结论与发现

1. **确定性策略（SL-MSE-SDM）优于标准 SL-MSE**：在 λ=0.4 时，所有数据集上 ADE 降低约 2%–13%，表明联合建模预测与决策过程能提升精度。
2. **随机策略 + 先进 RL 算法有效**：PPO 配合完整状态基线在所有数据集上相对 SL-MSE 有 4%–11% 的 ADE 降低（如 ETH 4%、Hotel 11%）。
3. **简单的 REINFORCE 效果不稳定**：因梯度方差高，部分子集（Zara1、Univ）表现差于监督基线。
4. **值网络设计重要**：完整状态基线显著优于简化基线（REINFORCE 下 Univ 最高提升 27%）；PPO 对两种基线不敏感。
5. **统一框架潜力大**：改进不依赖架构修改，可推广至更广泛的 SOTA 图注意力预测模型。
