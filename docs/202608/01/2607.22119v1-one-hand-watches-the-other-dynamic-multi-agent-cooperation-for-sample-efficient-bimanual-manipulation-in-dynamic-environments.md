## 摘要
多流机器人操作策略通过相对于环境参考系对动作进行建模，实现了无与伦比的样本效率和泛化能力。然而，现有方法通常假设这些参考系是严格外生的。这种因果假设在动态环境中会失效，例如当单个机器人手臂操作移动物体或两只手臂协调时，每只手臂实际上都成为另一只手臂动态环境的一部分。我们提出了DynaMAC，一个轻量级、策略无关的框架，它解决了这一因果局限，同时保留了多流策略的样本效率、计算速度和灵活性。DynaMAC将另一只手臂视为动态任务参数，从而为动态操作和双臂协调提供了统一的表述，无需显式的领导者-跟随者关系。为了严格评估这些能力，我们引入了DynaBench，一个用于动态环境中机器人操作的新型基准。在动态环境和双臂操作任务中，DynaMAC在样本数量减少20倍的情况下，比领先的概率和生成基线高出超过35个百分点。关键在于，DynaMAC能够从静态演示零样本泛化到动态环境，大幅简化了数据收集，并为迈向人机协作建立了一座优雅的桥梁。

## Abstract
Multi-stream robot manipulation policies achieve unparalleled sample efficiency and generalization by modeling actions relative to environmental reference frames. However, existing approaches typically assume these frames to be strictly exogenous. This causal assumption collapses in dynamic settings, such as when a single robot arm manipulates a moving object or when two arms coordinate, where each arm effectively becomes part of the dynamic environment of the other. We propose DynaMAC, a lightweight, policy-agnostic framework that resolves this causal limitation while preserving the sample efficiency, computational speed, and flexibility of multi-stream policies, DynaMAC treats the opposite arm as a dynamic task parameter, thereby providing a unified formulation for dynamic manipulation and bimanual coordination without requiring an explicit leader-follower relationship. To rigorously evaluate these capabilities, we introduce DynaBench, a novel benchmark for robot manipulation in dynamic environments. Across both dynamic environments and bimanual manipulation tasks, DynaMAC outperforms leading probabilistic and generative baselines by over 35 percentage points while requiring 20 times fewer samples. Crucially, DynaMAC generalizes zero-shot from static demonstrations to dynamic environments, substantially simplifying data collection and establishing an elegant bridge toward human-robot collaboration.

- 多流（Multi-Stream）策略学习通过在多个物体中心坐标系中建模动作分布，在样本效率和泛化能力上取得了显著成功，是目前模仿学习中极具前景的方向。
- 但这类方法隐含一个重要因果假设：**参考坐标系（任务参数）必须是严格外生的**，即参考系的运动不受机器人自身行为影响，仅单向地指导机器人动作（f → ξ_ee）。
- 该假设在三类重要场景中会崩溃：
  1. **动态环境**：例如从运动中的传送带上抓取工件时，物体在抓取前是外生参考系，但在被抓取后其位姿完全由机器人决定，因果方向反转（ξ_ee → f），继续将其当作独立任务参数会导致模型崩溃。
  2. **多智能体协作**：另一智能体的动作会持续改变相关任务参考系，例如交接、协作搬运等。
  3. **双臂操纵**：许多任务（开瓶盖、搬运大物体）需双臂协调，而现有大多数多流策略仅支持单臂操作。
- 论文核心意义在于：提出一个统一框架，将**动态环境操纵、多智能体协作、双臂协调**三类问题统一为"动态多流学习"（Dynamic Multi-Stream Learning），从而在不牺牲多流策略原生优势的前提下解决上述因果失效问题，并建立从静态演示到动态环境的零样本泛化桥梁。

## 二、方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- **DynaMAC**（Dynamic Multi-Agent Cooperation）是一个轻量级、策略无关（policy-agnostic）的框架，可作为外围层部署在任何多流策略之上。
- 关键洞察：**通过推断机器人末端执行器与任务物体之间的运动学链接（kinematic link），动态过滤掉已与末端执行器产生因果耦合的参考系，从而恢复任务参数的外生性**。
- 在双臂操纵中，**将另一只手臂的末端执行器视为一个动态任务参数**，从而无需显式的领导者-跟随者（leader-follower）关系或独立协调模块即可实现协调；主从角色可由任务参数选择自然涌现。

### 2.2 技术细节

**第一步：技能分割（Skill Segmentation）**
- 使用 TAPAS 将长程演示分割为较短技能段，并在每个技能内进行后续分析。

**第二步：运动学链接分析（Kinematic Link Analysis）**
- 当机器人抓取物体后，该物体对应流（stream）的方差骤降至接近零，表明末端执行器与物体之间存在强互信息。
- 为量化链接强度，定义几何平均标准差（Geometric Mean Standard Deviation）：
  - `M(f)_t = |det(Λ(f)_t)|^{-1/(2d)}`，其中 `Λ(f)_t = (Σ(f)_t)^{-1}` 是流 f 在时间 t 的精度矩阵，d = 6 为状态维度。
- 当 `M(f)_t < τ_M` 时（如 τ_M = 0.001 ≈ 1 mm/rad），判定该物体与末端执行器存在运动学链接，将其从任务参数集中过滤掉。
- 短暂的高精度峰值（如预抓取阶段）可通过时间方差过滤等方法忽略。

**第三步：虚拟末端执行器帧补充（Virtual Frame Supplementation）**
- 被过滤的动态物体帧可能导致后抓取阶段缺乏空间参考。
- 解决方案：在每个技能开始时记录末端执行器位姿，作为**静态虚拟帧**加入候选集。
- 该虚拟帧不仅驱动后抓取行为（如抓取后的抬升），还充当原始的"空间记忆"，使策略能回到操作前的起始位置。

**第四步：任务参数选择（Task-Parameter Selection）**
- 使用 TAPAS 的相对精度准则，对剩余动态物体帧和新增虚拟帧进行筛选：
  - `ω(f) = max_t det(Σ(f)_t)^{-1} / Σ_c det(Σ(c)_t)^{-1}`
  - 选择 `ω(f) > τ_ω` 的帧作为该技能使用的任务参数。
- 逐技能选择后再将技能策略序列化为完整长程任务。

**双臂操纵的统一表述**
- 将左侧手臂的末端执行器位姿 ξ_left 加入右侧手臂的候选任务参数集（反之亦然）。
- 以 HandOver 为例：`p(ξ_right | ξ_left)` 建模左臂对右臂的因果影响；若双方互为参考，则两个方向的流都体现这种相互影响。
- 相比传统的 leader-follower 架构，该方法无需预定义主从关系，角色可动态变化；相比单体策略（monolithic policy），动作空间不膨胀，样本效率得以保留。

### 2.3 信息论视角

- 论文指出了一个理论连接：条件熵 `H(ξ_ee|f) ∝ log det(Σ_f)`，因此互信息 `I(ξ_ee; f) = H(ξ_ee) − H(ξ_ee|f)` 与 `−log det(Σ_f)` 成正比。
- TAPAS 的任务参数选择本质上是在最大化互信息；DynaMAC 则通过运动学链接检测来隔离互信息激增的病态情形。

## 六、主要结论与发现

1. **因果崩溃是动态场景中多流策略失效的根源**：标准多流策略在动态环境中完全失败（MiDiGaP 在动态任务中成功率接近 0），证实了外生性假设破坏的严重性。
2. **DynaMAC 恢复外生性并统一三类问题**：通过运动学链接检测、虚拟帧补充和任务参数选择，一个统一框架可同时处理动态环境、多智能体协作和双臂操纵，无需显式协调模块或主从关系。
3. **显著的性能与效率优势**：在单臂动态任务中，DynaMAC 在样本量少 20 倍的情况下比 Diffusion Policy 高出 35 个百分点；数据等量时优势扩大至 89 个百分点。在动态双臂任务中平均成功率 0.96，远超所有基线。
4. **零样本动态泛化**：仅用静态演示训练的策略可在动态环境（平滑移动和突变瞬移）中零样本直接部署，大幅简化数据收集。
5. **对扰动的鲁棒性**：当任一手臂的轨迹被外部扰动时，另一手臂可动态重新协调，这为未来人机协作应用奠定了基础。
6. **真实世界验证**：在双臂 Franka 机器人上验证了仿真结论，并在人参与交接任务中零样本泛化成功。

## 七、优点

- **理论清晰**：将多流策略的失效精确归结为因果方向反转，并以互信息/条件熵的信息论视角统一解释任务参数选择和运动学链接检测，架起了与任务图生成工作的理论桥梁。
- **统一框架**：三类问题（动态环境、多智能体协作、双臂协调）首次被纳入同一个简洁、无主从关系的框架。
- **策略无关的模块化设计**：可作为轻量级外围层叠加在任何多流策略（GMM、GP、Flow Matching）上，不干扰基础策略的内部结构，且兼容 TAPAS 等已有组件。
- **极具实用价值**：零样本静态→动态泛化意味着无需收集动态演示就能部署到动态环境；对扰动和遮挡的鲁棒性为真实场景的人机协作开辟了道路。
- **开源开放**：代码、模型、基准环境全部公开，DynaBench 基于 RLBench 生态构建，兼容其他扩展，便于社区使用和扩展。

## 八、不足与局限

- **对技能分割的依赖**：DynaMAC 建立在 TAPAS 的技能分割基础上，若任务难以自动分割为离散技能，框架可能失效。论文承认这是继承自多流范式的结构性限制。
- **依赖外部视觉模块**：需要外部视觉编码器提供任务参数估计，感知误差（论文中真实世界主要失败原因）会直接限制整体性能。
- **遮挡问题**：在无参考物的自由空间交接中，若物体被遮挡、只能依赖物体跟踪时，性能急剧下降（论文已明确记录该脆弱性）。
- **动态场景覆盖面有限**：DynaBench 的动态模型基于静态构型间插值/瞬移，尚未涵盖更复杂的物体动力学（如非线性运动、多阶段动态），论文也指出未来可整合 DOMINO 的先进动态模型。
- **双臂任务静态场景中未超越基础方法**：在静态双臂任务中，DynaMAC 与 MiDiGaP 性能相等（0.95），说明两者在存在明确空间焦点的静态场景中并无显著差异，DynaMAC 的优势需结合其额外机制（动态过滤、虚拟帧）理解。
- **真实世界评估的深度有限**：单相机、固定摄像机视角、单一机器人平台、每条件 25 回合的样本量，且未对多样物体类型、多相机配置或不同机器人平台进行全面评估。
