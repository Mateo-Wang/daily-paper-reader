## 摘要
视觉与语言导航（VLN）使机器人能够在未见过的环境中遵循指令行动。近期，一种免训练范式应运而生：机器人查询多模态大语言模型以理解观察并规划下一步动作。然而，基于图像流或密集地图的长时程导航不可避免地带来不断增长的内存与推理瓶颈。我们提出HAM-VLN，一种决策耦合、由智能体自主生成的记忆机制，为机器人装备了持久且基于深度信息的世界图。在与选择下一步动作相同的模型调用中，HAM-VLN还记录语义与反思信息——包括房间类型、物体、导航进度及失败笔记。近期航点以原样保留在有界窗口内，而较早的历史仅通过基于相关性、近时性与显著性的检索，辅以单跳拓扑扩展重新进入上下文。该设计除每个航点的决策调用外，无需额外的大语言模型调用。与先前方法相比，HAM-VLN不仅提升了多种导航指标，还将上下文长度缩减超过65%。具体而言，HAM-VLN在VLN-CE R2R上达到61.0%的成功率（SR），在VLN-CE RxR上达到52.7%的SR，并在HM3D-v2 ObjectNav上无需任何训练即达到79.7%的SR。

## Abstract
Vision-and-language navigation (VLN) enables robots to follow instructions in previously unseen environments. Recently, a training-free paradigm has emerged: the robot queries a multimodal LLM to understand its observations and plan the next action. However, long-horizon navigation based on either image streams or dense map inevitably introduces a growing memory and reasoning bottleneck. We present HAM-VLN, a decision-coupled, agent-authored memory that equips the robot with a persistent, depth-grounded world graph. In the same model call used to select the next action, HAM-VLN also records semantic and reflective information---including room type, objects, navigation progress, and failure notes. Recent waypoints remain verbatim within a bounded window, while older history re-enters the context only through retrieval scored by relevance, recency, and salience, together with one-hop topological expansion. This design requires no additional LLM calls beyond the per-waypoint decision. Compared to previous methods, HAM-VLN not only improves various navigation metrics but also reduces the context length by more than 65%. Specifically, HAM-VLN achieves 61.0% Success Rate (SR) on VLN-CE R2R, 52.7% SR on VLN-CE RxR, and 79.7% SR on HM3D-v2 ObjectNav without any training.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **任务背景**：视觉与语言导航（VLN）要求机器人在未见过的环境中，依据自然语言指令进行导航并到达目标位置。零样本范式下，机器人通过查询多模态大语言模型（MLLM）来理解观测并规划下一步动作。
- **核心瓶颈**：长时程导航中，无论是基于**图像流**还是**密集语义地图**的历史表示，都存在根本性缺陷：
  - **Dense Semantic Map（密集语义地图）**：存储量随覆盖面积增长，且内容构建与导航决策脱节；
  - **Raw Visual History（原始视觉历史）**：将过往全景图直接追加进模型上下文，上下文长度随轨迹不断膨胀，关键地标会被淹没，且过去的死胡同不会自动标记为需避开的路径。
- **关键洞察**：已有方法虽然让历史观测"可用"，但MLLM并未参与决定"哪些信息值得保留供后续决策使用"。
- **本文目标**：将**智能体记忆（Agentic Memory）**引入导航循环，使记忆维护与决策过程耦合，在有限上下文内保留任务相关的长程导航状态。

## 2. 论文提出的方法论

### 2.1 核心思想
HAM-VLN构建一个**决策耦合、由智能体自主生成（agent-authored）**的记忆系统：在每次MLLM调用选择动作的同一时刻，同时完成记忆写入；近期观测保留在有界窗口内，而更早的历史仅在需要时通过结构化检索重新进入上下文。

### 2.2 双过程架构
策略被分解为两层：

- **System 2（慢速、深思熟虑的规划器）**：使用大型MLLM（Gemini-3.1-Pro），在每个航点读取自然语言指令 T、当前观测 Ot、记忆上下文 Mt，输出高层决策——前进方向、回溯到某历史航点、或验证停止。输出同时携带结构化JSON记录：动作、地点语义、观测物体、指令进度更新、失败笔记。
- **System 1（快速、反应式的接地策略）**：轻量MLLM（Qwen3.6-35B），将System 2选择的方向接地到像素空间——预测目标边界框，通过深度图和相机内参进行3D反投影，再由确定性控制器执行短程轨迹。

### 2.3 分层智能体记忆
记忆上下文构造公式：**Mt = Wt ⊕ Lt ⊕ R(Gt, qt)**，其中：

- **Wt（工作记忆）**：最近 K 个航点的原始帧（实验中 K=1）；
- **Lt（指令进度记录）**：有序的指令执行进度；
- **R(Gt, qt)（检索读取器）**：基于当前子目标查询世界图的紧凑切片。

### 2.4 稀疏深度接地世界图
世界图定义为带类型的场所-物体图：**Gt = (VP_t, VO_t, EPP_t, EPO_t)**：

- **Place states（场所节点）**：通过增量单链接聚类形成，聚合空间锚点、语义上下文、访问统计和可选失败证据；
- **Object states（物体节点）**：基于Grounding DINO和SAM的开放集检测与分割，通过深度投影并有机构造；
- **Place-Place边**：编码导航连通性；**Place-Object边**：编码语义包含关系及其置信度。
- **核心优势**：存储量随发现的场所和物体增长，而非随覆盖面积增长。

### 2.5 决策耦合更新
更新规则：**Lt+1 = UL(Lt, w_t)**，**Gt+1 = UG(Gt, w_t, Γ(Ot, Dt, Pt))**。其中w_t是System 2生成的语义写入内容，Γ 是从RGB-D观测提取的接地几何证据。动作、记忆写入在同一调用中协同完成，**无额外LLM调用**。

### 2.6 子目标条件检索
检索评分公式：**s_t(p) = α·rel(q_t, p) + β·rec_t(p) + γ·sal(p)**，其中：

- **rel**：查询-地点余弦相似度（使用本地bge-large-en-v1.5编码器）；
- **rec_t(p) = ρ^{t−τ(p)}**：基于最后访问时间的近时性（权重系数 α=1.0，β=0.3，γ=0.3，ρ=0.85）；
- **sal**：基于地标一致性和物体丰富度的显著性。

**拓扑感知读取**：种子预算Ks=3，最终地点预算Kp=5，选取最高分种子并做单跳扩展（one-hop expansion），保留该地点邻域后再序列化为模型上下文。

### 2.7 接地失败记忆（回溯）
- 当System 2决定回溯到之前访问的航点时，被放弃的轨迹后缀映射为场所级失败证据，并与决策理由一同存储；
- 该证据是**建议性而非禁止性**的：不参与评分计算，也不阻止场所再次被访问；仅当相关场所被检索到时才重新进入上下文，供System 2在当前子目标下重新解读失败。

### 2.8 四种功能记忆视图
1. **工作记忆**：近期K个航点的原样帧流；
2. **情景记忆**：访问轨迹和时序元数据，提供近时性；
3. **语义记忆**：场所-物体内容和拓扑，提供相关性；
4. **反思记忆**：附在场所上的失败笔记，在被检索到时原样重新进入上下文。

## 6. 论文的主要结论与发现

1. **分层智能体记忆显著优于原始视觉历史**：相同MLLM下，从完整原始历史（SR 53.3）到HAM-VLN（SR 61.0），SR提升7.7个点，同时上下文缩减67%；
2. **更大的视觉上下文不等于更好**：从K=3扩展到完整历史，API tokens增加98.7%，但SR反而下降4.7个点，SPL下降6.6个点——选择性地记忆比膨胀地记忆更有价值；
3. **反思记忆主要提升路径效率**：去掉反思记忆使SPL下降11.2个点（48.1→36.9），但SR仅下降5.3个点——失败证据对避免重复探索和提升路径效率作用最突出；
4. **世界图是所有记忆视图的基础**：去掉世界图导致SR下降9.3个点，即使替换为完整历史仍远低于完整模型；
5. **零样本导航可超越监督方法**：在HM3D-v2 ObjectNav上以79.7%的SR超过所有报告的监督方法，说明MLLM预训练中的房间级语义先验可以弥补无训练探索的不足。

## 7. 优点

- **创新的记忆设计**：将生成式智能体的记忆原则（相关性、近时性、重要性、反思）适配到具身导航的空间场景，具有跨领域移植的启发意义；
- **决策耦合的高效性**：记忆写入与动作选择在同一个LLM调用内完成，不增加推理次数，"免费"获得持久记忆；
- **深度接地的世界图**：存储量随发现的场所而非面积增长，同时保留几何拓扑信息，支持空间上可解释的记忆检索和回溯；
- **压缩与性能兼得**：在降低65%以上上下文的同时提升所有导航指标，打破了"越完整的历史越好"的直觉假设；
- **充分的消融**：对每个记忆组件的贡献进行了因果量化，验证了设计选择的合理性；
- **免训练的实用性**：完全不需要为任务训练模型，可直接部署于未见环境，且维护成本仅来自逐航点的决策调用本身。
