## 摘要
世界动作模型（WAM）联合学习环境动力学和机器人动作，将物理演化的先验引入具身控制。然而，有限时域的预测和动作生成不足以应对复杂的具身任务，这些任务需要全局规划、跨阶段状态维护、执行验证和失败恢复。我们将这种不匹配称为WAM的预测-深思鸿沟。为解决这一鸿沟，我们提出HarnessWAM，一个面向WAM的智能体框架。HarnessWAM采用基于视觉语言模型的任务管理器来维护基于证据的场景信念和结构化任务图。能力条件的可执行空间投影进一步将开放式的语义计划约束为满足任务依赖、具身状态约束以及底层WAM能力边界的原子技能序列。在执行过程中，HarnessWAM通过事件驱动的双时间尺度反馈循环运作：一个轻量级进度估计器持续提供高频执行证据，而任务管理器在关键里程碑处进行深思，联合考虑当前观测、任务状态和交互历史，以决定推进任务、获取额外观测、修订计划或启动局部恢复。该机制使机器人能够在子任务失败后恢复其状态，并在不丢弃先前获取的场景知识的情况下继续执行。HarnessWAM在RoboMemArena上实现了59.6%和69.9%的最先进的全任务和子任务成功率，在RoboCerebra Ideal上实现了23.7%的SR。这些结果表明，模型外部的结构化状态维护和闭环智能体决策能够有效地将WAM的局部控制能力扩展到可规划、可验证和可恢复的具身任务执行中。

## Abstract
World Action Models (WAMs) jointly learn environmental dynamics and robot actions, introducing priors over physical evolution into embodied control. However, finite-horizon prediction and action generation are insufficient for complex embodied tasks that require global planning, cross-stage state maintenance, execution verification, and failure recovery. We refer to this mismatch as the prediction-deliberation gap of WAMs. To address this gap, we propose HarnessWAM, an agentic framework for WAMs. HarnessWAM employs a vision-language-model-based Task Manager to maintain an evidence-grounded scene belief and a structured task graph. A capability-conditioned executable-space projection further constrains open-ended semantic plans into sequences of atomic skills that satisfy task dependencies, embodiment-state constraints, and the capability boundary of the underlying WAM. During execution, HarnessWAM operates through an event-driven, dual-timescale feedback loop: a lightweight progress estimator continuously provides high-frequency execution evidence, while the Task Manager deliberates at salient milestones by jointly considering the current observation, task state, and interaction history to determine whether to advance the task, acquire additional observations, revise the plan, or initiate local recovery. This mechanism enables the robot to recover its state after a subtask failure and resume execution without discarding previously acquired scene knowledge. HarnessWAM achieves state-of-the-art full-task and subtask success rates of 59.6% and 69.9% on RoboMemArena, and an SR of 23.7% on RoboCerebra Ideal. These results demonstrate that model-external structured state maintenance and closed-loop agentic decision making can effectively extend the local control capabilities of WAMs into embodied task execution that is plannable, verifiable, and recoverable.

## 2. 论文提出的方法论

### 2.1 总体框架

- 提出 **HarnessWAM**，一个模型外部的智能体框架，由三个关键模块组成：
  1. **VLM 任务管理器（Task Manager）**：维护证据化的场景信念（scene belief）和结构化任务图（task graph），在关键事件发生时进行高层深思。
  2. **能力条件可执行空间投影（Executable-Space Projection）**：将 VLM 产生的开放式语义计划编译为 WAM 实际可执行的原子技能序列。
  3. **事件驱动的双时间尺度反馈循环**：由轻量级进度估计器提供高频执行证据，由任务管理器在关键里程碑处进行低频、事件触发的深思决策。

  f = (s, p, o, v, \eta, c, E)

  P^\star = P_{\text{motion}} \cup P_{\text{grasp}} \cup P_{\text{contact}} \cup P_{\text{articulation}} \cup P_{\text{assembly}} \cup P_{\text{tool}}

  \[
  G_{k+1}|_{V^{\text{executed}}_k} = G_k|_{V^{\text{executed}}_k}

- 双时间尺度设计：
  - **快循环**：WAM 持续生成动作块；轻量级进度估计器 \(F_\phi\) 从最近 \(L\) 帧双视图 RGB 中预测连续进度 \(p_t\)、完成概率 \(c_t\) 和离散进度区间分布。

  - 长时组合操作与高层推理基准；

### 3.2 评价指标

- RoboMemArena：全任务成功率（full-task success）和子任务成功率（subtask success）；
- RoboCerebra：使用官方协议中的完成率 SR，计算关键对象状态转移的平均完成比例。

### 3.3 对比方法

- **RoboMemArena 基准对比**：π0.5、HiF-VLA、MemoryVLA、MemER、PrediMem。
- **同 WAM 诊断基线**：
  - WAM + Whole Task：直接用全局指令驱动 WAM；
  - WAM + Static Plan：初始化时生成线性计划并固定执行，不更新记忆、不重规划。
- **RoboCerebra Ideal 对比**：π0.5、OpenVLA、GPT-4o Planner + OpenVLA、HPE Framework。

### 3.4 实现细节

- 底层 WAM：LingBot-VA（架构不变，分别按各基准数据微调）。
- 任务管理器：Qwen3-VL-32B-Instruct，无任务特定微调，仅使用多视图 RGB。
- 进度估计器：SigLIP2 视觉编码器 + 四层因果 Transformer，输入最近 5 步双视图 RGB 和当前技能指令。

### 3.5 主要结果

- **RoboMemArena**：HarnessWAM 实现平均全任务成功率 59.6%、子任务成功率 69.9%，超过之前最佳 PrediMem（38.5%/55.2%）分别 21.1 和 14.7 个百分点。

- **RoboCerebra Ideal**：HarnessWAM 取得 SR 23.70%，超过 GPT-4o Planner + OpenVLA（21.92%）和 HPE Framework（21.10%）。

## 6. 主要结论与发现

1. **预测–深思鸿沟确实存在**：有限时域的 WAM 无法独立完成需要记忆、验证和恢复的复杂任务，HarnessWAM 的实验证明外部编排能显著弥补该缺陷。
2. **可执行空间投影贡献最大**：去掉投影后全任务成功率从 59.6% 骤降至 18.5%，说明 VLM 的语义计划若不经过能力/依赖/绑定/具身约束过滤，很难驱动 WAM。
3. **结构化的任务状态比静态分解更有效**：WAM + Static Plan 已比 Whole Task 提高 3.5 点全任务成功率，但 HarnessWAM 在此基础上再提升 11.7 点，说明闭环记忆更新和重规划不可或缺。
4. **事件驱动比固定频率更优**：固定间隔调用任务管理器导致全任务成功率下降 21.3 点；纯进度切换虽能维持子任务成功率，但会显著降低全任务成功率，说明语义验证对任务边界至关重要。
5. **局部恢复能带来非 trivial 提升**：移除恢复机制后全任务成功率下降 5.4 点，在顺序执行类任务中影响更明显。

## 7. 优点

- **问题识别清晰**：将 WAM 的“预测–深思”差距形式化，并给出模型外部解决思路，切中具身智能中长时任务的关键痛点。
- **框架模块化**：证据化信念、任务图、可执行投影、双时间尺度反馈、局部恢复等组件职责明确，且无需修改 WAM 内部结构，即插即用。
- **方法具有理论支撑**：利用运动基元低维性、抓取类型分布等实证结论论证原始技能本体的合理性。
- **消融设计严谨**：五个干预项分别针对状态、投影、事件触发、切换语义、恢复五个方面，能从任务层和计划层解释每个组件的贡献。
- **计划级诊断有价值**：将“词汇规范化”与“完整可执行投影”分离，揭示仅靠表面文本对齐远不足以生成可执行计划，为后续工作提供分析范式。
- **实验结果较强**：在 RoboMemArena 上大幅超越已有方法，并在 RoboCerebra Ideal 上达到 SOTA（虽然差距较小）。

- **算力信息缺失**：未报告训练/推理的 GPU、时间或成本，难以评估方法的实际资源门槛。
