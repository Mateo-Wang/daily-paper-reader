## 摘要
鲁棒的机器人控制受益于对状态转移的显式建模，但视频生成世界动作模型（WAM）会带来巨大的部署成本。现有的潜在WAM避免了显式的未来生成，但往往压缩预测表示或将预测建模与用于动作生成的表示相分离。我们引入了JEPA-WAM，一种构建在预训练V-JEPA空间中的潜在WAM，它通过共享预测器将潜在转移预测与连续动作生成耦合在一起。JEPA-WAM预测一个空间结构的联合当前-未来目标，该目标捕捉当前与未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应关系。通过共享预测器，转移监督直接塑造主干网络，并从中提取专门用于动作预测的表示。同样的设计也可以实例化到预训练的VLA策略中，同时保留其原始的感知和动作路径。在LIBERO-Plus上，JEPA-WAM达到79.2%，是在没有大规模机器人策略预训练情况下的最佳结果，而其预训练的π_{0.5}实例化达到86.3%，实现了最佳整体性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 论文总结：JEPA-WAM

### 1. 核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）策略在多种机器人操作任务中表现优异，但其动作预测目标仅隐式地建模状态转移，在分布偏移场景下鲁棒性受限。世界动作模型（WAM）通过显式建模未来状态来应对这一问题，但视频生成式 WAM 在部署时需要迭代式未来预测，计算成本过高。
- **核心问题**：现有潜空间 WAM 虽避免了显式未来帧生成，但面临两个互补的设计问题：
  1. **预测目标应是什么**？现有方法或复用视频生成器中间特征（并非为状态变化表示而优化），或将未来观测压缩为少量潜 token / 子目标（可能丢失细粒度空间结构）。
  2. **预测监督如何与动作生成集成**？现有方法或将来预测表征作为动作模块的额外上下文（可能引入冗余信息），或使用独立预测目标 / 潜动力学模块（对动作生成所用表征的影响较弱）。
- **核心主张**：JEPA-WAM 在预训练 V-JEPA 表示空间中构建潜 WAM，通过**共享预测器**将潜转移预测与连续动作生成耦合，预测**空间结构化的联合当前-未来目标**，使转移监督直接塑造动作生成所用的主干网络，同时避免显式未来帧生成的高部署成本。

### 2. 方法论

- **核心思想**：在预训练的 V-JEPA 2.1 表示空间中构建潜世界模型，用共享预测器同时完成潜转移预测（图文时序结构）与动作生成（条件表征提取）。
- **V-JEPA 表示空间与联合当前-未来目标**：
  - 冻结 V-JEPA 2.1 编码器 \(E_J\) 对各相机视角独立编码，按固定相机顺序拼接得到当前观测表示 \(Z_t = \text{Concat}_{v \in V} E_J(O_v^t) \in \mathbb{R}^{N_{\text{vis}} \times d_J}\)，保留稠密补丁级空间结构。
  - 训练时将当前观测 \(O_v^t\) 与 \(\delta\) 步后的未来观测 \(O_v^{t+\delta}\) 沿时间维堆叠，联合编码得到联合当前-未来目标 \(Y_{t,t+\delta} = \text{Concat}_v\, \text{sg}(E_J(\text{Stack}_{\text{time}}(O_v^t, O_v^{t+\delta})))\)。由于 V-JEPA 使用时间管径（tubelet size=2），双帧输入保持与单帧相同的空间 token 网格，保证补丁级对应。
  - 联合目标不是要求重建唯一的未来观测，而是强调两个时间端点之间的**视觉时序关系**：哪些区域稳定、哪些变化、局部物体与空间关系如何演化，同时保持稠密补丁级信息，避免全局池化压缩。
- **共享预测器**：
  - 共享预测器 \(F_\theta\) 采用 Qwen2.5-0.5B，处理投影后的视觉 token、任务指令和专用动作占位符 token：\((Q_t^{\text{wm}}, C_t) = F_\theta(P_{\text{vis}}(Z_t), \ell, P^{\text{act}})\)。
  - \(Q_t^{\text{wm}}\) 为视觉 token 位置的隐藏状态，用于预测联合当前-未来目标；\(C_t\) 为专用动作条件表征，送入动作专家。
  - 共享预测器使转移监督直接更新动作生成所用的同一主干网络。
- **潜转移预测**：轻量预测头 \(G_\phi\) 将 \(Q_t^{\text{wm}}\) 映射回 V-JEPA 空间：\(\hat{Y}_{t,t+\delta} = G_\phi(Q_t^{\text{wm}})\)，采用**逐补丁余弦距离**作为损失：\(L_{\text{wm}} = \frac{1}{BN_{\text{vis}}}\sum_{b,n}(1 - \cos(\hat{Y}^{(b)}_{t,t+\delta,n}, Y^{(b)}_{t,t+\delta,n}))\)。
- **动作预测与生成**：专用动作占位符输出 \(C_t\) 送入 DiT 动作专家 \(A_\psi\)，使用条件流匹配（conditional flow matching）。给定动作块 \(a\)，噪声 \(\epsilon\)，流时间 \(\tau\)（Beta 分布采样）：\(L_{\text{act}} = \mathbb{E}_{\epsilon,\tau}\left[\|A_\psi(a_\tau, \tau, s_t, C_t) - (a - \epsilon)\|_2^2\right]\)。默认使用速度预测目标；RoboTwin 2.0 上改用 x-prediction。
- **联合训练与部署**：总损失 \(L = L_{\text{act}} + \lambda_{\text{wm}} L_{\text{wm}}\)（\(\lambda_{\text{wm}}=0.5\)）。部署时移除目标分支与预测头，仅需当前观测和语言指令。
- **迁移到预训练 VLA 策略**：在预训练 π0.5 中引入 64 个可学习 future tokens，将其输出隐藏状态重塑为 8×8 粗特征图，经轻量投影和双线性上采样至 24×24，与联合当前-未来目标对齐。未来 tokens 可关注原始图像和语言前缀，但动作 tokens 被阻止关注这些新查询，确保原始动作路径不受干扰。

### 6. 主要结论与发现

- 在标准 LIBERO 上，JEPA-WAM 平均成功率 96.7%，与强 baseline 竞争；π0.5+JEPA Obj. 从 π0.5 的 96.9% 提升至 97.8%，表明转移监督不损害 ID 性能。
- 在 LIBERO-Plus 上，JEPA-WAM 平均 79.2%，为无大规模机器人策略预训练方法中的最佳；π0.5+JEPA Obj. 从 84.5% 提升至 86.3%，实现总体最优。
- 在 RoboTwin 2.0 上，JEPA-WAM Clean 79.9%、Random 36.9%，显著优于无预训练方法，Random 性能接近预训练 π0.5；π0.5+JEPA Obj. Clean 从 75.4% 提升至 84.6%，Random 基本持平。
- 真实世界实验中，JEPA-WAM OOD 54.2%（π0 仅 22.5%），π0.5+JEPA Obj. ID 从 77.5% 提升至 90.3%、OOD 从 72.5% 提升至 84.7%。
- 消融结论：
  - V-JEPA 表示空间本身即带来 OOD 鲁棒性（仅替换编码器即从 73.2% 提至 77.0%）。
  - 联合当前-未来目标优于仅未来目标（79.2% vs. 77.3%）和显式端点差分目标（70.9%）。
  - 保留原始补丁级空间结构优于 iREPA 风格卷积变换（79.2% vs. 74.7%）。
  - 最终层转移监督优于中间层监督（79.2% vs. 76.5%）。
  - 专用动作占位符优于直接共享全部隐藏状态（79.2% vs. 73.1%）。
- 推理效率：JEPA-WAM 在 RoboTwin 上 85 ms/次（11.76 Hz），快于 ABot-M0（125 ms），慢于 π0.5 系方法（约 55 ms）。

### 7. 优点

- **方法设计亮点**：
  - 共享预测器设计新颖，避免了预测与动作生成的分离，使转移监督直接塑造动作生成主干。
  - 联合当前-未来目标保留了密集补丁级空间结构，捕捉任务共享的视觉时序关系，而非压缩为全局或少量 token。
  - 无需显式未来帧生成，部署时去掉目标分支，推理开销低。
  - 同一目标形式可迁移至预训练 VLA（π0.5），无需修改原始感知和动作路径，通用性强。
  - 采用冻结 V-JEPA 编码器 + LoRA 适配，训练参数高效。
- **实验亮点**：
  - 覆盖多个 benchmark（LIBERO、LIBERO-Plus、RoboTwin 2.0、真实世界），且 LIBERO-Plus 的多种干扰类型拆解清晰。
  - 消融设计系统、控制变量较严谨。
  - 冻结表征探测实验（受控时间间隔、未见间隔泛化、去除端点位移后结构恢复）提供量化证据，支持联合目标的表征优势。
  - 同时报告了完整 task-wise 结果和 per-rollout 真实世界记录，透明性好。

### 8. 不足与局限

- **方法局限**：
  - 转移监督设计为任务共享的视觉时序结构，不适用于“同一观测在不同语言指令下会导致截然不同转移”的情况。作者在 Limitations 中明确承认语言条件化或模态条件化的转移目标是未来方向。
  - 使用视频生成器的冻结表示（V-JEPA）作为目标空间，当目标任务与 V-JEPA 预训练分布差异较大时，目标信息可能不够充分。
  - 联合目标对轨迹末端的处理是将未来帧截断到最后一帧，长时程转移关系覆盖有限。
- **实验局限**：
  - 真实世界任务数较少（仅 5 个），且仅在一个硬件平台上验证。
  - 真实世界 OOD 变化（背景、物体配置）相对简单，未覆盖更复杂的光照、传感器噪声等。
  - π0.5+JEPA Obj. 的迁移实验仅验证一个预训练 VLA，未扩展至其他预训练模型（如 OpenVLA、RDT-1B 等）。
  - 未报告真实世界实验的统计显著性（仅表 15 给出均值，无 CI）；除冻结表征探测外，主要仿真结果也未给出多次随机种子下的标准差。
  - 对比方法的精确训练配置可能不完全对齐（如是否使用相同的视觉编码器规模、数据增强等）。
  - 推理效率对比中，JEPA-WAM 比 π0.5 慢约 30 ms，但 Faster-WAM 等更高效方法未在相同硬件上对比。
- **其他**：论文未提供代码链接（仅提到 GitHub 项目页），复现难度较高；部分数值结果在正文和附录之间存在表述一致性风险（如实数值平均 59.82 与正文四舍五入的 59.8 一致，但 OOD 54.18 vs 54.2 也可）。
