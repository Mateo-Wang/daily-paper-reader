## 摘要
作为具身智能的一项关键能力，3D视觉定位（3DVG）主要在室内场景中通过RGB-D或点云输入进行研究，而现有的户外扩展大多仅依赖单目图像。这两种设置都无法满足真实世界户外感知的需求，因为在户外环境中，异构传感器捕获互补但不同的物理属性，如视觉纹理、3D几何和物体运动学，这些对于灵活且鲁棒的查询自适应定位至关重要，但尚未得到充分利用。为弥合这一差距，我们引入了Talk2Sensors，这是第一个基于相机、LiDAR和4D雷达构建的多传感器3D视觉定位数据集。它包含8,682条语言指令和20,558个被引用对象，并具有明确与传感器特定物理线索对齐的多样化提示。此外，我们提出了TSFormer，一个统一的基于Transformer的自动驾驶语言引导3D视觉定位框架。TSFormer采用从粗到细的属性感知融合策略：语言路由属性采样器首先通过调制传感器采样权重与查询级语言线索来执行粗粒度的文本条件特征检索，而后续的稀疏保留模态仲裁器模块则进行细粒度模态仲裁和文本引导细化，以确定精确的被引用空间位置。这种设计能够根据每个提示的语义需求动态路由外观、几何和运动线索，防止密集模态淹没稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准上实现了最先进的性能：在Talk2Sensors上比最强基线提高了8.05 mAP，并迁移到单目Mono3DRefer基准，取得了53.05%的Acc@0.5。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

## 1. 核心问题与整体含义

- **研究背景**：3D视觉定位（3DVG）是实现具身智能与自动驾驶交互感知的关键能力，但已有研究主要集中于室内 RGB-D/点云场景，户外工作大多只使用单目相机。真实户外场景中，相机、LiDAR 和 4D 毫米波雷达会捕获互补但异构的物理属性（视觉纹理、几何结构、运动/速度等），这些属性尚未被现有 3DVG 方法充分挖掘。
- **核心问题**：如何让自动驾驶系统根据自然语言查询，动态选择“最能回答该查询”的传感器物理线索，而不是对所有模态进行无差别、查询无关的融合。
- **论文意义**：
  - 提出 **Talk2Sensors**：首个同时基于相机、LiDAR 与 4D 雷达的三模态 3D 视觉定位数据集。
  - 提出 **TSFormer** 框架：实现“语言路由 + 稀疏保持”的物理线索匹配，支持查询自适应的多传感器融合。
  - 在 Talk2Sensors 上较最强基线提升 8.05 mAP，并可跨数据集迁移到 Mono3DRefer，验证了物理属性对齐范式的通用性。

## 2. 提出的方法论

### 2.1 总体思想
TSFormer 采用由粗到细的**属性感知融合**策略：
1. 先用语言查询做粗粒度的模态特征检索；
2. 再通过模态仲裁与文本引导精化确定目标物体的精确 3D 位置。

整体架构包含：预训练文本编码器、各模态骨干网络（ResNet-101、SparseEncoder-SECOND、RadarFeatureNet+PointPillarsScatter）、Language-Routed Property Sampler、Sparse-Preserving Modality Arbiter、共享 Transformer 解码器与接地预测头。

### 2.2 Language-Routed Property Sampler（LRPS）
- 目标：在统一查询空间中，按语言线索调制各传感器的采样权重，实现“文本条件化”的粗检索。
- 流程：
  1. 将全局文本特征投影到各模态语义空间：`t_m = φ_m(t)`。
  2. 将投影后的文本特征与 object queries 做通道级交互，得到文本-传感器相似度图 `D_m`。
  3. 通过可学习温度参数 `τ_m` 和 sigmoid 得到调制因子 `G_m`。
  4. 将 `G_m` 广播到 deformable attention 的采样权重上，并利用参考点 + 归一化偏移生成采样位置。
  5. 用多尺度 deformable attention 聚合得到语言条件化的初步传感器特征。
- 优点：规避了手动几何投影对齐，采样过程本身具备语言感知能力。

### 2.3 Sparse-Preserving Modality Arbiter（SPMA）
- 目标：在细粒度层面仲裁不同模态，防止高密度的相机特征淹没稀疏但关键的雷达信号。
- 流程：
  1. 对文本 token 做池化，得到全局文本向量并输入轻量门控网络，生成文本条件化的模态门 `z`。
  2. 可选 Top-K 稀疏选择掩码，Softmax 后得到各模态权重 `α`。
  3. 用 `α` 对各模态采样特征做加权求和，得到融合特征 `F_s`。
  4. 将 `F_s` 作为 query、文本 token 作为 key/value，进行 text-guided cross-attention。
  5. 经过 FFN、残差连接和 LayerNorm，输出最终模态仲裁特征 `F_SPMA`。

### 2.4 Grounding Decoder 与训练目标
- 采用 DETR 式集预测解码器，逐步精化查询特征。
- 每个查询输出：二值 referring 置信度 `α_i` 和 3D 边界框 `s_i = (x,y,z,w,h,l,θ)`。
- 采用匈牙利匹配进行 set prediction，匹配代价 = 置信度项 + L1 box 损失 + 3D GIoU 损失。
- 训练中使用逐层辅助监督，总损失为最终层接地损失与中间层损失之和。

## 6. 主要结论与发现

- TSFormer 在 Talk2Sensors 所有传感器配置下均取得最佳 mAP/mAOS：
  - 三传感器配置 EAA mAP 51.000，DCA mAP 66.499。
  - 较最强融合基线 FUTR3D 分别提升 +8.05/+7.62。
- LiDAR 是单模态中的主导信号（单模态 mAP 46.182），相机和雷达单独较弱；但 TSFormer 随模态增加单调提升（46.18→48.28→51.00），说明语言引导路由能真正提取互补信息。
- 朴素融合（如 FUTR3D）不会超过 LiDAR-only 性能，说明密集相机特征会淹没稀疏雷达信号，验证了“稀疏保持”的必要性。
- 增益最大场景集中在需要雷达和跨模态物理推理的 prompt 上（如 Radar Only、Camera+Radar、Camera+LiDAR+Radar），证明属性感知路由是增益来源。
- 在推理时

- 在推理时逐渐移除某一传感器，TSFormer 的性能衰减显著小于直接使用固定融合权重的基线，且语言查询中与缺失模态相关的属性词越少，性能下降越可控；当同时保留 LiDAR 与关键稀疏传感器时，模型仍能保持较高 mAP，说明学习到的路由机制具备一定“容错”能力。

## 7. 论文局限性与未来工作

- **数据集规模有限**：Talk2Sensors 仅基于单一日间城市场景（VoD），缺乏恶劣天气、夜间、高速路况等挑战性环境，传感器退化场景尚未覆盖。
- **语言范围较窄**：现有标注以物体颜色、类别、位置关系、运动状态为主，未涉及复杂指令（如“停在路口左侧等待的第二辆车”），对时空因果推理的考察不足。
- **传感器组合固定**：所有样本均假设三传感器同时可用，没有模拟传感器故障或选择性激活的真实部署情况（虽然测试时做了模态缺失鲁棒性分析，但训练阶段未建模缺失）。
- **缺乏端到端驱动闭环验证**：定位结果未连接到后续规划/控制任务，无法衡量 3DVG 误差对实际驾驶决策的影响。
- **未来方向**：① 扩展多天气、多城市、多传感器异构组合的数据集；② 引入时间维度的多帧语言定位；③ 结合大语言模型进行开放词汇的物理属性推理；④ 将稀疏路由机制推广到端到端自动驾驶的感知-决策一体化模型中。

## 8. 个人评价与总结

Talk2Sensors 论文的核心贡献在于将 3D 视觉定位问题从“室内小场景”推向“户外多传感器自动驾驶”，并提出了“语言路由+稀疏保持”这一新颖范式。TSFormer 通过 Language-Routed Property Sampler 和 Sparse-Preserving Modality Arbiter 两个模块，巧妙地解决了异构传感器特征空间不一致、高密度信息淹没低密度信息这两大关键痛点。实验设计较为严谨，对比基线丰富，消融充分，结果提升显著（+8.05 mAP），且跨数据集迁移验证了方法的通用性。尽管存在数据集单一、任务封闭等局限，但该工作为多模态三维定位提供了新的思考方向，具有较强的启发价值。作为一份探索性研究，它在“传感器物理属性与自然语言的语义关联”这一新兴交叉领域迈出了扎实的一步，值得后续研究者在此基础上进一步深耕。
