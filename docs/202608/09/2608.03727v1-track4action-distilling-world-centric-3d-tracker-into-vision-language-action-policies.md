## 摘要
动作标签告诉视觉-语言-动作（VLA）策略要模仿哪些机器人命令，但不告诉这些命令如何改变3D世界。对齐的示范片段包含了这一缺失的监督信息，因为其K帧转换记录了在相应K个动作执行期间产生的几何、运动、可见性和相机变化。我们提出了Track4Action，一个将这种已实现的转换从冻结的世界中心3D追踪器蒸馏到当前观测VLA策略中的框架。在训练期间，Track4World将片段V_{t:t+K}编码为池化的追踪器特征。可学习的追踪查询从当前的VLA隐藏状态中推断出此特征，在共享空间中对其进行匹配，并通过特征级门控来调节流匹配动作头。追踪器特征仅定义对齐目标，因此在部署时既不需要片段也不需要追踪器。Track4Action在零样本LIBERO-Plus上达到82.3%的成功率，比无对齐变体提高7.6个百分点，比LaMP提高3.0个百分点。它在干净和随机化的RoboTwin 2.0分割上分别获得80.44%和81.48%的成功率，并在四个物理双臂任务上平均成功率为67.5%，比无对齐变体高出25.0个百分点。在仿真和物理任务上的收益支持将动作对齐的3D追踪器特征作为无追踪器VLA部署的特权监督。我们的项目页面可在https://wing0night.github.io/track4action-project-page获取。

## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

## Track4Action 论文总结

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：视觉-语言-动作（VLA）策略能够将视觉观测和语言指令映射为机器人动作，但动作标签仅告诉策略“执行什么命令”，却未揭示这些命令如何改变3D世界。相同的末端执行器位移可能穿越自由空间、运输物体或改变相机视角，这些差异决定了任务是否成功，但动作标签不编码此类信息。
- **现有方法的不足**：已有工作通过未来预测（如未来图像、几何、视觉特征）或几何感知方法（如3D结构、场景流、空间特征对齐）来增强动作学习，但这些方法的监督目标通常是未来内容、显式几何变量或单一状态下提取的空间特征，并未利用“与演示动作块恰好对齐的多帧运动专用表示”。
- **核心洞见**：演示视频本身就包含所需的物理证据——与K个动作对齐的K+1帧记录了这K个转换期间产生的几何、运动、可见性和相机变化。作者提出利用世界中心3D追踪器组织这些变化，将动作对齐的追踪器特征作为训练时的“特权监督”，部署时完全去除——即让追踪器只在训练时“看见未来”，部署时策略仅凭当前观测与任务信息执行。

### 2. 论文提出的方法论（核心思想、关键技术细节）

- **整体框架**：训练时由冻结的Track4World教师模型处理动作对齐片段，提取追踪器特征作为对齐目标；学生VLA策略通过可学习track queries从当前隐状态中推断该特征，并将查询结果通过门控融入动作生成。部署时仅保留当前观测路径，无需片段或追踪器。
- **问题设定**：策略接收语言指令 l、当前RGB观测 I_t 和可选机器人状态 s_t，预测归一化动作块 A*_t = (a_t, ..., a_{t+K-1}) ∈ R^{K×d_a}。训练时还提供主视角片段 V_{t:t+K} = (o_t, ..., o_{t+K})，其K个帧间转换恰好与K个动作对应。
- **追踪器特征构建**：
  - 冻结的Track4World模型 T 对动作对齐片段编码世界中心3D轨迹、场景、运动、可见性和相机线索；
  - 通过池化得到紧凑的追踪器特征 f^{trk}_t = sg[Pool(T(V_{t:t+K}))]，其中sg为停止梯度；
  - 该特征描述的是与A*_t同步发生的世界变化，而非无关未来事件。
- **特征蒸馏**：
  - VLA骨干 E_θ 编码当前图像与指令得 H_t = E_θ(l, I_t)；
  - 可学习track queries Q 通过交叉注意力从 H_t 提取动作面临时特征 Z_t = D_θ(Q, H_t)；
  - 将 Z_t 与 f^{trk}_t 映射到共享空间后计算L2对齐损失 L_align = ‖z̄_t − f̄^{trk}_t‖²。
- **门控融合与动作生成**：通过特征级门控将 Z_t 与VLA序列融合为 H^cond_t，该条件输入流匹配动作头；教师特征 f^{trk}_t 从不进入动作头——融合的只是学生自己提取的查询表示，确保部署时完全无追踪器依赖。
- **总损失**：L = λ_act·L_act + λ_align·L_align，动作损失控制“做什么”，对齐损失教会动作面临表示“伴随什么世界转换”。
- **部署不变性**：部署时从 (l, I_t, s_t) 计算 H_t、Z_t、H^cond_t 并从噪声生成动作块，丢弃片段、冻结追踪器、目标与对齐分支，保留track-query与门控融合通路。

### 3. 实验设计（数据集、基准与对比方法）

- **LIBERO基准**：覆盖Spatial、Object、Goal、Long四个套件，在四个套件上训练单一策略并报告均值。对比OpenVLA、π0、π0.5、GR00T N1、UniVLA、villa-X、mimic-video、WorldVLA、F1、FlowVLA、TraceVLA、SpatialVLA等。输入为agent-view和wrist-view双RGB加8维机器人状态，预测7维delta末端动作，K=8。
- **LIBERO-Plus零样本OOD基准**：仅在原始LIBERO演示上训练，不做任何自适应，在Camera、Robot、Language、Light、Background、Noise、Layout七个扰动维度上评估。对比UniVLA、OpenVLA、OpenVLA-OFT、π0、π0-FAST、WorldVLA、LaMP等。
- **RoboTwin 2.0双臂基准**：50个双臂任务，分别评估干净（clean）与随机化（randomized）两种条件。输入为1个外部视角加2个腕部视角，无机器人状态，预测14维双臂关节与夹爪命令，K=16。对比π0.5、X-VLA（0.9B）、Motus w/o Pretrain（8B）等。
- **真实世界物理实验**：AgileX ALOHA风格平台（两条6-DoF Piper臂+平行夹爪，1个前置相机+2个腕部相机），四个任务——两个刚性物体任务（放辣椒到盘子、放卷心菜进锅并盖盖）、一个可变形物体任务（叠毛巾）、一个长时程任务（放两支笔入抽屉并关上）。每任务10次试验，报告成功率与四阶段过程分数（每里程碑25分）。对比π0.5和无对齐变体。
- **OOD物理设置**：三种留出变化——新物体布局与干扰物（辣椒转移）、未见毛巾颜色、纹理桌面背景。
- **对齐消融**：Track4Action w/o Align保留VLA骨干、动作头、模型规模、rollout接口，仅移除追踪器蒸馏通路；数据、优化器、训练计划保持固定。

- **LIBERO**：平均97.0%成功率，比无对齐变体高2.8个百分点、比π0.5高0.1个百分点；增益高度集中在LIBERO-Long（95.8% vs 86.2%，提升9.6点），说明追踪监督对需要跨阶段保持任务相关状态的长时程任务收益最大。
- **LIBERO-Plus**：官方平均82.3%，比LaMP高3.0个百分点，**在全部七个扰动类别上提升无对齐变体**（74.7%→82.3%，+7.6点），相机、噪声、机器人三类增益最大（+18.3、+9.0、+8.7点），RoboTwin上无对齐变体与未训练的基线性能均极低，蒸馏通路带来显著增益且无类别性回退。
- **RoboTwin 2.0**：干净条件80.44%、随机化条件81.48%，分别超过最强基线Motus w/o Pretrain 2.88和4.48个百分点，且随机化下成功率的提升趋势（+1.04点）进一步拉开差距。

- **总体判断**：动作对齐的3D追踪器特征是一种有效的特权监督，在仿真和物理任务中支持无追踪器的VLA部署，增益在更强世界状态与运动需求的场景中更加显著。

### 7. 优点与亮点

- **新颖的特权监督范式**：首次将世界中心3D追踪器特征（而非逐点轨迹或显式几何变量）作为训练目标蒸馏进VLA，部署零成本、完全追踪器无关。
- **时间对齐设计**：追踪目标严格对应动作块覆盖的K个帧间转换，使监督信号描述的是“该动作引起的世界变化”而非泛化的视频内容。
- **动作面临表示**：track queries既用于特征匹配又是动作头的输入条件，对齐损失直接塑造了面向控制的表示，避免了辅助解码器与主任务脱节的问题。
- **统一的跨域接口**：同一蒸馏框架在不同观测形态（单臂双视角/双臂三视角）、动作空间（7维/14维）、任务族（刚性、可变形、长时程）与仿真/物理条件下均取得一致增益。
- **消融设置严谨**：w/o对齐对照在数据、优化、规模、rollout全部匹配的前提下验证了完整通路的作用，极大地提高了归因的可靠度。

### 8. 不足与局限

- **数据依赖**：需要时间有序的演示片段才能构建监督目标，孤立的图像-动作对无法使用该方法；场景中存在独立运动物体时，命令与观测转换间的关联可能被削弱。
- **特征抽象损失**：池化目标强调段落级的整体世界运动，可能丢弃局部接触对应关系，无法提供细粒度的像素-物体级对齐监督。
- **教师模型错误传递**：继承Track4World在遮挡、快速运动等条件下的潜在误差，且仅使用主视角相机，未充分利用多视角信息。
- **物理评估规模有限**：仅覆盖一个双臂平台、四个任务和三种视觉OOD变化，缺乏不同实施例、相机配置和真实物理扰动的验证。
- **可变形物体仍是短板**：真实世界中叠毛巾成功率仅40%，低于π0.5的70%，说明方法对可变形物体操作的支持仍不足。
- **算力与训练成本未披露**：缺乏训练资源、时长等工程细节，不利于复现与公平对比训练开销。
