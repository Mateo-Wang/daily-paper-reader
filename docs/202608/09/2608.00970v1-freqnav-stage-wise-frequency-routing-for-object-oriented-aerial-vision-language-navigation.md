## 摘要
面向目标的空中视觉-语言导航（VLN）需要在长时间跨度和闭环控制下，搜索描述的目标并精确降落其上。在导航过程中，受目标描述指令的引导，感知优先级动态演变：早期探索优先关注低频空间布局，然后转向高频目标细节。现有的VLN方法使用相同的视觉标记来建模不同导航阶段中变化的感知需求，导致来自无关物体和背景杂乱的干扰。为此，我们将长时间跨度的空中导航建模为从空间结构到局部细节的频率偏好转移，并提出FreqNav，一个轻量级的频率路由自适应感知框架。在固定的计算预算下，FreqNav根据当前导航阶段动态地在频率分量之间重新分配视觉标记。频率标记路由器从双视图观测中选择与阶段相关的视觉表示，而阶段相关的接地模块通过显式监督锚定视觉证据。然后，扩散变换器预测平滑轨迹以进行连续控制。实验表明，FreqNav在优于强基线模型的同时，实现了约3倍更快的推理速度。实际部署进一步证明了其在长时间跨度空中自主性方面的有效性、效率及实际潜力。

## Abstract
Object-oriented aerial vision-and-language navigation (VLN) requires searching for a described target and landing on it precisely, under long-horizon and closed-loop control. Guided by a target-descriptive instruction during navigation, perceptual priorities dynamically evolve: early-stage exploration prioritizes low-frequency spatial layout, and then shifts to high-frequency target details. Existing VLN methods model the varying perceptual requirements across navigation stages with identical visual tokens, leading to interference from irrelevant objects and background clutter. To this end, we therefore formulate long-horizon aerial navigation as a frequencypreference shift from spatial structure to local detail and propose FreqNav, a lightweight frequency-routing adaptive perception framework. Under a fixed computational budget, FreqNav dynamically reallocates visual tokens across frequency components according to the current navigation stage. A Frequency Token Router selects stage-relevant visual representations from dual-view observations, while a Phase-dependent Grounding Module anchors visual evidence through explicit supervision. A Diffusion Transformer then predicts smooth trajectories for continuous control. Experiments show that FreqNav outperforms strong baselines while achieving approximately 3x faster inference. Real-world deployment further demonstrates its effectiveness, efficiency, and practical potential for long-horizon aerial autonomy.

### 1. 核心问题与整体含义（研究动机和背景）

- **任务背景**：面向目标的空中视觉-语言导航（Object-oriented Aerial VLN）要求无人机（UAV）在长时间跨度（long-horizon）和闭环控制条件下，依据自然语言指令自主搜索目标并精确降落。该能力对城市搜索与救援、物流配送、自动化巡检等实际应用具有重要意义。
- **核心问题**：在导航过程中，感知优先级会随导航阶段动态变化——早期目标不可见时，需要依赖低频空间布局进行全局探索；后期目标可见时，则需要高频目标细节进行精确定位与降落。然而，现有VLN方法（如CMA、TravelUAV-DA、AeroVLA等）在所有导航阶段使用统一的静态视觉token分配策略，无法适应这种感知需求的动态转变，导致无关物体和背景信息对决策产生干扰。
- **核心洞察**：作者将长时程空中导航形式化为一个“频率偏好转移”过程——从低频全局空间结构推理转向高频局部目标细节定位。基于这一洞察，提出在固定计算预算下动态重分配视觉token，以提升感知表征的信息密度和决策准确性。

### 2. 方法论（核心思想、关键技术细节）

#### 2.1 整体框架

FreqNav将空中VLN建模为部分可观测马尔可夫决策过程（POMDP），由三个核心模块构成：

1. **Frequency Token Router（频率token路由器）**：根据导航阶段动态选择与阶段相关的视觉表征；
2. **Phase-dependent Grounding Module（阶段依赖定位模块）**：通过显式监督锚定视觉证据；
3. **DiT-based Action Generation（基于扩散Transformer的动作生成）**：预测平滑的连续轨迹。

#### 2.2 Frequency Token Router

- **特征域频谱分解**：对视觉特征网格（而非原始RGB像素）沿两个空间轴应用二维DCT变换，将特征分解到频率空间，同时保留通道维度。
- **固定低频核心提取**：通过低通滤波裁剪低频分量并重建回空间域，得到前视/下视的固定核心token（保留全局语义）。
- **自适应频段银行构建**：将8×8频率网格按频率半径分为三个重叠频段：低频（r≤2）、中频（2≤r≤4）、高频（r≥4），两视角×三频段共产生6个候选频段银行。低频补充粗粒度布局，中频强调物体尺度结构，高频保留局部边界和纹理证据。
- **目标条件离散路由**：将目标描述的文本嵌入投影为6维logits，通过Gumbel-Softmax（straight-through估计器）实现可微分的离散选择，在固定token预算内选出一个自适应证据银行，与固定低频核心拼接形成最终的路由视觉token（共50个）。

#### 2.3 Phase-dependent Grounding

- 将路由后的视觉token插入Qwen VLM的提示序列中，追加128个可学习定位查询（排列为16×8网格并注入二维位置编码）。
- 通过与VLM深层自注意力机制的交互，这些查询与阶段感知的视觉特征及目标描述充分融合，输出接地查询状态。
- 通过辅助预测头输出二维空间热图，将热图锚定到“向前3步”（h_g=3）的专家航点在未来时刻的投影位置，实现显式空间监督，将视觉证据蒸馏为具体的空间表征。

#### 2.4 DiT-based Action Generation

- 采用Flow Matching框架，由DiT参数化，基于接地查询状态和当前UAV状态，通过条件向量场匹配生成K步连续航点（前进位移、垂直位移、偏航角），同时由并行分类头输出停止概率。
- **两阶段训练**：第一阶段用LoRA微调Qwen主干以进行多模态感知；第二阶段冻结VLM特征，训练DiT控制器。
- **推理**：从纯噪声出发，用16步均匀Euler步长解流匹配得到航点，并采用高频重规划策略（每执行一步后立即重新生成动作）防止误差累积。

### 3. 实验设计

#### 3.1 数据集与基准

- **基准**：TravelUAV benchmark中的UAV-Need-Help任务（基于AirSim仿真）。
- **数据规模**：12,149条人类操控轨迹，涵盖89个物体类别，场景包括城市、雪地、草地等户外环境，目标距离50–400米。
- **划分**：按轨迹长度分为Easy（<250m）和Hard（≥250m）；训练集7,922条轨迹，三个评估集：Seen Scenarios（1,418条）、Unseen Objects（629条）、Unseen Maps（958条）。
- **评估指标**：成功率（SR）、或acles成功率（OSR）、路径加权成功率（SPL）、导航误差（NE），成功半径为20m。

#### 3.2 对比方法

对比了多类基线：Random Action和Fixed Action（随机/固定动作下界）、CMA（循环跨模态注意力策略）、TravelUAV-DA（官方基准）、NavFoM（开放世界导航）、LongFly（长时程UAV导航）、AeroVLA（最强的端到端VLA基线）。

#### 3.3 主要实验结果

- **Seen Scenarios**：FreqNav全量SR 51.55%和SPL 41.67%为最优，较AeroVLA提升3.59% SR和3.13% SPL；Hard轨迹上提升最大（SR +7.40、SPL +5.88）。
- **Unseen Objects**：全指标最优，SR 57.23%、OSR 70.75%、NE 58.39m，其中OSR较AeroVLA提升5.89%。
- **Unseen Maps**：除NE外全指标最优，SR 39.04%（+1.46）、OSR 55.11%（+2.19）、SPL 30.50%（+2.28）；Hard轨迹上提升显著（SR +5.79、SPL +5.27）。

#### 3.4 消融实验

共三组消融实验：

1. **路由token容量**（50个视觉token下，自适应证据银行分配10 vs 20）：10/50配置最优（SR 51.55%），20/50导致严重性能下降（SR 39.02%），验证了高度稀疏视觉表征的鲁棒性。
2. **热图定位地平线**（h_g=1, 2, 3, 4 vs 无定位）：h_g=3最优（SR 51.55%），过短缺乏推理能力，过长导致过平滑问题。
3. **DiT航点块长度**（K=1, 2, 3 vs MLP基线）：K=1最优（SR 51.55%），更长块加剧复合误差。

#### 3.5 真实世界部署

在Feisi J310无人机平台上进行空地协同部署，对比AeroVLA的端到端延迟：FreqNav的VLM推理延迟为0.17s/步（AeroVLA为0.53s/步），完整重规划周期0.50s/步（AeroVLA为0.86s/步）。

### 4. 资源与算力

- 使用**4 × NVIDIA RTX A6000 GPU**进行分布式训练，每设备batch size为8，全局batch size为32。
- 训练**3个epoch**，使用AdamW优化器（学习率10⁻⁴，权重衰减0.01），bfloat16混合精度。
- 主干为Qwen2.5-VL-3B-Instruct，LoRA参数r=64，α=128，dropout=0.05。

### 6. 主要结论与发现

- **有效性的验证**：FreqNav在三个测试集上全面超越最强VLA基线AeroVLA，尤其在Hard轨迹上优势最大（SR提升最高达7.40个百分点），说明频率自适应路由在长时程导航+精确降落的双重要求场景下收益最大。
- **效率的验证**：通过将128个视觉token压缩到50个路由token，实现约3×推理加速；真实部署中VLM推理延迟仅0.17s/步，满足2m/s飞行速度下的实时闭环控制需求。
- **设计深度的验证**：过于稀疏（10/50最优）而非更多token（20/50）的视觉表征对目标条件决策更鲁棒；接地地平线过长导致过平滑；单步航点（K=1）在拓扑离散空间中优于多步块预测。

### 7. 优点

- **视角新颖**：首次将空中VLN的阶段性感知需求与频域表征联系起来，提出了“频率偏好转移”的新概念，为VLN中的视觉token优化提供了新的理论角度。
- **方法轻量高效**：在不增加计算资源（固定token预算）的情况下，通过智能路由同时提升性能和效率，实现“一石二鸟”。
- **模块设计精良**：双视角固定核心+自适应证据银行的组合、重叠频谱掩码的细节处理、特征域（而非像素域）的频率分解，均体现了精细的设计考量。
- **验证链条完整**：从仿真benchmark到真实无人机部署，从性能到延迟均有实验支撑，具有较高的实践参考价值。
- **泛化能力**：在Unseen Objects和Unseen Maps上均实现稳定提升，说明方法对目标泛化和环境泛化都有良好表现。

### 8. 不足与局限

- **实验覆盖有限**：消融实验仅在Seen Scenarios上报告，未提供Unseen集上的消融结果，削弱了对方法在泛化场景中增益来源的归因能力。真实部署仅涉及有限物体和地图，泛化性论证不足。
- **路由策略的解释性不足**：未分析路由器在导航不同阶段实际选择的频率银行分布，未验证“早期选低频、后期选高频”的核心动机是否在路由行为中真实体现，使“频率偏好转移”更多停留在设计假设层面。
- **token budget的敏感性**：消融显示将路由token从10增至20会导致SR从51.55%暴跌至39.02%，说明方法对token分配非常敏感，泛化能力存疑。
- **对比公平性有隐忧**：与AeroVLA的延迟对比中，FreqNav的3×加速主要来自视觉token压缩，但AeroVLA可能并未采用同等token预算优化，需确认对比是否在相同计算预算下进行。
- **训练数据与任务的局限**：仅在AirSim仿真环境中训练，仿真到现实的域差距问题仍存在；实际部署场景的多样性（天气、光照、感知噪声）未被充分验证。
- **架构扩展性**：基于Qwen2.5-VL-3B，较大模型上的路由机制有效性未验证；在第2阶段冻结VLM特征可能限制了控制模块与感知表征的联合优化。
