## 摘要
世界动作模型（WAM）通过建模观测如何演变来改进机器人控制，但在测试时生成未来观测会产生大量延迟。Fast-WAM为了效率去除了这一过程；然而，我们匹配的实现显示，Fast-WAM的泛化能力低于考虑未来的替代方案，尤其是在机器人演示稀缺和分布外场景中。为弥合这一差距，我们引入了**LAWA**，一种WAM架构，使用紧凑的潜在动作作为未来意图的操作性表示，从而在不生成未来观测的情况下实现高效的测试时未来想象。具体来说，一个通过无动作预训练增强的离散分词器生成以操作为中心的码本目标。LAWA将锚定到这些目标的连续潜在状态与可执行的动作块联合去噪，同时在推理时省略未来视频分支。在RoboCasa上，LAWA在少样本和全数据设置下分别达到了65.6%和80.8%的最先进平均成功率，比匹配的Fast-WAM基线分别高出9.6和4.5个百分点。它还保持了匹配的Joint-WAM变体的性能水平，同时推理延迟降低了42.9%。LAWA还在LIBERO-Plus上展示了具有竞争力的零样本鲁棒性，并在真实世界任务中表现出优越性能。这些结果表明，未来想象不必被抛弃：通过紧凑的潜在动作保留它，可以在性能、泛化和延迟之间取得有效的权衡。代码和模型将发布。

## Abstract
World action models (WAMs) improve robot control by modeling how observations evolve, but generating future observations at test time incurs substantial latency. Fast-WAM removes this process for efficiency; however, our matched implementations show lower generalization for Fast-WAM than for future-aware alternatives, especially with scarce robot demonstrations and in out-of-distribution scenarios. To bridge this gap, we introduce **LAWA**, a WAM architecture that uses compact latent actions as an operational representation of future intentions, enabling efficient test-time future imagination without generating future observations. Specifically, a discrete tokenizer enhanced by action-free pre-training produces manipulation-centric codebook targets. LAWA jointly denoises a continuous latent state anchored to these targets with executable action chunks while omitting the future-video branch at inference. On RoboCasa, LAWA achieves state-of-the-art average success rates of 65.6% and 80.8% in the few-shot and full data settings, improving over the matched Fast-WAM baseline by 9.6 and 4.5 points, respectively. It also preserves the performance level of the matched Joint-WAM variant while requiring 42.9% lower inference latency. LAWA also demonstrates competitive zero-shot robustness on LIBERO-Plus and superior performance on real-world tasks. These results show that future imagination need not be discarded: retaining it with compact latent actions yields an effective trade-off among performance, generalization, and latency. Code and models will be released.

## 2. 论文提出的方法论

### 核心思想

LAWA 将未来想象从观测空间（像素级视频预测）压缩至潜在动作空间，用一个离散分词器预训练得到的紧凑码本序列作为"未来的意图"，动作专家在推理时基于该意图与当前观测联合降噪生成可执行动作，全程无需生成未来视频帧。

### 关键技术细节

**① 潜在动作分词器（Latent Action Tokenizer）**

- 采用 DINOv2 编码器提取每帧 patch token，经非因果 Transformer（分解空间与时间注意力）获取上下文特征；
- 通过相邻帧特征差分捕捉动态转移，空间压缩为 L 个 token 后量化为离散码本嵌入；
- **前向解码器**以观测重建（下一帧预测）为目标，迫使离散码保留静态外观无法推断的转移信息；
- **掩码预测辅助监督**：加入 SAM 风格的掩码解码器，以潜在动作作为 prompt，预测手/机械臂掩码。掩码目标由 SAM 2 自动生成，无需人工标注；该设计将表示偏置导向交互区域，避免视频重建偏向静态外观。

**② 无动作自我中心视频预训练**

- 同时利用机器人视频和人类自我中心视频（egocentric videos）进行无监督预训练；
- 采用**每源帧采样对齐**（per-source frame sampling）协调异构数据间运动速度分布差异；
- 采用**加权重采样**，使机器人视频占比约 20%，保证机器人域的基础同时利用多样化的自我中心操作视频。

**③ 潜在动作未来意图（Latent Action as Intention）**

- 机器人策略训练时，冻结分词器，将观测序列编码为目标潜在动作 lt+1:t+H；
- LAWA 联合训练三个专家：视频去噪、潜在动作去噪与可执行动作去噪，通过多模型联合注意力耦合；
- **结构化注意力掩码**：潜在动作 token 只能访问当前观测和自身序列；动作 token 可访问当前观测、潜在动作序列与自身；防止未来观测信息泄露；
- 训练时目标由码本嵌入提供；**推理时**未来视频分支完全省略，当前观测特征缓存一次，仅对潜在意图和动作块联合迭代去噪，保持训练/推理一致的可视性掩码。

**④ 训练目标**

- 分词器预训练：`Ltok = L₁ + λperc·Lperc + λmask·Lmask`（L₁ 与 LPIPS 监督下一帧重建，Lmask 为掩码预测的 BCE + Dice + IoU）；
- 量化采用噪声替换量化（NSVQ），辅以低用量码字定期刷新防坍缩；
- 策略训练对视频、潜在动作、动作三个分支分别独立采样高斯噪声和偏移流时间，用流匹配（flow matching）目标训练：
  `L_LAWA = λvid·Lvid + λlat·Llat + λact·Lact`。

## 6. 论文的主要结论与发现

1. **潜在动作作为未来意图是有效的替代范式**：在 RoboCasa 上 LAWA 少样本成功率 65.6%、全数据 80.8%，比匹配的 Fast-WAM 提升 9.6 和 4.5 个百分点，同时与显式未来观测预测的 Joint-WAM 性能相当；
2. **推理延迟大幅降低**：相比 Joint-WAM 降低 42.9%（593.1 ms → 338.5 ms），仍保留测试时未来想象的收益；
3. **零样本鲁棒性更强**：LIBERO-Plus 总成功率 74.4%，比 Fast-WAM 高 14.4 点、比 Joint-WAM 高 4.0 点，尤其在相机视角（+44.3 点）和传感器噪声（+27.5 点）扰动下优势突出；
4. **自我中心预训练收益最大**：LAWA 从无动作自我中心视频中获得的增益（少样本 +5.9、全数据 +4.5）远大于 Fast-WAM 和 Joint-WAM；且 LAWA 随视频语料规模增长持续受益，而 Fast-WAM 收益近乎饱和。**无预训练时 LAWA 弱于 Joint-WAM，预训练后反超**，说明紧凑潜在动作接口需要大规模无标注视频配合；
5. **潜在动作路径被功能性使用**：推理时扰动潜在状态（噪声/打乱）导致成功率从 80.8% 降至 52.2%/56.4%，证明动作生成确实依赖该路径；
6. **真实世界验证**：LAWA 在精细装配与长周期任务上全面超过 Fast-WAM；仅用 25% 演示即可超过 Fast-WAM 全数据平均成功率（40.0% vs 33.8%）。
