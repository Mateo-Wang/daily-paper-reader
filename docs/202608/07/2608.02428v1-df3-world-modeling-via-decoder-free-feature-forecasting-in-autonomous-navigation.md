从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前在像素级别操作的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过高。虽然基于潜变量的方法尝试通过直接预测特征来缓解这一问题，但对用于状态到任务映射的重型解码器的持续依赖仍然是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），一种全新的框架，完全在潜空间内建模世界演化并直接生成任务输出，彻底消除了对解码器的需求。具体而言，DF$^3$将可学习的空间查询注入冻结的视觉基础模型的末端块，直接提取未来状态表示。通过采用轻量级、统一的多模态感知上下文融合（MACF）机制，该机制无缝地将粗粒度光流扭曲与细粒度潜变量互相关相结合，这些查询与历史标记表示交互，显式地对齐和预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准测试和机器人模拟器中的零样本部署上的大量实验表明，DF$^3$在实现与最先进方法相当的性能的同时，为集成感知和控制提供了卓越的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

  - **潜在空间预测方法**：在语义特征空间中预测未来特征（如 DINO-WM、DINO-Foresight），一定程度上减少了冗余细节，但仍然依赖重型解码器进行特征重建和任务映射，计算瓶颈依然存在。
- **核心问题**：是否可以在冻结的视觉基础模型（VFM）的编码器内部，完全无需解码器地完成未来特征预测和下游任务输出？
- **论文答案**：提出 **DF³（Decoder-Free Feature Forecasting）** 框架，在完全冻结的 ViT 编码器空间内完成世界模型的未来预测，并通过查询注入直接生成任务输出，彻底消除解码器计算开销。

## 2. 方法论

### 2.1 核心思想
- 利用预训练 DINOv3-ViT 作为**冻结**编码器，保留其丰富的语义表征能力。
- 在编码器**末端块**（terminal blocks）中注入两类可学习查询：
  - **预测查询（Prediction Queries）**：负责与历史上下文交互，生成下一帧的潜在特征表示。
  - **任务查询（Task Queries）**：基于预测特征，为下游任务（如语义分割）提取任务相关表示。
- 整个流程不引入任何独立解码器，所有预测和任务输出均在编码器内部通过注意力机制实现。

### 2.2 关键技术细节

#### 结构化查询注意力（Structured Query Attention）
- 在注入查询的末端自注意力层中施加**非对称注意力掩码**：
  - 上下文 tokens 可以互相注意，但**禁止**注意预测查询，防止信息泄露。
  - 预测查询可以注意所有上下文 tokens，用于聚合历史信息。
- 该掩码保证了上下文表示的纯净性，使查询专注于未来预测。

#### 运动感知上下文融合（MACF）机制
- 目的：使冻结的静态图像编码器具备时序建模能力，显式对齐运动特征。
- 包含**两个并行分支**：

1. **光流扭曲分支（Flow-based Warp）**：
   - 从预测查询预测稠密潜在光流场 \(\Delta p\)，将最近历史帧特征 \(f_{L1}(I_T)\) 扭曲到未来时刻，得到粗对齐特征 \(\tilde{f}_{warp}\)。
   - 计算扭曲特征与查询特征的差异，作为更新方向 \(M_{warp}\)。

2. **潜在互相关分支（Latent Cross-Correlation）**：
   - 在历史帧 \(I_{T-1}\) 和 \(I_T\) 之间，对每个空间位置在局部窗口（半径 \(r\)）内进行软匹配（cosine similarity + softmax）。
   - 计算“历史语义运动” \(V_{hist}\)，即当前特征与软匹配的上一帧特征的差，再经 MLP 投影为 \(M_{xcorr}\)。

3. **动态融合（Dynamic Fusion）**：
   - 两个分支输出拼接后经 MLP 融合，并用**可学习的 sigmoid 门控** \(G(q_{patch})\) 控制残差注入：
     \[
     \hat{f}_{L1}^{patch}(I_{T+1}) = q_{patch} + G(q_{patch}) \odot MLP_{fuse}([M_{warp}, M_{xcorr}])
     \]
   - 全局前缀 tokens 采用轻量级时间外推器，基于历史差分预测全局语义演化。

#### 训练目标
- 在特征层面进行监督，不依赖下游任务解码器联合训练。
- 损失函数 = **余弦相似度**（方向对齐）+ **Huber 损失**（幅度稳定化），对 patch tokens 和 prefix tokens 均计算。

## 6. 主要结论与发现

- DF³ 在 Cityscapes 上取得 **69.9 mIoU / 68.7 MO-mIoU**（短期），相比 DINO-Foresight（71.8 / 71.7）仅有小幅下降，但效率大幅提升：
  - FLOPs 降低 **36%**（1440.63 GFLOPs）
  - 推理延迟降低 **70%**（292.4 ms）
  - 峰值 GPU 内存降低 **67%**（3.1 GB）
  - 参数减少 **41%**（177.0 MB）
- 中期预测（T+3）性能下降明显（58.2 mIoU），表明自回归累积误差仍存在，但效率优势保持。
- **消融结论**：
  - 简单拼接或全局注意力不足以建模运动；显式运动建模（Warp 或 Xcorr）带来明显增益，两者组合最佳。
  - 互相关搜索半径 \(r=\{1,2,4,8\}\) 最佳；过小无法捕捉快速运动，过大（16）引入噪声。
- **定性分析**：预测特征能准确捕捉动态物体未来位置，但存在边缘粗糙、薄结构模糊等空间过平滑问题；在 MATRiX 仿真器中零样本驱动四足机器人轨迹规划，与 Oracle 轨迹高度对齐，验证了跨实体泛化能力。

## 7. 优点

- **方法创新性**：
