## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习具有前景。然而，人类与机器人之间的具身差异使这一任务具有挑战性。一种有前景的解决方案是学习与具身无关的、以物体为中心的可执行可供性。在这项工作中，我们提出了一种框架，利用以自我为中心的人类视频，结合最先进的3D运动恢复结构和手部网格重建，提取可执行的可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了在哪里交互、如何抓取以及如何移动。我们构建了EgoAffordance，这是一个大规模数据集，包含204K个片段，具有5.6M个视觉可供性和11.6M个抓取与轨迹可供性。在此基础上，我们引入了VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可执行可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的行动。通过大量实验，我们证明了VLAff不仅在视觉可供性预测上达到了最先进的性能，而且可以有效地应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

### 2. 论文提出的方法论：核心思想、关键技术细节

**核心思想**：从大规模第一视角（egocentric）人类视频中提取三类可执行可供性（视觉、抓取、轨迹），构建大规模数据集，并在一个基于大视觉-语言模型（VLM）的统一架构中联合学习这三类可供性的跨模态相关性。给定RGB图像和自然语言指令，直接输出视觉可供性热图、MANO手部抓取参数和6D手部轨迹。

**关键技术细节（数据提取流水线）**：

1. **数据准备**：利用现有egocentric视频数据集的语言描述与时间标注，对交互时间戳附近的帧进行采样；通过预训练大VLM提取关键交互信息（接触关键帧、动作标签、物体类别、交互手）。
2. **手-物交互提取**：
   - 使用手-物检测器获取手和物体的边界框；
   - 生成物体分割掩码并提取2D手部关键点；
   - 通过指尖关键点与物体掩码的交集识别接触区域并跟踪；
   - 使用MANO参数进行3D手部网格重建；
   - 为减少自我视角偏差，进行ego分割和视频修复（inpainting）。
3. **Ego-centric SfM（运动恢复结构）**：
   - 对修复后的帧进行单目深度估计；
   - 估计相机内参和相机位姿（过滤动态区域以保证稳健性）；
   - 结合相机位姿和深度图，跟踪3D手部轨迹，捕获接触前和接触后的运动模式。
4. **物体中心化变换**：将视觉热图峰值点投影到3D空间作为锚点，将抓取姿态和轨迹相对于该锚点进行空间变换，得到物体中心的抓取与轨迹表示，从而实现跨具身迁移。

**VLAff模型架构**：

- 基座VLM：Qwen2.5-VL，处理图像和语言指令，为所有token生成上下文嵌入。
- 额外视觉编码器：DINOv2，提供细粒度空间理解能力，弥补VLM在精确视觉定位上的不足。
- 三类专门token：
  - `<SEG>`：视觉可供性token，其嵌入通过分割解码器（类似LISA）生成像素级视觉可供性热图；
  - `<GRASP>`：抓取token，解码为96维MANO手部参数（全局手腕旋转 + 15个局部关节旋转，6D旋转表示）；
  - `<p*>`：轨迹token序列，通过空间分箱（spatial binning）将6D姿态空间离散化，采用自回归方式生成轨迹token序列。
- **训练损失**：视觉采用Soft Dice Loss（p=1.5），抓取采用Smooth L1 Loss，轨迹采用标准交叉熵损失；总损失为三者加权和。

**推理策略（提升3D轨迹物理合理性）**：

- **上下文轨迹引导**：利用GPT等高性能VLM作为高层规划器，提供3D方向向量（每个分量∈{-1,0,1}，编码相机坐标系的粗粒度运动意图），引导首个轨迹token的采样。
- **基于采样的轨迹选择**：使用核采样（top-p）生成K个候选轨迹，结合体素化碰撞检测和方向对齐的复合目标函数，选择最优轨迹。

### 3. 实验设计：数据集、Benchmark与对比方法

**数据集构建**：
- **EgoAffordance（本文构建）**：204,025个片段，包含5,782,431个视觉可供性热图和11,612,524个轨迹序列。来源包括EPIC-KITCHENS、Ego4D、Ego-Exo4D、H2O、HOI4D、HD-EPIC等多种egocentric视频数据集，覆盖16.4K个物体类别。
- 额外引入HANDAL和SceneFun3D数据，用于提升细粒度视觉可供性预测。
- 与现有数据集相比（UMD、AGD20K、IIT-AFF、ADE-Aff、HOVA-500K、H2O、HOI4D、EPIC-KITCHENS、HD-EPIC、Ego4D、Ego-Exo4D），EgoAffordance是唯一同时提供视觉可供性、手部姿态和相机轨迹三种标注的数据集。

**实验一：视觉可供性预测**：
- 测试集：从每个egocentric视频数据集中随机采样500个场景。
- 指标：IoU、NSS（归一化扫描路径显著性）、SIM（相似度）、KLD（KL散度）。
- 对比方法：VRB、UAD、3DOI、LISA（其中LISA为LLM-based开放词汇分割模型，输出归一化处理）。

**实验二：零样本操作**：
- 仿真环境：IsaacGym，包含PartManip、FrankaKitchen、ManiSkill的10个日常家庭任务（开门铰链柜、拉滑动柜、开微波炉、关微波炉、拿起水壶、开洗碗机、掀盖子、拉抽屉、关铰链柜、开水龙头）。
- 真实环境：Fetch和PR2移动操作机器人，5个厨房任务（开抽屉、拿起水桶、开锅盖、取平底锅、拿起水壶）。
- 每个任务测试10次，不进行任务特定训练。
- 对比方法：RAM、VRB、GeneralFlow、VidBot。基线不直接输出抓取姿态，统一用GraspNet生成；VLAff用手部姿态重定向估计夹爪姿态。

**实验三：可供性引导的操作学习（消融）**：
- 真实世界"开冰箱"任务，采用强化学习，奖励由VLM判定任务成功+可供性引导的稠密奖励。
- 消融配置：完整模型 vs 去除视觉热图 vs 去除抓取姿态 vs 去除轨迹。

### 6. 论文的主要结论与发现

1. **统一学习优于孤立学习**：联合学习视觉、抓取、轨迹三类可供性能够提升视觉可供性预测的性能，验证了跨模态相关性学习的关键假设。
2. **视觉可供性预测达到SOTA**：VLAff在IoU（0.121）、NSS（1.542）、SIM（0.142）、KLD（2.517）四个指标上均优于VRB、UAD、3DOI、LISA。
3. **真实世界零样本操作优势显著**：VLAff在真实机器人上平均成功率68%，比VidBot（52%）高16个百分点，表明大规模真实egocentric视频训练比依赖深度空间输入的仿真方法更适应真实场景复杂性。
4. **仿真场景中与VidBot相当**：仿真平均成功率83.0%，略低于VidBot的85.0%（VidBot可直接访问深度信息）。
5. **视觉可供性在操作学习中不可或缺**：消融实验显示，去除视觉热图后模型完全无法完成任务；抓取姿态的作用相对较小，原因是人手与夹爪形态差异大，精确手部姿态难以直接迁移。
6. **局限性**：偶尔会生成物理上不合理的轨迹，未来需结合3D场景感知的模型架构加以改进。

### 7. 优点（方法与实验设计的亮点）

- **数据规模化与全面性**：构建了目前最全面的可执行可供性数据集EgoAffordance（204K片段、560万视觉热图、1160万抓取/轨迹标注），远超现有数据集。
- **统一的框架设计**：首次将视觉、抓取、轨迹三类可供性整合在一个VLM框架中联合学习，利用跨模态相关性提升各模态预测质量，而非孤立建模。
- **物体中心的表示方式**：通过3D锚点将抓取和轨迹转换为物体中心坐标系，有效解决了人类到机器人迁移中的具身差异问题。

- **推理策略设计**：利用VLM高层推理提供方向引导 + 基于碰撞检测的采样选择，在推理阶段提升了3D轨迹的物理合理性，思路新颖。
- **多维度实验验证**：从静态预测、零样本操作（仿真+真实）、到策略学习辅助三个层面验证方法有效性，实验体系完整。
- **真实机器人验证**：在Fetch和PR2两台移动操作机器人上验证了方法的实际可用性。

### 8. 不足与局限

- **轨迹物理合理性待提升**：模型偶尔生成不满足物理约束的轨迹，虽引入引导策略但仍未完全解决。

- **仿真性能不及SOTA**：VidBot凭借深度输入在仿真中取得更高成功率（85% vs 83%），说明VLAff在空间精度上仍有提升空间。
- **算力信息披露不足**：未报告训练所需的GPU资源、时长和模型参数量，影响复现与可扩展性评估。
- **消融实验范围有限**：可供性引导RL消融仅在单一真实任务上验证，且未对轨迹引导策略（上下文引导、采样选择）做单独消融。
- **baseline公平性问题**：基线方法本身不输出抓取姿态，统一用GraspNet补全可能不是最优配置；同样VidBot使用了深度输入而VLAff没有，实验条件并非完全对齐。
- **语言指令依赖**：方法依赖预训练VLM提取交互信息和推理方向引导，存在级联误差风险，若场景理解出错，后续轨迹生成也会受影响。
