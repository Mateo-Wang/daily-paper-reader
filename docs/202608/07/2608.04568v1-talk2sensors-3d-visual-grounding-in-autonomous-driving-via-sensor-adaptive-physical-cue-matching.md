## 摘要
作为具身智能的关键能力，3D视觉定位（3DVG）主要在室内场景中借助RGB-D或点云输入进行研究，而现有的室外扩展大多仅依赖单目图像。这两种设置都无法满足真实世界室外感知的需求，在室外环境中，异构传感器捕获互补但不同的物理属性，如视觉纹理、3D几何和物体运动学，这些属性对于灵活且鲁棒的查询自适应定位至关重要，但目前尚未得到充分利用。为弥补这一差距，我们提出了Talk2Sensors，这是首个基于相机、LiDAR和4D雷达构建的多传感器3D视觉定位数据集。它包含8,682条语言指令和20,558个被指对象，其中多样的提示明确与传感器特定的物理线索对齐。此外，我们提出了TSFormer，一个统一的基于Transformer的框架，用于自动驾驶中的语言引导3D视觉定位。TSFormer采用了一种由粗到细的属性感知融合策略：语言路由属性采样器（Language-Routed Property Sampler）首先通过使用查询级语言线索调制传感器采样权重来执行粗略的文本条件特征检索，随后的稀疏保持模态仲裁器（Sparse-Preserving Modality Arbiter）模块进行细粒度的模态仲裁和文本引导细化，以确定精确的被指空间位置。这种设计使得能够根据每个提示的语义需求动态路由外观、几何和运动线索，防止密集模态压过稀疏但关键的传感器信号。大量实验表明，TSFormer在多个基准上取得了最先进的性能：在Talk2Sensors上比最强基线提高了8.05 mAP，并在单目Mono3DRefer基准上实现了53.05%的Acc@0.5。

## Abstract
As a key capability for embodied intelligence, 3D visual grounding (3DVG) has been predominantly studied in indoor scenes with RGB-D or point-cloud inputs, while existing outdoor extensions largely rely on monocular images alone. Both settings fall short of real-world outdoor perception, where heterogeneous sensors capture complementary yet distinct physical properties, such as visual texture, 3D geometry, and object kinematics, that are indispensable for flexible and robust query-adaptive grounding but remain under-exploited. To bridge this gap, we introduce Talk2Sensors, the first multi-sensor 3D visual grounding dataset built upon camera, LiDAR, and 4D radar. It contains 8,682 language instructions and 20,558 referred objects, with diverse prompts explicitly aligned with sensor-specific physical cues. Furthermore, we propose TSFormer, a unified Transformer-based framework for language-guided 3D visual grounding in autonomous driving. TSFormer adopts a coarse-to-fine property-aware fusion strategy: the Language-Routed Property Sampler first performs coarse text-conditioned feature retrieval by modulating sensor sampling weights with query-level linguistic cues, while the subsequent Sparse-Preserving Modality Arbiter module conducts fine-grained modality arbitration and text-guided refinement to determine the precise referred spatial location. This design enables dynamic routing of appearance, geometry, and motion cues according to the semantic requirements of each prompt, preventing dense modalities from overwhelming sparse but critical sensor signals. Extensive experiments demonstrate that TSFormer achieves state-of-the-art performance across multiple benchmarks: it improves over the strongest baseline by 8.05 mAP on Talk2Sensors, and transfers to the monocular Mono3DRefer benchmark with 53.05\% Acc@0.5.

## 2. 提出的方法论

### 核心思想
- 将语言查询视为“路由信号”，动态决定从哪些传感器提取证据，而不是对所有模态进行无差别融合。
- 采用**粗到细**策略：先通过语言条件粗略检索相关传感器特征，再通过细粒度模态仲裁和文本引导精确定位。

### 技术细节（TSFormer框架）

整体流程：各模态骨干提取特征（相机ResNet+FPN、LiDAR PointPillar/SECOND、雷达RadarFeatureNet+PointPillarsScatter）→ 文本用CLIP编码 → 两个核心模块处理 → 共享Transformer解码器输出3D框。

#### (a) Language-Routed Property Sampler (LRPS)
- 将全局文本特征投影到各传感器语义空间：`t_m = φ_m(t)`
- 计算文本与查询的通道级相似度：`D_m = Σ_c (Q_c ⊙ t_{m,c})`
- 通过可学习温度参数获得调制因子：`G_m = σ(τ_m D_m)`
- 将调制因子广播到可变形注意力权重上，在Softmax前乘以权重：
  `ĥA_m = Softmax(A_m ⊙ E(G_m))`
- 采样位置由参考点加偏移得到：`S_m = R_m + Δ_m/Ω_m`
- 最终通过多尺度可变形注意力聚合传感器特征：`O_m = MSDeformAttn(V_m, S_m, ĥA_m)`
- 效果：让采样过程显式受语言指导，优先提取与文本属性（几何、外观、运动）相关的区域。

#### (b) Sparse-Preserving Modality Arbiter (SPMA)
- 从文本令牌池化出全局语义向量：`t_g = φ_g(mean(T))`
- 通过轻量门控网络预测模态权重：`z = η_g(t_g)`，可选Top-K稀疏化，再Softmax归一化得`α = [α_cam, α_lidar, α_radar]`
- 加权融合各传感器采样特征：`F_s = Σ_m α_m O_m`
- 将融合特征作为查询，文本令牌作为键值，执行多头交叉注意力：`F_c = MHA(Q=F_s, K=T, V=T)`
- 最后经前馈网络+残差+层归一化得到`F_SPMA`。
- 效果：样本级模态门控防止密集相机特征淹没稀疏但关键的雷达信号。

#### (c) 解码与预测
- 采用DETR风格集合预测：900个查询，6层解码器。
- 每个查询输出指向置信度`α`（二分类，不预测类别）和3D框参数（中心、尺寸、偏航角）。
- 使用二分图匹配（匈牙利算法），损失包含交叉熵、L1回归、3D GIoU，并加入辅助解码层损失。

- **Mono3DRefer**（跨数据集泛化）：基于KITTI的单目3D视觉定位基准，使用Acc@0.25和Acc@0.5评估Unique/Multiple/Overall三个子集。

## 6. 主要结论与发现

- **三传感器互补有效**：TSFormer在完整配置下达到最高性能（EAA mAP 51.0），且性能随模态增加而单调提升，而FUTR3D融合所有模态后反而低于仅LiDAR设置，说明TSFormer的路由机制真正利用了异构线索。
- **语言引导是核心**：无文本输入的变体mAP仅为0.007，证明任务是“参照性”而非“穷举检测”。
- **雷达的价值**：在涉及雷达的提示上增益最大（如Camera+Radar提升8.16，Camera+LiDAR+Radar提升10.83），验证了语言路由对稀疏运动线索的重要作用。
- **鲁棒性**：推理时缺失相机或雷达时TSFormer退化更平稳，软门控提供了有效回退；LiDAR仍是几何主干，缺失LiDAR性能大幅下降。
- **跨数据集泛化**：TSFormer迁移到Mono3DRefer时在IoU=0.5阈值下显著超越专门方法，定位更精确。

## 7. 优点

- **首个三传感器3D视觉定位数据集**：填补了室外多传感器物理线索对齐的语言定位空白，提示基于可量化的客观物理属性（而非主观描述），并通过三级专家审核保证质量。
- **新颖的语言引导融合机制**：LRPS将语言调制注入可变形采样权重，SPMA用文本条件门控+Top-K稀疏化，使模型能够“按需取用”传感器信息，避免了传统刚性投影和均匀融合的缺陷。
- **统一框架，模块可替换**：基于FUTR3D实现，采样器与融合模块可独立替换，便于公平比较；解码器采用标准DETR范式，方法通用性强。
- **实验严谨**：大量消融与模块对比，定量与定性结合，并提供了效率、鲁棒性、传感器组合增益等多角度分析。
- **跨数据集验证**：显示了设计在单目任务上的可迁移性，增强了方法的可信度。

## 8. 不足与局限

- **数据集规模与多样性有限**：仅基于View-of-Delft单一城市场景，对象类别多为机动车、行人、骑行者等，缺乏恶劣天气、夜间、不同城市和复杂路口场景的数据，雷达的优势在不利天气下未能体现。
- **雷达单独性能过低**：仅雷达输入时mAP仅1.46，虽然解释为雷达稀疏性，但可能反映雷达特征编码或采样仍不足，模型对雷达的依赖需要进一步探索。
- **跨数据集验证较窄**：Mono3DRefer本身是单目基准，虽然补充了KITTI LiDAR，但缺乏完整三传感器（KITTI无雷达）的迁移实验，不能完全证明方法在异质传感器上的泛化。
- **场景理解局限**：方法只输出3D框，未涉及目标属性分类、关系解析或轨迹预测；对包含多个同类对象和复杂空间关系的查询，性能仍有限。
- **计算资源描述不完整**：未提供训练时间、参数量、内存占用等细节，只能通过推理速度间接评估效率。
- **潜在偏差风险**：提示由人工编写，虽经审核，但可能带有标注者风格偏差；数据集基于固定传感器配置，实际部署时传感器缺失或未对齐的鲁棒性仍需进一步验证。
