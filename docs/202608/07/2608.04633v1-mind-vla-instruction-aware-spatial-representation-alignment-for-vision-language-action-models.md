## 摘要
最近的视觉-语言-动作（VLA）方法通过与3D场景几何对齐其表示来提升泛化能力。然而，这些方法从根本上是指令无关的：它们将整个场景统一对齐，忽略了语言指令所指定的特定目标物体的3D几何。这导致在精细操作和目标遮挡任务上失败，而这些任务的成功取决于对目标物体而非整个场景的准确3D理解。为解决这一问题，我们提出了Mind-VLA，一种用于VLA模型的指令感知空间表示对齐方法。具体而言，Mind-VLA首先获取语言指令指定的目标物体，然后准备其目标物体三视图并提取相应的VAE和VGGT特征。最后，将VLA模型的潜在表示与这些特征对齐，以实现指令感知的3D理解。Mind-VLA在LIBERO上达到93.9%，在CALVIN上达到4.47，且采用紧凑的345M参数骨干网络。在具有目标遮挡的真实机器人任务中，Mind-VLA达到54%的平均成功率，在真实机器人对比中比表现最佳的指令无关方法高出32个百分点。代码将公开提供。

## Abstract
Recent Vision-Language-Action (VLA) methods improve generalization by aligning their representations with 3D scene geometry. However, these methods are fundamentally instruction-agnostic: the representations align the entire scene uniformly, neglecting the 3D geometry of the specific target object designated by the language instruction. This causes failures on fine-grained manipulation and target occlusion tasks, where success depends on accurate 3D understanding of the target object rather than the entire scene. To address this, we present Mind-VLA, an instruction-aware spatial representation alignment method for VLA models. Specifically, Mind-VLA first obtains the target object specified by the language instruction, then prepares its target-object tri-view and extracts the corresponding VAE and VGGT features. Finally, the latent representation of the VLA model is aligned with these features to enable instruction-aware 3D understanding. Mind-VLA reaches 93.9% on LIBERO and 4.47 on CALVIN with a compact 345M-parameter backbone. On real-robot tasks with target occlusion, Mind-VLA reaches 54% average success, outperforming the best-performing instruction-agnostic method in real-robot comparison by 32 percentage points. Code will be publicly available.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：视觉-语言-动作（VLA）模型已成为机器人泛化操作的主流范式，将语言指令与视觉观测映射为机器人动作。然而，许多操作任务要求模型具备超越 2D 识别的 3D 理解能力，如物体形状、姿态、空间关系和遮挡推理。
- **核心问题**：现有 3D 感知型 VLA 方法在引入 3D 信息时本质上是**指令无关的**——它们将整个场景均匀地对齐到 3D 特征空间，忽略了语言指令所指定的**目标物体**的 3D 几何。这导致两类关键场景的失败：
  - **细粒度操作任务**：目标物体与干扰物视觉相似时，难以做出正确判别；
  - **目标遮挡任务**：模型未显式学习保留被指令物体的 3D 结构，在目标被部分遮挡时可靠性不足。
- **总体意义**：操作任务中最关键的几何信息往往不是整个场景，而是机器人被要求操作的**指令目标物体**。本文提出指令感知的目标级空间对齐，为 3D 感知 VLA 提供了新方向。

## 2. 论文提出的方法论：核心思想、关键技术细节与流程

### 核心思想
Mind-VLA 的核心理念是：将 VLA 模型的潜在表示与**指令指定的目标物体**的 3D 特征对齐，而非与场景级 3D 特征对齐。所有辅助模块仅用于训练，推理时完全移除。

### 整体流程
1. **目标物体获取**：从语言指令 ℓ 中解析出目标物体 m(ℓ)；
2. **目标物体三视图构建**：为 m(ℓ) 离线准备俯视、正视、侧视三个正交视角（仿真中由网格渲染；真实机器人用手持相机拍摄三个近似规范视角）；
3. **特征提取**：用冻结的 Stable Diffusion VAE 和三视图编码为紧凑潜在表示；用冻结的 VGGT 提取多层几何特征；
4. **表示对齐**：将 VLA 骨干网络的潜在表示分别与 VAE 特征和 VGGT 特征对齐。

### 关键技术细节

**（1）基于基础 VLA 的扩展**
- 输入：双 RGB 图像（主相机 + 腕部相机，224×224）+ CLIP 编码的语言指令 + 8 维本体感受状态，由因果 Transformer 处理；
- 动作预测：扩散动作头，基于 DiT（Diffusion Transformer），训练损失为噪声预测损失 L_act。

**（2）场景级辅助损失（保留）**
- 逐 patch 的 RGB 重建损失 L_obs 和稠密 2D 运动预测损失 L_traj，保持工作空间外观与短期动力学。

**（3）目标物体三视图潜在预测（L_tri）**
- 通过冻结的 Stable Diffusion VAE 将三视图编码为潜在表示 Z_m(ℓ)（比原始 RGB 小 48 倍）；
- 在骨干输入中附加可学习的物体查询 token q_tri，通过 MLP 解码为预测的潜在表示 Ẑ_t；
- 使用均方误差损失，将该预测与目标三视图潜在表示对齐。

**（4）多层级 VGGT 特征对齐（L_geo）**
- 选取骨干网络的 4 个中间层，每层与 VGGT 的一个特征层配对；
- 对每个配对层，将三视图的 VGGT 特征在视图和空间维度上做均值池化，同时将 VLA 图像 token 特征均值池化后经投影头映射到 VGGT 特征空间；
- 使用余弦相似度作为对齐度量。

**（5）最终训练目标**
L_MindVLA = L_VLA + λ_tri·L_tri + λ_geo·L_geo

### 与现有方法的本质区别
- 与 Spatial Forcing、GLaD 等方法的场景级 VGGT 对齐不同，Mind-VLA 的 VGGT 对齐目标是**指令指定的目标物体**的三视图几何。

- **CALVIN ABC-D**：长程链式操作基准，1000 次 rollouts，报告 per-task 成功率和平均完成长度（Avg. Len.）。

### 真实机器人平台
- UFactory xArm 6 机械臂，配备静态 RealSense D455 和腕部 RealSense D435 相机；

## 6. 论文的主要结论与发现

- **性能超越**：Mind-VLA 以 345M 参数（比 7B 级模型小 9–20 倍）在 LIBERO 上达到 93.9% 平均成功率，匹配 π0（94.2%）与 GLaD（94.1%）水平；在 CALVIN 上达到 4.47 平均完成长度，超越 VPP（4.29）和 Seer（4.28）。
- **指令感知是关键**：在相同架构下，目标物体三视图 VGGT 对齐（93.9%）优于场景图像 VGGT 对齐（92.8%），在 LIBERO-Object 上差距最大（+4.0 pp）。
- **遮挡鲁棒性显著**：真实机器人 25% 目标遮挡下，Mind-VLA 仅下降 13 pp（67 → 54），而场景 VGGT 消融变体下降 29 pp（57 → 28），Seer 下降 23 pp，OpenVLA 下降 21 pp；比最佳指令无关方法（Seer）高出 32 个百分点。
- **物体聚焦与规范视角的贡献分解**：在 LIBERO-Object 上，物体聚焦占 +2.5 pp（SAM 裁剪变体 96.5% vs 场景 VGGT 94.0%），规范视角先验再贡献 +1.5 pp（完整模型 98.0%）；规范视角更多在物理遮挡场景中发挥决定性作用。

## 7. 优点：方法或实验设计上的亮点

- **问题定位精准**：明确指出现有 3D 感知 VLA 的“指令无关性”缺陷，切中精细操作与遮挡场景的痛点；
- **低成本高收益**：辅助监督全部在训练期间完成，推理时仅保留查询 token 的微小额外计算，部署开销可忽略；
- **目标级三视图设计巧妙**：离线准备的三视图不受推理时视角变化或遮挡影响，提供了稳定的目标几何先验；
- **双层面对齐互补**：VAE 潜在预测从输出端施加目标几何约束，VGGT 多层对齐在中间层引导特征结构演化，形成自上而下与自下而上的双向约束；
- **消融对比严格公平**：A3a vs A3b 的场景级 vs 目标级对比是直接证据，可干净归因指令感知带来的增益；
- **真实机器人实验具有说服力**：用物理遮挡物模拟目标遮挡，直观展示实际部署场景中指令感知对齐对鲁棒性的关键价值。

## 8. 不足与局限

- **有界物体词汇表假设**：每个目标物体需要一次性准备三视图（仿真中渲染或真实中手持拍摄），这类特权监督无法支持对任意未见物体的零样本部署；
- **单目标限制**：方法将每条指令映射为单一目标物体，在 LIBERO-Long 上（87.5%）落后于 DreamVLA（89.5%），说明长程链式任务可能更需要场景级建模；
- **真实实验覆盖面有限**：仅 3 个任务类别、2 个目标物体、30 次试验/条件，结论的外推性有限；
- **VGGT 教师模型本身的限制**：VGGT 可能依赖参考帧进行尺度恢复，但论文未明确说明目标物体三视图特征提取时的参考帧设置；若需参考帧，则部署时的观测与三视图参考之间的关系需进一步说明；
- **目标定位依赖**：训练时需知道指令对应的目标物体，实际应用时需要额外的目标识别或指令解析机制；
- **基准复杂性不足**：LIBERO 和 CALVIN 均为桌面级仿真基准，与真实复杂场景（杂乱环境、多目标干扰）存在差距。
