## 摘要
主流世界-动作模型（WAMs）通过适配预训练的视频生成模型（VGMs）进行机器人控制，迁移其学习到的动力学先验用于动作预测。这些VGMs通常在变分自编码器（VAE）潜在空间中训练。然而，VAE潜在空间是为像素重建优化的，这注重精细的外观细节，使得动作预测在视觉变化下变得脆弱。近期的工作在语义潜在空间中构建WAM，这对外观变化更加鲁棒。然而，这些模型无法利用仅在VAE空间中存在的大规模VGM预训练。为克服这一困境，我们提出了Robust-WAM，一种基于视频生成的WAM的通用后训练方法，它保留了基于VAE的生成路径，并在动作流上添加了轻量级的语义前瞻对齐目标。这保留了大规模VGM预训练，同时将动作锚定在外观不变的动力学中，在光照变化和其他视觉分布外条件下保持可靠。具体而言，我们采用可学习的查询令牌，通过将其输出隐藏状态与未来真实帧的语义前瞻对齐，将未来场景语义引入动作流。为了建立每个查询与其描述的未来步骤之间的时间对应关系，我们为其提供匹配动作令牌的位置编码。在分布外泛化模拟基准和真实机器人实验上的结果表明，我们的Robust-WAM在多个WAM基线上持续提高了成功率，而不会牺牲分布内性能。

## Abstract
Mainstream World-Action Models (WAMs) adapt pretrained video generation models (VGMs) for robot control, transferring their learned dynamics prior for action prediction. These VGMs are typically trained in a variational autoencoder (VAE) latent space. However, the VAE latent space is optimized for pixel reconstruction, which rewards fine appearance detail and leaves the action prediction fragile under visual shifts. Recent works build WAMs in semantic latent space, which are more robust to appearance shifts. However, these models cannot leverage the large-scale VGM pretraining that exists only in VAE space. To overcome this dilemma, we propose Robust-WAM, a general post-training method for video-generation-based WAMs that preserves the VAE-based generative path and adds a lightweight semantic foresight alignment objective on the action stream. This retains the large-scale VGM pretraining while grounding actions in appearance-invariant dynamics that stay reliable under illumination shifts and other visual out-of-distribution conditions. Specifically, we employ learnable query tokens to bring future-scene semantics into the action stream by aligning their output hidden states with the semantic foresight of future ground-truth frames. To establish the temporal correspondence between each query and the future step it describes, we give it the positional encoding of the matching action tokens. Experiments on out-of-distribution generalization simulation benchmarks and a real-robot setup show that our Robust-WAM consistently improves the success rates of multiple WAM baselines without sacrificing in-distribution performance.

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- **保留 VAE 生成路径**：视频分支完全保持原 WAM 不变，继续在 VAE 潜在空间中用 flow-matching 去噪预测未来帧，从而继承大规模 VGM 预训练的动力学先验。
- **在动作流上添加语义前瞻对齐目标**：通过可学习查询令牌（learnable query tokens），将动作流与**未来真值帧的语义特征**对齐，使动作预测锚定在外观不变的动力学上。

### 2.2 关键技术细节

#### （1）每个未来帧/视角设置语义查询令牌

- 引入 K 个可学习查询令牌 q ∈ R^{K×d}，其中 K = T_f × C（T_f 为未来帧数，C 为相机视角数），每个查询对应一个未来时间步和一个相机视角。
- 将查询令牌**前置拼接**到带噪动作令牌序列前：h = [q; h_a] ∈ R^{(K+L)×d}。

#### （2）共享时序位置编码（Shared Temporal PE）

- 查询令牌 k = (j−1)·C + c 对应**未来第 j 帧、第 c 个相机视角**。
- 第 j 帧是执行动作令牌 j·Δ 后到达的观测，因此该查询匹配的动作步为：**τ_j = min(j·Δ, L)**（当视频视界超出动作视界时取最后动作步）。
- 查询令牌**复用 WAM 自身动作流的位置编码**，即查询 q_n 使用位置索引 τ_⌈n/C⌉，而动作令牌保持原有索引 1,...,L。
- 这样模型就知道每个查询“看向多远的未来”，建立精确的时间对应关系。

#### （3）语义目标：冻结 DINOv3 CLS 嵌入

- 对每个训练样本，用**冻结的 DINOv3** 编码器提取 T_f 个未来真值帧在 C 个视角下的 CLS 嵌入，得到目标 z* ∈ R^{K×d_z}。
- CLS 嵌入能总结场景内容（物体、空间排列），同时**忽略纹理和光照细节**，是外观不变的语义摘要。
- 对齐目标是**未来帧**而非当前帧，使查询编码“示范动作将导致什么”，为动作流提供语义前瞻。

#### （4）对齐损失

- 动作块处理完拼接序列后，将查询输出通过线性头 g 映射到目标空间，计算**逐查询余弦对齐损失**：

**L_align = (1/K) · Σ_k [1 − cos(g(h̄_k), z*_k)]**

- 总损失为：**L = L_WAM + λ_align · L_align**（λ_align = 0.1）
- 原始动作头接收的仍是原有的 L 个动作令牌输出（h̄_{K+1:K+L}），不影响原动作预测路径。

#### （5）推理时零额外开销

- Inference 时**丢弃 DINOv3 教师和线性对齐头**，仅保留 K 个查询令牌在序列中，注意力路径不变，因此不增加推理成本。

### 2.3 与不同架构的集成

| 架构类型 | 代表模型 | 集成方式 |
|---------|---------|---------|
| **Action-Expert WAMs（MoE 型）** | GE-Act、FastWAM、Motus | 查询直接前置到专家（action expert）的令牌序列中，与其他动作令牌一样参与专家自注意力和对视频塔的交叉注意力 |
| **Unified WAMs（统一序列型）** | LingBot-VA | 查询插入动作段，赋予与对应动作令牌相同的序列/帧/噪声 ID，在 flex-attention 掩码规则下继承动作令牌的双向注意力模式 |

## 6. 主要结论与发现

1. **语义对齐显著提升 OOD 鲁棒性，且不损害 InD 性能**：
   - **LIBERO-Plus**：FastWAM 从 49.7%→58.9%（+9.2 点）；GE-Act 从 78.0%→80.9%（+2.9 点）；同时 clean LIBERO 分别提升 +0.3 和 +0.8 点。
   - **RoboTwin**：LingBot-VA 随机分片成功率从 29.8%→34.4%（+4.6 点），clean 保持 81.2%。
   - **真实机器人**：GE-Act+Robust-WAM 的 OOD 成功率从 57.3%→80.0%，InD-OOD 差距从 22.7 点缩小到 2.7 点。

2. **语义表示用于“增强”而非“替代”预训练先验更有效**：LDA-1B（纯语义空间、无大规模 VGM 预训练）在 LIBERO-Plus 仅达 45.5%，远低于 GE-Act+Robust-WAM 的 80.9%；RoboTwin 上同样大幅落后（12.3% vs 34.4%）。

3. **查询设计的关键性**：带时序位置编码的未来帧查询（+9.2）显著优于无时序 PE（+5.3）和当前帧目标（+3.0），说明“精确时间对应 + 未来语义”缺一不可。

4. **DINOv3 CLS 是最优对齐目标**：优于 DINOv3 Patch（+7.3）、DA3（+7.1）和组合目标（+6.8），说明紧凑的语义摘要向量已经足够，组合多目标反而可能带来优化困难。

5. **鲁棒性增益不仅限于光照变化**：在相机扰动（+12.4）、背景变化（+10.3）、传感器噪声（+18.9）等非光度扰动轴上也有大幅提升，语义目标对几何和视角变化同样有益。

## 7. 优点

- **方法设计优雅、即插即用**：无需重新训练 VAE 或视频 DiT，不改变原 WAM 的视频生成路径、分词方式或视频-动作注意力架构，只需在动作流中前置查询令牌并添加辅助对齐损失，即可作为通用后训练方法应用于不同 WAM。
- **推理零开销**：DINOv3 教师和对齐头只在训练中使用，推理时完全丢弃，不增加任何计算负担。
- **“鱼与熊掌兼得”的方案**：同时保留了大规模 VGM 预训练的动力学先验和语义空间的鲁棒性，避免了二选一的困境。
- **思想创新——共享时序位置编码**：与之前的工作（如 FLARE）不同，Robust-WAM 通过让查询复用对应动作令牌的位置编码来显式建立时序对应，这是对“未来查询时间定位”的精确处理。
- **实验系统全面**：从模拟到真实、从多架构到多扰动轴、从主实验到消融，证据链完整且自洽。
- **一致性与统计显著性**：所有数据集上的改进方向一致（OOD 增益为正、InD 不降），且真实机器人实验每任务 25 次 rollout 的结果差异足够大（如 OOD 从 64→92），具有实际意义。

## 8. 不足与局限

- **真实世界评估范围有限**：真实机器人实验只测试了光照变化（紫色/青色），未覆盖视角、背景、物体布局等更丰富的 OOD 扰动；虽然模拟中已验证这些维度有效，但真实世界中的泛化性仍需更多验证。
- **未充分探索任务规模和多样性**：LIBERO 和 RoboTwin 均为桌面操作任务，尚未在长时程任务、移动操作或灵巧手等更复杂的场景中验证。此外，RoboTwin 仅使用 2,500 条示范训练 LingBot-VA，任务范围有限。
- **部分基线改进幅度有限**：GE-Act 作为强基线时增益较小（LIBERO-Plus +2.9 点），且个别扰动轴（如 FastWAM 的 robot init 轴 −1.0，GE-Act 的 light 轴 −0.2）未能改进，说明方法的普适性仍有一定边界。
- **未报告计算开销数据**：尽管推理零开销，但训练时增加查询令牌和 DINOv3 特征提取的额外算力/显存消耗未被量化，这会影响实际部署成本评估。
- **对齐目标的语义信息可能存在残余外观偏差**：DINOv3 CLS 虽然对外观相对鲁棒，但并非完全不变；在极端外观变化下是否仍然可靠，论文未做深入分析。
- **仅测试了一个语义教师（DINOv3）**：虽然消融对比了 DA3 和 Patch token，但未测试 V-JEPA 等其他语义模型，无法确认 DINOv3 CLS 是最优选择还是仅在当时配置下最优。
- **辅助损失与主损失的平衡**：λ_align 固定为 0.1，未对不同的 WAM（不同规模、不同训练数据量）进行敏感性分析，最优权重可能因模型而异。
