## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过昂贵的数据扩展来解决，但我们的探查表明，根本原因在于架构而非语义理解不足。具体而言，我们证明当前的VLA模型内部能够成功保留正确的任务身份。失败实际上源于动态视觉观察与文本的联合编码，这引入了系统性特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构瓶颈，我们提出了接地语义重绑定（GSR），一种优雅的干预方法，通过将独立提取的任务语义与原生视觉特征显式融合，从头训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这种针对性干预仅使用规范演示即可显著恢复释义不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进模型的PRIDE分数推至新的纪录70.4，在指令生成能力上超越了最近推出的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一个原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，稳健的语义接地可以通过优雅的结构设计实现，绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

### 2. 论文提出的方法论

**核心思想：Grounded Semantic Re-binding（GSR，接地语义重绑定）**

GSR的核心原则是：**先独立于当前动态图像提取纯任务语义，再与视觉场景深度融合，最后重新学习动作映射**。具体包含以下关键组件：

**（1）稳定语言源（Stable Language Source）**
- 使用冻结的T5-large编码器将真实指令映射为纯语义表示。
- T5不接收任何图像或机器人状态输入，确保语义提取的稳定性。
- 这一设计基于诊断发现：当VLA-Adapter的辅助Qwen分支接收固定虚拟图像时，释义成功率从46.82%提升到61.58%，证明联合视觉-文本编码是特征偏移的根源。

**（2）架构感知的注入策略**
- 不同架构的语义融合点位不同，GSR采用"架构感知"的适配方式：
  - **VLA-Adapter**：将T5输出通过投影映射为sidecar K/V源，注入Bridge-Attention策略的每个MLPResNetBlock_Pro块中；原生Qwen语言输入被中性化（固定为"perform the task"），强制模型依赖T5语义。
  - **SmolVLA**：直接注入原生语言槽位，让T5语义与图像在SmolVLM内部深度交互后再生成动作；原生指令也替换为中性提示语。
  - **π0.5**：原生PaliGemma路由本身已可靠，因此保留真实指令，将T5作为补充语义源注入PaliGemma任务token位置。

**（3）完全重新初始化动作专家**
- 不微调预训练权重，而是从头训练全新的动作专家模块（如VLA-Adapter的反向Attention策略、π0.5的300M动作专家）。
- 这使策略从训练开始就学会如何将T5条件、视觉特征和机器人状态联合映射为动作，避免保留不稳定的旧映射关系。

**（4）ParaVLA：原生解耦架构**
- 采用完全分离的视觉-语言编码：冻结T5处理指令，DINOv2处理图像，仅在最终动作专家中融合。
- 0.33B参数，T5的token特征缓存后每次控制步无额外推理成本。

### 6. 论文的主要结论与发现

1. **根本原因诊断**：VLA模型在指令释义下性能骤降并非语义理解失败，而是架构性翻译失败——任务语义在内部保留完好，但视觉-文本联合编码引入系统性特征偏移，下游动作策略无法处理。

2. **GSR显著提升释义不变性**：
   - VLA-Adapter：Full Para成功率从46.82%提升至70.94%（+24.12pt）
   - SmolVLA：从4.47%提升至49.12%（+44.6pt，最大增益）
   - π0.5：从73.60%提升至75.59%（匹配训练步数下），PRIDE达到70.4，创下当前最高纪录，超过Xiaomi-Robotics-0的69.2

3. **轻量模型可媲美大规模基线**：VLA-Adapter+GSR（无大规模预训练）的指令跟随能力接近π0.5的水平，证明了结构设计的有效性和正交性。

4. **ParaVLA的极端鲁棒性**：0.33B参数的原生解耦模型在LIBERO-Goal上规范成功率为92.0%，释义成功率为91.0%（仅1pt差距），近乎完美的释义不变性。

5. **通用设计原则**：GSR归纳为"先纯净语义提取，后深度视觉接地，再重学习动作映射"的三步架构感知方法。

### 8. 不足与局限

**实验覆盖的局限：**
- **任务范围有限**：主要基于LIBERO-Goal的10个任务和LIBERO-Para的指令改写，未涵盖更广泛的语言变化类型（如多语言、复杂推理、未见组合等）。
- **真实机器人实验规模偏小**：仅6个任务、每策略30次试验，且部分任务（如任务3、5、6）GSR成功率为0%，泛化性需更大规模验证。
- **有效指令改写范围有限**：论文主要针对同义改写（动作表达、物体指称），未充分测试更困难的指令变化形式。

**方法局限性：**
- **π0.5的规范性能下降**：匹配训练步数下规范成功率从93.0%降至91.0%，需要延长训练步数（GSR*）才能恢复至96.0%。对大型动作专家而言，重新初始化的收敛成本是明确的短板。
- **ParaVLA的扩展性瓶颈**：当扩大视觉基础模型规模（如更大的DINO变体）时，系统无法展现出VLM级别的扩展能力，原生解耦范式目前难以大规模扩展。
- **对T5语义源的依赖**：如果T5本身对某些指令（如超出其知识范围的领域）理解不足，GSR的鲁棒性可能受限。
- **原生语言通路的中性化处理**：对VLA-Adapter和SmolVLA，将原生指令替换为固定中性提示语虽然有效，但也意味着放弃了这些模型预训练语言知识的潜在利用。

- 干预实验（如固定虚拟图像、词向子空间删除）的设计虽然巧妙，但可能引入实验者偏差，需要更多独立复现。
