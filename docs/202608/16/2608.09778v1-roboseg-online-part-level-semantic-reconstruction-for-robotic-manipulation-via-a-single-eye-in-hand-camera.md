## 摘要
机器人操纵需要能够识别可操作部件（如把手、边缘、触发器和工具尖端）的感知系统，而不仅仅是物体类别或点云。本文介绍了 RoboSeg，一个零件级语义重建系统，它将视觉语言模型（VLM）的功能部件发现、异步在线 RGB-D 语义重建和面向任务的抓取生成连接起来，无需 CAD 模型或预扫描网格。RoboSeg 在初始 RGB 观测上查询 VLM 以获得紧凑的功能部件提示，然后使用两个异步流进行扫描：一个用于 RGB-D 里程计和截断符号距离函数（TSDF）融合的高频几何线程，以及一个用于 SAM3 部件掩码的关键帧触发语义线程。投影掩码通过体素级时间投票融合成持久的部分标记点云；RoboSeg 使用该地图将 AnyGrasp 6自由度候选分配给语义部件，并选择与任务相关部件标签一致的抓取。RoboSeg 在手动标记物体上达到 83.4% 的平均部分交并比（mIoU）；在涉及四件物体和八项任务的 24 次物理试点试验中，所选抓取在所有试验中均接触到所请求的部件，并实现了 21/24 的总任务成功率。这些结果表明 RoboSeg 可作为任务条件下的操纵的语义索引层，同时保留 AnyGrasp 作为提议生成器。

## Abstract
Robotic manipulation requires perception systemsthat identify actionable parts such as handles, rims, triggers,and tool tips, not merely object categories or point clouds. This paper presents RoboSeg, a part-level semantic reconstructionsystem that links vision-language model (VLM) functional-partdiscovery, asynchronous online RGB-D semantic reconstruc-tion, and task-oriented grasp generation without requiring CAD models or pre-scanned meshes. RoboSeg queries a VLM onthe initial RGB observation to obtain compact functional part prompts, then scans with two asynchronous streams: a high-frequency geometry thread for RGB-D odometry and truncated signed distance function (TSDF) fusion, and a keyframe-triggered semantic thread for SAM3 part masks. Projectedmasks are fused by voxel-level temporal voting into a persistentpart-labeled point cloud; RoboSeg uses this map to assign AnyGrasp 6-DoF candidates to semantic parts and select grasps consistent with the task-relevant part label. RoboSeg reaches 83.4% mean part intersection-over-union (mIoU) over manually labeled objects; in a 24-trial physical pilot across fourobjects and eight tasks, the selected grasp contacts the requestedpart in all trials and achieves 21/24 combined task successes.These results characterize RoboSeg as a semantic indexing layerfor task-conditioned manipulation, with AnyGrasp retained asthe proposal generator.

## 1. 核心问题与整体含义

- **研究背景**：机器人操作的关键挑战在于识别**可操作的功能部件**（如杯柄用于提举、壶嘴用于倾倒），而非仅仅识别物体类别或生成通用点云。传统 3D 部件分割方法（PartSLIP、PartSTAD、ZeroPS 等）通常假设已知或预计算的完整几何（CAD 模型、网格），且在离线条件下优化标签，无法闭环至真实操作任务。
- **核心问题**：如何让机器人在**未知物体**上，通过**手眼相机的在线观测**，构建持久、任务相关的零件级语义地图，并据此生成符合任务语义的抓取候选。
- **整体含义**：RoboSeg 提出一个**在线感知到抓取的完整接口**——将 VLM 功能部件发现、异步 RGB-D 语义重建、AnyGrasp 任务条件抓取选择串联为单一流水线，**无需 CAD 模型或预扫描网格**，可作为任务条件操作中的语义索引层。

## 2. 方法论

### 核心思想
利用 VLM 先验地约束分割词汇（只关注功能部件），通过异步双线程架构解耦高频几何重建与低频语义推理，以体素级投票实现跨视角的时间一致性标签融合，最终用语义标签索引 AnyGrasp 抓取候选。

### 技术细节
**模块 A — VLM 引导的功能部件发现**
- 使用 Qwen3-VL 对初始 RGB 帧推理，输出紧凑的自包含部件列表（1—3 个），格式为 `{object: o, parts: [p1, ..., pn], cot: r}`。
- 只有 `parts` 字段传入 SAM3；`cot` 理由不参与下游。
- 语义搜索空间从"任意可见区域"压缩至"紧凑功能部件集"，减少 3D 融合的掩码数量。

**模块 B — 异步在线语义重建**
- **几何线程（高频）**：RGB-D 跟踪估计相机位姿（可选运动学正则化），将每个深度帧融合进 TSDF 体积。
- **语义线程（低频）**：按可配置关键帧间隔 τ 触发 SAM3 分割，将掩码反投影至 TSDF 体素坐标。
- **体素投票时间一致性**：每个被占据体素 v 维护 top-K 候选实例 ID 及其票数，K=3：
  - S(v) = {(i₁(v), s₁(v)), ..., (i_K(v), s_K(v))}
  - 新掩码到来时，在覆盖体素中查找同类实例 ID；无匹配则分配新 ID，并在每个体素中为选中 ID 加一票。
  - 查询时标签由最大票数决定：**î(v) = arg max_k s_k(v)**。
  - 效果：瞬态 2D 错误票数不足以主导，反复观测的部件区域收敛为稳定标签。

**模块 C — 任务条件抓取选择**
- 导出部件标记点云 + 实例表（ID→部件名）。
- AnyGrasp 在重建几何上生成密集 6-DoF 候选；对每个候选查询**夹爪闭合区域**内的点，分配主语义实例。
- 自然语言任务解析为实例表中的部件标签；筛选出标签匹配的候选，按 AnyGrasp 分数排序，执行最高分候选。

### 算法流程（Algorithm 1 摘要）
1. VLM 从初始帧发现部件并前向至 SAM3；
2. 初始化 TSDF 体积和逐体素投票张量；
3. 每帧：估计位姿→融合深度；
4. 每 τ 帧：SAM3 推理→掩码反投影→更新体素投票；
5. 导出点云与实例表；
6. AnyGrasp 生成候选→按夹爪区域分配部件标签；
7. 任务标签过滤→输出最高分匹配抓取。

## 6. 主要结论与发现

1. **部件发现与任务对齐**：RoboSeg 在在线扫描中恢复的功能部件比离线方法更直接地匹配操作需求（离线方法常将手柄、壶嘴、刀刃并入大的混合区域）。
2. **定量结果**：5 个物体上 83.4% mIoU；4 个对齐物体上与 PartField 相比，RoboSeg 达 86.7%、PartField 为 83.2%。
3. **几何骨干评估**：RGB-D 里程计与运动学位姿的融合结果差异不大（Chamfer 距离差仅 −0.4mm），说明几何骨干足以支持候选索引。
4. **物理验证**：24/24 次抓取**接触目标部件**（语义路由 100% 正确）；21/24 次物理提举成功；未过滤的 AnyGrasp top-1 在 8 个条件中仅有 4 个匹配目标部件，而 RoboSeg 语义过滤在 8/8 条件中选择目标部件候选。
5. **定位**：RoboSeg 应被视为**语义索引层**，而非抓取生成器的替代品；AnyGrasp 仍是提案生成器。

## 7. 优点

- **端到端在线闭环**：从原始 RGB-D 流到任务条件抓取执行，无需 CAD/网格/模板，直接面向真实操纵场景。
- **异步架构设计合理**：几何线程保持高频跟踪与融合，语义线程低频补标签，避免了 SAM3 推理延迟拖累完整系统。
- **体素投票机制有效**：以 top-K 投票张量抑制 2D 掩码的帧间标签闪烁，是一种轻量、内存可控的时间一致性方案。
- **VLM 约束分割词汇**：将开放词汇分割从"可见区域全集"缩至"功能部件子集"，有效避免 SAM"全分割"模式下按纹理/阴影/高光过度分割的问题。
- **任务与部件解耦**：任务解析只映射到部件标签，抓取评分仍由 AnyGrasp 承担——模块化清晰，便于替换任意组件。
- **评估设计诚实**：对离线基线给予更有利条件仍保持可比或更优，增强结果说服力；物理试验将"物理成功"与"任务部件接触"分离统计，归因清晰。

## 8. 不足与局限

- **实验规模有限**：24 次物理试验、5 个标注物体样本量小；作者自认结果应视为可行性证据。
- **物体与场景多样性不足**：使用标准化初始视图、手动重置；未涉及遮挡、物体姿态扰动、光照变化、多物体堆叠等复杂场景。
- **薄/突出部件精度差**：DoubleHandlePot（61.9% mIoU）和 WateringCan（70.1%）的低分源于薄把手和壶嘴——RSDF 融合在细几何上易丢失，影响后续部件标签和抓取索引。
- **物理失败未解决**：3 次失败均接触了正确部件但未能稳定提举，说明 AnyGrasp 与地图结合在执行层面仍存在不稳定因素，系统未对此失败模式做出反馈或修正。
- **缺少运行时剖析**：未报告各模块（SAM3 推理延迟、VLM 查询时间、TSDF 融合速率、端到端总时长）的耗时数据，难以判断实时性边界。
- **离线基线对齐不完整**：PartSLIP 无法纳入统一定量框架，削弱了与离线方法对比的完整性；部分比较仅停留在定性层面。
- **泛化性未验证**：所有实验基于同一物体集与 UR5+D435i；VLM 提示对未见物体类别的泛化能力、SAM3 对复杂纹理/光照的鲁棒性均未系统测试。
