## 摘要
世界动作模型（WAM）通过联合建模动作和未来观察来提高机器人策略学习。然而，仅以任务提示和观察上下文为条件进行未来预测，可能会捕获通用任务进展，而非所执行动作的特定后果。我们引入了SelfWAM，一种基于模态专用混合Transformer（MoT）架构的统一自接地WAM，它联合预测动作、动作条件下的未来RGB帧和机器人自遮挡掩码，从而将未来预测基于机器人可见身体及其动作引起的运动。在联合训练期间，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定的后果模型，同时保留仅动作的快速推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们使用针对未来机器人自遮挡掩码预测的提示专用目标，该目标去除了外观细节，并提供了一个其时间演变与条件动作紧密耦合的目标。总之，干净动作条件和未来自遮挡掩码监督使未来预测更直接地反映所执行动作如何改变机器人的可见运动和周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM产生更具动作敏感性的未来预测，并保持快速策略推理，同时提高策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

**研究动机**：世界动作模型（WAM）通过联合建模动作与未来观察来提升机器人策略学习。然而，现有方法（如 FastWAM）在预测未来视频时仅以当前观察、语言指令和本体感觉为条件，**并未显式利用产生该未来的演示动作**。这使得辅助的视觉预测目标容易退化为学习"通用任务进展"（generic task progression），而非"特定动作引发的具体后果"。

### 2. 方法论

**核心思想**：SelfWAM 是一个统一的自接地 WAM，采用**模态专用混合 Transformer（Mixture-of-Transformers, MoT）**架构，联合预测动作、动作条件化的未来 RGB 帧和机器人自掩码视频。

**关键技术细节**：

- **双流架构**：
  - 视频流：预训练视频扩散骨干（WAN2.2-5B），处理当前观察和噪声化未来视频潜变量。
  - 动作流：轻量级动作专家，参数由视频骨干权重插值初始化。
  - 两者通过混合注意力耦合，保留模态专用投影和前馈层。

- **不对称信息流（核心创新）**：
  - 训练时创建演示动作的**干净副本**（clean action copy），保持未破坏的原始动作，使用去噪时间步 t=0。
  - 注意力规则为：
    - Q_动作 → {O, eA}（噪声动作查询只能访问当前上下文和自身噪声动作）
    - Q_未来视觉 → {O, eV, A}（未来视觉查询额外访问干净动作副本）
    - Q_干净动作 → {O, A}
  - 效果：视频分支成为**动作特定后果模型**，而策略分支无法从干净动作或未来视觉 token 中恢复目标，防止目标泄漏；策略计算图与部署时完全一致。

- **未来机器人自掩码预测**：
  - 复用同一视频骨干，通过**不同输出提示**（RGB 提示 vs 自掩码提示）切换预测目标。
  - 每个演示同时构造两个世界模型实例：RGB 实例（有动作监督）和自掩码实例（无动作监督，仅视觉损失）。
  - 掩码去除外观、纹理、光照、背景变化，其时间演变与条件动作紧密耦合，提供更聚焦的"动作-身体运动"监督信号。
  - RGB:自掩码采样比例为 9:1。

- **训练目标**：
  - L = λact·Lact + λvideo·L_rgb/mask，其中 λact = λvideo = 1。

- **部署模式**：省略干净动作条件和未来视觉去噪，只保留当前上下文编码 + 轻量级动作专家迭代去噪，维持快速闭环控制。

### 6. 主要结论与发现

### 8. 不足与局限

- **未建模物理交互**：论文自身承认未显式建模接触、力、遮挡下的交互；对接触丰富的操作任务，仅 RGB

…视频预测难以准确预测形变和接触后的物体运动，自掩码虽抑制背景但也不包含力的信号，因此对接触密集的插拔、拧动等任务可能生成不准确的未来状态。

- **自掩码分割依赖外部模型**：真实机器人实验中自掩码目标依赖 RoboSeg 离线分割获得，分割质量直接影响监督信号；若分割出错（如将手指误分到物体），可能引入噪声。仿真中可依赖渲染器，但真实场景部署需要额外感知管线，增加了应用门槛。

- **动作条件化的作用机制未完全解释**：消融实验显示“仅动作条件、无自掩码”的变体在 RoboTwin 上性能略低于 FastWAM（90.80% vs 91.84%），说明引入干净动作副本后，策略分支在注意力上虽然掩蔽了视觉 token，但动作流庞大的参数量或梯度信号可能干扰了策略学习；论文未对这一现象给出具体分析（如梯度冲突、注意力权重可视化缺失）。

- **随机化设置上的提升幅度有限**：虽然随机化环境下 SelfWAM 比 FastWAM 提高约 1.2 个百分点，但绝对差异不大，且置信区间未报告；无法断定自接地预测在视觉泛化上具有显著优势。

- **推理效率评估条件单一**：延迟测试仅在 H200 单卡上进行，且未报告不同 batch size、不同输入分辨率下的变化；实际部署中若使用边缘设备，增加的动作流和自掩码分支的显存占用可能更敏感。

- **与最新方法比较不够全面**：对比基线包括 π0、π0.5、Motus、GigaWorld-Policy、FastWAM，但未包括近期出现的一些更强调世界模型能力的 VLA（如基于视频扩散的分层策略或更新的 WAM 版本），也未与同样使用机器人掩码/本体感受预测的方法对比，结论的时效性受限。

- **未来预测指标与策略性能的关联性未建立**：虽然 LPIPS、FVD 等指标改善，但论文没有进一步分析“预测质量提升”与“任务成功率提升”之间的因果关系；可能预测更准但不直接贡献于动作决策，也可能仅通过正则化效应获益。

## 9. 总结

SelfWAM 的核心贡献是提出了“自接地未来预测”这一新范式：通过将未来视频预测与演示动作、机器人自掩码显式绑定，使世界模型从“预测通用视频”转向“预测动作具体后果”。非对称信息流设计精准地实现了“动作条件化视觉预测”而不引入策略泄漏，使模型在训练时获得更强的动作-视觉对齐监督，推理时仍只运行轻量动作分支，实现接近零延迟开销的策略提升。实验证明其在仿真基准和真实机器人上均优于现有 WAM 基线，且对动作扰动敏感，证明了其未来预测确实被动作接地。

但该工作也存在明显局限：物理交互建模缺失、自掩码依赖外部分割、大规模算力依赖、以及消融中动作条件单独添加时的性能微降等问题，仍需后续研究解决。

## 10. 个人评价

- 该论文的价值在于**提出了一种有效的架构级方案**，将“动作条件化未来预测”与“机器人自身掩码预测”这两个独立思想统一到一个 MoT 框架中，并通过严谨的实验验证其有效性。非对称信息流是全文最精巧的设计。
- 对于机器人操作学习领域，该工作提示：**视频预测目标不必追求全局视觉逼真，而应聚焦于与动作因果相关的变化**——自掩码正是这一思想的实现。
- 然而，该方法建立在视频扩散大模型的强监督之上，其收益本质上来自多任务大规模数据 + 大模型容量，自接地技巧是否在小模型、小数据场景下依然有效，是后续值得关注的问题。
- 总体上，这是一篇方法新意明显、实验扎实、缺陷也清晰的优秀工作，适合作为 WAM 方向进一步研究的起点。
