## 摘要
强化学习通过评估从当前策略中采样的轨迹来改进自动驾驶视觉-语言-动作（VLA）模型。组相对策略优化（GRPO）从每个滚动组内的奖励差异中学习。当所有采样的轨迹都较差时，这种相对信号可以对失败进行排序，但无法识别失败区域之外的行为。我们提出了FIRE-VLA，一种失败信息驱动的自我进化框架，将此类未解决的失败转化为对下一个策略的特权监督。低奖励、低多样性的组触发来自同一模型冻结的轮次起始副本的自我蒸馏。教师和学生具有相同的参数规模，但只有教师能观察到隐藏的未来轨迹。监督遵循学生生成的前缀，并仅限于答案标记，而GRPO对每个组仍然有效。更新后的策略为下一轮提供教师，使得路由的失败分布随策略变化，而无需更大的外部教师。从相同的Qwen2.5-VL-3B SFT检查点开始，比较匹配学生滚动和策略更新次数。在来自150个留出的nuScenes场景的6,019个示例上，FIRE-VLA保持了可比的单样本规划，将G=4的平均L2从1.848降至1.500米，并将评估持续失败率从13.03%降至11.20%。平均误差的降低主要源于罕见的严重滚动，而非普通轨迹的均匀改进。

## Abstract
Reinforcement learning improves autonomous-driving vision-language-action (VLA) models by evaluating trajectories sampled from the current policy. Group relative policy optimization (GRPO) learns from reward differences within each rollout group. When all sampled trajectories are poor, this relative signal can rank failures without identifying behavior outside the failed region. We introduce FIRE-VLA, a failure-informed self-evolution framework that converts such unresolved failures into privileged supervision for the next policy. Low-reward, low-diversity groups trigger self-distillation from a frozen round-start copy of the same model. Teacher and student have the same parameter scale, but only the teacher observes the hidden future trajectory. Supervision follows the student's generated prefix and is restricted to answer tokens, while GRPO remains active for every group. The updated policy supplies the teacher for the next round, allowing the routed failure distribution to change with the policy without requiring a larger external teacher. Starting from the same Qwen2.5-VL-3B SFT checkpoint, the comparison matches student rollout and policy-update counts. On 6,019 examples from 150 held-out nuScenes scenes, FIRE-VLA retains comparable single-sample planning, reduces G=4 mean L2 from 1.848 to 1.500 m, and lowers evaluation-persistent failure prevalence from 13.03% to 11.20%. The reduction in mean error arises mainly from rare severe rollouts rather than uniform improvement across ordinary trajectories.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：视觉-语言-动作（VLA）模型在自动驾驶中通过视觉感知、语言推理与可执行轨迹生成来实现驾驶决策。常用做法是先经过监督微调（SFT）获取驾驶先验，再利用强化学习（RL）提升策略。其中组相对策略优化（GRPO）通过同一提示下多条采样轨迹之间的奖励对比来提供学习信号。
- **核心问题**：当一组采样轨迹全部较差时（即“未解决的失败组”，unresolved failure group），GRPO 只能对这些失败轨迹进行相对排序，却缺少能引导策略走出失败区域的行为校正信息。这种信息缺失并非目标函数消失或梯度变小，而是“正确校正信息不足”的问题。
- **整体含义**：论文希望在不引入更大外部教师模型的前提下，让同一 VLA 模型利用自身产生的未解决失败来监督下一代策略，从而实现自我进化。FIRE-VLA 框架的核心在于：将“低奖励、低多样性”的失败组路由到特权自我蒸馏路径，同时保留 GRPO 对全部组的训练。

## 2. 论文提出的方法论

### 2.1 核心思想
- 对每个 on-policy rollout 组计算奖励均值、标准差和有效比例，用批量相对阈值（第 30 百分位）判定“未解决失败组”。
- 对判定为未解决失败的组，额外施加“特权自我蒸馏”（Privileged Self-Distillation，PSD）；GRPO 仍保持对所有组有效。
- 教师模型是当前轮次开始时策略的冻结副本，与学生参数规模相同，唯一区别是教师额外获得隐藏的未来真实轨迹（privileged future information）。
- 蒸馏只在学生生成的答案 token 上进行，且沿学生生成的前缀进行，避免 off-policy 偏移。
- 每一轮训练结束后，更新后的策略成为下一轮的教师，使得未解决失败分布随策略变化而演化，无需外部大教师。

### 2.2 关键技术细节
- **奖励函数**：对有效 rollout，轨迹奖励为
  \( r = \left(1 + \frac{1}{6}\sum_{t=1}^{6} \|p_t - p^*_t\|_2^2 \right)^{-1} \)，无效响应得零奖励。
- **GRPO 优势计算**：组内标准化奖励，得到相对优势 \(\hat{A}^{(g)}_i\)，用于剪辑策略目标。
- **失败路由条件**：
  \[
  z_i^{\text{train}} = 1 \left[ \bar{r}_i \le Q_{0.3}^{\text{batch}}(\bar{r}) \wedge \sigma_i \le Q_{0.3}^{\text{batch}}(\sigma) \wedge v_i \ge 0.5 \right]
  \]
  其中 \(\bar{r}_i\) 为组内平均奖励，\(\sigma_i\) 为组内奖励标准差，\(v_i\) 为有效响应比例。
- **师生上下文构造**：
  - 学生上下文：\(c^S_{i,g,t} = (I_i, h_i, y_{i,g,<t})\)
  - 教师上下文：\(c^T_{i,g,t} = (I_i, h_i, \langle\text{priv}\rangle \tau^*_i \langle/\text{priv}\rangle, y_{i,g,<t})\)
  - 教师能看到真实未来轨迹，学生不能；两者共享学生生成的前缀。
- **蒸馏损失**：使用对称 Jensen–Shannon 散度（JSD），基于教师 top-16 token 加 1 个残差桶的紧凑分布；每个 token 的散度截断到 0.05；按答案 token 加权平均，组合系数 \(\lambda = 0.1\)。
- **总损失**：
  \[
  \mathcal{L}_B = \mathcal{L}_{\text{GRPO},B} + \lambda z_B^{\text{train}} \mathcal{L}_{\text{PSD},B}
  \]
  GRPO 对每个组均保持活跃，PSD 仅对路由组加入。

### 2.3 轮次式自我进化
- 序列：\(\pi_0 \to \pi_1 \to \cdots \to \pi_K\)，每轮内用冻结的 \(\pi_k\) 副本当教师，训练可更新的学生；更新后学生成为 \(\pi_{k+1}\) 并产生新的 rollout 分布，从而决定下一轮的路由。
- 实验中使用 K=2，每轮 75 次策略更新。

## 3. 实验设计

- **数据集与场景**：
  - 使用 nuScenes 数据集，采用前视相机图像和 6 个 BEV 未来路点（0.5s 间隔）的轨迹预测任务。
  - 训练：1,200 个唯一 RL prompts，分为两个不重叠的 600-prompt 子集用于两轮 FIRE-VLA；GRPO 使用相同 1,200 prompts。
  - 评估：150 个留出场景（与训练 SFT 和 RL 均无场景重叠）上的 6,019 个固定样本；另有 256 样本、37 场景的 SFT 验证集用于校准评估期持久失败检测器（与最终评估无重叠）。
- **Benchmark 与对比方法**：
  - 对比：标准 GRPO（同一 Qwen2.5-VL-3B SFT 初始化），以及公共 SFT 参考。
  - 评估模式：单样本低温采样（temperature 0.2）和 G=4 随机采样（temperature 0.8）。
  - 指标：轨迹 L2（1s/2s/3s/平均）、轨迹奖励、评估-持久失败率、严重随机失败比例（>10m）、CVaR、分位数等。
- **实现细节**：
  - 模型：Qwen2.5-VL-3B-Instruct 作为主干，全参数 BF16 训练，FSDP 分布式。
  - 优化器：学习率 \(5 \times 10^{-7}\)，权重衰减 \(10^{-2}\)，梯度裁剪 1.0，warmup 0.05，关闭 KL 惩罚与 LoRA。
  - 每个方法均采样 4 条响应/提示，总 rollout 4,800 条，策略更新 150 次。
  - 评估统计采用场景聚类的 paired bootstrap（10,000 次）置信区间。

## 6. 论文的主要结论与发现

- **单样本规划**：FIRE-VLA 与标准 GRPO 在单样本低温采样下可比较，数值 L2 略低但配对置信区间跨零（Avg. L2 差 -0.0397，CI [-0.1104, 0.0087]），统计上无显著优势。
- **随机采样显著改善**：G=4 平均 L2 从 1.848 m 降至 1.500 m（约 -18.8%），配对差 -0.3476 m，场景聚类 95% CI [-0.7711, -0.0319]。
- **持久失败率下降**：评估-持久失败率从 13.03% 降至 11.20%（-1.83 个百分点，CI [-2.55, -1.11]）。
- **严重尾部改善**：包含任一路点 >10 m 的样本比例从 1.35% 降至 0.83%；CVaR95 从 25.52 降至 17.72，CVaR99 从 118.58 降至 79.21。
- **收益集中于尾部**：winsorized 分析表明，FIRE-VLA 在普通轨迹区域（中位数、P90、P95）甚至略差于 GRPO，其平均误差下降主要来自罕见严重 rollouts 的抑制。
- **注意**：FIRE-VLA 的标量奖励（0.6156）低于 GRPO（0.6370），这种“奖励更高但物理误差更重尾”的现象源于有界倒数奖励对巨大误差的压缩效应。
- **恢复率不显著**：对 SFT 参考持久失败样本，FIRE-VLA 恢复率 25.21% 对 GRPO 23.35%，差异无统计显著性。

## 7. 优点

- **问题定位精准**：指出 GRPO 在所有轨迹都差时只能排序、无法提供逃逸方向这一关键局限，而不是泛泛批评相对奖励。
- **机制自洽且轻量**：教师和学生同参数规模，仅通过特权信息（隐藏未来）区分，无需外部大模型，跨轮次自我进化自然迭代。
- **路由与监督设计精细**：
  - 路由条件同时考虑低均值、低多样性和有效比例；
  - 蒸馏沿学生 on-policy 前缀进行，缓解 off-policy 偏移；
  - 仅对答案 token 施加，且 token 散度截断，避免过度干预；
  - GRPO 始终保留，避免完全替换 RL 目标。
  - 改进下一代策略的失败分布，形成“失败→监督→新失败”的自演化闭环。
- **实验方法严谨**：
  - 评估集固定、场景无重叠；
  - 配对场景聚类 bootstrap 置信区间；
  - 评估期持久失败检测器在独立 SFT 子集上校准并冻结，避免信息泄漏；
  - 提供完整复现配置与代码。

## 8. 不足与局限

- **统计效力有限**：单训练种子、无并行重复，评估置信区间只反映评估采样不确定性，不反映训练随机性。
- **非等计算比较**：FIRE-VLA 额外教师前向和优化器重启使其消耗更多计算资源，论文未进行等计算量对照。
- **缺少消融**：未分别证明失败路由阈值、PSD 损失、教师轮换的必要性；端到端对比无法归因各组件。
- **提示集不连续**：两轮使用不同提示子集，无法纵向跟踪同一提示的演化。
- **仅开环评估**：未测量闭环驾驶安全性、交通规则合规、舒适性或状态转移误差；无法断言实际驾驶性能提升。
- **收益局限**：平均 L2 改善主要来自稀有严重 rollouts，普通轨迹性能没有提升甚至略有下降；对大多数样本的实用性收益不明确。
- **奖励函数饱和**：有界倒数奖励在误差很大时几乎无梯度差异，可能导致奖励与物理风险的 Pearson 相关性极低（约 0.08），潜在的优化目标与评测指标不一致。
- **外部有效性**：基于 nuScenes 单一数据集、单一大模型（Qwen2.5-VL-3B），结论向其他数据集、模型大小或真实路况推广需谨慎。
